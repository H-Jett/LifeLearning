## 1. 杀青三个目的之间的冲突是什么？

**参考答案**：三个目的对**时间**和**温度**的要求方向相反。

| 目的 | 要求 |
|------|------|
| ① 钝化酶 | 叶温**尽快**升到 70 ℃ 以上 → 要**高温、快** |
| ② 散失青气 | 挥发低沸点青草气物质 → 要**时间**和透气 |
| ③ 失水变软（失重 30%~40%） | 便于揉捻成型 → 要**时间**；但失水过多会焦 |

**冲突**：①要"快而猛"，②③要"有时间"。于是每个方向都有两端的坑：

- 温度不够 / 升温慢 → 在酶活跃区停留过久 → **红叶红梗、闷红黄味**；
- 温度过高 → 叶绿素破坏过多 → **焦边、爆点**；
- 时间不够 → **青气未散、揉不成条**；
- 时间过长 → 闷黄、失水过度。

**为什么说"没有安全区间，只有平衡点"**：因为不存在一组参数能让三个目的同时达到最优，
只能取折中；而且**平衡点随鲜叶的嫩度、含水量、投叶量而移动**——
这就是为什么杀青依赖经验判断（叶质、香气、失重），而不是照搬温度表。

## 2. 为什么必须"最短时间内"升到 70 ℃ 以上？

**参考答案**：因为**升温途中必然经过酶的最适活动区（20~45 ℃），而在那里温度每升高 10 ℃，
酶活性增加一倍**。

所以慢慢加热和快速加热，**终点相同但过程完全不同**：

| | 快速升温 | 缓慢升温 |
|---|---|---|
| 在 20~45 ℃ 停留 | 极短 | 长 |
| 这段时间的酶活性 | 高但没时间干活 | 高**且有充足时间** |
| 实际发生的氧化量 | 很少 | **大量** |
| 结果 | 色泽匀绿、清香 | **红叶红梗、闷红黄味** |

**一句话**：慢升温等于**在你想灭酶之前，先把它催活了**。
这是第 4 章那条"温度既是开关也是油门"的直接应用。

**实践上怎么保证快**：锅温足够高、**投叶量不过多**（叶多则升温慢）、翻炒充分使受热均匀。

## 3. 筒温 260 ℃ 与叶温 80~85 ℃ 矛盾吗？

**参考答案**：**不矛盾**，因为它们是两个不同的物理量。

| 参数 | 含义 |
|------|------|
| **筒温 / 锅温** | **设备表面温度**（滚筒内壁、锅面） |
| **叶温** | **叶片本身的温度**——这才是决定酶死活的温度 |

叶温远低于筒温的原因：

1. **蒸发吸热**——鲜叶含水约 75%，受热后水分剧烈汽化，大量吸收潜热，把叶温"压"住；
2. **接触是瞬时的**——叶子在翻动，与高温面只是间断接触，不是持续贴着；
3. **热阻**——叶片表面有蒸汽膜，传热效率有限。

所以工艺上用高筒温，正是为了**在短时间内把足够的热量灌进去**（回到第 2 题：要快），
而叶温则被含水量自然限制在 100 ℃ 以下。

**实践含义**：读工艺参数时必须先问"**这是锅温还是叶温**"。
把 260 ℃ 拿去对照第 4 章的酶温度节点，会得出"茶叶早就烧焦了"的荒谬结论。

## 4. 四类绿茶的命名依据分别是什么？

**参考答案**：

| 类别 | 命名依据 |
|------|----------|
| **蒸青绿茶** | **杀青方式**（蒸汽杀青） |
| **炒青绿茶** | **最终干燥方式**（炒干） |
| **烘青绿茶** | **最终干燥方式**（烘干） |
| **晒青绿茶** | **最终干燥方式**（晒干） |

两层逻辑：先按杀青方式分为**炒热杀青**与**蒸汽杀青**；蒸汽杀青的即蒸青；
炒热杀青的再按**最终干燥方式**分为炒青、烘青、晒青。

**晒青毛茶这个例子为什么关键**：

> 普洱生茶的原料（晒青毛茶）**也是锅炒杀青的**，但因为最终**晒干**，所以归**晒青绿茶**。

如果"晒青"指杀青方式，这就直接矛盾了——它明明是炒的。
这个反例一次性证明了**命名的落脚点在干燥环节**。

**为什么容易混**：炒青类里**炒与干往往一体**（边炒、边做形、边干燥），
所以"炒青"听起来像在说杀青。

**⚠️ 考试口径**：教科书标准表述是"根据**杀青方式和干燥方式**的不同分为四类"，
即两个标准合用。若题目只问炒青与烘青的区别，答**干燥方式**。

## 5. 烘青做花茶坯是"降级使用"吗？

**参考答案**：**不是，是匹配。**

烘青的香气特征是**清鲜、带烘烤香、比较沉稳**，一般**不及炒青高扬**。
做花茶要窨入茉莉等花香，需要茶坯**不与花香打架**：

- 若用香气高扬的炒青（如带栗香的龙井类）做坯，**茶香与花香互相干扰**，两败俱伤；
- 烘青香气清雅、内敛，**能托住花香而不抢戏**，同时条索完整、吸附性好。

所以这是**风味目标的匹配**，不是把次品打发去做花茶。

**佐证**：烘青里有的是名茶——**黄山毛峰、太平猴魁、六安瓜片**都是烘青绿茶，
品质特优。可见"烘青 = 低级"完全不成立。

**可迁移的判断**：本书反复出现的原则——**不同工艺是不同目标下的取舍，不是质量等级**
（对照第 4 章：红碎茶浓强 vs 工夫红茶香甜）。

## 6. 龙井青锅"用力先轻后重"，过早和过迟各出什么问题？

**参考答案**：

| 时机 | 问题 | 原因 |
|------|------|------|
| **用力过早** | **挤出茶汁 → 茶色变暗发黑** | 此时叶片含水量还高、细胞饱满脆弱，重压直接把汁液挤出叶表；茶汁在高温锅面上氧化、焦化，形成暗黑色泽（对照第 4 章：破坏细胞 = 让多酚与酶相遇） |
| **用力过迟** | **产生茶末，或形成"空壳燥"** | 叶片已经失水变脆，这时才加压 → 直接压碎成末；或者外层已定型干硬而内部水分未走透，形成外壳硬、内里空的"空壳燥"，成品外形不实、易碎 |

**所以正确顺序是"先轻后重"**：

1. 初期含水高 → 轻手法（抓、抖）为主，**先散水、理条**；
2. 随着失水、叶片变柔韧 → 逐步加压（搭、拓）**做扁平**；
3. 到辉锅后半段才用**压**（正文明确：压只用于辉锅后半阶段），此时定形、增光滑。

**本质**：加压的时机要跟着**叶片含水率**走——这与第 4 章"工艺参数的前提是原料状态"是同一个道理。

## 7. 中国改锅炒、日本留蒸青，各自优先了什么？

**参考答案**：

| | 中国（明代起改锅炒） | 日本（沿用蒸青） |
|---|---|---|
| **优先** | **香气** | **绿色 + 鲜爽（旨味）** |
| 手段 | 高温锅炒，促进香气物质形成与转化 | 蒸汽杀青（温度较低），最大限度保留叶绿素 |
| 得到 | 香高、栗香/清香显、滋味浓爽 | "三绿"（干茶深绿、汤色碧绿、叶底青绿）、鲜感强 |
| 放弃 | 部分绿色（炒制中叶绿素破坏更多） | 香气（蒸青**香气弱、带青气**、涩味相对重、不够鲜爽） |

正文点明了改制的原因：蒸青相比炒青**香气带青气、涩味重、不鲜爽**——
这正是明代中国改用锅炒的动因。

**日本怎么补上鲜爽这一块**：靠**农艺**而不是工艺——**遮阴栽培**（第 1 章 1.5 节）
大幅降低酚氨比（实测可降到 4~5），让玉露、抹茶达到极致的鲜。
所以日本走的是"**低温保色 + 遮阴提鲜**"的组合拳。

**结论**：**没有谁对谁错，是两种风味目标下的不同取舍。**
这也解释了为什么两国绿茶喝起来像两种饮料。

## 8. 为什么绿茶的品质上限几乎完全由鲜叶决定？

**参考答案**：因为绿茶的工艺是**"冻结"而非"创造"**。

回到第 4 章的机制表：

- **绿茶**：一上来就杀青灭酶 → 此后**没有酶促氧化**去改造成分 →
  成品的成分格局 ≈ 鲜叶的成分格局。工艺能做的只有"保住"和"别做坏"；
- **乌龙茶**：萎凋 → **做青**（局部、部分氧化）→ 杀青 → 揉捻 → 干燥（+ **焙火**）。
  它的核心风味（花果香、韵）是在**做青和焙火中被创造出来的**，鲜叶只是底物。

对照第 1~3 章：绿茶的鲜爽直接取决于**酚氨比**，而酚氨比由品种（小叶种）、
季节（春茶）、海拔、遮阴、嫩度决定——**全在鲜叶层面**。
所以名优绿茶极度依赖明前、高山、良种。

**推论（很实用）**：

1. **绿茶最"诚实"**——原料差就是差，工艺救不回来；
2. 反过来，**乌龙茶更依赖制茶师傅**——同样的鲜叶，做青水平能拉开巨大差距；
3. 所以买绿茶要盯**产地、季节、品种、等级**；买岩茶要盯**做青与焙火水平**（第 9 章）。

## 9.（进阶）怎么判断辉锅温度哪个数据可信？

**参考答案**：本题练的是**用内部一致性做证据审查**，在拿不到原始文献时尤其有用。

争议：主流资料给辉锅锅温 **60~90 ℃**，个别资料给 **150~180 ℃** 并同时称"低于青锅"。

**线索一：自相矛盾。**
正文给出青锅锅温是 **80~100 ℃**。若辉锅是 150~180 ℃，那它**远高于**青锅，
与同一句话里"低于青锅"直接冲突。**一个内部矛盾的说法，可信度立刻大幅下降。**

**线索二：工序目的。**
青锅要**杀青**（需要快速把叶温推到 70 ℃ 以上，所以锅温高）；
辉锅是**整形 + 干燥**，此时叶子已经七八成干、含水很低。
低含水的叶子**没有足够的蒸发吸热来保护自己**——用 150~180 ℃ 去炒，
叶温会迅速逼近锅温，结果必然是焦糊。而成品要求是"扁平光滑、茶香透出"，不是焦。

**线索三：成品含水率。**
辉锅结束时含水降到 **5%~7%**。把水分从七八成干降到 5%~7% 需要的是
**持续、温和的低温脱水**（20~25 min），不是猛火。猛火会外焦内湿——
正是青锅段"空壳燥"的成因（第 6 题）。

**线索四：手法约束。**
辉锅要求"**手不离茶，茶不离锅**"，是**手工持续接触**的操作。
150~180 ℃ 的锅面，手是没法长时间贴着炒的——**人体工学直接排除了这个数值**。

**结论**：60~90 ℃ 与四条线索全部自洽，150~180 ℃ 与其中至少三条冲突。
本书采用前者。

**可迁移的方法**：拿不准数据时，别只比"哪个来源看起来权威"，
而是检查它**与同一体系内其他约束是否自洽**——工序目的、物理过程、
上下游参数、操作方式。**自相矛盾的说法可以直接排除。**

## 附：6.9 节「无器具版加餐」答案 —— 给杀青缺陷找原因

| 审评记录 | 最可能的成因 | 机理 |
|----------|-------------|------|
| **1. 干茶有红梗红叶，汤色泛黄，有闷味** | **杀青温度太低 / 投叶过多 → 升温太慢** | 叶子在 20~45 ℃ 酶活跃区停留过久，发生了不该有的酶促氧化（第 2 题）。"闷味"还提示摊放或杀青中透气不足 |
| **2. 叶底有焦边和黑色斑点，香气带火焦气** | **杀青温度过高** | 叶缘薄、先失水，最先焦化；叶绿素被大量破坏。也可能是翻炒不匀，局部长时间贴锅 |
| **3. 香气有明显青草气，滋味生涩** | **杀青程度不足**（时间不够 / 温度偏低） | 低沸点青草气物质未挥发掉（杀青目的②未达成）；同时多酚未经充分转化，生涩留存 |
| **4. 汤色黄暗，有水闷味，叶底不匀** | **杀青后未及时摊凉**，或**摊叶过厚**；叠加原料不匀 | 余温继续推动黄变与湿热作用 → 水闷味（第 4 章"停的动作有延迟"）。"叶底不匀"另指向采摘环节的原料不均一（第 3 章"五分开"） |

> **一条诊断经验**：绿茶的缺陷几乎都能追到**杀青的温度或时间**上，
> 但**"不匀"类缺陷要往前追到采摘**。这正是第三部分（审评）要系统训练的能力：
> **从感官反推工艺出了什么问题。**
