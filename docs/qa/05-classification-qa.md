# 第 5 章 · 思考题参考答案

> 只记录问题与参考答案。对应正文《第 5 章 5.8 思考题》。

<a id="q1"></a>

## 1. 为什么"加工工艺"必须是主、"品种产地"只能是辅？

**参考答案**：因为**只有工艺是决定成品性质的直接原因**，其余都是间接的、可替换的。

- **同一批鲜叶，走不同工艺 → 六种完全不同的茶**。这说明工艺的解释力最强。
- **同一个品种，可以做成好几类茶**。福鼎大白茶能做白茶也能做绿茶、红茶；
  云南大叶种能做红茶、普洱，也能做绿茶（第 2 章有实证）。
- **同一个产地产多种茶类**。武夷山既产岩茶（乌龙）也产正山小种（红茶）。

**如果反过来（品种/产地为主）会出什么问题**：

1. **分类不唯一**：同一品种做出的绿茶和红茶会被归进同一类，而它们的成分格局、
   冲泡方法、审评术语完全不同——分类就失去了指导意义；
2. **无法容纳新茶**：新品种、新产区出现时无处安放；
3. **与国际不兼容**：ISO 20715 同样按加工工艺和品质特征分类，
   若按产地分则无法与国际标准对齐。

**但"辅"也不是没用**：品种（安吉白茶的白化品种）、原料（嫩度等级）、
产地（地理标志）是在**大类之下再细分**时的依据。

<a id="q2"></a>

## 2. 安吉白茶、大红袍两个例子共同说明什么？

**参考答案**：说明一条硬原则——

> **决定茶类的是工艺，不是名字。**

- **安吉白茶**：名字里的"白"指**白化品种**（低温期叶片返白，氨基酸含量特别高），
  但它的工艺是杀青 → 揉捻 → 干燥，是**绿茶**。
- **大红袍**：是武夷岩茶，工艺走萎凋 → 做青 → 杀青 → 揉捻 → 干燥（+ 焙火），
  是**乌龙茶**，与红茶毫无关系。

**为什么会有这种命名**：茶名多来自历史、外形、传说、产地，形成时间**远早于**1979 年的六大茶类体系。
名字是"民间叫法"，分类是"科学体系"，两者本来就不同步。

**同类陷阱还有**：君山银针（黄茶）vs 白毫银针（白茶）；安化黑茶 vs 黑乌龙；
以及英文里红茶叫 black tea、黑茶叫 dark tea——**颜色命名系统本身就不自洽**。

## 3. 杀青的位置有哪三种情况？

**参考答案**：

| 位置 | 茶类 | 工艺意图 |
|------|------|----------|
| **在最前面**（第一道工序） | 绿茶、黄茶、黑茶 | **一上来就灭酶**，把成分冻结。此后的变化（闷黄的湿热、渥堆的微生物）都**不依赖茶叶自身的酶** |
| **在氧化工序之后** | 乌龙茶 | **先放后收**：让做青把氧化推进到想要的程度，再用高温**叫停**。这是唯一"可控中途终止"的设计 |
| **根本没有杀青** | 红茶、白茶 | 红茶要氧化走完全程，靠**干燥**终止；白茶不主动灭酶，靠**失水**让酶活性自然衰减 |

**为什么这个位置最关键**：因为杀青是"酶的开关"。开关放在流程的哪一格，
就决定了这类茶允许发生多少酶促氧化——**这正是六大茶类分野的物理本质**。

## 4. 黄茶和黑茶都是"绿茶 + 一步"，为什么差别极大？

**参考答案**：因为**加的那一步机制不同、程度也相差悬殊**。

| | 黄茶（+ 闷黄） | 黑茶（+ 渥堆） |
|---|---|---|
| 机制 | **湿热作用为主**（±残余酶） | **微生物作用** + 湿热 |
| 主体 | 茶叶自身的化学变化 | 外来微生物（黑曲霉等）及其**胞外酶** |
| 程度 | **浅尝即止** | **充分尽致** |
| 时长量级 | 数小时到数十小时 | 数十天（渥堆）到数年（陈化） |
| 结果 | 去青气生涩、转甜醇，仍近似绿茶 | 多酚被大量消耗、变 TB 与不溶物，红褐陈醇 |

第 4 章那个类比很到位：**两者都以绿茶为起点，只是走了远近不同的路程**。

**还有一层**：渥堆引入了**茶叶之外的生物系统**，所以黑茶的品质还取决于菌群、
堆温、翻堆等一整套变量，且**不同黑茶的优势菌种不同**（茯砖灰绿曲霉、米砖黑曲霉、
康砖青霉……）。黄茶没有这一层复杂度。

## 5. "按发酵程度排序"在哪两类茶上失真？

**参考答案**：在**黄茶**和**黑茶**上失真。

- **绿 → 白 → 青 → 红**：这几类的差别确实主要是**酶促氧化程度**的差别，排序成立；
- **黄茶**：主导机制是**湿热作用**（±残余酶），不是酶促氧化。把它塞进"轻发酵"位置是勉强的；
- **黑茶**：主导机制是**微生物作用**。

**为什么说黑茶"不在这根轴上"**：

1. **起点不同**——黑茶是从**绿茶（已灭酶）**分出去的，它的转化发生在酶已经死掉之后；
2. **主体不同**——干活的是微生物的胞外酶，不是茶叶自身的酶；
3. **方向不同**——渥堆让多酚**大量减少**（变茶褐素、变水不溶物），
   而"氧化程度轴"描述的是多酚**被氧化成什么**。用一根轴同时描述两种机制，会得出错误直觉
   （例如"黑茶是发酵最彻底的茶"——这句话把两种"发酵"混为一谈了）。

**正确的心智模型**：一根轴（绿→白→黄→青→红）+ 一条从绿茶分出去的岔路（黑茶）。

## 6. 白茶"不揉捻"意味着什么？为什么反而更难做？

**参考答案**：

**不揉捻 = 不主动破坏细胞结构**。回到第 4 章的隔离设计：多酚在液泡、酶在质体，
**只有细胞结构被破坏，两者才能相遇**。揉捻/摇青正是干这个的。

所以白茶的氧化只能靠**失水过程中细胞逐渐、自然地解体**来推动。后果有三：

1. **速度慢**——所以萎凋要 35~50 小时，而红茶发酵只要 2~3 小时；
2. **程度轻**——细胞破损率低，氧化总量有限，所以白茶是轻氧化；
3. **不均匀**——自然解体的进程无法像揉捻那样一次性、均匀地触发。

**为什么反而更难做**：

> **能调的旋钮太少。**

白茶只有萎凋和干燥两道工序，可控变量只剩**温度、湿度、时间、摊叶厚度**。
没有揉捻可以调整破损率，没有杀青可以精确叫停，没有发酵室可以设定参数。
而失水速率**两端都是缺陷**：太快（强日光）晒伤、色泽花杂、芽叶枯红；
太慢（低温高湿）氧化走不动、**青气不退、色泽偏暗**（第 4 章有实测对照）。

**一句话**：工序少 = 容错率低。"最简单"和"最好做"是两回事。

## 7. 用"氧化度百分比"论证茶类差别，问题在哪？

**参考答案**：至少三个问题。

1. **没有标准依据**。**国标并没有给各茶类规定氧化百分比**。GB/T 30766 的分类原则是
   "加工工艺、产品特性为主"，通篇不是按氧化度定义茶类的。这些数字是行业经验说法。
2. **"氧化度"缺乏统一测定方法**。要说"氧化了 70%"，得先定义**分母**是什么
   （全部多酚？儿茶素总量？）、用什么方法测、在哪个时间点测。这些都没有公认答案。
   对照第 1 章：**茶红素的含量报道从 5%~11% 到 5%~27% 都有，就是因为测法不同**——
   氧化度只会更混乱。
3. **区间宽到失去判别力**。"乌龙茶 15%~70%"横跨了从接近绿茶到接近红茶的整个范围，
   这样的数字无法用来判定任何具体样品。

**那该怎么说**：用**相对方向**（"乌龙茶的氧化程度介于绿茶与红茶之间，且因品类差异很大"），
以及**机制**（局部、部分、可控中止）。方向和机制是可靠的，精确数字不是。

**可迁移的判断**：遇到任何精确百分比，先问三件事——**谁定的标准？怎么测的？分母是什么？**

## 8.（进阶）普洱生茶该归哪一类？

**参考答案**：这是一个**至今没有统一答案**的问题，本书标为**有争议**。两种主张各有依据。

**主张 A：归晒青绿茶（工艺派）**

- 生茶的原料是**晒青毛茶**，工艺为：鲜叶 → 杀青 → 揉捻 → **晒干**。
  按 GB/T 30766"以加工工艺为主"的原则和绿茶的定义（杀青→揉捻→干燥），
  这**完全符合绿茶、且属晒青绿茶**；
- **紧压只是形状**，属再加工，不改变茶类归属；
- 新制生茶的感官特征（黄绿汤色、青气、苦涩、高多酚）也更接近绿茶。

**主张 B：归黑茶 / 普洱茶自成一类（产品派）**

- **GB/T 22111《地理标志产品 普洱茶》**把普洱茶分为**生茶与熟茶**，
  即在产品标准层面把生茶纳入"普洱茶"名下；
- 生茶的**目标形态是陈化后的产品**，而不是新制状态。经年陈化后其成分格局
  （多酚下降、茶褐素上升）和感官表现与绿茶相去甚远；
- 晒青毛茶**保留了部分酶活性**（叶温多在 80 ℃ 以下，第 4 章），
  这正是它区别于烘青/炒青绿茶、能够长期转化的关键——从"可转化性"看它不同于普通绿茶。

**为什么难以靠工艺逻辑单独解决**：

1. **分类的时间点不同**。按工艺分类看的是**制成那一刻**，按产品特性分类看的是
   **消费时的状态**。生茶恰好是"制成时像绿茶、陈化后像黑茶"的品类——
   而 GB/T 30766 的原则是"加工工艺**与**产品特性**为主**"，两个依据在这里**指向不同答案**。
2. **两个标准的目的不同**。GB/T 30766 是分类标准，GB/T 22111 是**地理标志产品**标准
   （保护"普洱茶"这个名称），后者本就不以茶类划分为目的。
3. **利益与习惯**。产业界习惯把生熟并称"普洱茶"，改口的成本很高。

**本书的处理**：讲清两种主张与各自依据，**不替读者裁定**；在需要判断具体问题时
（如"生茶能不能长期存"）回到**机理**层面回答（第 11 章），而不是靠归类回答。
