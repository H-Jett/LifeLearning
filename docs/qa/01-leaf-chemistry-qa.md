# 第 1 章 · 思考题参考答案

> 只记录问题与参考答案。对应正文《第 1 章 1.9 思考题》。

<a id="q1"></a>

## 1. 为什么夏茶更适合做红茶、春茶更适合做绿茶？

**参考答案**：核心是**酚氨比**的季节性差异。

- **春茶**：气温低、生长缓慢，茶树的**氮代谢**相对旺盛，氨基酸（尤其茶氨酸）累积多；
  同时光照弱、多酚合成少 → **酚氨比低** → 滋味鲜爽、苦涩轻。
  绿茶工艺是"高温杀青把成分冻结在原样"，它**不改造多酚**，所以原料本身就得鲜爽——春茶正合适。
- **夏茶**：光照强、气温高，**碳代谢**旺盛，茶多酚合成多、氨基酸相对少 → **酚氨比高** →
  直接做绿茶就是苦涩重。但红茶工艺要让多酚**充分氧化**成茶黄素/茶红素，
  **多酚是原料**——原料多，转化出的浓强度才够。

**"适制性"的含义**：一份鲜叶（由品种、季节、生态、嫩度共同决定的成分格局）
**更适合被加工成哪一类茶**。它是"原料成分格局"与"工艺改造方向"的匹配问题，
不是"这茶好不好"的问题。同一批夏茶做绿茶是次品、做红茶可能是好货。

> 这条推理是全书的缩影：**工艺 = 定向改造成分，所以原料要和改造方向匹配。**

## 2. "茶多酚越高品质越好"错在哪一步？

**参考答案**：错在**把某个单一成分的绝对量当成了品质指标**，跳过了"成分比例"这一层。

拆开看，这句话隐含两步推理，两步都有问题：

1. **"茶多酚 = 好东西"**：茶多酚在感官上贡献的是**苦、涩**。它是不是优点，取决于要做什么茶：
   做浓强型红茶是优点，做鲜爽型绿茶就是缺点。
2. **"多 = 好"**：茶的品质取决于**茶多酚 / 氨基酸 / 咖啡碱 / 糖 的比例是否协调**（酚氨比）。
   多酚单方面升高，通常意味着酚氨比升高，即苦涩压过鲜甜。

这句话之所以流传，是因为它混入了**健康宣传的语境**（茶多酚的抗氧化性）。
但"可能有益的成分含量"和"喝起来好不好"是两个独立问题，不能互相替代。

> 通用原则：**茶的品质从来不是某个成分越多越好，而是几种成分的比例是否协调。**

## 3. 沸水泡苦涩、85 ℃ 泡鲜甜，为什么？

**参考答案**：因为不同成分的**溶出速度和温度敏感性不同**，水温本质上是在**改变茶汤的成分配比**。

至少三条：

1. **氨基酸溶出快、且低温也能充分溶出**。85 ℃ 时鲜味物质该出来的基本都出来了——
   **降温几乎不损失鲜爽**。
2. **酯型儿茶素（EGCG、ECG）溶出慢、且高度依赖高温**。沸水会让它们大量进入茶汤——
   这是苦涩暴涨的主因。85 ℃ 相当于**给苦涩加了一道闸**。
3. **咖啡碱的溶解度随温度显著升高**，高温下苦味明显加强。

所以 85 ℃ 的效果不是"味道整体变淡"，而是**鲜甜基本保留、苦涩被压制** → 相对更鲜甜。
如果只是等比例变淡，你会觉得"水"，而不是"更鲜"。

**顺带一个反向推论**：武夷岩茶、普洱之所以要沸水，正是因为它们**需要**后段那些高温才溶出的东西——
多酚构成的"骨"、多糖构成的"稠"，以及只有沸水才激发得出来的高沸点香气。
**没有"最好的水温"，只有"和这款茶的目标风格匹配的水温"。**

## 4. 红茶放凉变浑浊，发生了什么？好事坏事？

**参考答案**：这是**冷后浑**（cream down），**通常是好事**。

**机制**：红茶中的**咖啡碱**与儿茶素的氧化产物**茶黄素、茶红素**形成络合物。
这类络合物在高温时溶解、低温时溶解度下降而析出，形成悬浮的细微颗粒 → 汤色转浑、甚至出现"乳凝"。

**为什么是正面信号**：它的出现需要**咖啡碱和茶黄素/茶红素都足够多**，
也就是内含物丰富、氧化程度到位。传统上判断优质工夫红茶，冷后浑是一个加分项，
常与"浓、强、鲜"的评价同时出现。

**要与真正的问题区分开**：

| 现象 | 判定 |
|------|------|
| 放凉后均匀转浑、回温后**能复原**，无异味 | 冷后浑，正常/正面 |
| 有酸馊、陈霉、异杂气味 | 劣变（第 19 章） |
| 汤中有明显沉渣、絮状漂浮物且伴异味 | 可能是杂质或变质，另作判断 |

## 5. "苦"和"涩"是同一回事吗？为什么要分开记？

**参考答案**：**不是同一回事，甚至不属于同一种感觉类型。**

- **苦是味觉**：咖啡碱、酯型儿茶素等刺激味蕾上的苦味受体。**即时**发生，舌根较明显，
  且味觉会疲劳适应。
- **涩是触觉 / 化学感**，不是味觉：多酚与唾液中的蛋白质结合并沉淀，
  口腔黏膜的**润滑性下降**，产生收敛、发干、起皱的机械感。因此它**有延迟**（下咽后几秒才起来）、
  **会累积**（连喝几杯越来越涩）、覆盖整个口腔而非某个味区。

**为什么审评必须分开记**：因为两者指向的**工艺问题不同**，混在一起就丢失了诊断信息：

| 感受 | 常见指向 |
|------|----------|
| **涩重、涩而不化** | 多酚未充分转化：做青不足、发酵不足；或鲜叶粗老、雨水叶 |
| **苦重** | 品种特性（大叶种）、咖啡碱高；或投茶过量、浸泡过度（冲泡问题，不是茶的问题） |

如果只写"味道重"，你无法判断该调工艺还是调冲泡。这就是审评术语要规范化的原因（第 15 章）。

**补充**：适度的涩是正常的，构成茶汤的"劲"和层次。真正的缺点是**涩而不化**——
迟迟不消退、伴随发麻发苦。

## 6. 玉露/抹茶为什么遮阴？想得到什么、代价是什么？

**参考答案**：遮阴（覆下栽培）的目标是**大幅降低酚氨比**，把鲜爽推到极致。

**机制**（两个方向同时作用）：

1. **光照促进茶多酚（尤其儿茶素）的合成**。遮去大部分光照 → 多酚合成减少 → **苦涩下降**；
2. 遮阴条件有利于**茶氨酸的累积与保留**（茶氨酸在光照下会向儿茶素方向转化消耗）→ **鲜甜上升**。

分子变少 + 分母变多 → 酚氨比大幅下降 → 极致的鲜（umami）、涩感很低。
这也是抹茶能"整片叶子磨粉吞下去"的前提：如果多酚很高，全叶摄入会苦涩到无法接受。

**代价（至少四条）**：

1. **产量下降**：遮光就是减少光合作用，新梢生长变慢、单产降低；
2. **成本大幅上升**：遮阴材料、人工管理、通常还要求手采；
3. **风格变窄**：香气类型改变——少了阳光带来的某些香气成分，
   得到的是"鲜到极致但不奔放"的风格，而非高香型；
4. **对茶树有负担**：长期遮阴影响树势，需要配套的养护管理。

> 这道题的价值在于：**任何工艺/农艺手段都是有代价的取舍**，
> 看懂"得到什么、失去什么"比记住"玉露要遮阴"重要得多。

## 7.（进阶）水浸出物都是 40%，为何一款"厚而甜"一款"浓而涩"？

**参考答案**：因为水浸出物是**总量指标**，不含**结构信息**。

同样 40% 的可溶物，可以有完全不同的组成：

| | "厚而甜"的那款 | "浓而涩"的那款 |
|---|---|---|
| 氨基酸占比 | 较高 → 鲜、甜 | 较低 |
| 可溶性糖 / 果胶多糖 | 较高 → **稠、滑、厚** | 较低 |
| 酯型儿茶素（EGCG/ECG） | 较低 | **较高 → 强苦强涩** |
| 咖啡碱 | 一般 | 偏高 → 苦 |
| 酚氨比 | 低 | 高 |

其他可能的原因（都不体现在水浸出物这个数字里）：

- **氧化程度不同**：红茶里 TF/TR 比例合适 → 鲜爽甜醇；TB 偏高 → 暗、钝、涩滞；
- **儿茶素的酯型/非酯型比例不同**（正文 1.3 节）：总多酚相同，酯型多的就是更苦涩；
- **物理形态不同**：揉捻重、颗粒细 → 前几泡溶出集中、冲击强，主观上更"浓涩"；
  整叶溶出慢 → 更"绵、匀"。

**结论**：水浸出物能有效识别**内质单薄**（数值很低 → 一定寡淡、不耐泡），
所以它作为**下限门槛**（国标常设最低限）是有意义的；但它**不能作为高分依据**——
"溶出来多少"不等于"溶出来的东西好不好、比例对不对"。

> 这是全书反复出现的判断句式：**总量相同、结构不同 → 品质不同。**
> 遇到任何单一数字指标（水浸出物、茶多酚含量、年份、海拔），都要先问一句：
> 它捕捉到结构了吗？
