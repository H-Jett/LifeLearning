## 一、成分与化学

<a id="tea-polyphenols"></a>
### 茶多酚（Tea polyphenols）
茶叶中多酚类物质的总称，占干物质约 18%~36%，主体是[儿茶素](#catechin)类（占茶多酚 70%~80%）。
感官上贡献**苦**与**涩**，是茶汤滋味的最大可变量，也是红茶氧化产物的原料。
测定方法见 GB/T 8313。

<a id="catechin"></a>
### 儿茶素（Catechins）
属黄烷醇类，茶多酚的主体。分两组：
- **酯型儿茶素**（复杂儿茶素）：EGCG、ECG —— 苦涩强、收敛性强；
- **非酯型儿茶素**（简单儿茶素）：EGC、EC、C —— 苦涩较弱、偏爽口。

**EGCG**（Epigallocatechin gallate，表没食子儿茶素没食子酸酯）是含量最高的单体儿茶素。
"总多酚相同但口感不同"的主要原因之一，就是两组的比例不同。

<a id="theanine"></a>
### 茶氨酸（L-theanine）
茶树的**特征性氨基酸**，占茶叶游离氨基酸总量一半以上（不同资料给 40%~70%）。
呈**鲜**（umami）带甜的味感，且能在感官上**掩盖苦涩**。遮阴栽培可提高其含量。
游离氨基酸总量测定见 GB/T 8314。

<a id="caffeine-tea"></a>
### 咖啡碱（Caffeine，茶叶中亦称茶素）
生物碱，占干物质 2%~4%，呈**苦**味，溶解度随温度显著升高。
能与[茶黄素](#theaflavin)、[茶红素](#thearubigin)络合，低温析出形成[冷后浑](#cream-down)。
测定方法见 GB/T 8312。

<a id="phenol-amino-ratio"></a>
### 酚氨比（Ratio of polyphenols to amino acids）
`茶多酚含量 ÷ 氨基酸含量`。判断茶树品种**适制性**与滋味走向的常用单一指标：
比值低 → 鲜爽（适制绿茶）；比值高 → 浓强苦涩（适制红茶）。
常见经验划分：<8 适制绿茶、8~15 兼制、>15 适制红茶（**各教材略有差异**）。

<a id="water-extract"></a>
### 水浸出物（Water extract）
规定条件下能被水浸出的物质总量，典型为干物质的 30%~48%。对应茶汤的浓度上限与"耐泡度"。
**只反映总量、不反映结构**，因此可作为"内质单薄"的下限门槛，不能单独作为高品质依据。
测定方法见 GB/T 8305。

<a id="theaflavin"></a>
### 茶黄素（Theaflavins, TF）
儿茶素氧化聚合的产物，红茶中典型 0.3%~1.5%。呈**橙黄色**、汤色**明亮**，
带鲜爽与刺激性，是红茶"浓、强、鲜"的主要来源。

<a id="thearubigin"></a>
### 茶红素（Thearubigins, TR）
氧化产物中含量最高的一类，红茶中典型 5%~11%。呈**红色**，滋味甜醇，是红茶汤色的主体。

<a id="theabrownin"></a>
### 茶褐素（Theabrownins, TB）
深度氧化/聚合产物，红茶中典型 4%~9%，黑茶中更高。呈**暗褐色**，滋味**滞钝**。
含量过高对应审评词"红暗""欠亮""味钝"。

<a id="cream-down"></a>
### 冷后浑（Cream down）
红茶茶汤冷却后变浑浊甚至出现乳凝的现象。机制是咖啡碱与茶黄素/茶红素形成络合物，
低温下溶解度降低而析出。**不是变质**，传统上视为内含物丰富、品质好的正面表征。

<a id="astringency"></a>
### 涩（Astringency）
**不是味觉，而是触觉/化学感**：多酚与唾液蛋白结合沉淀，口腔黏膜润滑性下降，
产生收敛、发干的机械感。特征是**有延迟**、**会累积**、覆盖整个口腔。
必须与[苦](#bitterness)分开记录。

<a id="bitterness"></a>
### 苦（Bitterness）
**味觉**，由咖啡碱、酯型儿茶素等刺激苦味受体产生。即时发生、舌根明显、会疲劳适应。

<a id="hui-gan"></a>
### 回甘 / 生津（Hui-gan / salivation）
咽下后口腔返回甜感（回甘）与唾液持续分泌（生津）。现象稳定存在且与品质相关，
但**生理机制尚有争议**（对比效应 / 缓慢释放 / 反射性分泌等假说）。本书照记现象，不把任何机理当定论。

## 二、原料与栽培

<a id="suitability"></a>
### 适制性（Processing suitability）
一份鲜叶（由品种、季节、生态、嫩度决定的成分格局）**更适合被加工成哪一类茶**。
它是"原料格局"与"工艺改造方向"的匹配问题，**不是品质高低问题**。

<a id="shaded-cultivation"></a>
### 覆下栽培 / 遮阴栽培（Shaded cultivation，日语「覆下栽培」）
采摘前若干天遮去大部分光照。效果是减少多酚合成、利于茶氨酸累积 → 酚氨比大幅下降 → 极致鲜爽。
日本玉露、抹茶的关键农艺手段。代价是产量下降、成本上升、香气类型改变。

<a id="cultivar"></a>
### 品种 / 茶树品种（Cultivar）
栽培品种。大叶种（如云南大叶种）多酚高、浓强，适制红茶与普洱；
小叶种（江浙一带）酚氨比低、鲜爽细腻，适制绿茶。

## 三、工艺（第二部分展开）

<a id="fermentation-tea"></a>
### "发酵"（Fermentation，茶叶语境）
茶行业沿用的历史名词。**除黑茶外，六大茶类里的"发酵"指的都不是微生物发酵**，
而是以多酚氧化酶催化的**酶促氧化**。真正的微生物参与只出现在黑茶/熟普的渥堆等后发酵工艺。
（第 4、11 章展开。）

<a id="fixation"></a>
### 杀青（Fixation / "kill-green"）
用高温使多酚氧化酶失活，**终止酶促氧化**，把成分"冻结"在接近鲜叶的状态。绿茶的关键工序。

<a id="withering"></a>
### 萎凋（Withering）
鲜叶失水并伴随内含物缓慢转化的过程。白茶工艺的核心，也是乌龙、红茶的前置工序。

<a id="pile-fermentation"></a>
### 渥堆（Pile fermentation）
黑茶/熟普的后发酵工艺：在湿热条件下堆积，**微生物**参与，使多酚深度转化为[茶褐素](#theabrownin)等。

## 四、审评（第三部分展开）

<a id="five-factors"></a>
### 五因子（Five factors）
标准感官审评的五个评价维度：**外形、汤色、香气、滋味、叶底**。方法见 GB/T 23776。

<a id="dry-wet-evaluation"></a>
### 干评 / 湿评（Dry / wet evaluation）
干评看未冲泡的干茶（外形、色泽、匀整度、净度）；湿评评冲泡后的汤色、香气、滋味、叶底。

<a id="reference-sample"></a>
### 对样评茶（Evaluation against a reference sample）
以标准样（实物参考样）为基准做相对判断，而非凭绝对记忆打分。是评茶保持一致性的核心手段。
