# 术语表

> 一律给 **中文 + 国标术语原词（若有）+ 英文**——因为国际证书全是英文，
> 而中国市场的标签用国标术语，你必须能把两套词对上。
>
> 每个词条前有显式锚点 `<a id="...">`，正文脚注直接跳过来（GitHub / 阅读器 / 网页三边都能跳）。

## 一、基本概念与分类

<a id="gem-materials"></a>
**珠宝玉石**（gem materials）——国标 GB/T 16552 使用的总称，涵盖天然珠宝玉石与人工宝石。
注意：`珠宝玉石`、`宝石`、`玉`、`玉石` 这四个词**不能作为具体名称**给一件商品定名。

<a id="natural-gemstone"></a>
**天然宝石**（natural gemstone）——由自然界产出、具美观耐久稀少性、可加工成饰品的**单晶体**
（部分为非晶质体）。定名时**不必加"天然"二字**。

<a id="natural-jade"></a>
**天然玉石**（natural jade / natural ornamental stone）——由自然界产出的**矿物集合体**（少数为岩石），
如翡翠、和田玉。定名时可在矿物/岩石名后加"玉"字，**不必加"天然"**。

<a id="natural-organic-gem"></a>
**天然有机宝石**（natural organic gem material）——由自然界生物作用形成、含有机成分的材料，
如珍珠、珊瑚、琥珀。定名不必加"天然"，但 `天然珍珠`、`天然海水珍珠`、`天然淡水珍珠` 是**例外**
——这里的"天然"是与"养殖"相对的关键信息，必须写。

<a id="artificial-product"></a>
**人工宝石**（artificial product）——完全或部分由人工生产的珠宝玉石的**总称**，
包含下面四类：合成宝石、人造宝石、拼合宝石、再造宝石。

<a id="synthetic"></a>
**合成宝石**（synthetic gemstone）——人工制造、且自然界有**已知对应物**，
化学成分、晶体结构、物理性质与天然对应物**基本相同**。定名必须在天然品种名前加"**合成**"二字，
如 `合成红宝石`、`合成祖母绿`。**它是真宝石，只是不是天然的**——但必须标明。

<a id="artificial-gemstone"></a>
**人造宝石**（artificial gemstone）——人工制造、自然界**无已知对应物**。
定名必须加"**人造**"二字，如 `人造钇铝榴石`。`玻璃`、`塑料` 是例外，不必加"人造"。

<a id="composite"></a>
**拼合宝石**（composite stone / assembled stone）——由两块及以上材料**人工拼合**、给人整体印象的宝石。
定名要逐层写出各层材料名，最后加"**拼合石**"三字。

<a id="reconstructed"></a>
**再造宝石**（reconstructed stone）——由天然珠宝玉石的碎块/碎屑经人工熔接或压制而成。
定名加"**再造**"二字，如 `再造琥珀`、`再造绿松石`。

<a id="imitation"></a>
**仿宝石**（imitation）——用于**模仿**天然珠宝玉石的颜色、外观或特殊光学效应的材料
（可以是人工宝石，也可以是另一种天然珠宝玉石）。"仿"字必须**紧接**在被模仿的名称前；
`仿宝石` 三个字**不能单独**作为名称使用；而且——**能确定具体材料时，应当直接用材料名定名**
（能写 `合成立方氧化锆` 就不该写 `仿钻石`）。

<a id="trade-name"></a>
**商贸名称**（trade name）——市场上流行的商业叫法（如"泰山玉""藏银"）。
国标规定商贸名称**不得单独使用**，只能在质量文件中以"商贸名称：×××"的形式**附注**说明。
这条规则俗称"**二名法**"。

## 二、优化、处理与合成

<a id="enhancement-treatment"></a>
**优化处理**（enhancement and treatment）——除切磨和抛光以外，用于改善珠宝玉石外观
（颜色、净度、特殊光学效应）、耐久性或可用性的**所有方法的总称**。国标把它分成两类：优化、处理。

<a id="enhancement"></a>
**优化**（enhancement）——**传统的、已被广泛接受**的改善方法。定名时**直接用宝石名称**，
无需在名称中体现；部分方法国标要求在质量文件中附注说明。典型：热处理（红蓝宝石）、
无色油浸（祖母绿）。

<a id="treatment"></a>
**处理**（treatment）——**非传统的、尚未被广泛接受**的方法。**必须在名称中体现出来**，
如 `翡翠（漂白、充填）`、`蓝宝石（扩散处理）`、`染色石英岩`。
看到括号或"处理"字样，就意味着这件东西的价值体系完全不同。

<a id="lgd"></a>
**培育钻石**（laboratory-grown diamond, LGD）——实验室生长的钻石，主流工艺为
CVD（化学气相沉积）与 HPHT（高温高压）。它在成分与结构上**就是钻石**。
国标术语为"**合成钻石**"，GB/T 16552 的第 1 号修改单明确注明"合成钻石"又称"培育钻石"。
无论叫哪个，**都必须标明**，不能只写"钻石"。

<a id="be-diffusion"></a>
**铍扩散**（Be-diffusion）——把**铍**从外部扩散进刚玉，**根本改变致色机制**。
石头被加热到接近熔点；铍能扩散得很深、影响整颗石头，因此**缺少经典表层扩散的特征**。
⚠️ **肉眼不可检测，必须靠 LA-ICP-MS**（XRF 测不了轻元素）。

<a id="flash-effect"></a>
**闪光效应**（flash effect）——裂隙被**高折射率材料**（如铅玻璃）愈合后，
在裂隙处看到的异色闪光：**明域下蓝绿、暗域下橙红**。是**铅玻璃充填**的经典判据，
常伴**扁平气泡**与玻璃充填空洞。
⚠️ 此类红宝石**极其脆弱**：常在维修、常规清洗、重新抛光中被毁，弱酸与家用清洁剂即可损坏。

<a id="discoid-fracture"></a>
**盘状裂隙**（discoid fracture）——包裹体受热膨胀在其周围造成的圆盘状裂隙，常伴**张力晕**。
是刚玉**经过加热**的有力证据；同类线索还有丝溶解成羽毛状/点状、包裹体变圆呈"雪球"状。

<a id="b-jade"></a>
**翡翠 B 货**——经**酸洗漂白 + 聚合物浸渍**的翡翠。酸洗使结构多孔而脆，故注树脂恢复外观。
⚠️ **FTIR 是唯一在所有情况下都能给出结论性证据的方法**：B 货在 **2800~3100 cm⁻¹**
出现 A 货没有的 **C-H 伸缩峰**（约 2856、2873、2928、2958 cm⁻¹）。
**B+C 货**（浸渍+染色）几乎没有商业价值。

<a id="curved-striae"></a>
**弯曲生长纹**（curved striae）——**焰熔法**（Verneuil）合成刚玉的最具诊断性特征，
弯曲源自生长时基座旋转；纹路**跨过刻面交界延续**，常伴沿纹排列的微小气泡。
对照：**天然**刚玉的色带沿**直的、有角度的**（六方/菱面体）平面。
⚠️ 三个陷阱：抛光痕会伪装（须聚焦石头内部并确认跨刻面）、垂直光轴看会显直、需特定照明。

<a id="flux-residue"></a>
**助熔剂残留**（flux residue）——**助熔剂法**合成的痕迹，白色高突起，
可呈**两相纱幕状**（会模仿天然的指纹状包裹体）、球滴状、管状、微粒云。
伴生的**锐边三角形/六边形金属薄片或粗短铂针**（来自坩埚）**强烈指示合成**。

## 三、晶体与结构

<a id="crystal-system"></a>
**晶系**（crystal system）——按对称性对晶体的分类。宝石学常用**七个**：立方、四方、六方、三方、
斜方、单斜、三斜（有些晶体学体系把三方并入六方，只分六个——**这不是矛盾，只是分类粒度不同**）。
晶系决定了[光性](#optic-character)，因此决定了一颗宝石有没有双折射、有没有多色性。

<a id="amorphous"></a>
**非晶质体**（amorphous）——内部原子不作规则重复排列，没有晶体结构。
珠宝里的典型：欧泊、琥珀、玻璃、天然玻璃。非晶质体**没有解理、没有双折射、没有多色性**。

<a id="optic-character"></a>
**光性**（optic character）——光在宝石中的传播行为，由晶系决定，分三档：

- **均质体**（isotropic）：立方晶系 + 非晶质体。光速各向相同，**无双折射、无多色性**。
  钻石、尖晶石、石榴石、玻璃、立方氧化锆都在这一档。
- **一轴晶**（uniaxial）：四方、六方、三方晶系。刚玉、水晶、绿柱石族、碧玺。
- **二轴晶**（biaxial）：斜方、单斜、三斜晶系。托帕石、金绿宝石、坦桑石、长石族。

后两档合称**非均质体**（anisotropic），有双折射，可能有多色性（第 4 章）。

<a id="cleavage"></a>
**解理**（cleavage）——晶体沿特定结晶方向**规则**裂开的性质，是**结构决定的固有弱面**，
不是瑕疵。按易裂程度分极完全、完全、中等、不完全等级。
钻石有四组八面体解理，托帕石有一组完全的底面解理——这是"钻石也会被磕掉一块"
和"托帕石不能进超声波"的根本原因。

<a id="fracture"></a>
**断口**（fracture）——**不沿**结晶方向的不规则破裂面。最常见的是**贝壳状断口**
（conchoidal fracture，像玻璃碎裂时的弧形波纹）。
解理面平整光亮、方向固定；断口弯曲粗糙、方向随机——这是区分两者的现场判据。

<a id="parting"></a>
**裂开**（parting）——沿**双晶面**或包裹体密集面的规则破裂，外观像解理，
但成因是生长缺陷而非晶格固有弱面。刚玉（红蓝宝石）**没有解理**，
但常因聚片双晶而有裂开——所以"红宝石无解理"不等于"红宝石不怕磕"。

<a id="twinning"></a>
**双晶**（twinning）——同一矿物的两个或多个单晶体按特定对称关系连生。
聚片双晶（多层平行连生）在刚玉中很常见，它既是天然的证据之一，也是裂开的来源。

<a id="differential-hardness"></a>
**差异硬度**（differential hardness，硬度各向异性）——同一晶体**不同方向的硬度不同**。
钻石各方向硬度差异明显，切磨时必须选择可磨的方向下手——这是"钻石能被钻石磨"的**工艺基础**
（用较硬的方向去磨较软的方向）。
> ⚠️ 别把两件事搞混：**"只能用钻石磨钻石"**是因为钻石是已知最硬的物质（没有更硬的磨料）；
> **"钻石能被磨"**才是差异硬度的功劳。

## 四、颜色的成因

<a id="idiochromatic"></a>
**自色**（idiochromatic）——致色元素**是化学式的一部分**，如孔雀石里的铜、橄榄石里的铁。
**判据：碾成粉末，粉末仍有颜色**。颜色跨产地基本一致，也更稳定。

<a id="allochromatic"></a>
**他色**（allochromatic）——纯净时**无色**，颜色来自不属于理想化学成分的**微量杂质**。
碾成粉末后粉末趋于白色。刚玉族、绿柱石族、水晶、尖晶石、钻石都属此类——
这也是同一种矿物能有十几种颜色、且颜色容易被人工改变的原因。

<a id="pseudochromatic"></a>
**假色**（pseudochromatic）——颜色并非来自吸收，而是结构对光的**衍射、干涉或散射**，
如欧泊的变彩、拉长石的晕彩。详见第 6 章。

<a id="chromophore"></a>
**致色元素**（chromophore）——造成颜色的元素，主要是**过渡金属**（Cr、Fe、V、Ti、Mn、Co、Ni、Cu）。
⚠️ **同一元素的不同价态给不同颜色**：Fe²⁺ 常给蓝绿，Fe³⁺ 常给黄褐；
**同一离子在不同主晶里也给不同颜色**：Cr³⁺ 在刚玉里红（红宝石）、在绿柱石里绿（祖母绿）。

<a id="crystal-field"></a>
**晶体场**（crystal field）——致色离子周围原子的排布方式，它决定了 d 轨道能级分裂的大小，
从而决定吸收哪个波段。这是"同一离子不同主晶不同颜色"的机制。

<a id="charge-transfer"></a>
**电荷转移**（charge transfer；金属间的记作 **IVCT**）——电子在**两个相邻离子之间**转移，
两者价态同时改变。蓝宝石的蓝即 **Fe²⁺→Ti⁴⁺**，吸收带以约 588 nm 为中心。
**效率远高于晶体场跃迁**：约 0.01% 的铁钛就能显出浓蓝。

<a id="band-gap-color"></a>
**带隙致色**（band gap）——半导体型宝石的机制。纯钻石带隙宽、不吸收可见光故无色；
掺**氮**（多一个价电子，N 型）→ **黄**，掺**硼**（少一个价电子，P 型）→ **蓝**。

<a id="color-center"></a>
**色心**（color center）——晶格**缺陷**（空位、间隙离子、电子/空穴陷阱）捕获电子后吸收特定波长，
**不需要致色杂质**。烟晶、紫水晶、紫锂辉石属此类。
⚠️ **色心常常不稳定**，热与紫外可使其衰变 → **褪色**。紫水晶加热约 420~440 °C 即转绿、
超过约 440 °C 转黄水晶。

<a id="light-sensitivity"></a>
**光敏性**（light sensitivity / fading）——颜色在光（尤其紫外）作用下减弱的性质，
多见于色心致色的品种：紫锂辉石（"晚宴石"）、maxixe 型绿柱石、萤石。
⚠️ **褪色不能反推"经过人工辐照"**——很多品种天然就不稳定。

<a id="chatoyancy"></a>
**猫眼效应**（chatoyancy）——**一组**平行排列的纤维或针状包裹体反射光，形成**一条**亮带。
⚠️ "猫眼"是**效应名不是品种名**：金绿宝石、碧玺、月光石、石英等都可有猫眼，价格差别极大。

<a id="asterism"></a>
**星光效应**（asterism）——**两组或更多**相交的定向包裹体反射光，形成**星**。
射线数由主晶对称性决定：刚玉中金红石丝沿三个方向（相交 60°）排列 → **六射星**。
与猫眼效应**机制相同**，区别只在包裹体有几组方向。

<a id="silk"></a>
**丝**（silk）——宝石学对刚玉中**金红石针状包裹体**的俗称，是星光与猫眼的来源。
⚠️ **约 1400 °C 以上丝会溶回刚玉晶格**——所以刻面蓝宝石靠热处理去丝提净度，
而**星光刚玉在实践中基本是无烧的**（烧了星就没了）。黑色星光蓝宝石多含**赤铁矿**丝。

<a id="play-of-color"></a>
**变彩**（play-of-color）——欧泊特有：规则排列的**二氧化硅小球三维阵列**
构成天然衍射光栅，产生随角度变换的彩色斑块。**球径决定颜色**
（约 150~200 nm 蓝紫、200~250 nm 黄绿、250~300 nm 红橙，大于约 333 nm 无变彩）。
小球易生成故蓝色最常见，**红色最稀有最贵**。

<a id="opalescence"></a>
**乳光**（opalescence）——普通欧泊（potch）中二氧化硅球大小不一、排列混乱，
光被**随机散射**产生的乳白朦胧感。⚠️ **与变彩是两个现象**，商品描述里常被混用。

<a id="labradorescence"></a>
**晕彩**（labradorescence）——拉长石的**锐利光谱色闪光**，来自层状出溶结构的**薄膜干涉**；
层常沿解理面排列，故方向性强（转到特定角度才爆闪）。
⚠️ 市场上的**"彩虹月光石"实为拉长石**，显示的是晕彩，不是月光效应。

<a id="adularescence"></a>
**月光效应**（adularescence，也译乳光）——月光石中正长石与钠长石**交替出溶层**造成的
**弥散乳白/蓝白浮光**。以**散射**为主（层较厚且不规则），蓝白色调主要来自**瑞利散射**；
最优质的蓝色乳光其钠长石层约 100 nm。

<a id="aventurescence"></a>
**砂金效应**（aventurescence）——日光石等所含**薄片状赤铁矿或铜片**对光的**反射**，
呈点点金光。是离散颗粒的反射，机制不同于出溶层干涉。

<a id="color-change"></a>
**变色效应**（color change / **变石效应** alexandrite effect）——**换光源**时颜色明显改变，
如变石日光下蓝绿、白炽灯下紫红。机制：Cr³⁺ 强吸收黄光，留下蓝绿与红两个透射窗口，
哪个占优取决于光源。⚠️ **还需人眼参与**：有研究用 von Kries 色恒常模型说明，
仅靠光谱变化不足以解释该效应。与[多色性](#pleochroism)（换方向）严格区分。

## 五、光学与物理性质

<a id="ri"></a>
**折射率**（refractive index, RI）——光从空气进入宝石时传播速度降低的比率。
用宝石折射仪测；标准折射仪量程上限约 1.78~1.81，**钻石、锆石、莫桑石都超量程**。

<a id="birefringence"></a>
**双折射率**（birefringence, DR）——非均质宝石内两条折射光线折射率的差值。
立方晶系与非晶质体（钻石、尖晶石、石榴石、玻璃、立方氧化锆）**没有双折射**。
双折射率**大于约 0.020** 时，10 倍放大镜下可见对侧棱线**重影**（doubling）。
⚠️ 沿光轴方向观察不出现双折射，而台面常切成垂直于 c 轴——所以**必须斜看**（第 4 章）。

<a id="anomalous-birefringence"></a>
**异常双折射**（anomalous birefringence）——均质体（如钻石、石榴石）因内部**应变**
在偏光镜下产生的反应，会模仿非均质体的表现。所以"偏光镜下有反应"**不能**直接断定是非均质体。

<a id="dispersion"></a>
**色散**（dispersion）——宝石对红光（686.7 nm）与紫光（430.8 nm）折射率之差，无单位。
数值越大，白光被分解成光谱色的能力越强。钻石 0.044，莫桑石 0.104（约 2.4 倍）。

<a id="fire"></a>
**火彩**（fire）——色散在视觉上的表现：宝石闪出的**彩色**光。
是**材料 × 切工**的结果——素面（蛋面）与原石几乎不显火彩。**与折射率无关**（那决定亮度）。

<a id="brightness"></a>
**亮度**（brightness / brilliance）——白光的内部与外部反射总和，即"白亮"的程度。
GIA 在切工分级里用 **brightness**，行业口语多说 **brilliance**。由折射率与切工共同决定。

<a id="scintillation"></a>
**闪烁**（scintillation）——**明暗区域的图案**，以及宝石或光源移动时的闪光。
关键在**对比**：没有暗区就没有闪烁，所以**适度的暗区是好切工的一部分**，不是缺陷。

<a id="pleochroism"></a>
**多色性**（pleochroism）——同一颗宝石**从不同方向看颜色不同**。
两色叫**二色性**（dichroism，一轴晶），三色叫**三色性**（trichroism，二轴晶）；
均质体**没有**多色性。
⚠️ 与**变色效应**（换光源才变色）、**色带分区**（颜色固定在某区域）是三件不同的事。

<a id="dichroscope"></a>
**二色镜**（dichroscope）——把宝石两个方向的颜色**并排**呈现在同一视场里的小工具，
是观察多色性的标准手段。业余可用一片线性偏光片替代，但**不能**替它判定一轴/二轴。

<a id="sg"></a>
**相对密度**（specific gravity, SG，俗称比重）——宝石质量与同体积水质量之比。
静水称重法可自测，但**镶嵌后测不了**。

<a id="mohs"></a>
**莫氏硬度**（Mohs hardness）——抗**刻划**能力的**相对**顺序（1~10），**不是线性刻度**。
硬度高 ≠ 耐用：钻石硬度 10 但有解理、能被敲裂；翡翠硬度 6.5~7 但韧性极好。

<a id="durability"></a>
**耐久性**（durability）——GIA 框架：由**硬度**（抗刻划）、**韧性**（抗破裂）、
**稳定性**（抗热/光/化学/湿度）三个**互相独立**的性质构成。
任何一项短板都能毁掉一件首饰，所以"耐用"不是一个数字能回答的问题。

<a id="toughness"></a>
**韧性**（toughness）——抵抗**破裂与崩口**的能力，由原子成键的**方式与结构**决定
（有无弱面），与硬度是两个独立的性质。
玉石类因纤维交织结构韧性极高；钻石虽最硬但因四组解理韧性只算中等；
祖母绿硬度 7.5~8 却因内含物、裂隙与解理而韧性差。

<a id="stability"></a>
**稳定性**（stability）——抵抗**热、光、化学侵蚀与湿度变化**的能力。
三要素中**最容易被忽略、且损伤基本不可逆**的一项，而且破坏往往由"清洗"与"存放"
这类善意行为造成。多数主流宝石相当稳定，有问题的是明确的少数派
（珍珠、珊瑚、橄榄石、多孔宝石、充填件、含水宝石）。

<a id="crazing"></a>
**龟裂**（crazing）——**欧泊**因失水产生的蛛网状细密裂纹，会散射掉变彩，**不可逆**。
欧泊含水约 3~21%，故**极干燥环境（保险柜、干燥剂旁、暖气边）是隐患**。

<a id="carat"></a>
**克拉**（carat, ct）——宝石重量单位，1 克拉 = 0.2 克 = 100 分（point）。
⚠️ 与贵金属的 **K 金**（karat，含金量单位）**是两个完全不同的概念**，英文都写 carat/karat 极易混淆。

## 六、成因与产地

<a id="placer"></a>
**砂矿**（placer / alluvial deposit）——原生矿经**风化、侵蚀、搬运**后在河床或冲积层中
富集形成的次生矿床。宝石业极重要的来源，一个常见原因是原生矿不经济或难以到达。

<a id="origin-determination"></a>
**产地判定**（geographic origin determination）——由**包裹体 + 微量元素化学 + 光谱**
综合推断宝石产地。前提是"结晶环境与宝石可测性质密切相关"，因此**当两地地质环境相似时会失效**。
多数实验室把结果表述为"**产地意见**（origin opinion）"，语气弱于成分与处理判定。
历史：Eduard Gübelin 于 1940 年出具首份产地报告；Gübelin 与 SSEF 于 1950 年代系统开展，AGL 1977 年加入。

<a id="la-icp-ms"></a>
**LA-ICP-MS**（激光剥蚀电感耦合等离子体质谱）——1990 年代末以来彩色宝石产地判定的主力手段。
用紫外激光在 **30~50 μm** 光斑上剥蚀微量样品，质谱定量，许多元素检出限达 **ppb 级**。
也用于检测**铍扩散处理**等留下化学信号的处理手段。

<a id="inconclusive"></a>
**结论不确定**（inconclusive）——证据含糊时实验室给出的正式结论。
因为产地之间的成分区间**几乎总有重叠**，这是**科学上诚实**的答案，不是技术失败。
⚠️ 实际含义：**你不应按产地溢价付款**。

## 七、鉴定工具

<a id="polariscope"></a>
**偏光镜**（polariscope）——判定单折射/双折射与光性符号，可显示应变与双晶。
⚠️ **不对称原则**：**"单折射"结果可放心接受，"双折射"反应要谨慎**
——因为钻石、石榴石会因应变产生[异常双折射](#anomalous-birefringence)。复核首选二色镜。

<a id="spectroscope"></a>
**分光镜**（spectroscope）——观察**吸收光谱**，把致色机制变成可观测证据。
衍射光栅型与棱镜型都可用；⚠️ **参考图必须匹配自己的仪器类型**，否则谱图对不上。

<a id="chelsea-filter"></a>
**查尔斯滤色镜**（Chelsea Colour Filter, CCF）——只透过约 570~580 nm（黄绿）与
620~700 nm（红）两个窄窗。含铬宝石显红、铁主导者显绿或惰性。
⚠️ **它不检测铬，只检测"红光是否占优"**，所以含铁无铬的铁铝榴石也显红；
**更关键的是它不能区分天然与合成**（同为铬致色则反应相同）。
钒致色与富铁的祖母绿可能不显红。**滤色镜不鉴定任何东西，只做早期预警**；
使用时必须用**强白炽光，不能用 LED**。

<a id="raman"></a>
**拉曼光谱**（Raman spectroscopy）——用激光激发、记录晶格振动的散射谱，与参考库比对，
回答"**这是什么、包裹体是什么**"。最有力的用途在**包裹体**（既指示天然/实验室生长，也指示产地）。

<a id="ftir"></a>
**FTIR**（傅里叶变换红外光谱）——回答"**有没有充填/浸渍、有没有热处理**"，
部分场合可判天然 vs 实验室生长；也揭示钻石类型、氮聚集态与晶格缺陷。

<a id="uv-vis-nir"></a>
**UV-Vis-NIR**（紫外-可见-近红外光谱）——回答"**它为什么是这个颜色**"，
也参与产地与商业类别判定（如高钴蓝尖晶石 vs 高铁灰蓝尖晶石）。
⚠️ 其**谱图解释不能自动化**，且镶嵌件与不透明件需专门配置。

## 八、标准与机构

<a id="ngtc"></a>
**NGTC**——国家珠宝玉石质量检验检测中心，中国市场证书的主要出具方。

<a id="cibjo"></a>
**CIBJO**——国际珠宝首饰联合会，发布《蓝皮书》(Blue Books)，是国际珠宝商贸术语的通行规则。

<a id="lmhc"></a>
**LMHC**——实验室手册协调委员会，由 GIA、SSEF、Gübelin、GIT 等主要实验室组成，
发布统一术语说明（例如祖母绿充填程度的分档用词）。

<a id="report-vs-certificate"></a>
**报告 vs 证书**（report / certificate）——**没有任何实验室提供"保证"**；
所谓"证书"的正式名称是**报告**，内容是受过训练的人员给出的**审慎意见**。
这解释了为什么两家顶级实验室会对同一颗石头给出不同结论。
⚠️ 读它的正确顺序：**先看做了什么检测，再看结论**。

<a id="cma"></a>
**CMA**（中国计量认证）——**强制性、法定**。所有对社会出具公证性检测报告的机构**必须**具备，
否则违法；具国内法律效力。**证书上没有任何资质标志，基本可判定有问题**。

<a id="cal"></a>
**CAL**（质量监督检验机构授权认可）——带执法性，只有**承担政府委托任务**的机构需要；
**前提是先取得 CMA**。

<a id="cnas"></a>
**CNAS**（中国合格评定国家认可委员会）——**自愿性**，任何具备能力的实验室均可申请，
已签署国际互认协议。由原 CNAB 与原 **CNAL** 合并而来，
所以**老证书上的 "CNAL" 是正常的历史标志**。
⚠️ CMA 与 CNAS **性质不同、不是级别高低**：前者强制（国内法律效力），后者自愿（国际互认）。

<a id="agl-grading"></a>
**AGL 分级报告**——**AGL 基本是唯一提供真正彩色宝石品质分级的实验室**。
两处反直觉：净度用自有十档（FI / LI / MI / HI / EI，**2.5 倍**放大下判定）；
**颜色分级数值越低越好**（基于主色纯度，历史上 3.5 约相当于钻石 D 色）。
另有 **TQIR** 总体品质综合评级。

<a id="trade-color-name"></a>
**商贸颜色名**（trade color name）——如"**鸽血红**""**皇家蓝**"，**GRS** 以使用它们著称，
在亚洲市场能显著影响价格。⚠️ 它是**颜色判定**，**不等于**对净度与切工的综合品质分级。

## 九、钻石地基（第 12 章）

<a id="kimberlite"></a>
**金伯利岩**（kimberlite）——把钻石从地幔深处带到地表的火成岩，本身**不生成**钻石，
只是"运输工具"：钻石在金伯利岩浆里是被**裹挟**上来的"外来晶体"（xenocryst），
年龄常比寄主金伯利岩老几亿到十几亿年。⚠️ **不要与下面两个发音相近的词混淆**：
`金伯利岩`（kimberlite，一种岩石）≠ `金伯利进程`（[Kimberley Process](#kimberley-process)，
一项国际认证制度）≠ `克什米尔`（Kashmir，南亚一个蓝宝石产地，见
[第 8 章](chapters/01-gemology/08-origin.md)）——三者中文译名都带"金伯利/克什米尔"字样，
但指完全不同的东西。

<a id="diamond-paragenesis"></a>
**钻石包裹体成因组合**（diamond paragenesis）——按共生包裹体矿物把钻石分两大类：
**橄榄岩型**（peridotitic，含铬镁铝榴石、顽火辉石等，多与古老克拉通地幔有关）、
**榴辉岩型**（eclogitic，含铁铝-镁铝榴石、绿辉石，与俯冲洋壳的再循环有关）。
全球范围橄榄岩型包裹体更常见，但不同矿区比例差异很大，部分矿区榴辉岩型反而占多数。

<a id="diamond-type"></a>
**钻石分型**（diamond type）——按**氮、硼杂质**的有无与存在形式分类，用红外光谱测定：

| 类型 | 杂质特征 | 天然钻石中占比（量级） | 对颜色的影响 |
|------|---------|------------------|------------|
| **Ia**（IaA / IaB） | 氮以**聚合态**存在（A 心：两个氮原子相邻；B 心：四个氮原子绕一个空位） | **绝大多数**（常引用 95% 以上） | IaA 基本不影响颜色；IaB 偏多会带**黄到棕色调** |
| **Ib** | 氮以**孤立态**分散存在 | **约 0.1%**，天然中罕见 | 吸收更强，偏**黄到棕**（"金丝雀"彩钻多属此类） |
| **IIa** | **检测不到氮** | **约 1~2%** | 通常近乎无色；因结构畸变也可能带色（可 HPHT 处理"修复"） |
| **IIb** | 检测不到氮，**含硼** | **约 0.1%**，最稀有之一 | 硼使其呈**浅蓝到灰蓝**色，且具半导体性 |

⚠️ **这不只是颜色分类，也是识别工具**：天然钻石里 **IIa 型很罕见**（约 1~2%），
但 **CVD 法培育钻石大多属于 IIa 型**——这种"自然界罕见、实验室常见"的错位，
是鉴定培育钻的线索之一（第 18 章细讲）。

<a id="thermal-conductivity"></a>
**热导率**（thermal conductivity）——钻石**导热能力极强**，常引用值约
**2000~2500 W/(m·K)**（天然Ⅱa型，室温），远超几乎所有仿钻材料（玻璃、CZ 等）。
这正是"热导笔"（thermal tester）类检测仪的物理原理：探针快速导走热量 → 判定为钻石。
⚠️ **莫桑石的热导率同样很高**，会让只测热导的仪器**误判**（第 19 章细讲，
这也是第一部分小结提到"热导笔会把莫桑石判成钻石"的技术原因）。

<a id="allotrope"></a>
**同素异形体**（allotrope）——同一元素因原子排列方式不同而形成不同物质。
钻石与石墨都是纯碳，但钻石中每个碳原子以 **sp³ 杂化**与四个相邻碳原子
成键（键角 109.5°），构成三维刚性网络；石墨是 **sp²** 杂化、层状六方网，
层内强键、层间靠弱的范德华力松散堆叠——这是"同是纯碳，一个极硬一个当铅笔芯"的结构原因。

<a id="metastable"></a>
**亚稳态**（metastable）——室温常压下**石墨才是热力学稳定态**，钻石理论上"应该"
缓慢转变成石墨，但这个转变需要跨过极高的**活化能垒**，实际速率在人类时间尺度上
可忽略不计。所以"钻石恒久远"在物理上有一层真实依据：**不是热力学稳定，而是动力学稳定**
——这与宝石圈常说的"恒久远"营销语是两回事，不能混为一谈（见第 12 章常见说法辨析）。

<a id="kimberley-process"></a>
**金伯利进程**（Kimberley Process，KPCS）——2000 年发起、2003 年正式生效的
国际认证制度，要求成员国对出口的**毛坯钻石**进行认证，以阻断"冲突钻石"
（反政府武装用以筹措战争经费的钻石）流入市场。⚠️ **定义很窄**：
只覆盖"反政府武装 vs 合法政府"这一种冲突模式，**不覆盖国家军队/治安部队的暴力、
强迫劳动、环境与人权问题**，也**只管毛坯钻，不管切磨抛光后的成品**。
不要把"通过金伯利进程认证"等同于"开采过程完全没有问题"。

<a id="manufactured-scarcity"></a>
**人造稀缺性**（manufactured scarcity，分析性概念而非行业术语）——
指供给本身并不稀少，但通过**人为控制流通量**（囤货、限量配售、单一渠道销售）
制造出"稀缺"的市场效果。本书用这个词来描述 20 世纪钻石行业的供给管理史
（第 12 章），**它是经济学与新闻调查文献里对这段历史的概括说法**，
不是地质学结论——碳元素本身在地壳中并不罕见，稀缺的是**达到宝石级、
经济可采的金刚石**这件事（见第 12 章 §12.5）。

## 十、4C ①克拉（第 13 章）

<a id="magic-size"></a>
**魔法尺寸**（magic size / magic weight）——GIA 官方使用的行业术语，指 **0.25 / 0.50 / 0.75 /
1.00 / 1.50 / 2.00 ct** 等整数或习惯性节点：由于这些重量**需求格外集中**，
跨过门槛后每克拉单价会**不成比例地跳涨**，即使视觉上与门槛下方的石头**几乎无法区分**。
GIA 给出的例子是 0.96 ct 与 1.02 ct——肉眼几乎分不出大小，但後者价格可能**高达约 20%**。

<a id="spread"></a>
**冠径/展开**（spread）——钻石台面方向的**直径**（圆钻）或**长宽平均值**（异形钻），
是肉眼感知"大小"的真正依据。⚠️ **克拉是重量单位，不是尺寸单位**：
同样克拉数的圆钻，切工**浅**（比例"摊开"）会显得**直径更大**，切工**深**
（重量藏在亭部）会显得**直径更小**——这正是"克拉重量 ≠ 视觉大小"的物理机制。

<a id="weight-estimation-formula"></a>
**重量估算公式**（weight estimation formula）——在钻石已镶嵌、无法取下称重时，
用**平均直径² × 全深 × 常数**估算克拉重量的行业公式（圆钻常数约 **0.0061**，
该常数由钻石比重 3.52 换算而来）。⚠️ **仅为估算**，实际重量可能因切工比例、
腰围厚度而有偏差，不能代替实际称重。

<a id="rapaport"></a>
**Rapaport 价格表**（Rapaport Price List）——钻石批发行业最常用的**参考基准价格表**，
每周发布，按**克拉区间 × 颜色 × 净度**组成价格矩阵（单位为"百美元/克拉"）。
⚠️ **它不包含切工、荧光等信息**，只是交易双方议价的**起点**，不是成交价；
且其克拉区间本身就是**离散分级**（如 0.90~0.99 / 1.00~1.49 / 1.50~1.99 ct），
这正是"魔法尺寸"在批发端的制度性根源之一——跨过区间边界，整行价格跟着跳变。

<a id="tcw"></a>
**总克拉重量**（total carat weight, TCW / CTW）——一件首饰上**所有钻石重量之和**，
与单颗主石的克拉重量（ct）是**两个不同的数字**。⚠️ **总克拉重量相同的首饰，
价格可能差很多**：由主石或碎钻（melee）构成的总重量，价值差异巨大——
碎钻（通常指 0.2 ct 以下的小钻）多按"筛号"成批定价而非逐颗计重与分级，
单位克拉价格远低于同等总重量的单颗大钻（这正是克拉"越大升值越快"这条规律
在首饰层面的直接推论）。
