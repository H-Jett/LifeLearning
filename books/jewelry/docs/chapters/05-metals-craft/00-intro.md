# 第五部分 · 贵金属与工艺：先读材料与结构，再比较做工和价格

一件首饰的价值不只在主石。金属的真实成分、覆盖层、制造方法和镶嵌结构会一起影响颜色、耐久性、维修难度
与成本。本部分不把“重”“亮”“大牌”当作质量结论，而按“材料 → 结构/工艺 → 证据 → 交易条件”逐层核验。

本部分的一个底线：印记、标签、发票和检测报告提供的是不同层级的证据。印记值得记录，却不能替代对具体
货品、重量构成、处理状态和售后条款的核验。
