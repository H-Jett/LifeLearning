# 第五部分小结：贵金属与工艺速查

| 遇到的说法 | 先拆成什么 | 该保留什么证据 |
|------------|------------|----------------|
| “18K / 足金 / 白金” | 金属类别、纯度表达、颜色 | 印记、标签、发票、货号 |
| “包金 / 厚镀 / 不掉色” | 基体、表层、工艺、保养 | 覆盖层说明、售后条款 |
| “手工 / 3D 打印 / 铸造” | 制造链、成品表面、结构 | 设计确认、验收照片、维修边界 |
| “六爪 / 包镶 / 显大” | 固定方式、脆弱处保护、佩戴场景 | 石座/爪位记录、检查与维修条款 |
| “克价低 / 保值 / 原价回收” | 材料、工艺、服务、交易用途 | 报价卡、总价、回收条件与有效期 |

## 五个动作

1. 将颜色词翻译成基体、纯度和表面处理；
2. 将工艺名翻译成结构、可见质量和维修限制；
3. 以侧光和放大观察事实，不用破坏性测试自行验材；
4. 对松动、掉石、裂纹或明显镀层问题先停戴、拍照、保留部件；
5. 用同一张报价卡比较总价、材料、工艺、交付和售后，不拿保险估价当回收承诺。
