# 🛠 项目 P5：完成一次可复核的首饰选购决策

本项目把全书的材料、处理、工艺、渠道和场景知识收束为一份决策档案。目标不是找到“唯一最低价”，而是让
你能说明：买什么、为什么、证据是什么、出现问题如何处理。

## 交付物

| 项目 | 要求 |
|------|------|
| 需求卡 | 场景、预算上限、交付日、不可妥协与可让步项 |
| 三张候选证据卡 | 身份/处理、金属、结构、报告、总价、售后 |
| 排序理由 | 至少说明一项取舍和一项风险控制 |
| 付款前清单 | 订单、发票、报告、验货、退换与维修 |
| 收货记录 | 外包装、货号、印记、实物、报告和异常处理 |

## 🅐 无器具版

在网页或门店资料中选择三件候选，使用[证书核对清单](../../forms/certificate-checklist.md)与第 40 章报价卡填写
证据。任何空白字段都不得用推测补全；若最终不买，也应写明“为何证据不足”。

## 🅑 有器具版

备齐后再做：收货时连续录制开箱，以 10 倍镜记录印记、石位和可见结构，以电子秤记录整件重量（不反推成分）。
发现不符、松动或文件无法核验时停戴、保留全部部件，并在订单渠道内发起处理。

## 验收标准

1. 所有主张均有报告、标签、订单、照片或明确的“未知”标记；
2. 总价与重量口径、金属/宝石描述、服务条款能互相对应；
3. 不把保险估价、口头回收或营销词当作变现承诺；
4. 能说清一个放弃候选的原因，以及买后第一项维护动作。
