# 第一部分小结（速查）

> 这一页是**速查**，不是复习。第一部分的目标是：一块石头摆在面前，
> 你知道**该问什么问题、用什么手段回答、什么时候必须交给实验室**。
> 下面把 11 章压缩成"最该记住的那一两条"，并汇总三份清单。

## 一、11 章的核心结论

| 章 | 最该记住的 |
|----|-----------|
| **1 · 定名规则** | **名称是唯一受法律约束的信息**。扫四个关键词：`合成`/`人造`/`再造`·`拼合`/`仿`；看有没有括号与"处理"字样。⚠️ 但**名称干净 ≠ 没被动过**——"优化"（热处理、无色油浸）在名称中不体现 |
| **2 · 晶体与结构** | **硬度抗刻划，韧性抗破裂，两回事**。钻石硬度 10 却有四组解理；翡翠硬度 6.5~7 但纤维交织结构让裂纹走不远，所以能做薄手镯。**超声波清洗的禁忌来自这里** |
| **3 · 光学①** | 高折射率 → **小临界角** → 更多光被锁在内部返回眼睛 → 亮。钻石临界角 24.4°、玻璃 41.8°。**"钻石亮"与"钻石硬"无关**。彩宝的**透字测试**能一秒判断亭部漏光 |
| **4 · 光学②** | 火彩来自**色散**（钻石 0.044、莫桑石 0.104），不是折射率。看重影抓莫桑石**必须斜看 45°**（它的光轴穿过台面）。**热导笔会把莫桑石判成钻石** |
| **5 · 颜色成因** | 大多数宝石是**他色**的（纯净时无色），所以同一矿物能有十几种颜色，**颜色也最容易被人为改变**。**色心致色的品种会褪色**（紫锂辉石、maxixe 绿柱石、萤石）；褪色**不能**反推人工辐照 |
| **6 · 特殊光学效应** | 猫眼与星光**同一机制**（定向包裹体反射），区别只在几组方向。**约 1400 °C 丝会溶回晶格，所以星光刚玉基本无烧**。效应类宝石**"完美"就是危险信号**，关键动作是**看侧面** |
| **7 · 耐久性** | 耐久 = **硬度 + 韧性 + 稳定性**三项独立，任何一项短板都能毁掉一件首饰。**灰尘含石英（7~7.5）**，所以硬度低于 7 的宝石日常擦拭就会磨花。**稳定性损伤基本不可逆** |
| **8 · 成因与产地** | 产地是**品质的乘数，不是替代品**。⚠️ **越干净的石头越难判产地**（可测元素更少）；顶级实验室**会分歧**，市场按低的定价。**处理状态的价差（5~8 倍）常大于产地溢价** |
| **9 · 鉴定工具** | **鉴定是排除，不是认出**。镶嵌之后折射率与比重都测不了→**贵重裸石镶嵌前送检**。**查尔斯滤色镜不能区分天然与合成**。**仪器不产生结论，人产生结论** |
| **10 · 处理与合成** | 界线看三条：是否引入外来物质 / 是否永久 / 是否需要特殊保养。**铅玻璃充填红宝石极其脆弱**（维修清洗抛光都可能毁掉，弱酸即损）。**翡翠只认 FTIR**。**判据会随技术演进而衰减** |
| **11 · 证书体系** | 它是**报告（意见）**不是保证。**先看检测项目，再看结论**。中国证书先找 **CMA**。**跨实验室不能直接比价**（GIA 与 IGI 差约一级）。**AGL 基本是唯一提供彩宝品质分级的** |

## 二、柜台前动作清单（全书汇总）

**不需要任何工具**的动作，按使用频率排序：

| # | 动作 | 出自 |
|---|------|------|
| 1 | **要求看完整名称并逐字读**，扫四个关键词与括号 | 第 1 章 |
| 2 | **听到商贸名称就追问国标名称**（"证书上写的是什么？"） | 第 1 章 |
| 3 | **问"这件怎么清洗"**——答"超声波随便洗"而东西是祖母绿/翡翠/珍珠/欧泊，说明他不了解自己卖的货 | 第 2、7 章 |
| 4 | **透字测试**：彩宝台面朝上放在有字的纸上，能读出字 = 亭部漏光 | 第 3 章 |
| 5 | **转动 + 换光源**：分清多色性（换方向）/ 变色效应（换光源）/ 色带（都不变） | 第 4、6 章 |
| 6 | **看侧面**：识破拼合石、箔背石、刻线仿星 | 第 6 章 |
| 7 | **效应类宝石看"完美度"**：星线太锐利像画上去 → 怀疑合成或刻线 | 第 6 章 |
| 8 | **问三个耐久性问题**："有解理吗？怕不怕热和溶剂？日常戴在手上合适吗？" | 第 7 章 |
| 9 | **看镶嵌与品种是否匹配**：祖母绿/坦桑石/欧泊/月光石用开放爪镶做戒指 = 警示信号 | 第 7 章 |
| 10 | **先比品质再谈产地**；为产地付钱必须要**权威实验室的产地报告** | 第 8 章 |
| 11 | **问"有烧无烧"往往比问产地更重要**（价差 5~8 倍） | 第 8、10 章 |
| 12 | **红宝石问"有没有充填"**；蓝宝石问"有没有扩散" | 第 10 章 |
| 13 | **自己搜索进官网核验证书**，⚠️ 不扫商家二维码；**比对数据**（照片/重量/尺寸/结论） | 第 11 章 |
| 14 | **不跨实验室比价**；中国证书先找 CMA、看清机构全称 | 第 11 章 |
| 15 | **听到"我做了二十年一眼能看出"时**，问"你依据的判据是哪一年的" | 第 10 章 |

## 三、自己能判断 vs 必须送检

这条分界是第一部分最实用的产出。

### ✅ 自己（或用简单工具）能得到**较强线索**的

| 问题 | 手段 | 强度 |
|------|------|------|
| 名称是否合规、有没有关键词 | 读字 | **结论性**（这是法定信息） |
| 证书是否可核验、覆盖了哪些项目 | 官网比对数据 | **结论性** |
| 是不是玻璃 / 高 RI 仿品 | 气泡、比重（压手）、棱线锐利度、火彩过艳 | 强线索 |
| 是不是莫桑石 | **斜看 45°** 的棱线重影 + 火彩过艳 | 强线索（但仍非结论） |
| 有无拼合、箔背、刻线仿星 | **看侧面** | 强线索 |
| 亭部是否漏光（切工） | 透字测试 | 较强 |
| 多色性 / 变色效应 / 色带 | 转动 + 换光源 | 较强 |
| 耐久性风险与保养禁忌 | 查品种 + 看镶嵌 | **可直接行动** |
| 铅玻璃充填的存在 | 闪光效应（明域蓝绿 / 暗域橙红） | 线索 |

### ❌ 无论多努力都**必须送检**的

| 问题 | 为什么 |
|------|--------|
| **翡翠是否 A 货** | **FTIR 是唯一在所有情况下给出结论性证据的方法** |
| **蓝宝石是否铍扩散** | **肉眼完全不可检测**（扩散得深，缺少表层特征），需 LA-ICP-MS |
| **祖母绿的充填程度** | 需 FTIR；紫外灯只能**定位**不能定性 |
| **天然还是合成** | 常数完全相同，只能靠生长特征 + 显微镜 + 经验 |
| **产地** | 需微量元素分析；且结论是**意见**，可能 inconclusive |
| **II 型钻石 / 培育钻** | 应始终送实验室（需 DiamondView、FTIR、多激光 PL） |
| **彩宝的品质等级** | 需 AGL 这类提供分级的实验室 |

> **一条时点规则**：**贵重裸石在镶嵌前送检**——
> 镶嵌后折射率与比重都失效、亭部与腰棱被遮挡（第 9 章）。

## 四、本书已记录的"判据失效与来源分歧"

**这一节是本书诚实性的体现**，也是最容易被其他资料省略的部分。
把它们集中在这里，是为了让你**知道哪些说法需要留余地**。

### 判据已经失效或不可靠的

| 判据 | 状态 | 出自 |
|------|------|------|
| 用**紫外荧光**区分天然与合成祖母绿 | **已不再可靠**（两者都会出现各种反应） | 第 9 章 |
| 用**查尔斯滤色镜**的"红得程度"区分天然与合成祖母绿 | **不可靠**：现代合成可能只显暗红，钒致色与富铁的天然祖母绿可能完全不显红。而且滤色镜**根本不能区分天然与合成** | 第 9 章 |
| 用**偏光镜**分离天然与合成紫水晶 | **变难了**（新一代合成品） | 第 9 章 |
| 用**显微特征**识别翡翠 B 货 | 该处理**最初曾未被一些实验室检出**；如今 **FTIR 才是决定性方法** | 第 10 章 |
| **热导笔**测钻石 | **会把莫桑石判成 Diamond**（导热接近）——需测电导或看重影 | 第 4 章 |
| **"透过台面看重影"** | 对莫桑石**必然失效**（光轴穿过台面），必须斜看 45° | 第 4 章（并修正了第 2 章的原写法） |

### 来源之间存在分歧、本书未强行统一的

| 项目 | 分歧 | 本书处理 |
|------|------|---------|
| **莫桑石双折射率** | 0.043 / 0.036 / 晶体学数据 0.3 量级 | 取区间 **0.036~0.043**，脚注记录分歧与可能原因（多型与波长不同） |
| **莫氏 9→10 的绝对硬度倍数** | 约 4 倍 / Rosiwal 标尺百倍以上 / **GIA 只说"硬很多倍"** | 采用 GIA 的谨慎口径，**不写死倍数**；并指出客观值应看 Vickers 或 Knoop |
| **断裂韧性数值**（软玉 225,000 / 硬玉 120,000 / 钻石 5,000~8,000+ / 刚玉 600） | 仅见一处资料、单位与标尺未明，且与 GIA 把刚玉评为"韧性优良"的定性分级不完全一致 | 只取**共识部分**（玉石极高 ≫ 钻石中等），三点局限全部标注 |
| **刚玉呈深红所需的铬含量（约 1%）** | 仅见一处资料 | 标注为**单一来源、未交叉验证**；可靠的是相对关系（d-d 跃迁需要的浓度远高于电荷转移） |
| **GIA 在彩宝产地判定上的分量** | 一说不常规提供且分量不及 SSEF/Gübelin/AGL；一说确实做且到处受尊重 | **并列两说**，并提醒较严厉的评论多来自**有商业角度的经销商博客** |
| **HRD 的分级严格度** | 通常认为紧随 GIA；但 Rapaport 的一次对照测试中**只排第四严** | 两说并列 |
| **摩根石的 Mn、金绿柱石的 Fe³⁺ 致色** | 属常见归因，未查到确切出处 | 用"**通常归因于**"而非断言 |
| **色心该归入自色还是他色** | 各家分类不同 | 按多数教材当作**独立机制**，并说明存在分歧 |
| 欧泊二氧化硅球径区间 | 常见 150~300 nm，也有延伸到约 400 nm 的说法 | 说明"规律一致、区间各家略有差异" |
| **砂矿的"筛选效应"** | 从搬运过程推出的合理推论，未查到量化研究 | 明确标注为**理解框架，不作品质判据** |

> **为什么要专门列这一节**：因为珠宝市场上最常见的错误不是"知道得少"，
> 而是"**把有争议的说法当成确定的事实**"。
> 记住哪些地方需要留余地，比多背十个数字有用。

## 五、进入第二部分之前

第一部分建立的是**通用的宝石学框架**：名称 → 结构 → 光学 → 颜色 → 效应 →
耐久性 → 成因 → 工具 → 处理 → 证书。**这套框架对所有品类都成立。**

**第二部分（钻石）会把它具体化到一个品类上**：

| 第一部分的原理 | 在第二部分变成 |
|--------------|--------------|
| 临界角与全内反射（第 3 章） | 4C 切工：亭角冠角的窗口、ASET 怎么看（第 16 章） |
| 色散与三分量（第 4 章） | 亮度/火彩/闪烁的评价（第 16 章）；花式切工无 cut grade（第 17 章） |
| 带隙致色（第 5 章） | 彩钻的颜色；培育钻的调色（第 14、18 章） |
| 解理与韧性（第 2、7 章） | 为什么要保护尖角、镶嵌怎么选（第 17 章） |
| 合成与处理（第 10 章） | CVD/HPHT 的识别与培育钻的定价（第 18 章） |
| 证书与校准差异（第 11 章） | GIA vs IGI 的等级偏移如何影响报价（第 20 章） |
