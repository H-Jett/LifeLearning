# 第 23 章 蓝宝石：颜色名、产地名与扩散处理不是一回事

蓝宝石是除红色品种之外的宝石级刚玉；市场最常讨论蓝色，但它也可以呈现其他颜色。与红宝石一样，
先描述正面外观，再核对天然/合成、处理和产地，才有可比的交易对象。

## 23.1 先看“蓝得怎样”，再听色名

蓝色蓝宝石要分开记录主色与次色、饱和度、明度、均匀度、窗口和灭灯。深不等于浓：过暗会降低正面
可见的蓝色与亮度；灰感、紫感或绿色调也不该被一个蓝色商品名抹去。

“矢车菊蓝”“皇家蓝”是常见商业或报告描述，并非消费者能凭屏幕照片统一判定的世界通用等级。若卖方
将其作为溢价理由，要求看到具体实验室的完整报告、原词、适用石头及报告日期；不要把它自动翻译成
“无烧”或特定产地。

## 23.2 产地意见不是品质证明

“克什米尔”“缅甸”“斯里兰卡”等是来源意见，不是材料定名或品质等级。产地判断依赖内含物、光谱和
化学等综合证据，并可能受材料、处理、数据库与实验室方法限制。报告没有给出产地意见时，销售单上的
产地词不应升级为事实；报告给出了意见，也仍需另看颜色、处理、切工与耐久性。

| 要比较的对象 | 应锁定的条件 |
|--------------|--------------|
| 两颗蓝色蓝宝 | 正面颜色、尺寸、切工表现、天然/合成结论与处理披露 |
| “无烧”与加热石 | 报告原文、实验室、检测日期与可比的颜色/净度/尺寸 |
| 有产地说法的石头 | 报告是否明确给出产地意见及限制，不把产地名替代品质观察 |

## 23.3 普通加热与晶格扩散

加热可以改变蓝宝石颜色或透明度表现；它与天然来源是不同命题。晶格扩散则是在加热中引入元素，
使元素进入晶格以改变或强化颜色。GIA 提醒扩散颜色的渗入深度可有差异：有的较浅，有的较深；浅层
颜色在重新抛光、改切或表面损伤时可能受影响。[^diffusion]

因此，“有烧”不能代替对扩散的披露。对于高价或准备改款的蓝宝石，要问的不是“处理过没有”这一句，
而是报告具体写了何种处理、颜色渗入的相关信息是否已披露、售后和维修谁负责。

| 状态 | 可从披露中确认什么 | 不该自行做什么 |
|------|--------------------|----------------|
| 未见加热迹象/无加热措辞 | 原文、出具机构和方法限制 | 把它当成永恒绝对结论 |
| 加热 | 处理结论、与其他候选石比较时是否同类 | 把加热等同于合成 |
| [晶格扩散](../../glossary.md#lattice-diffusion) | 扩散处理的具体披露、颜色渗入与维修边界 | 自行改切、重抛或用化学方式“测试” |
| 裂隙/空洞充填或染色 | 充填/染色范围、保养与售后 | 超声、蒸汽、酸性或溶剂清洗 |

## 23.4 星光蓝宝石是另一套观察题

星光来自适当取向的针状内含物反射，而不是“越干净越好”。评价时单独看星线是否居中、清晰、完整、
随光源移动是否顺畅，以及底色和弧面比例。不要因为有星光就跳过天然/合成和处理核验，也不要用普通
刻面石的透明度偏好机械否定它。

## 23.5 常见说法辨析

| 说法 | 判定 | 为什么 |
|------|------|--------|
| “克什米尔级就是品质等级” | **明确错误** | 产地意见与颜色、处理、切工是不同命题。 |
| “有烧蓝宝就是合成的” | **明确错误** | 加热是处理，合成是来源；需分别披露。 |
| “扩散就是普通加热，卖家写有烧就够了” | **不准确** | 扩散涉及外来元素与颜色渗入边界，应单独清楚披露。 |
| “颜色很深必然更好” | **明确错误** | 过暗会损害正面亮度和蓝色可见性。 |

## 23.6 🔎 柜台前的用处

1. 将颜色词改写成色调、饱和度、明度和均匀度的观察笔记；
2. 对“皇家蓝/矢车菊蓝/克什米尔/无烧”逐项索要报告原文，不把四个词打包相信；
3. 有扩散、充填、染色披露或处理不明时，把未来改款与保养成本纳入选择；
4. 比星光石时同时记录星线表现和底色，不以“净度”单项下结论；
5. 无法确认处理或报告与实物不对应时，暂停付款并考虑第三方复核。

## 23.8 本章实操

### 🅐 无器具版

选两条蓝宝石商品信息，逐栏标注颜色描述、天然/合成、加热、扩散、充填、产地和报告证据。把仅有的
口头词与书面证据分开，空白处写“待核”。

### 🅑 有器具版

在同一光源下用 10 倍镜记录刻面交界、磨耗和可见内含物，只用于外观记录。切勿为了检验扩散而刮磨、
重抛、浸液或加热；需要处理或产地结论时送检。
