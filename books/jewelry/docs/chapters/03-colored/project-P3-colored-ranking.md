# 🛠 项目 P3：三颗候选彩宝排序

目标不是替任何人给彩宝定价，而是将“喜欢的颜色”和“可核验证据”放进同一张决策卡，得出可复核的
排序与停止条件。

## 🅐 无器具版

选择三颗同一使用场景的候选石（可不同品种），在同一屏幕设置和尽可能相同的展示光线下填表：

| 字段 | A | B | C |
|------|---|---|---|
| 材料全名与天然/实验室生长 | | | |
| 正面颜色：色调/饱和度/明度/均匀度 | | | |
| 切工、窗口/灭灯、明显内含物/裂隙 | | | |
| 已披露处理、拼合或镶嵌限制 | | | |
| 报告号、实物对应与待核项 | | | |
| 佩戴场景、保养/维修风险 | | | |
| 总价、售后、退换与复检条件 | | | |

然后写出排序（A/B/C 或“不排序，先核验”），并明确：

1. 最影响你选择的两项外观偏好；
2. 每颗石的一个证据缺口；
3. 一条会让你停止交易或要求第三方复核的条件。

## 🅑 有器具版

在同一日光等效光和室内常用光下查看实物/视频，记录正面颜色、窗口/灭灯、裂隙到达表面的位置、镶嵌
遮挡和已知处理。用 10 倍镜只做观察记录；不要以浸液、加热、刮磨、酸碱或拆镶方式验证处理。

对高价值候选石，将“报告在线验证 → 报告与实物对应 → 收货复核/第三方检测 → 退换条款”写成下单前置
条件。若三颗材料、处理或证据水平不可比，正确结果可以是“不排序”。

## 交付物模板

> **我的第一选择/暂缓选择：**
>
> **外观理由：**（在何种光线、正面观察到什么）
>
> **证据理由：**（报告/披露支持了什么，仍缺什么）
>
> **佩戴与保养理由：**
>
> **不选另外两颗的原因：**
>
> **停止条件：**（例如报告不对应、关键处理未披露、无法给出复检/退换条款）

> 本项目不构成投资、估价或未来转售建议；报价、回收和流行偏好须在具体交易条件下另行核实。
