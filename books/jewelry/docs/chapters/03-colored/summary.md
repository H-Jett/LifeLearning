# 第三部分小结（速查）：颜色、身份、处理与证据不能互相替代

| 先问什么 | 再看什么 | 不要误当成 |
|----------|----------|------------|
| 颜色好不好？ | 色调、饱和度、明度、均匀度与正面表现 | 产地或营销色名 |
| 是什么材料？ | 天然/实验室生长、具体种属、拼合结构 | 一张修图或单一仪器反应 |
| 处理过什么？ | 报告原文、充填/扩散/加热及保养限制 | “天然”等于未处理 |
| 值不值得比较？ | 同光线、尺寸、切工、耐久性和交易条款 | 报价或单一参数 |

高价彩宝的最低闭环是：报告与实物对应 → 处理/来源命题分别阅读 → 将保养与复检写入交易条款。
证据不足时，“暂不排序”比按口头溢价付款更可靠。
