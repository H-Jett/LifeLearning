# 🛠 项目 P2：给定预算配一颗钻

目标不是得出“唯一最优钻石”，而是把预算、身份、外观、耐久性和交易条件写成可复核取舍。

## 🅐 无器具版

设定总预算和用途，选三颗候选裸石或三件成品，填表：

| 字段 | A | B | C |
|------|---|---|---|
| 天然/培育/未披露 | | | |
| 报告号与可核验性 | | | |
| 形状、克拉与毫米尺寸 | | | |
| 颜色、净度、切工/抛光/对称 | | | |
| 已知处理、荧光或关键风险 | | | |
| 金属/工艺/售后与总价 | | | |
| 我愿意接受的取舍 | | | |

**交付物**：一页选择说明，必须包含“为什么不选另外两颗”和“一条会让我停止交易的条件”。

## 🅑 有器具版

对候选石查看报告和旋转视频/实物，按第 16–19 章分别记录切工表现、内含物位置、花式切工图案或
来源披露。若购买金额较高，将“权威报告在线验证 + 收货复核/复检”写入交易流程。

> 这不是投资组合或收益建议；任何未来回收价格都应另行取得书面条款。
