# 🛠 项目 P4：玉石市场实地观察

目标不是在市场里给商品下鉴定结论，而是把“卖方说法、自己看到的、文件支持的、仍待核的”分开记录。

## 🅐 无器具版

选择三件可公开观察的商品（或三条合规线上商品信息），不妨碍经营、不要求拆镶、不拍摄被禁止的内容，填表：

| 字段 | 商品 A | 商品 B | 商品 C |
|------|--------|--------|--------|
| 材料名称与形制 | | | |
| 卖方的颜色/种水/产地/皮色/类型说法 | | | |
| 自己看到的外观（光线、颜色、裂隙、工艺） | | | |
| 报告、处理与实物对应信息 | | | |
| 保养、维修、退换/复检条款 | | | |
| 待核问题与停止条件 | | | |

**交付物**：一页观察日志。必须含至少一次“卖方说法与书面证据并不相同”或“证据不足，因此不排序”的记录。

## 🅑 有器具版

经卖方同意后，用 10 倍镜和常用光源记录表面抛光、裂隙、颜色分布、镶嵌遮挡和串线/金属状态；不使用
化学试剂、热源、针刺、敲击、浸液或拆卸。对疑似受保护物种物件，不作物种断言，不计划跨境携带，转向
主管机关/专业机构核验。

## 观察纪律

1. 不挡柜台、不强迫试戴、不索取或公开他人隐私信息；
2. 记录观察条件，不把不同灯光或不同修图照片当作可比颜色；
3. 报告二维码只验证文件存在，仍需核对它对应的实物；
4. 每条高溢价词都拆成材料、处理、产地、形态或法律合规命题；
5. 不能建立证据链时，正确结论是“待核/不交易”。

> 本项目是观察与决策训练，不构成鉴定、估价、法律或跨境通关意见。
