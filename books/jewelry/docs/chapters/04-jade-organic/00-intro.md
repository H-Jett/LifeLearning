# 第四部分 · 玉石与有机宝石：先分矿物、结构与处理，再谈市场语言

本部分进入中国市场常见的翡翠、和田玉、其他玉石、珍珠与有机宝石。它们的共同难点并非“术语太多”，
而是同一商业名下可能对应不同矿物、结构、处理或合法性条件。阅读时统一按：材料定名 → 外观观察 →
处理/结构 → 耐久性与交易证据推进。
