## 五、怎么引用（写作约定）

1. **正文**：写 `GB/T 16552` 这样的**纯编号**，并在本页表格里能查到；
2. **数值**：给区间而非单点，并注明来源类型，例如
   "刚玉折射率 1.762~1.770（《系统宝石学》通用值，随成分微变）"；
3. **市场惯例**：明确写"**市场惯例**，可能随行情变化"，不要写成好像有标准依据；
4. **传说**：进「常见说法辨析」小节，标注证据强度（有共识 / 有争议 / 缺乏证据 / 明确错误）。
