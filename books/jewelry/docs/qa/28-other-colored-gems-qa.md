# 第 28 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：名称可能是营销词，现象也可能出现在不同材料和不同结构中。应分别核验材料定名、天然/合成、拼合
结构和处理；例如“彩虹月光石”常指拉长石，而欧泊的变彩也不证明它是整块天然材料。

<a id="q2"></a>
## Q2

**答**：市场多数蓝色坦桑石经历加热，且实验室在不少情况下难以确认历史加热。报告没有该结论只能保留
原文和限制，不能把未检出/未注明扩展为绝对无热。

<a id="q3"></a>
## Q3

**答**：至少确认材料名称、天然/合成、是否双层/三层或其他拼合、是否染色/含浸、产地意见是否有报告支持、
变彩在何种光线和方向下观察、是否有龟裂/磨耗，以及清洗、维修、退换条款。最后核对报告号、重量、尺寸、
照片/特征与戒指实物；“耐戴”不能代替这些披露。
