# 第 39 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：爪数只提供一种冗余与覆盖方式。真正的安全还取决于爪的厚度和磨耗、石座与腰围贴合、石头尖角/裂隙、
金属结构及日常撞击。四爪也可合格，六爪也可能因磨耗或加工不良而松动，因此要检查完整结构与售后。

<a id="q2"></a>
## Q2

**答**：高托、光环、细戒臂和较少金属遮挡能改变比例与视觉焦点，却不改变主石的克拉重量、毫米尺寸、切工
或报告。比较时应同时看主石尺寸、镶嵌高度、侧面保护和整体维护成本。

<a id="q3"></a>
## Q3

**答**：先停止佩戴，不摇石或自行压爪；拍下四个尖角、爪尖、石位与勾丝位置，保留购买凭证。公主方尖角较
易受撞击，应请原商家或合格镶嵌师检查石头是否松动、爪座是否贴合、尖角是否应以 V 形爪或其他保护结构
处理，并书面确认维修/改托方案及对主石的风险。修复前不要继续佩戴或用胶水处理。
