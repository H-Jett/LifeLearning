# 第 43 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：保险替换估价用于在约定条件下重置相似物，回收报价则是某交易方在当期渠道、检测、状态和转售风险下
愿意支付的金额；目的与条件不同，不能推导彼此。

<a id="q2"></a>
## Q2

**答**：超声振动和清洗液可能影响充填、涂层、含浸、有裂隙材料及松动镶嵌。未知时无法判断风险，因此先用
软布/温和方式或请专业人员确认，避免用“洗得更干净”换取不可逆损伤。

<a id="q3"></a>
## Q3

**答**：要求报告和备注支持材料、充填/处理状态；要求“免费超声”具体适用对象、风险承担、检查与维修条件；
要求“原价回收”的主体、期限、检测、扣减、发票/报告要求及支付方式写入订单。若不能书面化，不把这些说法
计入价值，祖母绿优先采用温和清洁路径。
