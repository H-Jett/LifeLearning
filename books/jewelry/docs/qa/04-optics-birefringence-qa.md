# 第 4 章 思考题参考答案

> 只记「问题 + 正确答案」。案例题给**完整推理链**。

<a id="q1"></a>
## Q1

**问**：为什么"看不到棱线重影"不能证明一颗石头是均质体？给出三个不同原因。

**答**：三个互相独立的原因，任何一个都能造成**假阴性**：

1. **双折射率太小**。重影在 10 倍镜下可见的经验阈值是**约 0.020**。
   刚玉（0.008~0.010）、水晶（0.009）、绿柱石（0.005~0.009）都远低于这个值——
   它们是**非均质体，但本来就看不到重影**。
2. **观察方向不对（光轴方向）**。每种非均质宝石都有一个光轴方向，
   沿该方向观察时它表现得像均质体。而**台面通常被切成垂直于 c 轴**，
   所以"直着透过台面看"恰恰是最容易落进光轴方向的看法——莫桑石就是典型。
3. **光程太短**。重影的明显程度还取决于光在石头内部走过的距离，
   所以**小碎石（melee）**即使双折射中等也可能看不出来。

补充第四个（品种特异）：**蜕晶质（metamict）低型锆石**因自身放射性元素长期辐射损伤，
结晶度下降、双折射显著降低——**看不到重影不能排除锆石**。

> **要带走的判断**：这是"阴性结果的价值远低于阳性结果"的典型案例。
> **看到重影是强线索**（说明是非均质体，且双折射不小）；
> **看不到重影几乎什么都不能说明**。宝石学里大量测试都有这种不对称性，
> 用测试前先想清楚"阴性代表什么"。

<a id="q2"></a>
## Q2

**问**：为什么台面通常切成垂直于 c 轴？这个习惯如何破坏"透过台面看重影"这个测试？

**答**：

**为什么这么切**：沿光轴方向传播的光**不发生双折射**。
把台面切成垂直于 c 轴（即让观察方向接近光轴），能**最小化双折射造成的"发糊"**，
让石头看起来更清晰锐利。这是切磨工艺上的正确选择。

**它如何破坏测试**：测试的原理是"看到两束光造成的重影"，
但工艺特意把最常用的观察方向（透过台面正视）安排在**双折射最小的方向**上。
于是测试与工艺的目标正好相反——**工艺在努力消除你想观察的现象**。

**莫桑石是最典型的受害案例**：它的光轴方向正好穿过台面，
所以直着看**完全不出现重影**，会给出"这不是莫桑石"的错误结论。
正确做法是倾斜约 45°、透过冠部的风筝面或星小面去看亭部棱线交界。

> **要带走的判断**：**任何测试都要问"这个测试的前提条件是什么"**。
> 同一个动作（用放大镜看棱线），方向差 45° 就是有效与无效之别。
> 这也是为什么本书所有 🅑 实操都会写清"怎么看"，而不只说"看什么"。

<a id="q3"></a>
## Q3

**问**：色散和折射率都与折射率有关，为什么决定的是两种不同的视觉效果？

**答**：因为它们描述的是折射率的**两个不同侧面**：

| | 折射率 n | 色散 |
|---|---|---|
| 是什么 | 某一波长下光被减速/折弯的**绝对程度** | 不同波长之间折射率的**差值**（红光 686.7 nm 与紫光 430.8 nm 之差） |
| 决定 | 临界角 → 有多少光被锁在内部并返回眼睛；以及表面反射强度 | 白光被分离成光谱色的程度 |
| 视觉效果 | **亮度**（白亮）+ **光泽** | **火彩**（彩光） |

打个比方：折射率决定"**有多少光回到你眼里**"，色散决定"**这些光是白的还是彩的**"。

**两者可以完全脱钩**，这是最重要的一点：

- 蓝宝石折射率 1.766（高于水晶 1.548），但刚玉是**低色散**材料 → 亮但火彩弱；
- 金红石色散 0.28（钻石的 6 倍多）→ 彩光夸张，但它硬度低、不适合首饰；
- 钻石的特别之处是**两者都高**（n=2.417 且色散 0.044）→ 又亮又有彩，
  而且硬度 10 能长期维持锐利棱面和好抛光。

> **要带走的判断**："钻石为什么好"这个问题的完整答案需要三个量：
> **高折射率（亮）+ 中高色散（彩）+ 最高硬度（耐久）**。
> 单拎任何一个出来都能被别的材料超过——莫桑石色散更高、
> 但正是"更高"让它看起来假。

<a id="q4"></a>
## Q4

**问**：为什么"适度的暗区"是好切工的一部分而不是缺陷？

**答**：因为 GIA 三分量里的第三项——**闪烁**（scintillation）的定义就是
"**明暗区域的图案**，以及移动时的闪光"。

关键在于：**闪烁依赖对比**。

- 如果一颗石头正面全是均匀的亮光、没有暗区，看起来会是**平板、发白、像块塑料**——
  因为没有明暗交替，移动时就没有"一闪一闪"的变化；
- 正是明区与暗区形成**图案**，在石头或光源移动时**明暗互换**，
  人眼才感知到"在闪、在跳"。

所以好切工追求的不是"最亮"，而是**亮度、火彩、闪烁三者的平衡**，
其中闪烁天然需要暗区参与。

**但要区分"适度暗区"与"病态暗区"**：

| | 性质 |
|---|---|
| 适度暗区（好） | 分布均匀、与亮区形成清晰图案，移动时会变化 |
| 中心发暗 dark center（病） | 亭部**过深**，中心恒定发黑，移动也不变 |
| 暗色主刻面延伸到边缘 dark mains（病） | **冠高与亭深不匹配** |

判据是：**这个暗区在转动时会不会"活"**。会活的是图案，不会活的是漏光或结构问题。

> **要带走的判断**：这解释了为什么"看视频挑钻石"不可靠——
> 卖家用强聚光灯打出满屏亮光，恰恰破坏了对比，
> 让你既看不出真实的闪烁图案，也看不出病态暗区。

## Q5

**问**：强多色性为什么导致同等品质的单价更高？把因果链写完整。

**答**：因果链有四步：

1. **强多色性意味着不同方向颜色差别大**。例如坦桑石晶体：
   正面淡紫、侧面灰蓝、沿垂直轴红褐——三个方向的商业价值完全不同。
2. **切磨师必须把"颜色最好的方向"朝上（朝台面）切**，
   否则正面呈现的就是那个不好看的方向，整颗石头的价值大跌。
3. **但原石的形状不会配合这个要求**。最省料的切割取向（沿原石长轴、保留最大重量）
   与最佳颜色取向往往**不是同一个方向**。于是切磨师被迫**放弃更省料的方案**，
   多磨掉一部分材料。
4. **结果是出成率（原石→成品的重量转化率）下降**。同一块原石能出的成品克拉数更少，
   摊到每克拉成品上的原石成本就更高 → **同等品质的单价更高**。

**坦桑石还多一层**：它甚至存在"要蓝还是要紫"的取向决策——
市场对纯正蓝色的偏好高于紫色调，所以切磨师会为了争取蓝色方向再牺牲重量。

> **要带走的判断**：这条链把"物理性质 → 工艺约束 → 出成率 → 价格"打通了。
> 本书后面会反复用这个思路：**看到一个价格现象，先找它背后的工艺约束**。
> 反过来，这也是你在店里可以问的好问题：
> "这颗为什么切成这个比例？"——多色性、避裂、保重，答案通常在这三者之中。

## Q6

**问**：直播间"1 克拉钻戒"，主播用测钻笔演示"显示 Diamond"，并说"放大镜看没有双影，绝对是真钻"。
两个证据各有什么问题？

**答**：两个证据**恰好都在莫桑石这个最常见的仿品上失效**，组合起来仍然不能排除莫桑石。

**问题一：热导式测钻笔对莫桑石无效。**

- 传统测钻笔测的是**导热性**，而**莫桑石的导热性接近钻石**；
- 所以这类仪器**会把莫桑石判成 Diamond**——这是**已知的系统性问题**，不是偶发误差；
- 正确的仪器方案是测**电导率**（莫桑石数值明显更高），
  现在的"钻石/莫桑石双测笔"就是加了这一项。**只显示 "Diamond" 的单一热导笔不足为证**。

**问题二：看重影的方法被用错了方向。**

- 莫桑石的**光轴穿过台面**，直着透过台面看**本来就看不到重影**；
- 主播的观察若是"正视台面"，那么"没有双影"是**必然结果**，与真假无关；
- 正确做法是倾斜约 45°、透过冠部小面看亭部棱线交界。

**另外还有两点值得提醒**：

- 直播画面的分辨率与打光根本不足以支撑"看重影"这种细节判断——
  即使方向正确，**隔着屏幕也看不出来**；
- "1 克拉"这个描述要看是**单颗主石 1 克拉**还是**总重 1 克拉**（碎钻拼凑），
  后者是直播间的常见话术（第 42 章）。

**建议朋友做什么**（按优先级）：

1. **要证书**：看名称怎么写的——`钻石` / `合成钻石`（培育钻）/ `莫桑石`（国标名为
   `合成碳化硅`）是三个不同的东西，价格差一到两个量级（第 1 章）；
2. **官网核验编号**，逐项比对参数（[证书核对清单](../forms/certificate-checklist.md)）；
3. **无证书或核验不上，就走平台退货**——不要试图自己"鉴定"；
4. 若要自查，**斜看重影**并找带电导测试的双测笔，但**结论仍以送检为准**。

> **要带走的判断**：**两个不可靠的证据不能相加成一个可靠的证据。**
> 主播的演示形式上很有说服力（有仪器、有放大镜），但两项都恰好在莫桑石上失效——
> 这类"看起来专业的验证"比没有验证更危险。

<a id="q7"></a>
## Q7

**问**：网店称坦桑石*"转动能看到蓝色和紫色变化，是罕见的变色宝石，媲美亚历山大变石"*，
哪部分真实、哪部分是概念偷换？

**答**：

**真实的部分**：*"转动能看到蓝色和紫色变化"*——这是**真实且正常的现象**。
坦桑石属斜方晶系、二轴晶，有**强三色性**：正面淡紫、侧面灰蓝、沿垂直轴红褐。
转动时看到蓝紫变化完全符合它的物理性质，**不是卖点，是它的常态**。

**概念偷换的部分**：*"是罕见的变色宝石，媲美亚历山大变石"*——
这里把**多色性**偷换成了**变色效应**。两者机制完全不同：

| | 多色性（坦桑石有） | 变色效应（变石有） |
|---|---|---|
| 变色的触发条件 | **换观察方向**（转动石头） | **换光源**（日光 ↔ 白炽灯） |
| 物理机制 | 双折射的两束光被吸收的波长不同 | 特定致色元素（如 Cr）的吸收带正好落在两种光源的能量分布差异处 |
| 稀有度 | 常见，很多彩宝都有 | **罕见**，变石是代表 |
| 价格含义 | 影响切工取向与出成率，但**本身不构成溢价** | **显著溢价**，且变色越明显越贵 |

**这种偷换想让消费者产生的误解**：让人以为自己买到了"变色宝石"这一稀有类别，
从而接受高于坦桑石正常行情的价格，或者在心里把它与变石（金绿宝石族，价格高一个量级）归为一类。

**怎么一句话拆穿**：**"那我不转动石头，只换灯光看，颜色会变吗？"**
——真正的变色效应答案是"会"，多色性答案是"不会"。

> **要带走的判断**：珠宝话术最常见的手法不是编造，而是**把一个正常现象包装成稀有特性**。
> 防御方法是**回到定义**：这个现象的触发条件是什么？
> 触发条件对不上，名字再像也不是同一件事。

## Q8

**问**：在 GIA 4Cs 切工页面找 fish-eye 与 dark center，它们分别由什么参数问题引起？
照片上靠什么区分？

**答**：

**成因（这三条一起记最清楚）**：

| 现象 | 成因 |
|------|------|
| **鱼眼 fish-eye** | 亭部**过浅** |
| **中心发暗 dark center** | 亭部**过深** |
| **暗色主刻面延伸到边缘 dark mains** | **冠高与亭深不匹配** |

**照片上怎么区分**：

| 特征 | 鱼眼（过浅） | 中心发暗（过深） |
|------|------------|----------------|
| 整体亮度分布 | 中心**发白、发空、透亮** | 中心**发黑、发闷** |
| 标志性图案 | 台面内出现一圈**灰白色环**（腰棱的反射） | 中心一块**恒定的暗区**，形状规整 |
| 直径与重量的关系 | 同重量下**直径偏大**（显大） | 同重量下**直径偏小**（显小） |
| 是否"看穿" | 可能能透过石头看到背后（窗口效应） | 不会，但中心像堵住了 |

**一个实用的补充判据（照片以外）**：**转动它**。
鱼眼的白环和过深的黑心都**几乎不随转动变化**（是结构性的），
而好切工的明暗图案在转动时会"活起来"（这正是闪烁）。
所以**动态视频比静态照片更能区分**——虽然视频也会被强光掩盖（§4.6、第 16 章）。

> **要带走的判断**：这两种病一个"显大但漏光"、一个"显小又发闷"。
> 从买家角度：**过深是更亏的**（钱花在看不见的深度上，还牺牲了亮度），
> 而轻微过浅至少换到了"显大"——是否接受这个交换是明确的偏好选择，
> 前提是你知道自己在换什么（第 13、16 章）。
