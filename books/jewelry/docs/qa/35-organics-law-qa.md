# 第 35 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：材料鉴定回答“它是什么、可能有何处理”；CITES/海关文件回答在特定物种、来源、时间、国家和
交易方式下是否获准移动或贸易。两类文件的对象和法律功能不同，不能互相替代。

<a id="q2"></a>
## Q2

**答**：“老件/家传”只是卖方叙述，不足以证明物种、年代、合法来源、登记状态及进出口许可。象牙类还会
同时受国际附录与目的地国内规则影响，必须取得适用主管机关的书面核验。

<a id="q3"></a>
## Q3

**答**：不按卖方口头承诺携带。先取得物种、养殖/来源和交易文件；再向出口地与目的地 CITES 管理机构或
海关核实当期许可、申报和禁止规定。文件不足或无法核验时停止购买、寄送和跨境移动；不以图片或他人经验
替代书面答复。
