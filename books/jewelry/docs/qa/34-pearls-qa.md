# 第 34 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：光泽描述表面及近表层的反射强度和清晰度；珠层评价还涉及连续性、结构/近表面特征和必要时厚度，
并影响耐久性。两者相关但不是同一项，不能由强光泽推断珠层没有问题。

<a id="q2"></a>
## Q2

**答**：淡水、阿古屋、南洋和大溪地描述不同养殖环境、宿主与典型外观，不能取代尺寸、光泽、表面、珠层、
匹配、处理和具体交易条件。跨类型必须先明确你的佩戴偏好与比较维度。

<a id="q3"></a>
## Q3

**答**：要求报告或书面资料分别支持养殖/天然、南洋类型、颜色是否天然、珠层状态/厚度（如主张）和处理；
再逐颗记录尺寸、形状、光泽、表面、珠层表现和匹配。核对报告与项链长度、颗数、尺寸、照片/特征对应，
并写入保养、退换和复检条款；不能由“金色、几乎无暇”自行推出全部命题。
