# 第 29 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：同一外观线索可能来自材料本身、切工、损伤、不同处理或合成路径。预警信号的正确用途是要求披露、
调整比较对象或送检；处理/合成结论需要与材料相适配的综合检测证据。

<a id="q2"></a>
## Q2

**答**：天然描述来源，未处理描述后续历史。天然宝石可以经过加热、充填、扩散等处理；反过来，未见处理
结论也不自动证明天然。报告应分别写出能够支持的命题。

<a id="q3"></a>
## Q3

**答**：要求将“天然”对应到报告的天然/实验室生长结论；将“一点优化”具体为填充物、程度和报告原文；
再核对报告号、重量、尺寸、照片/特征与实物，并取得清洁、维修、退换和第三方复核条款。没有独立报告时，
把身份与处理列为待核，不按高确定性天然未处理材料比较或付款。
