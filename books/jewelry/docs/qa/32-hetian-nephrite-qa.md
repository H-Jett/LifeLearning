# 第 32 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：名称说明材料归类，产地说明来源；不同产地的透闪石质软玉可进入和田玉名称语境。若交易溢价来自
新疆和田产，必须要求独立产地意见或可追溯证据，而非只读名称栏。

<a id="q2"></a>
## Q2

**答**：皮色、毛孔、磨圆和裂隙可提供观察线索，却可能受自然变化、拍摄、修补、染色、加热或做皮影响。
单一线索不足以排除处理或证明特定形态/来源，需结合整件特征、证据链和必要的专业核验。

<a id="q3"></a>
## Q3

**答**：先核对材料名称是否为透闪石质软玉；再分别索取新疆和田产、籽料形态、天然红皮的书面证据和限制；
确认报告与重量、尺寸、照片/特征对应。随后同光线评估白度、细腻、裂隙、皮色过渡和工艺，并谈妥复检、
退换和保养。任何无法独立支持的高溢价词都保留为待核。
