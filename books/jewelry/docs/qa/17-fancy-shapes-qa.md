# 第 17 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：花式切工的轮廓、刻面排列和动态图案比圆钻多得多，不同形状还各有蝴蝶结、窗感、尖角或台阶刻面
等问题。GIA 的圆钻总评方法不能直接移植；应分别看报告完成度和该形状的正面表现。

<a id="q2"></a>
## Q2

**答**：轻微、会随移动变亮的暗区可以记录为图案特征，再由个人偏好决定；宽、暗、持续的蝴蝶结会更明显
降低整体亮度，应要求视频/实物比较并纳入价格与取舍，而不是仅凭静态图判断。

<a id="q3"></a>
## Q3

**答**：第一，中心长期透明发灰提示窗感或明显漏光，需看标准化动态视频；第二，极端修长只说明轮廓偏好，
仍要核对毫米尺寸、全深和整体明暗；第三，梨形尖端未受保护会增加日常磕碰风险，需评估镶嵌方案。三者
分别属于光学外观、尺寸/设计和耐久性，不能用“显大”一句带过。
