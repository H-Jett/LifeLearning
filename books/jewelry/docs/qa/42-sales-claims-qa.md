# 第 42 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：最低价没有说明比较的货品、规格、费用、有效期和售后。只在同一材料、重量、处理、报告、总价和条款
都一致时，价格才有可比性。

<a id="q2"></a>
## Q2

**答**：发票/订单是货品身份和服务承诺的重要证据。删减材质、处理、重量、货号或售后描述，可能让后续验货、
退换和争议处理失去依据；折扣不应以牺牲可追溯性为代价。

<a id="q3"></a>
## Q3

**答**：要求报告、机构官方核验、实物对应和处理备注支持“天然无优化”；要求写明总价、原价比较基准及有效期；
要求回收主体、期限、扣减、凭证和适用货品写入订单。无法书面化的承诺不计入价值，暂停付款而不是被“最后价”催促。
