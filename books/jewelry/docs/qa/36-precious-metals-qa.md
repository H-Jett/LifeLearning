# 第 36 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：18K 是金合金的纯度表达，说明的是合金中金所占的名义份额；镀金说的是表面覆盖层。前者不能推出有无
镀层，后者也不能推出基体是什么或金合金的纯度。交易时应分别要求材质/纯度和覆盖层披露。

<a id="q2"></a>
## Q2

**答**：白 K 金、铂金、钯金以及银色基体加覆盖层都可能显白；抛光、镀层和磨耗还会改变观感。应读取印记与
书面材质/纯度信息，核对发票和货号；有冲突或高价值情形时走适配的检测路径，而非凭颜色断言。

<a id="q3"></a>
## Q3

**答**：先把“白金”拆成可验证项目：要求明确基体是 Au、Pt 还是 Pd，写出纯度表达与可见印记；询问是否有
镀层、覆盖层在何处及其保养/翻新条件；确认钻石与金属分别如何描述、总重是否含主石和配件。再要求发票
列明品名、货号、材质/纯度、重量口径、价格、报告编号及退换/维修条款，并使其与价签、实物、报告相互对应。
若仍只给口头承诺或信息相互矛盾，应暂缓付款或选择可提供完整书面信息的货品。
