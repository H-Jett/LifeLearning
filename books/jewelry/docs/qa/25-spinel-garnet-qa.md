# 第 25 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：AAA/AA/A 可以是商家的内部描述，但没有尖晶石通用的质量分级标准。跨商家比较要回到同光线下的
颜色、切工、净度、尺寸，以及天然/合成、处理和报告是否对应实物。

<a id="q2"></a>
## Q2

**答**：石榴石是成分连续的矿物族；不同种属/变种的颜色、净度预期、尺寸稀有度和耐久性不同。只写
“石榴石”或一个营销色名，无法构成可复核的比较对象。

<a id="q3"></a>
## Q3

**答**：第一句话至少拆成尖晶石的天然/实验室生长、处理、颜色/钴致色、AAA 标签和报告对应五项；第二句
拆成石榴石具体种属、绿色外观、处理、耐久性和与祖母绿比较的限定条件。先取得报告和实物对应，再在
相同光线比较正面外观与佩戴需求；任何“平替”都不应替代材料身份与处理披露。
