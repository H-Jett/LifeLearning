# 第 26 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：“帕拉伊巴”在通行术语框架中主要涉及铜致色和特定颜色范围，并非巴西产地的同义词；巴西、
尼日利亚和莫桑比克等来源都需要以报告的产地意见独立支持。名称结论不能代替来源结论。

<a id="q2"></a>
## Q2

**答**：部分碧玺的加热改变稳定且不总能可靠检出。报告未写处理可能反映报告项目、可检出的证据和措辞，
不是消费者可以补写的绝对历史结论。应保留报告原文及其限制。

<a id="q3"></a>
## Q3

**答**：先要求可验证的完整报告，并对应报告号、石重、尺寸、形状、照片/特征与实物；再分别查天然/实验室
生长、铜致色/名称、处理措辞、产地意见及限制。随后在可比光线观察正面颜色，核对销售单与售后是否同样
披露。任一关键命题无法落到实物对应的书面证据时，暂停付款或安排第三方复核。
