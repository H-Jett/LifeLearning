# 第 3 章 思考题参考答案

> 只记「问题 + 正确答案」。案例题给**完整推理链**。

<a id="q1"></a>
## Q1

**问**：用 `sin θc = 1/n` 解释为什么折射率越高 → 临界角越小 → 反而越亮？
（最后一步最容易绕错。）

**答**：分三步，第三步是关键。

**第一步：n 越大，θc 越小**（纯数学）
`sin θc = 1/n`。n 变大 → `1/n` 变小 → `sin θc` 变小 → θc 变小。
钻石 n=2.417 → θc=24.4°；玻璃 n=1.50 → θc=41.8°。

**第二步：θc 是"全内反射的门槛"**
光从宝石内部射向表面时，入射角**大于** θc 的会被全部反射回内部；**小于** θc 的会折射出去（漏掉）。

**第三步（最易绕错的一步）：门槛低 = 更多光被留住**
θc 小意味着"超过门槛"的角度范围更大：

| | 被全内反射的入射角范围 | 占比 |
|---|---|---|
| 钻石（θc=24.4°） | 24.4° ~ 90° | 范围宽 |
| 玻璃（θc=41.8°） | 41.8° ~ 90° | 范围窄 |

**绕错的点在于"小"字**：直觉容易把"临界角小"读成"能反射的少"，其实恰恰相反
——临界角是**下限**，下限越低，符合条件的越多。

光被留在石头里并不等于亮；关键是它经过亭部两次反射后**从冠部射向观察者的眼睛**。
所以完整因果是：**高 n → 小 θc → 更大比例的光被锁在内部并被送回眼中 → 亮。**

> **要带走的判断**：这条因果链和"硬度"没有任何关系。
> 钻石的硬度只保证它**能长期维持**锐利棱面和好抛光（间接影响光泽），
> 但"亮"本身是折射率的功劳。

<a id="q2"></a>
## Q2

**问**：玻璃仿品和钻石切成完全相同的比例，为什么玻璃一定明显漏光？

**答**：因为**同一套角度是为某个特定临界角设计的**。

圆钻的亭角（约 40.75°）是按钻石的 θc=24.4° 算出来的：在这个亭角下，
从冠部进来的光打到亭部小面上的入射角**大于 24.4°**，所以被全内反射。

把同样的几何形状换成玻璃（θc=41.8°）：光打在亭部小面上的入射角**不变**，
但门槛从 24.4° 抬高到了 41.8°。于是原本"稳稳超过门槛"的那一大批光线，
现在**低于门槛**——直接从亭部折射出去，漏掉了。

**结果**：玻璃仿品会出现明显的中心透亮/发空，从台面能感觉到"看穿了"，
缺少钻石那种"光从里面被弹回来"的实感。

> **要带走的判断**：**切工参数不能跨材料照搬**。这正是为什么彩色宝石有自己的切工规则
> （§3.6），也是为什么莫桑石（θc=22.2°，比钻石还小）用钻石的比例切出来会"亮得过头"。

<a id="q3"></a>
## Q3

**问**：为什么标准折射仪测不出钻石的折射率？这个"测不出"是有用信息还是无用？

**答**：

**为什么测不出**：宝石折射仪的工作原理本身就依赖全内反射——把宝石贴在高 RI 棱镜上，
用接触液耦合，读临界角刻度。而**接触液与棱镜的折射率决定了量程上限**，
标准配置（二碘甲烷类接触液）上限约 **1.78~1.81**。
钻石 2.417 远超此值，光路条件不成立，仪器只能显示"超出量程"。

同样超量程的还有：高型锆石（约 1.95）、CZ（约 2.16）、莫桑石（约 2.65）。

**这是非常有用的信息**，因为它是一个**强力的排除条件**：

1. 一次读数就把候选范围从几百种缩到"RI > 1.81 的少数几种"；
2. 反过来，如果一颗号称"钻石"的石头**能**在折射仪上读出数（比如读到 1.55），
   那它**肯定不是钻石**——这是决定性的否证；
3. 接下来用其他手段就能快速定性（见[常数表](../reference/constants.md)）：

| 判据 | 钻石 | 莫桑石 | CZ | 锆石 |
|------|------|--------|----|------|
| 双折射（棱线重影） | 无 | **有，明显** | 无 | **有，极明显** |
| 比重 | 3.52 | 3.22 | **5.6~6.0（压手）** | 4.60~4.70 |
| 色散（火彩） | 0.044 | **0.104（过艳）** | 0.058~0.066 | — |

> **要带走的判断**：鉴定的实际逻辑是**排除**，不是"一眼认出"。
> "测不出来"在排除逻辑里和"测出某个值"一样有价值。
> 把仪器的**局限**当作信息来用，是专业与业余的分界线之一。

<a id="q4"></a>
## Q4

**问**：彩色宝石的切工为什么不能照搬钻石的理想比例？从临界角与价值来源两方面回答。

**答**：

**角度一：临界角不同，几何窗口不同**

彩宝的折射率普遍在 1.5~1.8，临界角 34°~42°（钻石只有 24.4°）。
门槛更高意味着：**可用的亭角范围更窄，也更容易漏光**。
照搬钻石的亭角，很多彩宝会直接出现**窗口效应**（透过台面能看到背后的东西），
颜色被冲淡、石头显得发空。

**角度二：价值来源不同，优化目标就不同**

- 钻石（无色）卖的是**光学表现**：亮度、火彩、闪烁。所以切工追求把光最大化地送回眼睛。
- 彩色宝石卖的是**颜色**（价值的绝大部分，第 21 章）。所以切磨师的首要目标是
  **把颜色浓度调到最佳**：
  - 颜色**浅**的原石 → 切**深**，延长光在石头里走的路径，颜色更浓；
  - 颜色**过深**的原石 → 切**浅**，避免整颗发黑。

这就是为什么同一个品种、同样重量的两颗彩宝，深度可以差很多，而**两者都可能是正确的工艺决策**。

> **要带走的判断**：评价彩宝切工不能拿钻石那套参数打分。
> 该问的是"**这个深度有没有把颜色做对**"和"**有没有窗口漏光**"。
> 这也解释了彩宝为什么难比价——它没有像钻石那样可对表的标准化参数（第 21 章）。

<a id="q5"></a>
## Q5

**问**：详情页称*"天然蓝宝石折射率高达 1.77，比水晶 1.54 高很多，所以火彩极其璀璨，媲美钻石"*，
指出两处概念错误。

**答**：

**错误一：把折射率当成火彩的来源。**
火彩（fire）来自**色散**，不是折射率。两者是不同的物理量：

- **折射率**决定光被折弯多少、临界角多大 → 影响**亮度**与**光泽**；
- **色散**决定白光被分解成彩色的程度 → 影响**火彩**。

一块材料完全可以折射率高而色散低。所以"RI 1.77 → 火彩璀璨"这个推理链**不成立**。

**错误二：拿蓝宝石的火彩去"媲美钻石"。**
钻石的色散是 **0.044**（这是所有火彩讨论的基准线，见[常数表](../reference/constants.md)）。
刚玉属于**低色散**材料，火彩很弱——这是行业共识：
蓝宝石的美感来自**颜色**（以及丝绒感、星光等），从来不是火彩。
拿火彩去比钻石，等于用蓝宝石最不擅长的维度去比。

> **诚实说明**：本书目前**没有核实到刚玉色散值的可靠公开出处**，
> 所以这里只给定性结论（低色散、火彩弱），不写具体数字。
> 按本书的查证纪律：**查不到确切来源的数字就不写**，等核实后补进常数表。

**顺带一个真正值得警惕的点**：这段文案还犯了"用参数堆砌营造专业感"的通病。
判断销售专业度的一个好方法是——**看他有没有把不同维度的参数混着用**。
把 RI 和火彩混为一谈，说明他在背话术，而不是懂原理。

<a id="q6"></a>
## Q6

**问**：两颗参数几乎相同的圆钻差价 15%。销售 A 说"亭角 40.8°，正好是理想值"，
销售 B 说"经过 ASET 检测，光学表现更好"。哪句证据更强？还要问什么？

**答**：

**B 的证据更强**，理由是**证据层级不同**：

| | A：亭角 40.8° | B：ASET 检测 |
|---|---|---|
| 提供的是 | **单一参数**，且只是"落在区间内" | **实际光学表现**的直接测量 |
| 局限 | 亭角合适**不足以**保证好看：还要冠角、腰厚、对称性、抛光、小面角度配合。而且 Tolkowsky 模型基于理想化假设，区间内不必然好看（§3.5 的诚实说明） | ASET 直接显示光从哪些角度返回、哪里漏光——**是结果而不是输入** |
| 类比 | 报一个配料的分量 | 尝了成品的味道 |

所以 A 说的是"及格线内"，B 说的是"实测表现"。**参数是筛选工具，光学表现才是判据。**

**但 B 的说法也不能直接采信**，要继续追问：

1. **"能给我看 ASET 图吗？"**——口头说"检测过"和拿出图是两件事；
2. **谁做的检测？**自家拍的还是第三方？自家设备与拍摄条件可以影响图像观感；
3. **其他参数呢？**要完整的：冠角、亭角、台宽比、腰厚、全深比、对称性、抛光、
   有无荧光（第 14、16 章）；
4. **两张证书是同一家实验室出的吗？**不同实验室的松紧度不同，
   "同色级同净度"跨实验室可能并不等价（第 11 章）——**这一项常常就是价差的真实来源**；
5. **差价里有多少与石头无关？**品牌、店面、渠道、售后、镶嵌工艺都可能占掉这 15%（第 40、41 章）。

**最终的判断方式**：把两颗放在**同一光源下**，同时看、转动着看，**用眼睛做最后一票**。
参数与图只是帮你缩小到"值得上手比较"的候选。

> **要带走的判断**：面对销售话术，比较的不是谁说得更专业，而是
> **谁提供的是可验证的证据**。"我们的参数正好是理想值"是最容易说的一句话，
> 也是信息量最低的一句。

<a id="q7"></a>
## Q7

**问**：看 GIA 4C 教育页的切工图示，过浅与过深在视觉上分别表现为什么？
哪一种更容易被误认为"石头很大"？

**答**：

**过浅（too shallow）的视觉表现**：

- 光从亭部漏出，中心区域**发空、发白、透亮**，缺少内部弹回来的亮光；
- 极端情况出现**"鱼眼"（fish-eye）**：从台面能看到腰棱的反射形成一圈灰白环；
- 严重时可以**透过石头看到背后的东西**（就是本章讲的窗口效应）。

**过深（too deep）的视觉表现**：

- 光被反射到不利方向、从旁边漏走，**中心发暗**，形成俗称的**"黑底"/"钉头"（nail head）**；
- 整颗石头看起来小而闷，缺少大面积的明亮反光。

**更容易被误认为"石头很大"的是过浅那种。** 原因是几何上的：

> 在**重量相同**的前提下，切得浅 → 深度小 → **直径变大**。
> 而人眼判断"大小"看的是**正面直径/台面面积**，不是重量。
> 所以过浅的石头**看起来更大**，代价是亮度差、可能有窗口或鱼眼。
>
> 反过来，过深的石头把重量"藏在了底下"：直径偏小、**显小**，
> 而且中心发暗——**花了买大石头的钱，得到了显小又发闷的效果**，这是更亏的一种。

> **要带走的判断**：这里有一个真实存在的取舍——
> 有些买家愿意接受**轻微偏浅**换取"显大"，这不是错，而是明确的偏好选择。
> 错的是**不知道自己在换什么**。第 13、16 章会把"显大 vs 光学表现"的权衡讲成可操作的方法。
