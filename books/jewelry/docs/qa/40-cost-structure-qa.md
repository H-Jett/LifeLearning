# 第 40 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：镶宝首饰的整件重量可能含主副石、扣件和不同结构；即使金属重量相同，纯度、镀层、空心、宝石身份/
处理、镶嵌、工艺和售后仍不同。必须先把重量口径和所有规格对齐，才可能讨论任何单位价格。

<a id="q2"></a>
## Q2

**答**：保险替换估价服务于在特定条件下重新购得相似物件；即时回收是回收方在当期渠道、材料、状态、再销售
风险和文件条件下提出的交易报价。用途、风险与市场不同，因此数值可能显著不同，不能互相替代。

<a id="q3"></a>
## Q3

**答**：先要求 A 补齐金属纯度、主副石身份/处理/报告、各项重量口径、镶嵌与表面结构、货号、总价和退换/
维修条件；再核对 B 的每项书面承诺能否与实物和报告对应。完成同一张报价卡后，按自己是否需要报告、改圈、
补镀等服务做取舍。不能从信息较少的一方直接推断“利润更高”或“必定更划算”；信息无法补齐就应视为不可比。
