# 第 22 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：它不是全球统一的基础颜色分级。报告中的描述由出具机构、观察条件和对象状态共同限定；
脱离这些信息，只剩模糊的营销词，不能推出天然、无烧、产地或价格。

<a id="q2"></a>
## Q2

**答**：加热要问报告对处理的具体措辞、检测限制和比较对象；铅玻璃充填还必须问充填披露、
保养、维修和售后边界。两者都不应隐瞒，但耐久性与日常处理要求并不相同。

<a id="q3"></a>
## Q3

**答**：先索取可验证的完整报告或编号，并将报告的重量、尺寸、形状、照片/特征与实物对应；再分别
确认天然/合成结论、加热结论、是否有充填、产地意见（若有）和“鸽血红”是否确为该机构原文。
若石头已镶嵌或无法对应，记录限制并在付款前安排复核或第三方检测；不要用截图和口头承诺补足证据。
