# 第 20 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：Rapaport 表是特定规格下的行业参考/要价基准，而不是每笔成交记录。实际交易还要考虑具体石头、
形状、切工、荧光、报告、库存、付款和退货条件，零售成品还额外包含金属、制造、品牌与服务。

<a id="q2"></a>
## Q2

**答**：4C 未覆盖主石的全部可见表现，也未包含戒托材质金重、工艺、镶嵌、报告、售后和渠道。因此只能
作为裸石比较的起点，不能直接决定两枚成品戒指哪件“更值”。

<a id="q3"></a>
## Q3

**答**：核验“国际报价”的来源、日期和适用规格；所谓六折的基准和计算式；“证书价”是谁做的何种估价；
回购的对象、触发条件、折算方式、费用和例外；以及报告在线核验、天然/培育来源、退换与复检规则。
没有书面条款的承诺不应计入购买价值。
