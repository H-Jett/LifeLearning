# 第 31 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：A/B/C 主要传达处理状态，不是颜色、透明度、质地、裂隙、工艺、形制和交易条款的总分。两件同为
A 货仍可差异极大；处理状态不同也必须先如实披露、再在同类条件下比较。

<a id="q2"></a>
## Q2

**答**：B 货的漂白与聚合物浸渍不仅改善外观，还涉及结构、热/化学品、清洗与维修风险。它影响的是后续
使用和证据链，而非只改变一次柜台前的视觉效果。

<a id="q3"></a>
## Q3

**答**：不把紫外反应当结论。要求独立报告，核对其处理原文、项目与实物对应；同时取得保养、退换和复检
条款。卖方若不能提供支持“天然 A 货”的可核验证据，则将处理状态列为待核，不按该溢价付款。
