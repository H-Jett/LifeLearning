# 第 18 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：培育钻石具有与天然钻石基本相同的化学、物理与光学性质，只是生长来源不同；莫桑石是碳化硅、
立方氧化锆是另一种材料。它们都可被用作“仿钻”，但不能叫作培育钻石。

<a id="q2"></a>
## Q2

**答**：HPHT 可指在高压高温环境中生长钻石的工艺，也可指对已长成的材料进行高压高温改色处理。
二者发生阶段不同，购买时必须看报告具体写的是生长方法还是检出的后处理。

<a id="q3"></a>
## Q3

**答**：CVD 与“天然”相矛盾：CVD 是实验室生长路线；“肉眼看不出”也不能取消披露和报告。还应追问
“无奶咖”是否有明确、可定义的报告依据，而不是营销形容词。要求书面列明材料来源、报告号及官网核验、
腰围刻字、生长方式、是否检出后处理、退换与复检条款。
