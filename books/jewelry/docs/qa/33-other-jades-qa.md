# 第 33 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：“瓷度”是对致密感、光泽和外观的市场描述；绿松石的孔隙、颜色和光泽可能受稳定化、含浸或染色
影响，部分处理不能只靠常规观察区分。应看书面披露和适当实验室结论。

<a id="q2"></a>
## Q2

**答**：颜色集中在裂隙/孔隙可提示染色风险，但天然纹理、杂质、切工与损伤也会影响外观。线索的正确用途
是要求处理披露或送检，而不是自行宣布“染色”。

<a id="q3"></a>
## Q3

**答**：要求材料名称、天然/处理结论、是否稳定化/含浸/染色、报告项目与原文；核对报告号、尺寸、重量、
照片/特征与实物；取得温和清洗、维修、退换和复检条款。“原矿、高瓷、无优化”应分别有可核验证据，
否则按待核处理而非按高确定性溢价付款。
