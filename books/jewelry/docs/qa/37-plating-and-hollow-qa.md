# 第 37 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：镀层说的是表面；基体说的是主体材料。白 K 金可以镀铑，普通金属也可以镀金或镀铑，同一物件还可能
是空心结构。若不拆开记录，就无法判断磨耗后会呈现什么、应怎样维修，也无法比较两件商品的材料与价格。

<a id="q2"></a>
## Q2

**答**：镀层磨耗取决于表层状态、佩戴频率、摩擦点、汗液、清洁剂、尺寸调整、抛光及首饰形状等条件。没有
统一寿命。可以问卖方的保养、补镀与售后条件，却不应把经验天数当成所有商品的质量判据。

<a id="q3"></a>
## Q3

**答**：先不把“18K 金色”读成 18K 金基体：要求写明基体、表层金属、工艺、是否空心和“厚镀”的可核验
指标及依据；再确认耳针/耳堵的材质、重量口径、磨耗后的售后和退换条件。“绝不掉色”是无法核验的绝对
承诺，应要求转为明确的适用条件与服务条款。若卖方不能提供基本材质和结构信息，则无法作同类比较，宜
暂缓购买或换资料完整的商品。
