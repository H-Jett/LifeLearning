# 第 41 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：渠道只安排了展示、付款、交付与售后路径，不能证明具体货品的材质、处理、重量或报告对应。无论在哪买，
都要核对经营主体、货品规格、总价、验货节点和售后。

<a id="q2"></a>
## Q2

**答**：至少保存商品链接/页面、直播展示与承诺、经营主体、客服确认、订单与付款、证书编号、物流和连续开箱
记录，使材料、实物与交易条款可互相对应。

<a id="q3"></a>
## Q3

**答**：不按私信链接转账。要求在可追溯的商品页/订单中写明实际经营者、货品规格、证书、总价和退换条件；
保存相关展示。无法补齐时停止交易，不能以“最低价”抵消无法验货与维权的风险。
