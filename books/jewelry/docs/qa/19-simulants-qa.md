# 第 19 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：“人造钻”可能混指培育钻、莫桑石或 CZ，材料身份不同、价值与披露也不同。订单应使用可核验的
准确材料名，例如“培育钻石（laboratory-grown diamond）”或“合成莫桑石”。

<a id="q2"></a>
## Q2

**答**：莫桑石的热学性质可使传统热导探针显示钻石类结果；且即使证明是钻石，也还没有区分天然、培育
或处理。天然来源结论需要报告或实验室的综合检测。

<a id="q3"></a>
## Q3

**答**：这条链只提供了一个有明确局限的筛查结果，不能支持“绝对天然”。应要求订单材料披露、可官网
验证的报告号、腰围刻字与实物对应；对高价值或信息不一致的石头，暂停交易并送权威实验室复检。
