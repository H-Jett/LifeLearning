# 第 27 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：变色由光源光谱、宝石多色性和切工共同呈现。没有光源与观察方向，别人无法复现你所见的颜色，
也不能与另一颗石作可比判断。

<a id="q2"></a>
## Q2

**答**：看光带是否锐利、明亮、居中、完整，移动光源时是否平顺；同时看底色、弧面比例、表面状态和材料
身份。仅有一条线不构成天然金绿宝石的结论。

<a id="q3"></a>
## Q3

**答**：拆为材料是否金绿宝石、是否天然、是否实验室生长/处理、颜色变化在何种光源下、光带是否为猫眼、
产地是否为俄罗斯及报告是否对应实物。手机闪光灯与一条亮线只能提供观察记录；付款前应索取可验证的完整
报告并对应石重、尺寸、照片/特征，必要时第三方复核。
