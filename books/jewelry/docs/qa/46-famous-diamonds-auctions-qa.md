# 第 46 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：名钻成交是特定物件在特定时间、地点、币种、买家竞争与条款下的结果，还包含极端稀缺、技术品质与出处。
普通首饰在材料、报告、渠道和流动性上均可能不同，不能按克拉直接套用。

<a id="q2"></a>
## Q2

**答**：宝石学卡记录重量、颜色、净度等可检测特征；历史卡记录其持有、重切和文献关联。二者相互补充而不互相
替代，传奇故事也不能替代任一证据。

<a id="q3"></a>
## Q3

**答**：要求卖方先提供这颗普通彩钻的身份、天然/处理、重量、颜色、净度、报告、总价和售后。说明名钻拍卖是
不可直接外推的历史个案；无法将两件货品规格与交易条件对齐时，不接受“名钻单价”作为定价依据。
