# 第 30 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：种侧重结构细腻与均匀感，水侧重透明度/透光表现，色侧重色调、饱和度、明度和分布，工侧重形制、
比例、抛光和雕工。它们是不同观察维度；例如透明度较好不能自动证明颜色、裂隙或工艺同样优秀。

<a id="q2"></a>
## Q2

**答**：交织结构带来较好韧性，但已有裂隙、薄弱边角、手镯连续圈和处理历史仍会影响破损风险与价值。
韧性是材料性质，不是对某件具体首饰状况的担保。

<a id="q3"></a>
## Q3

**答**：拆为材料是否翡翠/硬玉为主、“老坑/玻璃种/帝王绿”的外观与市场描述、天然/处理结论、缅甸产地
意见、手镯是否一体及裂隙状态。先取得完整报告并对应石重/尺寸/照片或特征；再在可比光线观察种水色工与
裂隙；对产地和处理分别看报告原文。直播截图不足以支撑这些高溢价命题。
