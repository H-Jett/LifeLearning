# 第 38 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：铸造和 3D 打印分别描述制造链中的路线或环节；它们不自动规定合金、结构厚度、后处理、镶嵌和终检
质量。应结合成品的表面、接缝、结构、石头牢度、材料披露和售后来判断具体货品。

<a id="q2"></a>
## Q2

**答**：抛光和电镀主要处理外观表层；它们无法证明内部没有缺陷、连接足够牢或宝石已安全镶嵌。甚至过度抛光
可能削弱细爪/花纹，镀层也可能随磨耗变化。因此应独立检查结构、活动部件和镶嵌。

<a id="q3"></a>
## Q3

**答**：先在自然/侧向光下拍摄针孔与锐边的位置、日期和整体图，保留原设计图、订单、材质/重量承诺与对话；
要求商家书面说明是表面问题、铸造问题还是可接受公差，并提出返工、换货、修复或退款的具体方案。不要自行
打磨或填补，以免改变责任边界。若涉及贵金属、宝石或尺寸争议，要求核对交付物与订单，并在必要时咨询独立
检测或消费者维权渠道。
