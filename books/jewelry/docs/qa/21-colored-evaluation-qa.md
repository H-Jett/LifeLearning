# 第 21 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：色调回答主要偏什么颜色，饱和度回答颜色强度/浓郁度，明度回答整体偏亮还是偏暗。三者必须一起写，
不能用“深蓝”同时代替所有评价。

<a id="q2"></a>
## Q2

**答**：多数彩宝没有跨品种通用净度系统；某些材料天然常见内含物，某些内含物还可能与外观或身份相关。
应评估它对正面美观、耐久性和材料预期的影响，而不是直接套钻石等级。

<a id="q3"></a>
## Q3

**答**：至少拆为颜色深浅/饱和度的外观观察、“无烧”的处理结论、以及“克什米尔”的产地/市场表述。
前者要在可比光线下看实物或标准视频；后两者要看权威报告的具体措辞、实验室与检测限制，不能靠口头承诺。
