# 第 44 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：两者的参与程度、尺码确定性、佩戴强度、交期和售后需求不同。同一石头参数在不同结构和使用方式下的
风险也不同，应先定义场景不可妥协项。

<a id="q2"></a>
## Q2

**答**：不能省掉材料身份/处理披露、结构安全、总价与关键售后条款、可追溯订单。可在大小、品牌、复杂工艺或
非关键装饰上调整，但须保持候选间规格可比。

<a id="q3"></a>
## Q3

**答**：优先选择尺码风险低或可可靠改圈/交换的款式，确认交期和书面退换条件；选耐久、低勾挂结构，保留预算
给改尺与售后。不要为了“惊喜”放弃订单、报告和收货验货路径。
