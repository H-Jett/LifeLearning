# 第 23 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：前者是产地意见，后者是颜色描述；两者都不替代对正面颜色、切工、透明度、天然/合成和处理的
核验。还须知道它是否确为特定实验室对眼前这颗石的书面结论。

<a id="q2"></a>
## Q2

**答**：普通加热与晶格扩散的处理机制和披露重点不同；扩散颜色可能有不同渗入深度，浅层颜色可能受
重抛、改切或表面损伤影响。因此维修前要把报告和处理信息交给维修方，而不是先处理后再追问。

<a id="q3"></a>
## Q3

**答**：先在相同光线下记录两者的颜色、均匀度、窗口/灭灯、尺寸和耐久性；再分别确认报告是否对应实物、
天然/合成结论、处理原文、产地意见（若有）及交易/售后条件。口头“皇家蓝、无烧、某产地”在未落到
对应报告前只是待核信息；加热石也不因此失去天然属性。完成同类比较后，才按自己的预算和偏好排序。
