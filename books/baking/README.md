# 烘焙的原理：从看懂配方到自己改配方

> 📖 **在线阅读**：<https://h-jett.github.io/LifeLearning/baking/>
> 🏠 **书架首页**：<https://h-jett.github.io/LifeLearning/>

一本写给厨房小白的**原理**书。它不给你配方，它让你读懂配方——
并且在读懂之后，能**自己改配方**：换糖量、换油脂、换粉、减糖、放大份量。

## 为什么要有这本书

配方只告诉你**放多少**，不告诉你**为什么是这个量**：

- 为什么这份饼干要放这么多糖？糖减一半会变成什么样？
- 黄油能不能换成植物油？
- 高筋面粉是不是做什么都更好？
- 泡打粉用完了，能不能用小苏打顶上？

这些问题的答案不在配方里。它们在一个更基本的事实里：

> **一份配方是几组竞争关系的配平。**
> 面粉、水、糖、油、蛋、盐、膨松剂在争同一批资源——
> **争水**、**争面筋**、**争温度窗口**、**争气**。
> 改动任何一项，都是在改这组配平。
>
> **所以改配方的正确问法永远是同一句：「它会抢走谁的什么？」**

而这一切之所以必须**事先**想清楚，是因为烘焙和炒菜有个根本差别：

> **炒菜可以边尝边改，烘焙一旦进炉就改不了。**

## 全书结构

七部分、**45 章 + 5 个实战项目**（完整清单见[学习路线图](docs/roadmap.md)）：

| 部分 | 主题 |
|------|------|
| 一 | 原料各自在做什么：面粉 / 水 / 糖 / 油脂 / 蛋 / 盐 / 膨松剂 + 烘焙百分比 |
| 二 | 膨发的三条路线：生物（酵母与酵种）/ 化学（酸碱配平）/ 物理（打发与蒸汽） |
| 三 | 结构是怎么立住的：面筋网络、淀粉糊化、蛋白凝胶、脂肪结晶；面团 vs 面糊 |
| 四 | 操作即控制变量：搅拌方式、温度控制、发酵与冷藏、整形与醒发 |
| 五 | 烤箱与热：炉内传热、炉温标定、蒸汽、模具、**用内部温度判断熟成** |
| 六 | 从原理到成品：逐类拆解 + 变体推演（换糖 / 换油 / 换粉 / 放大份量） |
| 七 | 改配方与诊断：配方平衡、替换规则与代价、失败诊断手册、保存与老化 |

## 怎么读

- **正文**讲机理，配 Mermaid 图与对照表，关键数值都带出处
  （统一登记在[参考书目与出处登记](docs/standards.md)，含**已知缺口**一节）；
- **所有配方与比例都用烘焙百分比表达**，并写明基准——本书默认**以面粉总量为 100%**；
- 每章有**「常见说法辨析」**：烘焙谣言逐条标注 ✅ 有共识 / ⚠️ 有争议 / ❌ 明确错误 / 缺乏证据；
- 每章末有**思考题**（含【案例】题，答案册给完整推理链）与**本章实操**两档：
  **🅐 零成本版**（**不用烤箱**）/ **🅑 开火版**（有烤箱时做的单一变量对照实验）；
- 每章末有 **🔎「下次烤之前的用处」** 与 **「本章依据」**。

核心工具是两张表，做任何一款成品都能用：

- [配方解码表](docs/forms/recipe-decode.md)——原料 → 烘焙百分比 → 扮演什么角色 → 改动会连带影响什么
- [烘焙记录与复盘表](docs/forms/bake-log.md)——比例、状态、室温水温、发酵时间、炉温、出炉判据、下次改哪一个变量

## 和《做菜的原理》什么关系

姊妹书，但**各自独立成站、内容不互相引用**。
两本书都会讲到美拉德反应、淀粉糊化、蛋白质变性，
**本书在自己的章节里重新讲一遍**并注明"另一本书里也讲过"，不会让你两边跳。

分开写的理由正是那条根本差别：《做菜的原理》教**边做边调**，这本书教**事先把账算清楚**。

## 正确性怎么保证

烘焙圈的谣言密度极高，而且**你没法当场纠错**——一炉毁了就是毁了。
所以这本书的写作纪律（完整版见 [CLAUDE.md](CLAUDE.md) §1）：

1. **不凭记忆写作**，关键数字要求两个独立来源；**查不到就不写死数字**，
   改成写规律或标"经验值"并说明波动范围；
2. **食品安全的数字必须引官方来源**，并注明**各国口径不同**
   （生面粉、生面糊、生蛋、天然酵种、保存期限）；
3. 区分「事实 / 官方规定 / 行业惯例 / 烘焙传说」四层，证据不足的一律进辨析栏目；
4. **不做医疗与营养治疗建议**——无麸质只讲工艺与代价，不谈治疗；
5. **只复述，不抄原文**，不搬运他人图片与表格版式。
