## 配方的语言

<a id="bakers-percentage"></a>
**烘焙百分比（baker's percentage / baker's math）**——一种记配方的方式：
**把配方中面粉总量记作 100%**，其余每样原料都写成"占面粉重量的百分之多少"。
所以一份配方的百分比加起来通常**远大于 100%**（这是正常的，不是算错了）。
它的价值有三个：**可比较**（两份来源不同的配方能摆到同一把尺子上）、
**可缩放**（想做多少就把面粉定成多少克，其余按比例算）、
**可改**（"糖从 50% 降到 30%"是一句能被执行也能被复现的话）。
⚠️ 用别的基准时（例如以面团总重为基准）**必须当页写明**，否则数字没有意义。

<a id="formula"></a>
**配方 / 配方表（formula）**——职业烘焙里更常说 formula 而不是 recipe，
因为它指的是**一组比例关系**，而不是一份操作说明。
本书用"配方"指比例，用"做法"指步骤——这两件事可以分开改。

<a id="formula-balance"></a>
**配方平衡（formula balance）**——一份配方里"起结构作用的原料"与
"削弱结构的原料"之间的相对量关系。
在本书的说法里，它就是"几组竞争关系的配平"：谁拿到水、谁妨碍面筋、
谁推迟定型、谁负责产气。改动一项就是在改这个平衡。

<a id="total-formula"></a>
**总配方百分比（total formula percentage）**——配方里含有
[预发酵面团](#preferment)（中种、汤种、酵种）时，**把所有部分的面粉加起来当作 100%**、
其余原料也各自加总之后算出的百分比。它是**唯一能和别的配方比较**的那一套数字。
⚠️ 它和"中种自己的含水量"是两个不同基准的数字：
一份中种含水 60%、总含水 65% 的配方非常常见，**把前者当成后者是最常见的换算错误**。

<a id="preferment"></a>
**预发酵面团（preferment）**——正式和面之前先做好、并让它发酵或糊化的一部分面团，
中种、波兰种、酸种（酵种）、汤种都属于这一类（细节在第 12、22 章）。
**它里面的粉与水必须计入总配方的面粉总量与总水量**——
汤种尤其容易被忘记，因为它看起来像"一碗糊"而不像"面团"。

## 面粉与面筋

<a id="gluten"></a>
**面筋（gluten）**——小麦粉里的两类蛋白质吸水之后，在机械作用下形成的
黏弹性网络。它是大多数小麦制品的**主要结构骨架**，也是面团"能被拉开又会回缩"的原因。
⚠️ 面筋**不是面粉里现成就有的东西**：面粉里有的是蛋白质，
面筋是**加水 + 施加机械作用 + 时间**之后才形成的。

<a id="glutenin-gliadin"></a>
**麦谷蛋白与麦醇溶蛋白（glutenin / gliadin）**——构成面筋的两类蛋白质，分工不同：
研究显示单体的**麦醇溶蛋白表面活性很高**、并出现在面团的**气室壁**上，
而聚合的**麦谷蛋白几乎没有表面活性**、只出现在面团主体中。
粗略地说，一个更负责"能拉长"，一个更负责"有弹性"。

<a id="ash"></a>
**灰分（ash）**——把面粉完全烧掉后剩下的矿物质残留占比，是**碾磨程度的间接指标**：
麸皮和胚芽的矿物质多，所以磨得越接近整粒、灰分越高。
欧洲的面粉常直接用灰分给面粉编号（如 T55、T65）。

<a id="damaged-starch"></a>
**损伤淀粉（damaged starch）**——碾磨过程中被机械破坏的淀粉颗粒。
它**吸水比完好颗粒多得多**，还会**降低淀粉糊化的起始温度**、影响成品老化速度。
这是"面粉吸多少水不能只看蛋白质含量"的重要原因之一。

<a id="farinograph-water-absorption"></a>
**粉质仪吸水量（farinograph water absorption）**——用标准仪器测出的
"这批面粉要加多少水才能达到规定稠度"，以占面粉重量的百分比表示。
它受蛋白质含量、损伤淀粉、以及阿拉伯木聚糖 / β-葡聚糖等**非淀粉多糖**共同影响——
所以它是"面粉能吃多少水"的综合指标，不是蛋白质含量的同义词。
一项用 150 份小麦、28 项指标做回归的研究给出的最优预测模型是四个变量：
**蛋白质含量 + 可溶性淀粉 + 损伤淀粉 + 水溶性阿拉伯木聚糖的比浓黏度**。

<a id="arabinoxylan"></a>
**阿拉伯木聚糖与非淀粉多糖（arabinoxylan / non-starch polysaccharides, NSP）**——
面粉里含量不高却**极能吃水**的一类多糖（麸皮里尤其多）。
研究显示加入高分子量或低分子量阿拉伯木聚糖都会**显著提高粉质仪吸水量**
与面团形成时间；大麦 β-葡聚糖同样提高吸水量。
它是"换一批粉，同样的水量突然不对"的常见原因之一。

<a id="extraction-rate"></a>
**出粉率与灰分的关系（extraction rate）**——一百份小麦磨出多少份面粉。
出粉率越高，带进来的麸皮与胚芽越多，于是**[灰分](#ash)越高、颜色越深、吸水越多，
而面筋网络越容易被麸皮颗粒打断**。
美国的面粉标准并不直接规定出粉率，而是用一条**比例式**限定去麸程度：
**灰分（干基）不超过「蛋白质（干基）÷ 20 + 0.35」**——
这说明**灰分单独没有意义，必须和蛋白质一起读**。
欧洲的面粉编号（T55、T65 一类）则直接按灰分编。
⚠️ 各国口径不同，以当地现行发布为准。

<a id="alpha-amylase"></a>
**α-淀粉酶与落降数值（α-amylase / falling number）**——
α-淀粉酶把淀粉切成更小的糖，是面粉自带的"拆解工"；
落降数值是衡量它活性的常规指标（**数值越低代表酶活越高**）。
酶活太低：后段产气乏力、上色不足；太高（典型原因是**小麦收获前发了芽**）：
淀粉被切得太多，面包心发黏、结构塌软。
一个很硬的旁证是法规本身：美国的面粉标准允许加麦芽大麦粉（不超过 0.75%）
或真菌 α-淀粉酶，理由原文写着"**为补偿酶的天然不足**"——
**酶活是一个被当作变量来管理的东西**。
⚠️ 本书未核到"落降数值低于多少就不能用"的一手阈值，因此不写阈值数字。

## 水与淀粉

<a id="hydration"></a>
**水合（hydration）**——原料吸水的过程。在烘焙里它有两层意思：
①**动作**：让面粉充分吸水（面筋才能形成、淀粉才能在受热时糊化）；
②**数量**：配方里水的烘焙百分比，中文常说"**含水量**"或"水粉比"。
"这个面团 75% 水"说的就是第二层意思。

<a id="water-competition"></a>
**争水（water competition）**——本书的核心说法之一：
一份配方里的水是**有限的、被多方争夺的资源**。
面筋要水才能形成，淀粉要水才能糊化，糖和盐会把水"占住"，
纤维与损伤淀粉会多吃水。**加水和减水的后果，取决于水被谁拿走了。**

<a id="gelatinization"></a>
**淀粉糊化（starch gelatinization）**——淀粉颗粒在**有水且受热**时吸水膨胀、
结构崩解，把体系变稠、变成凝胶。它是面包心、蛋糕体能"立住"的主要机制之一。
⚠️ 糊化温度**不是固定值**：随植物种类差别很大，并受含水量、pH、糖、盐、脂肪、
颗粒损伤程度影响。**烘焙体系尤其极端**——低水分 + 高糖会把糊化温度推得非常高，
在饼干这类配方里甚至几乎不发生糊化。（另一本书里也讲过糊化，那里讲的是煮锅里的情形。）

<a id="retrogradation"></a>
**回生 / 老化（starch retrogradation / staling）**——烤好的成品放置时变硬、变干、
掉渣的过程。主流解释是**支链淀粉重结晶**，并伴随水分在面筋与淀粉之间、
以及面包心与面包皮之间的**再分配**。
⚠️ 它**不等于"水跑光了"**：密封保存的面包同样会变硬。

<a id="amylose-amylopectin"></a>
**直链淀粉与支链淀粉（amylose / amylopectin）**——淀粉的两类分子。
直链基本是线性的，支链是高度分枝的。两者的比例随作物品种变化，
一项研究测到面包小麦的直链淀粉含量在 28.38%~30.94%（⚠️ 仅见于该研究，
本书只用它说明"大约四分之一到三分之一"这个量级）。
这个比例要紧的原因有两个：它影响**糊化与增稠行为**，
而且**[回生](#retrogradation)的主流解释正是支链淀粉重结晶**——
也就是说，它同时决定"烤的时候怎么定住"和"放两天会变成什么样"。

<a id="free-water"></a>
**自由水与结合水（free water / bound water）**——同样是"水"，
有的能自由流动、能蒸发、能参与反应，有的被糖、盐、蛋白质与淀粉束缚住。
[水分活度](#water-activity)描述的正是这个区别，而不是含水量。
理解它能解开一个常见困惑：**"含水量高"不等于"湿润"，
"变硬"也不等于"变干"**——密封保存的面包同样会变硬（见[回生](#retrogradation)）。

<a id="baking-loss"></a>
**烘焙失重（baking loss）**——进炉前后的重量差占进炉重量的比例，
跑掉的**主要是水**。它随炉温与时间上升：
一项研究把吐司在 190~230 °C 下各烤 40 分钟，对照组失重从 35.11% 升到 47.23%，
同时表皮温度从 128.5 °C 升到 190.2 °C。
⚠️ **这是一项研究、一种产品、一个固定时长的结果，不是"面包的失重率"**——
本书只用它的方向：**炉温越高、烤得越久，跑掉的水越多**。
把自己每一炉的失重记下来，比任何书上的数字都有用。

<a id="water-activity"></a>
**水分活度（water activity, a_w）**——描述"水有多容易跑出来 / 有多容易参与反应"的指标，
不是含水量。糖、盐这类溶质会把水"束缚住"、**降低水分活度**。
烘焙里它同时关系到**保湿口感**、**褐变速度**和**保存期限**。

## 糖

<a id="sucrose"></a>
**蔗糖（sucrose）**——最常说的"砂糖"，由一个葡萄糖和一个果糖连成的双糖。
两个要记住的性质：
① 它**不是还原糖**，必须先分解成葡萄糖与果糖（[转化糖](#invert-sugar)）
才能参与[美拉德反应](#maillard)；
② 在**抬高淀粉糊化温度**这件事上，它的能力强于许多其他甜味剂——
一项用 DSC 测 14 种低聚糖、阿洛酮糖与蔗糖对小麦淀粉影响的研究明确这么写，
并指出"**减糖的同时维持较高的糊化温度一直是个难题**"。
所以蔗糖在配方里是一个**很难被平替**的角色（见[推迟定型](#sugar-set-delay)）。

<a id="hmf"></a>
**5-羟甲基糠醛（HMF）**——糖在受热与褐变过程中生成的一种化合物，
在研究里常被当作**褐变进程的可测指标**。
本书引用它只是为了一条工艺结论：一项研究观察到
**[水分活度](#water-activity)降到 0.4 以下是一个临界点，越过之后 HMF 生成速率急剧上升**——
也就是"**先干，才谈得上褐变加速**"。
⚠️ 本书**不讨论**它的健康含义，也不做任何摄入建议。

<a id="hygroscopicity"></a>
**吸湿性（hygroscopicity）**——糖从环境（以及从面团其他成分那里）吸住水分的性质。
它解释了为什么高糖配方的成品**更湿润、更不容易干**——
糖把水攥在手里，既不给面筋、也不容易蒸发掉。

<a id="invert-sugar"></a>
**转化糖与还原糖（invert sugar / reducing sugar）**——蔗糖分解成葡萄糖与果糖后的混合物；
葡萄糖、果糖属于**还原糖**，能参与美拉德反应，而蔗糖本身不能直接参与。
这是"换一种糖，上色速度就变了"的原因之一。

<a id="sugar-set-delay"></a>
**推迟定型（delayed setting）**——糖在烘焙里的一个关键后果：
它**抬高淀粉糊化温度**、并**推迟或抑制面筋蛋白的受热交联**，
于是面团/面糊"定住"的时间被推后。
定得越晚，能摊开、能膨胀的时间就越长——这是"加糖让饼干摊得更大"的直接机制。

## 油脂

<a id="shortening-effect"></a>
**短化 / 起酥作用（shortening effect）**——油脂裹在面粉颗粒与蛋白质表面，
**妨碍它们互相连接成连续的面筋网络**，于是成品口感从"韧、有嚼劲"变成"酥、一咬就断"。
英文里 shortening 既指这个作用，也直接用作"起酥油"的名字。
> ⚠️ **诚实说明**：脂质在面团里的作用机理，**学界至今有互相对立的观点**
> （一篇脂质综述明确这么写）。本书只写方向与可复现的现象，不给机理定论。

<a id="solid-fat"></a>
**固态脂肪与液态油（solid fat / liquid oil）**——同样是"油脂"，
**能不能保持固态**决定了它能做什么：固态脂肪能被打进空气、能在面团里隔出层
（起酥、千层的前提）；液态油会直接被面团吸收，做不出层，也留不住打进去的空气。
所以"黄油换成色拉油"不是等量替换，是**换掉了一个功能**。
还要注意：按美国法律定义，**黄油的乳脂不低于 80%**，
剩下不到 20% 是水与乳固形物；而液态油基本是 100% 脂肪——
**等重替换连水都一起换掉了**。⚠️ 各国口径不同，以当地现行发布为准。

<a id="solid-fat-content"></a>
**固体脂肪含量（solid fat content, SFC）**——一块脂肪里"结晶成固体"的那部分所占比例。
它**随温度升高而下降**，所以"固态 / 液态"在油脂上不是一个开关，而是一条曲线。
一块脂肪好不好用，取决于它在**你操作的那个温度下**固体与液体的比例合不合适。
⚠️ 本书未核到家用黄油的 SFC—温度曲线数据，因此**不给温度数字**，只给判据。

<a id="plastic-range"></a>
**可塑范围（plastic range）**——一块脂肪"既能变形、又不会流动"的那段温度区间。
固体太多（太冷）→ 硬、脆、**一压就碎**，擀不开也裹不住；
固体太少（太暖）→ 软、塌、**留不住气泡**，也隔不出层。
本书给的判据是手指而不是温度计：
**能留下清晰指印、不粘手、不出油**，就在可塑范围里；
裹入用的油脂再加一条：**能弯不能断**。

<a id="polymorphism"></a>
**脂肪多晶型（polymorphism：α / β′ / β）**——同样的脂肪分子能排成不同的晶体形式，
熔点、晶体大小与网络性质都不同。一项关于可颂专用油脂的研究直接写道：
**β′ 晶型是烘焙应用中热力学上受偏好的那一种**，研究目标之一正是促进 β′ 形成并减小晶体尺寸。
另有研究提醒：给裹入用油脂做**机械加工（塑化）会对质地产生不利影响**——
所以"你怎么把黄油弄软"本身就是一个变量。

<a id="lamination"></a>
**裹入与起酥层（lamination）**——把固态脂肪与面团**交替折叠成多层**，
烘烤时靠蒸汽把层顶开。一篇综述指出关键是建立并**维持**这个多层结构；
同一篇综述也诚实地写道：**蒸汽被困住并把层顶起来的确切机制目前仍不清楚**。
一份可颂研究给出的参考用量是**裹入油可达面团重量的 35%**
（注意基准：**以面团重量计**，不是以面粉计）。
**"起酥"（有层）和"酥松"（口感短）是两件事**：前者必须用固态脂肪，后者液态油也能做到一部分。

<a id="oleogel"></a>
**油凝胶（oleogel）**——用蜡、单甘酯等胶凝剂把液态油"固定"成半固体网络，
用来在保留不饱和脂肪酸组成的同时提供固态脂肪的工艺功能。
本书引用它是因为它提供了一个很干净的证据：
一项用 36 种蜡—油油凝胶替代饼干起酥油的研究发现，
**熔点最高的巴西棕榈蜡油凝胶让饼干质地更强，蜂蜡油凝胶让饼干摊得更开、硬度更低**——
**脂肪什么时候熔化，直接改变成品形状**。

## 蛋与充气

<a id="aeration"></a>
**充气 / 打发（aeration / whipping）**——把空气以细小气泡的形式打进体系里。
它是**物理膨发**的核心：气不是烤出来的，是**事先打进去的**，烤箱只负责让它膨胀。
所以"打发到什么程度"决定了成品能涨多高。

<a id="foam-stability"></a>
**泡沫稳定性（foam stability）**——打进去的气泡能维持多久不并、不塌。
研究显示**蔗糖会让蛋清更难打起泡，但打起来之后更稳定**——
这解释了为什么很多配方要求"糖分次加入"。

<a id="emulsification"></a>
**乳化（emulsification）**——让油和水这两种本来不相溶的东西均匀分散在一起。
蛋黄里的成分是烘焙中最常用的乳化来源之一。
乳化做得好，面糊才不会"油水分离"，成品组织才细腻。

<a id="denaturation"></a>
**蛋白质变性与凝固（protein denaturation / coagulation）**——蛋白质受热后
原本折叠好的结构散开、互相缠结成网，从流动变成固体。
在烘焙里它是**结构定型**的主力之一（蛋、奶、以及面筋蛋白本身）。
**这个过程基本不可逆**——过了就回不来，这正是"进炉就改不了"的物理原因。
（另一本书里也讲过变性，那里讲的是炒锅里的情形。）

<a id="ovalbumin"></a>
**卵白蛋白（ovalbumin）**——蛋清里最主要的蛋白质。
一项磅蛋糕研究指出，它通过提供**巯基（—SH）**，在烘烤中形成**牢固的凝胶**，
从而参与蛋糕的结构。**蛋提供的"结构"主要是在烤箱里靠它凝出来的**，
和面筋"在案板上形成、在炉子里继续交联"的路径不同。

<a id="ldl"></a>
**低密度脂蛋白（low-density lipoprotein, LDL）**——蛋黄里装脂质的球状结构：
核心是非极性脂质，外面裹着磷脂、胆固醇与蛋白，因此**本身具有表面活性**。
一项海绵蛋糕研究用乙醇处理把 LDL 拆散后发现：
受影响的是**充气与气室稳定性**，而**蛋糕定型的时刻与程度基本不变**——
也就是说，**蛋黄的脂主要在管"气"，不是在管"定型"**。

<a id="yolk-plasma-granules"></a>
**蛋黄的浆质与颗粒（yolk plasma / granules）**——蛋黄离心后分成的两部分：
**浆质**富含低密度脂蛋白，**颗粒**蛋白质含量更高。
一项用松糕做的研究逐步用颗粒部分替代整只蛋黄，观察到面糊的**稠度系数非线性上升**，
充气与成品硬度也随之改变——**说明"加一个蛋黄"改的不只是脂肪量**。

<a id="crosslinking"></a>
**受热交联（heat-induced cross-linking）**——烘烤时面筋蛋白之间通过
**巯基—二硫键交换**继续连接成更大的网络。研究在 80~95 °C 的保温实验中
观察到这一过程按一级动力学进行、速率随温度升高。
简单说：**面团的最终结构不是在案板上定的，是在烤箱里定的。**

## 盐与发酵

<a id="fermentation"></a>
**发酵（fermentation）**——酵母（以及酵种里的乳酸菌）分解糖类，产生
二氧化碳、乙醇与各种风味物质的过程。
在烘焙里它同时做两件事：**产气**（让面团膨胀）和**产风味前体**
（研究显示发酵时的 pH 决定了释放出哪些氨基酸）。

<a id="osmotic-stress"></a>
**渗透胁迫（osmotic stress）**——高浓度的糖或盐把水从细胞里"拉"出去，
给酵母造成的压力。一项全基因组筛选显示：对高浓度蔗糖敏感的酵母突变体
**绝大多数同时对高浓度氯化钠或山梨醇敏感**，说明高糖对酵母主要就是渗透问题。
这是"甜面团发得慢""盐直接接触酵母不好"这类说法背后的机制。

<a id="osmotolerant-yeast"></a>
**耐高糖酵母（osmotolerant yeast）**——在高糖（高渗透压）环境下仍能维持产气能力的酵母。
它的存在本身就是"高糖会压制酵母"的行业旁证：
一项研究测试了四株商品压榨酵母，它们分别被推荐用于
**可颂类、面包、冷冻面团、意式节庆蛋糕**，结果证实它们在不同的复杂面团配方里
**技术表现确实不同**。
⚠️ 本书未核到"糖到多少百分比就必须换酵母"的阈值数据，因此不写阈值——
**甜面团发得慢是配方设计的必然结果，不是故障。**

<a id="rate-control"></a>
**控速（rate control）**——本书对盐在烘焙里主要角色的概括：
盐会**拖慢酵母的产气速度**（有研究把"加盐过多导致丙烯酰胺升高"归因于酵母生长被抑制），
从而拉长发酵时间、改变风味的积累。
所以"不放盐"的面团常常发得更快，但风味和操作性都会变——**盐不是可选项，是旋钮**。

<a id="co2-retention"></a>
**保气系数（CO₂ retention coefficient）**——发酵流变仪给出的指标：
**（总产气量 − 跑掉的 CO₂）÷ 总产气量**。它把"发酵"拆成了两个独立的问题——
**产了多少气**和**留住了多少**。一项 176 份样本的研究实测到：
加盐会让**总产气量下降**，却让**保气系数上升**（从约 81% 升到约 89%）。
**这是"发得快"与"发得好"不是一回事的最直接证据。**

<a id="alveograph"></a>
**吹泡示功仪与 W 值（alveograph, W）**——把面团吹成气泡直到破裂，
据此得到**W（面团力度）、P（韧性）、L（延展性）** 等指标。
它和[粉质仪](#farinograph-water-absorption)一样是**经验流变**方法：
测的是"面团在这台机器上的表现"，**不是某个物理常数**。
一项研究用它比较加盐与不加盐的面团：**W 在 97% 的样本上升、P 在 94% 上升，
但 L 方向不统一、P/L 没有确定方向**——所以"盐让面筋更强"只说对了一半。

## 膨松剂与化学膨发

<a id="chemical-leavening"></a>
**化学膨松（chemical leavening）**——靠**碳酸氢盐分解或与酸反应**放出 CO₂ 来产气。
它的特点是**放气快、过程可控**，但（一篇综述的说法）**风味复杂度不足**，
还可能留下**残留的咸味**。与生物膨发最大的差别是**时间尺度**：
一个是几十分钟到几十小时，另一个是遇水（或受热）立刻开始。

<a id="leavening-acid"></a>
**膨松酸（leavening acid）**——泡打粉里和碳酸氢钠配对的那一半。
常见的有酸式焦磷酸钠（SAPP）、磷酸二氢钙（MCP）、磷酸铝钠（SALP）、
硫酸铝钠（SAS）、酒石酸氢钾（塔塔粉）等。
它决定两件事：**能不能把 CO₂ 放干净**（见[中和值](#neutralization-value)）
和**什么时候放**（快作用 / 慢作用）。**换一种酸，成品的质地与风味都会变。**

<a id="neutralization-value"></a>
**中和值（neutralization value, NV）**——**100 份重量的膨松酸能中和多少份重量的碳酸氢钠**
（即让它放出全部可用的 CO₂）。它是配泡打粉的核心参数。
⚠️ 家用包装通常**不写**这个值——这正是本书**不给"小苏打换泡打粉"换算比例**的原因：
**缺少必需的输入条件。**

<a id="double-acting"></a>
**双效泡打粉（double-acting baking powder）**——准确的含义不是"发两次"，
而是**有多大比例的可用 CO₂ 被留到进炉之后才放**。
行业里用牌号直接标出来：例如 SAPP 10 / 28 / 40 分别表示约
**10% / 28% / 40% 的可用 CO₂ 在搅拌阶段放出（冷作用）**，其余在烘烤时放出（热作用）。
**"拌好要不要马上进炉"取决于它用的是哪一档**——而家用包装多半不写。

<a id="ammonium-bicarbonate"></a>
**碳酸氢铵（ammonium bicarbonate）**——俗称"臭粉"。受热直接分解，
放出 **CO₂ 与氨（NH₃）**，理论上不留残渣。
⚠️ 一项建模研究指出：它的最大产气被认为在 **59 °C** 附近，
**使用被限制在饼干这类低水分产品**上，因为残留物会在烘烤后留下异味；
同一研究的模拟还显示**大部分气来自碳酸氢盐，铵的贡献要小得多**。
一项对照研究发现：同一配方用碳酸氢铵做出的饼干**摊得最开、最不硬、脆裂性最高**。

<a id="self-rising-flour"></a>
**自发粉（self-rising flour）**——预先混好膨松剂的面粉。
美国 21 CFR 137.180 给了它一个**法定的酸碱配平例子**：面粉 + 碳酸氢钠 +
一种或多种膨松酸 + 盐；按规定方法测试**放出不少于 0.5% 的 CO₂**；
**酸的量要足以中和碳酸氢钠**；**酸与碳酸氢钠合计每 100 份面粉不超过 4.5 份**。
⚠️ 各国口径不同，以当地现行发布为准。
**注意它的写法本身就是[烘焙百分比](#bakers-percentage)——连法规都用这把尺子。**

## 热与褐变

<a id="maillard"></a>
**美拉德反应（Maillard reaction）**——氨基酸与**还原糖**受热时发生的一系列反应，
生成褐色物质和大量香气分子。烘焙里：面包皮、饼干边、蛋糕表面的香味与颜色主要靠它。
关键条件是**表面足够干、温度足够高**。
⚠️ 广为流传的"从 140~165 °C 开始"这个数字**缺乏可靠一手出处**，
本书只写方向不写数字（见[出处登记](standards.md)）。
（另一本书里也讲过美拉德，那里讲的是锅里的情形。）

<a id="caramelization"></a>
**焦糖化（caramelization）**——**糖单独**受热分解并聚合成褐色物质的过程，
不需要氨基酸参与。它与美拉德反应常同时发生，但**是两件事**——
所以"换一种糖"对颜色的影响，要分开这两条路径来想。

<a id="oven-spring"></a>
**炉内膨胀（oven spring）**——面团刚进炉的那段时间里，
气体受热膨胀、酵母在死亡前最后一次加速产气、水变成蒸汽，
共同把成品顶到最大体积的过程。
一项中试烤炉研究观察到：**蒸汽有利于膨胀，膨胀最大出现在面包芯温度接近 90 °C 时**。

<a id="steam-leavening"></a>
**蒸汽膨发（steam leavening）**——靠配方里的水在高温下变成蒸汽、
体积急剧增大来把成品顶起来。泡芙与千层酥主要靠它。
⚠️ 一篇起酥类综述明确指出：**蒸汽被困住并把层顶起来的确切机制目前仍不清楚**——
所以本书把它写成方向性机制，不给定量结论。

## 成品与判据

<a id="setting"></a>
**定型（setting）**——面团或面糊从"还能流动、还能变形"变成"形状固定下来"的那一刻。
它由淀粉糊化与蛋白质凝固共同决定。
**定型时间是烘焙里最被低估的变量**：定得早，成品高而不摊；定得晚，成品摊而扁。

<a id="cookie-spread"></a>
**摊开（cookie spread）**——饼干在烤箱里向外摊平的程度，通常用直径衡量。
研究显示饼干直径先线性增大、然后**突然定住**，所以最终直径 ≈ 摊开速率 × 定型时间。
这两个因子各自受配方影响——**这就是"改一项，饼干形状就变"的完整解释**。

<a id="doneness"></a>
**熟成判据（doneness criteria）**——判断"烤好了没有"的依据。
本书主张**用内部温度与状态判据，而不是只看时间**：
时间不可移植（你的烤箱、你的模具、你的份量都和作者不同），温度与现象可移植。
⚠️ 面包类成品的中心温度在烘烤后段会趋近水的沸点并停在那里——
模拟与实测研究都观察到面包芯温度不会越过 100 °C（约 98 °C 附近趋于稳定）。
