# 烘焙的原理：从看懂配方到自己改配方

> 一本写给**厨房小白**的原理书。它不给你配方，它让你**读懂**配方——
> 并且在读懂之后，能**自己改配方**：换糖量、换油脂、换粉、减糖、放大份量。
> 力求**正确**：数值标注出处、关键数字要两个独立来源，
> 烘焙圈流传的说法逐条标注证据强度，查不到出处的数字**宁可不写**。

## 这本书要解决的问题

配方只告诉你**放多少**，不告诉你**为什么是这个量**：

- 为什么这份饼干要放这么多糖？糖减一半会变成什么样？
- 黄油能不能换成植物油？换了之后口感为什么变了？
- 高筋面粉是不是做什么都更好？
- 泡打粉用完了，能不能用小苏打顶上？
- 为什么别人的配方在我家烤出来就是不对？

**这些问题的答案不在配方里。** 它们在一个更基本的事实里：

> **一份配方是几组竞争关系的配平。**
>
> 面粉、水、糖、油、蛋、盐、膨松剂在**争同一批资源**——
> **争水**、**争面筋**、**争温度窗口**、**争气**。
> 你改动任何一样，都是在改这组配平。
>
> **所以改配方的正确问法永远是同一句：「它会抢走谁的什么？」**

## 和《做菜的原理》什么关系

它们是**姊妹书，但不是同一本书的两半**，各自独立成站、内容不互相引用。
把两本书分开，恰恰是因为**炒菜和烘焙在最根本的一点上不同**：

| | 炒菜 | 烘焙 |
|---|------|------|
| 什么时候做决定 | **过程中随时**：尝一口，淡了加盐 | **全部在进炉之前** |
| 出错了能不能救 | 大多能：补味、加水、延长时间 | **进炉就定死了**，只能等下一炉 |
| 功夫下在哪 | 临场判断（火候、尝味、顺序） | **配方与操作的事先设计** |
| 主要工具 | 一道菜的处理方案表 | [配方解码表](forms/recipe-decode.md) + [烘焙记录表](forms/bake-log.md) |

所以《做菜的原理》教的是**边做边调**，这本书教的是**事先把账算清楚**。

> 两本书都会讲到美拉德反应、淀粉糊化、蛋白质变性这些机理。
> 按仓库约定，**本书在自己的章节里重新讲一遍**，并注明"另一本书里也讲过"，
> 不会让你在两本书之间跳来跳去。

## 怎么读这本书

- **正文**讲机理，配 Mermaid 图与对照表；关键数值都带出处
  （统一登记在[参考书目与出处登记](standards.md)），每章末有**「本章依据」**。
- **所有配方与比例都用[烘焙百分比](glossary.md#bakers-percentage)表达**，
  并写明以何物为 100%（通常是面粉总量）——这样不同来源的配方才能摆到同一把尺子上比较。
- **术语**首次出现处有脚注，中英对照汇总在[术语表](glossary.md)——
  烘焙资料大量是英文的，你得能对上。
- 每章有**「常见说法辨析」**栏目：把流传的说法逐条标注
  ✅ 有共识 / ⚠️ 有争议 / ❌ 明确错误 / 缺乏证据，并说明**它为什么流传**。
- 每章末有**思考题**（含【案例】题：给你一份配方或一次失败记录，让你自己推原因与改法），
  答案册给完整推理链。
- **本章实操**两档：
  - **🅐 零成本版**——不用烤箱，现在就能做（把三份配方换算成烘焙百分比对比、
    读一份商品面包的配料表反推工艺、给一份配方写"改糖 20% 会怎样"的预测）；
  - **🅑 开火版**——标注"有烤箱时做"，是**单一变量对照实验**
    （同一份饼干面团分两份，只改糖的用量）。
- 每章末有 **🔎「下次烤之前的用处」**：这一章能让你进炉前少犯哪个错。

## 关于正确性的四条纪律

烘焙圈的谣言密度极高（"必须揉出手套膜""戚风塌了一定是没倒扣"
"泡打粉和小苏打可以互换"），而且**你没法当场纠错**——一炉毁了就是毁了。
所以这本书的正确性靠纪律维持
（完整版见 [CLAUDE.md](https://github.com/H-Jett/LifeLearning/blob/main/books/baking/CLAUDE.md) §1）：

1. **数值必须有出处**，并说明波动范围。关键数字要求**两个独立来源**；
   只有一个来源时标注"仅见于 X"；**查不到就不写死数字**，改成写规律或标"经验值"。
   [出处登记](standards.md)里专设一节 **「已知缺口」**——
   列出本书查了但**没查到**的东西（例如家用烤箱温度偏差的公开测量数据）。
2. **区分事实 / 官方规定 / 行业惯例 / 烘焙传说**四层，证据不足的一律辨析并标证据强度。
3. **食品安全的数字必须引官方来源**（各国食品安全机构的公开指引），
   **并明确写出不同国家口径不同**——涉及生面粉、生面糊、生蛋、天然酵种与保存期限时尤其如此。
4. **不做医疗 / 营养治疗建议**——**无麸质只讲工艺与代价，不谈治疗**；
   减糖减油只讲它在配方里抢走了什么。

两条补充的硬规矩：

- **只复述，不抄原文**，也不搬运他人的图片与表格版式；要图用 Mermaid 自绘。
- **不写"这么做一定失败"这类绝对断言**——写"出现 X 时，先怀疑 Y，用 Z 来验证"。
