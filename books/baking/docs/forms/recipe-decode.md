# 配方解码表

> **这是全书的核心工具。** 它把"我该不该照这份配方做、能不能改"拆成五步：
>
> **各原料 → 烘焙百分比 → 它在这份配方里扮演什么角色 → 改动它会连带影响什么 → 我打算怎么改。**
>
> 用法：**看到任何一份配方时**，先花十分钟填这张表，再决定动不动手。
> 目标不是填得漂亮，而是让你在开烤箱之前就发现"我还没想清楚哪一项"。

## 0. 基准声明（最重要、也最容易漏的一格）

| 项 | 填写 |
|----|------|
| 这份配方的**面粉总量**是多少克？（有几种粉就加起来） | |
| 我用的百分比**基准**是什么？ | 本书默认：**面粉总量为 100%** |
| 如果用了别的基准（如面团总重），在这里写明 | |

> **为什么这一格必须先填**：[烘焙百分比](../glossary.md#bakers-percentage)离开基准就没有意义。
> "糖 50%"在面粉基准下和在总重基准下是完全不同的两份配方。
>
> **换算方法**：某原料的烘焙百分比 =（该原料克数 ÷ 面粉总克数）× 100%。
> 所以百分比加起来**通常远大于 100%**——这是正常的。

## 1. 原料 → 百分比 → 角色 → 牵连（主表）

一行一样原料。**角色**那一栏尽量写动词（"占住水""挡住面筋""产气""带入空气"），
不要只写名词。

| 原料 | 克数 | 烘焙百分比 | 它在**这份**配方里主要扮演什么角色 | 它在跟谁争？ | 如果把它改动 20%，最先变化的是什么 |
|------|------|-----------|--------------------------------|------------|----------------------------------|
| 面粉（写清品类） | | 100% | 例：提供面筋骨架 + 淀粉 | 争水 | 例：换低筋粉 → 结构更弱、更容易摊 |
| 水 / 牛奶 / 其他液体 | | | 例：让面粉水合、让淀粉能糊化 | 被面筋、淀粉、糖同时争 | |
| 糖 | | | 例：甜 + 保湿 + 上色 + **推迟定型** | 争水、妨碍面筋 | |
| 油脂（写清固态/液态） | | | 例：阻断面筋（短化）+ 带入空气 | 妨碍面筋、影响定型温度 | |
| 蛋 | | | 例：水分 + 乳化 + 结构 + 气泡 | 既给水又给结构 | |
| 盐 | | | 例：风味 + **控速** | 拖慢酵母、改变面筋形成 | |
| 膨松剂（酵母/小苏打/泡打粉） | | | 例：产气 | 需要"被留住" | |
| 其他（可可粉、果干、坚果…） | | | | | |

> **填完先回答一个问题**：这份配方里，**水被谁拿走得最多**？
> 这一个问题往往就决定了成品的质地（软 / 硬 / 酥 / 韧）。

## 2. 四组竞争关系的体检

把上表的信息归到四条竞争线上。**每一行都要能说出"谁赢了"**。

| 竞争 | 这份配方里的具体情况 | 谁占上风 | 我的判断依据 |
|------|-------------------|---------|------------|
| **争水**：面筋要水、淀粉要水、糖和盐占水 | 例：糖 50%、水 20% → 水很紧张 | | |
| **争面筋**：面粉给、油脂和糖挡、盐改变 | 例：油脂 40% → 面筋基本形不成 | | |
| **争温度窗口**：糖抬高糊化温度、油脂改变定型 | 例：低水高糖 → 定型很晚 | | |
| **争气**：气从哪来、被什么关住 | 例：只有泡打粉 + 打发的黄油 | | |

## 3. 这份配方靠什么"发"、靠什么"立住"

| 问题 | 我的答案 |
|------|---------|
| **气从哪来**？（酵母 / 化学膨松剂 / 打发的空气 / 蒸汽，可多选） | |
| **气被什么关住**？（面筋网络 / 蛋白泡沫 / 黏稠的面糊 / 层状结构） | |
| **结构最后靠谁定住**？（淀粉糊化 / 蛋白质凝固 / 脂肪凝固 / 以上都有） | |
| 这份配方**最怕**哪一步出错？为什么？ | |

> **一条经验判据**：**发不起来**先怀疑"产气"或"保气"；
> **发起来又塌了**几乎总是"定型"的问题——撑起来了，但没来得及定住。

## 4. 我打算改哪一项（改之前先预测）

**一次只改一项。** 先写预测，再去做，回来对照——这是本书希望你养成的核心习惯。

| 项 | 填写 |
|----|------|
| 我要改的是哪一样原料？从多少%改到多少%？ | 例：糖从 50% 降到 30% |
| **它抢走了谁的什么**？（改之后被松开的是谁） | 例：松开了水 → 面筋能形成得更充分 |
| 我预测成品会怎么变？（写**三个**具体方面：形状 / 质地 / 颜色） | 例：更不摊、更硬脆、颜色更浅 |
| 有没有需要**连带**改的？（例如减糖后要不要减一点液体或缩短时间） | |
| 我打算怎么**验证**？（做对照组？测中心温度？量直径？） | |

> **为什么要先写预测**：只有写下预测，你才能知道自己的模型哪里错了。
> 做完却没有预测，就只是又做了一次而已。

## 5. 结果回填（做完再回来）

| 项 | 填写 |
|----|------|
| 实际结果（形状 / 质地 / 颜色） | |
| 和预测**一致**的部分 | |
| 和预测**不一致**的部分 | |
| 我原来的模型错在哪？（这一格最值钱） | |
| 下一次改哪一项？ | |

> 详细的过程参数（室温、水温、面团状态、发酵时间、炉温、判据）
> 记在[烘焙记录与复盘表](bake-log.md)里，两张表配合用。

## 一份填好的示例（一份普通的黄油饼干）

**仅作示例**，数字是为了演示表格怎么填，不是推荐配方——
请用你手上那份配方的真实克数来算。

| 栏位 | 填写 |
|------|------|
| **0 基准** | 面粉总量 200 g ＝ 100%（本书默认基准） |
| **1 主表** | 面粉 100% / 黄油 50% / 糖 50% / 蛋 20% / 盐 1% / 泡打粉 1% |
| **1 角色** | 黄油：短化（挡住面筋）+ 打发时带入空气；糖：甜 + 占水 + 推迟定型 + 上色；蛋：唯一的液体来源 + 乳化；盐：风味；泡打粉：产气 |
| **2 争水** | 液体只有蛋（20%），糖却有 50% → **水极度紧张**，面筋几乎形不成 |
| **2 争面筋** | 黄油 50% + 糖 50% 同时在挡 → 成品必然偏酥、偏短 |
| **2 争温度窗口** | 低水 + 高糖 → 淀粉糊化被推得很晚，**定型晚 → 会摊开** |
| **2 争气** | 气来自打发黄油 + 泡打粉；靠黏稠的面团勉强留住 |
| **3 立住靠谁** | 主要靠冷却时**脂肪重新凝固**与糖的玻璃态，而不是淀粉糊化 |
| **4 我要改的** | 糖 50% → 30%。预测：更不摊（定型更早）、更硬而不是更酥（糖少了，水相对宽裕，面筋形成得多一点）、颜色更浅（可参与褐变的糖少了） |
| **5 回填** | 做完再写 |
