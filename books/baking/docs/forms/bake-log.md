# 烘焙记录与复盘表

> **配方解码表管"进炉前想清楚"，这张表管"这一次实际发生了什么"。**
>
> 烘焙的参数**不可移植**：同一份配方，换一台烤箱、换一个季节、换一批面粉，
> 结果就不一样。所以别人的时间只是参考，**你自己的记录才是依据**。
>
> 用法：做的当天边做边填（不用填满），出炉当天填完「结果」和「下次改哪一个变量」。

## 0. 这一次是什么

| 项 | 填写 |
|----|------|
| 日期 / 第几次做这款 | |
| 成品名称 | |
| 用的是哪份配方？（来源） | |
| **这一次我刻意改的那一个变量**是什么？ | 例：糖从 50% 降到 30%（其余不动） |
| 我的预测是什么？（抄自[配方解码表](recipe-decode.md)第 4 栏） | |

> **一次只改一个变量。** 如果这一栏填了两项以上，这次记录的价值就大打折扣。

## 1. 配方比例（用烘焙百分比记，面粉总量为 100%）

| 原料 | 克数 | 烘焙百分比 | 与上一次相比 |
|------|------|-----------|------------|
| 面粉（品类 / 牌子 / 批次） | | 100% | |
| 液体（水 / 奶 / 其他） | | | |
| 糖 | | | |
| 油脂（固态 / 液态 / 温度） | | | |
| 蛋 | | | |
| 盐 | | | |
| 膨松剂 | | | |
| 其他 | | | |

> 记下**面粉的牌子与批次**看起来很啰嗦，但它是"为什么这次不一样"的常见答案之一——
> 不同面粉能吃的水差别很大。

## 2. 环境与温度（最容易被忽略、又最容易记录）

| 项 | 数值 | 备注 |
|----|------|------|
| 室温 | °C | |
| 湿度（有仪器就记，没有就写"干 / 潮"） | | |
| 液体温度（水温 / 奶温） | °C | |
| 油脂温度或状态 | °C 或"冰硬 / 能压出指印 / 已软塌" | |
| **面团（面糊）搅拌结束时的温度** | °C | 有温度计就测；没有就写手感 |

> **为什么要测面团终温**：它是发酵速度、面筋状态、油脂状态的**汇总指标**——
> 一个数字能解释很多"同样操作结果却不同"的情况。
> ⚠️ 本书不给"面团必须打到多少 °C"这类数字，因为没有核到可靠的一手出处
> （见[出处登记](../standards.md)的「已知缺口」）；
> **但这不妨碍你把它测下来、作为你自己的基准。**

## 3. 面团 / 面糊状态（写现象，不写形容词）

| 阶段 | 我看到 / 摸到什么 | 用时 |
|------|-----------------|------|
| 混合完成（还有干粉吗） | | |
| 搅拌 / 揉面结束 | 例：能拉开一段再断 / 一拉就断 / 黏手程度 | |
| 静置或折叠（做了几次） | | |
| 整形前 | | |
| 入炉前（体积长大了多少倍？按下去会不会回弹） | | |

> **"写现象不写形容词"**：写"按下去凹陷慢慢回弹一半"，
> 而不是写"发好了"——后者三个月后你自己也看不懂。

## 5. 炉温与烘烤

| 项 | 填写 |
|----|------|
| 预热设定温度 / 预热多久 | °C / 分钟 |
| **烤箱实测温度**（有独立温度计就记） | °C（与设定值差多少？） |
| 上下火设置（能分别设的话） | 上火 °C / 下火 °C |
| 放在第几层？靠前还是靠后？ | |
| 用了蒸汽吗？怎么做的？ | |
| 模具 / 烤盘（材质、颜色、深浅） | |
| 中途转向了吗？第几分钟？ | |
| 设定时间 / 实际时间 | 分钟 / 分钟 |

> ⚠️ **你的烤箱几乎一定不准**，而且不同位置温度不同。
> 本书没有核到家用烤箱温度偏差的公开测量数据，所以不给"通常偏低多少"的数字——
> **请自己测**（第五部分的项目 P3 就是做这件事）。

## 6. 出炉判据（不要只看时间）

| 项 | 填写 |
|----|------|
| 我用什么判断"可以出炉了"？ | 例：中心温度 / 颜色 / 按压回弹 / 边缘状态 / 竹签 |
| **中心温度**（有探针温度计就测） | °C |
| 出炉时的外观描述 | |

> **为什么优先用中心温度与状态**：时间取决于你的烤箱、份量、模具，**不可移植**；
> 温度和现象可移植。
> ⚠️ 面包类成品的芯温在后段会趋近水的沸点并停住——模拟与实测研究都观察到
> 面包芯温度不会越过 100 °C（约 98 °C 附近趋于稳定），
> 所以**"芯温还在涨"本身就是个有用的信号**（详见[出处登记](../standards.md)）。

## 7. 出炉之后

| 项 | 填写 |
|----|------|
| 怎么冷却的（连模 / 脱模 / 倒扣 / 晾网） | |
| 冷却过程中有没有回缩、塌陷、出水？什么时候发生的？ | |
| 切开时的内部组织（气孔大小是否均匀、湿润还是干） | |
| 怎么保存的？（密封 / 敞着 / 冷藏 / 冷冻） | |
| 第二天、第三天分别变成什么样？ | |

> **老化那一栏值得记**：面包变硬**不等于"水跑光了"**——
> 密封保存的面包同样会变硬（主流解释是支链淀粉重结晶与水分再分配）。
> 记下"第二天什么样"能帮你判断：这是老化问题，还是一开始就没烤够。

## 8. 复盘（最值钱的一栏）

| 问题 | 我的答案 |
|------|---------|
| 结果和**预测**差在哪？（说具体：形状 / 质地 / 颜色 / 高度） | |
| 差的那一项，属于四组竞争的哪一组？（争水 / 争面筋 / 争温度窗口 / 争气） | |
| 我原来的模型错在哪？ | |
| 如果只允许改**一个**参数，改什么？为什么？ | |
| 下次最先做的那一个动作是什么？ | |

> **只改一个参数**这条约束很重要：一次改三样，你永远不知道是哪一样起了作用。

## 安全备忘（每次都适用）

| 项 | 说明 |
|----|------|
| **不要尝生面团、生面糊** | 美国 FDA 指出：关注的病原体是沙门氏菌与致病性大肠杆菌；"把生谷物加工成面粉并不会杀死有害细菌"；"烹熟是确保用面粉和生蛋做的食物安全的唯一方法" |
| 不要自己在家"热处理面粉" | 同一份 FDA 指引提醒：家用方法可能杀不干净 |
| 生面粉、生蛋与即食食品**分开存放** | 面粉是粉末，容易扬散 |
| 做完之后的清洁 | 手、盆、台面、工具都要洗；别把生面团给小孩当橡皮泥玩 |
| 涉及蛋液类成品的中心温度 | 美国 FDA 给蛋类菜品的是 160 °F（约 71 °C）；⚠️ **各国口径不同**，以自己所在地现行发布为准 |

> 来源与核对状态见[参考书目与出处登记](../standards.md)。
