# 🛠 项目 P1：把一份配方解码成烘焙百分比与角色表

> **这是第一部分的收尾项目，也是全书核心工具的第一次完整使用。**
>
> 前八章认了七个角色，第 9 章给了描述它们的语言。
> 这个项目要做的，是把两者合起来用一次——**在不开火的情况下，
> 你就能对一份没做过的配方说出"它想干什么、它的风险在哪、我改哪一项会发生什么"。**

**交付物**：一份填满的[配方解码表](../../forms/recipe-decode.md) + 下面四张表。
**做完你会拥有**：一份可以反复使用的、属于你自己的配方分析流程。

## P1.0 准备

| 需要 | 说明 |
|------|------|
| **三份配方** | 同一类成品（都是吐司、或都是曲奇、或都是马芬），来自三个不同来源 |
| **一台厨房秤** | 只有 🅑 才用得上；🅐 全程用计算器就够 |
| **计算器 / 手机** | — |
| **纸笔或表格软件** | 建议用表格，以后可以一直加行 |

> **选配方的两条建议**：
>
> 1. **同类**——不同类的配方没法比（比较曲奇和吐司的含水量没有意义）；
> 2. **至少有一份是你做过的**——它是你的"锚"，你知道它真实的样子。

## P1.1 第一步：换算（全部以面粉总量为 100%）

**基准声明**（这一格必须先填）：**本项目一律以配方中面粉总量为 100%**；
若某份配方用了别的基准，在备注里写明并**先换算过来**再填表。

> ⭐ **第一步永远是：把所有的粉加起来**——包括中种、汤种、酵种里的粉（第 9 章 §9.5）。

**交付表 ①：三份配方的百分比对照**

| 原料 | 配方 A（%） | 配方 B（%） | 配方 C（%） | 极差（最大−最小） |
|------|-----------|-----------|-----------|----------------|
| 面粉总量 | 100 | 100 | 100 | — |
| ├ 其中：粉 1（品类） | | | | |
| └ 其中：粉 2（品类） | | | | |
| 水 | | | | |
| 奶 / 其他液体 | | | | |
| 蛋（写明全蛋 / 蛋清 / 蛋黄） | | | | |
| 糖（写明种类） | | | | |
| 油脂（写明固态 / 液态） | | | | |
| 盐 | | | | |
| 膨松剂（写明种类） | | | | |
| 其他 | | | | |
| **合计** | | | | — |

**验算**：面粉克数 × 合计百分比 ÷ 100 = 这份配方的总重量。对不上就是漏项了。

> **"极差"这一栏是本表的重点**：它直接告诉你**这三份配方的分歧在哪**。
> 极差最大的两三项，就是你接下来要重点分析的对象。

## P1.2 第二步：角色诊断（用前八章的知识）

| 分歧项 | A / B / C 的值 | 它在配方里主要扮演什么角色 | 差别会造成什么（写**三个**具体方面） | 依据是哪一章 |
|--------|---------------|------------------------|--------------------------------|------------|
| 第 1 项 | | | | |
| 第 2 项 | | | | |
| 第 3 项 | | | | |

**可以直接拿来用的判据清单**：

| 看哪一项 | 问什么问题 | 出自 |
|---------|-----------|------|
| 面粉 | 它的**吸水量**是多少？（不是"蛋白质多少"——两者不是同义词） | 第 2 章 |
| 水 | 这份配方里，**水被谁拿走得最多**？ | 第 3 章 |
| 糖 | 它在**推迟定型**吗？成品会因此更摊、更晚定住吗？ | 第 4 章 |
| 油脂 | 它要**打气**吗？要**隔层**吗？它**带水**吗？ | 第 5 章 |
| 蛋 | 它主要在当**水 / 气 / 乳化 / 结构**中的哪一个？ | 第 6 章 |
| 盐 | 它在给谁**调速**？改它要连带改什么时间？ | 第 7 章 |
| 膨松剂 | **气从哪来？什么时候来？** | 第 8 章 |

## P1.3 第三步：风险定位

**交付表 ③：每份配方最可能在哪一步出问题**

| | 配方 A | 配方 B | 配方 C |
|---|-------|-------|-------|
| 气从哪来（可多选） | | | |
| 气被什么关住 | | | |
| 结构最后靠谁定住 | | | |
| **最怕哪一步出错** | | | |
| 出错时会表现成什么样 | | | |
| 这份配方对**新手**友好吗？为什么 | | | |

> **一条经验判据**（来自[配方解码表](../../forms/recipe-decode.md)）：
> **发不起来**先怀疑"产气"或"保气"；
> **发起来又塌了**几乎总是"定型"的问题——撑起来了，但没来得及定住。

## P1.4 第四步：改一项，先预测

**交付表 ④：改动推演（一次只改一项）**

选**一份**配方、**一项**原料来改。

| 项 | 填写 |
|----|------|
| 我选的配方 | |
| 我要改的原料，从 ____% 改到 ____% | |
| **它抢走了谁的什么**？改动之后被松开的是谁？ | |
| 预测 ①：**形状**会怎么变 | |
| 预测 ②：**质地**会怎么变 | |
| 预测 ③：**颜色**会怎么变 | |
| 需要**连带**改的是什么？ | |
| 我打算怎么**验证**？ | |
| 我对这个预测有多确定？（1~5 分） | |

> **为什么必须先写预测**：只有写下来，你才知道自己的模型哪里错了。
> **做完却没有预测，就只是又做了一次而已。**

## 🅐 零成本版（不用烤箱，现在就能做完）

**全部四张表都可以在不开火的情况下填完。** 做完这四张表，你已经完成了这个项目。

**再加两个只用眼睛和计算器的任务**：

### 🅐 任务一：读三份商品的配料表，反推它的"百分比顺序"

配料表按含量从高到低排列，**这本身就是一份粗糙的百分比表**。

| 观察 | 商品 A | 商品 B | 商品 C |
|------|-------|-------|-------|
| 品类 | | | |
| 配料表前三位是什么 | | | |
| **糖排在面粉前面吗** | | | |
| **油脂排在第几位** | | | |
| 用的是什么膨松剂 | | | |
| 有没有乳化剂、稳定剂 | | | |
| **推断：这是一份高糖高油配方，还是偏瘦的配方** | | | |
| 和你表 ① 里的哪一份最接近 | | | |

### 🅐 任务二：给你的"锚配方"写一份说明书

挑你做过最多次的那一份，写成别人能看懂的解码说明：

| 项 | 填写 |
|----|------|
| 配方（百分比，**以面粉总量为 100%**） | |
| 一句话说明它想做成什么 | |
| 它的气从哪来 | |
| 它靠什么定住 | |
| **做这份配方最容易翻车的一步**，以及怎么看出来 | |
| 如果只能改一项让它更符合我的口味，我会改哪一项 | |

> **这张表就是你自己的配方手册的第一页**（第七部分的项目 P5 会把它做完整）。

## 🅑 开火版（有烤箱时做）

在 🅐 的基础上，把**交付表 ④ 的预测真正做一次**。

### 🅑 任务三：预测 → 验证

**唯一变量**：表 ④ 里你选的那一项。其余原料克数、搅拌方式与时间、
每份重量与厚度、炉温、时间**全部一致**，两组**同时进炉**（做好标记）。

| | 对照组（原配方） | 试验组（改了一项） |
|---|---------------|-----------------|
| 改的是什么、改了多少 | — | |
| 面团 / 面糊的手感差别 | | |
| 出炉直径 / 高度 | mm | mm |
| 厚度 | mm | mm |
| 颜色（浅 / 中 / 深） | | |
| 内部组织（细密 / 中 / 粗） | | |
| 口感 | | |
| 第二天的软硬 | | |

**最重要的一张表是这个**：

| 项 | 填写 |
|----|------|
| 和预测**一致**的部分 | |
| 和预测**不一致**的部分 | |
| **我原来的模型错在哪**（这一格最值钱） | |
| 这次实验的**局限**（至少两条） | |
| 下一次我要改哪一项 | |

> ⚠️ **关于"局限"这一栏**：家庭条件下的对照实验样本量小、没有重复、
> 口感靠主观判断、家用烤箱温度几乎一定不准（第 29 章）。
> **它给你的是"在我这儿会怎样"，不是一条通用规律**——
> 但这恰恰是你最需要的那种知识。

### 🅑 任务四（加分）：把过程参数也记下来

用[烘焙记录与复盘表](../../forms/bake-log.md)记录这一次的室温、水温、
面团状态、发酵时间、炉温与出炉判据。

> **两张表的分工**：
> [配方解码表](../../forms/recipe-decode.md)记**配方**（可移植），
> [烘焙记录与复盘表](../../forms/bake-log.md)记**参数**（不可移植，只属于你家）。
> **第一部分讲的是前者，第四、五部分讲的是后者。**
>
> ⚠️ **安全提醒**：**不要尝生面团、生面糊**
> （美国 FDA：生面粉不是即食食品；含蛋的生面糊还有生蛋风险）；
> 生面粉与生蛋要和即食食物分开存放。
> 各国口径可能不同，以自己所在地现行发布为准。
