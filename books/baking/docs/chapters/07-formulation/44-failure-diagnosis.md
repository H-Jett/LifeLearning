# 第 44 章 失败诊断手册：现象 → 可能原因 → 下次改哪个变量

诊断不是给失败贴一个原因标签，而是把观察拆回过程：产气、保气、定型、传热与冷却。一个现象可由多条路径造成；下一炉的目标是排除一条路径，而不是同时“修好一切”。

## 44.1 先记录时点，再找机制

```mermaid
flowchart LR
    A[入炉前] --> B[炉内膨胀]
    B --> C[出炉]
    C --> D[冷却后]
    D --> E[切面 / 隔日]
    E --> F[选一个变量验证]
```

| 先记录什么 | 它帮助区分什么 |
|------------|----------------|
| 入炉前高度、状态、面糊流动性 | 产气 / 保气是否在进炉前已失配 |
| 炉内涨幅、表皮与割口 | 热路径、表皮约束和定型窗口 |
| 出炉与冷却后高度 | 炉内膨胀和冷却支撑不能混为一谈 |
| 切面、边缘、中心与隔日状态 | 局部传热、结构和回生 / 水分问题 |

## 44.2 现象查表

| 现象 | 先怀疑的机制 | 还需排查 | 下一次只验证 |
|------|--------------|----------|----------------|
| 涨不高 / 不发 | 产气不足或过早失气 | 酵母 / 膨松路径、温度、盐糖、面团状态 | 固定配方，记录发酵 / 醒发与入炉前高度 |
| 涨高后回缩 | 定型或冷却支撑不足 | 产气过量、配方结构、中心状态 | 记录入炉、出炉、冷却后三个高度 |
| 大洞、组织不均 | 气室合并或整形 / 混合失配 | 发酵进程、保气网络 | 只改一个整形或混合变量 |
| 表皮过深、中心偏湿 | 热进入表面过快或中心不足 | 炉温、炉位、模具、装填深度 | 固定配方，只检查炉温 / 炉位之一 |
| 干硬 | 可用水不足、烘烤失水或储存变化 | 糖油、总烘烤、回生 | 先区分刚出炉干硬还是隔日变硬 |
| 表皮裂得无序 | 表皮过早定型或膨胀方向失配 | 蒸汽、割口、整形与炉内涨幅 | 只改蒸汽维持方式或割口之一 |

这些是排查起点，不是从现象直接推出原因。比如冷却回缩，可能是炉内未及时定型，也可能是配方或冷却支撑；“没倒扣”只覆盖少数情形，不能作为万能答案。

## 44.3 三个容易误诊的组合

### 表面正常、中心湿黏

颜色只报告表面失水和褐变。先固定模具、装填与配方，检查实际热路径和中心状态；不要仅延长时间而不观察表皮是否已过深。

### 出炉高、冷却后明显回缩

将高度分成入炉、出炉、冷却后三次记录。若主要在冷却后失去高度，优先复核结构是否能承住；若炉内就没有足够涨幅，则从产气 / 保气继续排查。

### 第二天变硬

“变硬”不等于“水都跑了”。面包老化还涉及淀粉回生与水分再分配；先区分刚出炉干硬、保存中失水与隔日回生，才知道该看烘烤还是储存。

## 44.4 常见说法辨析

| 说法 | 判定 | 说明 |
|------|------|------|
| “塌陷一定是没倒扣” | ❌ | 产气、保气、定型和冷却都可能参与。 |
| “颜色够了就是熟了” | ❌ | 表皮与中心处在不同热环境，应结合中心状态。 |
| “一次多改几项，成功率更高” | ❌ | 同时改变会切断因果判断。 |
| “失败就说明配方不好” | ⚠️ | 原料、设备、操作和目标都可能不同；先建立记录。 |

## 44.7 🔎 下次烤之前的用处

失败后先写“何时发生”，再写“我只验证哪一条路径”。这比把所有补救动作同时塞进下一炉，更快累积真正可复用的经验。
