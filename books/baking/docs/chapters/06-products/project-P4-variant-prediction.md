# 🛠 项目 P4：变体推演——同一份配方改三处，先预测再验证

> **这是第六部分的验收。**
> 目标不是做出“最佳版本”，而是把改配方从一次性试错变成可复盘的小实验：每次先说清预测，实际做完再解释差异。

## P4.1 交付物：三行因果记录

选择你熟悉的一份烘焙配方。先把它换算为烘焙百分比（以面粉总量为 100%），写下原版作为基线；然后做三次变体，每次只动一项。

```mermaid
flowchart LR
    A[基线配方：百分比 + 状态] --> B[选一个变量]
    B --> C[写下预测与代价]
    C --> D[执行并记录]
    D --> E[比较实际与预测]
    E --> F[下一次只验证一个新问题]
```

| 交付物 | 必须包含 | 它防止什么 |
|--------|----------|------------|
| 基线卡 | 原料百分比、方法、成品状态 | 忘记自己从哪里出发 |
| 三行变体表 | 每次唯一变量、预测、实际 | 一次改三处仍强行归因 |
| 差异解释 | 哪条机制支持、哪些因素仍未知 | 把一次结果写成定律 |

## P4.2 先选目标，再选旋钮

目标可以是“更软”“更脆”“更开放的组织”或“更不甜”，但要翻译成可观察的状态。不同成品允许使用的旋钮不同：饼干、蛋糕、吐司和欧包不应硬套同一张答案表。

| 目标 | 可考虑的单一变量 | 同时预测的代价 | 观察量 |
|------|------------------|----------------|--------|
| 改变柔软 / 保湿感 | 水、糖或油脂中的一项 | 结构、上色、储存变化 | 切面、口感、隔日状态 |
| 改变摊开 / 层次 | 脂肪状态或操作中的一项 | 面筋、形状、烘烤路径 | 尺寸、边缘、断面 |
| 改变发酵表现 | 温度、时间或酵种投料中的一项 | 风味、失气、炉内涨幅 | 入炉前状态、出炉高度、气味 |
| 改变表皮 | 蒸汽方式或烤箱条件中的一项 | 颜色、脆度、体积 | 割口、外壳、炉内涨幅 |

不要为了“改三处”而在同一次烘焙里改三处。项目的“三处”是三轮单变量比较。

## P4.3 🅐 零成本版：纸上完成三轮预测

无需开炉。选一份已有成品照片或可靠记录的配方，先填基线，再为三个候选改动各写一行预测。没有实际结果时，将最后一列写成“待验证”，不能伪装成结论。

| 轮次 | 原版基线 | 唯一改动 | 我预测的主变化 | 我预测的代价 | 如何验证 |
|------|----------|----------|----------------|--------------|----------|
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

检查每一行：改动是否能用烘焙百分比或明确的操作条件描述？是否写了代价？是否没有悄悄把两个变量绑在一起？

## P4.4 🅑 开火版：三次最小变体

最好每次和基线比较；如果材料有限，至少保留完整的基线记录，并保证三轮使用相同器具、炉位和出炉判据。不要同时更换面粉、炉温、整形、发酵和水量。

| 轮次 | 唯一变量（写清基准） | 其余保持不变 | 预测 | 实际观察 | 预测与实际差在哪 | 下次只验证什么 |
|------|------------------------|--------------|------|----------|----------------|----------------|
| 基线 | 无 | | | | | |
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |

涉及比例时写明“以面粉总量为 100%”。涉及时间、温度、蒸汽或整形时，写下你实际使用的条件；它们是本次实验的上下文，不应被外推成所有厨房的参数。

## P4.5 复盘：实际没有按预测走时怎么办

“预测错了”正是项目最有价值的结果。按下面顺序复盘：

1. 变量真的只有一个吗？先排除秤量、面粉批次、炉温、分份大小等同时变化；
2. 观察是否和目标对应？例如只看颜色，不能推出组织为何改变；
3. 机制有没有竞争关系？增水、糖、油脂、发酵和热常同时牵动多个结果；
4. 下一轮只补验证一个最不确定的环节。

| 现象 | 先不要下的结论 | 更好的下一步 |
|------|----------------|--------------|
| 没看到预期变化 | “这个变量没用” | 检查改变量是否足够可辨、其余条件是否一致 |
| 多项结果一起变化 | “一定只由我改的那项造成” | 查是否连带改变了操作或烘烤路径 |
| 一次成功 | “这就是通用最佳配方” | 在相同条件下复做，或只改一个相邻变量 |

## P4.6 🔎 下次烤之前的用处

下一次想“顺手改一点”时，先写一句：我改的是____；我预计它会抢走 / 让出____；我会用____来判断。这样一炉即使不完美，也会留下能用于下一炉的信息。

## P4.7 本项目依据

本项目复用全书的竞争关系框架与第 26 章的称量纪律、第 27 章的配方外变量、第 29～33 章的烤箱 / 出炉记录，以及第 34～40 章的成品推演。它不提供“通用改动幅度”：不同配方、原料、设备和目标的结果不能由一次记录外推。出处与限制见[参考书目与出处登记](../../standards.md)。

---

**第六部分到此结束。**

你现在不必把变体当赌注：先做预测，再做一次干净的比较；结果无论符合与否，都会让下一次判断更具体。
