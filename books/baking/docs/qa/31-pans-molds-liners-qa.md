# 第 31 章 思考题参考答案

<a id="q1"></a>
## Q1

更深的模具同时改变面糊厚度、中心到表面的距离与边缘 / 中心受热差。时间并不随深度线性变化；应以中心与边缘的状态判据重新验证。

<a id="q2"></a>
## Q2

同一批面团分成两份，保持份量、形状、烤盘、炉位与烘烤过程尽量一致，只让一组用硅胶垫、另一组用另一种既定接触面。记录底部颜色、扩散、边缘与中心，而不是一次同时换盘、换温度和换配方。

<a id="q3"></a>
## Q3

导热快只说明热在材料中传开的能力方向。实际成品还受厚度、蓄热、预热、颜色、涂层、形状、炉位与配方影响；“好”也取决于想要的底部、边缘和中心状态。
