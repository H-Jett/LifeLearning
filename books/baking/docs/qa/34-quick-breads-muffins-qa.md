# 第 34 章 思考题参考答案

<a id="q1"></a>
## Q1

化学膨发的反应在加水与受热阶段展开，已有气泡和反应窗口不能无限等待。干湿合并后拖得越久，产气、气泡流失和结构定型越可能脱节；因此应在均匀合并后尽快入炉。

<a id="q2"></a>
## Q2

液体增加会改变粉和淀粉可获得的水、面糊流动性以及定型时机，不只是把“稠”调成“稀”。应先确认原配方的目标与称量，再设计一次只改液体的对照。

<a id="q3"></a>
## Q3

面粉、含水、糖油蛋、膨松剂、工具和搅拌方式都会改变体系。本书没有核到可把“搅 N 下”推广到所有马芬的证据；更可靠的是记录状态，并做单变量比较。
