# 第 40 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：水会影响延展，但开放气孔还依赖网络能否保气、发酵到什么状态、整形怎样重排气室，以及表皮何时定型。水合研究也提示，水更多的收益可与网络断裂等代价同时出现；因此应把水作为一个变量记录，而不是把它当成大孔的充分条件。

<a id="q2"></a>
## Q2

**答**：时间只记录过程经过了多久，不记录面团在这段时间里实际产气、失气、酸化和保气的结果。温度、面粉与接种源都会改变这个过程；酵种共同园实验中，不同接种源的涨发速率和最大高度已有差异。应结合高度、张力、气味与环境记录判断本次状态。

<a id="q3"></a>
## Q3

**答**：蒸汽在表面凝结，推迟表皮变干和定型，让内部已有的气体有较长的膨胀窗口。它没有替内部新增稳定气室，也不能重新建立已经被破坏的网络；所以内部保气失败时，蒸汽不能作为补救的替代品。
