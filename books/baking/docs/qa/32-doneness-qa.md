# 第 32 章 思考题参考答案

<a id="q1"></a>
## Q1

颜色主要反映表面失水和褐变；中心仍是高含水区域，受热路径、厚度与模具影响不同。因此表面金黄与中心定型是两条需要分别验证的线。

<a id="q2"></a>
## Q2

继续烤可能让表面进一步过深，却不必然解决中心问题。应同时检查炉温是否已标定、模具深度和装填量是否改变、炉位及热路径是否造成表面先受热；下次只改一个主要变量。

<a id="q3"></a>
## Q3

模具壁和烤盘本身可通过传导让探针读数偏高，气孔则可能偏低或不稳定。中心熟度需要测最厚、最后受热的食物区域，并将读数与该产品的结构状态和安全指引一起判断。
