# 系统品酒：从葡萄酒到烈酒

> 一本"边学边记"的品酒入门书：**物质基础 + 品种与风土 + 酿造工艺 + 产区法规 + 系统品鉴 + 烈酒**。
> 力求**正确**：所有数值标注出处，流传的说法逐条标注证据强度，
> 拿不准的地方明确写"有争议"而不含糊过去。

> **前置声明**：本书面向**法定饮酒年龄以上**的读者。**适度饮酒，未成年人不饮酒，酒后不驾车。**
> 本书**不做医疗与健康建议**——酒与健康只讲研究现状与证据等级（第 44 章）；
> 也**不做投资建议、不做真伪鉴定结论**。

## 这本书的核心观点

> **一杯酒给你的所有感受，都来自可以命名、可以测量、可以拆开比较的东西。**

- **品种与风土**决定了原料里有什么（能有多少糖、多少酸、多少酚类）；
- **酿造与陈年**在定向改造这些成分（每道工序都在调某一个结构要素）；
- **品鉴**是从感受反向读出成分格局；
- **法规与酒标**是这套信息里**唯一受法律约束**的部分——所以最值得先学。

所以这本书不从"记酒名"开始，而是**先建立机理，再挂名字**。

## 给谁看

- 想从"能喝"走到"会品"，但受不了"用心感受"这类说法的人；
- 买酒时想知道**钱花在哪**、哪些溢价可以绕开的人；
- 已经在备考某个酒类认证，想把**原理**补齐的人
  （本书**不是**任何认证的备考教材，也不复制任何商业认证的版权体系，
  但知识框架可以互相印证）；
- 对葡萄酒之外的**烈酒**也想有一套统一理解方式的人。

**不需要**任何前置知识，也**不需要**先买一柜子酒——本书每章的 🅐 实操都**不需要开瓶喝酒**。

## 怎么读这本书

- **正文**讲机理，配流程图与对照表；关键数值都带出处（见[出处与资料登记](standards.md)）。
- **术语**首次出现处有脚注，全称、原文与解释汇总在[术语表](glossary.md)——
  酒标多是外文，所以每个术语都给"中文 + 原文 + 英文"。
- 每章有**「常见说法辨析」**栏目：把酒圈流传的说法逐条标注
  ✅ 有共识 / ⚠️ 有争议 / ❌ 明确错误 / 缺乏证据。
- 每章末有**思考题**（指向答案册，可跳转），以及**本章实操**，分两档：
  - **🅐 无器具版**——不用买酒、不用开瓶，现在就能做（读酒标、查法规、算糖酒转化、比对酒评）；
  - **🅑 有条件版**——需要具体酒款与器具，标注"备齐后再做"，列清清单。
- 每章末还有 **🔎「买酒与点酒时的用处」**——把原理压成几个可执行动作。
- **实战项目 P1~P5** 挂在部分末尾，把一整部分的知识串起来用一次。

## 体例说明（读之前值得知道的三件事）

**① 数字的写法。** 本书区分三种数字，写法不同：

| 类型 | 写法 | 例子 |
|------|------|------|
| **法规限值** | 引编号（不带年份，避免版本漂移），登记进 standards.md | "EU 对葡萄酒的最低实际酒精度有明确规定，见 §…" |
| **测量范围** | 给区间 + 来源 + 波动原因 | "干型葡萄酒的甘油通常在 x~y g/L，随品种与年份变化" |
| **经验值** | 明写"经验值"，说明不同资料有差异 | "侍酒温度的常见建议区间（经验值）" |

**只有一个来源的数字会明写"仅见于 X"；查不到可靠来源的，本书写规律而不写数字**——
看到本书没给具体数，那通常是刻意的。

**② 证据强度的四档。** 辨析表里的标记含义固定：

| 标记 | 含义 |
|------|------|
| ✅ 有共识 | 机理清楚且多来源一致 |
| ⚠️ 有争议 | 有研究支持也有反对，或适用条件受限 |
| ❌ 明确错误 | 与可验证的事实矛盾 |
| 缺乏证据 | 说法本身没错也没被证实，目前没有可引用的证据 |

**③ 版权与图片。** 本书**不搬运他人实拍图与酒标图**（酒标含商标），
要看图就在正文里给权威链接；示意图一律用 Mermaid 自绘。
品鉴表**结构自拟**，不复制任何商业认证体系的版权条目与版式。

## 关于正确性的四条纪律

这本书没有 GPU 可以跑数据来自证，所以正确性靠纪律维持：

1. **数值必须有出处**，关键数字要**两个独立来源**；只有一个来源就写"仅见于 X"；
   查不到就**写规律或标"经验值"并说明波动范围**，绝不编造精确数字。
2. **区分事实 / 法规规定 / 行业惯例 / 酒圈传说**四层，证据不足的一律标证据强度。
3. **法规默认已过期，一律现查**。酒类法规改得很勤（脱醇酒类别、烈酒定义、
   中国白酒的定义都改过），本书正文引编号不引年份，版本状态与核对时间记在
   [出处与资料登记](standards.md)。
4. **数字只当示例，讲的是规律**：要带走的是"为什么"，不是背表格。
