# 第 31 章 缺陷与污染：TCA、Brett、氧化、还原、挥发酸

缺陷诊断的第一原则是：一个气味词不是原因证明。相同或相近的感受可能来自样品状态、杯具残留、开瓶时间、温度、个人阈值或不同化合物。家庭品鉴应记录线索、复测条件并保留“不确定”，而非隔着一杯酒给出生产环节的断言。

> **适度饮酒，未成年人不饮酒，酒后不驾车。** 发现异常时不需要为了诊断而继续饮用。

## 31.1 从感受到假设，而不是从感受跳到判决

~~~mermaid
flowchart TD
 A[记录异常感受] --> B[检查杯具、温度、开瓶时间]
 B --> C[换杯/复闻/与同伴比较]
 C --> D{现象是否稳定？}
 D -->|否| E[记录为条件性或不确定]
 D -->|是| F[提出候选机制]
 F --> G[不把候选机制当作隔屏鉴定]
~~~

| 常被讨论的类别 | 记录时可观察什么 | 不应直接断言 |
|----------------|------------------|----------------|
| TCA / 软木污染 | 闷、霉、湿纸板类异常与果香被压低 | 仅凭“有软木塞”就确定 TCA |
| Brett 相关气味 | 动物、药品、皮革等联想及其强度 | 所有皮革味都来自 Brett，或必然是缺陷 |
| 氧化 | 新鲜果香下降、坚果/氧化样变化、颜色变化 | 只凭颜色就断定氧化 |
| 还原性气味 | 硫样、火柴/橡胶类联想及醒杯后的变化 | 闻到一次就判断整瓶不可饮用 |
| 挥发酸 | 醋样或指甲油样刺激与整体协调性 | 任何酸味都是挥发酸 |

## 31.2 “风格”与“缺陷”需要额外证据

某些香气在低强度、特定产区传统或特定酒款中可能被接受；强度、样品状态与语境决定其是否破坏整体。对消费者而言，最有用的结论通常是“我在这个样品中感到异常，值得换杯、复测或向商家反馈”，而不是“我已准确定位微生物/封闭件故障”。

## 31.3 常见说法辨析

| 说法 | 判定 | 说明 |
|------|------|------|
| “软木塞酒一定有 TCA” | ❌ 明确错误 | 封闭件类型不是单杯污染的证据。 |
| “所有皮革/动物气味都是 Brett 缺陷” | ❌ 明确错误 | 感官词与原因并非一一对应，且接受度依语境而变。 |
| “颜色偏褐就能确诊氧化” | ❌ 明确错误 | 颜色受品种、陈年、酒型与光照等多因素影响。 |
| “闻到异常必须把酒喝完确认” | ❌ 明确错误 | 不需为了诊断而继续饮用；可换杯、停止或寻求专业帮助。 |

## 31.4 🔎 买酒与点酒时的用处

遇到疑似异常，先保留瓶、酒标、开瓶时间与样品状态，换干净杯复闻并请同伴比较。若异常稳定且影响饮用体验，向商家描述可观察症状，不需要用术语赌对原因。

## 31.6 本章实操

### 🅐 无器具版

将一条“这酒坏了”的酒评改写为三栏：观察到的感受、已排除的条件、仍待确认的候选原因。删除无法从样品直接观察到的生产过程断言。

### 🅑 有条件版

备齐后再做：对疑似异常样品先换清洁杯、记录时间与温度，再由同伴独立闻样。只比较描述一致性，不自行添加化学试剂或进行任何处理。**适度饮酒，未成年人不饮酒，酒后不驾车。**
