# 第五部分导读 · 系统品鉴与缺陷识别

这一部分的目标不是替读者决定“好喝”，而是把观察、描述、偏好与缺陷判断拆开，使同一杯酒可以在不同时间、不同人之间被更诚实地比较。流程是自拟记录工具，不复制商业认证的版权表格。
