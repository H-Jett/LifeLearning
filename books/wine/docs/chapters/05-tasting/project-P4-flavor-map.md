# 🛠 项目 P4：建立个人风味坐标

本项目的交付物不是“最爱的酒清单”，而是一张能解释自己偏好、稳定性与盲法表现的个人记录地图。它可以帮助选酒，但不能代表他人的偏好或某个产区的客观排名。

> **适度饮酒，未成年人不饮酒，酒后不驾车。** 可分多次、小样本完成；不为项目增加饮酒量。

## P4.1 交付物

~~~mermaid
flowchart LR
 A[每次独立记录] --> B[拆描述/偏好/诊断]
 B --> C[选择 3-5 条结构轴]
 C --> D[定期盲法复测]
 D --> E[更新偏好边界]
~~~

至少保留六条记录，并包含：

| 字段 | 目的 |
|------|------|
| 日期、样品编码、条件 | 让记录可复查 |
| 结构轴：酸度、单宁、酒精感、酒体、甜度 | 不用香气词堆砌偏好 |
| 描述与偏好分栏 | 避免“不喜欢=缺陷” |
| 信心与疲劳状态 | 识别不稳定判断 |
| 是否盲法 | 标记期待控制强度 |
| 下次验证问题 | 让地图可以更新 |

## P4.2 🅐 无器具版

不需要开瓶：从过往酒评、餐厅记录或第 28 章练习中整理六条记录。把“喜欢/不喜欢”翻译为结构假设，例如“我偏好中高酸、低到中单宁、酒精感不突出的样品”；每条都注明证据数量与反例。

## P4.3 🅑 有条件版

备齐后再做：在两次以上场合对部分样品盲编码复测。每轮只比较一个问题（例如酸度偏好），并使用[品鉴记录表](../../forms/tasting-note.md)。揭晓后记录偏好是否稳定，而不是强迫自己得出“正确答案”。**适度饮酒，未成年人不饮酒，酒后不驾车。**

## P4.5 自检

- [ ] 每条结论可回到原始记录；
- [ ] 描述、偏好与诊断没有混写；
- [ ] 至少一次记录使用盲码或明确说明未盲；
- [ ] 写出反例或未知，而非制造固定人设；
- [ ] 未把个人地图当购买评级或医学建议。
