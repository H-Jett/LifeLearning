# 🛠 项目 P3：做一个产区的深度档案

本项目不要求你背完产区地图，而是交付一张能复查、能更新的“产区档案卡”。目标是把一个名称拆成法律边界、原料/工艺规则、事实来源与自己的风格假设；任何没有证据的栏位都允许留空。

> **适度饮酒，未成年人不饮酒，酒后不驾车。** 🅐 不需要开瓶，🅑 仅在条件具备时进行。

## P3.1 交付标准

~~~mermaid
flowchart LR
 A[选择一个具体 PDO/PGI/AOC/AVA] --> B[查官方规范]
 B --> C[填事实字段并附链接]
 C --> D[写可证伪的风格假设]
 D --> E[用酒标或盲测记录验证]
 E --> F[标出已证实、未证实与未知]
~~~

合格交付物包含：

1. 一个明确、可查询的产区名称，而不是“法国”“新世界”这类大词；
2. 至少一条官方或法规来源链接，并写明核对日期；
3. 把“规范事实”“气候/地理线索”“生产者选择”“个人品鉴”分栏；
4. 至少一条你愿意被样品推翻的风格假设；
5. 不把价格、历史名气或等级词当感官结论。

## P3.2 档案卡模板

| 项目 | 填写内容 | 证据/不确定性 |
|------|----------|----------------|
| 产区全名与法律类别 |  | 官方规范或注册页 |
| 地理边界 |  | 只写已核字段 |
| 允许品种/来源比例 |  | 规则版本与日期 |
| 关键工艺或陈年术语 |  | 术语适用范围 |
| 年份与生产者 |  | 具体酒款信息 |
| 风格假设 |  | 用“可能”表述，列出反例条件 |
| 实际记录 |  | 盲法与否、样品、日期 |
| 修订结论 |  | 哪些被证实、哪些仍未知 |

## P3.3 🅐 无器具版：只做资料核验

选择一张可见正背标的酒，先完成档案卡的前五行。来源优先顺序：产品规范/监管机构 > 产区管理机构 > 生产者技术资料。营销页只能作为“市场上这样说”的材料，不能替代规范。

完成后写三句话：

- 标签已经保证了什么；
- 标签没有保证什么；
- 为了验证你的风格假设，下一步需要什么样的对照。

## P3.4 🅑 有条件版：用记录修正假设

备齐后再做：选择两款同一产区或同一品种的合法来源样品，由同伴随机编码。先以[品鉴记录表](../../forms/tasting-note.md)独立记录，再揭示信息并更新档案卡。一次品鉴只能支持“这两份样品在此条件下不同/相近”，不能推出整个产区的普遍结论。

**适度饮酒，未成年人不饮酒，酒后不驾车。**

## P3.5 自检清单

- [ ] 产区名称与法定类别没有混写；
- [ ] 所有法规性结论都有可访问来源；
- [ ] 将事实、推测和偏好分栏；
- [ ] 没有用“更高级/更贵”替代感官描述；
- [ ] 实测记录写明是否盲法、是否有对照；
- [ ] 未核到的内容明确标作未知。
