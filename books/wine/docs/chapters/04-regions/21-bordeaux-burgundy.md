# 第 21 章 法国 ①：波尔多与勃艮第——酒庄分级与地块分级

波尔多和勃艮第都不是一个能由单一“等级表”解释的名字。两地都先受 AOC 的地理与生产规则约束；其后才叠加不同历史形成的质量信号。读酒标时，最重要的问题不是“谁更高级”，而是：这个词在说**酒庄、地块、产区还是生产者**？

> **适度饮酒，未成年人不饮酒，酒后不驾车。** 本章 🅐 实操不需要开瓶。

## 21.1 同为 AOC，分级对象不同

~~~mermaid
flowchart TD
 A[法国 AOC] --> B[法定原产地与生产规范]
 B --> C[波尔多：常见信号以酒庄/城堡为单位]
 B --> D[勃艮第：常见信号以地块与 AOC 层级为单位]
 C --> E[还须看具体子产区、年份、生产者与酒款]
 D --> F[还须看具体 Climat、村庄、生产者与年份]
~~~

**波尔多**常以混酿与酒庄名组织市场信息。1855 年分级是历史上重要的酒庄等级体系，但它并不覆盖所有波尔多 AOC、所有酒庄或所有酒款；把“1855 列级”误读成“全波尔多唯一官方等级”，会漏掉右岸、甜酒、其他分级与大量未列级酒庄。AOC 名称本身仍是另一层法律信息：它说明的是受原产地规范约束的产品，而不是给每一瓶的感官品质打分。[^bordeaux]

**勃艮第**更适合从地名往下读：区域级、村庄级、一级园与特级园是常见 AOC 层级；在其内部，*Climat* 是有边界、名称和历史生产传统的葡萄园地块概念。一个酒庄可持有多个地块的葡萄，反过来同一地块也可能由多个生产者酿装；所以勃艮第酒标上，地块层级与生产者名通常都不可省略。[^bourgogne]

| 先读什么 | 波尔多的典型问题 | 勃艮第的典型问题 |
|----------|------------------|------------------|
| 法定产地 | 是哪个 AOC/子产区？ | 是区域、村庄、一级园还是特级园 AOC？ |
| 分级信号 | 这是否只是某一历史/局部分级？对象是酒庄还是酒款？ | 标签的地名是 Climat、村庄，还是生产者/酒商名称？ |
| 实际生产者 | 谁酿造、装瓶，是否为同一酒庄体系？ | 谁拥有或采购葡萄，是否为 domaine / négociant？ |
| 当年条件 | 年份是否改变成熟度、产量或风格？ | 同一 Climat 在不同年份和生产者下如何变化？ |

## 21.2 “Château”与“Climat”都不是品质保证书

在波尔多，*Château* 常被用作酒庄/品牌名称；它不能仅凭词面证明有城堡、等级或固定品质。在勃艮第，*Climat* 不是天气，而是被明确划定并命名的葡萄园地块；它也不自动等于特级园，更不替代 AOC、年份和生产者信息。Bourgogne 官方资料将 Climats 与 lieux-dits 区分讨论，并把 AOC 层级与地块信息并列呈现。[^climat]

这两种系统的共同点是：法律产地规则、历史声誉与市场价格可以重叠，却不是同一件事。价格还会受到稀缺性、品牌、渠道、年份供给和收藏需求影响；不能从一个等级词倒推出“必然更好喝”或“必然更值得买”。

## 21.3 一张酒标的读取顺序

1. 先定位 AOC 与颜色/酒型，确认法律地理框架；
2. 再识别分级词的对象：酒庄、地块、村庄还是产区；
3. 找生产者/装瓶者，区分葡萄来源与酿造主体；
4. 最后把年份、价格与自己的饮用目的放进判断；若信息不足，就只把它当作信息不足，而非补想象。

## 21.4 常见说法辨析

| 说法 | 判定 | 说明 |
|------|------|------|
| “1855 分级就是波尔多全部酒的排名” | ❌ 明确错误 | 它是特定历史体系，不覆盖全部产区、酒庄和酒款。 |
| “勃艮第的 Climat 就是天气” | ❌ 明确错误 | 此处指有边界、名称与历史传统的葡萄园地块。 |
| “特级园一定比一级园更合我口味” | ⚠️ 过度推断 | 层级提供产地信息，但年份、生产者、风格和个人偏好仍独立。 |
| “写 Château 就表示列级酒庄” | ❌ 明确错误 | 名称用语与特定分级并非同义。 |

## 21.5 🔎 买酒与点酒时的用处

看到波尔多，先把“酒庄名—AOC—年份”分开读；看到勃艮第，先把“地块/AOC 层级—生产者—年份”分开读。预算有限时，不要为一个脱离这些上下文的等级词买单；先确认它具体承诺了什么。

## 21.7 本章实操

### 🅐 无器具版

找一张波尔多与一张勃艮第的正背标照片（不必购买），按下表只填写肉眼可核到的字段；空白就是下一步应追问的信息。

| 字段 | 波尔多标签 | 勃艮第标签 | 这个字段说明什么 |
|------|------------|------------|------------------|
| AOC |  |  | 法定地理/生产框架 |
| 分级或地块词 |  |  | 它的对象是什么 |
| 生产者/装瓶者 |  |  | 谁对成品负责 |
| 年份 |  |  | 本批葡萄的时间坐标 |

### 🅑 有条件版

备齐后再做：选两杯来自同一大区、不同生产者或不同地块层级的合法来源样品，以[品鉴记录表](../../forms/tasting-note.md)盲编码记录。只描述可感知差异，不把等级词当作解释；揭晓后再检查自己的期待是否影响判断。**适度饮酒，未成年人不饮酒，酒后不驾车。**
