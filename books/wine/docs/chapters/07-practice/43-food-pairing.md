# 第 43 章 餐酒搭配：机理而非口诀

搭配不是“红肉配红酒”的记忆题，而是菜与酒一起入口后，甜、酸、咸、鲜、脂肪、辣与酒的结构如何重新排列。先识别主导变量，再小步验证。

> **适度饮酒，未成年人不饮酒，酒后不驾车。**

## 43.1 用结构做实验

~~~mermaid
flowchart TD
A[一道菜] --> B[找主导：甜/酸/咸鲜/脂肪/辣]
B --> C[选酒的甜酸、单宁、酒精、气泡]
C --> D[小口交替尝试]
D --> E[记录变化：更平衡/更突兀/无差异]
~~~

| 菜的主导特征 | 优先观察的酒结构 | 避免当成定律 |
|---|---|---|
| 明显甜味 | 酒是否显得更酸、更苦 | “甜菜只能配甜酒” |
| 油脂与咸鲜 | 酸度、气泡、单宁的体感 | “油腻必配某品种” |
| 辛辣 | 酒精感、甜感、温度 | “辣菜不能喝酒” |
| 高酸 | 酒是否显得松散或尖锐 | “白酒永远配海鲜” |

## 43.2 常见说法辨析

| 说法 | 判定 | 说明 |
|---|---|---|
| “红肉配红酒是铁律” | ❌ 明确错误 | 烹饪方式、酱汁和配菜常比肉的颜色更关键。 |
| “搭配只有一个正确答案” | ❌ 明确错误 | 可以追求对比或协调，个人偏好也不同。 |
| “先尝再记录没有意义” | ❌ 明确错误 | 小样验证比口诀更可复现。 |

## 43.3 🔎 买酒与点酒时的用处

点菜后说出主导酱汁和辣/甜程度，再要求一杯试饮；多人聚餐可选结构中等、兼容度较高的酒，而非强行满足所有人。

## 43.5 本章实操

### 🅐 无器具版

为一餐菜品标出主导结构，并为每道菜写一项“需要验证、不能猜”的搭配假设。

### 🅑 有条件版

用两款来源合法的小样与同一口菜交替尝试，记录哪一款让酸、甜、辣和余味怎样变化。**适度饮酒，未成年人不饮酒，酒后不驾车。**
