# 第 42 章 侍酒：把动作变成可解释的变量

侍酒不是仪式竞赛。温度、杯型、开瓶、醒酒和剩酒保存都在改变你接触到的香气、气体与氧气；每个动作都应有目的和可观察结果。

> **适度饮酒，未成年人不饮酒，酒后不驾车。**

## 42.1 先诊断，后动作

~~~mermaid
flowchart LR
A[开瓶前] --> B[记录酒种、温度、状态]
B --> C{问题是什么?}
C -->|过热/过冷| D[小幅调整温度]
C -->|香气封闭| E[分杯观察变化]
C -->|有异常| F[记录并与渠道沟通]
D --> G[再品尝并记录]
E --> G
~~~

| 动作 | 主要改变 | 不能保证 |
|---|---|---|
| 调温 | 挥发与口腔刺激的呈现 | 修复缺陷 |
| 换杯 | 顶空与饮用方式 | 让酒“升级” |
| 醒酒 | 与空气接触的时间和面积 | 所有酒都会变好 |
| 密封冷藏 | 减慢开瓶后变化 | 无限延长寿命 |

## 42.2 常见说法辨析

| 说法 | 判定 | 说明 |
|---|---|---|
| “红酒都必须醒很久” | ❌ 明确错误 | 酒种、状态和目标不同。 |
| “越贵越该大力醒酒” | ❌ 明确错误 | 价格不是操作参数。 |
| “杯型毫无作用” | ⚠️ 过度简化 | 它会改变呈现，但不是魔法。 |

## 42.3 🔎 买酒与点酒时的用处

先要一小杯试酒，再决定是否调温、换杯或分杯观察；把“我希望它更清爽/更开放”说清楚。

## 42.5 本章实操

### 🅐 无器具版

为一次聚餐写侍酒计划：每个动作后面必须写“要观察什么”。

### 🅑 有条件版

同一酒分两杯，一杯立即品、一杯短暂静置后品，记录差异和不确定性。**适度饮酒，未成年人不饮酒，酒后不驾车。**
