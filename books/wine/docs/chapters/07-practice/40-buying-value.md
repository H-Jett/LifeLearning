# 第 40 章 选购：价格结构与“性价比”藏在哪

“性价比”不是酒的客观属性，而是预算、用途、可替代性与失败成本的比值。把价格拆开，才能避免把名气、包装或稀缺叙事误认成液体品质。

> **适度饮酒，未成年人不饮酒，酒后不驾车。**

## 40.1 先定义任务，再看价格

~~~mermaid
flowchart TD
 A[预算] --> B[用途：日常/配餐/送礼/收藏]
 B --> C[必须条件：风格、人数、到货时间]
 C --> D[比较同用途替代品]
 D --> E[核对渠道、标签、保存与退换]
 E --> F[记录结果，校准下一次]
~~~

| 价格中可能包含 | 可验证线索 | 不能据此断言 |
|---|---|---|
| 税费、物流、渠道层级 | 销售地、规格、到手价 | 酒液本身更好 |
| 包装与礼盒 | 商品图、净含量 | 更耐存或更适口 |
| 稀缺与品牌 | 配额、年份、市场供给 | 适合你的用途 |
| 生产与陈年 | 法定年龄词、技术信息 | 每个批次都同样出色 |

## 40.2 一个可复用的比较表

同一预算只比较可替代的对象。把每瓶记录为：到手单价、净含量、酒精度、用途、风格证据、保存风险、退换条件，以及“我愿为哪一项多付钱”。最后一项必须能说成完整句子，例如“为确定的产区和稳定的餐酒搭配多付”，而不是“因为它看起来高级”。

## 40.3 常见说法辨析

| 说法 | 判定 | 说明 |
|---|---|---|
| “贵一定更值” | ❌ 明确错误 | 价格与用途、渠道、稀缺和包装共同相关。 |
| “低价酒不能配餐” | ❌ 明确错误 | 配餐首先看结构与菜品，不是价签。 |
| “限量就是投资价值” | ⚠️ 证据不足 | 限量不等于有流动市场或保真、保存条件。 |

## 40.4 🔎 买酒与点酒时的用处

每次购买只写一个目的和一个预算上限；不能说明目的的购买，先不下单。餐厅点酒则用“杯数、菜品、预算、是否愿意尝试”四项向侍酒师提问。

## 40.6 本章实操

### 🅐 无器具版

以一个明确用途挑三件候选商品，填比较表；把未知项写为未知，不以宣传语补齐。

### 🅑 有条件版

在一次聚餐后，把实际饮用量、菜品匹配和是否会复购补入表格。**适度饮酒，未成年人不饮酒，酒后不驾车。**
