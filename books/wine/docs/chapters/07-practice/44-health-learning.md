# 第 44 章 酒与健康的证据等级，以及往专业走的路

酒不是健康工具。WHO 指出，不能建立一个对健康或癌症风险无害的饮酒量；风险还会随饮用量、频率、个体健康状况和饮用情境而变。少饮或不饮风险更低；未成年人、孕哺期、驾驶与操作设备前，以及存在药物相互作用或健康疑虑时，应避免饮酒并向医生或药师咨询。

> **适度饮酒，未成年人不饮酒，酒后不驾车。**

## 44.1 读健康结论先看研究问题

~~~mermaid
flowchart TD
A[看到“酒有益/有害”标题] --> B[问：比较对象是谁?]
B --> C[问：观察研究还是干预研究?]
C --> D[问：结局、剂量、时间和混杂因素?]
D --> E[不把群体关联改写成个人处方]
~~~

“适量有益”的许多叙事容易受比较组、既往健康和生活方式等混杂影响。面对健康问题，本书不给具体饮酒配额，也不以某种酒的价格、颜色或“天然”叙事降低风险。[WHO 资料](https://www.who.int/europe/news/item/04-01-2023-no-level-of-alcohol-consumption-is-safe-for-our-health)

## 44.2 专业学习是能力路线，不是头衔竞赛

| 目标 | 更适合的练习 | 不必先做 |
|---|---|---|
| 买酒和配餐 | 标签、记录、预算项目 | 追逐证书名称 |
| 餐饮服务 | 菜单、服务流程、盲品校准 | 背完所有产区 |
| 深入产区/行业 | 读法规、技术资料和原始来源 | 把课程讲义当法规 |

## 44.3 常见说法辨析

| 说法 | 判定 | 说明 |
|---|---|---|
| “红酒可以当保健品” | ❌ 明确错误 | 酒精本身有风险，不能以酒替代医疗或健康行为。 |
| “观察到相关性就证明因果” | ❌ 明确错误 | 还需看比较组、混杂、设计和可重复性。 |
| “有证书就无需继续记录” | ❌ 明确错误 | 专业能力仍需要持续校准与更新。 |

## 44.4 🔎 买酒与点酒时的用处

把饮酒看成可选的风味活动，而不是健康投资；任何时候都保留不喝、少喝、换成无酒精饮品的选项。
