# 第 41 章 储存与陈年潜力：什么酒值得存

储存的第一目标是减慢不想要的变化，不是把所有酒“养得更好”。陈年潜力则是酒、封口、储存史和你的等待成本共同决定的判断。

> **适度饮酒，未成年人不饮酒，酒后不驾车。**

## 41.1 两个问题分开问

~~~mermaid
flowchart TD
A[一瓶酒] --> B{近期会喝吗?}
B -->|会| C[避光、温度稳定、按标签保存]
B -->|不会| D{有可靠储存条件与陈年理由吗?}
D -->|有| E[记录购入、位置与复查日期]
D -->|没有| F[不把“存着”当升值策略]
~~~

| 因素 | 可做的动作 | 不宜承诺 |
|---|---|---|
| 温度与波动 | 阴凉、稳定、远离热源 | 精确预测成熟日期 |
| 光照 | 避免强光与日晒 | 深色瓶可无限免责 |
| 封口与姿态 | 按生产者建议、避免长期漏液 | 单凭封口推断品质 |
| 购买记录 | 留存渠道、日期、状态 | 替代真实储存史 |

## 41.2 “值得存”需要证据链

先问：我期待它改变什么？有什么关于结构、生产与保存的证据？我能否接受它不如现在好喝？若其中任一项答不上来，买一瓶近期饮用、一瓶以后复查通常比囤很多瓶更有学习价值。

## 41.3 常见说法辨析

| 说法 | 判定 | 说明 |
|---|---|---|
| “越贵越耐存” | ❌ 明确错误 | 价格不等于结构、封口和储存史。 |
| “酒越老越好” | ❌ 明确错误 | 陈年是变化，不是单向升级。 |
| “只要放冰箱就万无一失” | ❌ 明确错误 | 还要考虑温度波动、光照、空间与酒种。 |

## 41.4 🔎 买酒与点酒时的用处

将“可陈年”写成待验证假设，而不是价值标签；优先购买有清楚渠道与保存条件的酒。

## 41.6 本章实操

### 🅐 无器具版

为现有三瓶酒建立卡片：购入时间、来源、当前位置、计划饮用日和未知项。

### 🅑 有条件版

以同款不同保存史的合法样品做盲比并记录差异，不把一次结果推广到全部酒。**适度饮酒，未成年人不饮酒，酒后不驾车。**
