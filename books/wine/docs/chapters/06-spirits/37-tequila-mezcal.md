# 第 37 章 龙舌兰与梅斯卡尔：先读原产地与生产路径

两者都与 agave（龙舌兰属/美洲龙舌兰）有关，却不是可以互换的名字。最可靠的起点不是“烟熏、顺口、传统”这些感受词，而是标签是否声明受保护名称、适用哪部标准，以及该名称承诺的原料和生产路径。

> **适度饮酒，未成年人不饮酒，酒后不驾车。**

## 37.1 两个受保护名称，两套问题

Tequila（龙舌兰酒）的官方定义指定 *Agave tequilana* Weber azul，即蓝色龙舌兰；其标签首先可区分为 `Tequila` 和 `Tequila 100 % de agave`。前者可在发酵前补加不超过 49% 的其他糖；后者的糖分只能来自蓝色龙舌兰。这里的“100%”说的是**糖源类别**，不是“没有任何后续处理”的万能承诺。[资料登记](../../standards.md)

Mezcal（梅斯卡尔）也有独立的原产地与 NOM-070 规范。规范把合格生产路径区分为 Mezcal、Mezcal Artesanal（手工型）和 Mezcal Ancestral（祖传型）；三者都包括蒸煮、粉碎、发酵、蒸馏，但可用设备的边界不同。因此，`artesanal` 是一条受规范约束的生产路径信息，不是一张自动胜出的品质奖状。

~~~mermaid
flowchart TD
    A[看到 agave 烈酒标签] --> B{写有 Tequila?}
    B -->|是| C[核对 NOM-006 与原产地]
    C --> D[读类别：Tequila / 100% de agave]
    C --> E[读等级：blanco 至 extra añejo]
    B -->|否| F{写有 Mezcal?}
    F -->|是| G[核对 NOM-070 与原产地]
    G --> H[读生产类别：Mezcal / Artesanal / Ancestral]
    F -->|否| I[仅按实际标签与销售地规则判断]
~~~

| 标签字段 | 它实际缩小了什么范围 | 它不能单独证明什么 |
|---|---|---|
| `100 % de agave` | Tequila 的糖源类别 | 无添加、必然更好或一定更适合你 |
| `blanco / reposado / añejo` | Tequila 标准中的类别与最短木材接触边界 | 具体桶型、风味强度或价格合理性 |
| `Artesanal / Ancestral` | Mezcal 的合规生产路径 | 所有批次风味一致、绝对更“高级” |
| 地名、生产者、批次 | 继续核实的线索 | 自动等于受保护名称或真伪保证 |

## 37.2 时间词和生产词不能混读

在 Tequila 中，`reposado` 至少有两个月木材接触；`añejo` 至少一年，`extra añejo` 至少三年，后两类使用的容器上限为 600 L。它们是**最低规则**，不是“所有成分都恰好陈年这么久”的感官预测公式。`joven/oro` 还可能是 blanco 与较陈年类别的混合，或是经标准允许处理的 blanco；不能望文生义为“年轻就一定未处理”。

在 Mezcal 中，生产类别回答的是“蒸煮、粉碎、发酵、蒸馏怎样被允许完成”，不是以陈年时间构成的同一套等级。把 Tequila 的时间词拿去解释 Mezcal 的传统生产词，或反过来，都把不同维度压成了一个“高低档”刻度。

## 37.3 常见说法辨析

| 说法 | 判定 | 说明 |
|---|---|---|
| “所有 agave 烈酒都是 Tequila” | ❌ 明确错误 | Tequila 是有指定植物与原产地规则的受保护名称；Mezcal 有独立规范。 |
| “100% agave 就表示无添加、纯天然” | ❌ 明确错误 | 该词首先限定 Tequila 的糖源，不能替代对其他处理和标签的逐项核对。 |
| “Artesanal 一定比 Mezcal 更好” | ❌ 明确错误 | 它描述合规生产路径；品质判断仍要看样品、信息透明度与个人偏好。 |
| “有烟熏味就必然是 Mezcal” | ⚠️ 不能据此判断 | 风味描述不能替代原产地名称、规范与标签字段。 |

## 37.4 🔎 买酒与点酒时的用处

先把问题拆成四项：名称是否受保护、原料类别是什么、标签中的时间/生产词属于哪套标准、还有哪些信息没有写。这样能避免把“100%”“手工”“祖传”直接换算成品质或价格。当店员只用故事词而说不出标签字段时，把结论保留为“信息不足”。

## 37.6 本章实操

### 🅐 无器具版

找一张 Tequila 和一张 Mezcal 的合法销售页或酒标图，只抄可见字段到两栏：受保护名称、原料/类别、时间或生产词、产地、未知项。把“高级”“小众”“传统”等词另列为营销或待核信息，不填入事实栏。

### 🅑 有条件版

备齐后再做：以盲码比较两款标签信息不同、来源合法的 agave 烈酒，先只记录香气、甜感、木质感和余味，再揭示标签；最后标出哪些预测来自字段，哪些只是事后故事。**适度饮酒，未成年人不饮酒，酒后不驾车。**
