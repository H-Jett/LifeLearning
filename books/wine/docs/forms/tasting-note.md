# 品鉴记录表

> 一张表两个用途：**逼你按顺序观察**，以及**让历次记录可比较**。
> 结构自拟，参考的是可公开引用的系统性品鉴框架（见[出处与资料登记](../standards.md)）。
>
> **适度饮酒，未成年人不饮酒，酒后不驾车。** 记录用的分量很小，
> 一支酒分成多次、每次 20~30 mL 就足够完成一次完整记录。

## 怎么用这张表

1. **一杯一张**。同一支酒在不同温度 / 开瓶后不同时间，算**不同次记录**（这恰恰是最有信息量的对比）。
2. **先填客观栏，再填感受栏**。客观栏抄自酒标，不需要判断；感受栏才需要你出手。
3. **量表是 1~5 的整数**，允许写 "3~4"。刻度含义见下面的[刻度定义](#scale)，
   每次都用同一套定义——**尺度只对你自己历次记录之间有意义**，不要和别人的分数比。
4. **填不出来就写"读不出"**，不要猜。"读不出"是有价值的记录，编一个数不是。

## 刻度定义（自用锚点，固定不变）

| 项 | 1 | 3 | 5 | 生理/物质依据（详见第 1 章） |
|----|---|---|---|------------------------------|
| **甜** | 尝不到甜 | 明显但不腻 | 甜是主角 | 残糖（也受甘油、酒精的甜感干扰） |
| **酸** | 平、发闷 | 有支撑感 | 尖锐、大量生津 | 有机酸浓度 + pH，注意"生津量"比"酸味"更可靠 |
| **涩** | 完全不干 | 舌面有摩擦感 | 牙龈发紧、口腔发糙 | 单宁等酚类与唾液蛋白结合——**触觉**，不是味觉 |
| **苦** | 无 | 尾端一点苦 | 明显苦 | 小分子酚类（与涩分开记，两者常被混为一谈） |
| **酒精感** | 没有热感 | 喉咽处温热 | 明显灼烧 | 乙醇的化学刺激（三叉神经），不是味觉 |
| **body** | 像水 | 中等稠厚 | 厚重、裹口 | 乙醇 + 残糖 + 干浸出物共同贡献的综合印象 |
| **香气强度** | 要凑很近才有 | 举杯即有 | 满桌都是 | 挥发性成分的顶空浓度（随温度显著变化） |
| **余味长度** | 咽下即无 | 十几秒 | 半分钟以上还在 | 通常与浓度、酚类、酸度相关 |

> **诚实说明**：这八项里，"甜/酸/苦"属味觉，"涩/酒精感"属**化学触觉**，
> "香气"属嗅觉，"body"是多通道综合印象。它们**不是同一种东西**，
> 混在一张表里只是为了方便记录——判断时要记得它们的来源不同。

| 项 | 填写 |
|----|------|
| 强度（1~5） | |
| 第一印象（不加修饰，想到什么写什么） | |

> **可疑气味那一栏最值得认真填**——它是第 31 章缺陷识别的原始素材。
> 现在读不出名字没关系，**先记下"像什么"**。

## 表五 · 结论与复盘

| 项 | 填写 |
|----|------|
| 一句话总结 | |
| 我喜欢吗（1~5）——**和"品质"分开记** | |
| 我觉得它在品质上的档位（入门 / 日常 / 优秀 / 出色），以及理由 | |
| 有无缺陷嫌疑？（写"怀疑 X，需要 Y 来确认"，不写"是坏的"） | |
| 适合配什么菜 / 什么场合 | |
| 如果再买一瓶，我会改变什么（温度、杯型、醒酒、搭配） | |
| **和酒标的一致性**：风格与我根据产区+品种的预判吻合吗？ | |

> 最后一行是这张表的长期价值所在：**它在训练"从酒标预测风味"的能力**。
> 预判错了才是好事——写下你原本预期什么、实际是什么，差异在哪。

## 进阶：对照记录（同一支酒，两种条件）

想快速提高，最有效的做法不是多喝不同的酒，而是**同一支酒做对照**。
一瓶酒倒两杯，只改一个变量：

| 变量 | A 杯 | B 杯 | 我观察到的差异 |
|------|------|------|--------------|
| 温度（如 10 ℃ vs 18 ℃） | | | |
| 杯型（如小口杯 vs 大肚杯） | | | |
| 时间（刚开瓶 vs 2 小时后） | | | |
| 有无食物（空口 vs 配一口奶酪/坚果） | | | |

> **只改一个变量**——这是让感官练习变成"实验"而不是"喝酒"的唯一分别。
> 每次改两个以上，你就再也说不清是谁造成的差异了。
