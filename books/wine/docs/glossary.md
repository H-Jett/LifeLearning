## 甜：糖与甜味物质

<a id="residual-sugar"></a>
**残糖**（英：residual sugar, **RS**；法：sucre résiduel）——
发酵结束后仍留在酒里的、可发酵性糖的总量，通常以 g/L 表示。
它是"甜不甜"的主要来源，但**不是唯一**来源：乙醇与甘油都带一点甜感。
酒标上的甜度术语（干型 / 半干 / 半甜 / 甜，以及起泡酒的 brut 一族）是**按残糖区间划的法规术语**，
不是酒庄的形容词。

<a id="glucose-fructose"></a>
**葡萄糖与果糖**（英：glucose / fructose）——
葡萄汁里的两种主要单糖。酿酒酵母 *Saccharomyces cerevisiae* 是**嗜葡萄糖的**（glucophilic），
即优先消耗葡萄糖，所以发酵中后期与甜型酒的残糖里**果糖占比会升高**。
两种糖的甜度并不相同，这是"同样残糖、甜感不同"的一个可能原因——
但**具体甜度比值本书尚未核到一手出处**，见[出处与资料登记](standards.md)的待办清单。

<a id="chaptalization"></a>
**加糖**（英：chaptalization；法：chaptalisation）——
发酵前向葡萄汁加糖以提高最终酒精度的操作。它提高的是**酒精**而不是甜度，
是否允许、允许多少由各产区法规规定。

<a id="dry-extract"></a>
**干浸出物**（英：total dry extract / sugar-free extract；亦作"无糖浸出物"）——
把酒中的水和挥发性成分蒸干后剩下的全部固体物质总量（糖、酸、甘油、酚类、矿物质等）。
它是**酒体**最接近"可测量"的那个指标，检测报告里常见。

## 酸：有机酸与 pH

<a id="total-acidity"></a>
**总酸 / 可滴定酸**（英：total acidity / titratable acidity, **TA**）——
用碱滴定测出的可解离酸总量。⚠️ **表达基准各地不同**：OIV 与欧盟体系以**酒石酸**计，
部分文献以硫酸计——**同一瓶酒换个基准数字就变了**，看数字必须先看单位写的是什么。

<a id="ph"></a>
**pH**——
溶液中**游离**氢离子浓度的对数指标。它与总酸**不是同一件事**：
总酸量的是"总共有多少酸"，pH 量的是"这些酸解离出了多少氢离子"。
pH 决定了颜色表现、二氧化硫的有效形态比例与微生物稳定性；
而入口的"酸感"更多跟总酸与糖的相对关系走。**两个指标必须一起看**。

<a id="tartaric-acid"></a>
**酒石酸**（英：tartaric acid；法：acide tartrique）——
葡萄特有的主要有机酸之一，在常见果实中相当罕见，也是葡萄酒酸度最稳定的骨架
（酵母与乳酸菌基本不消耗它）。低温下会与钾结合析出**酒石酸氢钾**结晶
（瓶底的"酒石"，无害，不是杂质）。

<a id="malic-acid"></a>
**苹果酸**（英：malic acid；法：acide malique）——
第二主要有机酸，口感比酒石酸更"生硬"。随葡萄成熟被呼吸消耗，
凉气候地区残留更多。可被乳酸菌转化（见下条）。

<a id="mlf"></a>
**苹果酸乳酸发酵**（英：malolactic fermentation, **MLF**；亦称"二次发酵"）——
乳酸菌把苹果酸转化为乳酸并放出二氧化碳的过程。结果是**酸度下降、口感变柔**，
并可能带来乳制品类香气。它是**工艺选择**，不是必然步骤（第 14 章）。

<a id="volatile-acidity"></a>
**挥发酸**（英：volatile acidity, **VA**）——
酒中可被蒸馏带出的酸，主体是**乙酸**。低浓度下增加复杂度，超过阈值则是缺陷
（醋味、指甲油味，后者实际上来自乙酸乙酯）。各法系都对它设了**法定上限**（第 31 章）。

## 涩与苦：酚类物质

<a id="polyphenol"></a>
**多酚 / 酚类物质**（英：polyphenols / phenolics）——
一大类含酚羟基的化合物的总称，来自果皮、果籽、果梗与橡木。
它负责**颜色、涩感、部分苦味与抗氧化**，是红葡萄酒与白葡萄酒最大的成分差异之一。
常以"总酚"（多以没食子酸当量表示）衡量。

<a id="tannin"></a>
**单宁**（英：tannin；法：tanin）——
能与蛋白质结合的一类多酚。葡萄酒里主要是**缩合单宁**（原花青素），
由儿茶素类单元聚合而成；来自橡木的**水解单宁**是另一类。
分子大小是关键变量：**偏小的单元更偏苦，聚合度更高的更偏涩**。

<a id="astringency"></a>
**涩感**（英：astringency）——
口腔黏膜的**干燥、收缩、发糙**的感觉。⚠️ 它是**触觉 / 机械感受**，**不是味觉**：
主流机制认为单宁与唾液蛋白（尤其富脯氨酸蛋白）结合沉淀，破坏了唾液的润滑层，
于是舌与腭之间的摩擦增大（另有直接作用于口腔上皮受体的补充机制）。
所以"涩"在舌头的味觉地图上找不到位置，而且**会随每一口累积**。

<a id="anthocyanin"></a>
**花色苷**（英：anthocyanins；亦译"花青素苷"）——
红葡萄皮中的色素类多酚，决定年轻红酒的颜色；对 pH 敏感，
并在陈年中与单宁结合形成更稳定的聚合色素——这是红酒颜色由紫红转砖红的化学基础。

<a id="bitterness"></a>
**苦味**（英：bitterness）——
真正的**味觉**，由苦味受体介导。酒中部分小分子酚类是苦的。
苦与涩常被一起说成"涩"，但它们是**两个不同通道**：苦是味觉、涩是触觉，
而且两者的分子偏好不同——记录时应当分开打分（见[品鉴记录表](forms/tasting-note.md)）。

## 酒精与"化学感觉"

<a id="ethanol"></a>
**乙醇**（英：ethanol / ethyl alcohol）——
发酵的主产物。它同时干四件事：提供**热感与辛辣**（化学刺激）、贡献**甜感**、
增加**黏稠与体积感**、并作为溶剂**改变香气分子在液相与气相之间的分配**。
所以"酒精度"从来不只是"度数"。

<a id="abv"></a>
**酒精度**（英：alcohol by volume, **ABV**；标签常见 `% vol`）——
20 ℃ 下乙醇的体积百分比。酒标标示值与实测值之间**法规允许一定误差**，
各法系的容差不同（第 20 章）。

<a id="chemesthesis"></a>
**化学感觉 / 化学触觉**（英：chemesthesis）——
由**三叉神经**等躯体感觉系统介导的化学刺激感受：辣、凉、刺、酒精的灼热都属于此类。
它**既不是味觉也不是嗅觉**。乙醇的灼热感与辣椒素走的是同一类通路
（涉及 TRPV1 等受体），这解释了为什么"高酒精"和"辣"在口感上有共通之处。

<a id="body"></a>
**酒体**（英：body）——
对"口中重量感、稠厚度"的综合印象。**它不对应单一物质**：
乙醇、残糖、干浸出物都在贡献。因此 body 是**印象**而非测量值——
本书在需要精确时一律拆成"酒精度 + 残糖 + 干浸出物"来说。

<a id="glycerol"></a>
**甘油**（英：glycerol）——
酵母发酵的主要副产物之一，在酒中含量仅次于水与乙醇（糖之外）。
它**略甜、略黏**。⚠️ 但"甘油造成酒的稠厚感/挂杯"是被显著夸大的说法：
在葡萄酒的常见浓度下，其对**黏度**的贡献很小，感官研究更支持它贡献**甜感**（第 1 章辨析表）。

<a id="marangoni"></a>
**马兰戈尼效应**（英：Marangoni effect；俗称"酒腿""酒泪""挂杯"）——
乙醇比水更易挥发，杯壁液膜处乙醇先跑掉，导致该处**表面张力升高**，
把下方液体拉上来形成薄膜、聚成液滴滑落。它是**乙醇与水的表面张力梯度**造成的流体现象，
**主要受酒精度、温度与杯壁洁净度影响**，与"品质""甘油多"没有已建立的对应关系。

## 香气与嗅觉

<a id="volatile-compound"></a>
**挥发性化合物**（英：volatile compounds）——
能从液相进入气相、从而被鼻子闻到的成分。酒中已鉴定的挥发性成分数量极多
（正文给具体量级与来源），但**绝大多数浓度低于感知阈值**，对香气无贡献。

<a id="detection-threshold"></a>
**感知阈值**（英：detection threshold / odour threshold）——
能被察觉到的最低浓度。⚠️ 阈值**不是物理常数**：它随**介质**（水 / 模拟酒液 / 真酒）、
**测定方法**与**人群**变化，个体差异常达一个数量级以上，
所以引用阈值必须同时给测定条件。

<a id="oav"></a>
**香气活性值**（英：odour activity value, **OAV**）——
某成分的浓度除以它的感知阈值。OAV > 1 才**可能**对香气有贡献。
它是筛选"哪些分子值得关注"的工具，但**不能简单相加**——
成分之间存在协同与掩盖，所以高 OAV 不等于"闻起来就是这个味"。

<a id="retronasal"></a>
**后鼻腔嗅觉**（英：retronasal olfaction）——
食物与酒在口中时，挥发性成分经由咽腔向上进入鼻腔被嗅到。
日常说的"味道"绝大部分来自这条通路——这就是**捏住鼻子喝酒会失去大半风味**的原因。
与之相对的是从鼻孔吸入的**前鼻腔嗅觉**（orthonasal）。

<a id="headspace"></a>
**顶空**（英：headspace）——
杯中液面之上的那层气体空间。你闻到的其实是顶空里的浓度。
温度升高会提高挥发性成分的分压、从而提高顶空浓度——
这是**"酒温高香气冲"的物理基础**（第 1 章、第 42 章）。

<a id="matrix-effect"></a>
**基质效应**（英：matrix effect）——
同一浓度的香气分子，在不同液体里"跑出来"的比例不同。
酒精度尤其关键：乙醇作为溶剂会把一部分疏水性香气分子**留在液相**，
所以高酒精的酒有时香气反而"收着"。这也是为什么香气数据必须说明测定介质。

<a id="varietal-aroma"></a>
**品种香 / 一类香气**（英：varietal / primary aroma）——
来自葡萄本身（含以糖苷等形式存在的**香气前体**）的香气。
与之并列的是**发酵香（二类）**与**陈年香（三类）**（第 4 章）。
分层的意义在于：**有些香气可以被工艺造出来，有些不能**——这直接关系到定价。

## 缺陷与污染（第 1 章先认名字，第 31 章展开）

<a id="tca"></a>
**TCA · 2,4,6-三氯苯甲醚**（英：2,4,6-trichloroanisole, **TCA**）——
"木塞味"（cork taint）的主要责任分子，气味像湿纸板 / 潮湿地下室，
并会**压低**酒本身的果香。感知阈值极低（正文给数量级与来源）。
同类还有 TBA（三溴苯甲醚）等。

<a id="brett"></a>
**酒香酵母**（英：*Brettanomyces* / *Dekkera*，行业简称 **Brett**）——
一类可在酒中生长的酵母，产生**挥发性酚类**（如 4-乙基苯酚、4-乙基愈创木酚），
气味被描述为马厩、创可贴、烟熏、动物皮革。
⚠️ **它是"缺陷"还是"风格"取决于浓度与共识**，本书并列两种立场（第 31 章）。

<a id="so2"></a>
**二氧化硫 / 亚硫酸盐**（英：sulfur dioxide, **SO₂** / sulfites）——
酿酒中最重要的抗氧化与抗微生物添加物，在酒中以游离态与结合态共存，
有效形态比例强烈依赖 **pH**。总量有**法定上限**；多国要求酒标标注
"contains sulfites / 含亚硫酸盐"。其与头痛的关系见第 1 章辨析表（第 5 章展开）。

<a id="oxidation"></a>
**氧化**（英：oxidation）——
酒接触氧后的一系列变化：颜色变黄/变砖、果香减弱、出现坚果与苹果干气息。
适度氧化是某些风格（如部分雪莉、马德拉）的**刻意设计**，
过度则是缺陷——**同一化学过程，两种评价**，取决于是否可控、是否符合该酒的设计（第 17、18 章）。

## 感官通道与个体差异（第 2 章）

<a id="taste-receptor"></a>
**味觉受体**（英：taste receptors）——
味蕾中味觉受体细胞上负责识别甜、酸、苦、咸、鲜的分子机制的统称。
甜与鲜由 T1R 家族、苦由 T2R 家族介导；酸的关键在于质子通道（见下条）。
⚠️ 受体**分布在所有有味蕾的区域**（舌缘与舌背、软腭、咽），**不存在"分区专营"**；
但口腔不同位置的敏感度确有**小而显著**的差异。嘴唇、舌下、硬腭、颊内侧不产生味觉。

<a id="otop1"></a>
**Otop1 · 质子通道**（英：Otopetrin-1, OTOP1）——
被证明是**酸味**（对酸的味觉反应）所必需的质子通道：缺失它，味觉细胞与神经对酸刺激的反应消失。
它让"酸"成为五种基本味中机制较为明确的一项。

<a id="olfactory-receptor"></a>
**嗅觉受体**（英：olfactory receptors, **OR**；亦称气味受体 odorant receptors）——
嗅上皮细胞上的一大类 G 蛋白偶联受体，是人类基因组中最大的多基因家族。
人类**约有 400 个有功能的 OR 基因**，另有数量相当的**假基因**（已失效）。
嗅觉采用**组合编码**：一个分子激活多个受体，一个受体响应多类分子，
大脑读的是**激活模式**——所以"一个分子对应一种气味"是错的。

<a id="orthonasal"></a>
**前鼻腔嗅觉**（英：orthonasal olfaction）——
从鼻孔吸入气味分子的通路，即"闻杯子"时用的那条。
与[后鼻腔嗅觉](#retronasal)相对；两条路的气流、稀释与温度条件不同，**阈值可以不同**。

<a id="specific-anosmia"></a>
**特异性嗅盲**（英：specific anosmia）——
对**某一类分子**选择性地闻不到，而其余嗅觉正常。
它与嗅觉受体基因的个体差异直接相关（如 β-紫罗兰酮与 OR5A1、androstenone 与 OR7D4）。
⚠️ **定义性特征是"提高浓度也无效"**——这正是它与"阈值偏高"的区别，
也是判断一次感官分歧原因的关键测试。

<a id="trigeminal"></a>
**三叉神经（化学感觉通路）**（英：trigeminal system / chemesthesis）——
负责口鼻腔"辣、凉、刺、灼热"等化学刺激感受的躯体感觉系统。
人体实验显示：只麻醉味觉神经不影响涩感，**同时**阻断味觉与三叉神经支配才使涩感消失——
因此**涩主要走这条通路**。乙醇的灼热、二氧化碳的刺感同属此类。另见[化学感觉](#chemesthesis)。

<a id="prop-taster"></a>
**PROP 味觉者分型**（英：PROP taster status, **PTS**）——
按对苦味物质 **6-正丙基硫氧嘧啶（PROP）** 的敏感度把人分为无感者 / 一般味觉者 / 超级味觉者，
与 *TAS2R38* 基因型相关。⚠️ 它与葡萄酒感知的关系**证据不一致**：
有研究报告它与红酒的味觉/涩感**强度**相关，也有研究报告它对消费者的风味感知与接受度影响有限。
**"强度不同"与"判断更准"是两回事。**

<a id="fungiform-papillae"></a>
**菌状乳头**（英：fungiform papillae）——
舌前部含味蕾的乳头，密度的个体差异很大，常与 PROP 分型一起被用来讨论味觉敏感度差异。
⚠️ 密度与口腔反应性的关系在文献中仍有分歧。

<a id="cross-modal"></a>
**跨通道交互 · 气味诱导的甜味增强**（英：cross-modal interaction；
odour-induced sweetness enhancement, **OISE**）——
嗅觉信号改变味觉感知的现象：在**含糖量完全相同**的样品中，改变气味强度会改变甜度评分，
并呈**倒 U 形**（气味过强反而不再增甜）。
⚠️ 这意味着"**闻起来甜**"与"**有残糖**"是两栏，记录时必须分开写。

<a id="sensory-adaptation"></a>
**感官适应 / 感官疲劳**（英：sensory adaptation / fatigue）——
持续暴露于同一刺激时感知强度下降。嗅觉尤其明显，所以"一直贴着杯子闻"不是好方法；
正确做法是**短闻、间隔、再闻**。⚠️ **涩的方向相反——它会随每一口累积**，
因此连续品鉴必须留间隔并清口。

## 发酵与代谢（第 3 章）

<a id="redox-balance"></a>
**氧化还原平衡**（英：redox balance）——
酵母必须让 NADH 与 NAD⁺ 的收支相抵，糖酵解才能持续。
乙醛还原为乙醇是主要的 NAD⁺ 再生途径；但合成菌体会额外产生 NADH，
多出来的部分靠**生成甘油**来消耗——**这是甘油必然存在的根本原因**（另见[甘油](#glycerol)）。

<a id="ehrlich-pathway"></a>
**埃利希通路**（英：Ehrlich pathway）——
酵母利用氨基酸作氮源时的分解途径：**氨基酸 → 转氨 → α-酮酸 → 脱羧 → 还原 → 高级醇**。
酵母的目的是取得氮，高级醇是被丢出来的碳骨架。

<a id="higher-alcohol"></a>
**高级醇 / 杂醇**（英：higher alcohols / fusel alcohols）——
比乙醇碳链更长的一类醇，由[埃利希通路](#ehrlich-pathway)生成。
异戊醇、异丁醇等高浓度时呈溶剂样刺鼻气息；**2-苯乙醇**（来自苯丙氨酸）则是玫瑰 / 蜂蜜香。
它们同时是**乙酸酯的直接前体**——所以氮状况会连带改写酯的组成。

<a id="ester"></a>
**酯**（英：esters）——
年轻葡萄酒果香的主要化学载体，分两族：**乙酸酯**（乙酰辅酶 A + 高级醇，
由醇乙酰基转移酶 AATase 催化，代表是带香蕉气息的乙酸异戊酯）与
**脂肪酸乙酯**（中链脂肪酸 + 乙醇）。
⚠️ 酯化与水解**可逆**，所以瓶储中酯的组成会漂移——**年轻果香会淡去**。

<a id="yan"></a>
**可同化氮**（英：yeast assimilable nitrogen, **YAN**）——
葡萄汁中酵母能利用的氮，主要是铵盐与游离氨基酸。
不足会导致发酵变慢或中止并促进硫化氢生成；水平不同则改变高级醇与酯的比例。
需求量**因菌株而异**，本书不给推荐值。

<a id="stuck-fermentation"></a>
**发酵中止**（英：stuck fermentation；法：fermentation languissante）——
发酵在糖未耗尽时停止。常见诱因包括氮不足、温度失控、酒精毒性、营养缺乏等。
后果不只是残糖偏高，还包括微生物稳定性下降。

## 香气的三个来源（第 4 章）

<a id="fermentation-aroma"></a>
**发酵香 / 二类香气**（英：fermentation / secondary aroma）——
在酒精发酵与苹果酸乳酸发酵中由微生物生成的香气，主要是[酯](#ester)、
[高级醇](#higher-alcohol)、挥发性酸与双乙酰等。
⚠️ 它**相对可控、可重复**，因此作为溢价理由较弱；而且**年轻时最强、会随时间减弱**。

<a id="aging-aroma"></a>
**陈年香 / 三类香气**（英：ageing / tertiary aroma）——
在木桶熟成与瓶中陈年过程中生成或转化的香气。
两条来路要分清：**外来的（橡木，有廉价替代方案）**与
**内生的（时间与仓储换来的化学变化，难以伪造）**。

<a id="aroma-precursor"></a>
**香气前体**（英：aroma precursors）——
葡萄中不挥发、闻不到的结合态香气分子，最常见的是**糖苷结合态**
（单萜等）与**半胱氨酸 / 谷胱甘肽结合态**（品种硫醇）。
需经酶解或酸解释放才能被感知——**这就是"总量由葡萄决定、闻到多少由发酵决定"的原因**。

<a id="methoxypyrazine"></a>
**甲氧基吡嗪**（英：methoxypyrazines, **MPs**）——
一类含氮杂环化合物，带**青椒 / 草本**气息，代表是 **3-异丁基-2-甲氧基吡嗪（IBMP）**。
主要存在于果梗与果皮，随葡萄成熟而下降，且其下降与**苹果酸的分解高度相关**——
因此它同时是一个**成熟度信号**。

<a id="monoterpene"></a>
**单萜**（英：monoterpenes）——
十个碳的萜类，以**花香**为主要印象，在麝香系品种与雷司令等品种中含量较高。
常见的有芳樟醇、香叶醇、香茅醇、α-松油醇。在葡萄中大量以糖苷结合态存在。

<a id="norisoprenoid"></a>
**C13-降异戊二烯**（英：C13-norisoprenoids）——
由葡萄中**类胡萝卜素**裂解而来的一族香气分子，包括 β-大马士酮（果香、烤苹果）、
β-紫罗兰酮（紫罗兰、覆盆子）、[TDN](#tdn)（煤油）与维他斯品（桉叶、樟脑）。
它们横跨"一类"与"三类"：前体来自葡萄，但部分分子在陈年中才生成。

<a id="volatile-thiol"></a>
**挥发性硫醇 / 品种硫醇**（英：volatile / polyfunctional thiols）——
带**西柚、黄杨、百香果、柑橘皮**气息的一类含硫化合物，代表是 3-巯基己-1-醇（3MH）、
乙酸-3-巯基己酯（A3MH）与 4-巯基-4-甲基戊-2-酮（4MMP）。
⚠️ 它们在葡萄汁中**大量以结合态存在，必须靠酶作用释放**，
而酿酒酵母的释放效率并不高——**这是"同一片园子、不同酒庄差别巨大"的一个化学原因**。

<a id="tdn"></a>
**TDN · 1,1,6-三甲基-1,2-二氢萘**（英：1,1,6-trimethyl-1,2-dihydronaphthalene, **TDN**）——
雷司令陈年后"煤油 / 汽油"气息的责任分子，含量**依赖紫外线**，南北半球差异很大。
人类受体 **OR8H1** 被鉴定为其选择性受体。
⚠️ **同一分子在不同市场评价相反**：在澳大利亚常被视为加分项，在欧洲可能成为拒绝的理由。

## 二氧化硫、二氧化碳与"矿物感"（第 5 章）

<a id="molecular-so2"></a>
**分子态二氧化硫**（英：molecular SO₂）——
溶液中未解离的 SO₂ / H₂SO₃ 形式，是**抗菌活性的主力**。
它占游离 SO₂ 的比例由 **pH** 决定（pKa₁ ≈ 1.8）：pH 越高，有效形态越少。
⚠️ **法规管的是总量，酿酒师关心的是分子态**——所以"游离 SO₂ 是多少"脱离 pH 没有意义。

<a id="free-bound-so2"></a>
**游离 / 结合 / 总二氧化硫**（英：free / bound / total SO₂）——
**游离** = 分子态 + 亚硫酸氢根 + 亚硫酸根；**结合** = 已与醛、酮、糖、羧酸等结合而失活的部分；
**总量** = 二者之和，也是各法域限量与标注门槛所依据的指标。
⚠️ **"结合 SO₂" 至今没有被普遍接受的定义**，不同参考方法释放结合态的条件不同，
无法保证测的是同一批物质——因此本书不给游离/结合的比例数字。

<a id="minerality"></a>
**矿物感**（英：minerality；法：minéralité）——
近二十年高频出现的葡萄酒描述词。⚠️ **至今没有公认定义**：
对近一千七百名消费者的研究显示，不同经验层次的人所指完全不同
（矿物水的离子 / 风土概念 / 燧石味 / 酸度）；专业人士之间也找不到共识含义。
"**土壤矿物直接进入酒中**"的解释在地质学上讲不通（岩石无味、不易挥发、
酒中矿质元素常低于感知阈值）。
在夏布利所做的研究中，与该描述相关的是**甲硫醇等挥发性硫化物**，
且差异只在**前鼻腔嗅闻**条件下出现。
**本书的用法：把它当成一个待拆解的词，追问对方指的是哪一种。**

## 方法与法规基础词（第 4、19、20 章展开）

<a id="oiv"></a>
**OIV · 国际葡萄与葡萄酒组织**（法：Organisation Internationale de la Vigne et du Vin；
英：International Organisation of Vine and Wine）——
政府间组织，发布分析方法汇编、酿酒规范与全球统计，是本书数值的首要引用来源之一。

<a id="pdo-pgi"></a>
**PDO / PGI · 原产地保护 / 地理标志保护**（英：protected designation of origin /
protected geographical indication）——
欧盟统一的两级地理标志框架。各成员国的传统名称（法国 AOC、意大利 DOC/DOCG、
西班牙 DO/DOCa 等）在这个框架下各自对应其中一级（第 19 章）。

<a id="iso-3591"></a>
**ISO 3591 品酒杯**（英：ISO 3591 wine-tasting glass；业内称"ISO 杯"）——
国际标准化组织定义的标准品酒杯形状与尺寸，用于让不同场合的感官评价条件可比。
本书凡涉及"标准条件下"的香气描述，默认指这类杯型（登记见[出处与资料登记](standards.md)）。

## 葡萄这种植物：物种与繁殖（第 6 章）

<a id="vitis-vinifera"></a>
**葡萄属 / 欧洲种葡萄**（拉：*Vitis* / *Vitis vinifera* L.；英：grapevine / European grapevine）——
*Vitis* 是葡萄属，据 OIV 统计已鉴定约 80 个种，分**圆叶葡萄亚属（Muscadinia）**与
**真葡萄亚属（Euvitis）**；后者又分美洲组、东亚组与**欧亚组**，
而欧亚组**只有 *Vitis vinifera* 一个种**——世界上绝大多数酿酒品种都属于它。
该种下分**野生型亚种 sylvestris** 与**栽培型亚种 vinifera**。

<a id="phylloxera"></a>
**葡萄根瘤蚜**（拉：*Daktulosphaira vitifoliae*；英：grape phylloxera；法：phylloxéra）——
原产北美的同翅目害虫，兼有有性与无性世代。
在 *V. vinifera* 品种上**以根部虫态为主**，在美洲原生 *Vitis* 种上**以叶部虫态为主**；
损害很大程度来自**取食点被土传次生病原侵染**。
主要防治手段是**源自美洲原生 *Vitis* 的抗性砧木**。

<a id="rootstock"></a>
**砧木与接穗**（英：rootstock / scion；法：porte-greffe / greffon）——
嫁接体的下半截（根系）与上半截（结果的枝）。
今天绝大多数酿酒葡萄是"**欧洲种的接穗 + 美洲种（或其杂交后代）的砧木**"。
砧木影响树势、产量、环境适应性以及葡萄的糖、有机酸与酚类组成；
但它对**香气**的影响在公开研究中**高度依赖情境、缺少一致趋势**。

<a id="grafting"></a>
**嫁接**（英：grafting；法：greffage）——
把一个品种的枝条接到另一株的根系上，使两者长成一株。
在葡萄上它最初是**应对根瘤蚜**的工程方案，后来成为调节树势与适应土壤的常规手段。

<a id="own-rooted"></a>
**自根**（英：own-rooted；法：franc de pied）——
未经嫁接、用自身根系生长的葡萄植株。
它是一个**可核实的事实陈述**；但"自根因此更好"目前**缺乏可引用的证据**。

<a id="clonal-selection"></a>
**克隆选种与马萨尔选种**（英：clonal selection / massal selection；
法：sélection clonale / sélection massale）——
同一品种内部再分层的两种做法：前者从单株扩繁出遗传上高度一致的一群（"某某号克隆"），
后者从老园里挑一批表现好的植株一起繁殖、保留园内多样性。
葡萄的自然突变常见，且被持续的无性繁殖保留下来——这正是这一层存在的原因。
⚠️ **本书尚未核到二者规程的一手出处**，因此不做优劣判断。

<a id="direct-producer-hybrid"></a>
**直接生产者杂交种**（英：direct producer hybrid, **DPH**；法：hybride producteur direct）——
19 世纪末至 20 世纪中叶为应对根瘤蚜而培育的种间杂交品种，可不经嫁接直接栽培。
欧盟法规允许 *V. vinifera* 与葡萄属其他种的杂交种进入成员国目录，
但**点名排除了 Noah、Othello、Isabelle、Jacquez、Clinton、Herbemont 六个品种**。

## 物候与成熟（第 7 章）

<a id="phenology"></a>
**物候期**（英：phenology；对应的编号系统：**改良 E-L 系统** modified Eichhorn-Lorenz system、
**扩展 BBCH 尺度** extended BBCH scale）——
植物在一年中依次经历的可辨认发育阶段（萌芽、展叶、开花、坐果、转色、成熟）。
葡萄栽培用**编号系统**来消除口语描述的歧义，
两套常用体系都发表于 1995 年，**编号让年份之间与产区之间的比较成为可能**。

<a id="veraison"></a>
**转色**（法：véraison；英：veraison / onset of ripening；BBCH 81）——
浆果从"生长期"转入"成熟期"的节点：颜色开始变化、糖开始积累。
它的生理意义更关键：**转色后木质部流入被阻断**，
糖与水都改由**韧皮部**供应，二者的增量因此绑定在一起。

<a id="berry-shrivel"></a>
**果实收缩（失水浓缩）**（英：berry shrivel / berry weight loss）——
浆果达到最大重量后开始失水的阶段。此时每颗果的**溶质总量已接近平台**，
但水在减少，**糖度（°Brix）仍会继续上升**。
⚠️ 因此"糖度更高"**不一定**等于"糖更多"——它也可能只是"水更少"。

<a id="growing-degree-days"></a>
**积温**（英：growing degree days, **GDD**；亦称 degree days）——
把生长季内每天超过某个**基准温度**的部分累加起来，用以量化热量供应。
⚠️ **基准温度与统计区间必须与数字一起给**，否则两个积温数值不可比较。
本书核到的一手用法是**以 10 ℃ 为基准**。

<a id="technological-ripeness"></a>
**工艺成熟度与酚类成熟度**（英：technological ripeness / phenolic ripeness）——
前者指糖与酸达到目标（可用糖度与可滴定酸测量，成本低）；
后者指单宁与花青素的量与质地达到目标。
⚠️ **酚类成熟度缺少统一的、可引用的判据**，本书因此不给任何指标。

## 风土与产地（第 8 章）

<a id="terroir"></a>
**风土**（法：terroir；英：terroir / vitivinicultural terroir）——
OIV 在 2010 年通过决议给出的定义：指**一个区域**，
在其中关于"**可辨识的物理与生物环境**"与"**所施用的葡萄栽培与酿造实践**"
之间相互作用的**集体性知识**得以形成，从而为源自该区域的产品带来独特特征；
它**包括**特定的土壤、地形、气候、景观特征与生物多样性特征。
⚠️ 该决议同时要求**防止把这一描述性定义与地理标志（GI）的法律定义混淆**。

<a id="vine-water-status"></a>
**树体水分状况**（英：vine water status）——
葡萄树实际获得的水分相对于其需求的状态。
它被认为是气候与土壤影响果实组成的**主要中介变量**；
**适度的水分亏缺**会限制新梢与浆果生长，对高品质红葡萄酒的果实组成很关键。

<a id="carbon-isotope-discrimination"></a>
**碳同位素判别**（英：carbon isotope discrimination，记作 **δ¹³C**）——
在**葡萄糖分**上测定的一个指标，用于**回溯性地评估整个成熟期的树体水分状况**。
它让"水分胁迫"从一个形容词变成一个可测量、可制图的参数。

<a id="microbial-terroir"></a>
**微生物风土**（英：microbial terroir）——
指葡萄表面微生物群落存在**非随机的地理与品种格局**这一观察。
⚠️ 从"组成有差异"到"酒喝起来不同"，还差**是否参与发酵**与
**代谢物是否超过感知阈值**两步，本书未核到补上这两步的研究。

<a id="strontium-isotope"></a>
**锶同位素比**（英：strontium isotope ratio，记作 **⁸⁷Sr/⁸⁶Sr**）——
酒中锶的同位素比反映葡萄园土壤**可交换部分**的比值，
结合详细的地质与土壤资料可用于**产地溯源**。
⚠️ 它是一个**没有味道**的标签：土壤的化学签名确实进入了酒，但它不参与风味。

## 品种的分子标识（第 9 章）

<a id="berry-colour-locus"></a>
**果皮颜色位点**（英：berry colour locus）——
控制葡萄果皮是否积累花青素的位点，由两个高度相似的相邻调控基因
***VvMYBA1*** 与 ***VvMYBA2*** 组成，**任何一个有功能都会显色**。
白色果皮需要**两个基因都失活**：前者因启动子插入**逆转座子**而不转录，
后者由两个非保守突变失活。已检测的 55 个白色品种**全部只携带白色等位基因**，
据此推论**现存白色品种有共同起源**。

<a id="parentage-analysis"></a>
**亲子鉴定（微卫星标记）**（英：parentage analysis / microsatellite markers, SSR）——
用高度多态的重复序列位点比对品种间的亲缘关系。
它把"某品种的来历"从传说变成了可查的结论——
例如霞多丽与另外 15 个法国东北部品种被鉴定为 **Pinot × Gouais blanc** 的后代。

## 红葡萄品种的酚类指纹（第 10 章）

<a id="anthocyanin-acylation"></a>
**花色苷的取代与酰化**（英：substitution pattern / acylation of anthocyanins）——
果皮花色苷是**一族**分子，彼此差别在两处：**B 环上的取代模式**
（分**二取代**与**三取代**，后者含 malvidin 一系）与**糖基上是否再挂一个酰基**。
⚠️ **同样多的花色苷，可以给出完全不同的色调与颜色寿命**。
已核到的两条：**赤霞珠与内比奥罗分别以三取代型与二取代型为主**；
**黑皮诺不产酰化花色苷**。

<a id="skin-vs-seed-tannin"></a>
**皮单宁与籽单宁**（英：skin-derived / seed-derived tannins）——
红葡萄酒单宁的两大来源（加上保留果梗时的**梗单宁**共三类），
区别不只在化学结构，更在**进入酒里的时间**：
皮来源的黄烷-3-醇因水溶性好而**约五天即达最大值的 80~85 %**；
籽来源的化合物外面有**脂质角质层**这道扩散屏障，**需要十天以上**，
并随发酵中乙醇浓度上升而逐步释放。籽来源的没食子酰化比例更高。

<a id="mdp"></a>
**平均聚合度**（英：mean degree of polymerisation, **mDP**）——
缩合单宁（原花青素）聚合体中平均含有多少个黄烷-3-醇单元。
它是描述"单宁质地"最接近可测量的指标：
**mDP 高的更偏粗糙、干**，**mDP 低的更偏顺滑**（第 1 章）。
另有**没食子酰化度**与**原翠雀素比例（%PD）**等结构参数，同样在浸渍中演变。

<a id="rotundone"></a>
**Rotundone**（一种倍半萜；英：rotundone）——
"黑胡椒"气息的责任分子，是极少数**单分子对应单一描述词**的例子。
⚠️ 它同时是"阈值不是常数"的标准教材：两项研究给出的红葡萄酒阈值分别为
**16 ng/L**（受训人群）与 **146 ng/L**（非专业消费者），
嗅盲比例分别约为 **1/5~1/4** 与约 **40 %**；
**嗅盲的定义性特征是提高浓度也无效**（第 2 章）。

## 葡萄园管理（第 11 章）

<a id="planting-authorisation"></a>
**种植授权**（英：authorisation for vine plantings）——
欧盟对酿酒葡萄种植与重植的许可制度。授权对应**以公顷表示的具体面积**，
按客观、非歧视的标准发放、**不收费**、**有效期三年**；
成员国每年发放的**新种植授权对应其实际种植面积的 1 %**，可设更低比例或区域限制，
理由须为**避免供过于求**或**避免某个 PDO/PGI 被显著贬值**。
试验用地、嫁接苗圃与**仅供酒农家庭消费**的地块不适用。

<a id="yield-limit"></a>
**每公顷最高产量**（英：maximum yield per hectare；法：rendement）——
欧盟 PDO/PGI **产品规范的强制内容之一**（与地理区域划定、品种、
允许的酿酒操作等九项并列）。⚠️ **它是资格约束，不是品质承诺**：
法规同时允许以"避免某 PDO/PGI 被显著贬值"为由限制种植授权——
**稀缺性在这里部分是法定安排**。

<a id="vine-balance"></a>
**树体平衡**（英：vine balance；常用指标为**产量与修剪重量之比**，即 Ravaz 指数）——
把"产量高不高"换成"产量与树体生长量匹配不匹配"的思路。
⚠️ 本书只核到一项试验中被引用的**修剪重量每米 0.3~0.6 kg**
这一"适合产出高品质酿酒葡萄"的区间，**比值本身的推荐范围未核到，因此不给**。

<a id="canopy-management"></a>
**树冠管理**（英：canopy management）——
通过**控制新梢数、控制树势、选择架式**来调节树冠微气候的一整套操作。
关键指标是**叶层数**：经典综述主张**约三层叶**的树冠密度；
**每公顷新梢数多、行距宽、树势高、叶片偏垂直**会加重遮阴，
**窄行或分冠**可减轻。夏季修剪（疏梢、去叶、疏果）属于其中的季中手段，
⚠️ 其中**去叶的可塑性很高**——产量可增可减、成熟可提前可推迟。

<a id="biodynamic"></a>
**有机与生物动力**（英：organic / biodynamic viticulture）——
两套不同性质的体系：**有机在欧盟由法规规定**（现行框架为 (EU) 2018/848，
取代 (EC) 834/2007 与 (EC) 889/2008）；**生物动力是私营认证标准**，
其与有机认证的**主要区别是必须使用九种"制剂"**。
⚠️ 在一项唯一变量就是制剂的长期重复试验中，**前六年土壤质量没有差异**，
产量与果串、果粒指标也无差异；差异出现在**产量/修剪重量比**与**果实化学**上。

## 红葡萄酒的浸皮与萃取（第 12 章）

<a id="maceration"></a>
**浸皮 / 浸渍**（英：maceration；法：macération）——
让葡萄汁（或发酵中的酒）与果皮、果籽、（可选的）果梗保持接触，
以萃取酚类、香气前体、氮源与多糖的工序。
⚠️ 关键在于**不同组分的萃取速度完全不同**：单体花色苷通常**头 4~7 天见顶后下降**，
皮单宁**约五天达八成**，籽单宁**十天以上**才大量进入——
所以"泡多久"是一个**取舍**，不是一个程度。

<a id="cap-management"></a>
**酒帽与帽管理**（英：cap；法：chapeau / cap management）——
发酵产生的二氧化碳把果皮顶到液面形成的致密层，以及把它重新混入液体的操作。
常见做法：**压帽（pigeage）**、**淋帽/循环（remontage）**、
**放液回淋（délestage）**、旋转罐，以及用气体使帽保持松散的"软"管理。
⚠️ **帽内温度可比下方发酵液高出多达 14 ℃**；帽管理同时在调**萃取、温度分布与氧暴露**
三件事——这也是"不做帽管理的酒还原味更高"的机制来源。

<a id="polymeric-pigment"></a>
**聚合色素**（英：polymeric pigments）——
单体花色苷与单宁等酚类结合后形成的更稳定的有色物质
（吡喃花色苷如 vitisin A/B 也属这一大类的相关产物）。
⚠️ 它解释了一个关键事实：**浸渍时长主要影响花色苷的组成与稳定性，
而不是简单地影响浓度**——测到的"单体花色苷下降"并不等于看到的"颜色变浅"。

<a id="copigmentation"></a>
**共色作用**（英：copigmentation）——
花色苷与其他无色酚类（如黄酮醇、羟基肉桂酸）通过分子间作用形成复合体，
使颜色在短期内显著增强或偏移。它是**年轻红葡萄酒颜色的重要组成部分**，
也是后续形成稳定聚合色素的中间环节。

<a id="carbonic-maceration"></a>
**二氧化碳浸渍**（法：macération carbonique；英：carbonic maceration, **CM**）——
把**完整未破损的果串**放进密闭容器、先充二氧化碳，
使果粒在缺氧环境下从呼吸转为**胞内发酵**的做法（**1934 年由 Michel Flanzy 发明**）。
果粒内在酵母发酵开始前就产生**约 1.5~2 %** 的乙醇。
典型 **5~15 天**：**30~32 ℃ 时 5~8 天**、**15 ℃ 时 15~20 天**。
成酒常表现为**颜色与酒体更轻、涩感更低、更果味**（红色浆果与糖果类）。

<a id="whole-bunch"></a>
**整串 / 带梗发酵**（英：whole-bunch / whole-cluster fermentation）——
将部分或全部**不除梗的果串**投入发酵，比例通常在 **10 %~100 %**。
它带来**梗来源的单宁**并可**提高梗与皮单宁的比例、降低籽单宁的相对贡献**，
同时发生部分胞内浸渍。⚠️ 代价是：**梗会吸附花色苷**，
高比例还可能提高甲氧基吡嗪、丁香酚、愈创木酚等"青梗"相关分子。

<a id="extended-maceration"></a>
**发酵后延长浸渍**（英：post-fermentative extended maceration）——
酒精发酵结束后仍与固体接触一段时间再压榨。
此时处于**全水醇介质**，萃取靠扩散与浓度梯度。
⚠️ 它失去了发酵产生的二氧化碳保护，**氧暴露与微生物风险上升**；
已核到的一项赤霞珠对照（10 天 vs 30 天）显示：
**花色苷损失、原花青素萃取增加，其中约 73 % 为籽来源**。

## 白葡萄酒与桃红的工艺（第 13 章）

<a id="debourbage"></a>
**澄清 / 去泥**（法：débourbage；英：juice settling / clarification）——
把压榨得到的葡萄汁中的果肉碎片、果皮碎屑与胶体分离出去的工序。
欧盟授权的手段包括**离心与过滤**、**浮选**（**仅可使用氮、二氧化碳或通气**）、
**制造惰性气氛**、**鼓泡**（**仅可使用氩或氮**）与**果胶酶类**
（仅用于浸渍、澄清、稳定、过滤与**使香气前体显现**）。
⚠️ 澄清程度影响的是"**发酵会产生什么**"，不只是"酒清不清"。

<a id="free-run-press-wine"></a>
**自流汁 / 自流酒与压榨汁 / 压榨酒**（英：free-run juice / wine；press juice / press wine；
法：jus de goutte / jus de presse）——
靠自重流出的部分与随压力升高榨出的部分，成分不同，实践中**分开收集**、事后决定是否调配。
⚠️ **各段之间成分差异的可引用定量数据，本书尚未核到，因此正文不给数字。**
另需知道：欧盟**禁止过度压榨**——皮渣与酒脚中的酒精量须**至少相当于成酒酒精体积的 5 %**。

<a id="grp"></a>
**GRP · 葡萄反应产物**（英：grape reaction product）——
葡萄汁中的**羟基肉桂酸类**（如咖啡酰酒石酸）被**多酚氧化酶**氧化成醌后，
与**谷胱甘肽**结合生成的产物。它是白葡萄汁氧化链条上的关键中间站——
生成 GRP 的那部分底物就不再继续走向褐变。

<a id="glutathione"></a>
**谷胱甘肽**（英：glutathione, **GSH**）——
葡萄与酵母中天然存在的含硫三肽，在白葡萄酒中被作为二氧化硫的部分替代方案讨论。
⚠️ 已核到的对照：**SO₂ 使葡萄汁耗氧速率降低约 72 %**，
纯 GSH 约 **23 %**、富 GSH 失活酵母约 **36 %**；
在**葡萄健康**时 GSH 防褐变有效，**存在漆酶（灰霉）时效果不足**。

<a id="saignee"></a>
**放血法**（法：saignée；英：bleeding）——
在红葡萄酒发酵早期放出一部分果汁单独酿成桃红的做法。
⚠️ 它常常**同时是红葡萄酒生产的一环**：放走一部分汁会提高剩余部分的皮汁比。
桃红的另外两条路线是**直接压榨**与**短时浸渍后分离**。

<a id="skin-contact-white"></a>
**带皮发酵白葡萄酒**（英：skin-contact white wine；俗称 "orange wine"）——
用白葡萄品种、按红葡萄酒的方式带皮发酵所得的酒。
按萃取曲线可直接推出其后果：会萃取**皮与籽来源的单宁**，因而**有涩感**；
**颜色变深来自非花青素类酚的氧化与聚合**（白品种没有花色苷）。
⚠️ 本书未核到针对这一类酒的系统性一手研究，**不给时长与风格断言**。
