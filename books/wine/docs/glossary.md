# 术语表

> 酒标、检测报告和文献多是外文，所以每个词条都给 **中文 + 原文术语（若有）+ 英文**。
> 词条按主题分组；**每条前有显式 `<a id>` 锚点**，各章脚注直接跳转（三边通用）。
>
> 本表随各章推进增补。当前覆盖到**第 1 章**。
> 数值与限值不写在这里——它们在正文里带出处，出处登记在[出处与资料登记](standards.md)。

## 甜：糖与甜味物质

<a id="residual-sugar"></a>
**残糖**（英：residual sugar, **RS**；法：sucre résiduel）——
发酵结束后仍留在酒里的、可发酵性糖的总量，通常以 g/L 表示。
它是"甜不甜"的主要来源，但**不是唯一**来源：乙醇与甘油都带一点甜感。
酒标上的甜度术语（干型 / 半干 / 半甜 / 甜，以及起泡酒的 brut 一族）是**按残糖区间划的法规术语**，
不是酒庄的形容词。

<a id="glucose-fructose"></a>
**葡萄糖与果糖**（英：glucose / fructose）——
葡萄汁里的两种主要单糖。酿酒酵母 *Saccharomyces cerevisiae* 是**嗜葡萄糖的**（glucophilic），
即优先消耗葡萄糖，所以发酵中后期与甜型酒的残糖里**果糖占比会升高**。
两种糖的甜度并不相同，这是"同样残糖、甜感不同"的一个可能原因——
但**具体甜度比值本书尚未核到一手出处**，见[出处与资料登记](standards.md)的待办清单。

<a id="chaptalization"></a>
**加糖**（英：chaptalization；法：chaptalisation）——
发酵前向葡萄汁加糖以提高最终酒精度的操作。它提高的是**酒精**而不是甜度，
是否允许、允许多少由各产区法规规定。

<a id="dry-extract"></a>
**干浸出物**（英：total dry extract / sugar-free extract；亦作"无糖浸出物"）——
把酒中的水和挥发性成分蒸干后剩下的全部固体物质总量（糖、酸、甘油、酚类、矿物质等）。
它是**酒体**最接近"可测量"的那个指标，检测报告里常见。

## 酸：有机酸与 pH

<a id="total-acidity"></a>
**总酸 / 可滴定酸**（英：total acidity / titratable acidity, **TA**）——
用碱滴定测出的可解离酸总量。⚠️ **表达基准各地不同**：OIV 与欧盟体系以**酒石酸**计，
部分文献以硫酸计——**同一瓶酒换个基准数字就变了**，看数字必须先看单位写的是什么。

<a id="ph"></a>
**pH**——
溶液中**游离**氢离子浓度的对数指标。它与总酸**不是同一件事**：
总酸量的是"总共有多少酸"，pH 量的是"这些酸解离出了多少氢离子"。
pH 决定了颜色表现、二氧化硫的有效形态比例与微生物稳定性；
而入口的"酸感"更多跟总酸与糖的相对关系走。**两个指标必须一起看**。

<a id="tartaric-acid"></a>
**酒石酸**（英：tartaric acid；法：acide tartrique）——
葡萄特有的主要有机酸之一，在常见果实中相当罕见，也是葡萄酒酸度最稳定的骨架
（酵母与乳酸菌基本不消耗它）。低温下会与钾结合析出**酒石酸氢钾**结晶
（瓶底的"酒石"，无害，不是杂质）。

<a id="malic-acid"></a>
**苹果酸**（英：malic acid；法：acide malique）——
第二主要有机酸，口感比酒石酸更"生硬"。随葡萄成熟被呼吸消耗，
凉气候地区残留更多。可被乳酸菌转化（见下条）。

<a id="mlf"></a>
**苹果酸乳酸发酵**（英：malolactic fermentation, **MLF**；亦称"二次发酵"）——
乳酸菌把苹果酸转化为乳酸并放出二氧化碳的过程。结果是**酸度下降、口感变柔**，
并可能带来乳制品类香气。它是**工艺选择**，不是必然步骤（第 14 章）。

<a id="volatile-acidity"></a>
**挥发酸**（英：volatile acidity, **VA**）——
酒中可被蒸馏带出的酸，主体是**乙酸**。低浓度下增加复杂度，超过阈值则是缺陷
（醋味、指甲油味，后者实际上来自乙酸乙酯）。各法系都对它设了**法定上限**（第 31 章）。

## 涩与苦：酚类物质

<a id="polyphenol"></a>
**多酚 / 酚类物质**（英：polyphenols / phenolics）——
一大类含酚羟基的化合物的总称，来自果皮、果籽、果梗与橡木。
它负责**颜色、涩感、部分苦味与抗氧化**，是红葡萄酒与白葡萄酒最大的成分差异之一。
常以"总酚"（多以没食子酸当量表示）衡量。

<a id="tannin"></a>
**单宁**（英：tannin；法：tanin）——
能与蛋白质结合的一类多酚。葡萄酒里主要是**缩合单宁**（原花青素），
由儿茶素类单元聚合而成；来自橡木的**水解单宁**是另一类。
分子大小是关键变量：**偏小的单元更偏苦，聚合度更高的更偏涩**。

<a id="astringency"></a>
**涩感**（英：astringency）——
口腔黏膜的**干燥、收缩、发糙**的感觉。⚠️ 它是**触觉 / 机械感受**，**不是味觉**：
主流机制认为单宁与唾液蛋白（尤其富脯氨酸蛋白）结合沉淀，破坏了唾液的润滑层，
于是舌与腭之间的摩擦增大（另有直接作用于口腔上皮受体的补充机制）。
所以"涩"在舌头的味觉地图上找不到位置，而且**会随每一口累积**。

<a id="anthocyanin"></a>
**花色苷**（英：anthocyanins；亦译"花青素苷"）——
红葡萄皮中的色素类多酚，决定年轻红酒的颜色；对 pH 敏感，
并在陈年中与单宁结合形成更稳定的聚合色素——这是红酒颜色由紫红转砖红的化学基础。

<a id="bitterness"></a>
**苦味**（英：bitterness）——
真正的**味觉**，由苦味受体介导。酒中部分小分子酚类是苦的。
苦与涩常被一起说成"涩"，但它们是**两个不同通道**：苦是味觉、涩是触觉，
而且两者的分子偏好不同——记录时应当分开打分（见[品鉴记录表](forms/tasting-note.md)）。

## 酒精与"化学感觉"

<a id="ethanol"></a>
**乙醇**（英：ethanol / ethyl alcohol）——
发酵的主产物。它同时干四件事：提供**热感与辛辣**（化学刺激）、贡献**甜感**、
增加**黏稠与体积感**、并作为溶剂**改变香气分子在液相与气相之间的分配**。
所以"酒精度"从来不只是"度数"。

<a id="abv"></a>
**酒精度**（英：alcohol by volume, **ABV**；标签常见 `% vol`）——
20 ℃ 下乙醇的体积百分比。酒标标示值与实测值之间**法规允许一定误差**，
各法系的容差不同（第 20 章）。

<a id="chemesthesis"></a>
**化学感觉 / 化学触觉**（英：chemesthesis）——
由**三叉神经**等躯体感觉系统介导的化学刺激感受：辣、凉、刺、酒精的灼热都属于此类。
它**既不是味觉也不是嗅觉**。乙醇的灼热感与辣椒素走的是同一类通路
（涉及 TRPV1 等受体），这解释了为什么"高酒精"和"辣"在口感上有共通之处。

<a id="body"></a>
**酒体**（英：body）——
对"口中重量感、稠厚度"的综合印象。**它不对应单一物质**：
乙醇、残糖、干浸出物都在贡献。因此 body 是**印象**而非测量值——
本书在需要精确时一律拆成"酒精度 + 残糖 + 干浸出物"来说。

<a id="glycerol"></a>
**甘油**（英：glycerol）——
酵母发酵的主要副产物之一，在酒中含量仅次于水与乙醇（糖之外）。
它**略甜、略黏**。⚠️ 但"甘油造成酒的稠厚感/挂杯"是被显著夸大的说法：
在葡萄酒的常见浓度下，其对**黏度**的贡献很小，感官研究更支持它贡献**甜感**（第 1 章辨析表）。

<a id="marangoni"></a>
**马兰戈尼效应**（英：Marangoni effect；俗称"酒腿""酒泪""挂杯"）——
乙醇比水更易挥发，杯壁液膜处乙醇先跑掉，导致该处**表面张力升高**，
把下方液体拉上来形成薄膜、聚成液滴滑落。它是**乙醇与水的表面张力梯度**造成的流体现象，
**主要受酒精度、温度与杯壁洁净度影响**，与"品质""甘油多"没有已建立的对应关系。

## 香气与嗅觉

<a id="volatile-compound"></a>
**挥发性化合物**（英：volatile compounds）——
能从液相进入气相、从而被鼻子闻到的成分。酒中已鉴定的挥发性成分数量极多
（正文给具体量级与来源），但**绝大多数浓度低于感知阈值**，对香气无贡献。

<a id="detection-threshold"></a>
**感知阈值**（英：detection threshold / odour threshold）——
能被察觉到的最低浓度。⚠️ 阈值**不是物理常数**：它随**介质**（水 / 模拟酒液 / 真酒）、
**测定方法**与**人群**变化，个体差异常达一个数量级以上，
所以引用阈值必须同时给测定条件。

<a id="oav"></a>
**香气活性值**（英：odour activity value, **OAV**）——
某成分的浓度除以它的感知阈值。OAV > 1 才**可能**对香气有贡献。
它是筛选"哪些分子值得关注"的工具，但**不能简单相加**——
成分之间存在协同与掩盖，所以高 OAV 不等于"闻起来就是这个味"。

<a id="retronasal"></a>
**后鼻腔嗅觉**（英：retronasal olfaction）——
食物与酒在口中时，挥发性成分经由咽腔向上进入鼻腔被嗅到。
日常说的"味道"绝大部分来自这条通路——这就是**捏住鼻子喝酒会失去大半风味**的原因。
与之相对的是从鼻孔吸入的**前鼻腔嗅觉**（orthonasal）。

<a id="headspace"></a>
**顶空**（英：headspace）——
杯中液面之上的那层气体空间。你闻到的其实是顶空里的浓度。
温度升高会提高挥发性成分的分压、从而提高顶空浓度——
这是**"酒温高香气冲"的物理基础**（第 1 章、第 42 章）。

<a id="matrix-effect"></a>
**基质效应**（英：matrix effect）——
同一浓度的香气分子，在不同液体里"跑出来"的比例不同。
酒精度尤其关键：乙醇作为溶剂会把一部分疏水性香气分子**留在液相**，
所以高酒精的酒有时香气反而"收着"。这也是为什么香气数据必须说明测定介质。

<a id="varietal-aroma"></a>
**品种香 / 一类香气**（英：varietal / primary aroma）——
来自葡萄本身（含以糖苷等形式存在的**香气前体**）的香气。
与之并列的是**发酵香（二类）**与**陈年香（三类）**（第 4 章）。
分层的意义在于：**有些香气可以被工艺造出来，有些不能**——这直接关系到定价。

## 缺陷与污染（第 1 章先认名字，第 31 章展开）

<a id="tca"></a>
**TCA · 2,4,6-三氯苯甲醚**（英：2,4,6-trichloroanisole, **TCA**）——
"木塞味"（cork taint）的主要责任分子，气味像湿纸板 / 潮湿地下室，
并会**压低**酒本身的果香。感知阈值极低（正文给数量级与来源）。
同类还有 TBA（三溴苯甲醚）等。

<a id="brett"></a>
**酒香酵母**（英：*Brettanomyces* / *Dekkera*，行业简称 **Brett**）——
一类可在酒中生长的酵母，产生**挥发性酚类**（如 4-乙基苯酚、4-乙基愈创木酚），
气味被描述为马厩、创可贴、烟熏、动物皮革。
⚠️ **它是"缺陷"还是"风格"取决于浓度与共识**，本书并列两种立场（第 31 章）。

<a id="so2"></a>
**二氧化硫 / 亚硫酸盐**（英：sulfur dioxide, **SO₂** / sulfites）——
酿酒中最重要的抗氧化与抗微生物添加物，在酒中以游离态与结合态共存，
有效形态比例强烈依赖 **pH**。总量有**法定上限**；多国要求酒标标注
"contains sulfites / 含亚硫酸盐"。其与头痛的关系见第 1 章辨析表（第 5 章展开）。

<a id="oxidation"></a>
**氧化**（英：oxidation）——
酒接触氧后的一系列变化：颜色变黄/变砖、果香减弱、出现坚果与苹果干气息。
适度氧化是某些风格（如部分雪莉、马德拉）的**刻意设计**，
过度则是缺陷——**同一化学过程，两种评价**，取决于是否可控、是否符合该酒的设计（第 17、18 章）。

## 方法与法规基础词（第 4、19、20 章展开）

<a id="oiv"></a>
**OIV · 国际葡萄与葡萄酒组织**（法：Organisation Internationale de la Vigne et du Vin；
英：International Organisation of Vine and Wine）——
政府间组织，发布分析方法汇编、酿酒规范与全球统计，是本书数值的首要引用来源之一。

<a id="pdo-pgi"></a>
**PDO / PGI · 原产地保护 / 地理标志保护**（英：protected designation of origin /
protected geographical indication）——
欧盟统一的两级地理标志框架。各成员国的传统名称（法国 AOC、意大利 DOC/DOCG、
西班牙 DO/DOCa 等）在这个框架下各自对应其中一级（第 19 章）。

<a id="iso-3591"></a>
**ISO 3591 品酒杯**（英：ISO 3591 wine-tasting glass；业内称"ISO 杯"）——
国际标准化组织定义的标准品酒杯形状与尺寸，用于让不同场合的感官评价条件可比。
本书凡涉及"标准条件下"的香气描述，默认指这类杯型（登记见[出处与资料登记](standards.md)）。
