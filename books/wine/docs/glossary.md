## 甜：糖与甜味物质

<a id="residual-sugar"></a>
**残糖**（英：residual sugar, **RS**；法：sucre résiduel）——
发酵结束后仍留在酒里的、可发酵性糖的总量，通常以 g/L 表示。
它是"甜不甜"的主要来源，但**不是唯一**来源：乙醇与甘油都带一点甜感。
酒标上的甜度术语（干型 / 半干 / 半甜 / 甜，以及起泡酒的 brut 一族）是**按残糖区间划的法规术语**，
不是酒庄的形容词。

<a id="glucose-fructose"></a>
**葡萄糖与果糖**（英：glucose / fructose）——
葡萄汁里的两种主要单糖。酿酒酵母 *Saccharomyces cerevisiae* 是**嗜葡萄糖的**（glucophilic），
即优先消耗葡萄糖，所以发酵中后期与甜型酒的残糖里**果糖占比会升高**。
两种糖的甜度并不相同，这是"同样残糖、甜感不同"的一个可能原因——
但**具体甜度比值本书尚未核到一手出处**，见[出处与资料登记](standards.md)的待办清单。

<a id="chaptalization"></a>
**加糖**（英：chaptalization；法：chaptalisation）——
发酵前向葡萄汁加糖以提高最终酒精度的操作。它提高的是**酒精**而不是甜度，
是否允许、允许多少由各产区法规规定。

<a id="dry-extract"></a>
**干浸出物**（英：total dry extract / sugar-free extract；亦作"无糖浸出物"）——
把酒中的水和挥发性成分蒸干后剩下的全部固体物质总量（糖、酸、甘油、酚类、矿物质等）。
它是**酒体**最接近"可测量"的那个指标，检测报告里常见。

## 酸：有机酸与 pH

<a id="total-acidity"></a>
**总酸 / 可滴定酸**（英：total acidity / titratable acidity, **TA**）——
用碱滴定测出的可解离酸总量。⚠️ **表达基准各地不同**：OIV 与欧盟体系以**酒石酸**计，
部分文献以硫酸计——**同一瓶酒换个基准数字就变了**，看数字必须先看单位写的是什么。

<a id="ph"></a>
**pH**——
溶液中**游离**氢离子浓度的对数指标。它与总酸**不是同一件事**：
总酸量的是"总共有多少酸"，pH 量的是"这些酸解离出了多少氢离子"。
pH 决定了颜色表现、二氧化硫的有效形态比例与微生物稳定性；
而入口的"酸感"更多跟总酸与糖的相对关系走。**两个指标必须一起看**。

<a id="tartaric-acid"></a>
**酒石酸**（英：tartaric acid；法：acide tartrique）——
葡萄特有的主要有机酸之一，在常见果实中相当罕见，也是葡萄酒酸度最稳定的骨架
（酵母与乳酸菌基本不消耗它）。低温下会与钾结合析出**酒石酸氢钾**结晶
（瓶底的"酒石"，无害，不是杂质）。

<a id="malic-acid"></a>
**苹果酸**（英：malic acid；法：acide malique）——
第二主要有机酸，口感比酒石酸更"生硬"。随葡萄成熟被呼吸消耗，
凉气候地区残留更多。可被乳酸菌转化（见下条）。

<a id="mlf"></a>
**苹果酸乳酸发酵**（英：malolactic fermentation, **MLF**；亦称"二次发酵"）——
乳酸菌把苹果酸转化为乳酸并放出二氧化碳的过程。结果是**酸度下降、口感变柔**，
并可能带来乳制品类香气。它是**工艺选择**，不是必然步骤（第 14 章）。

<a id="volatile-acidity"></a>
**挥发酸**（英：volatile acidity, **VA**）——
酒中可被蒸馏带出的酸，主体是**乙酸**。低浓度下增加复杂度，超过阈值则是缺陷
（醋味、指甲油味，后者实际上来自乙酸乙酯）。各法系都对它设了**法定上限**（第 31 章）。

## 涩与苦：酚类物质

<a id="polyphenol"></a>
**多酚 / 酚类物质**（英：polyphenols / phenolics）——
一大类含酚羟基的化合物的总称，来自果皮、果籽、果梗与橡木。
它负责**颜色、涩感、部分苦味与抗氧化**，是红葡萄酒与白葡萄酒最大的成分差异之一。
常以"总酚"（多以没食子酸当量表示）衡量。

<a id="tannin"></a>
**单宁**（英：tannin；法：tanin）——
能与蛋白质结合的一类多酚。葡萄酒里主要是**缩合单宁**（原花青素），
由儿茶素类单元聚合而成；来自橡木的**水解单宁**是另一类。
分子大小是关键变量：**偏小的单元更偏苦，聚合度更高的更偏涩**。

<a id="astringency"></a>
**涩感**（英：astringency）——
口腔黏膜的**干燥、收缩、发糙**的感觉。⚠️ 它是**触觉 / 机械感受**，**不是味觉**：
主流机制认为单宁与唾液蛋白（尤其富脯氨酸蛋白）结合沉淀，破坏了唾液的润滑层，
于是舌与腭之间的摩擦增大（另有直接作用于口腔上皮受体的补充机制）。
所以"涩"在舌头的味觉地图上找不到位置，而且**会随每一口累积**。

<a id="anthocyanin"></a>
**花色苷**（英：anthocyanins；亦译"花青素苷"）——
红葡萄皮中的色素类多酚，决定年轻红酒的颜色；对 pH 敏感，
并在陈年中与单宁结合形成更稳定的聚合色素——这是红酒颜色由紫红转砖红的化学基础。

<a id="bitterness"></a>
**苦味**（英：bitterness）——
真正的**味觉**，由苦味受体介导。酒中部分小分子酚类是苦的。
苦与涩常被一起说成"涩"，但它们是**两个不同通道**：苦是味觉、涩是触觉，
而且两者的分子偏好不同——记录时应当分开打分（见[品鉴记录表](forms/tasting-note.md)）。

## 酒精与"化学感觉"

<a id="ethanol"></a>
**乙醇**（英：ethanol / ethyl alcohol）——
发酵的主产物。它同时干四件事：提供**热感与辛辣**（化学刺激）、贡献**甜感**、
增加**黏稠与体积感**、并作为溶剂**改变香气分子在液相与气相之间的分配**。
所以"酒精度"从来不只是"度数"。

<a id="abv"></a>
**酒精度**（英：alcohol by volume, **ABV**；标签常见 `% vol`）——
20 ℃ 下乙醇的体积百分比。酒标标示值与实测值之间**法规允许一定误差**，
各法系的容差不同（第 20 章）。

<a id="chemesthesis"></a>
**化学感觉 / 化学触觉**（英：chemesthesis）——
由**三叉神经**等躯体感觉系统介导的化学刺激感受：辣、凉、刺、酒精的灼热都属于此类。
它**既不是味觉也不是嗅觉**。乙醇的灼热感与辣椒素走的是同一类通路
（涉及 TRPV1 等受体），这解释了为什么"高酒精"和"辣"在口感上有共通之处。

<a id="body"></a>
**酒体**（英：body）——
对"口中重量感、稠厚度"的综合印象。**它不对应单一物质**：
乙醇、残糖、干浸出物都在贡献。因此 body 是**印象**而非测量值——
本书在需要精确时一律拆成"酒精度 + 残糖 + 干浸出物"来说。

<a id="glycerol"></a>
**甘油**（英：glycerol）——
酵母发酵的主要副产物之一，在酒中含量仅次于水与乙醇（糖之外）。
它**略甜、略黏**。⚠️ 但"甘油造成酒的稠厚感/挂杯"是被显著夸大的说法：
在葡萄酒的常见浓度下，其对**黏度**的贡献很小，感官研究更支持它贡献**甜感**（第 1 章辨析表）。

<a id="marangoni"></a>
**马兰戈尼效应**（英：Marangoni effect；俗称"酒腿""酒泪""挂杯"）——
乙醇比水更易挥发，杯壁液膜处乙醇先跑掉，导致该处**表面张力升高**，
把下方液体拉上来形成薄膜、聚成液滴滑落。它是**乙醇与水的表面张力梯度**造成的流体现象，
**主要受酒精度、温度与杯壁洁净度影响**，与"品质""甘油多"没有已建立的对应关系。

## 香气与嗅觉

<a id="volatile-compound"></a>
**挥发性化合物**（英：volatile compounds）——
能从液相进入气相、从而被鼻子闻到的成分。酒中已鉴定的挥发性成分数量极多
（正文给具体量级与来源），但**绝大多数浓度低于感知阈值**，对香气无贡献。

<a id="detection-threshold"></a>
**感知阈值**（英：detection threshold / odour threshold）——
能被察觉到的最低浓度。⚠️ 阈值**不是物理常数**：它随**介质**（水 / 模拟酒液 / 真酒）、
**测定方法**与**人群**变化，个体差异常达一个数量级以上，
所以引用阈值必须同时给测定条件。

<a id="oav"></a>
**香气活性值**（英：odour activity value, **OAV**）——
某成分的浓度除以它的感知阈值。OAV > 1 才**可能**对香气有贡献。
它是筛选"哪些分子值得关注"的工具，但**不能简单相加**——
成分之间存在协同与掩盖，所以高 OAV 不等于"闻起来就是这个味"。

<a id="retronasal"></a>
**后鼻腔嗅觉**（英：retronasal olfaction）——
食物与酒在口中时，挥发性成分经由咽腔向上进入鼻腔被嗅到。
日常说的"味道"绝大部分来自这条通路——这就是**捏住鼻子喝酒会失去大半风味**的原因。
与之相对的是从鼻孔吸入的**前鼻腔嗅觉**（orthonasal）。

<a id="headspace"></a>
**顶空**（英：headspace）——
杯中液面之上的那层气体空间。你闻到的其实是顶空里的浓度。
温度升高会提高挥发性成分的分压、从而提高顶空浓度——
这是**"酒温高香气冲"的物理基础**（第 1 章、第 42 章）。

<a id="matrix-effect"></a>
**基质效应**（英：matrix effect）——
同一浓度的香气分子，在不同液体里"跑出来"的比例不同。
酒精度尤其关键：乙醇作为溶剂会把一部分疏水性香气分子**留在液相**，
所以高酒精的酒有时香气反而"收着"。这也是为什么香气数据必须说明测定介质。

<a id="varietal-aroma"></a>
**品种香 / 一类香气**（英：varietal / primary aroma）——
来自葡萄本身（含以糖苷等形式存在的**香气前体**）的香气。
与之并列的是**发酵香（二类）**与**陈年香（三类）**（第 4 章）。
分层的意义在于：**有些香气可以被工艺造出来，有些不能**——这直接关系到定价。

## 缺陷与污染（第 1 章先认名字，第 31 章展开）

<a id="tca"></a>
**TCA · 2,4,6-三氯苯甲醚**（英：2,4,6-trichloroanisole, **TCA**）——
"木塞味"（cork taint）的主要责任分子，气味像湿纸板 / 潮湿地下室，
并会**压低**酒本身的果香。感知阈值极低（正文给数量级与来源）。
同类还有 TBA（三溴苯甲醚）等。

<a id="brett"></a>
**酒香酵母**（英：*Brettanomyces* / *Dekkera*，行业简称 **Brett**）——
一类可在酒中生长的酵母，产生**挥发性酚类**（如 4-乙基苯酚、4-乙基愈创木酚），
气味被描述为马厩、创可贴、烟熏、动物皮革。
⚠️ **它是"缺陷"还是"风格"取决于浓度与共识**，本书并列两种立场（第 31 章）。

<a id="so2"></a>
**二氧化硫 / 亚硫酸盐**（英：sulfur dioxide, **SO₂** / sulfites）——
酿酒中最重要的抗氧化与抗微生物添加物，在酒中以游离态与结合态共存，
有效形态比例强烈依赖 **pH**。总量有**法定上限**；多国要求酒标标注
"contains sulfites / 含亚硫酸盐"。其与头痛的关系见第 1 章辨析表（第 5 章展开）。

<a id="oxidation"></a>
**氧化**（英：oxidation）——
酒接触氧后的一系列变化：颜色变黄/变砖、果香减弱、出现坚果与苹果干气息。
适度氧化是某些风格（如部分雪莉、马德拉）的**刻意设计**，
过度则是缺陷——**同一化学过程，两种评价**，取决于是否可控、是否符合该酒的设计（第 17、18 章）。

## 感官通道与个体差异（第 2 章）

<a id="taste-receptor"></a>
**味觉受体**（英：taste receptors）——
味蕾中味觉受体细胞上负责识别甜、酸、苦、咸、鲜的分子机制的统称。
甜与鲜由 T1R 家族、苦由 T2R 家族介导；酸的关键在于质子通道（见下条）。
⚠️ 受体**分布在所有有味蕾的区域**（舌缘与舌背、软腭、咽），**不存在"分区专营"**；
但口腔不同位置的敏感度确有**小而显著**的差异。嘴唇、舌下、硬腭、颊内侧不产生味觉。

<a id="otop1"></a>
**Otop1 · 质子通道**（英：Otopetrin-1, OTOP1）——
被证明是**酸味**（对酸的味觉反应）所必需的质子通道：缺失它，味觉细胞与神经对酸刺激的反应消失。
它让"酸"成为五种基本味中机制较为明确的一项。

<a id="olfactory-receptor"></a>
**嗅觉受体**（英：olfactory receptors, **OR**；亦称气味受体 odorant receptors）——
嗅上皮细胞上的一大类 G 蛋白偶联受体，是人类基因组中最大的多基因家族。
人类**约有 400 个有功能的 OR 基因**，另有数量相当的**假基因**（已失效）。
嗅觉采用**组合编码**：一个分子激活多个受体，一个受体响应多类分子，
大脑读的是**激活模式**——所以"一个分子对应一种气味"是错的。

<a id="orthonasal"></a>
**前鼻腔嗅觉**（英：orthonasal olfaction）——
从鼻孔吸入气味分子的通路，即"闻杯子"时用的那条。
与[后鼻腔嗅觉](#retronasal)相对；两条路的气流、稀释与温度条件不同，**阈值可以不同**。

<a id="specific-anosmia"></a>
**特异性嗅盲**（英：specific anosmia）——
对**某一类分子**选择性地闻不到，而其余嗅觉正常。
它与嗅觉受体基因的个体差异直接相关（如 β-紫罗兰酮与 OR5A1、androstenone 与 OR7D4）。
⚠️ **定义性特征是"提高浓度也无效"**——这正是它与"阈值偏高"的区别，
也是判断一次感官分歧原因的关键测试。

<a id="trigeminal"></a>
**三叉神经（化学感觉通路）**（英：trigeminal system / chemesthesis）——
负责口鼻腔"辣、凉、刺、灼热"等化学刺激感受的躯体感觉系统。
人体实验显示：只麻醉味觉神经不影响涩感，**同时**阻断味觉与三叉神经支配才使涩感消失——
因此**涩主要走这条通路**。乙醇的灼热、二氧化碳的刺感同属此类。另见[化学感觉](#chemesthesis)。

<a id="prop-taster"></a>
**PROP 味觉者分型**（英：PROP taster status, **PTS**）——
按对苦味物质 **6-正丙基硫氧嘧啶（PROP）** 的敏感度把人分为无感者 / 一般味觉者 / 超级味觉者，
与 *TAS2R38* 基因型相关。⚠️ 它与葡萄酒感知的关系**证据不一致**：
有研究报告它与红酒的味觉/涩感**强度**相关，也有研究报告它对消费者的风味感知与接受度影响有限。
**"强度不同"与"判断更准"是两回事。**

<a id="fungiform-papillae"></a>
**菌状乳头**（英：fungiform papillae）——
舌前部含味蕾的乳头，密度的个体差异很大，常与 PROP 分型一起被用来讨论味觉敏感度差异。
⚠️ 密度与口腔反应性的关系在文献中仍有分歧。

<a id="cross-modal"></a>
**跨通道交互 · 气味诱导的甜味增强**（英：cross-modal interaction；
odour-induced sweetness enhancement, **OISE**）——
嗅觉信号改变味觉感知的现象：在**含糖量完全相同**的样品中，改变气味强度会改变甜度评分，
并呈**倒 U 形**（气味过强反而不再增甜）。
⚠️ 这意味着"**闻起来甜**"与"**有残糖**"是两栏，记录时必须分开写。

<a id="sensory-adaptation"></a>
**感官适应 / 感官疲劳**（英：sensory adaptation / fatigue）——
持续暴露于同一刺激时感知强度下降。嗅觉尤其明显，所以"一直贴着杯子闻"不是好方法；
正确做法是**短闻、间隔、再闻**。⚠️ **涩的方向相反——它会随每一口累积**，
因此连续品鉴必须留间隔并清口。

## 发酵与代谢（第 3 章）

<a id="redox-balance"></a>
**氧化还原平衡**（英：redox balance）——
酵母必须让 NADH 与 NAD⁺ 的收支相抵，糖酵解才能持续。
乙醛还原为乙醇是主要的 NAD⁺ 再生途径；但合成菌体会额外产生 NADH，
多出来的部分靠**生成甘油**来消耗——**这是甘油必然存在的根本原因**（另见[甘油](#glycerol)）。

<a id="ehrlich-pathway"></a>
**埃利希通路**（英：Ehrlich pathway）——
酵母利用氨基酸作氮源时的分解途径：**氨基酸 → 转氨 → α-酮酸 → 脱羧 → 还原 → 高级醇**。
酵母的目的是取得氮，高级醇是被丢出来的碳骨架。

<a id="higher-alcohol"></a>
**高级醇 / 杂醇**（英：higher alcohols / fusel alcohols）——
比乙醇碳链更长的一类醇，由[埃利希通路](#ehrlich-pathway)生成。
异戊醇、异丁醇等高浓度时呈溶剂样刺鼻气息；**2-苯乙醇**（来自苯丙氨酸）则是玫瑰 / 蜂蜜香。
它们同时是**乙酸酯的直接前体**——所以氮状况会连带改写酯的组成。

<a id="ester"></a>
**酯**（英：esters）——
年轻葡萄酒果香的主要化学载体，分两族：**乙酸酯**（乙酰辅酶 A + 高级醇，
由醇乙酰基转移酶 AATase 催化，代表是带香蕉气息的乙酸异戊酯）与
**脂肪酸乙酯**（中链脂肪酸 + 乙醇）。
⚠️ 酯化与水解**可逆**，所以瓶储中酯的组成会漂移——**年轻果香会淡去**。

<a id="yan"></a>
**可同化氮**（英：yeast assimilable nitrogen, **YAN**）——
葡萄汁中酵母能利用的氮，主要是铵盐与游离氨基酸。
不足会导致发酵变慢或中止并促进硫化氢生成；水平不同则改变高级醇与酯的比例。
需求量**因菌株而异**，本书不给推荐值。

<a id="stuck-fermentation"></a>
**发酵中止**（英：stuck fermentation；法：fermentation languissante）——
发酵在糖未耗尽时停止。常见诱因包括氮不足、温度失控、酒精毒性、营养缺乏等。
后果不只是残糖偏高，还包括微生物稳定性下降。

## 香气的三个来源（第 4 章）

<a id="fermentation-aroma"></a>
**发酵香 / 二类香气**（英：fermentation / secondary aroma）——
在酒精发酵与苹果酸乳酸发酵中由微生物生成的香气，主要是[酯](#ester)、
[高级醇](#higher-alcohol)、挥发性酸与双乙酰等。
⚠️ 它**相对可控、可重复**，因此作为溢价理由较弱；而且**年轻时最强、会随时间减弱**。

<a id="aging-aroma"></a>
**陈年香 / 三类香气**（英：ageing / tertiary aroma）——
在木桶熟成与瓶中陈年过程中生成或转化的香气。
两条来路要分清：**外来的（橡木，有廉价替代方案）**与
**内生的（时间与仓储换来的化学变化，难以伪造）**。

<a id="aroma-precursor"></a>
**香气前体**（英：aroma precursors）——
葡萄中不挥发、闻不到的结合态香气分子，最常见的是**糖苷结合态**
（单萜等）与**半胱氨酸 / 谷胱甘肽结合态**（品种硫醇）。
需经酶解或酸解释放才能被感知——**这就是"总量由葡萄决定、闻到多少由发酵决定"的原因**。

<a id="methoxypyrazine"></a>
**甲氧基吡嗪**（英：methoxypyrazines, **MPs**）——
一类含氮杂环化合物，带**青椒 / 草本**气息，代表是 **3-异丁基-2-甲氧基吡嗪（IBMP）**。
主要存在于果梗与果皮，随葡萄成熟而下降，且其下降与**苹果酸的分解高度相关**——
因此它同时是一个**成熟度信号**。

<a id="monoterpene"></a>
**单萜**（英：monoterpenes）——
十个碳的萜类，以**花香**为主要印象，在麝香系品种与雷司令等品种中含量较高。
常见的有芳樟醇、香叶醇、香茅醇、α-松油醇。在葡萄中大量以糖苷结合态存在。

<a id="norisoprenoid"></a>
**C13-降异戊二烯**（英：C13-norisoprenoids）——
由葡萄中**类胡萝卜素**裂解而来的一族香气分子，包括 β-大马士酮（果香、烤苹果）、
β-紫罗兰酮（紫罗兰、覆盆子）、[TDN](#tdn)（煤油）与维他斯品（桉叶、樟脑）。
它们横跨"一类"与"三类"：前体来自葡萄，但部分分子在陈年中才生成。

<a id="volatile-thiol"></a>
**挥发性硫醇 / 品种硫醇**（英：volatile / polyfunctional thiols）——
带**西柚、黄杨、百香果、柑橘皮**气息的一类含硫化合物，代表是 3-巯基己-1-醇（3MH）、
乙酸-3-巯基己酯（A3MH）与 4-巯基-4-甲基戊-2-酮（4MMP）。
⚠️ 它们在葡萄汁中**大量以结合态存在，必须靠酶作用释放**，
而酿酒酵母的释放效率并不高——**这是"同一片园子、不同酒庄差别巨大"的一个化学原因**。

<a id="tdn"></a>
**TDN · 1,1,6-三甲基-1,2-二氢萘**（英：1,1,6-trimethyl-1,2-dihydronaphthalene, **TDN**）——
雷司令陈年后"煤油 / 汽油"气息的责任分子，含量**依赖紫外线**，南北半球差异很大。
人类受体 **OR8H1** 被鉴定为其选择性受体。
⚠️ **同一分子在不同市场评价相反**：在澳大利亚常被视为加分项，在欧洲可能成为拒绝的理由。

## 二氧化硫、二氧化碳与"矿物感"（第 5 章）

<a id="molecular-so2"></a>
**分子态二氧化硫**（英：molecular SO₂）——
溶液中未解离的 SO₂ / H₂SO₃ 形式，是**抗菌活性的主力**。
它占游离 SO₂ 的比例由 **pH** 决定（pKa₁ ≈ 1.8）：pH 越高，有效形态越少。
⚠️ **法规管的是总量，酿酒师关心的是分子态**——所以"游离 SO₂ 是多少"脱离 pH 没有意义。

<a id="free-bound-so2"></a>
**游离 / 结合 / 总二氧化硫**（英：free / bound / total SO₂）——
**游离** = 分子态 + 亚硫酸氢根 + 亚硫酸根；**结合** = 已与醛、酮、糖、羧酸等结合而失活的部分；
**总量** = 二者之和，也是各法域限量与标注门槛所依据的指标。
⚠️ **"结合 SO₂" 至今没有被普遍接受的定义**，不同参考方法释放结合态的条件不同，
无法保证测的是同一批物质——因此本书不给游离/结合的比例数字。

<a id="minerality"></a>
**矿物感**（英：minerality；法：minéralité）——
近二十年高频出现的葡萄酒描述词。⚠️ **至今没有公认定义**：
对近一千七百名消费者的研究显示，不同经验层次的人所指完全不同
（矿物水的离子 / 风土概念 / 燧石味 / 酸度）；专业人士之间也找不到共识含义。
"**土壤矿物直接进入酒中**"的解释在地质学上讲不通（岩石无味、不易挥发、
酒中矿质元素常低于感知阈值）。
在夏布利所做的研究中，与该描述相关的是**甲硫醇等挥发性硫化物**，
且差异只在**前鼻腔嗅闻**条件下出现。
**本书的用法：把它当成一个待拆解的词，追问对方指的是哪一种。**

## 方法与法规基础词（第 4、19、20 章展开）

<a id="oiv"></a>
**OIV · 国际葡萄与葡萄酒组织**（法：Organisation Internationale de la Vigne et du Vin；
英：International Organisation of Vine and Wine）——
政府间组织，发布分析方法汇编、酿酒规范与全球统计，是本书数值的首要引用来源之一。

<a id="pdo-pgi"></a>
**PDO / PGI · 原产地保护 / 地理标志保护**（英：protected designation of origin /
protected geographical indication）——
欧盟统一的两级地理标志框架。各成员国的传统名称（法国 AOC、意大利 DOC/DOCG、
西班牙 DO/DOCa 等）在这个框架下各自对应其中一级（第 19 章）。

<a id="iso-3591"></a>
**ISO 3591 品酒杯**（英：ISO 3591 wine-tasting glass；业内称"ISO 杯"）——
国际标准化组织定义的标准品酒杯形状与尺寸，用于让不同场合的感官评价条件可比。
本书凡涉及"标准条件下"的香气描述，默认指这类杯型（登记见[出处与资料登记](standards.md)）。
