# 第 38 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：在欧盟规则中，gin 可以通过加香获得以杜松为主导的风味；distilled gin 则要求乙醇与杜松及天然植物材料共同蒸馏，单纯加香的 gin 不能称为 distilled gin。前者是较宽的名称，后者是有额外生产要求的名称。

<a id="q2"></a>
## Q2

**答**：它不说明一定在伦敦生产，也不说明必然更贵、更好喝或更适合某一杯调酒。它首先说明的是欧盟定义下的生产、着色与甜化条件。

<a id="q3"></a>
## Q3

**答**：可改写为：过滤了什么、用什么滤材、每次怎样处理、是否有成分或分析数据？水在生产中处于什么环节？“纯净”在适用市场是否有定义？它是原味还是调味版？这些问题比把宣传词直接当事实更可核查。
