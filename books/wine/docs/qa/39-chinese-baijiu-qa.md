# 第 39 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：香型能告诉你该查哪些产品标准，并提供有限的风格线索；但生产者、批次、保存状态和人的感知都不同。品鉴记录才把某次样品的感受变成可比较的信息。

<a id="q2"></a>
## Q2

**答**：它描述的是生产路径中的物料状态，不是从低到高的品质尺。品质和是否适合饮用者还取决于合规、信息透明度、保存与实际风味。

<a id="q3"></a>
## Q3

**答**：逐项拆开：查标准号是否现行、"特级"是否有可适用的规范或标签依据、"纯粮"指向何种可见配料与工艺信息、"无勾调"到底指什么。无法获得原始标签、标准或生产者说明的词，应保留为营销或待核陈述。
