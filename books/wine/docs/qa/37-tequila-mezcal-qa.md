# 第 37 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：它直接说明 Tequila 的糖分只能来自蓝色龙舌兰。它并不自动证明无添加、风味更好、年份更长，或适合所有饮用者；这些仍要按具体标签和适用规则核实。

<a id="q2"></a>
## Q2

**答**：`Artesanal` 描述的是 NOM-070 下允许的生产路径和设备边界，不是感官评分或品质等级。原料、批次、操作、保存状态与个人偏好都仍会改变评价。

<a id="q3"></a>
## Q3

**答**：至少要核实它是否使用受保护名称、生产地是否在相应原产地范围、`ancestral-style` 是否是受规范术语而非营销措辞、`aged` 具体适用哪套规则和多久，以及生产者与批次信息。单靠三个英文词不足以把它归入 Tequila 或 Mezcal 的任何法定类别。
