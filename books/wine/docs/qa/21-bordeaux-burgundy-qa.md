# 第 21 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：波尔多常见的历史分级主要以酒庄为对象，勃艮第的常见层级则更强调 AOC 与地块。两者都还必须与生产者、年份和具体酒款一起读，不能把名称相同的“等级”当成可直接横比的分数。

<a id="q2"></a>
## Q2

**答**：AOC 是法律地理与生产规范框架；历史分级是特定体系下的声誉/分类信号；市场价格还受稀缺、品牌、年份和渠道影响。三者会相关，但没有一条能单独推出另两条。

<a id="q3"></a>
## Q3

**答**：先看到“Climat”只说明其可能在使用勃艮第地块术语，不能推出特级园或品质。应要求 AOC、生产者/装瓶者与年份，再查该名称究竟是地块、品牌还是营销表述；信息不足时不接受“特级品质”作为可核验结论。
