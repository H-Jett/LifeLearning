# 第 23 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：DOCG 首先说明法律来源与控制框架；从这里到“好喝”还隔着具体 disciplinare、年份、生产者、酒款状态和饮用者偏好，不能跳过。

<a id="q2"></a>
## Q2

**答**：陈年等术语由具体称谓的产品规范定义。即便词面相同，不同产区的允许品种、最低时间、容器或其他条件也可能不同，必须逐个核验。

<a id="q3"></a>
## Q3

**答**：IGT 是地理标志框架，不是“低等级餐酒”的同义词。应先查该 IGT 的规范、品种与生产者，再比较具体酒款；不能从缩写本身推出感官品质或价值。
