# 第 3 章 思考题参考答案

<a id="q1"></a>
## Q1

**问**：为什么 1 g 糖最多只能产 0.511 g 乙醇？剩下的去了哪？
估算 220 g/L 糖完全发酵每升放出多少升二氧化碳。

**答**：

**为什么是 0.511**：化学计量决定的。一分子葡萄糖（摩尔质量 180.16）
生成两分子乙醇（各 46.07）与两分子二氧化碳（各 44.01）：

```
乙醇质量分数 = 2 × 46.07 / 180.16 ≈ 0.511
CO₂  质量分数 = 2 × 44.01 / 180.16 ≈ 0.489
0.511 + 0.489 = 1.000 ✓
```

**剩下的 0.489 就是二氧化碳**——它以气体形式跑掉了。
（注意：这只是**主干反应**的账。实际上碳还要分给菌体、甘油、有机酸、高级醇与酯，
所以真实的乙醇产率**低于** 0.511。）

**CO₂ 体积估算**（写清假设）：

假设：① 糖全部发酵完；② 只按主干反应计（这给出的是**理论上限**）；
③ 气体在 20 ℃、101.325 kPa 下视作理想气体。

```
CO₂ 质量 = 220 g/L × 0.489 ≈ 107.6 g/L
物质的量  = 107.6 ÷ 44.01 ≈ 2.445 mol/L
摩尔体积  = RT/P = 8.314 × 293.15 ÷ 101325 ≈ 0.02405 m³/mol = 24.05 L/mol
体积      = 2.445 × 24.05 ≈ 59 L
```

**约 59 升气体，每升葡萄汁。** 实际略低于此，因为部分碳去了支路。

> **要带走的判断**：这个数字的意义不在酒里，在**酒窖里**。
> 二氧化碳比空气重，会在地面、罐内、地坑积聚。
> 一个 5 000 L 的罐在发酵期要放出约 **300 立方米**气体——
> 这就是为什么发酵季的酒窖是需要通风与监测的作业环境。

<a id="q2"></a>
## Q2

**问**：甘油为什么"必然"产生？从氧化还原收支解释。它的第二个作用是什么？

**答**：

**第一性原理：NADH 必须被还回 NAD⁺。**

- 糖酵解（EMP 通路）在把葡萄糖变成丙酮酸的过程中会**产生 NADH**；
- 酒精发酵的最后一步——**乙醛还原成乙醇**——正是用来消耗这些 NADH、
  把 NAD⁺ 再生出来的。理论上这一对刚好平账；
- **但酵母还要合成自己的菌体**，而合成代谢会**额外产生 NADH**。
  于是出现了一笔"多余的还原力"；
- 这笔多余的 NADH 必须找到别的出口，否则糖酵解就会因为缺 NAD⁺ 而停下来。
  **出口就是甘油**：磷酸二羟丙酮经甘油-3-磷酸脱氢酶（Gpd1p / Gpd2p）还原，
  每生成一分子甘油消耗一分子 NADH。

有直接的实验支持这条逻辑：在缺氧、呼吸能力缺失的条件下，
酵母细胞**严格依赖 Gpd2p** 才能生长；而补加乙偶姻（acetoin，另一个 NADH 的去处）
可以**逆转**这种生长抑制（*J. Biol. Chem.* 2004）——
这说明"甘油通路"真的是在干"处理多余 NADH"这件事。

**第二个作用：渗透压保护。** 高糖的葡萄汁对酵母是一个**高渗环境**，
甘油是酵母常用的相容性溶质。

**量级**：代谢工程文献给出的参考是，酵母生产乙醇时
**约 4~5 % 的碳源被用于生成甘油**（⚠️ 该陈述的语境是工业乙醇发酵，不是葡萄酒）。

> **要带走的判断**：甘油不是酿酒师"做出来"的东西，
> 而是**发酵这件事在化学上必然的伴生物**。
> 所以"我们的工艺让甘油特别高"这类说法，要问的是"**高多少、怎么测的**"，
> 而不是"你们怎么做到的"。

<a id="q3"></a>
## Q3

**问**：①"甘油让酒变稠"能不能说？②"甘油带来甜感"能不能说？为什么证据强度不同？

**答**：

**① "甘油让酒变稠"——不能说。** 有两条独立证据都指向"不成立"：

- Noble & Bursick 1984 给了量化理由：黏度的**差别阈**约 **0.141 mPa·s**，
  而要靠甘油达到这个增量需要加 **25.8 g/L**；酒里常见的甘油是 **1.0~9.0 g/L**。
  也就是说，酒中甘油含量的正常波动**根本够不到人能察觉的黏度变化**。
- Gawel & Waters 2008 做了一个更干净的实验：先用**匙羹藤**与**甜味等化**
  两种方法把甘油自带的甜味屏蔽掉（否则品评者会用甜度线索来"猜"黏度），
  然后加 **6 g/L** 甘油——**感知黏度没有提高**。
  作者的结论直接写着：不能靠提高甘油来增强干白的口感黏度。

**② "甘油带来甜感"——只能有条件地说，本书标 ⚠️ 有争议。**

- 支持方：Noble & Bursick 1984 测到甜度的**差别阈**是 **+5.2 g/L**，
  并据此认为在酒中常见浓度下，甘油的**主要**感官贡献就是甜；
- 不支持方：Gawel 等 2007 在三款雷司令上把甘油设为 5.2 / 7.2 / 10.2 g/L，
  发现**酒精和甘油都没有一致地影响甜度评分**。

**为什么两个答案的强度不一样？** 关键在于**问的问题不同**：

| | 1984 年测的 | 2007 年测的 |
|---|---|---|
| 问题 | **差别阈**：加多少才**察觉得到变化** | **强度评分**：在给定的三个水平上打多少分 |
| 方法 | 配对比较 | 描述性评分 |
| 因此 | 回答"甘油**能不能**影响甜" | 回答"在这几个水平上甘油**有没有**影响评分" |

两种设计对同一个现象的敏感度不同，所以结论不一致**不必然是矛盾**。
本书的做法是**并列写出来，不裁决**——这正是"⚠️ 有争议"这个标记的用途。

> **要带走的判断**：两个"结论相反"的研究，先看**它们问的是不是同一个问题**。
> 很多"学界还有争议"其实是"两组人测的是两件事"。

<a id="q4"></a>
## Q4

**问**：高级醇来自哪条通路、以什么为原料？为什么说葡萄园的氮状况会改写酒的香气？

**答**：

**通路**：**埃利希通路（Ehrlich pathway）**。
**原料**：**氨基酸**（尤其是支链氨基酸与芳香族氨基酸）。

**三步**：

```
氨基酸 --转氨--> α-酮酸 --脱羧--> 醛 --还原--> 高级醇
          ↑
     氨基被"抠"下来，
     用于酵母的同化反应（这才是酵母的真正目的）
```

也就是说：**酵母的目的是拿氮，高级醇是把碳骨架丢出来的副产物。**

典型对应：亮氨酸 → 异戊醇；异亮氨酸 → 活性戊醇；缬氨酸 → 异丁醇；
**苯丙氨酸 → 2-苯乙醇（玫瑰 / 蜂蜜香）**。

**为什么葡萄园的氮状况会改写香气**，链条有三段：

1. **葡萄园的氮素状况** → 决定葡萄汁里的**可同化氮（YAN）**（铵盐 + 游离氨基酸）；
2. **YAN 的多少与构成** → 决定酵母走多少埃利希通路、产生哪些高级醇；
3. **高级醇** → 又是**乙酸酯**的直接前体（AATase 把乙酰辅酶 A 接到高级醇上）。
   所以氮不只改高级醇，**连带改酯**。

另外两个方向的后果：

- **YAN 太低** → 发酵变慢或**中止**，并促使酵母产生 **H₂S（臭鸡蛋味）**；
- **YAN 水平不同** → 已有研究观察到乙酸酯、芳樟醇、橙花醇的表现都不同。

> **要带走的判断**：香气不是"葡萄里本来有多少就有多少"。
> **葡萄园 → 汁的氮 → 酵母代谢 → 香气**这条链，
> 是第二部分（品种与风土）和第三部分（酿造）之间最实在的一座桥。

<a id="q5"></a>
## Q5

**问**："降温到 12.5 ℃ 所以更果味"——哪一步是化学事实，哪一步是未证明的推断？

**答**：

**是化学事实的部分**：降温**确实**改变了香气成分的组成。
Deed 等 2017 在两批马尔堡长相思上、用四株酵母做了 12.5 ℃ 与 25 ℃ 的对照，
定量了 32 个香气化合物，其中 **14 个**驱动了差异：
12.5 ℃ 的酒**3-巯基己醇（3MH）与高级醇更低**，但**果味的乙酸酯更高**。

**是未被证明的推断**：从"成分变了"跳到"**喝起来更果味**"。
同一项研究的感官结果是：

- **75 % 的酒对**，评价组**没有**测到果味的显著差异；
- 剩下 **25 %** 有显著差异的酒对里，**25 ℃ 发酵的反而更果味**，
  且高果味与 **3MH** 相关（而 3MH 恰恰是低温组更低的那个）。

作者据此提出：低温的好处**可能不在"更果味"，而在"果味与青味的平衡更好"**；
并且既然多数酒对没有显著差异，**提高发酵温度或许可以在不损害品质的前提下省电**。

**所以这句话应该怎么说才站得住**：

> "我把发酵温度降到 12.5 ℃。已发表的对照实验显示这会改变香气成分的组成
> （乙酸酯更高、3MH 与高级醇更低），但同一实验里多数酒对的果味强度
> **没有**显著的感官差异。我的选择是基于风格平衡的判断，不是基于'一定更果味'。"

⚠️ **反向也别过度解读**：这是**一个品种、两批汁、四株酵母**的结果，
不能推广成"发酵温度无所谓"。

> **要带走的判断**：**"成分变了" → "感受变了"中间有一道感官实验的门槛。**
> 酒类宣传里最常见的偷渡，就是从门这边直接走到门那边。

## Q6

**问**：指出这段产品页文案至少五处问题，并给出三个追问。

> *"南意大利产区，传统干法加糖工艺提升糖度，自然发酵不加任何酸，
> 甘油含量高达 12 g/L 带来丝滑稠厚口感，酒精度 15 % vol 体现酿造功力。"*

**答**：问题至少**六处**。按"看到什么 → 推出什么"排：

1. **"南意大利 + 干法加糖"** → **与法规直接冲突**。
   (EU) No 1308/2013 Annex VIII Part I, B.3 规定：干法加糖（dry sugaring）
   只允许在 A 区、B 区，以及 C 区中**除希腊、西班牙、意大利、塞浦路斯、葡萄牙
   以及法国若干上诉法院辖区之外**的地方。
   **意大利的葡萄园在被排除之列**，而条文里给出的"国家主管机关可例外授权"
   只针对**法国**的那几个辖区。所以"南意大利传统干法加糖"是一句**说不通的话**。
2. **"不加任何酸"被当成卖点** → **把法定允许的操作污名化**。
   增酸在 C I / C II / C III(a) 区是允许的，上限（葡萄酒）**2.50 g/L**（以酒石酸计）。
   在南意大利这样的暖产区，增酸是**常规工具**而不是造假。
3. **"干法加糖 + 不加酸"这个组合本身也值得追问** → 法规里
   **增酸与增浓是互斥的**（除非委员会给出豁免）。
   文案同时强调了"提升糖度"和"不加酸"，虽然不直接矛盾，
   但说明写文案的人**并不知道这两件事在法规里是一对**。
4. **"甘油 12 g/L 带来丝滑稠厚口感"** → **❌ 归因错误**。
   黏度差别阈约 0.141 mPa·s，靠甘油达到需要 **+25.8 g/L**；
   屏蔽甜味后 +6 g/L 甘油**未提高**感知黏度。
   12 g/L 是一个在酒里偏高但并不离谱的数（第 1 章有 14.9 g/L 的个案），
   **它不能撑起"稠厚"这个结论**。
5. **"15 % vol 体现酿造功力"** → **❌ 明确错误**。
   酒精度主要是**采收糖度**的后果（第 1 章的换算：约 240~270 g/L 糖的量级），
   再叠加法规允许的增浓额度。它是**气候与采收决策**的信息，不是技艺指标。
   而且在 C 区，增浓上限只有 **1.5 % vol**，
   这意味着 15 % vol 的绝大部分必须来自**葡萄本身**。
6. **整段没有一个可核查项**：没有产区层级（DOC/DOCG/IGT）、没有品种、
   没有年份、没有残糖与总酸。**唯一像硬数据的两个数字（甘油、酒精度）
   都被用来支撑站不住的结论。**

**三个追问（每问一句都能定性）**：

1. "**你们是哪个种植区？酒标上的产区层级怎么写的？**"
   ——这一问同时检验"干法加糖"这句话，因为增浓额度与加糖方式都按区划分。
2. "**总酸是多少、以什么计？做过增酸吗？**"
   ——暖产区最该问的就是酸；对方答不上"以什么计"就说明数字不是自己的。
3. "**15 % vol 里有多少来自增浓？采收时的糖度是多少？**"
   ——这一问把"功力"转成可核查的采收数据。

> **要带走的判断**：这段文案的毛病和第 1 章那段电商文案是**同一类**——
> **数字大多是真的，因果全是编的**。
> 而这一次多了一层：它还**踩到了法规**。产区 + 工艺的组合，是可以直接核对的。

## Q7

**问**：甲（12.0 % vol，甘油 9.5 g/L）与乙（13.8 % vol，甘油 6.0 g/L），
"甲甘油更高所以更厚"站不站得住？你预期哪支更重？

**答**：

**这句话站不住。** 逐项核对：

**① 甘油的差距：9.5 − 6.0 = 3.5 g/L。**

- 这个差距**低于**甜度差别阈（+5.2 g/L，Noble & Bursick 1984）；
- 更是**远低于**黏度差别阈所需的加量（+25.8 g/L）；
- 而 Gawel & Waters 2008 在屏蔽甜味后加 6 g/L 都没测到黏度变化。

**结论：3.5 g/L 的甘油差，预期在口感上察觉不到。**

**② 酒精的差距：13.8 − 12.0 = 1.8 % vol。**

- 这个跨度和 Gawel 等 2007 用的范围（11.6 / 12.6 / 13.6 % vol，跨度 2.0 % vol）**几乎一样**；
- 那项研究在**三款酒上全部**测到"酒精 ↑ → 热感 ↑"，
  并在**三款中的两款**上测到 body 与感知黏度升高；
- 再加上第 1 章的黏度实测（水基 0.89~0.92 → 含酒精模型液 1.38~1.41 → 红酒 1.53~1.57 mPa·s），
  **酒精对黏度的物理贡献是有数字的**。

**所以预期：乙（13.8 % vol）更可能显得更重、更热、body 更足**，
尽管它的甘油更低。

**但要诚实标注三个限制**：

1. 两支酒还有**别的差异**（残糖、总酸、干浸出物、酚类），
   技术资料只给了两项，不足以完全解释 body；
2. 2007 年的研究里 body 只在**三款中的两款**上随酒精升高——**不是百分之百**；
3. 这是**预期**，不是结论。要确认，需要**同杯型、同温度、同量、盲测**（本章实操四）。

> **要带走的判断**：当销售拿两个数字讲因果时，先做一次**"这个差距够不够大"**的检查。
> 很多说法不是方向错了，而是**差距根本没到人能察觉的门槛**。
> 这个检查只需要一个数：**差别阈**。

## Q8

**问**：查 (EU) No 1308/2013 Annex VIII Part I，回答种植区、增浓上限、是否允许干法加糖。

**答**：这是**查证题**，考的是过程。下面是本书自己做这道题的结果与经验。

**本书查到了什么（截至 2026-09-13）**：

- **Annex VIII Part I 全文已读**。其中：
  - **A.2 增浓上限**：A 区 **3 % vol**、B 区 **2 % vol**、C 各区 **1.5 % vol**；
    A.3 允许在气候特别不利的年份**再加 0.5 %**（需委员会批准）；
  - **B.3 干法加糖的地理范围**：只允许在 A 区、B 区，以及 **C 区中除希腊、西班牙、意大利、
    塞浦路斯、葡萄牙，以及法国 Aix-en-Provence、Nîmes、Montpellier、Toulouse、Agen、Pau、
    Bordeaux、Bastia 等上诉法院辖区内的葡萄园之外**的区域；
    **法国的上述辖区可由国家主管机关例外授权**；
  - **B.6 增浓后总酒精度上限**：A 区 11.5、B 区 12、C I 12.5、C II 13、C III 13.5 % vol；
    **B.7 例外**：红葡萄酒在 A 区可提至 12、B 区可提至 12.5 % vol；
    成员国还可为**带原产地名称**的酒另定上限。

- **但种植区（A / B / C I / C II / C III）的具体地理界定不在 Annex VIII 里**，
  而在 **Annex VII 的附录（Appendix I）**。**本书本轮没有逐条核对这份地理清单**，
  因此正文中**没有写"某国属于某区"这类断言**（只复述了法规明确点名的排除国家名单）。

**所以本书的诚实结论是**：

> **增浓与加糖的"规则"已核到原文；"某个具体产区属于哪一区"本书尚未核对。**
> 这条待办已记入[出处与资料登记](../standards.md)。

**这道题真正要教的三件事**：

1. **法规是分层的**。数字在一个附件里，地理界定在另一个附件里——
   **只读到一半就写结论，是酒类内容里最常见的错误来源**。
2. **"被排除的名单"往往比"被允许的范围"更好用**。
   B.3 直接点名了五个国家和八个法国辖区，
   这比去推断"某地属于哪个区"可靠得多——**先用硬名单，再用推断**。
3. **注意条文里的"但是"**。法国那几个辖区被排除，**紧接着就是一句例外授权条款**。
   漏掉这一句，你会得出一个过于绝对的结论。
   **法规里的例外条款，往往就是行业真实做法所在。**

> **要带走的判断**：**读法规要读到"例外"为止。**
> 只读主条款就下结论，跟只读摘要不读方法一样不可靠。
