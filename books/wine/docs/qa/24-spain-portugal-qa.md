# 第 24 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：传统术语的使用受具体 DOP 与产品规范约束；不同产区、颜色和类别可有不同条件。Rioja 的规则只能证明 Rioja 标签所作的承诺。

<a id="q2"></a>
## Q2

**答**：它通常表达受 IVDP 类别体系认可的木桶陈年风格/成熟度，可来自不同年份酒的调配；不是逐滴酒液的出生证明。

<a id="q3"></a>
## Q3

**答**：先区分它是带年龄 Tawny、Colheita 还是其它类别；查 IVDP 的定义、标签上的年份和装瓶信息。年龄词本身不足以证明整瓶酒一直以同一状态存放了 40 年。
