# 一道菜的处理方案表

> **这是全书的核心工具。** 它把"我该怎么做这道菜"拆成六步，
> 每一步都对应[四条线](../chapters/01-four-lines/01-what-happens-in-a-dish.md)里的一条或几条。
>
> 用法：**动手之前**填前五栏（5 分钟就够），做完填第六栏「复盘」。
> 目标不是填得漂亮，而是让你在开火前就发现"我还没想清楚哪一步"。

## 0. 先回答一个问题（最重要的一栏）

| 问题 | 我的答案 |
|------|---------|
| 我要把**什么**变成**什么**？（一句话，说状态不说菜名） | 例：把硬的带筋牛腩，变成软糯能挂汁的块 |

> 这一栏答不出来，后面全是瞎填。"做个红烧肉"不是答案，
> "把五花肉的皮和筋变软、脂肪部分融出来、表面有褐色和甜味、汤汁能挂住"才是答案。

## 1. 食材盘点（四条线里的"水"和"热"从这里开始）

| 食材 | 含水多还是少？ | 主要成分是什么？（瘦肉 / 带筋 / 淀粉类 / 叶菜 / 蛋奶） | 成熟需要的时间：长还是短？ | 它怕什么？ |
|------|--------------|---------------------------------------|------------------|-----------|
| | | | | 例：蛋怕久（窗口窄）；叶菜怕出水；带筋肉怕快 |
| | | | | |
| | | | | |

> **填这一栏时问自己**：这些食材的"需要时间"差多少？
> 差得多，就必须**分开处理**或**分批下锅**——这是最常见的失败原因之一。

## 2. 预处理（解决什么问题？解决不了就别做）

| 预处理动作 | 我想解决的**具体**问题 | 它属于哪条线 | 代价是什么 | 真的需要吗？ |
|-----------|-------------------|------------|-----------|------------|
| 例：焯水 | 去血沫与异味 / 对齐成熟时间 / 定色 | 水（溶出）+ 热 | 水溶性成分流失 | |
| 例：腌 / 上浆 | 保水、让表面先形成保护层 | 水 + 味 | 多一步、多一个碗 | |
| 例：擦干表面 | 让表面能升到褐变需要的温度 | 热 + 水 | 无 | |
| | | | | |

> **判据**：如果你说不出这一步解决什么问题，它大概率可以省。
> 菜谱里的步骤不是都必需的——有些只是那位作者的习惯。

## 3. 技法选择（哪条线是主要手段？）

| 问题 | 我的答案 |
|------|---------|
| 主要手段是哪条线？（热 / 水 / 味 / 时间） | |
| 选哪种技法？（炒 / 煎 / 炸 / 蒸 / 煮 / 炖 / 烤 / 拌） | |
| 为什么是它？（用上面第 0 栏的目标来解释） | |
| 需要**几段**加热？（例：先煎上色再炖 = 两段） | |
| 我的锅具与火力够吗？不够怎么绕？ | 例：锅小 → 分两次炒；火弱 → 减量、延长预热 |

> **一条经验判据**：**要不要褐变（香味与颜色）**，基本决定了要不要"干、热、高于水沸点"的阶段；
> **要不要软烂（筋、皮、纤维）**，基本决定了要不要"长时间、不要大滚"的阶段。
> 两个都要，就是两段——顺序通常是**先褐变，后软烂**。

## 4. 调味顺序（什么时候加，比加多少更容易出错）

| 加什么 | 什么时候加 | 为什么是这个时机 | 加多少（先少后补） |
|-------|-----------|----------------|-----------------|
| 例：盐（第一次，结构性） | 下锅前 / 腌的时候 | 对水下命令（出水、保水），不是为了定味 | |
| 例：需要爆香的（葱姜蒜、花椒、豆瓣） | 油温上来后、食材前 | 要靠热把香气激发出来 | |
| 例：需要加热转化的（糖色、酱油、酒） | 加热阶段 | 上色、去腥、增香都要时间和温度 | |
| 例：盐（第二次，定味） | 快出锅前尝过之后 | 只有在接近成品的浓度下，咸淡才判断得准 | |
| 例：怕挥发的（香油、香菜、鲜柠檬汁、白胡椒） | 关火后 | 一加热就跑 | |

> **默认规则**（可迁移）：
> **靠加热才起作用的先放，一加热就没了的最后放，定味的放在"尝过之后"。**

## 5. 火候与时间（把玄学变成可记录的东西）

| 阶段 | 火力（大/中/小） | 现象判据（看什么、听什么、闻什么） | 计划时间 | 实际时间 |
|------|---------------|--------------------------------|---------|---------|
| 预热 | | 例：滴水成珠 / 油面开始轻微波动 | | |
| 阶段一 | | 例：肉表面变色、贴锅面有声 | | |
| 阶段二 | | 例：汤汁微微冒泡但不大滚 | | |
| 收尾 | | 例：汤汁能挂住勺背 | | |

> **为什么要记"现象判据"而不只是时间**：你家的灶、锅、食材量都和菜谱作者不同，
> **时间不可移植，现象可移植**。

安全相关的那一格单独列出来，不要和口感混在一起：

| 安全项 | 我怎么确认 |
|-------|-----------|
| 生肉 / 生禽 / 生蛋是否达到所在地要求的中心温度？ | 例：用温度计测最厚处（不能只看颜色） |
| 生熟是否分开（刀、板、盘、手）？ | |
| 做完后是否在规定时间内冷藏？ | |

> ⚠️ 具体数字请用**自己所在地现行官方指引**；本书用到的来源见[出处登记](../standards.md)，
> 各国口径不同这件事本身在第 1 章与第 42 章都会讲。

## 6. 复盘（最值钱的一栏）

| 问题 | 我的答案 |
|------|---------|
| 结果和第 0 栏的目标差在哪？（说状态：太干 / 太淡 / 没上色 / 太烂） | |
| 差的那一项，属于哪条线？ | |
| 如果只允许改**一个**参数，改什么？ | |
| 下次先做的那一个动作是什么？ | |

> **只改一个参数**这条约束很重要：一次改三样，你永远不知道是哪一样起了作用。
> 这也是第四部分所有对照实验的设计原则。

## 一张填好的示例（番茄炒蛋）

仅作示例，参数按自己的锅和火力调整。

| 栏位 | 填写 |
|------|------|
| **0 目标** | 蛋是大块嫩滑（不老不散），番茄出了汁但没化成泥，汤汁能挂在蛋上，整体有咸有一点甜 |
| **1 食材** | 蛋：窗口窄、怕久；番茄：含水极多、一加热就出汁 |
| **2 预处理** | 蛋液打散 + 少量盐（结构性，让蛋液均匀）；番茄切块（大小决定出汁速度） |
| **3 技法** | 主手段＝热；**两段**：先炒蛋（要高温短时）→ 盛出 → 炒番茄出汁 → 合并 |
| **4 调味顺序** | 盐分两次（蛋液里一点 + 合并后尝完补）；糖在番茄出汁后加（调整酸感）；葱花关火后放 |
| **5 火候** | 蛋：中大火、油面波动后下蛋液，凝固大半即翻动、立刻出锅；番茄：中火到出汁、汁略收 |
| **6 复盘** | 例：蛋偏老 → 属"热/时间" → 下次只改一项：蛋液下锅后**提前 10 秒**出锅 |
