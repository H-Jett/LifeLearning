# 术语表

> 中文 + 英文原词 + 一句"它在厨房里具体指什么"。
> 英文原词很重要——食物科学的资料多是英文的，你得能把厨房里的说法和资料里的词对上。
>
> 每个词条前有显式锚点（`<a id="...">`），所以正文和答案册都能直接跳过来。
> 按**四条线 + 安全 + 中式工艺**分组，随章节推进增补。

## 热：传热与温度

<a id="conduction"></a>
**导热（conduction）**——热量在**互相接触**的物体内部或之间传递。
厨房里：锅底 → 食材接触面 → 食材内部，全靠导热。
它解释了为什么"贴着锅的那一面先熟"、为什么厚的肉需要更长时间。

<a id="convection"></a>
**对流（convection）**——靠**流动的液体或气体**把热量带到食材表面。
厨房里：沸水、蒸汽、油锅里的油、烤箱里的热风都是对流。
流动越快，热量送到表面的速度越快——这就是为什么搅动能加快加热、也能让受热更均匀。

<a id="radiation"></a>
**辐射（radiation）**——不需要介质，靠电磁波直接传热。
厨房里：炭火、明火的火焰、烤箱上方的加热管、烧烤架。
它的特点是**只加热"看得见"的那一面**，所以需要翻面。

<a id="htc"></a>
**换热系数（heat transfer coefficient, h）**——描述"每平方米表面、每度温差、
每秒能把多少能量送到食材表面"的工程量，单位 W/(m²·K)。
厨房里：它决定"同样的温度，谁烫得更快"。
食品建模文献里用到的取值量级：静止空气约 8、强制热风/气炸约 100、平底锅接触约 200。
⚠️ 这些是**模型取值**而非实测汇编，不同研究差别很大，**只能看量级**。

<a id="latent-heat"></a>
**汽化潜热（latent heat of vaporization）**——把液态水变成水蒸气所需的能量，
不伴随温度上升。文献取值约 **2.26 × 10⁶ J/kg**。
厨房里：它是"表面有水就上不了色"的定量原因——
蒸发 1 kg 水所需的能量，约等于把这 1 kg 水升温 540 °C。
反过来，**蒸汽冷凝时会把这份能量原样放出来**，所以蒸的传热很猛。

<a id="specific-heat"></a>
**比热容（specific heat capacity）**——让单位质量的物质升高 1 °C 所需的能量。
水约 4.1~4.2 kJ/(kg·K)，在常见物质里很高。
厨房里：它解释了水"难烧开也难凉"，也是"汽化潜热 ÷ 比热容 ≈ 540"这个比较的分母。

<a id="microwave-heating"></a>
**微波加热（microwave heating）**——微波让食物里的水分子振动，
分子间的摩擦产生热量。家用微波炉常见频率 2450 MHz。
⚠️ **它不是"从里往外"加热**：美国 FDA 明确表述，较厚的食物由微波加热**外层**，
**内部主要靠从热的外层导热进去**。所以厚的东西仍要切小、摊开、翻动、静置。

<a id="maillard"></a>
**美拉德反应（Maillard reaction）**——**氨基酸与还原糖**在受热时发生的一系列反应，
生成褐色物质（类黑精）和大量香气分子。
厨房里：肉的焦褐外壳、面包皮、煎出来的"锅气"香味，主要都是它。
关键条件是**表面足够干、温度足够高**；碱性条件会加快它。
⚠️ 常见的"从 140~165 °C 开始"这个数字**缺乏可靠一手出处**，本书只写方向不写数字。

<a id="caramelization"></a>
**焦糖化（caramelization）**——**糖单独**受热分解并聚合成褐色物质的过程，
不需要氨基酸参与。厨房里：炒糖色、焦糖布丁表面的那层。
与美拉德反应常同时发生，但它们是两件事。

<a id="denaturation"></a>
**蛋白质变性（protein denaturation）**——蛋白质在受热（或遇酸、遇盐）时
原本折叠好的结构散开、然后互相缠结成网。
厨房里：蛋白由透明变白、肉由软变紧、奶被"点"成豆花，都是变性加凝聚。
**它基本不可逆**——这是"过了就回不来"的物理原因。
⚠️ 变性温度**不是固定值**：浓度、盐、pH、升温速率都会移动它。
纯蛋白在实验室测得的变性温度（例如卵白蛋白在水中约 80 °C）
往往高于同一蛋白在真实食物体系里开始变稠的温度（全蛋液在 60 多 °C 就有明显变化）。

<a id="collagen-gelatin"></a>
**胶原与明胶（collagen / gelatin）**——胶原是结缔组织（筋、膜、皮）的主要蛋白质，
生的时候又韧又硬；在**足够高的温度下持续足够长的时间**，它会转化成明胶，
口感变成软糯、汤汁变得黏稠挂嘴。
厨房里：牛腩、猪蹄、鸡爪炖久了"软烂出胶"，就是这件事。
这是**硬部位与嫩部位需要完全不同加热策略**的根本原因。

<a id="gelatinization"></a>
**淀粉糊化（starch gelatinization）**——淀粉颗粒在**有水且受热**时吸水膨胀、
结构崩解，把液体变稠。
厨房里：米饭变软、面条煮熟、勾芡变亮变稠、土豆变粉，都是糊化。
糊化温度**随植物种类差别很大**（不同天然淀粉的起始膨胀温度从约 55 °C 到约 85 °C 不等），
并受含水量、pH、糖与盐影响。

<a id="carryover"></a>
**余温加热（carryover cooking）**——离火之后，食材外层的热量继续往中心传，
中心温度还会再上升一段。
厨房里：这就是为什么肉要"静置"、为什么蒸鱼要按"关火后还会熟一点"来算时间。

## 水：水分与溶出

<a id="water-activity"></a>
**水活度（water activity, a_w）**——食物中水的"可用程度"（不是含水量），
决定微生物能不能生长、也影响表面能不能褐变。
厨房里：表面水活度高（湿）时，热量都被用来蒸发水了，温度上不去，所以不上色。

<a id="free-water"></a>
**自由水（free water）**——食物里能自由移动、能蒸发出去、能被微生物利用的那部分水。
厨房里：它是"会出水""会蒸发""上不了色"的那部分水，也是[水活度](#water-activity)衡量的对象。

<a id="bound-water"></a>
**结合水（bound water）**——被盐、糖、蛋白质、淀粉等拉住、不容易跑掉的那部分水。
厨房里：果酱含水不少却耐放，就是因为糖把大量水变成了结合水。
**加盐、加糖不改变含水量，却能改变水活度**，靠的就是这个转化。

<a id="leaching"></a>
**溶出 / 浸出（leaching）**——水溶性成分（盐、糖、部分维生素、呈味物质）
从食材内部转移到水里。
厨房里：焯水、水煮、煲汤都会发生。**你是想要它还是不想要它，决定了这一步该怎么做**：
做汤要的是溶出，炒青菜怕的就是溶出。

<a id="osmosis"></a>
**渗透（osmosis）**——水穿过细胞膜，从"淡"的一侧流向"浓"的一侧。
厨房里：撒盐后蔬菜出水、肉腌后先出水再回吸，都是它。
所以**盐不只是味道，它还是对水下的一道命令**。

<a id="reduction-sauce"></a>
**收汁（reduction）**——通过蒸发让汤汁变少、变浓。
厨房里：它同时做三件事——浓缩味道、提高黏度让汁"挂住"食材、
以及（因为水少了）让表面温度有机会升上去开始褐变。

## 味：味觉与调味

<a id="threshold"></a>
**阈值（threshold）**——能被察觉到的最低浓度（察觉阈）或能被认出是什么味的浓度（识别阈）。
厨房里：它解释了为什么"加了一点点盐，整道菜忽然就有味道了"——
你越过了阈值，而不是加了多少盐的问题。**每个人的阈值不同，所以必须自己尝**。

<a id="umami"></a>
**鲜味（umami）**——由**谷氨酸**等氨基酸和**核苷酸**引起的味觉，
中文常说"鲜"。厨房里：肉、海鲜、番茄、香菇、干贝、酱油、发酵制品都提供它。

<a id="glutamate"></a>
**谷氨酸 / 谷氨酸钠（glutamate / monosodium glutamate, MSG）**——鲜味的主要来源之一。
食物蛋白质被消化后释放的游离谷氨酸，与味精里的谷氨酸**化学上相同**。
典型膳食每天从蛋白质获得的谷氨酸量，远大于添加味精带来的量（美国 FDA 的量级对比）。

<a id="taste-interaction"></a>
**味味相互作用（taste–taste interaction）**——两种味道混在一起时，
感受到的强度不等于各自的简单相加：可能**增强**、可能**抑制**、也可能**没影响**。
⚠️ 这三种结果都存在，所以"加糖一定压酸""加盐一定提甜"这类断言
都需要具体条件，不能当成定律用。

<a id="volatile"></a>
**挥发性香气物质（volatile aroma compounds）**——能挥发进入鼻腔、被嗅觉感知的分子。
厨房里：它们**一加热就跑**——这就是"香料什么时候放"这个问题的物理基础：
要靠加热激发的（如爆香葱姜、花椒）先放，怕挥发掉的（如香油、香菜、鲜柠檬汁）最后放。

## 时间：速率与顺序

<a id="time-temperature"></a>
**时间—温度等效（time–temperature equivalence）**——同一个效果
（杀灭微生物、让胶原软化、让蛋白凝固）可以用"高温短时"或"低温长时"两种方式达到。
官方安全指引里就是这么写的：英国 FSA 把食物中心 70 °C/2 分钟
与 60 °C/45 分钟、65 °C/10 分钟、75 °C/30 秒、80 °C/6 秒列为**等效组合**。
厨房里：这是"炖"和"炒"在原理上并不矛盾的原因——它们在同一条曲线的两端。

<a id="rate"></a>
**速率（rate）**——单位时间内发生了多少。
厨房里：**温度决定速率，时间决定累积量**。你控制的永远是这两个旋钮，
而目标是某个"累积到刚好"的状态——这也是为什么"火大一点就得快一点"。

## 肉与蛋白质的结构

<a id="myofibrillar"></a>
**肌原纤维蛋白（myofibrillar protein）**——肌肉里负责收缩的那套蛋白质
（肌球蛋白、肌动蛋白等），约占肉中蛋白质的 50%~55%。
厨房里：它决定**质地的主体**——弹性、紧实，以及受热收缩把水挤出来这件事。
"肉变柴"主要是它干的。

<a id="sarcoplasmic"></a>
**肌浆蛋白（sarcoplasmic protein）**——溶在肌纤维胞浆里的可溶性蛋白质，
包括各种酶和**肌红蛋白**。
厨房里：肌红蛋白是肉呈红色的原因（不是血）；这类蛋白受热聚集，
也是"血水"和汤里浮沫的来源之一。

<a id="whc"></a>
**持水力 / 保水性（water-holding capacity, WHC）**——肉在受到加热或挤压时
留住自身水分的能力。
厨房里：它随温度下降，而且**不是均匀下降**——
一项建模研究的拟合曲线显示，持水量在约 62~72 °C 之间从约 2.99 掉到约 1.30
（kg 水/kg 干物质），中点在 **67 °C** 附近。
另一独立来源的实验汇总印证了位置：**蒸煮损失在 60→70 °C 显著上升，70→80 °C 变化不明显**。
⚠️ 这条曲线是**特定研究拟合的函数**，位置会随部位、pH、腌制状态漂移，**只用它的形状**。

<a id="cooking-loss"></a>
**蒸煮损失 / 得率（cooking loss / yield）**——加热过程中损失的重量比例，
以及它的反面（出锅重量 ÷ 下锅重量）。
厨房里：它就是"多不多汁"的客观指标。文献汇总的牛肉低温慢煮得率：
50 °C 约 89%~92%，55 °C 约 74%~84%，60 °C 约 81%，而走到久炖区间（约 100 °C×2 小时
或 75 °C×36 小时）大约只剩六成。
⚠️ 这些数字来自**不同研究**，条件不同，**不可横向直接比较**，只看方向。

<a id="crosslink"></a>
**交联（cross-link）**——胶原分子之间的共价连接，相当于给绳子打的结。
厨房里：交联越多越难拆，所以肉越硬、越需要时间。
它的程度取决于**肌肉类型、物种、基因型、年龄、性别与运动量**；
**动物年纪越大，交联越成熟、越热稳定、越难打断**——
这就是"老母鸡要炖更久"的机制。

<a id="imct"></a>
**肌内结缔组织（intramuscular connective tissue, IMCT）**——包裹肌纤维与肌束的三层套筒：
**肌内膜**（endomysium，包每一根纤维）、**肌束膜**（perimysium，包一束纤维，
决定肉的"纹理"）、**肌外膜**（epimysium，包整块肌肉，就是能撕下来的那层筋皮）。
厨房里：肌外膜能用刀去掉，肌束膜可以靠**逆纹切**缩短，肌内膜只能靠加热。

<a id="shear-force"></a>
**剪切力（shear force）**——实验室用仪器切开一块熟肉所需的力，是**嫩度的客观指标**
（力越小越嫩）。
厨房里：它让"嫩"这件事可以被比较。⚠️ 一条反直觉的文献结论：
**生肉**的剪切力与胶原含量高度相关，但在**熟肉**里，胶原含量与剪切力的相关性
**并不清楚，且随肌肉类型与烹饪条件变化**——因为加热同时在软化胶原、收紧肌纤维。

<a id="ltlt"></a>
**低温长时 / 高温短时（LTLT / HTST）**——达到同一个结果的两条路线：
**低温长时**（如 50~58 °C 保持 24~48 小时）与**高温短时**。
厨房里：中式炖、焖、卤走的其实是"**高温长时**"——因为只要水在沸腾，
温度就在沸点附近。**"小火"不等于"低温"**：小火只是让沸腾不那么剧烈。

## 食品安全

<a id="danger-zone"></a>
**危险温度带（temperature danger zone）**——细菌繁殖最快的温度区间。
美国 CDC 的表述是约 40~140 °F（约 4~60 °C）。
⚠️ **各国口径与表述不同**，具体数字以自己所在地现行官方发布为准。

<a id="core-temperature"></a>
**中心温度（internal / core temperature）**——食物**最厚处中心**的温度，
是判断"熟没熟"的唯一可靠指标。
美国 CDC 明确指出：除海鲜外，**不能靠颜色和质地判断是否安全熟透**。
⚠️ 各国的安全最低中心温度不同（例如猪肉整块：美国 145 °F 约 63 °C + 静置 3 分钟，
加拿大 71 °C），详见[出处登记](standards.md)。

<a id="cross-contamination"></a>
**交叉污染（cross-contamination）**——生食材（尤其生肉、生禽、生蛋）上的微生物
通过刀、板、手、抹布转移到熟食或即食食物上。
厨房里：它与温度无关，所以**再高的火也救不了它**，只能靠分开处理。

## 中式厨房术语

<a id="huohou"></a>
**火候**——中式厨房对"火力大小 + 加热时间 + 到什么程度"的统称。
它其实同时包含了本书"热"和"时间"两条线；
本书会把"火候"拆成可测量的部分（温度、时间、现象判据）来讲，而不是当成玄学。

<a id="hot-pan-cold-oil"></a>
**热锅冷油**——中式炒菜的操作惯例：先把锅烧热，再倒入（相对冷的）油，
随即下食材。常被用来解释"不粘锅"和"不过火"。
⚠️ 本书查证时**没有找到直接的实验证据**，只能从机制上部分解释，
故在辨析栏目里标为"缺乏直接证据"。

<a id="oil-heat-levels"></a>
**几成热**——中式对油温的经验分档（"三成热""七成热"）。
它是**现象判据**（油面波动、下料后的声音与气泡状态），不是温度读数；
不同资料给出的换算并不一致，所以本书优先讲现象，换算只作参考并标注为经验值。

<a id="blanching-cn"></a>
**焯水（blanching）**——把食材在沸水（或热水）里短时间加热后取出。
厨房里它可能在解决四个**不同**的问题：去血水与异味、去除部分草酸或涩味、
定色与钝化酶、以及让不同食材的成熟时间对齐。
**代价是水溶性成分的溶出**：文献报道 90 °C/15 分钟焯水条件下，
豌豆与茄子的抗坏血酸损失约 65~70%、青椒约 50%。
所以"要不要焯"取决于你想解决的是哪个问题。

<a id="velveting"></a>
**上浆挂糊**——下锅前给食材裹一层淀粉/蛋液/水的混合物。
从原理上看，它是**给蛋白质加一层外套**：这层糊先受热糊化，
把热量的冲击和水分的流失挡在外面，所以肉能保持嫩。

<a id="thickening"></a>
**勾芡**——用淀粉水在菜快出锅时收稠汤汁。
它是淀粉糊化的应用：变稠的汤汁能**挂**在食材表面，
让"味道待在嘴里的时间"变长——所以勾芡本质上是调味手段，不只是外观手段。
