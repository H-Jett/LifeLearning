# 术语表

> 中文 + 英文原词 + 一句"它在厨房里具体指什么"。
> 英文原词很重要——食物科学的资料多是英文的，你得能把厨房里的说法和资料里的词对上。
>
> 每个词条前有显式锚点（`<a id="...">`），所以正文和答案册都能直接跳过来。
> 按**四条线 + 安全 + 中式工艺**分组，随章节推进增补。

## 热：传热与温度

<a id="conduction"></a>
**导热（conduction）**——热量在**互相接触**的物体内部或之间传递。
厨房里：锅底 → 食材接触面 → 食材内部，全靠导热。
它解释了为什么"贴着锅的那一面先熟"、为什么厚的肉需要更长时间。

<a id="convection"></a>
**对流（convection）**——靠**流动的液体或气体**把热量带到食材表面。
厨房里：沸水、蒸汽、油锅里的油、烤箱里的热风都是对流。
流动越快，热量送到表面的速度越快——这就是为什么搅动能加快加热、也能让受热更均匀。

<a id="radiation"></a>
**辐射（radiation）**——不需要介质，靠电磁波直接传热。
厨房里：炭火、明火的火焰、烤箱上方的加热管、烧烤架。
它的特点是**只加热"看得见"的那一面**，所以需要翻面。

<a id="htc"></a>
**换热系数（heat transfer coefficient, h）**——描述"每平方米表面、每度温差、
每秒能把多少能量送到食材表面"的工程量，单位 W/(m²·K)。
厨房里：它决定"同样的温度，谁烫得更快"。
食品建模文献里用到的取值量级：静止空气约 8、强制热风/气炸约 100、平底锅接触约 200。
⚠️ 这些是**模型取值**而非实测汇编，不同研究差别很大，**只能看量级**。

<a id="latent-heat"></a>
**汽化潜热（latent heat of vaporization）**——把液态水变成水蒸气所需的能量，
不伴随温度上升。文献取值约 **2.26 × 10⁶ J/kg**。
厨房里：它是"表面有水就上不了色"的定量原因——
蒸发 1 kg 水所需的能量，约等于把这 1 kg 水升温 540 °C。
反过来，**蒸汽冷凝时会把这份能量原样放出来**，所以蒸的传热很猛。

<a id="specific-heat"></a>
**比热容（specific heat capacity）**——让单位质量的物质升高 1 °C 所需的能量。
水约 4.1~4.2 kJ/(kg·K)，在常见物质里很高。
厨房里：它解释了水"难烧开也难凉"，也是"汽化潜热 ÷ 比热容 ≈ 540"这个比较的分母。

<a id="microwave-heating"></a>
**微波加热（microwave heating）**——微波让食物里的水分子振动，
分子间的摩擦产生热量。家用微波炉常见频率 2450 MHz。
⚠️ **它不是"从里往外"加热**：美国 FDA 明确表述，较厚的食物由微波加热**外层**，
**内部主要靠从热的外层导热进去**。所以厚的东西仍要切小、摊开、翻动、静置。

<a id="maillard"></a>
**美拉德反应（Maillard reaction）**——**氨基酸与还原糖**在受热时发生的一系列反应，
生成褐色物质（类黑精）和大量香气分子。
厨房里：肉的焦褐外壳、面包皮、煎出来的"锅气"香味，主要都是它。
关键条件是**表面足够干、温度足够高**；碱性条件会加快它。
⚠️ 常见的"从 140~165 °C 开始"这个数字**缺乏可靠一手出处**，本书只写方向不写数字。

<a id="caramelization"></a>
**焦糖化（caramelization）**——**糖单独**受热分解并聚合成褐色物质的过程，
不需要氨基酸参与。厨房里：炒糖色、焦糖布丁表面的那层。
与美拉德反应常同时发生，但它们是两件事。

<a id="denaturation"></a>
**蛋白质变性（protein denaturation）**——蛋白质在受热（或遇酸、遇盐）时
原本折叠好的结构散开、然后互相缠结成网。
厨房里：蛋白由透明变白、肉由软变紧、奶被"点"成豆花，都是变性加凝聚。
**它基本不可逆**——这是"过了就回不来"的物理原因。
⚠️ 变性温度**不是固定值**：浓度、盐、pH、升温速率都会移动它。
纯蛋白在实验室测得的变性温度（例如卵白蛋白在水中约 80 °C）
往往高于同一蛋白在真实食物体系里开始变稠的温度（全蛋液在 60 多 °C 就有明显变化）。

<a id="collagen-gelatin"></a>
**胶原与明胶（collagen / gelatin）**——胶原是结缔组织（筋、膜、皮）的主要蛋白质，
生的时候又韧又硬；在**足够高的温度下持续足够长的时间**，它会转化成明胶，
口感变成软糯、汤汁变得黏稠挂嘴。
厨房里：牛腩、猪蹄、鸡爪炖久了"软烂出胶"，就是这件事。
这是**硬部位与嫩部位需要完全不同加热策略**的根本原因。

<a id="gelatinization"></a>
**淀粉糊化（starch gelatinization）**——淀粉颗粒在**有水且受热**时吸水膨胀、
结构崩解，把液体变稠。
厨房里：米饭变软、面条煮熟、勾芡变亮变稠、土豆变粉，都是糊化。
糊化温度**随植物种类差别很大**（不同天然淀粉的起始膨胀温度从约 55 °C 到约 85 °C 不等），
并受含水量、pH、糖与盐影响。

<a id="carryover"></a>
**余温加热（carryover cooking）**——离火之后，食材外层的热量继续往中心传，
中心温度还会再上升一段。
厨房里：这就是为什么肉要"静置"、为什么蒸鱼要按"关火后还会熟一点"来算时间。

## 水：水分与溶出

<a id="water-activity"></a>
**水活度（water activity, a_w）**——食物中水的"可用程度"（不是含水量），
决定微生物能不能生长、也影响表面能不能褐变。
厨房里：表面水活度高（湿）时，热量都被用来蒸发水了，温度上不去，所以不上色。

<a id="free-water"></a>
**自由水（free water）**——食物里能自由移动、能蒸发出去、能被微生物利用的那部分水。
厨房里：它是"会出水""会蒸发""上不了色"的那部分水，也是[水活度](#water-activity)衡量的对象。

<a id="bound-water"></a>
**结合水（bound water）**——被盐、糖、蛋白质、淀粉等拉住、不容易跑掉的那部分水。
厨房里：果酱含水不少却耐放，就是因为糖把大量水变成了结合水。
**加盐、加糖不改变含水量，却能改变水活度**，靠的就是这个转化。

<a id="leaching"></a>
**溶出 / 浸出（leaching）**——水溶性成分（盐、糖、部分维生素、呈味物质）
从食材内部转移到水里。
厨房里：焯水、水煮、煲汤都会发生。**你是想要它还是不想要它，决定了这一步该怎么做**：
做汤要的是溶出，炒青菜怕的就是溶出。

<a id="osmosis"></a>
**渗透（osmosis）**——水穿过细胞膜，从"淡"的一侧流向"浓"的一侧。
厨房里：撒盐后蔬菜出水、肉腌后先出水再回吸，都是它。
所以**盐不只是味道，它还是对水下的一道命令**。

<a id="reduction-sauce"></a>
**收汁（reduction）**——通过蒸发让汤汁变少、变浓。
厨房里：它同时做三件事——浓缩味道、提高黏度让汁"挂住"食材、
以及（因为水少了）让表面温度有机会升上去开始褐变。

## 味：味觉与调味

<a id="threshold"></a>
**阈值（threshold）**——能被察觉到的最低浓度（察觉阈）或能被认出是什么味的浓度（识别阈）。
厨房里：它解释了为什么"加了一点点盐，整道菜忽然就有味道了"——
你越过了阈值，而不是加了多少盐的问题。**每个人的阈值不同，所以必须自己尝**。

<a id="umami"></a>
**鲜味（umami）**——由**谷氨酸**等氨基酸和**核苷酸**引起的味觉，
中文常说"鲜"。厨房里：肉、海鲜、番茄、香菇、干贝、酱油、发酵制品都提供它。

<a id="glutamate"></a>
**谷氨酸 / 谷氨酸钠（glutamate / monosodium glutamate, MSG）**——鲜味的主要来源之一。
食物蛋白质被消化后释放的游离谷氨酸，与味精里的谷氨酸**化学上相同**。
典型膳食每天从蛋白质获得的谷氨酸量，远大于添加味精带来的量（美国 FDA 的量级对比）。

<a id="taste-interaction"></a>
**味味相互作用（taste–taste interaction）**——两种味道混在一起时，
感受到的强度不等于各自的简单相加：可能**增强**、可能**抑制**、也可能**没影响**。
⚠️ 这三种结果都存在，所以"加糖一定压酸""加盐一定提甜"这类断言
都需要具体条件，不能当成定律用。

<a id="volatile"></a>
**挥发性香气物质（volatile aroma compounds）**——能挥发进入鼻腔、被嗅觉感知的分子。
厨房里：它们**一加热就跑**——这就是"香料什么时候放"这个问题的物理基础：
要靠加热激发的（如爆香葱姜、花椒）先放，怕挥发掉的（如香油、香菜、鲜柠檬汁）最后放。

<a id="flavor"></a>
**风味（flavor）**——你嘴里感受到的**全部**："味觉 + 嗅觉 + 口腔的温度/痛觉/触觉"的总和。
厨房里：**味觉只有五种，香气有成千上万种**——所以"没味道"最常见的原因是缺香而不是缺盐。
现场判据：**捏住鼻子尝一口、松开再尝一口**，差别小就说明这道菜本来就没什么香气。

<a id="retronasal"></a>
**鼻后嗅觉（retronasal olfaction）**——食物在口腔里释放的挥发性分子
经由口腔后部向上进入鼻腔而被闻到。
厨房里：**吃东西时的"香"主要走这条路**，所以捏住鼻子会让风味大幅下降。

<a id="umami-synergy"></a>
**鲜味协同（umami synergism）**——**谷氨酸**与**核苷酸**（IMP、GMP）同时存在时，
鲜味强度远高于各自单独作用之和。
一项经典研究中，固定总量、改变 IMP 占比，**在 20%~80% 之间鲜味强度大幅上升**（倒 U 形）。
厨房里：**想更鲜，先加"另一类"而不是更多同一类**——
昆布 + 鲣节、番茄 + 牛肉、香菇 + 酱油，都是这个模式。

<a id="trigeminal"></a>
**三叉神经感觉 / 化学刺激感（trigeminal sensation, chemesthesis）**——
辣、凉、刺激感这类**不属于味觉**的口腔感受，由躯体感觉系统承担。
辣与烫共用一条通路（TRPV1 在**高于 43 °C** 时激活），
所以**热的辣菜更辣、放凉会减弱**；薄荷的"凉"走的是另一条（TRPM8，低于约 25~28 °C）。
厨房里：**太辣不能用处理"太咸"的办法去救**，因为它根本不是味觉。

<a id="mixture-suppression"></a>
**混合抑制（mixture suppression）**——几种味道混在一起时，
**每一种通常都比单独品尝时更弱**。
厨房里：这是"往锅里加东西"的**默认结果**——
增强需要条件（低到中等浓度、特定配对），而抑制几乎不需要条件。
所以"越调越平、越调越像调料味"是可预期的，不是手艺问题。

<a id="oite"></a>
**气味引起的味觉增强（odor-induced taste enhancement, OITE）**——
闻到的气味改变了你**尝到**的味觉强度：气味本身不提供咸味，
却让同样的盐尝起来更咸。
已核到的例子：中式豆豉的气味物质在 0.3% 盐水中增强咸味、酱油气味增强咸味、
沙丁鱼香气增强低盐奶酪的咸味、烟熏大蒜让水煮鸡**少放 33% 盐**仍被接受。
⚠️ **两个前提**：气味必须与味道**一致**、且必须走**鼻后**通路。

<a id="congruency"></a>
**风味一致性（congruency）**——气味与味道在经验上"配不配"。
减钠综述的表述是：**只有一致且熟悉的风味组合才能有效产生气味引起的味觉增强**。
厨房里：补咸要用"闻起来就该是咸的"那类香（酱油、腊味、豆豉、鱼干、烟熏），
甜香增强的是甜。**乱配香气不会增强，只会变怪。**

<a id="orthonasal"></a>
**鼻前嗅觉（orthonasal olfaction）**——隔着空气、食物还没进嘴时闻到的气味。
厨房里：它和[鼻后嗅觉](#retronasal)在效果上差别很大——
减钠研究中鼻后路径可达 **75%**，而鼻前最高约 **13.60%**。
**"厨房里很香"意味着香气已经离开了食物**，那正是你吃不到的部分。

<a id="kokumi"></a>
**厚味（kokumi）**——一类物质带来的口腔感受：
这类物质**在起作用的浓度下本身不产生任何味道**，
却能增强鲜、甜、咸与脂肪感，并带来
**厚度（thickness）、满口感（mouthfulness）、持续感（continuity）**。
受体主要是**钙敏感受体（CaSR）**。
最早从**无臭大蒜提取物**中发现（谷胱甘肽），此外见于洋葱、豆类、
**酱油**、泡菜、发酵可可豆、陈年奶酪、酵母提取物与"炖透的菜"。
厨房里：**鲜是音符，厚味是混响**——它解释了"味精要配着菜用"和"久炖的汤更厚"。
⚠️ 相关的解释框架尚未定论，本书只用方向。

<a id="taste-adaptation"></a>
**感官适应与疲劳（sensory adaptation / fatigue）**——持续或反复接受同一种刺激后，
对它的感受强度下降。
厨房里：**连尝五口比第一口更不准**。
专业感官评价对付它的办法是**样品之间用纯水漱口、每轮评价之间间隔 1 小时**，
并用**重复独立测量**而不是"多尝几口"来提高可靠性。
所以纠偏时要**认真对待第一口**，需要更可靠的判断就隔一会儿再尝、或让别人替你尝。

<a id="qda"></a>
**定量描述分析（quantitative descriptive analysis, QDA）**——
感官评价的一套标准方法：训练过的小组用**有定义的量表**给每个属性打分，
样品用随机数编码、重复多次取平均。
厨房里：它提示了两件可以照搬的事——**打分要有外部锚点**
（例如用 1.0 / 3.0 / 6.0 g/L 的盐水定义 1 / 3 / 6 分），
以及**很浓的样品要先稀释再判断**（否则分辨不出差别）。
项目 P2 做的就是给自己搭一套简化版的锚点。

<a id="jar"></a>
**"刚刚好"量表（just-about-right, JAR）**——感官评价中让人直接判断
"这个属性是太少、刚好、还是太多"的量表。
厨房里：它比"你觉得好吃吗"有用得多，因为它**直接指向要调哪一个方向**。
[尝味纠偏表](forms/tasting-fix.md)的第一步"先判断是多了还是少了"就是这个思路。

## 调味料与发酵品

<a id="volatile-acid"></a>
**挥发性酸 / 不挥发酸（volatile / non-volatile acids）**——
前者在烹饪温度下会随蒸汽跑掉（醋里的**乙酸**是代表），
后者会留下来（**乳酸、苹果酸、柠檬酸、琥珀酸**）。
谷物醋中**乙酸 + 乳酸合计占总有机酸八成以上**。
厨房里：这条区分解释了"**久煮的醋，酸还在、香没了**"，
也是"醋要放两次"这条操作的依据——早放给作用，晚放给香。

<a id="alliinase"></a>
**蒜氨酸酶（alliinase）**——完整蒜瓣里与底物**蒜氨酸**分处不同区隔的酶，
**细胞被破碎时两者相遇**，才开始生成风味物质。
最适温度约 **35~40 °C**，**60 °C** 以上逐渐失活，**超过 80 °C 不可逆失活**。
厨房里：它解释了为什么"整颗蒜炖汤没有蒜味"——**你没让它破碎**；
也解释了为什么蒜下锅的温度会改变最终的风味走向。

<a id="allicin"></a>
**蒜素（allicin）**——蒜被切、拍、剁之后由蒜氨酸生成的主要产物，
那股"冲鼻子"的味就是它。它本身**不稳定**，会继续转化成二硫化物、三硫化物等。
厨房里：**拍碎比切片生成更多蒜素、风味更受偏好，但切片更稳定**（碎得越细氧化越快）；
后续走向由介质决定——**油促进重排生成"肉香"硫醚、水煮则因水溶而流失、烤最浓、蒸最"鲜蒜"**。

<a id="sanshool"></a>
**山椒素（sanshool）**——花椒"麻"的来源，代表物质是**羟基-α-山椒素**。
它**不是味觉**：它激活 **TRPV1 与 TRPA1** 通道，
并通过**抑制双孔钾通道（KCNK3/9/18）**直接兴奋感觉神经元——属于**三叉神经**那一类感受。
它**易被氧化分解**，在油/乳液体系中（与抗氧化剂共存时）更稳定。
厨房里：这解释了"花椒油""油泼花椒"这类做法的方向，
以及为什么花椒粉放久了会"不麻只剩苦"。

## 时间：速率与顺序

<a id="time-temperature"></a>
**时间—温度等效（time–temperature equivalence）**——同一个效果
（杀灭微生物、让胶原软化、让蛋白凝固）可以用"高温短时"或"低温长时"两种方式达到。
官方安全指引里就是这么写的：英国 FSA 把食物中心 70 °C/2 分钟
与 60 °C/45 分钟、65 °C/10 分钟、75 °C/30 秒、80 °C/6 秒列为**等效组合**。
厨房里：这是"炖"和"炒"在原理上并不矛盾的原因——它们在同一条曲线的两端。

<a id="rate"></a>
**速率（rate）**——单位时间内发生了多少。
厨房里：**温度决定速率，时间决定累积量**。你控制的永远是这两个旋钮，
而目标是某个"累积到刚好"的状态——这也是为什么"火大一点就得快一点"。

## 肉与蛋白质的结构

<a id="myofibrillar"></a>
**肌原纤维蛋白（myofibrillar protein）**——肌肉里负责收缩的那套蛋白质
（肌球蛋白、肌动蛋白等），约占肉中蛋白质的 50%~55%。
厨房里：它决定**质地的主体**——弹性、紧实，以及受热收缩把水挤出来这件事。
"肉变柴"主要是它干的。

<a id="sarcoplasmic"></a>
**肌浆蛋白（sarcoplasmic protein）**——溶在肌纤维胞浆里的可溶性蛋白质，
包括各种酶和**肌红蛋白**。
厨房里：肌红蛋白是肉呈红色的原因（不是血）；这类蛋白受热聚集，
也是"血水"和汤里浮沫的来源之一。

<a id="myoglobin"></a>
**肌红蛋白（myoglobin）**——[肌浆](#sarcoplasmic)中的携氧色素，
**肌肉呈红色就是因为它**。运动多、需要持续供氧的肌肉肌红蛋白更多、颜色更深。
厨房里：它解释了"鸡腿比鸡胸深""牛肉比猪肉深"，
也解释了从肉里渗出的红色汁液**多半不是血**，而是含肌红蛋白的水。

<a id="fiber-type"></a>
**肌纤维类型（muscle fibre type）**——骨骼肌纤维按代谢与收缩特性分型，
常见的分法是 **I 型**（红肌、氧化型、慢）与 **IIa / IIx / IIb 型**（偏白肌、酵解型、快）。
一项 meta 回归（限于猪）给出的方向：**I 型频率高 → [滴水损失](#drip-loss)下降、
亮度下降（颜色更深）、感官嫩度上升**；**IIb 型频率高 → 滴水损失上升**。
厨房里：**颜色深的部位通常更"耐做"，颜色浅的部位窗口更窄**——
所以鸡胸比鸡腿容易做柴。⚠️ 该证据是 meta 回归而非对照实验，本书只取方向。

<a id="drip-loss"></a>
**滴水损失（drip loss）**——生肉在储存中自行渗出汁液的量，是[持水力](#whc)的一个指标。
厨房里：滴水损失大的肉，下锅后也更容易掉水；
托盘里积了很多红色汁液，通常意味着这块肉**持水力偏弱**。

<a id="imf"></a>
**肌内脂肪（intramuscular fat, IMF）**——分布在肌束之间的脂肪，
也就是俗称的"大理石纹""雪花"。
在和牛的研究中，**嫩度、多汁感与脂香主要与 IMF 含量相关**。
厨房里：它同时干三件事——**给润、给香、兜住香**
（大多数香气分子在脂里比在水里更易溶）。
所以**纯瘦肉的问题不只是"柴"，还有"香留不住"**，而这一点靠"锅里多放油"补不全。

<a id="background-toughness"></a>
**背景韧度（background toughness）**——由结缔组织（主要是[胶原](#imct)及其[交联](#crosslink)）
决定的那部分韧度，它**不会因为宰后成熟而消失**，只能靠长时间加热转成明胶来改变。
厨房里：它是"腩、腱、前后腿必须炖"的原因。
⚠️ 但要注意一条反直觉的结论：**生肉**的剪切力与胶原含量高度相关，
而**熟肉**中两者的相关性并不清楚、且随肌肉类型与烹饪条件变化——
**所以"胶原多 = 一定柴"并不成立**。

<a id="salt-soluble-protein"></a>
**盐溶性蛋白（salt-soluble protein）**——需要一定离子强度才能溶解的那部分肌肉蛋白，
主体就是[肌原纤维蛋白](#myofibrillar)。
厨房里：**加盐搅打肉馅（"打上劲"）就是在把它们溶出来**——
溶出的蛋白会包住脂肪、把水锁住，形成肉丸、虾滑那种弹而多汁的质地。
所以这一步的盐**必须早加**，因为溶解需要时间和接触；
一旦下锅受热、蛋白变性凝固，就来不及了。
⚠️ 相关定量（如"至少 2% 氯化钠"）来自**工业肉制品**研究，不可直接搬到家常菜。

<a id="whc"></a>
**持水力 / 保水性（water-holding capacity, WHC）**——肉在受到加热或挤压时
留住自身水分的能力。
厨房里：它随温度下降，而且**不是均匀下降**——
一项建模研究的拟合曲线显示，持水量在约 62~72 °C 之间从约 2.99 掉到约 1.30
（kg 水/kg 干物质），中点在 **67 °C** 附近。
另一独立来源的实验汇总印证了位置：**蒸煮损失在 60→70 °C 显著上升，70→80 °C 变化不明显**。
⚠️ 这条曲线是**特定研究拟合的函数**，位置会随部位、pH、腌制状态漂移，**只用它的形状**。

<a id="cooking-loss"></a>
**蒸煮损失 / 得率（cooking loss / yield）**——加热过程中损失的重量比例，
以及它的反面（出锅重量 ÷ 下锅重量）。
厨房里：它就是"多不多汁"的客观指标。文献汇总的牛肉低温慢煮得率：
50 °C 约 89%~92%，55 °C 约 74%~84%，60 °C 约 81%，而走到久炖区间（约 100 °C×2 小时
或 75 °C×36 小时）大约只剩六成。
⚠️ 这些数字来自**不同研究**，条件不同，**不可横向直接比较**，只看方向。

<a id="crosslink"></a>
**交联（cross-link）**——胶原分子之间的共价连接，相当于给绳子打的结。
厨房里：交联越多越难拆，所以肉越硬、越需要时间。
它的程度取决于**肌肉类型、物种、基因型、年龄、性别与运动量**；
**动物年纪越大，交联越成熟、越热稳定、越难打断**——
这就是"老母鸡要炖更久"的机制。

<a id="imct"></a>
**肌内结缔组织（intramuscular connective tissue, IMCT）**——包裹肌纤维与肌束的三层套筒：
**肌内膜**（endomysium，包每一根纤维）、**肌束膜**（perimysium，包一束纤维，
决定肉的"纹理"）、**肌外膜**（epimysium，包整块肌肉，就是能撕下来的那层筋皮）。
厨房里：肌外膜能用刀去掉，肌束膜可以靠**逆纹切**缩短，肌内膜只能靠加热。

<a id="shear-force"></a>
**剪切力（shear force）**——实验室用仪器切开一块熟肉所需的力，是**嫩度的客观指标**
（力越小越嫩）。
厨房里：它让"嫩"这件事可以被比较。⚠️ 一条反直觉的文献结论：
**生肉**的剪切力与胶原含量高度相关，但在**熟肉**里，胶原含量与剪切力的相关性
**并不清楚，且随肌肉类型与烹饪条件变化**——因为加热同时在软化胶原、收紧肌纤维。

<a id="ltlt"></a>
**低温长时 / 高温短时（LTLT / HTST）**——达到同一个结果的两条路线：
**低温长时**（如 50~58 °C 保持 24~48 小时）与**高温短时**。
厨房里：中式炖、焖、卤走的其实是"**高温长时**"——因为只要水在沸腾，
温度就在沸点附近。**"小火"不等于"低温"**：小火只是让沸腾不那么剧烈。

## 食品安全

<a id="danger-zone"></a>
**危险温度带（temperature danger zone）**——细菌繁殖最快的温度区间。
美国 CDC 的表述是约 40~140 °F（约 4~60 °C）。
⚠️ **各国口径与表述不同**，具体数字以自己所在地现行官方发布为准。

<a id="core-temperature"></a>
**中心温度（internal / core temperature）**——食物**最厚处中心**的温度，
是判断"熟没熟"的唯一可靠指标。
美国 CDC 明确指出：除海鲜外，**不能靠颜色和质地判断是否安全熟透**。
⚠️ 各国的安全最低中心温度不同（例如猪肉整块：美国 145 °F 约 63 °C + 静置 3 分钟，
加拿大 71 °C），详见[出处登记](standards.md)。

<a id="cross-contamination"></a>
**交叉污染（cross-contamination）**——生食材（尤其生肉、生禽、生蛋）上的微生物
通过刀、板、手、抹布转移到熟食或即食食物上。
厨房里：它与温度无关，所以**再高的火也救不了它**，只能靠分开处理。

## 淀粉与植物组织

<a id="amylose"></a>
**直链淀粉（amylose）**——淀粉里那种基本是直链的分子。普通淀粉颗粒含 **15%~30%**，
**糯性（waxy）淀粉不到 1%**。
厨房里：它**容易溶出、容易重新排队结晶**，所以**负责"凝"**——
汤汁放凉能成冻、冷饭会变硬，主要是它干的。

<a id="amylopectin"></a>
**支链淀粉（amylopectin）**——树枝状的大分子，重新排队很慢。
厨房里：它**负责"黏"**——糯米、糯玉米的黏糯、芡汁的拉丝感。
**糯性食材黏，是因为几乎只有支链，不是因为"淀粉更多"。**

<a id="retrogradation"></a>
**回生 / 老化（retrogradation / staling）**——糊化后的淀粉在放凉与存放过程中
**重新排列成有序结构并把水挤出来**。
表现：变硬、变浑、结皮、**析水**、成冻。
速度：**直链几分钟到几小时，支链几小时到几天**。
⚠️ 一条反直觉的结论：**陈化带来的"又干又硬"不一定意味着失水**——
水常常还在食物里，只是不在原来的位置。

<a id="resistant-starch"></a>
**抗性淀粉（resistant starch, RS）**——消化酶不易分解的那部分淀粉。
熟米饭在低温储存中回生，抗性淀粉比例会上升。
⚠️ 本书只把它当作"**回生确实发生了**"的客观指标，
**不做任何营养或健康层面的推论**（本书纪律：不做医疗与营养治疗建议）。

<a id="pectin"></a>
**果胶与 β-消除（pectin / β-elimination）**——果胶是把植物细胞粘在一起的"胶水"
（集中在细胞之间的中间层）。加热时它主要通过 **β-消除反应**降解，
而这个反应**发生在非酸性环境中、由氢氧根离子催化**，速率取决于温度、pH 与酯化程度。
厨房里：**加碱更快烂，加酸不容易烂**——
"煮豆放一点碱""番茄放早了土豆煮不软"是同一条规律的两面。

## 颜色与酸碱

<a id="melanoidin"></a>
**类黑精（melanoidins）**——美拉德反应末期生成的褐色高分子聚合物。
厨房里：肉的焦褐外壳、面包皮、酱油与啤酒的颜色，主要是它。
⚠️ 注意反应的**分期**：**风味在中期就已明显，而颜色到末期才最强**——
所以"颜色越深越香"只在前半段成立。

<a id="enzymatic-browning"></a>
**酶促褐变与多酚氧化酶（enzymatic browning / polyphenol oxidase, PPO）**——
食材被切开或碰伤后，**酚类物质、含铜的 PPO 与氧气**相遇，
酚被氧化成醌、再聚合成褐黑色的黑色素。
厨房里：苹果、土豆、藕、香蕉、牛油果、蘑菇切开变黑，都是它。
**它不需要加热，室温就发生**，所以和"上色"完全是两件事。
对策四条：**隔氧（泡水）、加酸（PPO 最适 pH 5~7，低于 pH 3.0 受抑制）、
焯烫把酶烫死、降温减速**。

<a id="pheophytin"></a>
**脱镁叶绿素（pheophytin）**——叶绿素在**酸催化**下失去卟啉环中的镁离子后的产物，
颜色由鲜绿变成**橄榄褐**。
厨房里：这就是"青菜发黄"的化学身份。加热会让叶绿素暴露在**植物组织自身的酸**中，
所以**时间越长越黄**；用略带碱性的水煮能避免变色，但碱会同时加速软化。

<a id="anthocyanin"></a>
**花青素（anthocyanins）**——紫甘蓝、紫薯、蓝莓、桑葚等的色素，
颜色由一组**随 pH 移动的酸碱平衡**决定，**酸性条件下红色形式占优势**。
厨房里：它等于一个**天然 pH 指示剂**——发蓝发绿说明偏碱，加点酸就会转红。

<a id="isoelectric-point"></a>
**等电点（isoelectric point）**——蛋白质净电荷为零的那个 pH。
在这一点上蛋白分子彼此靠得最紧，**持水力最低**。
厨房里：**pH 离等电点越远，持水力越高**——
所以**酸腌和碱腌都能让肉更嫩更多汁**，它们是同一条 U 形曲线的两侧。
中式厨房常用的**碱腌（小苏打）**走的就是碱这一侧。

## 中式厨房术语

<a id="huohou"></a>
**火候**——中式厨房对"火力大小 + 加热时间 + 到什么程度"的统称。
它其实同时包含了本书"热"和"时间"两条线；
本书会把"火候"拆成可测量的部分（温度、时间、现象判据）来讲，而不是当成玄学。

<a id="hot-pan-cold-oil"></a>
**热锅冷油**——中式炒菜的操作惯例：先把锅烧热，再倒入（相对冷的）油，
随即下食材。常被用来解释"不粘锅"和"不过火"。
⚠️ 本书查证时**没有找到直接的实验证据**，只能从机制上部分解释，
故在辨析栏目里标为"缺乏直接证据"。

<a id="oil-heat-levels"></a>
**几成热**——中式对油温的经验分档（"三成热""七成热"）。
它是**现象判据**（油面波动、下料后的声音与气泡状态），不是温度读数；
不同资料给出的换算并不一致，所以本书优先讲现象，换算只作参考并标注为经验值。

<a id="blanching-cn"></a>
**焯水（blanching）**——把食材在沸水（或热水）里短时间加热后取出。
厨房里它可能在解决四个**不同**的问题：去血水与异味、去除部分草酸或涩味、
定色与钝化酶、以及让不同食材的成熟时间对齐。
**代价是水溶性成分的溶出**：文献报道 90 °C/15 分钟焯水条件下，
豌豆与茄子的抗坏血酸损失约 65~70%、青椒约 50%。
所以"要不要焯"取决于你想解决的是哪个问题。

<a id="velveting"></a>
**上浆挂糊**——下锅前给食材裹一层淀粉/蛋液/水的混合物。
从原理上看，它是**给蛋白质加一层外套**：这层糊先受热糊化，
把热量的冲击和水分的流失挡在外面，所以肉能保持嫩。

<a id="thickening"></a>
**勾芡**——用淀粉水在菜快出锅时收稠汤汁。
它是淀粉糊化的应用：变稠的汤汁能**挂**在食材表面，
让"味道待在嘴里的时间"变长——所以勾芡本质上是调味手段，不只是外观手段。
