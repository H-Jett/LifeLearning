# 🛠 项目 P5：写出你自己的“家常菜说明书”

> **这是全书的验收。**
> 说明书不是十篇漂亮菜谱，而是十张能在你家复做、能随着失败更新的卡片：目标状态、关键变量、安全点、停点和纠偏，缺一不可。

## P5.1 最终交付物

| 交付物 | 要有的内容 | 价值 |
|--------|------------|------|
| **① 十道菜目录** | 覆盖不同食材 / 技法，并标出最常失败的点 | 不只会一类菜 |
| **② 每道一页说明书** | 原理、参数范围 / 现象停点、纠偏和安全项 | 不依赖固定分钟数 |
| **③ 版本记录** | 每次只改一项，写下结果 | 经验会累积而非遗失 |

十道不必一次写完，也不必都是“大菜”。一碗面、一盘青菜、一锅汤都可以；“十道”只是促使你覆盖不同变量，不是一次作业的最低门槛。

## P5.2 选菜：让十张卡片互相补位

| 类别 | 可选例子 | 你会练到什么 |
|------|----------|--------------|
| 蛋奶 / 窄窗口 | 番茄炒蛋、蒸蛋 | 凝固与停点 |
| 叶菜 / 高水分 | 清炒青菜 | 分批、水分、调味时机 |
| 米面 / 淀粉 | 蛋炒饭、面条、粥 | 吸水、糊化、回生 |
| 肉 / 两段加热 | 煎肉、水煮肉片 | 厚度、上浆、中心验证 |
| 带筋 / 长时间 | 炖肉、卤菜 | 胶原、时间与收汁 |
| 鱼 / 海鲜 | 清蒸鱼 | 窄窗口、生熟分开 |
| 汤 / 一锅菜 | 炖菜、蔬菜汤 | 下锅顺序与浓度 |
| 冷菜 / 即食 | 凉拌菜 | 原料、清洁与交叉污染 |

不吃其中某类食材就换成自己常做的替代品。目标是覆盖“热、水、结构、味、安全”的不同难题，不是凑齐菜名。

## P5.3 🅐 零成本版：先写三张纸上说明书

从你最常做的三道菜开始，阅读已有菜谱或回忆自己的做法，使用[一道菜的处理方案表](../../forms/dish-plan.md)完成每道的前五栏。然后压缩成下表：

| 菜 | 目标状态 | 最关键的一条线 | 两个现象停点 | 最常见失败 | 下次唯一改动 |
|----|----------|----------------|--------------|------------|--------------|
| | | | | | |
| | | | | | |
| | | | | | |

必须写成状态，而不是“按菜谱做”：例如“叶梗熟而叶不闷、盘中没有明显游离水”，比“炒两分钟”更能跨锅具复用。

## P5.4 🅑 开火版：把十道菜逐步做成活文档

每次只做一张卡。开做前写计划，做完再补复盘；不要为了填表改变原本安全流程。涉及生肉、禽、鱼、蛋、剩菜或易腐食材时，按[第 42 章](42-food-safety.md)和所在地现行官方指引确认生熟分开、中心条件与冷藏。

```text
【菜名】__________  版本：v___  日期：__________

目标状态：________________________________________
食材与关键差异（厚度 / 含水 / 初温）：________________
关键动作及其理由：__________________________________
停点（看 / 听 / 闻 / 测）：_________________________
安全确认：__________________________________________
发生的问题：________________________________________
下次只改：__________________________________________
```

## P5.5 让说明书真的可更新（交付物③）

每道菜最多记录一条“本次改变”，防止把结果归因给一串同时发生的调整。

| 菜与版本 | 我只改了什么 | 其余保持什么 | 结果 | 我的暂定规则 | 仍未排除的变量 |
|------------|--------------|--------------|------|--------------|----------------|
| | | | | | |
| | | | | | |

“v2 比 v1 好”不是充分记录。要写“v2 中我把叶和梗分开下锅；锅、总量和调味相同；叶更完整但梗仍偏硬；下次只改变梗的切法”。这样的说明书可以被下次推翻，也因此可信。

## P5.6 自检清单

| 做到了 | 说明 |
|--------|------|
| 每张卡开头都是目标状态 | 你在追结果，不是背动作 |
| 有至少一个可观察停点 | 你没把作者的分钟数当定律 |
| 安全项单列且与口感分开 | 你没把“嫩”误当“安全” |
| 每次复盘只选一个变量 | 你能逐步知道什么有效 |
| 有“未排除变量”一栏 | 你不会把单次结果当普遍规律 |

## P5.7 本项目依据

P5 不新设食谱比例与安全数字，而是把全书工具汇总：

| 用到的工具 | 对应位置 |
|------------|----------|
| 四条线与逐行解释菜谱 | 第 1 章、项目 P1 |
| 咸度 / 鲜度基准与纠偏 | 第二部分、项目 P2、[尝味纠偏表](../../forms/tasting-fix.md) |
| 同食材对照、只改一个变量 | 项目 P3、 第 43 章 |
| 条件改变时的补偿 | 项目 P4 |
| 食品安全、证据等级与拓展边界 | 第 42、44、45 章 |

所有来源与限制见[参考书目与出处登记](../../standards.md)。
