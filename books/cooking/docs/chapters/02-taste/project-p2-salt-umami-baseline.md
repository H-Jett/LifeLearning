# 🛠 项目 P2：给自己做一套咸度与鲜度标定

> **这是第二部分的验收。**
> 第 9~15 章讲了味觉怎么工作、味与味怎么互相影响、每种调料解决什么问题、
> 以及尝味纠偏的流程。这个项目只做一件事：
>
> > **把"你自己的舌头"从一台没刻度的仪器，变成一台有刻度的仪器。**
>
> **为什么这件事必须自己做**：第 15 章已经说明，个体差异极大——
> 跨文化研究里同一处理下不同人群聚类的评分变化能差出数倍。
> **别人的"刚刚好"不是你的。**
> 所以本书不给"一斤菜放几克盐"，而是教你做一把**自己的尺子**。

## P2.1 交付物

做完这个项目，你手上应该有**三样东西**：

| 交付物 | 是什么 | 用在哪 |
|--------|-------|-------|
| **①我的咸度标尺卡** | 1 分 / 3 分 / 6 分分别对应什么浓度，以及我的"刚刚好"落在哪 | 以后说"这道菜我要 4 分咸"时，那个 4 分是**有定义的** |
| **②我的鲜度与协同记录** | 加鲜之后咸度感知变了多少；两侧鲜味叠加的效果 | 判断"缺盐还是缺鲜"时的参照 |
| **③一次完整的纠偏记录** | 一碗汤，从"不对"救到"可以" | 验证第 15 章的闭环真的能跑 |

零成本版做①②；开火版做①②③。

## P2.2 为什么用盐水做标尺

因为**有一条可引用的锚点**。

第 15 章引用的那项研究中，60 人的感官小组测得：

- 氯化钠溶液在 **1.0~6.0 g/L** 区间内，咸度感知强度与浓度**高度线性**（R²=0.9995）；
- 研究据此把 **1.0 g/L 定为 1 分、3.0 g/L 定为 3 分、6.0 g/L 定为 6 分**；
- **超过 6.0 g/L 后排序准确率骤降**（即使梯度放宽到 0.5 g/L 也只有 20%），
  因此量表上限定在 6.0 g/L。

> ⚠️ **要说清楚的适用范围**：
> 这是**纯氯化钠水溶液**的结果，**不是菜**。
> 菜里有脂肪、有淀粉、有鲜味物质、有温度差，
> 每一样都会移动你的感知（第 10、13、15 章）。
>
> **所以这把尺子的用途是"给你自己的分数下定义"，
> 不是"换算成菜里该放多少盐"。**

## P2.3 🅐 零成本版

不用开火、不用食材，只需要**盐、水、杯子、一把能称到 0.1 g 的秤**（没有秤见下面的替代方案）。

### 任务一：配出你的标尺

配 6 杯，每杯 **200 mL 水**：

| 杯 | 加盐 | 浓度 | 该研究给的分值锚点 |
|----|------|------|------------------|
| ① | 0.2 g | 1.0 g/L | **1 分** |
| ② | 0.4 g | 2.0 g/L | — |
| ③ | 0.6 g | 3.0 g/L | **3 分** |
| ④ | 0.8 g | 4.0 g/L | — |
| ⑤ | 1.0 g | 5.0 g/L | — |
| ⑥ | 1.2 g | 6.0 g/L | **6 分** |

**没有精确秤的替代方案**：用**一杯浓盐水做母液**再倍比稀释——
比如 1 L 水里溶 6 g 盐（≈6 g/L）当作 ⑥，
然后取 ⑥ 100 mL + 水 100 mL 得到 ≈3 g/L（③），依此类推。
**倍比稀释比称小重量更容易做准。**

> ⚠️ **操作提醒**：**每杯只含一小口，尝完吐掉，不要喝下去**；
> 两杯之间**用白水漱口**。
> 本书**不做任何摄入量建议**——这是一次**测量**，不是一次进食。

### 任务二：找出你的三个点

按**从淡到浓**的顺序尝（反过来会因为适应而失真）。

| 我要找的点 | 定义 | 我的结果 |
|----------|------|---------|
| **察觉点** | 第一杯让我觉得"**这不是白水**"的 | 第 ___ 杯，约 ___ g/L |
| **识别点** | 第一杯让我明确觉得"**这是咸的**"的 | 第 ___ 杯，约 ___ g/L |
| **"刚刚好"点** | 如果这是一碗清汤，我觉得**最舒服**的那一杯 | 第 ___ 杯，约 ___ g/L |

做完回答：

1. 你的察觉点和识别点差几杯？（第 9 章：这两者本来就是不同的阈值）
2. 你的"刚刚好"点落在 1~6 分的哪里？
3. 从 ⑤ 到 ⑥，你**分得出差别**吗？往上再浓一点呢？
   （研究中超过 6.0 g/L 后排序准确率只有 20%——**你大概也会在这里失去分辨力**）

### 任务三：把标尺变成一张卡

抄到手机备忘录里。**这是交付物①**。

```
【我的咸度标尺】  日期：____
  1 分 = 1.0 g/L  —— 我的感觉：____________
  3 分 = 3.0 g/L  —— 我的感觉：____________
  6 分 = 6.0 g/L  —— 我的感觉：____________
  我的察觉点：约 ___ g/L
  我的"刚刚好"：约 ___ g/L（= ___ 分）
  我在 ___ g/L 以上就分不清差别了
```

### 任务四：鲜味会不会改变你的咸度判断

**需要**：味精或鸡精（没有的话用酱油，但要知道酱油**自带盐**，会干扰结论）。

取**两杯同样浓度**的盐水（建议用你的"刚刚好"点**下面一档**，也就是略淡的那杯）：

| 杯 | 内容 | 咸度（用你的 1~6 分打分） | 鲜度（0~10） | 整体"够味"（0~10） |
|----|------|----------------------|------------|-----------------|
| A | 纯盐水 | | | |
| B | 同浓度盐水 + **极少量味精** | | | |

做完回答：

1. B 的**咸度分数**比 A 高吗？
   （第 9 章一手研究：**0.10% 味精可增强咸味强度**；
   第 10 章：鲜味物质增强咸味，最佳情形实现约 **24.25%** 的减钠）
2. 如果 B 的咸度更高，这说明"**咸不够**"这个判断可能是**误诊**——它可能是"鲜不够"；
3. ⚠️ 如果你**没有**观察到差别，这**不算推翻上面的结论**。为什么？
   （提示：你用的浓度、用量、体系都和研究不同；单次、单人、无对照、无盲测）

### 任务五：两侧鲜味的协同

**需要**：谷氨酸侧（酱油、海带水、番茄汁）与核苷酸侧（干香菇水、肉汤、干贝水）各一样。

| 杯 | 内容 | 鲜度（0~10） | "厚不厚"（0~10） |
|----|------|------------|---------------|
| ① | 淡盐水（对照） | | |
| ② | ① + 谷氨酸侧 | | |
| ③ | ① + 核苷酸侧 | | |
| ④ | ① + **两侧都加** | | |

做完回答：

1. ④ 比 ② 和 ③ 里**更强的那一个**还要强吗？
   （第 9 章：**IMP 占比 20%~80% 时鲜味强度大幅上升，呈倒 U 形**）
2. 这解释了为什么"补鲜要换一类，而不是加更多同一类"吗？
3. ⚠️ 本书**没有核到**各食材中谷氨酸与核苷酸的**具体含量**，
   所以**你无法用这个实验算配比**——它只能给你**方向感**。

## P2.4 🅑 开火版

**有灶台和食材时做。** 在零成本版的①②之上，加一次**完整的纠偏演练**。

### 任务六：一碗故意做坏的汤，把它救回来

**需要**：一小锅清汤（鸡汤、菜汤、甚至清水煮点青菜都行）、
盐、酱油、一个核苷酸侧的鲜味来源（香菇水/肉汤）、醋、香油、淀粉水（可选）。

**第一步：故意做出一个问题。** 三选一：

| 选项 | 怎么做 | 你要练的诊断 |
|------|-------|------------|
| **A** | 只加盐，加到你标尺上的 4~5 分，**不加任何鲜味来源** | "咸够了但寡、空" |
| **B** | 只加酱油，不加盐 | "有味但不够、且颜色重了" |
| **C** | 先勾一点薄芡，再判断咸淡 | "被增稠骗了" |

**第二步：按第 15 章的闭环救它。** 边做边填：

| 轮次 | 我尝到什么 | 我判断缺/多了什么 | 我**只**改了哪一样 | 改完再尝的结果 |
|------|----------|----------------|----------------|-------------|
| 1 | | | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |

**必须遵守的三条**（否则这次练习没有意义）：

1. **每轮只改一个变量**；
2. **改完搅匀、等几秒再尝**；
3. **在接近食用温度时判断**。

**第三步：复盘。**

1. 你一共用了几轮救回来？
2. 有没有哪一轮你**改了两样**？结果是不是变得说不清了？
3. 如果选了 C，**勾芡前后的咸度判断差多少**？
   （一手研究：增稠使咸、酸、甜强度均显著下降，β 约 −4.16 / −3.29 / −3.43）
4. 最终的咸度落在你标尺的**第几分**？和你在 P2.3 里找到的"刚刚好"一致吗？

### 任务七：把标尺搬到真实的菜里（选做）

盐水里的"刚刚好"和菜里的"刚刚好"**不是一回事**——菜里有脂肪、淀粉、鲜味物质和温度。
这一步就是去量这个差距。

| 菜 | 我按标尺判断的咸度分数 | 实际用了多少盐（含酱油折算） | 家人/朋友的评价 | 差距在哪 |
|----|------------------|------------------------|--------------|---------|
| | | | | |
| | | | | |

> ⚠️ **别把"折算"当成精确计算**：酱油的钠含量各品牌差别很大
> （实测 10 个中国市售样品钠离子平均 54.6 mg/mL，但离散度很大），
> 本书**不提供换算公式**。这一栏只是让你**意识到它的存在**。

## P2.6 这个项目想让你相信的三件事

1. **"不够味"通常不是"不够咸"。**
   一手反例已经有了：水煮牛肉缺项实验里，
   **去掉豆瓣的那组咸度更高，鲜味与总体可接受度却只有 4.25**（完整组 8.0 以上）。
2. **你的分辨力有上限。**
   超过 6.0 g/L 之后，人对咸度差别的排序准确率掉到 20%。
   **这意味着"越调越咸"不是意志力问题，是分辨力问题**——
   所以要在偏淡的一侧做决定。
3. **调味主要是流程，不是天赋。**
   在什么状态下尝、按什么顺序补、一次只改一个——这三条都可以学、可以练。
   **真正需要个人化的只有基准，而基准就是你刚才做出来的那张卡。**
