# 第 12 章 糖与酸：它们在菜里干的活不只是甜和酸

> **本章目标**：让你不再把糖和酸当成"甜味剂"和"酸味剂"。
>
> 在一道中式菜里，糖经常**根本不是为了甜**（红烧的糖色、提鲜的那一点糖、
> 腌肉里的糖），酸也经常**不是为了酸**（去腥、保色、让肉嫩、让菜脆）。
> 第 8 章已经讲完了酸碱对**质地、颜色、气味**的三种作用；
> 这一章补上**味觉这一侧**，并把糖的"非甜工作清单"讲清楚。
>
> 学完这一章你会知道：**"加糖压酸"是真的，但它的账比你想的复杂——
> 因为糖的甜也正在被酸压着。**

## 12.1 先分家：甜是感受，糖是物质

这和第 9 章"辣不是味觉"是同一种分家动作，但方向相反：

| 概念 | 属于 | 说明 |
|------|------|------|
| **甜** | 感受 | 由 **T1R2 + T1R3** 受体二聚体介导（第 9 章）；**多种物质都能引起它** |
| **糖** | 物质 | 一大类碳水化合物。它们**除了甜，还会参与一堆化学与物理过程** |

一篇 2026 年关于复杂食品体系减糖的综述把这件事说得很直接：

> 在食品与饮料中减糖在技术上仍然困难，因为糖贡献的**不只是甜味和热量**，
> 还包括**质地、黏度、体积、颜色形成、稳定性与风味释放**等多重功能性质。

> ## 这句话是本章的纲
>
> **减糖之所以是一个工业难题，正是因为糖在食品里同时干着六七件事。**
> 你在家里"少放点糖"的时候，减掉的**也不止是甜**。

## 12.2 糖的六件"非甜工作"

前四件本书在第一部分已经讲过机理，这里只做索引 + 厨房含义；后两件是本章新增。

| # | 糖在干什么 | 机理在哪一章 | 厨房里的含义 |
|---|-----------|------------|------------|
| **①** | **当褐变的燃料** | 第 7 章 | **还原糖**参与美拉德反应；糖单独受热则**焦糖化**（分子美食学综述：戊糖与己糖脱水生成特征产物发生在**高于 150 °C**）。所以"上色不够"有时候不是火不够，是**没有糖** |
| **②** | **抢水**：把自由水变成结合水，降低水活度 | 第 3 章 | 这是果酱、蜜饯耐放的原因（美国 FDA 的水活度指南里，巧克力酱 0.83、花生酱 0.70）。在菜里：**糖会让汁"稠"得更快**，因为可用的水变少了 |
| **③** | **推迟淀粉糊化** | 第 6 章 | 一项研究测得：**35% 蔗糖体系中峰值糊化温度升高约 11~12 °C**。所以**甜的糊、甜的馅、甜的面糊需要更高温度或更长时间才熟透** |
| **④** | **保护蛋白质，提高变性温度** | 本章新增 | 一项用差示扫描量热法比较蔗糖与海藻糖的研究显示：**含蔗糖的样品变性温度高于对应的含海藻糖样品**，两者都起稳定作用。⚠️ 这是**溶菌酶与肌红蛋白在溶液里**的测量，不是蛋羹。**方向可用**：糖让蛋白质更耐热 → 这就是蛋羹、布丁、卡仕达里放糖后"更不容易老"的机理方向 |
| **⑤** | **给质地、黏度和"厚度"** | 本章新增 | 减糖综述列出的功能里就有质地、黏度、体积。⚠️ 注意第 10 章：**增稠会让味觉强度下降**——所以糖在"加甜"的同时可能在"减味" |
| **⑥** | **压住酸（以及被酸压住）** | 本章 12.3 | 见下一节 |

> ## 一条立刻能用的推论
>
> **一道菜里"那一点点糖"往往不是为了甜。**
>
> 下次看到菜谱里出现"糖 少许"而这道菜明显不是甜口的，按顺序猜：
>
> 1. **压酸 / 平衡**（最常见，尤其是番茄、醋、酸菜类）；
> 2. **帮助上色**（红烧、酱烧类）；
> 3. **改质地或口感厚度**；
> 4. **真的是为了甜**（本地口味偏好）。
>
> **猜中了，你就知道能不能省——省不省的判据是"这件事我还需不需要"。**

## 12.3 甜与酸：本书证据最强的一对相互作用

第 10 章给过结论，这里给完整的账。

### 两个独立来源

**来源一：跨文化消费者实测**（中国 120 人、丹麦 139 人，水溶液）

| 样品 | 甜度评分 | 酸度评分 |
|------|---------|---------|
| 2.50% 蔗糖 | **6.32** | 1.51 |
| 0.140% 柠檬酸 | 1.90 | **6.42** |
| 0.114% 酒石酸 | 1.82 | **6.36** |
| 蔗糖 + 柠檬酸 | **4.53** | **4.79** |
| 蔗糖 + 酒石酸 | **4.49** | **4.70** |

**两边都掉了约四分之一到三成**（均 p < 0.001）。
换成另一种酸，结果几乎一样；两个国家的消费者在"酸压甜"这一侧表现一致。

**来源二：阈值层面建模**（独立研究）

在柠檬酸背景下测蔗糖的阈值，得到的关系是：**柠檬酸浓度越高，蔗糖的绝对阈值越高**——
也就是**要放更多糖才尝得出甜**。

> ## 所以"加糖压酸"的完整说法是：
>
> **糖和酸在互相抑制。你压住酸的同时，糖的甜也正在被酸压着。**
>
> 三条推论：
>
> 1. **糖醋味不是"糖 + 酸"，是"两个都被削弱之后剩下的新平衡"**；
> 2. **糖醋类菜要放的糖，总是比你按甜度估计的多得多**——
>    因为其中很大一部分甜根本没被你尝到；
> 3. **想让一道菜"酸得明显"，减糖往往比加酸更有效**——
>    加酸会把总浓度继续推高，而减糖是在"松开刹车"。

### ⚠️ 一个必须写出来的例外条件

那项跨文化研究在讨论里指出：早期有研究报告过**酸能增强甜**，
而这些研究用的是**阈下浓度**的协议（interacting tastant 在阈值以下）；
**用阈上浓度的研究则一致地得到抑制**。

> **这又是第 10 章那条规律**：**浓度决定方向。**
> 在"能尝出来"的浓度范围内（也就是做菜的范围），**抑制是稳定的结论**。

### ⚠️ 还有一个"你自己"的变量

同一项研究的聚类分析发现：**有一群人几乎不被压**。

| 聚类 | 只有糖时的甜度 | 糖 + 柠檬酸时的甜度 | 被压掉多少 |
|------|------------|---------------|----------|
| 聚类 1（110 人，其中 71% 是中国受试者） | 5.80 | **3.25** | 很多 |
| 聚类 3（64 人） | 6.62 | **5.73** | 很少 |

> **厨房含义**：**同一份糖醋汁，你和家人的判断可能天然不同**——
> 这不是谁的舌头"更准"，而是这种相互作用本身就有很大的个体差异。
> **所以调糖醋味要让人尝，而不是照克数配。**

## 12.4 酸的另一面：它在味觉这一侧做什么

第 8 章讲的是酸对**质地、颜色、气味**的作用。这一节只补味觉侧。

| 酸做的事 | 证据 | 厨房含义 |
|---------|------|---------|
| **降低盐的阈值** | 第 9 章：0.0042 M 柠檬酸使咸味察觉阈下降约 **56%**；减钠综述另转引一项研究——**往氯化钠溶液里加醋，显著降低了盐的察觉阈与识别阈**（⚠️ 转引，原文未核） | **觉得淡的时候，一点酸可能比一点盐更对症**。这是"补偿"而不是"加量"（第 10 章） |
| **被甜压住，也压住甜** | 本章 12.3，✅ 两个独立来源 | 糖醋、酸甜、番茄类菜的调味逻辑 |
| **削弱鲜味** | 第 9 章：**味精在强酸或强碱条件下鲜味强度下降** | **一道很酸的菜里"觉得不鲜"，先调酸度，再考虑加鲜味调料** |
| **和"咸"互相增强？** | ⚠️ 只有转引（"酸味与咸味互相增强"），**本书未核到一手** | 只作为方向，不当结论 |
| **"解腻"** | ⚠️ **本书未核到直接证据**，见 12.5 | 只能标为惯例 |

### 酸什么时候加（第 8 章那张表的味觉版补充）

第 8 章给了三个时机（下锅前腌 / 加热中途 / 出锅前后）以及它们的质地与颜色代价。
从**味觉**角度再补两条：

> - **想要酸"香"（醋香、柠檬香、酒香）→ 最后放**：
>   挥发性的酸香一煮就跑（第 8、13 章）；
> - **想要酸"味"（骨架、平衡）→ 可以早放**：
>   不挥发的酸留得住，而且有时间与其他味融合。
>
> **很多菜要放两次醋，就是这个原因**：一次给味，一次给香。

## 12.5 关于"解腻"：本书能说什么、不能说什么

"酸能解腻""喝口茶解腻"是流传极广的说法。本书的处理如下。

**能确认的**：

1. **油腻感不是味觉**。第 9 章已经讲过，五味里没有"腻"。
   对脂肪的感受涉及口腔的触觉/润滑感与脂肪酸的化学感受，走的是另一套系统；
2. **脂肪感是可以被跨模态改变的**。一项一手研究给出了正面证据：
   在低盐奶酪里，**沙丁鱼香气显著增强咸味**，而**脂肪感的增强只在两种香气混合时显著**。
   **也就是说：香气确实能改变你对"油不油"的判断。**

**不能确认的**：

> ⚠️ **"酸能降低油腻感"这条，本书没有核到直接的对照研究。**
> 它在机理上讲得通（改变口腔感受、刺激唾液、与脂肪感竞争注意力），
> 但**讲得通不等于被验证过**。
>
> 本书因此把它标为**惯例 + 机制推理**，并**登记为缺口**。

> **一条诚实的替代表述**（这是本书能给的）：
> **"腻"这个抱怨，先别假设它是脂肪太多。**
> 它也可能是**缺酸（没有对比）、缺香（太单调）、缺咸（味道扁平）、
> 或者温度太高（脂肪在口腔里的行为随温度变化）**。
> **先尝一口判断到底缺什么，再决定加什么**——这正是第 15 章要做的事。

## 12.6 本章的可迁移规则

> ## 看到一道菜里有糖或有酸，问三个问题：
>
> | 顺序 | 问题 | 判据 |
> |------|------|------|
> | **①** | **它是为了"味"，还是为了别的？** | 糖：上色 / 抢水 / 推迟糊化 / 稳定蛋白 / 质地 / 压酸；酸：质地 / 颜色 / 抑酶 / 去腥 / 压甜 / 降盐阈值 |
> | **②** | **如果是为了"味"，它压住了什么？** | 糖压酸、酸压甜、酸压鲜——**这三条都有证据** |
> | **③** | **它该在哪个时机进去？** | 要**香** → 最后；要**味** → 可以早；要**参与反应**（上色、糊化、质地） → 必须早 |
>
> **一条兜底规则**：
> **调"酸甜"这一对时，先把其中一个定下来，再动另一个。**
> 因为它们互相抑制，**同时动两个你会迷路**——
> 你分不清是"酸少了"还是"糖多了"，而这两件事在锅里的补救方式完全不同。

## 12.7 常见说法辨析

按本书约定标注**证据强度**：✅ 有共识 / ⚠️ 有争议 / ❌ 明确错误 / 缺乏证据。
来源见[出处登记](../../standards.md)。

| 说法 | 判定 | 说明 |
|------|------|------|
| "太酸了加点糖" | ✅ **有两个独立来源**，但**代价常被忽略** | 跨文化实测：2.50% 蔗糖使柠檬酸的酸度评分从 6.42 降到 4.79；独立的阈值建模研究显示柠檬酸会抬高蔗糖的甜味阈值。**关键是它双向**——糖压酸的同时，酸也在压糖。所以糖醋菜要放的糖比凭甜度估计的多 |
| "酸能增强甜（一点柠檬让水果更甜）" | ⚠️ **只在阈下浓度的研究里出现过** | 那项跨文化研究在讨论里指出：报告"酸增强甜"的早期研究用的是**阈下浓度**协议；**用阈上浓度的研究一致地得到抑制**。**做菜时你用的是能尝出来的浓度，所以按"抑制"来预期** |
| "菜里放糖就是为了甜" | ❌ **多数时候不是** | 减糖综述列出的糖的功能包括**质地、黏度、体积、颜色形成、稳定性与风味释放**。红烧的糖色（焦糖化/美拉德）、果酱里的糖（降低水活度）、蛋羹里的糖（提高蛋白质变性温度）都不是为了甜 |
| "糖放多了菜会更快糊" | ⚠️ **方向合理，但机理是两条** | 一条是**焦糖化**（糖单独受热分解，特征产物在高于 150 °C 生成）；另一条是糖参与**美拉德**（第 7 章）。⚠️ 本书**没有核到**"含糖多多久会糊"的定量数据，只给方向 |
| "甜的糊/馅更难熟" | ✅ **有实测方向** | 一项研究测得 **35% 蔗糖体系中峰值糊化温度升高约 11~12 °C**。⚠️ 这是特定体系的实验，**不能换算成你的甜馅** |
| "蛋羹里加糖更嫩" | ⚠️ **机理方向有支持，不是直接证据** | 一项差示扫描量热研究显示**蔗糖提高溶菌酶与肌红蛋白的变性温度**。⚠️ 这是**纯蛋白在溶液里**的测量，不是蛋羹。方向可用（糖让蛋白质更耐热 → 凝固窗口往后挪），**但本书不给"加多少糖能多嫩"的数字** |
| "酸能解腻" | ⚠️ **惯例 + 机制推理，本书未核到直接对照** | 能确认的是：**油腻感不是味觉**，而**脂肪感可以被香气跨模态改变**（低盐奶酪研究中混合香气显著增强脂肪感）。但"酸降低腻感"本书**未找到对照研究**，登记为缺口 |
| "酸能让菜更有味，比加盐管用" | ⚠️ **有阈值层面的支持** | 0.0042 M 柠檬酸使咸味察觉阈下降约 **56%**；另有转引称"加醋显著降低盐的察觉阈与识别阈"（⚠️ 原文未核）。**注意这是阈值层面**，说的是"更容易察觉"，不等于"尝起来更咸" |
| "酸的菜里觉得不鲜，是鲜味料放少了" | ⚠️ **先怀疑 pH** | 第 9 章：**味精在强酸或强碱条件下鲜味强度下降**，并有分子构型层面的解释。**先把酸度调下来再判断鲜够不够** |
| "糖醋比例按菜谱来就行" | ⚠️ **个体差异很大** | 同一项跨文化研究的聚类分析显示：某个聚类的甜度被压掉近一半（5.80 → 3.25），另一个聚类几乎不被压（6.62 → 5.73）。**糖醋味必须尝着调** |
| "调酸甜的时候，酸和糖一起加效率高" | ❌ **会让你失去判断力** | 因为它们互相抑制，同时动两个变量时，**你分不清问题出在哪一边**。**先定一个，再调另一个** |

## 12.8 🔎 下次做菜时的用处

1. **看到不甜的菜里有"糖 少许"，先猜它在压酸或帮上色**，再决定省不省。
2. **糖醋汁要放的糖比你想的多**——因为一大半甜被酸吃掉了。
3. **想让一道菜"更酸"，先试减糖，再试加酸。**
4. **调酸甜时一次只动一个变量**，否则你会迷路。
5. **甜的馅、甜的糊要煮得更久或更热**（糖推迟糊化）。
6. **很酸的菜里觉得不鲜，先降酸，别急着加鲜味调料。**
7. **觉得淡，一点酸有时比一点盐更对症**——而且它不推高咸度上限。
8. **醋放两次**：早的一次给味，晚的一次给香。
9. **"腻"先别假设是油多**——可能是缺酸、缺香、缺咸或者温度问题。

## 12.10 本章实操

### 🅐 零成本版 · 任务一：画出你自己的"糖酸抑制曲线"（不用开火）

**需要**：水、糖、白醋（或柠檬汁）、五个杯子。

先配一杯"基准酸水"（酸到你觉得"明显但不难受"），然后做五份，
每份加入**递增**的糖量（第 1 份不加）。

| 份 | 加糖量（刀尖/勺） | 我尝到的酸（0~10） | 我尝到的甜（0~10） | 整体好不好喝（0~10） |
|----|--------------|---------------|---------------|----------------|
| ① | 0（对照） | | 0 | |
| ② | 极少 | | | |
| ③ | 少 | | | |
| ④ | 中 | | | |
| ⑤ | 多 | | | |

做完把"酸"这一列画成一条线（横轴是糖量）。

做完回答：

1. 酸的下降是**一开始就很快**，还是**加到一定量才明显**？
2. 到第几份你开始觉得"甜压过头了"？那一份的酸还剩多少？
3. **你最喜欢的那一份**是第几份？它的酸和甜分别是多少？
4. 这个"最喜欢的点"，和你平时按菜谱放的糖量差多少？

> **这张表就是你自己的糖醋基准**，比任何菜谱的比例都可靠。建议留着，项目 P2 会用到。

### 🅐 零成本版 · 任务二：找出菜谱里"不为甜"的糖

找 3~5 份**不是甜口**的中式菜谱（红烧、酱烧、炒菜、汤都行），
把里面的糖找出来，判断它在干什么。

| 菜谱 | 糖的用量描述 | 我猜它在干什么 | 判据 | 能不能省 |
|------|-----------|------------|------|---------|
| | | | | |
| | | | | |
| | | | | |

**判断提示**：

| 如果这道菜里有… | 糖很可能在… |
|--------------|-----------|
| 番茄、醋、酸菜、泡菜、山楂 | **压酸** |
| "炒糖色""上色""红亮" | **参与褐变**（第 7 章） |
| 长时间收汁 | **质地 + 抢水**（汁更稠、更挂） |
| 酱油、豆瓣等咸味重的调料 | **平衡整体**（也可能在压咸味调料自带的苦/涩） |

### 🅐 零成本版 · 任务三：给"腻"做一次诊断练习

回忆（或下次吃到）一道让你觉得"腻"的菜，按下面逐条排查，**不要直接假设是油多**。

| 可能原因 | 判据 | 我的判断 |
|---------|------|---------|
| 真的脂肪多 | 嘴里有明显的油膜感、凉了会凝 | |
| **缺酸** | 整道菜没有任何对比、一路"沉下去" | |
| **缺香** | 捏鼻测试差别很小（第 9 章） | |
| **缺咸** | 味道扁平、"隔着一层" | |
| **温度问题** | 凉了之后更腻 | |

做完回答：

1. 你判断的主要原因是哪一条？
2. 按本书的顺序（补香 → 补鲜 → 补盐 → 补酸），你会先试哪一个？
3. ⚠️ 本书说"酸解腻"未核到直接证据——这会改变你的做法吗？为什么？

### 🅑 开火版 · 任务四：一份糖醋汁，四个版本（有灶台时做）

**需要**：醋、糖、水、酱油（可选）、四个小碗。

| 版本 | 糖 | 醋 | 尝到的甜 | 尝到的酸 | 整体评价 |
|------|----|----|--------|--------|---------|
| ① 基准 | 1 份 | 1 份 | | | |
| ② 加糖 | **2 份** | 1 份 | | | |
| ③ 减糖 | **0.5 份** | 1 份 | | | |
| ④ 双倍 | 2 份 | **2 份** | | | |

做完回答：

1. ②（加糖）和 ③（减糖）**哪个更能让"酸"明显改变**？
2. ④ 和 ① 的"甜酸比"一样，尝起来是"两倍强"吗？
3. 如果目标是"酸得明显但不刺",你会走 ② 还是 ③ 的方向？
4. 让家人也评一次——**你们的"刚好"差多少？**

### 🅑 开火版 · 任务五：同一份蛋液，两种含糖量

**需要**：鸡蛋、水（或牛奶）、糖、两个碗、蒸锅。

调两份完全一样的蛋液，一份不加糖，一份加糖（自己定量，别太多），
**同锅同时蒸、同时出锅**。

| 组 | 加糖了吗 | 凝固得早还是晚 | 质地（嫩/老/蜂窝） | 出水了吗 |
|----|---------|------------|---------------|---------|
| ① | 否 | | | |
| ② | 是 | | | |

做完回答：

1. 两组凝固的时间点有差别吗？方向符合"糖提高蛋白质变性温度"的预期吗？
2. 质地上有没有可感知的差别？
3. ⚠️ 本书说这条证据来自**纯蛋白在溶液里的测量**，不是蛋羹。
   **你这次实验的结果能不能算"验证"？** 为什么不能？（提示：变量控制、样本数、主观评价）

> **第 3 问才是这个实验的重点**：它让你体会到
> **"自己做一次"和"有证据"之间还差很远**——
> 这正是本书对所有厨房实验的态度：**能形成自己的判据，但不能当成结论去推广。**

> ⚠️ **安全提醒**：实验剩下的食物不要在室温下久放。
> 美国 FDA 的指引是易腐食品在烹调后 **2 小时内**冷藏
> （环境温度高于 90 °F 时缩短到 1 小时）；蛋类菜品的安全最低中心温度为 160 °F（约 71 °C）。
> **各国口径不同，以本地现行发布为准。**
