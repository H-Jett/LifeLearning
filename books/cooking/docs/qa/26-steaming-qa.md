# 第 26 章 思考题参考答案 · 蒸：恒温 100 °C 的温和与它的局限

<a id="q1"></a>
## Q1

**答**：食材不浸在烹饪水中，少了可溶物直接向水里迁移的路径；但热本身仍会改变热敏成分，也会继续改变蛋白质和质地。

<a id="q2"></a>
## Q2

**答**：常压蒸汽温度受水沸点限制，食材表面难达到干热褐变所需的高温且表面保持湿润，因此不能形成煎炸式褐壳。

<a id="q3"></a>
## Q3

**答**：水多先查水线、盖子冷凝、盘子积水与食材自身出水；肉老而干先查中心是否超过目标状态、厚薄是否不均、是否冷藏直上却沿用常温时间。下一次分别只改一个变量，例如调整摆放或缩短至刚达目标状态。

<a id="q4"></a>
## Q4

**答**：中心升温的路径与厚度、形状、起始温度、盘子和蒸汽状态有关，不随重量简单线性变化。重量相同的扁鱼和厚鱼也会有不同结果。
