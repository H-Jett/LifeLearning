# 第 45 章思考题参考答案

## 1. 为什么温度计通常比第二只相似的锅更能提升判断能力？

因为它能把最厚处是否达到目标条件从猜测变成可测证据。第二只相似锅未必解决原有的测量缺口；但温度计也必须正确使用，并遵从当地安全指引。

## 2. 第一次做面包时，怎样把“塌了”拆成热、水、结构三个候选问题？

可分别问：中心是否得到足够且均匀的热；面团中的水分、表面失水和蒸汽如何变化；气体网络是否在能支撑形状时定型。下一次只改变其中一个可记录条件，而不是同时换配方、温度和器具。

## 3. 为什么本章不提供自制罐头或发酵配方？

它们的安全依赖具体食品、工艺和所在地官方要求。通用机制和工业法规分类不足以构成家庭安全流程；应使用针对类别的现行官方资料。
