# 第 28 章 思考题参考答案 · 炖、焖、卤：长时间低温改造结缔组织

<a id="q1"></a>
## Q1

**答**：肉在较早阶段已可“熟”，久炖额外追求的是结缔组织随热与时间改变后的质地。与此同时肌纤维仍会失水，故必须管理两条相反过程。

<a id="q2"></a>
## Q2

**答**：硬部位的结缔组织问题更显著，可能值得以时间换取软化；里脊等瘦嫩部位的主要风险是肌纤维失水，久炖通常没有相同收益。

<a id="q3"></a>
## Q3

**答**：先确认部位、切块大小与当前质地，判断是否仍处在胶原尚未充分转化的阶段；同时把汤汁咸度单独处理，例如避免继续浓缩或分开调整。不能仅因肉韧就无限加大火。

<a id="q4"></a>
## Q4

**答**：小火的价值更多是让热输入、蒸发和机械扰动更可控；常压液体温度仍接近沸点，最终质地还取决于部位、时间、温度轨迹和水分管理。
