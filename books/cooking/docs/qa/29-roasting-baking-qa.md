# 第 29 章 思考题参考答案 · 烤：辐射、热空气与干燥

<a id="q1"></a>
## Q1

**答**：烤盘通过接触传热加热底面，上火管/炉壁以辐射偏向“看得见”的面，热空气则包围表面；三条热路强度和遮挡不同，故颜色与熟度会不同。

<a id="q2"></a>
## Q2

**答**：预热只是让环境和烤盘达到较稳定起点；食材中心仍要靠从表面向内导热，受厚度、起始温度和表面水分影响。

<a id="q3"></a>
## Q3

**答**：出水发软先查摆放是否拥挤、表面是否太湿、蒸汽能否离开；边缘焦黑中心硬先查是否离辐射源太近、切块是否过大或不均、是否只顾上色而未管理中心导热。两种情况都不宜盲目延长时间。

<a id="q4"></a>
## Q4

**答**：热风能加强对流，却不消除辐射、烤盘接触和遮挡造成的不均。翻面或换层是否必要，应由实际颜色、厚度和设备热区决定。
