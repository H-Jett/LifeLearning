# 第 41 章 思考题参考答案 · 蛋炒饭

<a id="q1"></a>
## Q1

**答**：回生与水分重分布能解释冷饭更硬、更易分粒的方向；但熟饭储存同时是安全问题，必须按当地冷却与冷藏指引处理。不能为了得到“隔夜”质地而室温久放。

<a id="q2"></a>
## Q2

**答**：高水配料释放的液态水会占用热量、降低干热表面形成的机会；若下锅量又大，锅灶来不及蒸发水，米粒会在湿热中黏连。应把高水配料分段处理、降低单次量或改变目标。

<a id="q3"></a>
## Q3

**答**：先把饭摊开散出蒸汽并轻轻掰散；青菜按厚薄分段、减少表面水，蛋先短时定型；以小份下饭，观察是否积水和米粒能否分开，再短时合并定味。目标是控制水负担和给锅恢复空间，不是模仿隔夜时间。

<a id="q4"></a>
## Q4

**答**：冷藏米饭的回生与多孔结构研究支持“可能更易分粒”的机制方向，但本书未核到在家庭锅灶中控制其他变量的隔夜饭—现煮饭炒制对照。因此不能升级为“必须”或“必然更好吃”。
