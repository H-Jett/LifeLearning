# 第 36 章 思考题参考答案 · 清炒青菜

<a id="q1"></a>
## Q1

**答**：出水主要涉及细胞水释放、下锅量和蒸发能力；发黄主要涉及叶绿素在热中累积变化。提高火力可能帮助处理一部分水，却不能撤销已经发生的颜色变化；分别诊断才有用。

<a id="q2"></a>
## Q2

**答**：厚梗与薄叶的传热距离和到达目标质地的速度不同。一起下锅时，为等梗变软往往让叶受热过久；分段下锅可让两者更接近地结束。

<a id="q3"></a>
## Q3

**答**：目标是梗熟、叶仍有颜色且锅中不积太多水；变量包括叶面水、一次下锅量、梗叶厚度差和加热时间。先沥干，梗先下、叶后下，必要时减量分批；叶刚塌即尝味并离火。验证看梗是否熟、叶是否仍有颜色、锅中是否积液，而不是一味延长时间。

<a id="q4"></a>
## Q4

**答**：应标为证据不足。现有资料没有给出支持“加盐保绿”的直接对照；相邻焯水资料反而提示加盐会增加水分和水溶性成分损失。不能把惯例写成普适结论。
