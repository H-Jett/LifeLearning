# 第 25 章 思考题参考答案 · 炸：油作为传热介质，外壳是怎么形成的

<a id="q1"></a>
## Q1

**答**：油把热量传给食材，同时表面水汽化、内部水向外迁移，外层因脱水形成壳和孔隙。只看温度会漏掉决定口感和吸油的水分变化。

<a id="q2"></a>
## Q2

**答**：离油后蒸汽冷凝会降低孔内压力，表面附着油可能进入孔道；及时沥去表面油因此可能降低最终油感，但不是零油保证。

<a id="q3"></a>
## Q3

**答**：第一批先检查块是否过厚、油温是否过高或时间是否只顾上色；第二批先检查油温是否因投料太多而下降、时间是否被拖长、离油后是否沥油。两批都不应只用“再炸久一点”处理。

<a id="q4"></a>
## Q4

**答**：复炸可把内部接近熟度与表面再脱水分成两段；但实际效果还受厚度、裹粉、油温、时长和油质影响，不是单纯提高油温。
