# 第 15 章 思考题参考答案 · 调味的纠偏流程

> 只记「问题 + 正确答案」。案例题给完整推理链。
> 回正文：[第 15 章](../chapters/02-taste/15-tasting-loop.md)

<a id="q1"></a>
## Q1：为什么要在"偏淡的那一侧"做决定？

**因为你在高浓度区分辨不出差别——这是可测量的，不是感觉。**

一项 60 人感官小组的研究测了氯化钠溶液的咸度感知：

| 浓度区间 | 表现 |
|---------|------|
| **1.0~6.0 g/L** | 感知强度与浓度**高度线性**（R²=0.9995） |
| **4.0~6.0 g/L** | 用 0.5 g/L 的梯度做排序，准确率 **70%** |
| **超过 6.0 g/L** | 排序准确率**骤降**——**即使梯度放宽到 0.5 g/L，也只有 20%** |

研究据此把感知量表的上限定在 **6.0 g/L**，并且把原液太咸的酱油**稀释 50 倍**后再评价。

**厨房含义**：一锅已经很咸的菜，你**尝不出**"加了这一点之后咸了多少"——
你等于在闭着眼睛调。

**还有第二个理由**：**方向不对称**。"少了"可以补，"多了"只能稀释、去除或掩盖。

**所以两条合起来**：在偏淡的一侧，你**既看得清、又退得回**。

<a id="q2"></a>
## Q2：尝之前的五步准备与证据层级

| 准备 | 做法 | 理由 |
|------|------|------|
| **① 状态** | 在**接近成品**时尝（汤收了、芡勾了） | 收汁与勾芡会大幅改变浓度与味觉强度 |
| **② 温度** | 调到**接近食用温度** | 温度会移动感知（已核到：低温下甜味敏感度下降） |
| **③ 清口** | 两次尝之间**喝一口白水** | 感官评价中样品间用纯水漱口，防止串味 |
| **④ 稀释** | 很浓的东西（酱料、卤汁）**先稀释再判断** | 该研究把酱油稀释 50 倍后评价；高浓度分辨不出 |
| **⑤ 注意力** | **认真对待第一口**；重要的菜让别人也尝一次 | 感官评价每轮间隔 1 小时以避免疲劳；且样品用随机数编码以排除预期 |

**证据层级（重要）**：

- **①②里的机理**（增稠降低味觉强度、低温降低甜味敏感度）是 ✅ **一手研究结论**；
- **③④⑤**是**感官评价的行业方法学**——它们写在研究的"方法"部分，
  是为了**保证测量可靠**而设计的，
  **不是**"这样做菜会更好吃"的实验结论。

本书把后者标为 ⚠️ **惯例 + 有明确理由**：理由清楚、代价为零，所以值得照做，
但不要说成"有实验证明"。

<a id="q3"></a>
## Q3：为什么"多了"比"少了"难救？

**因为你没有"减法工具"。**

盐进了汤里就出不来了；苦味物质溶进去了也拿不回来。能做的只有三类：

| 手段 | 例子 | 证据强度 | 代价 |
|------|------|---------|------|
| **稀释** | 加水/高汤、加无味载体（豆腐、土豆、米饭、面）、另做一份不加盐的合并 | ✅ **确定**（纯物理） | 会**一起稀释掉鲜与香**，通常要再补鲜 |
| **去除** | 撇油、把没焦的部分**换到干净锅**、挑出苦的食材 | ✅ **确定** | 有时会损失一部分成品 |
| **在感受上盖住** | 加糖压酸、加酸解腻、加脂肪降苦 | ⚠️ **有争议** | 混合味有**增强/抑制/无影响**三种结果，**方向取决于浓度** |

**特别要点名一个错误做法**：

> **"放块土豆吸盐"——❌ 机制不成立。**
> 土豆吸走的是**含盐的汤水**，不是盐。净效果等于少量稀释。
> 想稀释就直接加水或加料，更可控。

**推出的纪律**：**宁可先少放，尝过再补。**
这不是保守，是因为**方向不对称**。

<a id="q4"></a>
## Q4：补味的顺序，以及跳过第一步的后果

**顺序：①质地与浓度 → ②盐 → ③鲜与厚 → ④酸 → ⑤香。**

**排序逻辑是"从物理到感受"——越靠前的越会推翻后面的判断。**

| 次序 | 为什么在这里 |
|------|------------|
| **①质地与浓度** | 收汁/勾芡**整体改变所有味的强度**。在它之前做的任何调味判断都会作废 |
| **②盐** | 主味、不可替代（第 11 章）。后面三步都建立在"盐已经对了"之上。注意先把酱油/蚝油/豆瓣带来的钠算进去（第 14 章） |
| **③鲜与厚** | 鲜味物质能**增强咸味感知**，所以它可能让你回头重判第②步。补要**补另一侧**（IMP 占比 20%~80% 时协同最强），且它需要"有东西可增" |
| **④酸** | 酸与甜**互相抑制**、与咸**互相增强**——它会动前面所有东西，所以**小量、靠后** |
| **⑤香** | 挥发性的东西留不住，越早加损失越大。现成的香出锅放 |

**跳过第一步会发生什么**（这是最常见的错误）：

- **汤还没收就定咸淡** → 收完水少了，浓度上来，**太咸**；
- **勾完芡觉得变淡了就加盐** → 但变淡是因为**增稠降低了味觉强度**
  （β 约 −4.16 / −3.29 / −3.43），**钠其实没少**；
  等菜稍凉、口感变化后，就会觉得齁。

**正确动作**：**先把浓度/质地定下来，再开始调味；每一步之后重新尝。**

<a id="q5"></a>
## Q5：哪一类问题调味补不了？

**褐变。**

如果你尝到的是"**颜色浅、没有炒过的味道**"，那不是调味问题，是**第 7 章的问题**：

- 锅不够热；
- 食材表面太湿（有自由水时，那一部分的温度就上不了沸点以上）；
- 一次下锅太多（家用灶通常最高约 2.5 kW，一次约能褐变 800 g 肉）。

**为什么补不了**：褐变香气是**在高温干燥表面上"造"出来的**。
菜已经进入有水的阶段之后，表面温度被钉在沸点附近，**这个窗口已经关上了**。
往里加酱油、加糖、加香料，只能加别的味，**加不出那股香**。

**尝到它时应该做的**：

1. **停止往里加调料**（继续加只会让味道越来越乱）；
2. 接受这一锅，把它当成另一种菜做完（比如就做成清爽版的）；
3. **记下来**：下次分批下锅、表面擦干、锅先充分预热。

> **把"补得了的"和"补不了的"分开，本身就是纠偏能力的一部分。**

<a id="q6"></a>
## Q6："一次只改一个"的具体理由

**因为混合味的结果不可事后拆解。**

第 10 章已经核到：二元味味相互作用可能出现**增强、抑制或无影响**三种结果，
而且**方向取决于浓度**。

这意味着：

> **"加盐 + 加糖"的净效果 ≠ 加盐的效果 + 加糖的效果。**

所以如果你同时加了盐、糖和醋：

- 结果**变好**了 → 你不知道该把功劳记给谁，下次不知道要重复哪一步；
- 结果**变坏**了 → 你不知道该怪谁，甚至可能把有用的那一步也删掉；
- 更糟的是，三者之间可能**互相抵消**，让你误以为"什么都没发生"，于是加更多。

**还有一条补充规则**：**改完要搅匀、等几秒再尝**。两个理由：

1. 固体调料需要时间溶解与分布；
2. 增稠体系里味觉物质的释放本来就慢——**马上尝会低估你刚加的东西**，
   于是你又加一次，然后就过量了。

<a id="q7"></a>
## Q7【案例】：排骨汤"咸够了但寡淡"，且刚勾了薄芡

### （a）完整动作序列

| 步 | 做什么 | 理由 |
|----|-------|------|
| **1** | **什么都先别加。搅匀，等 30 秒，重新尝一次** | 刚勾完芡：一手研究显示**增稠使咸、酸、甜强度均显著下降**。现在这一口**不可靠** |
| **2** | 把汤调到**接近喝的温度**再尝 | 温度会移动感知 |
| **3** | 清口（喝一口白水），再尝一小口 | 排除前一口的串味 |
| **4** | 确认"咸度够"这个判断**在重新尝之后仍然成立** | 如果其实是被芡压低了，那就**不是缺鲜**，而是需要等一等或略调浓度 |
| **5** | 若确实是"咸够但空" → **只补鲜/厚这一项** | 按顺序③；且**只改一个** |
| **6** | **补另一侧**：汤里已有肉（核苷酸侧）→ 补**谷氨酸侧**（一点酱油、海带、番茄、发酵物） | IMP 占比 20%~80% 时鲜味协同最强，**补另一类比加更多同一类有效** |
| **7** | 搅匀、等几秒、**重新尝** | |
| **8** | 若还差一点"厚" → 加一点葱/蒜/久炖一会儿 | 厚味（第 13 章） |
| **9** | **最后**出锅前补香（香油、葱花、白胡椒） | 挥发性的东西最后放 |
| **10** | **记一行**：尝到什么、判断缺什么、做了什么、结果 | 这是唯一会变强的部分 |

### （b）第一步应该排除什么

**排除"芡造成的假性变淡/变钝"。**
刚勾完芡时的那一口是**系统性偏低**的，直接据此下结论会误判。

### （c）补完鲜还是觉得空，怀疑什么

按可能性排序：

1. **缺"厚"而不是缺"鲜"**——一锅只有肉和水的汤，可能确实缺厚味物质
   （葱蒜、发酵物、久炖都能加）；
2. **鲜味调料"没有东西可增"**——第 13 章那条：
   在只有基本味的体系里加味精不会增强任何东西，需要先搭底；
3. **酸度压住了鲜**——如果放了不少酱油（pH 约 5），
   注意"味精在强酸或强碱条件下鲜味强度下降"；
4. **是缺香不是缺味**——第 9 章的诊断：
   "没味道"最常见的原因是缺香。可以做**捏鼻测试**验证。

### （d）不应该做的

- ❌ **加盐**（已经确认咸够了；一手反例：去掉豆瓣的那组咸度更高而鲜味只有 4.25）；
- ❌ **同时加酱油 + 味精 + 醋 + 香油**（一次改了四个，学不到任何东西）；
- ❌ **在刚勾完芡、汤还烫的时候就下结论**。

<a id="q8"></a>
## Q8【案例】：菜谱写"加盐 4 g"，照做后偏咸

### （a）至少三个原因

| 原因 | 机理 |
|------|------|
| **① 你的其他调料带进了更多钠** | 酱油、蚝油、豆瓣都自带盐。实测中 10 种市售酱油的**钠离子平均 54.6 mg/mL**。你用的酱油可能比菜谱作者的咸 |
| **② 你的食材重量/含水量与菜谱不同** | 同样"一份"，水少了浓度就高。收汁程度不同，终点浓度差很多 |
| **③ 你收汁比菜谱久** | 水少 → 浓度上升。菜谱很少写"收到什么程度" |
| **④ 盐的粗细不同** | 不同粗细的盐**同样一勺的重量不同**（若你用勺不用秤）。⚠️ "盐晶体大小与咸味感受的定量关系"本书**未核到一手数据** |
| **⑤ 你在错误的状态/温度下尝并补过一次** | 例如没收汁时觉得淡、又加了一点 |
| **⑥ 个体差异** | 跨文化研究显示同一处理下不同人群聚类的评分差出数倍 |

**注意**：把原因全归到"我口味淡"是**最没用的解释**，因为它推不出任何动作。

### （b）怎么验证

**一次只验证一个**：

1. 先验证①：**下次把盐全部去掉**，只用酱油等复合调料，尝完再决定要不要补盐。
   如果这样就够咸 → 原因是①；
2. 再验证③：**在收汁前后各尝一次并记录**，看浓度跳了多少；
3. 验证④：**用秤称一次你平时那"一勺"盐**，和 4 g 比较。

### （c）下次怎么改写这份菜谱

把"加盐 4 g"改写成**流程 + 判据**：

> 1. 先放酱油/蚝油等带盐的调料（按原量）；
> 2. 收汁到"汤汁能挂住勺背"；
> 3. **此时尝第一口**（接近食用温度、清口后）；
> 4. **盐分 2~3 次加，每次不超过我校准过的"一小撮"**，每次搅匀重尝；
> 5. 记下最终用量 → **这就是我自己的 4 g**。

**这正是项目 P2 的用途**：把"别人的克数"换成"我自己的基准 + 一套流程"。

## Q9【辨析】："多尝几口就能尝准"

**判定：❌ 明确错误（方向反了）。**

**专业感官评价的做法恰恰相反**——它把"少尝"当成可靠性的前提：

| 他们的做法 | 目的 |
|-----------|------|
| 每个样品之间**用纯水漱口** | 消除前一个样品的残留影响 |
| **每轮评价间隔 1 小时**，明确写为"以避免疲劳" | 感官会适应与疲劳 |
| 样品用**三位随机数编码** | 排除预期对判断的影响 |
| 每个样品**重复三次取平均** | 用重复而不是"多尝"来提高可靠性 |

**注意这里的区别**：他们提高可靠性的办法是
**"在受控条件下重复独立的测量"**，
而不是"在同一次里连续多尝几口"。后者只会叠加疲劳与适应。

**厨房里的正确做法**：

1. **认真对待第一口**（它是最可靠的一口）；
2. 两次之间**清口**；
3. 需要更可靠时，**间隔一会儿再尝**，或者**让别人替你尝一次**；
4. 重要的菜**在不同时间尝两次**。

<a id="q10"></a>
## Q10【辨析】："勾完芡尝着淡了，是芡把味吃掉了"

**这条要拆成两半判断。**

### 成立的一半：现象 ✅

一手研究（56 名健康受试者、蔗糖/柠檬酸/0.3 M 氯化钠三种模型饮料 × 三档增稠剂）显示：

> **咸（β=−4.16）、酸（β=−3.29）、甜（β=−3.43）三种强度均随增稠剂加入显著下降**
> （p<0.001），且**幅度与斜率随味觉种类差别很大**。

所以"勾完芡尝着淡了"**不是错觉**。

### 本书不写的一半：机理 ⚠️

**"是芡把味吃掉了"这个说法暗示了一个机理**（黏度把味觉物质困住/挡住）。
但该研究的作者**明确指出**：

> **把黏度作为解释变量时，模型的解释力反而更低。**

也就是说，**黏度本身不是一个好的机理解释**。
本书因此只写**现象与操作结论**，**不写机理**，并把它登记为已知缺口。

### 操作结论（这才是要记住的）

> **勾完芡、放完蚝油、收完汁，一律重新尝。**
> 并且**不要在刚勾完芡的那一口之后马上加盐**——
> 你测到的"淡"里有一部分不是钠变少了。

<a id="q11"></a>
## Q11：两个诚实的局限，以及为什么不给"几克盐"

### 局限一：它不告诉你"应该多咸"

**因为没有人能告诉你。** 跨文化糖酸研究的聚类分析里，
同样的处理（在糖里加酸）：

- 聚类 1（110 人，其中 71% 是中国受试者）：甜度 **5.80 → 3.25**；
- 聚类 3（64 人）：甜度 **6.62 → 5.73**。

**同一杯溶液，不同的人感受到的变化差出数倍。**

### 局限二：它依赖一台会漂移的仪器

第 9 章已核到**老年人味觉与嗅觉功能下降**；
此外感冒、口干、刚吃过很咸或很辣的东西都会改变判断。
**应对办法只有"不要只信一次尝"**：不同时间尝两次，或让别人替你尝。

### 为什么宁可写局限，也不给"一斤菜放几克盐"

三条理由：

1. **给出去也不成立**。第 14 章已经证明：10 种市售酱油的
   总氨基酸差两倍以上、核苷酸差近十倍——**你和菜谱作者用的不是同一批原料**。
   一个精确的克数在别人的厨房里是假精确；
2. **它会挤掉真正有用的东西**。如果本书给了克数，读者就会去背克数，
   而不是去建立**方法**（在什么状态下尝、按什么顺序补、一次只改一个）——
   而只有方法能迁移到第 101 道菜；
3. **这是本书的纪律**：查不到就不写死数字，
   凡个体差异主导的结论只给方向不给数值
   （见[出处登记](../standards.md)的缺口清单）。

> **本书的替代方案是项目 P2**：
> 用几杯不同浓度的盐水，**给你自己**标定一把尺子。
> 之后你说"这道菜我要 4 分咸"时，那个 4 分是**有定义的**——
> 这比任何人给你的克数都更有用。
