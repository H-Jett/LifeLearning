# 第 39 章 思考题参考答案 · 水煮肉片与滑肉

<a id="q1"></a>
## Q1

**答**：第一段负责让肉片分散、表面定型并尽量不过久；第二段负责让它与汤汁、配菜和调味结合。若把两件事压进一段长时间加热，肉片会在等待其他任务完成时继续收缩失水。

<a id="q2"></a>
## Q2

**答**：上浆只能改变表面层的传热与蒸发条件。肉片内部一旦因过久热暴露而蛋白收缩、失水，外层并不能把状态倒回去；核心控制仍是切片、热输入和离火时机。

<a id="q3"></a>
## Q3

**答**：外白只说明表层蛋白已变化；先检查肉片厚薄是否不均、第一段是否等到完全紧实、第二段是否在滚汤中停留过久。下一次只改一项，例如在肉片刚分散、达到安全要求后即进入最终短时合并，而不同时改腌料和火力。安全熟度应按当地指引验证。

<a id="q4"></a>
## Q4

**答**：可确认的方向是淀粉糊化和蛋清凝固形成表面层，可能减缓传热和蒸发；未核到的是家庭场景下各种浆料配比、肉种和锅具中减少失水的定量对照。因此不能承诺“锁住”或给固定比例。
