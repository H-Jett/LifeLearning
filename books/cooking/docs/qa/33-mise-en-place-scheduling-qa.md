# 第 33 章 思考题参考答案 · 切配前置与时间表

<a id="q1"></a>
## Q1

**答**：分钟表把火力、锅具、食材大小和意外都假定为固定；依赖图只声明先后与不可中断关系，更能在实际进度变化时重排。

<a id="q2"></a>
## Q2

**答**：入锅时机不同、混合后易出水或变色的食材不适合早早混在一起。按下锅顺序分组，既保留状态，也减少开火时的判断。

<a id="q3"></a>
## Q3

**答**：先启动饭；番茄炒蛋可在中段完成并短暂保温；清炒青菜等待代价高、开火后需要连续注意力，应在最后切配就绪后再做。具体仍取决于你的锅灶与上桌时间。

<a id="q4"></a>
## Q4

**答**：这会迫使等待代价高的菜过早或过晚完成。不同菜能承受的等待不同；合理的先后出锅、保温和最后一分钟任务更接近成品状态的目标。
