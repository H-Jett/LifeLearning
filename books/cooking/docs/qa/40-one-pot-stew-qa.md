# 第 40 章 思考题参考答案 · 一锅炖

<a id="q1"></a>
## Q1

**答**：菜名不能说明各食材要达到什么状态；按终点分组才能看出谁需要长时湿热、谁怕久、谁应该最后定味。顺序服务的是不同材料的状态，而非“都在同一锅”这一形式。

<a id="q2"></a>
## Q2

**答**：安全控制点关注需要充分加热的食材最厚处是否达到当地要求；口感控制点关注最容易过头的短窗口食材。肉安全达标不等于叶菜刚好，根茎软了也不等于肉的安全要求已满足。

<a id="q3"></a>
## Q3

**答**：带骨肉先在稳定湿热中开始；按土豆和胡萝卜的切块厚度在中段加入；青菜最后加入、刚到目标状态即离火。安全验证点是肉最厚处依当地指引检查；口感验证点是土豆中心与青菜状态。汤汁咸淡在接近最终液量时再定。

<a id="q4"></a>
## Q4

**答**：它遗漏了大块食材渗入慢、瘦肉会失水、蔬菜会过软、液体会浓缩的限制。早放有时服务于汤汁交换或长时软化，但不是所有食材都该承担同样的时间。
