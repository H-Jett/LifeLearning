# 第 34 章 思考题参考答案 · 家庭灶的限制怎么绕

<a id="q1"></a>
## Q1

**答**：最大火只提高持续供热的一端；若下锅量和表面水带来的蒸发负担仍超过系统能力，锅内仍会积水、表面温度受限。应同时减少水负担或分批。

<a id="q2"></a>
## Q2

**答**：分批主要降低某一时刻的食材量和水负担；分段则把“上色、煮透、收汁”等需要不同条件的目标拆到不同阶段。两者可同时使用，但不是同一件事。

<a id="q3"></a>
## Q3

**答**：目标是肉片有可见表面颜色且整体熟透；主要限制是小锅与一个炉头无法同时蒸发四人份肉片带来的水。顺序可为：擦干、按两到三批短时上色并盛出，再合并加液体或调味完成中心熟化。验证不靠分钟，而看每批是否有积水、首次颜色何时出现、合并后是否仍熟而不柴。若仍积水，下次只再减少每批量。

<a id="q4"></a>
## Q4

**答**：盖盖能减少散热并帮助锅内湿热累积，却不会提高热源持续输出；同时它提高湿度，可能延后需要干燥表面的褐变。它适合焖熟，不是无代价的“加火”。
