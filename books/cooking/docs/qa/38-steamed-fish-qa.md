# 第 38 章 思考题参考答案 · 清蒸鱼

<a id="q1"></a>
## Q1

**答**：热从外层向内传，边缘先变白不代表中心已达到安全要求。最厚处通常是热到中心距离最长的位置，安全验证应以它为重点并遵循当地指引。

<a id="q2"></a>
## Q2

**答**：蒸制的任务是以尽量短的额外热暴露完成安全熟度和鱼肉状态；葱姜、酱汁、热油等香气任务不必占用同一段湿热时间。分开后可独立控制口感、液体与香气。

<a id="q3"></a>
## Q3

**答**：不能直接照搬。同重量不代表中心到表面的距离相同：厚切鱼的热路径更长。先以最厚处作为主要变量，准备温度计并按当地安全要求验证；记录达到要求时薄边的状态，下一次再调整切法或摆放，而不是把两者强行用同一时钟控制。

<a id="q4"></a>
## Q4

**答**：蒸出液可能稀释酱汁、带来不想要的气味，也可能保留某些可利用的味道；是否倒取决于成品目标、原料状态与后续调味。它不是安全处理的替代步骤。
