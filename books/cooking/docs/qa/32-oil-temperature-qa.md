# 第 32 章 思考题参考答案 · 油温怎么判断

<a id="q1"></a>
## Q1

**答**：油温描述的是锅中介质的局部状态；食物中心是否熟还取决于食材厚度、初始温度、加热时间与传热路径。颜色只主要反映表面反应，不能替代中心温度或官方安全指引。

<a id="q2"></a>
## Q2

**答**：水遇热油会剧烈反应并可能飞溅；它只说明局部发生了水汽化，不能给出稳定、可迁移的温度读数。少量同类食材试探能同时显示当前任务的声音、出水和上色，更有决策价值。

<a id="q3"></a>
## Q3

**答**：先停止继续加料并降低热输入，必要时离火让系统回退；不要为“维持油温”而继续炸。确认不再持续冒烟后，再以小份食材试探。已明显焦苦的食材不应靠加调味掩盖。

<a id="q4"></a>
## Q4

**答**：烟点随油的种类、品质和使用历史而变，而且目视烟并非精确仪器；即便尚未冒烟，食材表面也可能因局部过热而快速焦化。应同时看食材的颜色速度与锅内状态。
