# 第 35 章 思考题参考答案 · 番茄炒蛋

<a id="q1"></a>
## Q1

**答**：先蛋能保留较干热条件下快速定型的大块蛋；先番茄再倒蛋则让蛋在汁中凝固、与番茄更融合。两者的热和水路径不同，因此成品也不同；先确定想要哪种状态。

<a id="q2"></a>
## Q2

**答**：汁水承载酸、盐、糖和鲜味，并能挂住蛋；但液态水存在时，热量会持续用于升温和蒸发，表面难维持干热褐变。故把蛋的干热阶段放在番茄大量出汁之前。

<a id="q3"></a>
## Q3

**答**：目标是大块嫩蛋与可挂住的番茄汁；限制是小火薄锅容易被食材和水降温。先把番茄切好、擦干外表面；少量分次做蛋，在大半凝固且仍润泽时盛出；再以中等热输入让番茄出汁并略收；尝汁后定味，最后让蛋短时回锅。验证看蛋是否继续收紧、汁是否能裹住蛋，而不是照搬分钟。

<a id="q4"></a>
## Q4

**答**：应标为“证据不足”。盐可能影响蛋白体系，但本书没有核到控制盐量、蛋液组成、锅温和加热方式的家庭对照证据；不能从一次体验推出必然变老。
