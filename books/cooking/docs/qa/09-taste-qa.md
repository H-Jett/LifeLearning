# 第 9 章 思考题参考答案

> 只记「问题 + 正确答案」。案例题给**完整推理链**。
> 涉及数字的地方，来源见[参考书目与出处登记](../standards.md)。

<a id="q1"></a>
## Q1

**问**："味道"由哪三部分构成？为什么"没味道"最常见的原因不是缺盐？怎么当场区分？

**答**：

| 组成 | 是什么 | 有多少种 |
|------|-------|---------|
| **味觉（taste）** | 舌头上的受体接收到的信号 | **只有五种**：甜、咸、酸、苦、鲜 |
| **嗅觉（smell）** | 挥发性分子，吃东西时主要走**鼻后**通路 | **成千上万种** |
| **口腔的其他感觉** | 温度、痛（辣）、触觉（质地）、收敛感（涩） | 走躯体感觉系统 |

**为什么"缺香"比"缺盐"更常见**：一道菜能给你的"味觉"信息只有五个维度，
而"香"的维度是几千个。**当一道菜让你觉得"寡淡、扁平、没意思"时，
统计上更可能是那几千个维度都空着，而不是那五个里少了一个。**

综述给的证明方式很直接：**只要在吃东西时捏住鼻子，整体风味感受就会大幅下降**。

**当场区分（10 秒）**：

1. 捏住鼻子，尝一口，记住感受；
2. 松开鼻子，再尝一口。

| 结果 | 结论 | 该补什么 |
|------|------|---------|
| 两口差别**很大** | 香气系统是有内容的 | 问题可能在味觉侧（盐/鲜/酸） |
| 两口差别**很小** | **这道菜本来就没什么香气** | **补香**——而且香气怕热，要**最后放** |

<a id="q2"></a>
## Q2

**问**：五味各对应什么受体？哪两种仍不确定？本书为什么要写出不确定性？

**答**：

| 味 | 受体 / 通道 | 确定程度 |
|----|-----------|---------|
| 甜 | **T1R2 + T1R3** 二聚体 | 较确定 |
| 鲜 | **T1R1 + T1R3** 二聚体 | 较确定 |
| 苦 | **T2R 家族**（多成员、多态性明显） | 较确定 |
| **酸** | **Otop1**（质子通道）是**最有希望的候选** | ⚠️ **未定论**（早前的一些候选已被后续研究否定） |
| **咸** | **ENaC** 被认为是主要候选 | ⚠️ **未定论**：综述表述"针对 ENaC 的直接验证研究至今尚未成功"；另有证据提示存在**两类**咸味感受细胞（对低浓度敏感 / 对高浓度不敏感） |

**本书为什么写出这些**：三个理由。

1. **防止把"听起来已解决"的问题当成定论**——厨房谣言常常建立在"科学已经证明"上；
2. **它能解释一些现象为什么没有干净答案**：比如"为什么高浓度和低浓度的咸感觉不一样"，
   答案可能就在那"两类细胞"上，但目前还不能写死；
3. **这是本书的写作纪律**：区分事实、官方规定、惯例、传说四层，
   而"科学界尚有争议"属于必须标出来的一层。

<a id="q3"></a>
## Q3

**问**：为什么"舌头味觉分区图"是错的？给出两条独立证据。

**答**：**❌ 与现代味觉生理学不符。**

| 证据 | 内容 | 来源 |
|------|------|------|
| **证据一（解剖层面）** | 味蕾位于**轮廓乳头、菌状乳头、叶状乳头**上；而**丝状乳头**（覆盖舌面大部分、造成舌面粗糙感的那种）**感受触觉、温度和痛觉，不含味蕾，不能感受味道** | 味觉综述（2022） |
| **证据二（细胞层面）** | **每个味蕾都含有一个或多个能对各种味觉品质做出反应的细胞**；也就是说——**味觉细胞是"化学调谐"的，但味蕾不是** | 味觉信号转导综述（2019） |

**准确的表述**：不同区域的**敏感度**可以存在差别，
但"某个区域**只**负责某一种味"是错的。

⚠️ **诚实说明**：这张图的来历（通常被归因于对二十世纪初一项研究的误读与转译）
本书**没有核到**一手考证，所以正文只说"现代生理学证据不支持分区说"，
**不复述那段来历**。

**它为什么流传**：因为它被印进了几代人的课本；
而且人确实能感觉到"苦味在喉咙后部更明显"这类体验——
但那与"分区"是两回事（吞咽时刺激的位置本来就不同）。

<a id="q4"></a>
## Q4

**问**：辣、涩为什么不算味觉？温度通道阈值表能解释哪些厨房现象？

**答**：

**不算味觉的依据**：综述明确表述——
**辛辣（pungency）与收敛（astringency）主要由躯体感觉系统检测，
因此不被列入五种基本味觉。**

**涩的机制**：富含脯氨酸的唾液蛋白与多酚结合并**沉淀**，造成**润滑感丧失**——
所以涩是"嘴里发干、发紧"的**触觉**体验，不是尝到了某种味。

**温度通道阈值表**：

| 通道 | 激活条件 |
|------|---------|
| TRPV1 | 高于 **43 °C** |
| TRPV2 | 高于 **52 °C** |
| TRPV3 | 约 **34~38 °C** 以上 |
| TRPV4 | 约 **27~35 °C** 以上 |
| TRPM8 | 低于约 **25~28 °C** |
| TRPA1 | 低于 **17 °C** |

综述补充：**高于 43 °C 与低于 15 °C 都伴随痛感**。

**它能解释的四个现象**：

| 现象 | 解释 |
|------|------|
| **热的辣菜比凉的辣菜辣** | 辣椒素与高温共用 TRPV1 这一套报警系统，两个刺激叠加 |
| **辣菜放凉辣感减弱** | 同上，去掉了温度那一份贡献 |
| **薄荷、绿茶让人觉得"凉"** | 走的是 TRPM8（低温通道），与实际温度无关 |
| **"太烫"和"太辣"感受相似** | 因为它们本来就是同一类信号（痛/温觉），不是味觉 |

**厨房里的操作推论**：**太辣不能用"稀释"的思路去救**
（那是处理"太咸"的办法）。可以降低食用温度、或走油脂/乳制品那条路（第 14 章）。
⚠️ "喝水解辣无效"这条常见解释本书**未核到**一手对照，只标机制推理。

<a id="q5"></a>
## Q5

**问**：什么是阈值？为什么"阈值以下等于没放"不一定成立？

**答**：

**两种阈值**：

| 名称 | 含义 |
|------|------|
| **察觉阈** | 能感觉到"这杯水里有点什么"的最低浓度 |
| **识别阈** | 能说出"这是咸的"的浓度（**通常高于察觉阈**） |

**阈值解释了调味的非线性**：阈值以下，加多少都像没加；
越过之后，感受迅速出现。**这就是"忽然就有味道了"的原因。**

**为什么"阈下等于没放"不成立——本章给的反例**：

味觉综述指出，多种**焦谷氨酰肽与 Amadori 产物**在**阈下浓度**就能
**增强酱油的鲜味**；而这些化合物在**阈上浓度**下通常被感知为**苦**。

**两条推论**：

1. **有些东西你尝不出它，但它在起作用**——
   这就是"底味""高汤""一点点酱油"存在的意义：
   它们不是为了被尝出来，而是为了**改变别的味道的表现**；
2. **同一种物质，浓度不同，作用可能相反**（阈下增鲜 → 阈上发苦）。
   所以**"好东西多放点"经常是错的**。

<a id="q6"></a>
## Q6

**问**（案例）：冬瓜排骨汤"很清淡、没什么味道"，只放了盐和姜。
（a）四问顺序怎么排查？（b）缺鲜怎么补？（c）缺香怎么补？（d）会不会是缺褐变？

**答**：

**（a）按本章的四问顺序**：

| 顺序 | 问题 | 这道汤的判断 |
|------|------|------------|
| ① 缺香？ | 捏鼻子尝 vs 松鼻子尝 | 冬瓜排骨汤本身香气就少（没有爆香、没有香料、没有褐变），**很可能差别不大 → 缺香** |
| ② 缺鲜？ | 是不是"扁平、一下就没了" | 排骨提供核苷酸侧，但**谷氨酸侧几乎是空的** → **很可能缺鲜** |
| ③ 缺盐？ | 各种味道是不是"隔着一层" | 你已经放了盐，先别急着加 |
| ④ 缺酸？ | 是不是腻、沉、闷 | 清汤通常不腻，这一条大概率不是 |

**（b）缺鲜的补法（关键是"换一类"）**：

这道汤里**排骨已经提供了核苷酸侧**，所以补**谷氨酸侧**收益最大：

| 补法 | 属于哪一侧 | 备注 |
|------|----------|------|
| 几片干香菇或香菇水 | 核苷酸侧（补强同侧） | 也有效，但不如换侧 |
| 一小块海带/昆布 | **谷氨酸侧** ✅ | 与排骨形成协同 |
| 半勺酱油 | **谷氨酸侧** ✅ | 会带颜色 |
| 一点点味精/鸡精 | **谷氨酸侧**（鸡精常含核苷酸） | 见第 9.9 节对"味精有害"的辨析 |
| 一小把虾皮/干贝 | 核苷酸侧为主 | 也带香气 |

**为什么不建议只是多加盐**：

1. 减钠综述给出的方向是反过来的——**鲜味物质能增强咸味强度**
   （0.10% 味精可增强咸味；最佳情形实现约 24.25% 的减钠）。
   **也就是说补鲜往往能顺带解决"觉得淡"**；
2. **加盐不可逆**。汤一旦过咸，只能靠加水稀释（而稀释会把本来就不多的鲜味也稀释掉）。

**（c）缺香的补法（记住：香气怕热，最后放）**：

| 补法 | 加入时机 |
|------|---------|
| 白胡椒粉、香油 | **出锅前/出锅后** |
| 葱花、香菜、芹菜末 | **出锅时撒** |
| 姜丝（换成出锅前再补一点生的） | 分两次：早放的管味，晚放的管香 |

**（d）有没有可能是缺褐变**：**有，而且这是这道汤的结构性问题。**

判断方法很简单：**这道汤从头到尾都泡在水里**。
按第 3、7 章的结论，只要锅里有大量自由水，温度就被封顶在沸点附近，
**褐变窗口从来没有打开过**。

对策（如果你想要更"厚"的汤）：**先把排骨煎/煸上色再加水**。
⚠️ 代价是汤色会变、清爽感会下降——**这是取舍，不是改进**。
如果你要的就是一碗清汤，那就别动它，改从鲜和香入手。

<a id="q7"></a>
## Q7

**问**（案例）：凉拌菜在厨房尝着刚好，上桌却觉得淡。（a）两个可能原因？
（b）对策？（c）怎么改"尝味"这个动作？

**答**：

**（a）至少两个原因**：

| 原因 | 机制 |
|------|------|
| **① 温度变了** | 综述指出**低温下我们对甜味的敏感度下降**（冰淇淋含糖常达 15%、食用温度 −13~−6 °C 就是这个道理）。你在厨房尝的时候菜可能还没凉透，上桌时已经降到更低的温度，整体感受随之变弱 |
| **② 你适应了** | 调味过程中你反复尝同一种味道，感受被钝化——**你以为的"刚好"其实偏淡** |
| ③ 汁没裹上 | 凉拌菜出水后，调味汁被稀释并沉到碗底，**菜本身其实没带走多少味**（这属于"挂不住"的问题，见第 3 章收汁与黏度） |
| ④ 食材继续出水 | 撒了盐的蔬菜会持续渗出水（第 3 章的渗透），把味道冲淡 |

**（b）对策**：

| 针对 | 做法 |
|------|------|
| ① 温度 | **在接近实际食用温度时定味**——凉菜就等它凉了再最后调一次 |
| ② 适应 | 中途**清口**（喝口水）、或**让别人尝一口**（惯例做法，⚠️ 本书未核到对照研究） |
| ③ 挂不住 | 提高汁的黏度（芝麻酱、蒜泥、少量糖/油），或**拌好再静置几分钟让它吸味** |
| ④ 出水 | **提前杀水**：盐渍后挤掉水再调味；或者**上桌前才拌** |

**（c）怎么改"尝味"这个动作本身**：

> **三条通用纪律**：
>
> 1. **在食用温度下尝**（热菜趁热、凉菜等凉）；
> 2. **尝三次就停一停、清口**；
> 3. **最后一次定味放在最接近上桌的时刻**——尤其是会继续出水、继续降温的菜。

## Q8

**问**（辨析）："味精有害"——判断证据强度，复述 FDA 表述，说明本书为什么不给摄入量建议。

**答**：**❌ 官方结论不支持"有害"这个断言。**

**美国 FDA 公开页面的表述（复述）**：

| FDA 说了什么 |
|------------|
| 在食品中添加味精"**一般认为是安全的（GRAS）**" |
| 味精里的谷氨酸与**食物蛋白消化产生的游离谷氨酸在化学上相同** |
| 量级对比：典型膳食**每天从蛋白质获得约 13 g 谷氨酸**，而**添加味精带来的约 0.55 g** |
| **在对照试验中，科学家未能稳定地诱发（人们报告的）反应** |
| 1990 年代 FASEB 报告结论是味精安全，同时指出**敏感个体在不随餐摄入 3 g 或以上时**可能出现**短暂、轻微**的症状；而"**一份添加味精的食物通常含不到 0.5 g**" |
| 标签必须写明"monosodium glutamate"；**含天然游离谷氨酸配料的产品不得标"无味精"** |

**它为什么流传得这么广**：这是一个很好的"厨房传说"样本——
一个基于个案报告的说法，在**没有通过对照试验验证**的情况下，
通过媒体与口耳相传被固化成了"常识"。

**本书为什么不给摄入量建议**：这是本书的写作纪律
（"不做医疗/营养治疗建议，营养相关只讲证据等级"）。本书能做的是：
**复述机构结论的原话与适用范围**，让你自己判断。
**"该不该放味精"是口味与个人选择问题，不是本书能替你决定的事。**

<a id="q9"></a>
## Q9

**问**（辨析）："西瓜撒点盐更甜"——判断证据强度；本书查到的数据是哪个方向的？
为什么反方向的数据不能用来证明它？

**答**：**⚠️ 证据不足，本书不当定论用。**

**本书查到的数据是反方向的**：一篇减钠综述（转引 Stevens 1995）给出的是
**"别的味道如何影响咸味"**：

| 在 NaCl 溶液里加入 | **咸味**察觉阈值的变化 |
|------------------|------------------|
| 0.40 M 蔗糖 | 下降约 **60%** |
| 0.0042 M 柠檬酸 | 下降约 **56%** |
| 0.00025 M 奎宁 | 下降约 **33%** |

**为什么这些数据不能证明"盐提甜"**：

1. **方向不同**：上面测的是"**糖对咸的影响**"，而"盐提甜"问的是"**盐对甜的影响**"。
   感官相互作用**不保证对称**——A 增强 B 不等于 B 增强 A；
2. **指标不同**：上面测的是**察觉阈值**（更容易被察觉），
   而"更甜"说的是**阈上的强度感受**。这是两个不同的量；
3. **结果本来就有三种**：同一篇综述（转引 Keast & Breslin 2003）指出，
   混合味之间可能**增强、抑制或没有影响**——
   **不能假定一定是其中哪一种**。

**本书的结论**：
**"盐提甜"在本书查到的文献里没有对应数据，所以标为 ⚠️ 证据不足。**
它可能是真的，也可能只是"因为盐提升了整体的风味感受"而被归因到甜上；
⚠️ 本书**没有核到**能分辨这两种解释的实验。

**你可以怎么自己验证**：切两块同一个西瓜的相邻部分，一块撒极少量盐、一块不撒，
**蒙眼**让别人递给你（避免预期效应），尝完写下判断。
**做三轮，看看你能不能稳定地分辨。**

<a id="q10"></a>
## Q10

**问**：为什么"补香、补鲜、补酸可逆，加盐不可逆"？这对纠偏顺序意味着什么？

**答**：

**严格说，四者都不可逆**（加进去的东西拿不出来）。
本书说的"可逆"是**实践意义上的**：

| 操作 | 出错后的挽救成本 |
|------|--------------|
| **补香**（香油、葱花、香菜、胡椒） | **最低**。放多了通常只是"某个味道突出"，加一点别的就能压住；而且很多香气会挥发掉 |
| **补鲜** | **较低**。过量表现为"味精味"，可以靠稀释和加酸缓解 |
| **补酸** | **中等**。过量可以靠稀释、加糖或加脂缓解（⚠️"加糖压酸"本书标为方向性证据不足） |
| **加盐** | **最高**。过咸**只有稀释这一条路**——而稀释会把**所有**味道一起冲淡，等于整道菜推倒重来 |

**这就是四问顺序的理由**：

```mermaid
flowchart LR
    A["①补香<br/>（代价最小）"] --> B["②补鲜"] --> C["③补盐<br/>（代价最大）"] --> D["④补酸/调平衡"]
```

> **通用原则**：**先做可逆的事，再做不可逆的事。**
> 这不只是调味的原则，也是全书的方法论——
> 第 5 章说"时间不够就别开始"，第 7 章说"分批下锅"，
> 都是同一个思路：**把不可挽回的决定尽量往后推。**

**一个具体的执行版本**：

| 步骤 | 动作 | 等多久再判断 |
|------|------|------------|
| 1 | 捏鼻测试 → 若缺香，先补香 | 立刻能感觉到 |
| 2 | 若仍"扁平"，补鲜（换一类） | 搅匀后等 10~20 秒 |
| 3 | 若仍"隔着一层"，**少量**加盐 | **每次等 10 秒以上**再尝（盐需要溶解与扩散） |
| 4 | 若觉得腻/沉，出锅前补一点酸 | 立刻尝 |

⚠️ 第 3 步的"等一等"很重要：**盐来不及溶解扩散时，你尝到的是"还没发生的结果"**，
连着加两次是新手最常见的过咸原因。
