# 第 37 章 思考题参考答案 · 红烧肉

<a id="q1"></a>
## Q1

**答**：上色阶段需要相对干的表面与足够热输入；加液体后的湿热阶段以稳定熟化和时间累积为目标；收汁阶段则要处理液量、浓度与挂汁。用同一火力与同一停点，会把不同目标混淆。

<a id="q2"></a>
## Q2

**答**：收汁使溶质浓度上升、黏度提高以便挂住食材，也逐步减少水对温度的限制，让末段色香变化有机会发生。停点应是汁能裹住肉，而不是完全无水。

<a id="q3"></a>
## Q3

**答**：目标是肉保持已得到的软化、汁能挂住而不过咸；限制是继续强收会进一步浓缩盐。先停止继续收，加入少量合适液体稀释并重新尝味；必要时以更温和方式让汁恢复可挂的状态。下次把定味留到接近最终液量时。

<a id="q4"></a>
## Q4

**答**：对结缔组织较多的部位，时间有助于发生软化；但瘦肉受热会失水，且不同部位、温度和切块的取舍不同。因此“越久越嫩”遗漏了肉的结构与温度条件，不能当通用规则。
