# 第 27 章 思考题参考答案 · 煮与汆：水里的对流与溶出

<a id="q1"></a>
## Q1

**答**：可溶物可能进到烹饪水；若汤会被喝掉，这些迁移物仍属于这餐，若弃掉则被带走。但热敏成分还可能因加热而变化，所以喝汤不等于零损失。

<a id="q2"></a>
## Q2

**答**：同一常压下两者温度都接近沸点；大滚主要增加水流、翻动和蒸发。熟制速度仍取决于食材厚度、投料量与实际接触。

<a id="q3"></a>
## Q3

**答**：做汤时可让食材和汤水共同承担风味，切法与时间服务于汤的目标；凉拌菜则希望保留食材口感，通常缩短水中停留并及时停止加热。是否弃水也应按这两个目标区分。

<a id="q4"></a>
## Q4

**答**：汆烫只能在特定时间内改变表面和部分可溶物，不能证明所有风险物都被去除，也不能替代交叉污染控制与对高风险食材的中心熟度要求。
