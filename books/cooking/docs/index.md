# 做菜的原理：从照着菜谱做到自己决定怎么做

> 一本写给**厨房小白**的原理书。它不给你菜谱，它让你**读懂**菜谱——
> 并且在没有菜谱的时候，自己知道该怎么处理食材、加什么、按什么顺序。
> 力求**正确**：数值标注出处、关键数字要两个独立来源，
> 厨房里流传的说法逐条标注证据强度，查不到出处的数字**宁可不写**。

## 这本书要解决的问题

菜谱只告诉你**做什么**，不告诉你**为什么**：

- 为什么要焯水？焯完的水为什么要倒掉？
- 为什么先炒蛋再炒番茄？反过来会怎样？
- 为什么这道菜加料酒、那道菜加糖？
- 盐到底什么时候放？

这些问题的答案不在菜谱里。它们在**四条线**里：

> **做菜就是在四条线上做决定——热、水、味、时间。**
>
> - **热**：能量从哪来、走多快、在表面和中心分别到了什么温度；
> - **水**：食材里的水、锅里的水、跑掉的水——它决定温度的上限和口感的下限；
> - **味**：可溶物的搬运（盐进去、鲜味出来）+ 感受层面的相互作用（谁增强谁、谁盖住谁）；
> - **时间**：和温度是同一件事的两个轴——同样的结果，高温短时和低温长时都可能达到。

**菜谱只是别人在这四条线上做的一组具体选择。** 读懂四条线，你就能改这组选择——
这就是"自己决定怎么做"的含义。

  让你自己推处理方案），答案册给完整推理链。

  - **🅐 零成本版**——不用开火，现在就能做（把菜谱逐行翻译成原理、

    （同样的蛋分别用冷锅、热锅炒，记录差别）。
- 每章末有 **🔎「下次做菜时的用处」**：这一章能让你当场少犯哪个错。

## 关于正确性的四条纪律

厨房是**谣言密度最高**的地方（"锁住肉汁""味精有害""热锅冷油"），
所以这本书的正确性靠纪律维持
（完整版见 [CLAUDE.md](https://github.com/H-Jett/LifeLearning/blob/main/books/cooking/CLAUDE.md) §1）：

1. **数值必须有出处**，并说明波动范围。关键数字要求**两个独立来源**；
   只有一个来源时标注"仅见于 X"；**查不到就不写死数字**，改成写规律或标"经验值"。
   实例：广为流传的"美拉德反应从 140~165 °C 开始"，本书查证后**没有找到一手出处**，
   因此正文不写这个数字（详见[出处登记](standards.md)）。
2. **区分事实 / 官方规定 / 惯例 / 厨房传说**四层，证据不足的一律辨析并标证据强度。
3. **食品安全的数字必须引官方来源**（各国食品安全机构的公开指引），
   **并明确写出不同国家口径不同**——本书同时列出美国、加拿大、英国的数字，
   读者以自己所在地现行发布为准。
4. **不做医疗 / 营养治疗建议**——营养相关只讲证据等级、只复述机构结论的原话与适用范围。

两条补充的硬规矩：

- **只复述，不抄原文**，也不搬运他人的图片与表格版式；要图用 Mermaid 自绘。
- **不写"这么做一定不好吃"这类绝对断言**——写"出现 X 时，先怀疑 Y，用 Z 来验证"。
