# 做菜的原理：从照着菜谱做到自己决定怎么做

> 📖 **在线阅读**：<https://h-jett.github.io/LifeLearning/cooking/>
> 🏠 **书架首页**：<https://h-jett.github.io/LifeLearning/>

一本写给厨房小白的**原理**书。它不给你菜谱，它让你读懂菜谱——
并且在没有菜谱的时候，自己知道该怎么处理食材、加什么、按什么顺序。

## 为什么要有这本书

菜谱只告诉你**做什么**，不告诉你**为什么**：

- 为什么要焯水？焯完的水要倒掉吗？
- 为什么先炒蛋再炒番茄？反过来行不行？
- 为什么这道菜加料酒、那道菜加糖？
- 盐到底什么时候放？

这些问题的答案不在菜谱里，在**四条线**里：**热、水、味、时间**。
一道菜里发生的一切，都是这四条线在起作用。把四条线搞清楚，菜谱就从"指令清单"
变成了"别人的一种参数选择"——而你可以自己选。

## 全书结构

七部分、**45 章 + 5 个实战项目**（完整清单见[学习路线图](docs/roadmap.md)）：

| 部分 | 主题 |
|------|------|
| 一 | 底层四条线：做菜到底在改变什么（传热 / 水 / 蛋白质 / 淀粉 / 褐变 / 酸碱） |
| 二 | 味觉与调味原理：五味与鲜、相互作用、中式调料图谱、什么时候加 |
| 三 | 食材与预处理：肉的嫩化、去腥增香、蔬菜的水与颜色、蛋奶米面 |
| 四 | 基础技法：炒煎炸蒸煮炖烤拌——传热特征、成功条件、失败诊断 |
| 五 | 厨房工程与调度：火力锅具、油温、切配前置、一顿多菜的时间表 |
| 六 | 从原理到菜：拆解家常菜，每步标注对应原理 + 变体推演 |
| 七 | 安全、诊断与拓展：温度红线、失败诊断手册、营养的证据等级 |

## 怎么读

- **正文**讲机理，配 Mermaid 图与对照表，关键数值都带出处
  （统一登记在[参考书目与出处登记](docs/standards.md)）；
- 每章有**「常见说法辨析」**：厨房谣言逐条标注 ✅ 有共识 / ⚠️ 有争议 / ❌ 明确错误 / 缺乏证据；
- 每章末有**思考题**（含【案例】题，答案册给完整推理链）与**本章实操**两档：
  **🅐 零成本版**（不用开火）/ **🅑 开火版**（有灶台和食材时做的小对照实验）；
- 每章末有 **🔎「下次做菜时的用处」** 与 **「本章依据」**。

核心工具是两张表，做任何一道菜都能用：

- [一道菜的处理方案表](docs/forms/dish-plan.md)——食材 → 预处理 → 技法 → 调味顺序 → 火候与时间 → 复盘
- [尝味纠偏表](docs/forms/tasting-fix.md)——太咸 / 太淡 / 发苦 / 发腥 / 太油 / 没味道，分别怎么救

## 正确性怎么保证

厨房是谣言密度最高的地方，所以这本书的写作纪律（完整版见 [CLAUDE.md](CLAUDE.md) §1）：

1. **不凭记忆写作**，关键数字要求两个独立来源；**查不到就不写死数字**，
   改成写规律或标"经验值"并说明波动范围；
2. **食品安全的数字必须引官方来源**，并注明**各国口径不同**；
3. 区分「事实 / 官方规定 / 惯例 / 厨房传说」四层，证据不足的一律进辨析栏目；
4. **不做医疗与营养治疗建议**，营养只讲证据等级；
5. **只复述，不抄原文**，不搬运他人图片与表格版式。
