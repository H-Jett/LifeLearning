## 基础与计量

<a id="green-coffee"></a>
**生豆（green coffee / green bean）**
经处理与干燥、尚未烘焙的咖啡种子。它是咖啡贸易的实物形态，也是一切风味的**前体库**——
后面所有环节只能改造和取用它已有的东西，不能无中生有。

<a id="roasted-coffee"></a>
**熟豆（roasted coffee）**
经过烘焙的咖啡豆。与生豆相比，它的化学组成已被大幅改写：大部分蔗糖消失，
绿原酸大量降解，出现了生豆里几乎不存在的数百种挥发性香气分子。

<a id="dry-basis"></a>
**干基（dry basis, d.b.）**
把含水量扣除后再算百分比的表示方式。咖啡文献里的成分含量绝大多数是干基，
因为生豆含水率本身会变（第 12 章），不扣水就没法跨样品比较。
**看到成分含量先确认是干基还是湿基**，否则数字之间差的可能只是水。

<a id="arabica"></a>
**阿拉比卡（Arabica，*Coffea arabica*）**
商业上产量与价格最高的咖啡物种，四倍体、可自花授粉。
化学上的典型特征是咖啡因与绿原酸较低、蔗糖与脂质较高（第 1、6 章）。

<a id="canephora"></a>
**卡内弗拉 / 罗布斯塔（Canephora / Robusta，*Coffea canephora*）**
第二大商业物种，二倍体。"罗布斯塔"严格说是它的一个栽培群，但市场上常被当作物种名使用。
化学上咖啡因与绿原酸明显高于阿拉比卡，蔗糖与脂质较低（第 1、6 章）。

<a id="precursor"></a>
**风味前体（flavor precursor）**
本身不（或不太）呈现最终风味，但在烘焙中会转化成呈味呈香物质的成分。
咖啡里最重要的三类前体是**蔗糖、蛋白质/氨基酸、绿原酸**。
"这支豆有潜力"这句话，技术上说的就是"它的前体格局好"。

## 生物碱

<a id="caffeine"></a>
**咖啡因（caffeine，1,3,7-三甲基嘌呤二酮）**
咖啡里最著名的生物碱，**味觉上是苦的**，且**热稳定性高**——
所以它在烘焙中损失有限，不同烘焙度之间的差异远小于坊间想象（第 1、17 章）。
需要强调的是：它虽然苦，却**不是**咖啡苦味的主要贡献者（第 1 章 §1.4）。

<a id="trigonelline"></a>
**葫芦巴碱（trigonelline，N-甲基吡啶-3-羧酸）**
生豆中含量仅次于咖啡因的生物碱，本身带苦味但贡献有限。
它的重要性在于**烘焙中会大量分解**，产物包括烟酸（niacin / 维生素 B3）
以及一系列吡啶、吡咯类挥发物——后者是咖啡"烘烤香"的组成部分（第 1、16 章）。

## 酚类与它们的去路

<a id="cga"></a>
**绿原酸类（chlorogenic acids, CGA）**
一大类酚酸与奎宁酸形成的酯的总称（**不是单一化合物**），生豆中含量最高的酚类物质。
主要亚类是咖啡酰奎宁酸（CQA）、阿魏酰奎宁酸（FQA）和二咖啡酰奎宁酸（diCQA）。
它们在烘焙中大量降解，是**苦味与涩感的主要来源链条的起点**（第 1、17 章）。

<a id="cql"></a>
**绿原酸内酯（chlorogenic acid lactones, CQL）**
绿原酸在烘焙中脱水成环形成的内酯。研究把它与**中浅烘咖啡的苦味**联系起来
（第 1 章 §1.4 给出文献）。

<a id="phenylindane"></a>
**苯基茚满（phenylindanes）**
绿原酸内酯在**更深烘焙**下进一步转化的产物，与"粗糙、持久、后段回上来"的那种苦味相关。
它是"深烘的苦和浅烘的苦不是同一种苦"这一现象的化学解释（第 1、17 章）。

<a id="quinic-acid"></a>
**奎宁酸（quinic acid）**
绿原酸水解后释放出的酸。它既有酸味也带涩与"干"的感觉，
常被用来解释**过度烘焙或长时间保温后**咖啡出现的那种不讨喜的酸涩（第 1、17 章）。

<a id="caffeic-acid"></a>
**咖啡酸（caffeic acid）**
绿原酸水解的另一半产物（酚酸部分）。注意它与咖啡因（caffeine）是**完全不同**的物质，
中文名只差一个字，英文也只差几个字母，是初学时最容易混的一对。

## 糖类与褐变产物

<a id="sucrose"></a>
**蔗糖（sucrose）**
生豆中最主要的游离糖，是阿拉比卡与罗布斯塔差异最大的成分之一。
它在烘焙中**几乎被消耗殆尽**——既参与焦糖化，也水解成还原糖后参与美拉德反应。
所以"咖啡的甜"基本不是蔗糖直接带来的（第 1、16 章）。

<a id="reducing-sugar"></a>
**还原糖（reducing sugars）**
葡萄糖、果糖等含游离羰基的糖。它们是**美拉德反应的糖一侧反应物**，
生豆中游离态含量很低，但蔗糖水解会补充它们。

<a id="maillard"></a>
**美拉德反应（Maillard reaction）**
还原糖的羰基与氨基酸/蛋白质的氨基之间的一系列反应，产生大量香气分子与褐色高分子。
它是烘焙中**最重要的风味生成机制**，不是单一反应而是一整张反应网络（第 16 章）。

<a id="strecker"></a>
**斯特雷克降解（Strecker degradation）**
美拉德反应网络中的一支：氨基酸与二羰基化合物反应，脱羧脱氨生成相应的醛。
很多咖啡里"麦芽""可可""坚果"类气味的分子出自这条路径（第 16 章）。

<a id="caramelization"></a>
**焦糖化（caramelization）**
糖在受热下（**不需要氨基参与**）自身脱水、聚合、裂解的过程。
它与美拉德反应常被混为一谈，但反应物不同、产物不同——分清两者是读懂烘焙章节的前提。

<a id="melanoidin"></a>
**类黑精（melanoidins）**
美拉德反应末期形成的褐色高分子含氮化合物，结构至今没有完全定论。
它们贡献咖啡的颜色，并被认为参与**body 与部分苦味**（第 1、16 章）。

<a id="polysaccharide"></a>
**多糖（polysaccharides）**
生豆干重里占比最大的一类物质，主要是半乳甘露聚糖（galactomannan）、
阿拉伯半乳聚糖（arabinogalactan）与纤维素。它们大部分构成细胞壁、不溶于水，
但**部分片段在烘焙中被解聚**后可被萃出，参与 body（第 1、18 章）。

## 脂质、蛋白质与酸

<a id="lipid"></a>
**脂质 / 咖啡油（lipids / coffee oil）**
以甘油三酯为主，集中在胚的细胞内，烘焙中基本不挥发但会向豆表迁移。
它们几乎不溶于水，因此在滤纸冲煮与意式/金属滤网之间造成明显的口感差异（第 1、26、30 章）。

<a id="protein-aa"></a>
**蛋白质与游离氨基酸（proteins & free amino acids）**
生豆中的储藏蛋白与少量游离氨基酸，是**美拉德反应的氨基一侧反应物**。
它们在成品咖啡里剩得很少，重要性几乎全在"作为前体"这一面（第 1、16 章）。

<a id="organic-acid"></a>
**有机酸（organic acids）**
咖啡酸味的直接来源。生豆里主要是柠檬酸、苹果酸等；
烘焙中一部分被分解，另一部分（如甲酸、乙酸、乳酸、奎宁酸）被生成（第 1、17 章）。

<a id="titratable-acidity"></a>
**可滴定酸度（titratable acidity）**
用碱滴定测得的总酸量，与 **pH 不是一回事**：pH 只反映游离氢离子浓度，
可滴定酸度反映酸的总量。两杯 pH 相同的咖啡可以酸得完全不一样（第 1、22 章）。

## 感受侧的词

<a id="body"></a>
**body（醇厚度 / 口感重量）**
舌面感受到的"重量感与黏稠感"，属于**触觉**而非味觉。
主要与不挥发性溶质总量、脂质、被解聚的多糖片段与悬浮细粉相关（第 1 章 §1.5）。

<a id="astringency"></a>
**涩（astringency）**
不是味道而是一种**触觉/化学感受**：多酚类与唾液蛋白结合，使口腔黏膜失去润滑。
所以涩是"干、收紧、起皱"，与苦是两回事，虽然它们经常同时出现（第 1、4 章）。

<a id="flavor"></a>
**风味（flavor）**
味觉（舌）+ 嗅觉（尤其是**口腔后部经鼻腔的回气嗅觉**）+ 三叉神经感受（温度、刺激、涩、
奶油感）三者在大脑里合成的整体知觉。
**"风味"绝大部分来自嗅觉**——这是第 4 章的主题，也是"捏住鼻子喝咖啡"这个实验能说明的事。

<a id="volatile"></a>
**挥发性香气物质（volatile aroma compounds）**
分子量较小、能在常温下挥发进入鼻腔的化合物。烘焙咖啡里已被鉴定出的种类数以百计，
但其中真正对香气有贡献的只是很小一部分——**含量高不等于贡献大**，
关键是它的**气味阈值**（第 4、16 章）。

## 萃取侧的词

<a id="extraction-yield"></a>
**萃取率（extraction yield, PE / EY）**
被溶出进入液体的干物质**占投入咖啡粉干重的百分比**。
它衡量的是"从粉里取走了多少"，与"这杯有多浓"是两个独立的量（第 22 章）。

<a id="tds"></a>
**TDS（total dissolved solids，总溶解固体）**
咖啡液中溶解物质的质量百分比，也就是通常说的"**浓度**"。
它衡量的是"这杯有多浓"，与萃取率同样是两个独立的量——
**同一个 TDS 可以由完全不同的萃取率做到**（第 22 章）。

<a id="solubility"></a>
**溶解度与溶出速率（solubility & dissolution rate）**
两个常被混淆的概念：**溶解度**是"最多能溶多少"（热力学上限），
**溶出速率**是"多快溶出去"（动力学）。冲煮时间调的主要是后者（第 21、24 章）。

## 咖啡果与生豆的结构

<a id="exocarp"></a>
**外果皮（exocarp / epicarp）**
咖啡果最外面的那层表皮，带蜡质角质层。未成熟时含大量叶绿素而呈绿色，
成熟时叶绿素降解、花青素积累而转红；也存在成熟时不变红的**黄果**突变型（第 2 章）。

<a id="pulp"></a>
**果肉（pulp，外中果皮）**
外果皮之下、胶质层之外的那层多汁组织，成熟时软化。
水洗法里它被去果皮机刮掉，日晒法里它留在豆上一起干燥。
它的干制品就是 cascara 的主要来源（第 2、10 章）。

<a id="mucilage"></a>
**胶质层（mucilage，内中果皮）**
紧贴羊皮层的那层黏滑组织，由几层栅状细胞构成。**它绝大部分是水**，
糖与果胶物质的含量都不高——所以"胶质层 = 糖"是常见误解。
它的真正角色是**发酵的底物**，处理法的差异很大程度上是在处理它（第 2、10、11 章）。

<a id="parchment"></a>
**羊皮层（parchment / pergamino，内果皮）**
包在种子外面的一层木质化硬壳，主要成分是纤维素、半纤维素与木质素。
产地常常带着它储存（parchment coffee / en pergamino），出口前才**脱壳（hulling）**（第 2、12、13 章）。

<a id="silverskin"></a>
**银皮（silverskin，珠心残余 perisperm）**
贴在种子表面的一层极薄的膜，是珠心被胚乳挤压后的残余。
它跟着生豆进烘焙机，在烘焙中脱落成银皮屑，但**中央线的沟里通常会残留**（第 2、15 章）。

<a id="chaff"></a>
**银皮屑（chaff）**
烘焙过程中从豆表脱落的银皮碎片。烘焙机需要专门排除它，
否则积聚在机内可能被烤焦。它是"银皮"这一层在烘焙环节的名字（第 2、15 章）。

<a id="endosperm"></a>
**胚乳（endosperm）**
种子里储存养分的组织，也就是你说的"咖啡豆"的主体。
第 1 章那张成分表描述的就是它。它的细胞壁多糖构成了生豆干重里占比最大的一部分（第 1、2、18 章）。

<a id="center-cut"></a>
**中央线（center cut）**
咖啡豆平的那一面上那道纵向的沟。它是两粒种子在果实里对生、互相贴合留下的形态，
沟里常有银皮残留。它的颜色与完整性是生豆瑕疵判断的观察点之一（第 2、13 章）。

<a id="peaberry"></a>
**圆豆（peaberry）**
一颗果实里只有一枚胚珠正常发育时形成的**单粒、近球形**的种子。
它形状与平豆不同，因此常被单独筛出售卖；但"更好喝"这一说法本书未找到对照研究支持（第 2 章）。

<a id="cascara"></a>
**咖啡果皮茶（cascara）**
咖啡果实的干制果肉/果壳，可以冲泡成饮品。在欧盟，它已按新食品法规
作为"第三国传统食品"被通报（第 2 章给出文件坐标）。

## 水与水质

<a id="hardness"></a>
**硬度（hardness）**
水中**钙、镁等二价阳离子的总量**，常以 mg/L CaCO₃（ppm as CaCO₃）表示。
它是"有多少东西"的量，与碱度**不是**一回事（第 3 章）。

<a id="alkalinity"></a>
**碱度（alkalinity）**
水**中和酸的能力**（缓冲能力），主要由碳酸氢根贡献，同样常以 mg/L CaCO₃ 表示。
它决定结垢倾向，也决定咖啡里的酸会被"顶掉"多少。
**单位与硬度相同，所以是最容易被混淆的一对**（第 3 章）。

## 感官通路与阈值

<a id="orthonasal"></a>
**前鼻嗅觉（orthonasal olfaction）**
吸气时气味分子从鼻孔进入鼻腔的路径——你**闻**杯子时用的就是这条（第 4 章）。

<a id="retronasal"></a>
**回气嗅觉（retronasal olfaction）**
食物在口中释放的挥发物随呼气从口腔后部上行进入鼻腔的路径——你**喝**的时候用的是这条。
人习惯把它的内容归因到"嘴里"，于是把它当成了"味道"。
**"风味"的绝大部分信息来自这条通路**（第 4 章）。

<a id="chemesthesis"></a>
**化学触感 / 三叉神经感受（chemesthesis）**
由三叉神经等躯体感觉神经介导的口鼻腔化学感受，包括辣、凉、刺激、
以及部分涩感与温度感。它**既不是味觉也不是嗅觉**，却是"口感"的重要组成（第 1、4 章）。

<a id="detection-threshold"></a>
**检测阈（detection threshold）**
能察觉"这个样品与空白不同"的最低浓度。**察觉到有东西，但说不出是什么**（第 4 章）。

<a id="recognition-threshold"></a>
**识别阈（recognition threshold）**
能说出"这是苦的/酸的"的最低浓度，**通常高于检测阈**。
第 1 章引用的那些苦味阈值属于这一类（第 4 章）。

<a id="oav"></a>
**气味活性值（odor activity value, OAV）**
某成分在样品中的**浓度 ÷ 它的气味阈值**。OAV > 1 才意味着它单独存在时可被闻到。
它解释了为什么"检出多"不等于"闻得到"（第 4、16 章）。

## 证据与研究方法

<a id="grade"></a>
**GRADE（Grading of Recommendations, Assessment, Development and Evaluation）**
国际通用的证据分级方法，把系统综述与荟萃分析的证据分为
**高 / 中 / 低 / 极低**四级：研究设计决定起点，异质性、发表偏倚、不精确等因素可上下调整。
**它评的是"证据有多可靠"，不是"效应有多大"**（第 5 章）。

<a id="confounding"></a>
**混杂与残余混杂（confounding / residual confounding）**
当某个第三变量同时影响暴露与结局时产生的虚假关联；即使做过统计调整，
因测量误差或建模粗糙而残留下来的那部分叫**残余混杂**。
吸烟是咖啡健康研究里的头号混杂（第 5 章）。

<a id="mendelian-randomization"></a>
**孟德尔随机化（Mendelian randomization, MR）**
用与暴露相关的遗传变异作为**工具变量**来推断因果的方法。
它能降低混杂与反向因果的影响，但依赖三个不易验证的假设，
且在咖啡这类高度行为化的暴露上要格外小心（第 5 章）。
