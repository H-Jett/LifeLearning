## 基础与计量

<a id="green-coffee"></a>
**生豆（green coffee / green bean）**
经处理与干燥、尚未烘焙的咖啡种子。它是咖啡贸易的实物形态，也是一切风味的**前体库**——
后面所有环节只能改造和取用它已有的东西，不能无中生有。

<a id="roasted-coffee"></a>
**熟豆（roasted coffee）**
经过烘焙的咖啡豆。与生豆相比，它的化学组成已被大幅改写：大部分蔗糖消失，
绿原酸大量降解，出现了生豆里几乎不存在的数百种挥发性香气分子。

<a id="dry-basis"></a>
**干基（dry basis, d.b.）**
把含水量扣除后再算百分比的表示方式。咖啡文献里的成分含量绝大多数是干基，
因为生豆含水率本身会变（第 12 章），不扣水就没法跨样品比较。
**看到成分含量先确认是干基还是湿基**，否则数字之间差的可能只是水。

<a id="arabica"></a>
**阿拉比卡（Arabica，*Coffea arabica*）**
商业上产量与价格最高的咖啡物种，四倍体、可自花授粉。
化学上的典型特征是咖啡因与绿原酸较低、蔗糖与脂质较高（第 1、6 章）。

<a id="canephora"></a>
**卡内弗拉 / 罗布斯塔（Canephora / Robusta，*Coffea canephora*）**
第二大商业物种，二倍体。"罗布斯塔"严格说是它的一个栽培群，但市场上常被当作物种名使用。
化学上咖啡因与绿原酸明显高于阿拉比卡，蔗糖与脂质较低（第 1、6 章）。

<a id="precursor"></a>
**风味前体（flavor precursor）**
本身不（或不太）呈现最终风味，但在烘焙中会转化成呈味呈香物质的成分。
咖啡里最重要的三类前体是**蔗糖、蛋白质/氨基酸、绿原酸**。
"这支豆有潜力"这句话，技术上说的就是"它的前体格局好"。

## 生物碱

<a id="caffeine"></a>
**咖啡因（caffeine，1,3,7-三甲基嘌呤二酮）**
咖啡里最著名的生物碱，**味觉上是苦的**，且**热稳定性高**——
所以它在烘焙中损失有限，不同烘焙度之间的差异远小于坊间想象（第 1、17 章）。
需要强调的是：它虽然苦，却**不是**咖啡苦味的主要贡献者（第 1 章 §1.4）。

<a id="trigonelline"></a>
**葫芦巴碱（trigonelline，N-甲基吡啶-3-羧酸）**
生豆中含量仅次于咖啡因的生物碱，本身带苦味但贡献有限。
它的重要性在于**烘焙中会大量分解**，产物包括烟酸（niacin / 维生素 B3）
以及一系列吡啶、吡咯类挥发物——后者是咖啡"烘烤香"的组成部分（第 1、16 章）。

## 酚类与它们的去路

<a id="cga"></a>
**绿原酸类（chlorogenic acids, CGA）**
一大类酚酸与奎宁酸形成的酯的总称（**不是单一化合物**），生豆中含量最高的酚类物质。
主要亚类是咖啡酰奎宁酸（CQA）、阿魏酰奎宁酸（FQA）和二咖啡酰奎宁酸（diCQA）。
它们在烘焙中大量降解，是**苦味与涩感的主要来源链条的起点**（第 1、17 章）。

<a id="cql"></a>
**绿原酸内酯（chlorogenic acid lactones, CQL）**
绿原酸在烘焙中脱水成环形成的内酯。研究把它与**中浅烘咖啡的苦味**联系起来
（第 1 章 §1.4 给出文献）。

<a id="phenylindane"></a>
**苯基茚满（phenylindanes）**
绿原酸内酯在**更深烘焙**下进一步转化的产物，与"粗糙、持久、后段回上来"的那种苦味相关。
它是"深烘的苦和浅烘的苦不是同一种苦"这一现象的化学解释（第 1、17 章）。

<a id="quinic-acid"></a>
**奎宁酸（quinic acid）**
绿原酸水解后释放出的酸。它既有酸味也带涩与"干"的感觉，
常被用来解释**过度烘焙或长时间保温后**咖啡出现的那种不讨喜的酸涩（第 1、17 章）。

<a id="caffeic-acid"></a>
**咖啡酸（caffeic acid）**
绿原酸水解的另一半产物（酚酸部分）。注意它与咖啡因（caffeine）是**完全不同**的物质，
中文名只差一个字，英文也只差几个字母，是初学时最容易混的一对。

## 糖类与褐变产物

<a id="sucrose"></a>
**蔗糖（sucrose）**
生豆中最主要的游离糖，是阿拉比卡与罗布斯塔差异最大的成分之一。
它在烘焙中**几乎被消耗殆尽**——既参与焦糖化，也水解成还原糖后参与美拉德反应。
所以"咖啡的甜"基本不是蔗糖直接带来的（第 1、16 章）。

<a id="reducing-sugar"></a>
**还原糖（reducing sugars）**
葡萄糖、果糖等含游离羰基的糖。它们是**美拉德反应的糖一侧反应物**，
生豆中游离态含量很低，但蔗糖水解会补充它们。

<a id="maillard"></a>
**美拉德反应（Maillard reaction）**
还原糖的羰基与氨基酸/蛋白质的氨基之间的一系列反应，产生大量香气分子与褐色高分子。
它是烘焙中**最重要的风味生成机制**，不是单一反应而是一整张反应网络（第 16 章）。

<a id="strecker"></a>
**斯特雷克降解（Strecker degradation）**
美拉德反应网络中的一支：氨基酸与二羰基化合物反应，脱羧脱氨生成相应的醛。
很多咖啡里"麦芽""可可""坚果"类气味的分子出自这条路径（第 16 章）。

<a id="caramelization"></a>
**焦糖化（caramelization）**
糖在受热下（**不需要氨基参与**）自身脱水、聚合、裂解的过程。
它与美拉德反应常被混为一谈，但反应物不同、产物不同——分清两者是读懂烘焙章节的前提。

<a id="melanoidin"></a>
**类黑精（melanoidins）**
美拉德反应末期形成的褐色高分子含氮化合物，结构至今没有完全定论。
它们贡献咖啡的颜色，并被认为参与**body 与部分苦味**（第 1、16 章）。

<a id="polysaccharide"></a>
**多糖（polysaccharides）**
生豆干重里占比最大的一类物质，主要是半乳甘露聚糖（galactomannan）、
阿拉伯半乳聚糖（arabinogalactan）与纤维素。它们大部分构成细胞壁、不溶于水，
但**部分片段在烘焙中被解聚**后可被萃出，参与 body（第 1、18 章）。

## 脂质、蛋白质与酸

<a id="lipid"></a>
**脂质 / 咖啡油（lipids / coffee oil）**
以甘油三酯为主，集中在胚的细胞内，烘焙中基本不挥发但会向豆表迁移。
它们几乎不溶于水，因此在滤纸冲煮与意式/金属滤网之间造成明显的口感差异（第 1、26、30 章）。

<a id="cafestol"></a>
**咖啡醇（cafestol）**
咖啡特有的一类**双萜**之一。它几乎不溶于水而随油脂走，因此**滤纸会把它大量留住**，
金属滤网、法压壶、煮沸式与意式则留得多（第 1、5 章给出文献坐标）。
第 5 章引用的机构综述把滤泡咖啡与煮沸咖啡在血脂结局上的差异归因于这一类物质。

<a id="kahweol"></a>
**咖啡豆醇（kahweol）**
与咖啡醇同属咖啡双萜，来源与去路相似。**两者的比值**可用于区分不同的咖啡物种与变种——
例如利比里卡各变种之间就能靠这个比值分开（第 5、6 章）。

<a id="protein-aa"></a>
**蛋白质与游离氨基酸（proteins & free amino acids）**
生豆中的储藏蛋白与少量游离氨基酸，是**美拉德反应的氨基一侧反应物**。
它们在成品咖啡里剩得很少，重要性几乎全在"作为前体"这一面（第 1、16 章）。

<a id="organic-acid"></a>
**有机酸（organic acids）**
咖啡酸味的直接来源。生豆里主要是柠檬酸、苹果酸等；
烘焙中一部分被分解，另一部分（如甲酸、乙酸、乳酸、奎宁酸）被生成（第 1、17 章）。

<a id="titratable-acidity"></a>
**可滴定酸度（titratable acidity）**
用碱滴定测得的总酸量，与 **pH 不是一回事**：pH 只反映游离氢离子浓度，
可滴定酸度反映酸的总量。两杯 pH 相同的咖啡可以酸得完全不一样（第 1、22 章）。

## 感受侧的词

<a id="body"></a>
**body（醇厚度 / 口感重量）**
舌面感受到的"重量感与黏稠感"，属于**触觉**而非味觉。
主要与不挥发性溶质总量、脂质、被解聚的多糖片段与悬浮细粉相关（第 1 章 §1.5）。

<a id="astringency"></a>
**涩（astringency）**
不是味道而是一种**触觉/化学感受**：多酚类与唾液蛋白结合，使口腔黏膜失去润滑。
所以涩是"干、收紧、起皱"，与苦是两回事，虽然它们经常同时出现（第 1、4 章）。

<a id="flavor"></a>
**风味（flavor）**
味觉（舌）+ 嗅觉（尤其是**口腔后部经鼻腔的回气嗅觉**）+ 三叉神经感受（温度、刺激、涩、
奶油感）三者在大脑里合成的整体知觉。
**"风味"绝大部分来自嗅觉**——这是第 4 章的主题，也是"捏住鼻子喝咖啡"这个实验能说明的事。

<a id="volatile"></a>
**挥发性香气物质（volatile aroma compounds）**
分子量较小、能在常温下挥发进入鼻腔的化合物。烘焙咖啡里已被鉴定出的种类数以百计，
但其中真正对香气有贡献的只是很小一部分——**含量高不等于贡献大**，
关键是它的**气味阈值**（第 4、16 章）。

## 萃取侧的词

<a id="extraction-yield"></a>
**萃取率（extraction yield, PE / EY）**
被溶出进入液体的干物质**占投入咖啡粉干重的百分比**。
它衡量的是"从粉里取走了多少"，与"这杯有多浓"是两个独立的量（第 22 章）。

<a id="tds"></a>
**TDS（total dissolved solids，总溶解固体）**
咖啡液中溶解物质的质量百分比，也就是通常说的"**浓度**"。
它衡量的是"这杯有多浓"，与萃取率同样是两个独立的量——
**同一个 TDS 可以由完全不同的萃取率做到**（第 22 章）。

<a id="solubility"></a>
**溶解度与溶出速率（solubility & dissolution rate）**
两个常被混淆的概念：**溶解度**是"最多能溶多少"（热力学上限），
**溶出速率**是"多快溶出去"（动力学）。冲煮时间调的主要是后者（第 21、24 章）。

## 咖啡果与生豆的结构

<a id="exocarp"></a>
**外果皮（exocarp / epicarp）**
咖啡果最外面的那层表皮，带蜡质角质层。未成熟时含大量叶绿素而呈绿色，
成熟时叶绿素降解、花青素积累而转红；也存在成熟时不变红的**黄果**突变型（第 2 章）。

<a id="pulp"></a>
**果肉（pulp，外中果皮）**
外果皮之下、胶质层之外的那层多汁组织，成熟时软化。
水洗法里它被去果皮机刮掉，日晒法里它留在豆上一起干燥。
它的干制品就是 cascara 的主要来源（第 2、10 章）。

<a id="mucilage"></a>
**胶质层（mucilage，内中果皮）**
紧贴羊皮层的那层黏滑组织，由几层栅状细胞构成。**它绝大部分是水**，
糖与果胶物质的含量都不高——所以"胶质层 = 糖"是常见误解。
它的真正角色是**发酵的底物**，处理法的差异很大程度上是在处理它（第 2、10、11 章）。

<a id="parchment"></a>
**羊皮层（parchment / pergamino，内果皮）**
包在种子外面的一层木质化硬壳，主要成分是纤维素、半纤维素与木质素。
产地常常带着它储存（parchment coffee / en pergamino），出口前才**脱壳（hulling）**（第 2、12、13 章）。

<a id="silverskin"></a>
**银皮（silverskin，珠心残余 perisperm）**
贴在种子表面的一层极薄的膜，是珠心被胚乳挤压后的残余。
它跟着生豆进烘焙机，在烘焙中脱落成银皮屑，但**中央线的沟里通常会残留**（第 2、15 章）。

<a id="chaff"></a>
**银皮屑（chaff）**
烘焙过程中从豆表脱落的银皮碎片。烘焙机需要专门排除它，
否则积聚在机内可能被烤焦。它是"银皮"这一层在烘焙环节的名字（第 2、15 章）。

<a id="endosperm"></a>
**胚乳（endosperm）**
种子里储存养分的组织，也就是你说的"咖啡豆"的主体。
第 1 章那张成分表描述的就是它。它的细胞壁多糖构成了生豆干重里占比最大的一部分（第 1、2、18 章）。

<a id="center-cut"></a>
**中央线（center cut）**
咖啡豆平的那一面上那道纵向的沟。它是两粒种子在果实里对生、互相贴合留下的形态，
沟里常有银皮残留。它的颜色与完整性是生豆瑕疵判断的观察点之一（第 2、13 章）。

<a id="peaberry"></a>
**圆豆（peaberry）**
一颗果实里只有一枚胚珠正常发育时形成的**单粒、近球形**的种子。
它形状与平豆不同，因此常被单独筛出售卖；但"更好喝"这一说法本书未找到对照研究支持（第 2 章）。

<a id="cascara"></a>
**咖啡果皮茶（cascara）**
咖啡果实的干制果肉/果壳，可以冲泡成饮品。在欧盟，它已按新食品法规
作为"第三国传统食品"被通报（第 2 章给出文件坐标）。

## 水与水质

<a id="hardness"></a>
**硬度（hardness）**
水中**钙、镁等二价阳离子的总量**，常以 mg/L CaCO₃（ppm as CaCO₃）表示。
它是"有多少东西"的量，与碱度**不是**一回事（第 3 章）。

<a id="alkalinity"></a>
**碱度（alkalinity）**
水**中和酸的能力**（缓冲能力），主要由碳酸氢根贡献，同样常以 mg/L CaCO₃ 表示。
它决定结垢倾向，也决定咖啡里的酸会被"顶掉"多少。
**单位与硬度相同，所以是最容易被混淆的一对**（第 3 章）。

## 感官通路与阈值

<a id="orthonasal"></a>
**前鼻嗅觉（orthonasal olfaction）**
吸气时气味分子从鼻孔进入鼻腔的路径——你**闻**杯子时用的就是这条（第 4 章）。

<a id="retronasal"></a>
**回气嗅觉（retronasal olfaction）**
食物在口中释放的挥发物随呼气从口腔后部上行进入鼻腔的路径——你**喝**的时候用的是这条。
人习惯把它的内容归因到"嘴里"，于是把它当成了"味道"。
**"风味"的绝大部分信息来自这条通路**（第 4 章）。

<a id="chemesthesis"></a>
**化学触感 / 三叉神经感受（chemesthesis）**
由三叉神经等躯体感觉神经介导的口鼻腔化学感受，包括辣、凉、刺激、
以及部分涩感与温度感。它**既不是味觉也不是嗅觉**，却是"口感"的重要组成（第 1、4 章）。

<a id="detection-threshold"></a>
**检测阈（detection threshold）**
能察觉"这个样品与空白不同"的最低浓度。**察觉到有东西，但说不出是什么**（第 4 章）。

<a id="recognition-threshold"></a>
**识别阈（recognition threshold）**
能说出"这是苦的/酸的"的最低浓度，**通常高于检测阈**。
第 1 章引用的那些苦味阈值属于这一类（第 4 章）。

<a id="oav"></a>
**气味活性值（odor activity value, OAV）**
某成分在样品中的**浓度 ÷ 它的气味阈值**。OAV > 1 才意味着它单独存在时可被闻到。
它解释了为什么"检出多"不等于"闻得到"（第 4、16 章）。

## 物种、品种与育种

<a id="species"></a>
**物种（species）**
生物分类的基本单位。商业咖啡涉及的主要是 *Coffea arabica*、*C. canephora*、*C. liberica*
三个物种。**豆袋上写"阿拉比卡"是物种信息，不是品种信息**——它覆盖了全世界大约六成的咖啡（第 6 章）。

<a id="cultivar"></a>
**栽培品种（cultivar / variety）**
经人工选育或选拔、性状稳定且可被重复繁殖的栽培群体，例如 Typica、Bourbon、Caturra、
SL28、Gesha、Castillo。这才是豆袋上"品种"一栏应该填的层级（第 6 章）。

<a id="genetic-group"></a>
**遗传群（genetic group）**
比品种更大、比物种更小的一层，指一批具有共同祖先或共同亲本来源的品种集合，
例如"波旁-铁皮卡群""卡蒂姆群""萨奇姆群"。**看到群名不要当成单一品种**（第 6 章）。

<a id="landrace"></a>
**地方种（landrace）**
在特定自然与人文环境中长期适应、由人工选择逐渐形成的传统地方品种。
咖啡的地方种主要来自埃塞俄比亚的森林——那是 *C. arabica* 演化的地方（第 6 章）。

<a id="allotetraploid"></a>
**异源四倍体（allotetraploid）**
由两个**不同物种**杂交后基因组加倍形成的多倍体，细胞里同时带着两套来源不同的染色体组
（亚基因组）。*C. arabica* 就是 *C. eugenioides* 与 *C. canephora* 的异源四倍体后代（第 6 章）。

<a id="heb"></a>
**同源基因表达偏倚（homeologue expression bias, HEB）**
异源多倍体中，来自两个亲本亚基因组的同源基因拷贝**表达量不相等**的现象。
它解释了为什么"基因组里各有一半"不等于"两边各出一半力"（第 6 章）。

<a id="introgression"></a>
**基因渗入（introgression）**
通过杂交与回交把**另一个物种**的部分基因带进本物种的过程。
咖啡里最重要的一次渗入是把 *C. canephora* 的抗叶锈基因带进 *C. arabica*（第 6、8 章）。

<a id="timor-hybrid"></a>
**帝汶杂交种（Timor Hybrid / Híbrido de Timor, HdT）**
1920 年代在东帝汶岛上**自然发生**的 *C. arabica* × *C. canephora* 种间杂交后代。
它带着来自 canephora 的抗叶锈基因，且染色体数与阿拉比卡相同，因而可以与之杂交。
它是全世界抗锈育种最重要的共同抗源——**也正因如此，抗性丧失会同时波及很多品种**（第 6、8 章）。

<a id="catimor"></a>
**卡蒂姆群（Catimor Group）**
帝汶杂交种 × **Caturra** 的后代群。**它是一群品种，不是一个品种**（第 6 章）。

<a id="sarchimor"></a>
**萨奇姆群（Sarchimor）**
帝汶杂交种 × **Villa Sarchi** 的后代群。同样是一**群**品种，Marsellesa 即属此群（第 6 章）。

<a id="f1-hybrid"></a>
**F1 杂交种（F1 hybrid）**
两个遗传距离较远的亲本杂交后的**第一代**。产量与适应性常显著优于常规品种，
但**它的种子不能留种**（见"分离"）（第 6 章）。

<a id="segregation"></a>
**分离（segregation）**
F1 杂交种的子代（F2）因基因重组而丧失亲本性状组合的现象。
后果是产量、抗性、品质都可能退化，所以 F1 品种**只能靠无性繁殖（克隆）扩繁**（第 6 章）。

## 病虫害与抗性

<a id="clr"></a>
**咖啡叶锈病（coffee leaf rust, CLR）**
由专性寄生真菌 *Hemileia vastatrix* 引起的叶部病害。症状始于叶背的淡黄色病斑，
继而产生橙色孢子堆，导致**落叶**乃至枝条死亡。它是改写现代咖啡品种版图的那场病（第 8 章）。

<a id="race"></a>
**生理小种（race）**
同一病原物种内，按**毒性因子组合**区分的类型。抗性是"寄主抗性基因 × 病原毒性因子"的配对关系，
所以**"抗病"必须问"对哪个小种"**（第 8 章）。

<a id="pyramiding"></a>
**基因聚合（gene pyramiding）**
把**多个**主效抗性基因累积到同一个品种里，使病原必须同时突破多道锁。
对无法通过有性重组组合毒性因子的**无性繁殖病原**尤其有效（第 8 章）。

<a id="partial-resistance"></a>
**部分抗性（partial resistance）**
不追求"完全不发病"，而是降低发病速率的抗性。它通常是**广谱**的，
因而不容易促使病原产生专门突破它的基因型——代价是它不会让病害消失（第 8 章）。

<a id="latency-period"></a>
**潜育期（latency period）**
从病原侵染到开始产生新的传播体（孢子）所需的时间。
它缩短一点，一个流行季能跑的世代数就增加，而流行是**指数**过程（第 8 章）。

<a id="cbb"></a>
**咖啡果小蠹（coffee berry borer, *Hypothenemus hampei*）**
危害最大的咖啡害虫，也是**唯一能完全以咖啡种子为食并在其中繁殖**的昆虫。
它的相关细菌携带咖啡因去甲基化基因——**解毒工作被外包给了共生菌**（第 8 章）。

<a id="cbd"></a>
**咖啡浆果病（coffee berry disease, CBD）**
由真菌 *Colletotrichum kahawae* 引起、攻击**果实**的病害，目前局限于生产阿拉比卡的非洲国家，
但被视为对其他地区的潜在检疫威胁（第 8 章）。

## 采收与成熟度

<a id="selective-picking"></a>
**选择性采摘（selective picking）**
只摘达到成熟标准的果子、一季多次进园的采收方式。成熟度一致性最高，人工成本也最高；
且成本**不是线性的**——树上熟果稀疏时，加人未必增产（第 9 章）。

<a id="strip-picking"></a>
**撸枝采收（strip picking）**
一次把整根枝条上的果子全部撸下的采收方式。快而便宜，但绿果、熟果、干果混在同一批里（第 9 章）。

<a id="false-maturity"></a>
**假熟（false maturity）**
咖啡果的**外部转色**与**内部糖分积累**不同步的现象。它是"红了就等于熟了"这句话的直接反例；
即使用高光谱加机器学习，区分高糖果与低糖果的准确率也远低于 100%（第 9 章）。

<a id="outturn"></a>
**出品比（cherry to green bean outturn）**
多少鲜果能换来多少生豆。它**不是常数**：随物种、基因型、处理法与计量基准变化，
品种目录把它列为**品种性状**而非固定值（第 9 章）。

<a id="proxy-variable"></a>
**代理变量（proxy variable）**
本身不直接起作用、但与真正起作用的量高度相关，因而被拿来替代观测的量。
本书遇到的三个典型代理是：**海拔**代理温度、**果皮颜色**代理成熟度、**豆型大小**代理筛分一致性。
用代理变量时永远要问三句：它为什么相关？什么条件下会解耦？解耦时我能察觉吗？（第 7、9 章）

## 处理法与发酵

<a id="natural-process"></a>
**日晒 / 自然处理（natural process, dry process）**
不脱皮脱肉，整颗果实直接干燥。干燥期最长（文献记载可达 2~4 周），
因而种子经历的**干旱胁迫时间最长**、参与的微生物量也最大（第 10 章）。

<a id="washed-process"></a>
**水洗（washed process, wet process）**
机械脱皮脱肉后，通过发酵或机械方式把[胶质层](#mucilage)去净，再干燥。
发酵时长文献记载为 6~48 小时；种子**脱皮后立刻启动发芽**，失水也更快（第 10 章）。

<a id="honey-process"></a>
**蜜处理 / 半日晒（honey process, semi-dry, pulped natural）**
脱皮脱肉但**保留部分胶质**随豆一起干燥。综述给出的保留范围是 20%~80%；
"黄蜜/红蜜/黑蜜"是**行业惯例用语**，各产地界定不一，
本书未找到可核对的"颜色 ↔ 保留率"统一定义（第 10 章）。

<a id="germination-metabolism"></a>
**处理期间的发芽代谢（germination during post-harvest treatment）**
咖啡种子没有休眠期，被果肉与抑制物压住时不发芽；一旦脱皮，发芽程序即启动。
用发芽专属酶**异柠檬酸裂解酶（isocitrate lyase, ICL）**追踪，
水洗约在第 2 天达峰、日晒约在第 1 周达峰。
**这是"同批果子两种处理仍然不同"的机理解释**（第 10 章）。

<a id="gaba"></a>
**γ-氨基丁酸（γ-aminobutyric acid, GABA）**
植物的**胁迫代谢物**。干燥期水势下降会诱发大量累积，
因而日晒豆的含量比水洗豆高约一个数量级。
本书用它作为"处理法确实改变了种子代谢"的**指纹**，而不是风味物质（第 10、12 章）。

<a id="dehydrin"></a>
**脱水素（dehydrin）**
一类与耐旱相关的蛋白。其基因表达高峰出现在干燥期的胚与胚乳组织中，
是干旱胁迫的分子标记（第 10、12 章）。

<a id="siaf"></a>
**自诱导厌氧发酵（self-induced anaerobic fermentation, SIAF）**
把物料装入**密闭**容器，不充气，靠微生物自身呼吸把氧耗尽并积累 CO₂。
与之相对的"**半厌氧（semi-anaerobic）**"指**开放**发酵槽。
对照实验显示：开放条件下醋酸菌更活跃，密闭条件下乳酸路线占优（第 11 章）。

<a id="carbonic-maceration"></a>
**碳浸渍（carbonic maceration）**
借自葡萄酒的做法：密闭容器中**人为充入 CO₂**。
它与 SIAF 的区别是初始气氛由人给定，而不是靠微生物自己造出来（第 11 章）。

<a id="starter-culture"></a>
**起始培养物 / 接种（starter culture, inoculation）**
向发酵中投入已知菌株（如 *Saccharomyces cerevisiae*、*Pichia kluyveri*）使其迅速占优。
多项独立研究报告接种使结果**更可重复**，并与**更低的缺陷相关化合物**同现；
但各研究的分数增益是单点观测，不可外推（第 11 章）。

<a id="label-effect"></a>
**标签效应（label effect / expectation effect）**
包装或菜单上的文字改变品尝者的预期，进而**真实地改变其感知与评价**。
一项实验中同一支咖啡配三种处理法标签，酸度评价与喜好度随之改变。
**它是"凡评判处理法必须盲测"这条纪律的直接理由**（第 11 章，第 39 章展开）。

## 干燥与储存

<a id="moisture-content"></a>
**含水率（moisture content）**
样品中水的**量**。必须说明**基准**：湿基（wet basis, wb）以样品总重为分母，
干基（[dry basis](#dry-basis)）以干物质为分母，同一份样品会得出两个不同的数。
读到任何含水率数字先问三句：**谁的水？湿基还是干基？在工序的哪一步？**（第 12 章）

<a id="water-activity"></a>
**水分活度（water activity, a_w）**
样品中水的蒸汽压与同温纯水蒸汽压之比，取值 0~1，反映水有多"自由"。
**微生物与化学反应关心的是自由水，不是总水量**——
所以两份含水率相同的豆，稳定性可以差很多（第 12 章）。

<a id="sorption-isotherm"></a>
**吸附等温线与平衡含水率（sorption isotherm / equilibrium moisture content）**
在给定温度下，含水率随水分活度（或环境相对湿度）变化的曲线。
它意味着**含水率不是豆的固有属性，而是它与环境达成的平衡**，
且曲线随温度移动——这正是"回潮"的物理本质（第 12 章）。

<a id="case-hardening"></a>
**表壳硬化（case hardening）**
表面干得太快、内部水分出不来，形成"外干内湿"的豆。
危险之处在于它是**假合格**：平均含水率测出来可能达标，但分布是错的（第 12 章）。

<a id="re-wetting"></a>
**回潮（re-wetting）**
干燥过程中或储存期间重新吸湿，使干燥曲线出现反复。
与表壳硬化并列为干燥的两大失败模式（第 12 章）。

<a id="parchment-storage"></a>
**带壳储存（parchment storage）**
保留[羊皮层](#parchment)储存生豆。两年储存实验中，
带壳豆的**种子活力维持一年以上**，而脱壳豆六个月内即丧失。
⚠️ 该研究测的是活力，不是杯测分；"活力 ↔ 香气变平"是作者的推论（第 12 章）。

<a id="seed-viability"></a>
**种子活力（seed viability）**
种子是否仍具备萌发能力，可用四唑法测定。
本书用它说明一件反直觉的事：**生豆是活的，而且会死**（第 12 章）。

<a id="raised-bed"></a>
**高床（raised bed, African bed）**
高约 0.8~1.2 m 的网面干燥平台，摊层 2~4 cm，每天翻动 2~3 次。
相对晒场（patio）的优势是上下两面通风、污染风险更低（第 12 章）。

<a id="past-crop"></a>
**过季豆 / 当季豆（past crop / current crop）**
按距采收时间给生豆分的**行业惯例**说法。
本书查证的结论是：**"会随储存变化"有实验支持，但"超过 N 个月就是过季豆"缺乏可核对的通用阈值**；
同样的天数在恒温恒湿处与高温高湿处结果完全不同。
**该问的是"怎么存的"，不是"哪一年的"**（第 12 章）。

## 分级与瑕疵

<a id="screen-size"></a>
**目数（screen size）**
用带圆孔的筛板筛豆，记录被某孔径**截留在上方**的豆子百分比。
孔径单位是 **1/64 英寸**（"14 目" = 14/64 英寸）。
它量的是**尺寸分布（一致性）**，不是单颗大小；
烘焙商在意它是因为均匀可避免小颗粒被烤焦。豆粒大小首先是**品种性状**（第 13 章）。

<a id="defect-count"></a>
**瑕疵计数（defect count）**
在规定重量的样品中按类别数出瑕疵豆与异物，再按严重程度加权。
各体系的类别与折算规则不同，但"**数数 + 加权**"的结构共通。
它保证的是**下限**（明显的坏被筛掉），不是上限（第 13 章）。

<a id="floater"></a>
**浮豆（floater）**
密度偏低、在水中浮起的豆，在分级中被当作一个瑕疵类别。
化学上确与正常豆可区分（若干瑕疵类的酰基奎宁酸高于正常豆）；
但**"浮起 ⇒ 难喝"仍缺乏盲测对照**，且浮豆是按**物理性质**定义的集合，
成因混杂（未熟、虫蛀、干燥过度、内部空腔）（第 13 章）。

<a id="ptd"></a>
**马铃薯味缺陷（potato taste defect, PTD；亦称 peasy defect）**
东非咖啡的一类缺陷，对应分子为 **IPMP（3-异丙基-2-甲氧基吡嗪）**。
证据链为：盾蝽取食造成伤口 → 微生物 → IPMP → 杯中生马铃薯味；
**虫害是必要但不充分条件**。注意：新鲜马铃薯中的甲氧基吡嗪浓度很低，
这个名字来自感知联想而非成分同源（第 13 章）。

<a id="methoxypyrazine"></a>
**甲氧基吡嗪（methoxypyrazines）**
一类气味阈值极低的化合物，典型气味为生青、豌豆、青椒。
关键事实是：它们在**所有优质咖啡样品**中都能检出——
**是浓度问题，不是有无问题**（第 13 章）。

<a id="icip"></a>
**ICO 综合指标价与四个组（I-CIP and its four groups）**
国际咖啡组织发布的世界咖啡价格指标，把咖啡分为
**Colombian Milds · Other Milds · Brazilian Naturals · Robustas** 四组。
分组依据是**物种 × 处理法 × 产地**，**不是杯测分**——
所以组间差价主要反映分类与供需，精品议价发生在**组内**（第 13 章，第 43 章展开）。

## 证据与研究方法

<a id="grade"></a>
**GRADE（Grading of Recommendations, Assessment, Development and Evaluation）**
国际通用的证据分级方法，把系统综述与荟萃分析的证据分为
**高 / 中 / 低 / 极低**四级：研究设计决定起点，异质性、发表偏倚、不精确等因素可上下调整。
**它评的是"证据有多可靠"，不是"效应有多大"**（第 5 章）。

<a id="confounding"></a>
**混杂与残余混杂（confounding / residual confounding）**
当某个第三变量同时影响暴露与结局时产生的虚假关联；即使做过统计调整，
因测量误差或建模粗糙而残留下来的那部分叫**残余混杂**。
吸烟是咖啡健康研究里的头号混杂（第 5 章）。

<a id="mendelian-randomization"></a>
**孟德尔随机化（Mendelian randomization, MR）**
用与暴露相关的遗传变异作为**工具变量**来推断因果的方法。
它能降低混杂与反向因果的影响，但依赖三个不易验证的假设，
且在咖啡这类高度行为化的暴露上要格外小心（第 5 章）。
