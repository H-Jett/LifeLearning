## 基础与计量

<a id="green-coffee"></a>
**生豆（green coffee / green bean）**
经处理与干燥、尚未烘焙的咖啡种子。它是咖啡贸易的实物形态，也是一切风味的**前体库**——
后面所有环节只能改造和取用它已有的东西，不能无中生有。

<a id="roasted-coffee"></a>
**熟豆（roasted coffee）**
经过烘焙的咖啡豆。与生豆相比，它的化学组成已被大幅改写：大部分蔗糖消失，
绿原酸大量降解，出现了生豆里几乎不存在的数百种挥发性香气分子。

<a id="dry-basis"></a>
**干基（dry basis, d.b.）**
把含水量扣除后再算百分比的表示方式。咖啡文献里的成分含量绝大多数是干基，
因为生豆含水率本身会变（第 12 章），不扣水就没法跨样品比较。
**看到成分含量先确认是干基还是湿基**，否则数字之间差的可能只是水。

<a id="arabica"></a>
**阿拉比卡（Arabica，*Coffea arabica*）**
商业上产量与价格最高的咖啡物种，四倍体、可自花授粉。
化学上的典型特征是咖啡因与绿原酸较低、蔗糖与脂质较高（第 1、6 章）。

<a id="canephora"></a>
**卡内弗拉 / 罗布斯塔（Canephora / Robusta，*Coffea canephora*）**
第二大商业物种，二倍体。"罗布斯塔"严格说是它的一个栽培群，但市场上常被当作物种名使用。
化学上咖啡因与绿原酸明显高于阿拉比卡，蔗糖与脂质较低（第 1、6 章）。

<a id="precursor"></a>
**风味前体（flavor precursor）**
本身不（或不太）呈现最终风味，但在烘焙中会转化成呈味呈香物质的成分。
咖啡里最重要的三类前体是**蔗糖、蛋白质/氨基酸、绿原酸**。
"这支豆有潜力"这句话，技术上说的就是"它的前体格局好"。

## 生物碱

<a id="caffeine"></a>
**咖啡因（caffeine，1,3,7-三甲基嘌呤二酮）**
咖啡里最著名的生物碱，**味觉上是苦的**，且**热稳定性高**——
所以它在烘焙中损失有限，不同烘焙度之间的差异远小于坊间想象（第 1、17 章）。
需要强调的是：它虽然苦，却**不是**咖啡苦味的主要贡献者（第 1 章 §1.4）。

<a id="trigonelline"></a>
**葫芦巴碱（trigonelline，N-甲基吡啶-3-羧酸）**
生豆中含量仅次于咖啡因的生物碱，本身带苦味但贡献有限。
它的重要性在于**烘焙中会大量分解**，产物包括烟酸（niacin / 维生素 B3）
以及一系列吡啶、吡咯类挥发物——后者是咖啡"烘烤香"的组成部分（第 1、16 章）。

## 酚类与它们的去路

<a id="cga"></a>
**绿原酸类（chlorogenic acids, CGA）**
一大类酚酸与奎宁酸形成的酯的总称（**不是单一化合物**），生豆中含量最高的酚类物质。
主要亚类是咖啡酰奎宁酸（CQA）、阿魏酰奎宁酸（FQA）和二咖啡酰奎宁酸（diCQA）。
它们在烘焙中大量降解，是**苦味与涩感的主要来源链条的起点**（第 1、17 章）。

<a id="cql"></a>
**绿原酸内酯（chlorogenic acid lactones, CQL）**
绿原酸在烘焙中脱水成环形成的内酯。研究把它与**中浅烘咖啡的苦味**联系起来
（第 1 章 §1.4 给出文献）。

<a id="phenylindane"></a>
**苯基茚满（phenylindanes）**
绿原酸内酯在**更深烘焙**下进一步转化的产物，与"粗糙、持久、后段回上来"的那种苦味相关。
它是"深烘的苦和浅烘的苦不是同一种苦"这一现象的化学解释（第 1、17 章）。

<a id="quinic-acid"></a>
**奎宁酸（quinic acid）**
绿原酸水解后释放出的酸。它既有酸味也带涩与"干"的感觉，
常被用来解释**过度烘焙或长时间保温后**咖啡出现的那种不讨喜的酸涩（第 1、17 章）。

<a id="caffeic-acid"></a>
**咖啡酸（caffeic acid）**
绿原酸水解的另一半产物（酚酸部分）。注意它与咖啡因（caffeine）是**完全不同**的物质，
中文名只差一个字，英文也只差几个字母，是初学时最容易混的一对。

## 糖类与褐变产物

<a id="sucrose"></a>
**蔗糖（sucrose）**
生豆中最主要的游离糖，是阿拉比卡与罗布斯塔差异最大的成分之一。
它在烘焙中**几乎被消耗殆尽**——既参与焦糖化，也水解成还原糖后参与美拉德反应。
所以"咖啡的甜"基本不是蔗糖直接带来的（第 1、16 章）。

<a id="reducing-sugar"></a>
**还原糖（reducing sugars）**
葡萄糖、果糖等含游离羰基的糖。它们是**美拉德反应的糖一侧反应物**，
生豆中游离态含量很低，但蔗糖水解会补充它们。

<a id="maillard"></a>
**美拉德反应（Maillard reaction）**
还原糖的羰基与氨基酸/蛋白质的氨基之间的一系列反应，产生大量香气分子与褐色高分子。
它是烘焙中**最重要的风味生成机制**，不是单一反应而是一整张反应网络（第 16 章）。

<a id="strecker"></a>
**斯特雷克降解（Strecker degradation）**
美拉德反应网络中的一支：氨基酸与二羰基化合物反应，脱羧脱氨生成相应的醛。
很多咖啡里"麦芽""可可""坚果"类气味的分子出自这条路径（第 16 章）。

<a id="caramelization"></a>
**焦糖化（caramelization）**
糖在受热下（**不需要氨基参与**）自身脱水、聚合、裂解的过程。
它与美拉德反应常被混为一谈，但反应物不同、产物不同——分清两者是读懂烘焙章节的前提。

<a id="melanoidin"></a>
**类黑精（melanoidins）**
美拉德反应末期形成的褐色高分子含氮化合物，结构至今没有完全定论。
它们贡献咖啡的颜色，并被认为参与**body 与部分苦味**（第 1、16 章）。

<a id="polysaccharide"></a>
**多糖（polysaccharides）**
生豆干重里占比最大的一类物质，主要是半乳甘露聚糖（galactomannan）、
阿拉伯半乳聚糖（arabinogalactan）与纤维素。它们大部分构成细胞壁、不溶于水，
但**部分片段在烘焙中被解聚**后可被萃出，参与 body（第 1、18 章）。

## 脂质、蛋白质与酸

<a id="lipid"></a>
**脂质 / 咖啡油（lipids / coffee oil）**
以甘油三酯为主，集中在胚的细胞内，烘焙中基本不挥发但会向豆表迁移。
它们几乎不溶于水，因此在滤纸冲煮与意式/金属滤网之间造成明显的口感差异（第 1、26、30 章）。

<a id="protein-aa"></a>
**蛋白质与游离氨基酸（proteins & free amino acids）**
生豆中的储藏蛋白与少量游离氨基酸，是**美拉德反应的氨基一侧反应物**。
它们在成品咖啡里剩得很少，重要性几乎全在"作为前体"这一面（第 1、16 章）。

<a id="organic-acid"></a>
**有机酸（organic acids）**
咖啡酸味的直接来源。生豆里主要是柠檬酸、苹果酸等；
烘焙中一部分被分解，另一部分（如甲酸、乙酸、乳酸、奎宁酸）被生成（第 1、17 章）。

<a id="titratable-acidity"></a>
**可滴定酸度（titratable acidity）**
用碱滴定测得的总酸量，与 **pH 不是一回事**：pH 只反映游离氢离子浓度，
可滴定酸度反映酸的总量。两杯 pH 相同的咖啡可以酸得完全不一样（第 1、22 章）。

## 感受侧的词

<a id="body"></a>
**body（醇厚度 / 口感重量）**
舌面感受到的"重量感与黏稠感"，属于**触觉**而非味觉。
主要与不挥发性溶质总量、脂质、被解聚的多糖片段与悬浮细粉相关（第 1 章 §1.5）。

<a id="astringency"></a>
**涩（astringency）**
不是味道而是一种**触觉/化学感受**：多酚类与唾液蛋白结合，使口腔黏膜失去润滑。
所以涩是"干、收紧、起皱"，与苦是两回事，虽然它们经常同时出现（第 1、4 章）。

<a id="flavor"></a>
**风味（flavor）**
味觉（舌）+ 嗅觉（尤其是**口腔后部经鼻腔的回气嗅觉**）+ 三叉神经感受（温度、刺激、涩、
奶油感）三者在大脑里合成的整体知觉。
**"风味"绝大部分来自嗅觉**——这是第 4 章的主题，也是"捏住鼻子喝咖啡"这个实验能说明的事。

<a id="volatile"></a>
**挥发性香气物质（volatile aroma compounds）**
分子量较小、能在常温下挥发进入鼻腔的化合物。烘焙咖啡里已被鉴定出的种类数以百计，
但其中真正对香气有贡献的只是很小一部分——**含量高不等于贡献大**，
关键是它的**气味阈值**（第 4、16 章）。

## 萃取侧的词

<a id="extraction-yield"></a>
**萃取率（extraction yield, PE / EY）**
被溶出进入液体的干物质**占投入咖啡粉干重的百分比**。
它衡量的是"从粉里取走了多少"，与"这杯有多浓"是两个独立的量（第 22 章）。

<a id="tds"></a>
**TDS（total dissolved solids，总溶解固体）**
咖啡液中溶解物质的质量百分比，也就是通常说的"**浓度**"。
它衡量的是"这杯有多浓"，与萃取率同样是两个独立的量——
**同一个 TDS 可以由完全不同的萃取率做到**（第 22 章）。

<a id="solubility"></a>
**溶解度与溶出速率（solubility & dissolution rate）**
两个常被混淆的概念：**溶解度**是"最多能溶多少"（热力学上限），
**溶出速率**是"多快溶出去"（动力学）。冲煮时间调的主要是后者（第 21、24 章）。
