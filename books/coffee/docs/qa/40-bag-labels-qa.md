# 第 40 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：处理法描述的是工艺路径，实际杯中还受品种、成熟度、发酵细节、干燥、烘焙和冲煮影响。它能帮助提出“先试什么”的假设，不能承诺某个固定风味。

<a id="q2"></a>
## Q2

**答**：直接问“这包的实际烘焙日期是哪一天？”保质期、生产日期或赏味期不能替代该字段；若无法提供，应把新鲜度的不确定性写入购买决定。

<a id="q3"></a>
## Q3

**答**：先看烘焙日期、净含量、批次、处理法、品种、产区与评分来源等可追溯字段；“柑橘、花香”只是一组待验证的描述。再用同条件盲喝比较，避免标签预期先决定结论。
