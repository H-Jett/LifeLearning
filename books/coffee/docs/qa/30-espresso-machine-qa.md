# 第 30 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：压力表显示的是某个测点的系统压力；它不能告诉你流量、粉饼温度、局部裂隙或杯中浓度。应与出液质量、时间、
重复性和口感一起读，不能把一个读数当判决。

<a id="q2"></a>
## Q2

**答**：不同机器的“预浸泡”可能对应不同水路动作。应记录具体程序、何时出液和后续压力/流量变化，先在本机验证；
不能把他人机器的秒数移植过来。

<a id="q3"></a>
## Q3

**答**：优先检查机器是否充分预热、两杯之间的恢复与清洁状态、用水和操作是否一致。确认这些外部条件稳定后，才检查
研磨与粉饼制备；否则会把热状态差异错判成豆子或刻度问题。
