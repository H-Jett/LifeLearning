# 第 44 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：它没有说明要解决的工作任务和当前缺口。先把目标改写为稳定出品、感官校准、生豆质检或采购沟通等可观察任务，再用记录判断缺的是流程、知识、反馈还是共同协议，才能选自学、模块课程或评价执照路径。

<a id="q2"></a>
## Q2

**答**：SCA 技能课程适合按岗位补吧台、冲煮、生豆、烘焙或感官等具体能力，并可累积为跨模块路径。Q Grader 面向已有杯测/感官经验且需要按共同标准评估、描述和沟通质量的人；它不是其它岗位技能的替代品。

<a id="q3"></a>
## Q3

**答**：先看他是否已有连续的盲测与杯测记录：能否在随机编码下稳定区分样品、能否用一致的结构描述、能否与同伴校准，以及是否熟悉 CVA 的公开框架。若这些证据还不足，先做数周受控练习并复盘；若工作确实需要质量评价且基础稳定，再按当期官方要求评估报名。
