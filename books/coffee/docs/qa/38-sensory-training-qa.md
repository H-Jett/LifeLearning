# 第 38 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：三角题只要求指出哪杯不同，没有要求说明“更酸/更甜/更好”。即使多轮检出差异，也要用独立的描述或偏好记录
判断差异方向与意义。

<a id="q2"></a>
## Q2

**答**：差异可能小于当前检测能力，或被样本数、温度、疲劳与流程噪声掩盖。正确结论是“在这些条件和次数下尚未检出”，
而不是宣称两样品在所有情境中相同。

<a id="q3"></a>
## Q3

**答**：报告“3 轮中答对 2 轮，样本太少，结果仅作练习记录”，并附样品、温度和随机顺序。不要称已证明可分辨；下次
增加独立轮次并控制疲劳后再评估。
