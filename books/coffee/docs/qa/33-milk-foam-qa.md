# 第 33 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：泡沫由气液界面的蛋白、脂肪状态、加工方式、温度与蒸汽动作共同决定。脂肪影响其中一环，却不能单独预测细腻度、
稳定性或倒入表现。

<a id="q2"></a>
## Q2

**答**：终温是可重复的过程输入，能帮助区分“进气/循环不同”与“加热不同”。它不是所有奶通用的最佳温度，但比手感
更适合建立自己的条件卡。

<a id="q3"></a>
## Q3

**答**：先把它视为一款新配方：记录包装信息、初始量和终温，在其余条件固定下重复两次；再只改变进气或终温。不能把
牛奶的秒数和动作直接移植，也不要马上把问题归给咖啡豆。
