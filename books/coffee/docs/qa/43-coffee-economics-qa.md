# 第 43 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：指标价只是一类基准信号。具体豆的质量差价、合同、库存、物流、损耗、烘焙、包装、零售和税费都在其后发生；零售价不能倒推出某一环的固定分成。

<a id="q2"></a>
## Q2

**答**：Fairtrade 规则以市场参考价或最低价中较高者为基础，再按规则处理适用的差价、溢价和有机差额等。它是特定认证交易的机制，不等于全部咖啡市场，也需查当期规则。

<a id="q3"></a>
## Q3

**答**：先问“直接”具体指与谁交易、是否公开批次/合同/价格或第三方可核验信息。这个术语没有统一全球标准，所以品牌自述本身不足以证明关系、价格或收入分配。
