# 第 31 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：固定力度的可重复性难测且受手法、粉碗和粉量影响；水平、稳定的平面与多杯结果可直接观察。压粉的目标是减少
结构差异，不是达到一个脱离设备的数字。

<a id="q2"></a>
## Q2

**答**：它可能提示局部低阻力，但研磨、粉量、粉碗/分水、机器状态同样会改变水流。应固定配方、复做，并一次只测试
一个解释，例如分布步骤，而不是立刻给布粉工具定罪。

<a id="q3"></a>
## Q3

**答**：先做一组完全相同的三杯，并把粉量、机器预热、出液目标和制备步骤写下来，确认波动是否可重现。随后只改变
一个分布/整平步骤；若仍漂移，检查磨豆机、粉碗、分水与机器恢复，而非同步调整研磨和压粉。
