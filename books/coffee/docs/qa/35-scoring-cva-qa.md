# 第 35 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：总分压缩了多个属性和评审印象；两杯可因不同风味、质地或余韵达到相近分数。消费者偏好、冲煮条件与目标饮用
方式也不同，所以不能从同分推出同一购买建议。

<a id="q2"></a>
## Q2

**答**：描述记录样品有什么，偏好记录评价者是否喜欢或认为它适合目标市场。分开填写能减少“我不喜欢”反向改写为
“它没有某属性”的偏差，也让不同市场的价值判断可以被说明。

<a id="q3"></a>
## Q3

**答**：先要求明确它说的是哪一个 CVA 环节、哪一批样品、何时、由谁和按何流程评估。CVA 不是一个可脱离表格与版本的
通用“95 分”标签；即使程序完整，也仍要看描述、偏好与本批次信息。
