# 第 36 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：具体词暗示了更强的辨识证据。没有参照物或重复支持时，“果味”准确传达了已知信息，也保留了之后进一步校准的空间；
写“蓝莓”会制造无法复查的精确感。

<a id="q2"></a>
## Q2

**答**：两人先面对同一参照物并使用同一层级词汇，就能比较“是否有柑橘感、强度如何”，而不是比较各自脑中不同的“清新”。
参照物不消除偏好，却使分歧可以被定位。

<a id="q3"></a>
## Q3

**答**：先盲写“果味，较接近柑橘；桃子未能确认”，再揭码记录豆袋的说法。这样保留了自己的感受和商家的假设，也避免把
标签当成感官事实；下次可用桃子和柑橘参照物复核。
