# 第 41 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：排气只是一条变化链。挥发物损失、氧化相关反应、包装与温度也会影响香气和杯中表现；不同豆与烘焙的排气轨迹不同，所以不能把 CO₂ 单独当作新鲜度尺。

<a id="q2"></a>
## Q2

**答**：研究支持特定条件下冷冻样品更接近新鲜对照，却没有覆盖所有包装、家庭冰箱、反复开合、烘焙度与储存年限。正确做法是小份密封、记录条件，并在自己系统中对照。

<a id="q3"></a>
## Q3

**答**：先固定冲煮条件复做，并检查研磨、用水与器具清洁；再回看烘焙日、开封日、储存位置、开袋频率与包装状态。若只有随储存条件/时间稳定变化，储存是更强的候选；否则保留多个解释。
