# 第 28 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：全浸泡使用同一份水，达到平衡后咖啡与液体的分配关系约束萃取率；增加水量会稀释杯中液体，因此最先改变
的是浓淡。它不代表所有粉水比、所有原料都会给出同一个萃取率数字。

<a id="q2"></a>
## Q2

**答**：它先经历浸泡，随后又经过阀门与纸滤排液。前一段应按平衡逻辑理解，后一段仍受纸张、流量和排液阻力影响；
记录应包含浸泡结束点与排液表现。

<a id="q3"></a>
## Q3

**答**：先记录实际温度、粉水比、两组接触时长、过滤方式和是否稀释。结果接近可能意味着在你的条件下已接近平衡，
也可能是感官分辨不足；下一步做重复杯或测 TDS，而不是把它变成通用“最佳时长”。保存时间另行按卫生要求管理。
