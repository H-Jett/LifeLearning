# 第 27 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：段数只说明把水分成几次倒入，没有说明每段水量、间隔、水柱、位置、滤杯、粉床和研磨。它们都会影响液面、
流动与混合；因此必须比较完整条件卡，而不是比较一个动作名称。

<a id="q2"></a>
## Q2

**答**：时间波动先提示输入或床层重复性不足。若立刻改研磨，会把“流程没复现”误判为“刻度不对”。应先检查称量、
注水计划、滤纸贴合和研磨机状态，再做重复杯确认。

<a id="q3"></a>
## Q3

**答**：先判断“淡”是浓度问题还是味道不清晰造成的印象。若整体强度低而流程稳定，先固定其余条件、用粉水比建立目标
浓淡；若同时有涩、流速异常或杯感混浊，先回查床层与均匀性，不能把研磨当作唯一旋钮。每一步只改一个变量。
