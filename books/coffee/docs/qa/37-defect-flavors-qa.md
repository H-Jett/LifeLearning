# 第 37 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：PTD 与 IPMP 等物质和受损豆/微生物证据有关，但甲氧基吡嗪并非只存在于缺陷样品，虫害也不是充分条件。准确说法是：
它是一条含多个候选环节的证据链，而不是虫害的直接指纹。

<a id="q2"></a>
## Q2

**答**：标记物可帮助识别或关联某类样品，但同一物质可能存在于多种条件，且感官感受还受浓度、基质和其他化合物影响。
它需要与感官、批次和对照一起解释。

<a id="q3"></a>
## Q3

**答**：固定豆、研磨、水与器具复做，并与基准豆盲对照；检查储存、磨豆机残粉、滤纸/器具清洁和烘焙日期。若异常稳定，
保留样品与完整记录再追问烘焙商，而不是仅凭一次喝感断定仓储问题。
