<a id="q1"></a>
## Q1

**问**：把描述烘焙度的物理量分成状态量与过程量，各自漏掉了什么？

**答**：

一项研究列出的候选量至少有七个：**颜色、密度、失重、总时长、一爆后时长、入豆温、下豆温**[^rd1]。

| 类型 | 指标 | 它记录什么 | 漏掉什么 |
|------|------|-----------|---------|
| **状态量** | 颜色 | 在颜色轨迹上的位置 | **路径**——不同曲线收敛到同一条轨迹[^rd2] |
| | 密度 | 结构膨胀程度 | 生豆自身差异；口径（堆积/真/表观）不统一 |
| | 失重率 | 总共少了多少质量 | 水与干物质的**构成比**[^st4] |
| **过程量** | 总时长 / 一爆后时长 | 路径的一部分 | 结果（同样时长可落在不同位置） |
| | 入豆温 / 下豆温 | 设备侧的设定与终点读数 | 豆的真实状态（读数是探针周围温度[^rp9]） |

**一句话**：**状态量不记路径，过程量不记结果，而且过程量还依赖设备。**
所以"烘焙度"必须**连同测法一起报告**。

<a id="q2"></a>
## Q2

**问**："普适色曲线"在什么场景下是好消息、什么场景下是坏消息？

**答**：

**实验事实**：七条总时长相同但动态差异极大的曲线 × 三个产地，
L\*a\*b\* 始终落在同一条轨迹上；在转色、一爆、二爆三个里程碑处颜色近似相同；
系统综述（PRISMA）显示罗布斯塔也落在这条曲线上[^rd2]。

| 场景 | 好 / 坏 | 理由 |
|------|--------|------|
| **跨机器沟通"烘到哪儿了"** | ✅ 好消息 | 颜色是稳健的落点指标，比温度可靠得多（温度依赖探针与机型[^rp9]） |
| **用颜色定义烘焙度标准** | ✅ 好消息 | 作者正是据此讨论其对行业烘焙度标准的意义[^rd2] |
| **用颜色检查曲线有没有问题** | ❌ 坏消息 | 一条**刻意复制"烤"（baked）**的曲线同样落在这条轨迹上[^rd2]——颜色对缺陷是盲的 |
| **用颜色判断"发展是否充分"** | ❌ 坏消息 | 同上；判据只能落在香气/感官（[第 20 章](../chapters/03-roasting/20-roast-defects.md)） |

> **本质**：颜色把**二维的（路径 × 落点）**信息压缩成了**一维的**。
> 压缩带来通用性，也带来信息损失——这两件事是同一枚硬币。

<a id="q3"></a>
## Q3

**问**：为什么同一个失重率可以对应不同的干物质损失？这对比较两家的失重数据意味着什么？

**答**：

**因为失重是合计量**：

```
失重 = 水（原有水分 + 反应生成的水） + 干物质损失（CO₂ 与挥发物带走的碳）
```

排气分析研究测定了 CO₂ 与水蒸气的释放，并报告**质量平衡能相当好地解释称重法测得的失重**[^st4]。

**于是**：生豆含水率 11% 与 9% 的两支豆，**烘到同样 15% 的失重率**，
前者的失重里水占的比例更大、干物质损失更小——**化学上走得更近**。

**对比较的意味**：

1. **必须同时知道生豆含水率**，否则失重率不可比；
2. **必须知道基准**（干基 / 湿基）；
3. 这正是行业区分"总失重"与"有机物失重"的原因（**行业惯例**，各家算法不一，本书不给公式）；
4. 更稳的做法是**同一支豆纵向比较**，而不是横向比两家。

> **提醒**：[第 17 章](../chapters/03-roasting/17-cga-and-bitterness.md)的"约 14% 失重"与
> [第 18 章](../chapters/03-roasting/18-structure-cracks-porosity.md)的"约 12%~14% 失重"
> 来自不同研究、不同设备，**不能当作同一把尺子**。

<a id="q4"></a>
## Q4

**问**：密度物理上很明确，为什么说它"混杂最多"？给一个能用的场景。

**答**：

**物理上明确 ≠ 作为指标明确。** 三层混杂：

1. **生豆自身**：品种、海拔、处理法、含水率都会改变生豆密度（第二部分）。
   两支生豆密度就不同（如该研究的 0.707 与 0.692 g/mL[^rd1]），烘完之后的差值无法归因给烘焙。
2. **口径**：自由沉降密度、振实密度、真密度、表观密度各不相同；
   显微 CT 与比重瓶测的又是另一套[^st3]。
3. **样品状态**：整豆还是磨碎、是否过筛、是否已排气[^rd1]。

**能用的场景**：**同一支豆、同一套流程的纵向跟踪**。例如：

> 同一支生豆、同一台机器，记录每一批的"熟豆堆积密度"。
> 如果某一批明显偏高，说明这批可能烘得更浅或膨胀不足——
> 这是**自己跟自己比**，三层混杂里的前两层都被固定住了。

**不能用的场景**：拿两支不同的豆比密度，然后说"这支烘得更深"。

<a id="q5"></a>
## Q5

**问**：**【案例】** A 写"Agtron 62（整豆）"，B 写"Agtron 62（粉）"，能认为烘焙度相同吗？

**答**：

**不能。**

**推理链**：

**看到什么** → 两个相同的数字，但**测的对象不同**。

**这意味着什么** → **整豆颜色与咖啡粉颜色差异显著**。
证据强度不低：一项系统综述**直接把只报告整豆颜色的研究排除在外**，理由正是这一点[^rd2]；
另一项研究则对同一批样品**两种都测**[^rd1]。
物理上也说得通：整豆测的是**表面**（还包括银皮残留与油光），
粉测的是**断面的平均**——而[第 15 章](../chapters/03-roasting/15-roasting-physics.md)
讲过豆内存在干燥锋面、内外状态不同。

**还需要确认什么**：

1. 仪器与量表版本（Agtron 有不同量表，gourmet 与其他量表数值不同）；
2. 制样方式：磨到多细、装样量、是否旋转多次取平均[^rd1]；
3. 有没有第二个指标可以交叉验证（失重率、下豆时间）。

**该怎么做**：**索要同口径的数据**（例如都给粉的读数），
或者干脆改用自己的设备语言比较——同刻度磨出来的粒径与流速
（[第 18 章](../chapters/03-roasting/18-structure-cracks-porosity.md)实操）。

<a id="q6"></a>
## Q6

**问**：**【案例】**"我用色卡确认颜色一致，所以两批烘焙一样"——两个漏洞？

**答**：

**漏洞一：测法层面（视觉比色不可靠）**

视觉判定受**照明、样品量、周围颜色与观察角度**影响[^rd2]。
两批豆在不同时间、不同光线下比色，本身就可能差出一档。
仪器化正是为了解决这个问题[^rd2]；而即便用仪器，也还有"整豆还是粉"的口径问题[^rd2][^rd1]。

**漏洞二：信息层面（颜色本身承载不了"过程"）**

即使颜色测得完全准确，它也只是轨迹上的一个点。
七条差异极大的曲线都落在同一条轨迹上，**其中一条是刻意复制"烤"这种缺陷的**[^rd2]。
所以"颜色一致"**不能**推出"烘焙过程一致"，更不能推出"品质一致"。

**正确的说法**：
"两批豆的**落点**看起来一致；要确认过程是否一致，我需要看曲线记录，
或者做一次盲测对照（[第 20 章](../chapters/03-roasting/20-roast-defects.md)）。"

## Q7

**问**：四类分类 100% 准确率为什么不能推出"能精确测量烘焙度"？怎样设计更有说服力的测试？

**答**：

**为什么不能**：

1. **类别太粗**：生豆 / 浅 / 中 / 深四类[^rd5]，类间差异远大于类内差异——
   这类任务人眼也接近满分；
2. **100% 本身是个警号**：说明数据集的类别边界很干净（可能同一批豆、同样拍摄条件），
   模型可能学到了与烘焙度无关的线索（光照、背景、批次）；
3. **分类 ≠ 测量**：分类输出的是标签，测量输出的是**带不确定度的连续值**。
   这与[第 14 章](../chapters/02-upstream/14-origin-map.md)讲产地溯源时的区分完全一致——
   **能判别不等于能预测**。

**更有说服力的设计**：

| 要素 | 做法 |
|------|------|
| **目标量** | 改成回归：预测**连续**的色度值或失重率，报告误差（如 RMSE）而不是准确率 |
| **验证集** | 用**不同批次、不同设备、不同产地**的豆做外部验证（而不是同一数据集随机划分） |
| **参照** | 与仪器读数（分光光度计/色度计）对照，并注明整豆还是粉[^rd2] |
| **难度** | 加入**相邻烘焙度**的样品对（差 1~2 个色度档），看模型能否分辨 |
| **对照** | 设一个人类基线（有经验的烘焙师看同样的图像） |

## Q8

**问**：**【辨识】** 三包豆的烘焙度描述属于哪种量？

**答**：没有唯一答案，但判定与追问是固定的。

| 描述形式 | 属于 | 缺什么 | 该问的一句话 |
|---------|------|-------|------------|
| "中焙""City+""法式" | **行业惯例分档**，不是测量 | 一切 | "有没有色度或失重的数字？" |
| "Agtron 62" | 颜色（状态量） | **整豆还是粉**、仪器与量表 | "这个值是整豆测的还是粉测的？" |
| "失重 14.5%" | 合计量 | 基准、生豆含水率 | "干基还是湿基？生豆含水率多少？" |
| "一爆后发展 1 分 30 秒" | 过程量 | 落点 | "下豆时的色度或失重是多少？" |
| "深烘，油亮" | 感官描述 + 表面状态 | 一切 | 出油与新鲜度**无一手证据**（[出处登记 §七](../standards.md)） |

> **实践提示**：追问时只问**一个**最有信息量的问题。
> 经验上"整豆还是粉"和"生豆含水率多少"这两句最能看出对方的专业程度——
> 答得上来的，多半也记录了曲线。
