# 第 17 章 思考题参考答案

> 只记「问题 + 正确答案」。案例题给**完整推理链**。
>
> 文献编号（[CGA2]、[B3]…）对应[出处与资料登记 §4.20](../standards.md)。

<a id="q1"></a>
## Q1

**问**：绿原酸在烘焙中的四条去路分别对应什么感受？

**答**：

| 去路 | 化学内容 | 对应的感受 | 证据 |
|------|---------|-----------|------|
| **① 异构化** | 5-CQA → 3-CQA / 4-CQA | 本身不直接产生新感受，但**改变了后续产物的构成** | [^cga3][^cga2] |
| **② 水解** | → 咖啡酸 + 奎宁酸 | 奎宁酸参与酸感；两个碎片继续受热生成**酚（来自奎宁酸）与儿茶酚（来自咖啡酸）**→ 焦味、药味 | [^cga4][^a1] |
| **③ 内酯化** | → 醌内酯（绿原酸内酯） | **"咖啡特征性"的苦**，峰在浅中烘 | [^cga2][^b3] |
| **④ 深度降解与聚合** | → 4-乙烯基邻苯二酚寡聚物（含苯基茚满）、类黑精 | **粗糙刺激的苦**；类黑精带来**颜色、质地与涩** | [^b2][^b3][^a3] |

> **一句话记忆**：**同一个前体，分别落进了苦、涩、焦味与颜色四个桶。**

<a id="q2"></a>
## Q2

**问**：内酯相对水平与前体相反，这为什么否定"生豆绿原酸高 ⇒ 熟豆更苦"？

**答**：

**观察**：熟豆中 3-CQL 与 4-CQL 的相对水平，与生豆中它们各自前体的相对水平**相反**；
作者据此推断**烘焙先让绿原酸异构化，然后才形成内酯**，
因此**熟豆中内酯的水平并不反映生豆中前体的水平**[^cga2]。

**为什么这否定了那条推理**：

```
生豆 CGA 总量 ──(异构化)──> 异构体比例改变 ──(内酯化, 上限约 30%)──> 内酯 ──(继续加深)──> 降解
```

链条上有**三步**都由烘焙条件决定：异构化程度、内酯化程度（最多约为可用前体的 **30%**[^cga2]）、
以及内酯随后的降解[^b3]。
**任何一步都能打断"生豆多 ⇒ 熟豆多"的比例关系。**

**一般性启示**（本书反复出现的一条）：

> **烘焙不是按比例放大或缩小生豆，而是重排它。**
> 所以"用生豆成分预测杯中表现"只有在**同一套烘焙条件下**才有意义；
> 跨烘焙度比较生豆指标，通常没有可比性。

<a id="q3"></a>
## Q3

**问**："浅烘的苦"与"深烘的苦"分子上差在哪？为什么冲煮参数换不回来？

**答**：

**分子层面的差别**[^b3][^b2]：

| | 浅—中烘 | 深烘 |
|---|---------|------|
| 主角 | **醌内酯**（绿原酸内酯） | **4-乙烯基邻苯二酚寡聚物**（含多羟基苯基茚满） |
| 苦的描述 | "**咖啡特征性**的苦味轮廓" | "**粗糙刺激**（harsh）"，令人联想到重烘意式 |
| 生成与消失 | 浅中烘生成，**重烘时降解** | 由前者降解而来，随烘焙加深累积 |

**为什么冲煮换不回来**：

1. **冲煮不能创造分子**：冲煮只能决定**取出多少、取出哪一类**（[第 1 章](../chapters/01-foundation/01-bean-composition.md)的"第一原理"）。
   深烘豆里的醌内酯**已经被降解掉了**[^b3]，杯子里没有的东西取不出来；
2. **能调的是比例，不是种类**：不同类别化合物的萃取行为不同[^b3]，
   所以你可以让粗糙苦少一点，但**无法把它变成另一类苦**；
3. **深烘还同时抬高了涩与 body**[^a3][^a6]，这几条一起变，
   靠单一参数很难只压住其中一条。

> **可执行的结论**：**苦的"类型"由烘焙决定，苦的"量"由冲煮决定。**
> 想换类型，换豆；想换量，调参数。

<a id="q4"></a>
## Q4

**问**：不含氮的酸却产生了含氮杂环，这提醒我们读模型实验要注意什么？

**答**：

**观察**：奎宁酸、咖啡酸与绿原酸**都不含氮原子**，但加热后的产物中
回收到了**吡啶、吡咯与吡嗪**类含氮杂环[^cga4]。

**三条提醒**：

1. **模型体系不是纯净的**：氮可能来自原料杂质、反应器环境或残留物。
   **读模型实验要问"体系里还有什么"**；
2. **模型 ≠ 真实豆子**：在真实咖啡里，这些酸与庞大的氨基酸/蛋白池共存（[第 16 章](../chapters/03-roasting/16-roasting-chemistry-1.md)），
   反应会相互串联；模型实验的价值在于**指认可能的路径**，不是复现真实比例；
3. **正因如此，模型实验的结论要"只取机理、不取数值"**：
   本书引用该研究时取的是"**酚主要来自奎宁酸、儿茶酚来自咖啡酸**"与
   "**氧气不起重要作用**"这两条**定性**结论，
   而**不把 μg/g 数值搬到真实咖啡上**。

<a id="q5"></a>
## Q5

**问【案例】**："买了低咖啡因的豆，所以应该不苦"——怎么回应？

**答**：

**缺的那一步**：他默认了"**苦 = 咖啡因**"，而这一步没有证据支持。

**回应要点**（按证据强度排列）：

1. **主要苦味驱动者不是咖啡因**：以味觉响应为导向逐级分离咖啡饮料的研究指认
   **绿原酸的烘焙产物（醌内酯）**为主要苦味驱动者[^b1]；
2. **咖啡因的苦还会被压住**：在天然浓度下，类黑精把咖啡因的苦味强度**削弱约一半**[^b7]；
   同一研究还发现咖啡因与绿原酸成络**不影响**其苦味，并直言咖啡因的感官角色"**仍不清楚**"[^b7]；
3. **低因处理本身会改变别的东西**：脱因工艺会带走/改变一部分其他成分，
   **杯中表现的差异不能简单归给"咖啡因少了"**（本书未在此展开，
   脱因工艺留待第七部分）；
4. **真正决定苦的是烘焙度与萃取**：苦的**类型**由烘焙决定[^b3][^b2]，
   苦的**量**由萃取决定[^b3]。

> **一句话回应**："你降低的是一个**次要**的苦味来源，
> 而主要来源（绿原酸的烘焙产物）跟咖啡因含量没有关系。"

<a id="q6"></a>
## Q6

**问【案例】**：深烘美式的"苦 + 涩 + 烧焦味"分别来自什么？怎么区分烘焙与冲煮问题？

**答**：

**三种感受的最可能来源**：

| 感受 | 最可能的化学来源 | 证据 |
|------|----------------|------|
| **粗糙的苦** | 4-乙烯基邻苯二酚寡聚物（多羟基苯基茚满），由醌内酯在重烘时降解而来 | [^b3][^b2] |
| **涩** | 富酚类黑精级分（触觉通路，不是味觉） | [^a3] |
| **烧焦味/药味** | 酚类（主要来自奎宁酸）与儿茶酚类（来自咖啡酸） | [^cga4] |

**区分"烘焙问题"与"冲煮问题"的验证步骤**（按顺序做，一次只改一件事）：

| 步骤 | 做什么 | 怎么判读 |
|------|-------|---------|
| 1 | **降低萃取强度**：磨粗一点 / 降低水温 / 缩短时间 | 若三种感受**同步减弱但质地不变**，说明是"取多了"，属**冲煮**可调范围 |
| 2 | **同一支豆做冷萃或低温萃取** | 若粗糙苦与焦味**仍在**，说明这些分子确实存在于豆中 → 指向**烘焙** |
| 3 | **换同产地、更浅烘焙度的豆**，用同一参数 | 若感受结构明显改变 → 进一步支持是烘焙度造成的 |
| 4 | **换一包同款**（不同批次） | 排除单批次问题 |

> **关键判据**：**冲煮改变的是强度，烘焙改变的是类型。**
> 如果调参数只能让它"淡一点"而不能让它"变一种苦"，那就是烘焙侧的事。

<a id="q7"></a>
## Q7

**问**：把萃取时间延长一倍，苦的强度与质地会怎么变？怎么验证？

**答**：

**预测**（要分开两件事）：

| 维度 | 预测 | 依据 |
|------|------|------|
| **强度** | **上升**（更多可溶物被取出） | 萃取的基本图景（第四部分） |
| **质地/构成** | **也会改变**，因为**不同类别的化合物萃取行为不同**[^b3] | 所以延长时间不是"等比例放大" |

**为什么第二条常被忽略**：人们默认"萃取久 = 同样的东西更多"，
但[第 1 章](../chapters/01-foundation/01-bean-composition.md)引用的对照实验已经证明
**把浓度统一到相同 TDS 后，不同萃取方式的苦、酸、香气仍显著不同**——
**浓度相同不等于成分格局相同。**

**验证设计**：

1. 同一支豆、同一研磨、同一水温，做两杯：正常时间 T 与 2T；
2. **把两杯稀释到相同 TDS**（或粗略对齐"同样浓"）——这一步是关键，
   否则你只是在比较浓度；
3. 盲测（同伴编号）记录：苦**强度**、苦**质地**、涩、酸、香气；
4. 结论写法：**"在这支豆、这套参数下，把浓度对齐之后，两杯在 ____ 上仍有差异。"**

> **如果对齐浓度后两杯几乎一样**，那也是个有价值的结果：
> 说明在这段时间窗内，延长时间主要改变了浓度而非格局。

## Q8

**问【辨识】**：三处"咖啡为什么苦"的说法，对照证据判断并记录有无出处。

**答**（开放题，给判定清单）：

**逐条对照清单**：

| 常见主张 | 本书判定 | 依据 |
|---------|---------|------|
| "苦来自咖啡因" | ❌ | 主要驱动者是绿原酸的烘焙产物[^b1]；咖啡因苦度被类黑精削弱约一半[^b7] |
| "咖啡因占苦味 10%~30%" | **缺乏证据** | 本书未找到任何一手出处（[出处登记 §六 #3](../standards.md)） |
| "烘得越深，苦味物越多" | ⚠️ 不完整 | 是**种类变化**：醌内酯降解为粗糙的寡聚物[^b3][^b2] |
| "苦是萃取过度造成的" | ⚠️ 只对一半 | 萃取决定**量**；类型由烘焙决定[^b3] |
| "涩是苦的一种" | ❌ | 涩属触觉通路；咖啡上已有类黑精致涩的直接证据[^a3] |

**记录表**：

| 出处 | 主张 | 判定 | 给了出处吗 | 出处类型（论文/科普/无） |
|------|------|------|-----------|----------------------|
| | | | | |

**这个练习的典型收获**：

> 你会发现**几乎所有说"咖啡因是苦味主因"的材料都不给出处**，
> 而给出处的材料往往指向 Hofmann 团队这一系列以**感官为导向**的分离研究[^b1][^b2][^b3]——
> 而那一系列研究的结论恰恰相反。
>
> **这就是本书"关键结论要两个独立来源、查不到就不写"这条纪律的价值**：
> 它让你在面对一个流传二十年的说法时，仍然能问出"**证据在哪**"。
