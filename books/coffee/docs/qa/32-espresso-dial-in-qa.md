# 第 32 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：时间由研磨、粉饼阻力、机器供水与目标出液共同产生。把它单独设为目标会掩盖真正变化的输入；应和出液质量、
机器状态与感官一起记录。

<a id="q2"></a>
## Q2

**答**：先检查机器预热/恢复、粉饼制备、研磨与用水是否真的一致。相同质量只说明总量相近，不能证明温度、流动路径
或成分格局相同；先复做再归因。

<a id="q3"></a>
## Q3

**答**：若主要是浓度不足，先通过目标出液或粉量验证浓淡假设。调细研磨会同时改变流速和萃取，测试的是另一个问题；
把两个问题混在一起就无法知道是哪项改善了杯感。
