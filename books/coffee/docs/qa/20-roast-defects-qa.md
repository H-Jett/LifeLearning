# 第 20 章 思考题参考答案

<a id="q1"></a>
## Q1

**问**：五类缺陷的标记化合物分别是什么？"标记物"为什么比"某分子 = 某缺陷"更准确？

**答**：

| 缺陷 | 标记化合物 |
|------|-----------|
| light（过浅） | 吲哚 |
| scorched（焦斑） | 4-乙基-2-甲氧基苯酚（4-乙基愈创木酚） |
| dark（过深） | 苯酚 |
| baked（烤） | 麦芽酚 |
| underdeveloped（夹生） | 2,5-二甲基呋喃 |

（均出自同一项六曲线对照实验[^df1]。）

**为什么叫"标记物"而不是"等于"**：

1. **它是被"选出来"的**：研究者从 37 种此前已确认的关键气味物里，
   为每类缺陷**各挑一个变化最显著的**[^df1]——不是说只有它变了；
2. **它是相对丰度的变化**，不是一个判定阈值——文献没有给"超过多少就算缺陷"；
3. **它不是感受本身**：你喝到的是几十种分子的混合结果
   （[第 4 章](../chapters/01-foundation/04-perception.md)：混合物的感受不能简单相加）；
4. **单一体系**：这些标记物来自一支豆、一台设备的对照实验，换体系需要重新验证。

> 与[第 13 章](../chapters/02-upstream/13-green-grading.md)对"马铃薯味 ↔ IPMP"的处理一致：
> **可以用它做筛查，不能用它做判决。**

<a id="q2"></a>
## Q2

**问**：为什么 [DF1] 与 [DF2] 不算两个独立证据？怎样做一次真正独立的验证？

**答**：

**因为它们共用同一套东西**：同一支单一产地豆、同样的六条曲线做出的同一批样品，
以及重叠的作者团队[^df1][^df2]。

如果这批样品的烘焙执行有系统偏差（比如"baked"那条曲线同时也烘得更深），
那么**两篇论文会一起错**。所以它们是**同一证据体系的化学面与感官面**，
而不是彼此的独立重复。

> **这与本书一贯的交叉验证纪律一致**：两个来源要独立，
> **独立指的是样品、设备与团队都不同**（[第 1 章](../chapters/01-foundation/01-bean-composition.md)的成分数据就是这么处理的）。

**一次真正独立的验证该怎么设计**：

| 要素 | 做法 |
|------|------|
| **样品** | 不同产地、不同处理法的至少两支豆（避免"只在这支豆上成立"） |
| **设备** | 不同机型（滚筒 + 流化床），因为传热方式不同（[第 15 章](../chapters/03-roasting/15-roasting-physics.md)） |
| **团队** | 另一个实验室独立执行 |
| **缺陷定义** | 预先写死每条缺陷曲线的操作定义（否则各家的"baked"不是同一件事） |
| **盲法** | 感官评价必须盲测并随机化呈样（[第 11 章](../chapters/02-upstream/11-fermentation-experimental.md)的标签效应） |
| **预注册指标** | 事先声明用哪些标记物与哪些感官维度，避免事后挑选 |

## Q3

**问**：用普适色曲线解释为什么"每批测色度"发现不了"烤"。

**答**：

**事实**：七条动态差异极大的曲线，颜色在 L\*a\*b\* 空间中**落在同一条轨迹上**，
而其中一条（记为 EM）正是**为了复制"烤"这种缺陷**而设计的[^rd2]。

**推理**：

```
色度读数 = 轨迹上的位置（一维）
不同路径 → 同一位置 ⇒ 读数相同
⇒ 只看读数，无法反推路径
⇒ "烤"这种"路径缺陷"在色度上不可见
```

**类比**：色度像里程表，它告诉你开了多远，**不告诉你路上有没有急刹车**。

**推论（很实际）**：

1. **以色度为唯一质控手段是不够的**——色度合格的批次照样可能是"烤"的；
2. 能发现缺陷的是**香气与感官**（标记物[^df1]、描述性分析与消费者测试[^df2]、电子鼻[^df3]）；
3. 所以严肃的烘焙商**每批杯测**不是仪式感，而是目前**唯一**被验证过的判据路径。

<a id="q4"></a>
## Q4

**问**："在某两个指标上不可区分" vs "无害"——区别是什么？为什么必须用前者？

**答**：

| 说法 | 含义 | 它需要什么证据 |
|------|------|--------------|
| **"在指标 X 上不可区分"** | 已测的那个指标没有显示差异 | 一次在该指标上的对照实验（已有：TA[^rp9]、颜色[^rd2]） |
| **"无害"** | **所有**与品质相关的维度都没有差异 | 至少需要**感官**对照实验；而现有研究**明确写了未做感官评价**[^rp9] |

**为什么必须用前者**：

1. **缺席的证据不是证据的缺席**：TA 只是众多化学维度中的一个，
   颜色只记录落点；香气物、结构、萃取行为都没被测；
2. **该研究自己划了边界**：作者既指出"据其所知没有已发表数据支持 RoR 转负会严重降质"，
   **也**写明未做感官评价[^rp9]——两句话要一起引；
3. **这正是本书的通用纪律**：把"未被支持"与"被否定"分开
   （[第 9 章](../chapters/02-upstream/09-harvest-ripeness.md)对未熟果、
   [第 12 章](../chapters/02-upstream/12-drying-storage.md)对过季豆都是这么处理的）。

**正确的一句话**：
**"这条被行业当成硬指标的判据，目前还没有被感官实验检验过。"**

<a id="q5"></a>
## Q5

**问**："终温差 1 ℃ 都能检出化学差异"为什么不能支持"1 ℃ 决定成败"？

**答**：

**该研究做了什么**：用 ¹H NMR 加化学计量学分析 13 条工业烘焙曲线的萃取液，
报告**终温相差约 1 ℃、或总时长相差约 25 秒**时，化学组成的变化**仍可被检出**[^nm1]。

**它证明的是"分析方法的灵敏度"，不是"品质的敏感性"。** 中间缺了三步：

1. **该研究未做感官评价**——没有人喝过这些样品并报告差异；
2. **可检出 ≠ 可感知**：感知有阈值，很多化学差异落在阈值以下
   （[第 4 章](../chapters/01-foundation/04-perception.md)：含量高不等于有贡献，关键是气味阈值）；
3. **可感知 ≠ 更好**：即使能尝出差别，也不代表某一侧更受偏好
   （偏好要做消费者测试，如 [DF2] 那样[^df2]）。

**一句话**：**灵敏的仪器会在任何工艺里找到差异**；
把"能测出差"当成"有意义的差"，是读工艺类文献时最常见的一个跳步。

<a id="q6"></a>
## Q6

**问**：**【案例】**"一爆后 flick 了，我直接倒掉了。" 怎么回应？

**答**：

**推理链**：

**他看到什么** → 曲线上一爆后 RoR 突然抬起。

**行业为什么这么判** → "flick 会烧到表面/破坏风味"是流传很广的经验，
而且烘焙师往往有**自己的**批次记忆作支撑。

**文献能核到什么** →
在一项 5 kg 商用机的对照实验里，**夸张 flick（EF）**与**RoR 转负（NR）**两条曲线的
**可滴定酸度动态与中庸曲线几乎无法区分**，作者并写明"据其所知没有已发表数据支持
RoR 转负会严重降质"，同时自述**未做感官评价**[^rp9]；
另一项同组研究显示这两条曲线的**颜色**也落在普适轨迹上[^rd2]。

**该怎么回应（兼顾两边）**：

> "有意思的是，目前唯一公开的对照实验里，flick 与掉火在酸度和颜色上都测不出差别，
> 而且那项研究没做感官——所以它既不能证明你错，也不能证明你对。
> **要不要试一次？** 同一支豆、同一天，一锅正常、一锅让它 flick，
> 编号后请三个人盲测。如果你的判断成立，你就有了自己的证据；
> 如果测不出来，你可能会少倒掉很多豆。"

**要点**：不要用"文献说无害"去否定从业者的经验（文献没这么说），
而是**把争论变成一个可做的实验**——这正是本书第六部分（感官）的价值所在。

## Q7

**问**：**【案例】** 纸板味 + 平淡 + 没甜感，但豆色正常。原因？两步实验？

**答**：

**第一步推理：颜色正常说明了什么**

几乎什么都没说明。颜色只记录落点，不记录路径；
**刻意做成"烤"的曲线同样落在普适颜色轨迹上**[^rd2]。
所以"颜色正常"**不能排除**烘焙缺陷。

**可能原因（按层分）**：

| 层 | 可能原因 | 线索 |
|----|---------|------|
| 烘焙 | **"烤"（baked）**：麦芽酚一侧的标记[^df1]，感官上表现为平淡、缺乏层次[^df2] | 纸板/面包皮味、香气整体弱 |
| 烘焙 | 过浅或夹生 | 谷物/生青味更突出（不同标记物[^df1]） |
| 上游 | 生豆陈化 / 储存不当 | 干香整体钝、"平"（[第 12 章](../chapters/02-upstream/12-drying-storage.md)） |
| 下游 | 豆放太久 / 研磨后久置 | 与购买日期和研磨时间相关（第 41 章） |
| 冲煮 | 萃取不足 | 同时伴随明显的酸尖与空洞感 |

**两步实验**：

1. **第一步（动冲煮）**：把萃取强度向两个方向各推一次
   （更细/更久 与 更粗/更快），其他全部不动。
   - **症状明显改变** → 冲煮问题为主；
   - **症状几乎不变** → 进入第二步。
2. **第二步（换豆）**：换一支不同烘焙商的同类型豆，**用你原来的参数**冲。
   - **症状消失** → 问题在豆（烘焙或生豆）；
   - **症状还在** → 检查水（[第 3 章](../chapters/01-foundation/03-water.md)）与器具残留。

**关键判读**：**"纸板/平淡"对冲煮参数往往不敏感**——
因为缺的是香气物**本身**，而冲煮只能选择性取出已经存在的东西
（[第 16 章](../chapters/03-roasting/16-roasting-chemistry-1.md)）。

## Q8

**问**：quaker 实验（7 颗/65 颗才显著）与"完全不含"的规定为什么可以同时合理？

**答**：

**实验说的是"效应"**：在那项实验里，颜色等于或高于 Agtron 82.8 的未熟豆，
要到**一杯 65 颗里有 7 颗**才显著损害感官特征[^df4]。
这是一条**剂量—效应**信息。

**规定说的是"可执行的门槛"**，它要满足三个额外条件：

| 条件 | 说明 |
|------|------|
| **可检验** | "完全不含"能靠目视分选检验；"每杯不超过 6 颗"在一批几十公斤的豆上无法核查 |
| **有安全裕度** | 实验只测了特定颜色档的 quaker、特定豆与特定比例；其他条件下阈值可能更低 |
| **信号价值** | quaker 比例同时是**采收与分选质量**的指标——即使少量不毁杯，它也说明上游在漏水 |

**所以两者不矛盾**：**实验回答"会不会坏"，规定回答"怎么管"。**

> ⚠️ **绝不能反读**成"未熟豆没关系"。该实验是单一体系，且它自己就证明了
> 未熟豆的风味来自**未熟这一化学组成**[^df4]——量大了一定有影响。

## Q9

**问**：**【辨识】** 三段"烘焙缺陷"内容的证据分级。

**答**：没有唯一答案，但分级标准固定：

| 级别 | 特征 | 例子 |
|------|------|------|
| **化学/感官证据** | 指向具体缺陷类别，且该类别在文献中有标记物与感官验证 | "烤会带来纸板/麦芽样的平淡"[^df1][^df2] |
| **行业经验** | 说得出操作，但查不到对照实验 | "RoR 不能掉头"[^rp9]、"DTR 要 20%~25%"（检索当日无文献） |
| **无法核对** | 给了精确数字却没有来源，或与已知证据冲突 | "一爆在 XXX ℃"、"色度合格就没有缺陷"[^rd2] |

**做这道题时最值得注意的一件事**：
**越是给出精确数字的说法，越容易落在第二、三级。**
精确度与可核对性经常是**反相关**的——这是本书从第 1 章讲到现在的同一件事。
