# 第 42 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：称量、计时与记录先把输入固定，使后续变化可以归因。风味配件即使有效，也很难在粉量、研磨和水温都漂移时被验证；因此低成本的重复性工具往往先释放其它器具的价值。

<a id="q2"></a>
## Q2

**答**：先固定称量、清洁、器具与流程，连续多杯观察同刻度的流速和杯感是否仍大幅漂移；再检查保留粉、刀盘状态与豆温等因素。只有问题持续且能指向研磨，升级才有明确理由。

<a id="q3"></a>
## Q3

**答**：一杯可能受随机操作、温度、期待或豆子状态影响。应固定条件、盲编码并重复，与旧滤杯对照；若改善稳定且符合你的目标，再把购买结论写为有证据支持。
