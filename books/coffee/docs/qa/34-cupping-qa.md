# 第 34 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：描述回答“样品呈现了什么”，偏好回答“我或目标市场是否喜欢”。把两者混成一个分数会让价格、标签和个人偏好
掩盖样品本身的可交流信息。

<a id="q2"></a>
## Q2

**答**：先固定样品、粉水比、研磨、水、杯具和呈样时点；再用盲编码与随机顺序减少期待偏差。精确模仿某个专业秒数
不如让所有样品真正处在相同条件重要。

<a id="q3"></a>
## Q3

**答**：感官阈值、词汇、偏好和注意力不同都会导致分歧。先看两人是否使用同条件与盲编码，再比较描述是否一致；偏好
不同本来就可能合理，重复与训练才能判断结论有多稳定。
