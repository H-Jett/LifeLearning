# 第 39 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：即使不知道身份，永远先喝 A 仍会让温度、疲劳、残留与第一口/最后一口效应系统性偏向某一条件。随机顺序把这些影响分散，才更接近在比较自变量本身。

<a id="q2"></a>
## Q2

**答**：三角题问能否检测到差异，偏好题问谁更喜欢。一个人可稳定分出 A/B 却没有偏好，也可因随机或期待而偏好某杯却不能稳定辨别；必须分别记录。

<a id="q3"></a>
## Q3

**答**：写“在本次轮次中未稳定检出 A/B 差异；参与者的盲态偏好记录倾向 B”，并保留答对数、所有偏好与条件。不要把偏好描述为已证明的感官差异，也不要将未检出写成产品完全相同。
