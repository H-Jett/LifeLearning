# 第 29 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：两者都有加压滤过的一面，但摩卡壶的驱动力随加热过程变化，粉床与意式紧实粉饼也不同；意式的压力、时间或
粉量不能直接移植。应从本机的热源、流动与重复性建立基线。

<a id="q2"></a>
## Q2

**答**：虹吸过程至少分为上水、上壶浸泡/混合和停火后的滤器回流。只报上壶接触时间，无法知道加热和回流阶段是否
相同，也无法复现完整输入。

<a id="q3"></a>
## Q3

**答**：先检查滤器是否正确装配和清洁、粉量与研磨是否造成阻力、器皿/热源的加热与停火流程是否一致。不要同时改
粉水比、研磨、搅拌和火力；若器皿或密封异常，应停止操作并按制造商说明处理。
