# 第 25 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：平均值把不同区域混在一起。一部分水可能快速穿过低阻力区而萃取不足，另一部分在高阻区接触更久；
两者混合后可得到一个看似正常的平均值，仍掩盖局部不均。

<a id="q2"></a>
## Q2

**答**：慢流可来自细粉比例、整体低渗透率、粉量、滤纸或压实等。通道说的是水流在空间中偏向某些路径，必须
结合重复性、进水/床层条件和单变量对照，而不能由总时间独自判断。

<a id="q3"></a>
## Q3

**答**：先固定豆子、粉量、研磨、水量、温度和目标出液，连续记录过程与口感；选择一个输入（例如湿润方式
或布粉方式）做重复对照。若差异仍大，再检查磨豆机、秤和器具清洁，而非同时把研磨、时间和注水都改掉。
