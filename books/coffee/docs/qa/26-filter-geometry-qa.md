# 第 26 章 思考题参考答案

<a id="q1"></a>
## Q1

**答**：几何改变床层和流动分配，研究可观察到感官差异；但偏好取决于豆子、烘焙、研磨、注水和个人目标，不能从
“有差异”推出一种对所有情况更好。

<a id="q2"></a>
## Q2

**答**：滤纸既过滤也参与流动阻力，且可能与细粉堆积共同改变出液。换纸后总时间改变不必立刻归因于研磨，先用
记录建立新基线再单变量调整。

<a id="q3"></a>
## Q3

**答**：先固定豆、粉量、水量、水温与注水，记录新滤杯的时间和口感；下一杯只微调研磨建立基线。不要同时改
粉量、温度、注水和滤纸，否则无法判断慢流来自几何、纸张还是新参数。
