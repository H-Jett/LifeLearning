# 🛠 项目 P3 · 给自己做一条“萃取率—口感”标定

> 目标不是找出一条普适的“金杯曲线”，而是在**一支具体豆、一个器具、一段具体时间**内，建立你自己的
> “改了什么 → 量到什么 → 喝到什么”记录。它把第 21~25 章的因果模型变成可复核的小实验。

## P3.1 交付物

| 交付物 | 最低要求 |
|--------|----------|
| 固定条件卡 | 豆子、烘焙日、器具、水、粉量、水量、温度、注水写清楚 |
| 实验记录 | 至少三杯；每轮只改变一个旋钮 |
| 感官记录 | 先写感受，再看 TDS/萃取率或揭晓参数 |
| 结论 | 只针对这支豆/这套器具；写出一个未知项与下次动作 |

## P3.2 先选一个旋钮

| 可选自变量 | 适合谁 | 不要同时改什么 |
|------------|--------|----------------|
| 研磨刻度 | 有同一台可复现磨豆机 | 粉量、粉水比、温度、注水 |
| 出液/总水量 | 能稳定称重 | 研磨与粉量 |
| 水温 | 有控温能力 | 研磨、时间、注水 |
| 注水/搅拌方式 | 手冲且其他输入稳定 | 研磨、粉量与总水量 |

不要把“时间”当作独立旋钮强行扫描：滤过式里它常是研磨与流速的结果。若时间变了，记录它；但先说明你
真正主动改变的是什么。

```mermaid
flowchart LR
 A[固定豆子和配方] --> B[只改一个旋钮]
 B --> C[称重/计时；有条件再测 TDS]
 C --> D[盲标或先写感官]
 D --> E[重复至少一次]
 E --> F[只对本组条件作结论]
```

## P3.3 🅐 无器具版：画“参数—感受”而不是假装有萃取率

没有折光仪时，不要填写一个猜出来的萃取率。用同一支豆、同一器具做三杯，只改变研磨（粗/中/细）或
总水量（少/中/多）之一，填写[冲煮记录表](../../forms/brew-log.md)。每杯先盲标或先写感受，再揭晓条件：

| 轮次 | 主动改变的变量 | 总时间（记录值） | 浓淡感 | 酸/苦/甜/body | 你愿意再喝吗 | 下一杯只改什么 |
|------|----------------|------------------|--------|---------------|---------------|----------------|
| 1 | | | | | | |
| 2 | | | | | | |
| 3 | | | | | | |

这张表不是“萃取率—口感曲线”，而是你的**条件—感受标定**。它仍然能告诉你哪一端开始出现太淡、太涩、
不稳定或不喜欢的变化。

## P3.4 🅑 有条件版：TDS 与萃取率的测量闭环

> 所需：秤（0.1 g）、计时器、同一器具与水；可选咖啡折光仪。折光仪要按说明校准、取代表性样品；没有
> 咖啡专用校准就不把通用 Brix 数字直接当 TDS。

固定粉量与总投水，选择三个相邻研磨档位；每档至少做两次。记录成品饮料质量 `M饮料` 与 TDS；萃取率按第
22 章公式计算：`萃取率 ≈ M饮料 × TDS ÷ M干粉`。这是**杯中平均值**，不是床层每一处的萃取率（第 25 章）。

| 研磨/自变量 | 重复 | 干粉 g | 饮料 g | TDS % | 计算萃取率 % | 时间 | 感官（先写） |
|-------------|------|--------|--------|-------|---------------|------|----------------|
| A | 1 | | | | | | |
| A | 2 | | | | | | |
| B | 1 | | | | | | |
| B | 2 | | | | | | |
| C | 1 | | | | | | |
| C | 2 | | | | | | |

可把横轴画为你主动改变的变量，纵轴并列写平均 TDS、平均萃取率与自己的偏好（不需要伪精确的平滑曲线）。
如果两次重复差异很大，先把结果标为“重复性不足”，回查磨豆、称量、注水与床层均匀性。

## P3.5 结论模板

> 在 ______（豆/烘焙日）、______（器具）、______（固定配方）下，我只改变了 ______。
> 在 ______ 到 ______ 的范围内，测到/感到 ______；我的偏好最高点是 ______。
> 该结论不推广到其他豆或器具；本轮最大不确定性是 ______，下一轮只验证 ______。

## P3.6 常见错误

| 做法 | 为什么会毁掉结论 | 修正 |
|------|------------------|------|
| 一杯同时改研磨、水温和注水 | 无法归因 | 回到一个变量 |
| 先看参数再品尝 | 预期会影响描述 | 先盲标或先写感官 |
| 用单次 TDS 判定“均匀” | 平均值掩盖床层局部差异 | 记录过程、重复并排查床层 |
| 把三杯结果外推为所有咖啡规律 | 豆、烘焙、器具均会变 | 限定结论范围 |
