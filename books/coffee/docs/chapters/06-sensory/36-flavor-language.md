# 第 36 章 风味描述语言：风味轮与感官词典

风味词不是猜产地的密码，也不是修辞比赛。它们的作用是让“有点像某种东西”变成可让别人复查的感官观察：在什么条件、
什么强度、用什么参照物、由谁感知到。

## 36.1 从大类走向具体

SCA 对风味轮的使用建议是从中心的大类往外走，越往外描述越具体；WCR 感官词典则为属性提供定义与参照物。[^wheel]
若只能可靠地说“果味”，就停在果味；不要因为豆袋写了蓝莓而强迫自己闻到蓝莓。

```mermaid
flowchart LR
 A[整体印象] --> B[大类：果味/烘焙/香料等]
 B --> C[子类：如柑橘]
 C --> D[具体参照：如柠檬]
 D --> E[记录强度、样品与条件]
 E --> F[下次与同一参照物复核]
```

| 层级 | 合格表达 | 不合格跳跃 |
|------|----------|------------|
| 大类 | “有明显果味” | “这一定是埃塞俄比亚” |
| 子类 | “更接近柑橘而非浆果” | “像某农场的日晒批次” |
| 具体 | “像新鲜柠檬皮的香气” | 无参照就写“柠檬糖” |
| 强度 | “中等，在冷却后更明显” | “很高级” |

## 36.2 参照物让词汇可校准

同一词在不同人脑中可能不同。参照物把词义锚在可重复的气味、味道或质地上；比较前应先闻/尝参照物，再回到咖啡。
WCR 词典的价值不在于要求人人背完，而在于展示“定义 + 参照物 + 强度”的工作方式。[^lexicon]

家庭参照物应安全、可获得且在当天新鲜；对不可食用的芳香参照，不要吞咽。也不要把参照物直接加入杯测样品，否则会改变
咖啡本身。

## 36.3 一张最小描述卡

| 字段 | 示例写法 |
|------|----------|
| 条件 | 盲编码、同一水与冲煮法、品尝温度段 |
| 香气/风味 | 果味 → 柑橘 → 更像柠檬皮 |
| 基本味与质地 | 酸感中等、甜感低、口感轻 |
| 时间变化 | 热时烘焙感明显；冷却后柑橘更清楚 |
| 置信度 | “可复述，但需下次用参照物再核” |

这比列十个漂亮名词更有用，因为它保留了条件与不确定性。

## 36.4 常见说法辨析

| 说法 | 判定 | 说明 |
|------|------|------|
| “风味轮是风味预测表” | ❌ 明确错误 | 它是描述与沟通工具，不从产地推断杯中一定有什么。 |
| “越具体越专业” | ❌ 明确错误 | 具体必须由参照物与重复支持；停在大类完全有效。 |
| “词典限制个人感受” | ❌ 明确错误 | 它先建立共同锚点，再允许清楚地交流差异。 |
| “一个词对应一个化合物” | ❌ 过度简化 | 风味通常是多种化合物、味觉与语境共同造成的感受。 |

## 36.5 🔎 买豆与冲煮时的用处

豆袋词应被当作待验证的假设：先盲喝，再看它是否与自己的参照物匹配。若手冲与意式得到不同描述，先记录冲煮条件，
不要断言其中一杯“把真实风味冲错了”。

## 36.7 本章实操

### 🅐 无器具版

选一个风味大类，为它找一项安全参照物。写下你观察的是气味、基本味还是质地，并用“更像 A 而非 B”的句式做两条描述。

### 🅑 有条件版

以盲编码的两杯咖啡做记录：先只写大类，随后闻/尝一个参照物再写子类。隔天重做，比较具体词是否仍成立；不成立时退回
上一级描述，而不是硬保留原词。
