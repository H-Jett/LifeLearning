# 杯测记录表（自拟）

> ⚠️ **这不是 SCA 官方杯测表**。本表**参考行业通行的杯测框架自拟**，
> 目的是让自学者在没有校准环境、没有参照物的情况下也能做出**可比较的记录**。
>
> 官方的杯测协议与评分表（含百分制表与 Coffee Value Assessment）**有版权**，
> 本书不复制其条文与分值版式；需要现行官方版本请去
> [SCA 官方网站](https://sca.coffee/)。第 34、35 章会讲怎么读官方表、
> 以及它与本表的差别在哪。
>
> **本表刻意不给总分**。理由见下方 §4——在你有参照物之前，
> 一个总分数字不会让你进步，逐项描述才会。

## 一、本次杯测的条件（先锁死，再开始）

| 条件 | 本次取值 | 说明 |
|------|---------|------|
| 样品数 | | 建议 2~4 支，多了记不住 |
| 每支的杯数 | | 有条件就每支 ≥2 杯（用来发现"同一支豆的杯间差异"）|
| 粉量 / 水量 / 粉水比 | | **所有样品必须完全一致**，这是杯测的全部意义所在 |
| 研磨（磨名 + 刻度） | | 同上，一致；每换样先走一小把豆清膛 |
| 水（来源 / TDS） | | 同上，一致 |
| 水温（注水时） | | 同上，一致 |
| 浸泡时长 → 破渣时间 | | 同上，一致 |
| 是否盲测（编号是否由他人贴） | | **强烈建议盲测**，理由见第 39 章 |
| 环境（安静 / 有无异味 / 光线） | | 香水、饭菜味会毁掉整场 |

> **杯测的定义就是"把所有非样品变量锁成一样"**。
> 如果你做不到完全一致，也没关系——但请**把实际取值写下来**，
> 这样你至少知道自己这一场的结论能推广到什么范围。

## 四、排序与理由（代替总分）

| 排序 | 样品 | 我为什么把它排在这个位置（必须写具体项，不许写"更好喝"） |
|------|------|-----------------------------------------------|
| 1 | | |
| 2 | | |
| 3 | | |

> **为什么不给总分**：总分是**为了在评审之间传递信息**而存在的，
> 它的前提是所有人都被校准到同一把尺子上（这正是 Q-Grader 训练在做的事）。
> 一个人自己给的总分，既不能和别人比，也不能和三个月后的自己比——
> 那个数字唯一的作用是让你误以为自己在进步。
>
> **排序 + 具体理由**没有这个问题：它强迫你指出**可被验证的差异**。

> 最有价值的一栏是第三栏。**豆袋上的描述你尝不到，可能有三种原因**：
> ①它就是营销词；②你的冲煮参数没把那些成分带出来；③你还没建立这个词的参照物。
