# 豆袋核对清单

> 🅐 **无器具**，随时能用。买豆前（看详情页）或收到豆后（看实物袋）逐项打勾。
>
> 这张表的用法不是"缺项就不买"，而是**让你知道自己在为多少信息付钱**。
> 同样价钱，一包把字段填满的豆和一包只写"精品咖啡豆 中度烘焙"的豆，
> 买到的确定性完全不同。

## 一、必须有的字段（缺一项就该追问）

| # | 字段 | 有？ | 袋上原文 | 缺失意味着什么 |
|---|------|------|---------|--------------|
| 1 | **烘焙日期**（不是保质期 / 赏味期 / 生产日期） | ☐ | | 只写保质期 = 你无法判断新鲜度，这是最常见的规避手法 |
| 2 | 净含量 | ☐ | | 算单价的分母 |
| 3 | 产国 | ☐ | | 连产国都不给，通常是拼配商业豆 |
| 4 | 是否为拼配（单品 or blend） | ☐ | | 未注明的"某国某产区"有时是主基调 + 补充豆 |
| 5 | 适用方式（手冲 / 意式 / 通用） | ☐ | | 影响烘焙度选择，不是硬约束但是有用的信号 |

## 二、精品豆应该有的字段（越全越说明供应链透明）

| # | 字段 | 有？ | 袋上原文 | 这个字段能让你推出什么 |
|---|------|------|---------|---------------------|
| 6 | 产区 / 合作社 / 庄园 | ☐ | | 可追溯性；也是复购时找同一支豆的依据 |
| 7 | 品种 | ☐ | | 风味潜力的上限与价格的一大来源（第 6 章） |
| 8 | 处理法 | ☐ | | 对风味的影响常常大于产区（第 10、11 章） |
| 9 | 海拔 | ☐ | | 与密度、酸质相关（第 7 章，注意是相关不是因果） |
| 10 | 烘焙度（且说明用什么衡量） | ☐ | | 只写"中度"信息量很低（第 19 章） |
| 11 | 烘焙商建议的冲煮参数 | ☐ | | 你的调试起点，能省两三次试错 |
| 12 | 杯测分 / 评分（并注明谁评的） | ☐ | | 没有评分人与协议的分数，参考价值有限（第 35 章） |
| 13 | 采收年份 / 批次号 | ☐ | | 判断是不是过季生豆（第 12 章） |

## 三、需要警惕的写法

| # | 看到这种写法 | 为什么要警惕 | 我会怎么追问 |
|---|------------|------------|------------|
| 14 | 只有"赏味期""最佳风味期"没有烘焙日期 | ☐ 见到就记下来 | "烘焙日期是哪天？" |
| 15 | 产地写成一个极大的范围（如只写一个洲） | ☐ | "具体产区 / 合作社是哪里？" |
| 16 | 风味描述堆了很多个词但没有产区与处理法 | ☐ | 描述词是**推销**，字段才是**信息** |
| 17 | 用"顶级""特级""珍稀"这类无定义等级词 | ☐ | "这个等级是按哪套体系评的？"（第 13 章） |
| 18 | 声称的品种与该产国常见品种明显不符 | ☐ | 不一定是造假，但值得问一句（第 6、14 章） |
| 19 | 深烘豆袋上写着大量明亮水果调 | ☐ | 与烘焙化学矛盾（第 16、17 章） |
| 20 | 没有单向排气阀、且声称"极新鲜" | ☐ | 排气阀与包装方式是判断包装工艺的线索（第 41 章） |

## 四、算一下单价与信息密度

| 项 | 填写 |
|----|------|
| 价格 ÷ 净含量 = 每 100 g 单价 | |
| 第一部分（5 项必须字段）填满了几项？ | / 5 |
| 第二部分（8 项精品字段）填满了几项？ | / 8 |
| 第三部分（7 条警惕写法）命中了几条？ | / 7 |
| **我的结论**（买 / 追问后再决定 / 不买，写理由） | |

> **要带走的判断**：贵不贵不看绝对价格，看**单位价格买到的确定性**。
> 一包字段齐全、烘焙日期 5 天前的豆，比一包便宜三成但只写"中度烘焙"的豆，
> 往往是更省钱的选择——因为后者你可能要扔掉半包才发现不对。
