# 记录表

> 喝过不写下来就留不住。这里放**可复用的空表**，各章的实操直接链过来，不复制粘贴。
> 用法：复制表格到自己的笔记里填，或者打印出来放在手冲台边上。

| 表 | 什么时候用 | 需要器具 |
|----|----------|---------|
| [冲煮记录表](brew-log.md) | 每次冲煮（手冲 / 浸泡 / 意式）都填一行 | 🅐 无器具也能填一半 / 🅑 有秤和计时器才完整 |
| [杯测记录表（自拟）](cupping-sheet.md) | 同时对比 2 支以上的豆，或想把感受写成可比较的记录 | 🅐 用马克杯 + 勺子即可 / 🅑 有秤与固定粉水比更可比 |
| [豆袋核对清单](bag-checklist.md) | 买豆前 / 收到豆后，逐项核对标签给了哪些信息 | 🅐 无器具 |

## 为什么要填表

三个理由，都很实际：

1. **强迫你一次只动一个变量**。新手调咖啡是"感觉淡了就多放点粉、顺手把水温也提了"，
   结果这一杯变好变坏都无法归因。表格的第一功能是**锁住你没动的那些格子**。
2. **让你发现自己没记什么**。填不出来的格子，正是你的信息缺口——
   "研磨刻度"填不出来，说明你换过磨；"出液时间"填不出来，说明你没计时。
   这比"今天这杯不错"有信息量得多。
3. **形成可比较的记录**。喝过二十杯，回头翻表你会发现自己的偏好在漂移，
   这时候才谈得上"练出舌头"。

> **一条重要提醒**：这些表的输出是**观察记录**，不是**结论**。
> 记录写"入口偏尖、尾段发干，怀疑萃取不足或研磨过粗，下次只调细一档验证"是专业的；
> 写"这豆子不行"是不专业的——那需要先排除自己这一侧的所有变量。

## 一个关于杯测表的说明（重要）

本书提供的[杯测记录表](cupping-sheet.md)是**参考行业通行框架自拟的**，
**不是** SCA 官方杯测表，也不是 Coffee Value Assessment（CVA）表。

原因有两条：

1. **官方表有版权**，条文与分值版式不能复制到这里；
2. 官方表是为**校准过的评审在标准环境下给商业样打分**设计的，
   对自学者来说，很多格子在你有参照物之前填不出有意义的数字。

需要官方表格与协议时，请去 [SCA 官方网站](https://sca.coffee/) 获取现行版本
（第 34、35 章会讲怎么读它）。
