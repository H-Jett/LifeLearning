# 系统学咖啡：从一颗生豆到一杯咖啡

> 一本"边学边记"的咖啡入门书，深度对标 **SCA / CQI（Q-Grader）知识框架**：
> 风味化学 + 处理法与烘焙 + 萃取原理 + 杯测感官。
> 力求**正确**：数值标注出处、关键数字要两个独立来源，
> 流传的说法逐条标注证据强度，拿不准的地方明确写"有争议"而不含糊过去。

## 这本书的核心观点

> **咖啡的一切技术问题，本质都是同一件事——让哪些成分、以多少比例、进入这一杯。**

- **种植与处理**决定生豆里**有什么**；
- **烘焙**把前体物**改造成**呈味呈香物质；
- **冲煮**从熟豆里**选择性取出**这些物质；
- **杯测**是从感受**反向读出**成分格局；
- **选购与储存**决定你拿到的是不是你以为的那批分子。

所以这本书不从"记产区名字"开始，而是**先建立机理，再挂名字**。

## 怎么读这本书

- **正文**讲机理，配 Mermaid 机理图与对照表；关键数值都带出处
  （统一登记在[出处与资料登记](standards.md)）。
- **术语**首次出现处有脚注，全称与英文原词汇总在[术语表](glossary.md)——
  豆袋和协议多是英文，必须能对上。
- 每章有**「常见说法辨析」**栏目：把咖啡圈流传的说法逐条标注
  ✅ 有共识 / ⚠️ 有争议 / ❌ 明确错误 / 缺乏证据，并说明**它为什么流传**。
- 每章末有**思考题**（指向答案册，数量按内容而定，不固定几道），
  以及**本章实操**，分两档：
  - **🅐 无器具版**——不用买豆买器具，现在就能做（读豆袋、查官方资料、盲品）；
  - **🅑 有条件版**——需要秤/磨/温度计/滤杯等，标注"备齐后再做"并列清器具与替代方案。
- 每章末有 **🔎「买豆与冲煮时的用处」**：把原理翻译成一两句可执行的判断。

## 关于正确性的四条纪律

这本书没有 GPU 可以跑数据来自证，所以正确性靠纪律维持
（完整版见 [CLAUDE.md](https://github.com/H-Jett/LifeLearning/blob/main/books/coffee/CLAUDE.md) §1）：

1. **数值必须有出处**，并说明波动范围。关键数字要求**两个独立来源**；
   只有一个来源时标注"仅见于 X"；**查不到就不写死数字**，改写成规律或标"经验值"。
2. **区分事实 / 标准规定 / 行业惯例 / 圈内说法**四层，证据不足的一律辨析并标证据强度。
3. **价格只讲机制不写死数字**（C 价与零售价随时变，讲的是定价结构）。
4. **不做医疗 / 健康建议**——咖啡与健康只讲证据等级、只复述机构结论的原话与适用范围，
   不给摄入量建议、不做疗效或风险承诺。

两条补充的硬规矩：

- **不搬运他人实拍图**，也不内嵌外链图片；要图用 Mermaid 或文字判据，
  必要时正文给权威来源链接。
- **不复制 SCA 官方杯测表 / CVA 表的条文与分值版式**（有版权）。
  本书的[杯测记录表](forms/cupping-sheet.md)是**参考行业框架自拟**的。
