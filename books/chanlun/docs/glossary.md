# 术语表

每个词条前有显式锚点，正文用 `[术语](../../glossary.md#anchor)` 跳过来。
缠论术语的一个麻烦是：**原著用词、圈内简称、各家实现的叫法并存**，
所以每条都给「本书用词 + 原著用词 + 英文」三栏，读者看别处的材料时能对上。

## 走势与分类

<a id="zoushi"></a>
**走势**（原著：走势；英文 price action）
打开行情图看到的价格轨迹本身。原著的表述是"打开走势图看到的就是走势"——
这是一个**刻意不加修饰的起点**：不假设它由什么因素决定，只承认它是可观察的。
走势分级别（见 [级别](#jibie)）。

<a id="zoushi-leixing"></a>
**走势类型**（原著：走势类型；英文 price action type）
上涨、下跌、盘整三者之一。⚠️ 注意"走势"与"走势类型"不是一回事：
走势是看到的东西，走势类型是对它的分类结果，而且**只有"完成的"走势才能被定类型**。

<a id="panzheng"></a>
**盘整**（原著：缠中说禅盘整；英文 consolidation）
只包含**一个** [中枢](#zhongshu) 的完成走势类型。注意这是**按中枢个数**定义的，
不是按"看起来横着走"定义的——一段肉眼看着很陡的走势，只要只有一个中枢，就是盘整。

<a id="qushi"></a>
**趋势**（原著：缠中说禅趋势；英文 trend）
包含**两个及以上**依次同向、且**互不重叠**的同级别中枢的完成走势类型。
方向向上称上涨，向下称下跌。"不重叠"是硬条件，一旦重叠就不是趋势而是更大级别的中枢。

<a id="zoushi-zhong-wanmei"></a>
**走势终完美**（原著：走势终完美 / 基本原理一）
"任何级别的任何走势类型终要完成"。本书把它标为〔不可证伪〕并说明理由——
详见 [第 1 章](chapters/01-foundation/01-three-types.md) 与第 18 章。

## 几何层

<a id="baohan"></a>
**包含处理**（原著：包含关系处理；英文 K-line inclusion merging）
把存在包含关系的相邻 K 线合并成一根，再在合并后的序列上找分型。
它是几何层的第一步，也是**第一个引入人为约定的地方**（见第 6 章）。

<a id="fenxing"></a>
**分型**（原著：分型；英文 fractal）
连续三根（经包含处理后的）K 线构成的局部极值结构，分顶分型与底分型。
⚠️ 其严格定义不在本书掌握的第 1–48 课原文内，见 [出处登记](sources.md)。

<a id="bi"></a>
**笔**（原著：笔；英文 stroke）
由一个顶分型与一个底分型连成的最小方向段。先顶后底为向下一笔，先底后顶为向上一笔。

<a id="xianduan"></a>
**线段**（原著：线段；英文 segment）
由至少三笔构成、且满足特征序列条件的更高一层方向段。线段划分的"两种情况"
是各家程序化实现分歧最大的地方（见第 10 章）。

<a id="tezheng-xulie"></a>
**特征序列**（原著：特征序列；英文 characteristic sequence）
判断线段是否被破坏所用的辅助序列：以向上笔开始的线段，取其中所有向下笔构成序列，
反之亦然。

## 中枢

<a id="zhongshu"></a>
**中枢**（原著：缠中说禅走势中枢；英文 pivot / central zone）
某级别走势类型中，被至少三个连续次级别走势类型所重叠的那一段价格区间。
区间写作 `[ZD, ZG]`（记号见 [记号速查](notation.md)）。
这是整个理论的核心概念：走势类型、级别、背驰、买卖点全部建立在它之上。

<a id="zhongshu-yanshen"></a>
**中枢延伸**（原著：走势中枢的延伸）
中枢形成后，走势继续围绕它上下波动而不产生新的同级别中枢。

<a id="zhongshu-kuozhan"></a>
**中枢扩张**（原著：走势中枢的扩展 / 级别扩张）
围绕两个同级别中枢的波动区间发生重叠，从而产生一个**更高级别**的中枢。
这是级别提升的唯一通道（第 15 章）。

## 级别与分解

<a id="jibie"></a>
**级别**（原著：级别；英文 level）
走势类型的层级。理论上由中枢的递归定义产生，**不等同于 K 线周期**——
周期图只是级别的一种近似实现（第 3 章）。
⚠️ "抛开级别谈趋势与盘整毫无意义"是原著反复强调的一点。

<a id="duoyixing"></a>
**多义性**（原著：走势的多义性）
同一段走势按不同分解方式可以得到多种**都合法**的解释。
原著强调"多义性不是含糊性"，本书会说明这个区分成立在什么条件下、代价是什么（第 31 章）。

<a id="tongjibie-fenjie"></a>
**同级别分解**（原著：同级别分解）
把一段走势完全拆成同一级别的走势类型的连接，用来确定操作节奏。

## 力度与买卖点

<a id="beichi"></a>
**背驰**（原著：背驰 / 背弛；英文 divergence）
在一个趋势里，后一段同向走势的力度弱于前一段。
⚠️ **前提是趋势**——原著原话是"没有趋势，没有背驰"。盘整里的类似现象叫盘整背驰，
两者的技术含义不同（第 20、21 章）。

<a id="panzheng-beichi"></a>
**盘整背驰**（原著：盘整背弛）
围绕单个中枢的震荡中，离开中枢的那一段力度弱于前一段同向段。
它常常转化成第三类买卖点。

<a id="qujiantao"></a>
**区间套**（原著：借用数学分析的区间套）
从大级别的背驰段出发，在次级别中找出其中的背驰段，逐级收缩以精确定位转折区间。

<a id="maimaidian"></a>
**三类买卖点**（原著：第一 / 二 / 三类买卖点）
理论给出的三种结构性位置，记作 1B/1S、2B/2S、3B/3S。
⚠️ 本书使用这些记号**只为描述结构**，不对任何具体标的作买卖判断。

## 市场与数据

<a id="fuquan"></a>
**复权**（英文 adjusted price）
把除权除息造成的价格跳变还原掉，使价格序列在时间上可比。
**不复权的图上会凭空出现假缺口与假中枢**，是把缠论写成代码时踩到的第一个坑（第 2、4 章）。

<a id="chuquan"></a>
**除权除息**（英文 ex-rights / ex-dividend）
分红、送转、配股之后，价格按规则同比例下调。这个下调**不是交易造成的**，
在未复权序列上表现为一个巨大的跳空，会在几何层上制造假分型、假缺口、假中枢（第 2 章）。

<a id="jihe-jingjia"></a>
**集合竞价**（英文 call auction）
在某一时点对累积的申报做**一次批量撮合**，产生开盘价与收盘价。
⚠️ 它不是连续竞价中的某一笔成交，所以集合竞价时段内**不存在"走势"**。

<a id="yizi-ban"></a>
**一字板**（英文 limit-locked bar）
全天只在涨停价或跌停价一个价位成交的 K 线。
按中枢定义，这样的一天只构成**最低级别中枢的延伸**，
无论连续多少天都不足以形成更高级别的中枢（原著第 20 课）。
"时间长"与"级别大"是两回事。

<a id="tingpai"></a>
**停牌**（英文 trading halt）
交易暂停。原著第 26 课自己指出：本理论成立的前提是"交易能延续且算数"，
停牌、退市、交易作废会直接使前提失效。
