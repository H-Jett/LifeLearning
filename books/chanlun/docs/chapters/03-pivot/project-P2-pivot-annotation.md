# 🛠 项目 P2 · 给一段行情做完整的中枢标注

> 第三部分的收尾项目。交付一份**可以被别人复核**的分解——
> 这是本书对"做完了"的定义：不是"我看懂了"，而是"别人拿着我的材料能得到同样的结果"。

## 交付物

| # | 交付物 | 作用 |
|---|---|---|
| 1 | **约定清单**（第 11 章 16 项 + 第 13/14/15 章新增 3 项） | 让结果可复现 |
| 2 | **中枢标注表** | 每个中枢的区间、构成段、状态 |
| 3 | **中枢链与走势类型序列** | 延伸 / 扩张 / 趋势的判定结果 |
| 4 | **级别链** | 各层的中枢数与层数 |
| 5 | **歧义记录** | 判不准的地方，以及你选了什么 |

第 5 项最容易被跳过，但它是这个项目**最有价值**的产出——
它记录的是你的判据还不够硬的地方。

## 🅐 手工版

**需要**：第 12~17 章 🅐 档的全部记录、
[中枢标注表](../../forms/pivot-worksheet.md)、
[走势分解记录表](../../forms/decomposition-log.md)。

### 第一步：把约定写死

在动笔之前，先填这张表。**填完再标图**，不要边标边定规则。

| # | 约定 | 我的选择 |
|---|---|---|
| 1 | 复权方式 | |
| 3 | 包含处理初始方向 | |
| 4 | 是否处理"后包含前" | |
| 8 | 成笔间隔门槛 `g` | |
| 10 | 成笔失败处理 | |
| 15 | 中枢建在笔还是线段上 | |
| 17 | 中枢延伸段数上限 | |
| 18 | **判"不重叠"用 `[ZD,ZG]` 还是 `[DD,GG]`** | |
| 19 | 扩张后大中枢区间怎么算 | |

⚠️ 第 18 项是影响最大的一项——按第 14 章实测，
它能让趋势占比在 16.4% 和 95.7% 之间跳。

### 第二步：逐层标注

1. **几何层**：包含处理 → 分型 → 笔（第 6~8 章）；
2. **中枢层**：逐三段算 `[ZD, ZG]`，验证 `ZD ≤ ZG`（第 12 章）；
3. **延伸**：逐段判断是否仍触及 `[ZD, ZG]`，更新 `GG/DD`（第 13 章）；
4. **破坏**：离开 + 回抽不回来才算（第 16 章定理三）；
5. **去向**：按 `[DD, GG]` 判扩张还是新生（第 14、15 章）；
6. **走势类型**：按中枢个数分类（第 17 章）。

每一步都填进标注表。

### 第三步：自检

逐条打勾，任何一条不通过就回去改：

- [ ] 每个中枢都满足 `DD ≤ ZD ≤ ZG ≤ GG`？
- [ ] 每个中枢至少三段构成？
- [ ] 延伸时 `[ZD, ZG]` **没有**被改动？
- [ ] 判破坏时，回抽段**已经走完**？
- [ ] 相邻的走势类型**没有**出现"上涨 + 上涨"或"下跌 + 下跌"？
- [ ] 每个被判为"完成"的走势类型，都**至少含一个中枢**？（原理二）
- [ ] 全程只在**一个级别**上讨论？

### 第四步：和实测对照

把你的结果和本书的基线比：

| 指标 | 本书实测 | 你的 |
|---|---|---|
| 平均每中枢占用笔数 | 6.1 | |
| 中枢延伸到三段以上的比例 | 76.5% | |
| 中枢区间相对宽度（中位数） | 3.4% | |
| 相邻中枢走向扩张的比例 | 79.3% | |
| 走势类型中盘整的占比 | 84.0% | |

⚠️ 样本小的时候偏离是正常的。但如果**趋势占比远高于 16.4%**，
几乎可以断定第 18 项约定用错了（第 15 章 Q4）。

### 第五步：找人复核

把**约定清单 + 标注表**交给另一个人，让他按你的清单重做一遍。

- 结果一致 → 恭喜，你的分解是可复核的；
- 结果不一致 → **差异必然在约定清单里**（第 11 章 Q2 的〔推论〕）。
  逐项比对，找出是哪一项——**这一步才是整个项目的精华**。

## 🅑 代码版

**需要**：第 12~17 章实现的全套中枢与递归。
**先填[检验预登记表](../../forms/prereg-template.md)。**

### 第一步：把 19 项约定全部参数化

第 11 章已经要求过 16 项，这里补上第 17、18、19 项：

```text
pivot_config(
    max_extend      = ...,   # 17. 延伸段数上限（9 / None）
    overlap_on      = ...,   # 18. 判不重叠用 "ZG_ZD" 还是 "GG_DD"
    expand_interval = ...,   # 19. 扩张后区间："recompute" / "intersect" / "envelope"
)
```

### 第二步：跑全套自检断言

把第 11 章的 14 条，加上第三部分新增的这几条：

| 断言 | 出处 |
|---|---|
| `DD ≤ ZD ≤ ZG ≤ GG` | 第 12 章 |
| 中枢构成段数 ≥ 3 | 第 12 章 |
| 延伸后 `[ZD, ZG]` 不变 | 第 13 章 |
| 延伸后 `DD` 单调不增、`GG` 单调不减 | 第 13 章 |
| 中枢结局必属于 {延伸中, 破坏→扩张, 破坏→新生} | 第 16 章 |
| 每层对象数严格递减、递归必然终止 | 第 17 章 |
| 每个完成的走势类型至少含一个中枢 | 第 18 章（原理二） |
| 每个走势类型至少三段次级别 | 第 18 章（定理二） |
| 相邻走势类型不同向 | 第 1 章 |

**全部通过之后再往下。**

### 第三步：复现第三部分的全部实测

| 指标 | 本书实测 |
|---|---|
| 中枢数 / 平均笔数 | 336 / 6.1 |
| 构成段数分布 | 恰好 3 段 23.5%，≥9 段 11.9% |
| 区间相对宽度 | 中位数 3.4% |
| 相邻中枢三分类 | 扩张 79.3% / 趋势 16.4% / 更大中枢 4.3% |
| 走势类型分布 | 盘整 84.0% / 上涨 9.2% / 下跌 6.7% |
| 级别链 | 3~4 层，每层衰减到约 1/4 |

### 第四步：约定敏感性（本项目的核心）

仿照第 11 章的做法，对第 17、18、19 项各做一次单因子测试，
报告下面三个下游量的变化：

1. **中枢区间集合的重合率**（不是数量，是逐个对得上）；
2. **走势类型序列**的差异比例；
3. **级别链层数**。

然后回答一个问题：

> **第三部分新增的这三项约定，哪一项影响最大？
> 它和第 11 章测出的"成笔失败处理"（端点重合率 26.2%）相比如何？**

本书的预期是**第 18 项最大**（它能让趋势占比差近六倍），
但**没有测过它对中枢区间集合的影响**——这是留给你的。

### 第五步：交付

产出一份文档，包含：

- 19 项约定清单（全部填满）；
- 第三步的全部统计量；
- 第四步的敏感性结果；
- 样本范围、复权方式、数据快照的校验和（项目 P1 的交付卡）；
- **歧义记录**：实现中你不得不做选择、而原文没有写死的地方。

登记进[出处与资料](../../sources.md)第五节。

## 验收标准

- [ ] 19 项约定**全部**填写，没有"未定"？
- [ ] 全套自检断言通过？
- [ ] 统计量与本书基线的偏离，能**解释**吗？（不要求一致，要求能解释）
- [ ] 敏感性测试报告了**三个下游量**，不只是数量？
- [ ] 另一个人拿着你的清单，能重现你的结果吗？
- [ ] 歧义记录非空？（**如果为空，多半不是没有歧义，而是没找**）

## 常见的坑

| 坑 | 症状 | 出处 |
|---|---|---|
| 延伸时更新了 `[ZD, ZG]` | 中枢越延伸越窄，甚至自我否定 | 第 13 章 Q3 |
| 判不重叠用了 `[ZD, ZG]` | 趋势占比飙到 95% | 第 14、15 章 |
| 破坏只判"离开" | 中枢被切碎，延伸状态几乎消失 | 第 16 章 Q6 |
| 混用级别 | 走势类型里数不出中枢 | 第 18 章 Q6 |
| 边标边定规则 | 结果无法复现，也说不清自己用了什么 | 本项目第一步 |
