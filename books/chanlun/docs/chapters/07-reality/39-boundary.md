# 第 39 章 · 边界与天花板

> 全书最后一章。把前面 38 章的结论收拢成一个回答：
> **这套工具能做什么、不能做什么、以及为什么。**

## 39.1 它能做什么

〔推论〕**它提供了一套能对账的语言。**

第 1 章 1.1 节说过这套理论的野心：把"看图"变成一件**可以对账**的事。
经过六部分的实测，本书的判断是：**这个野心在定义层与推论层上基本实现了。**

具体产出三样：

**一、一组无歧义的概念。**
中枢、走势类型、级别、背驰、三类买卖点——
每一个都有形式化的定义，不含"我觉得""看起来像"。

**二、一组可以自动检查的结构性质。**

本书累计收获了 20 余条自检断言，**全部从定义推出**：

| 层 | 断言 |
|---|---|
| 包含处理 | 输出无包含、幂等、长度不增 |
| 分型 | 顶底严格交替、数量差 ≤ 1 |
| 笔 / 线段 | 方向严格交替、端点一顶一底、段数下界 |
| 中枢 | `DD ≤ ZD ≤ ZG ≤ GG`、延伸不改区间、去向穷尽 |
| 走势类型 | 完成必含中枢、至少三段次级别、相邻不同向 |
| 买卖点 | 完备性、一二类与一三类不重合 |
| 全局 | 增量结果 == 全量结果 |

〔推论〕**这些断言的价值不依赖理论是否"有效"**——
它们让你能验证**自己的实现有没有写对**，这本身就是实在的产出。

**三、一套讨论的纪律。**
声明级别、声明约定、区分定义与经验断言——
这套纪律让两个人的分歧可以被**定位**，而不是变成立场之争。

## 39.2 它不能做什么

〔推论〕**它不能给出关于收益的结论**——至少在本书的数据条件下不能。

原因不是理论有问题，而是**结构性的稀缺**：

```text
2053 笔 → 336 中枢 → 54 趋势对（16.4%）→ 8 个趋势背驰
```

〔推论〕**每一环都在收窄，而最终样本量落在个位数。**

而降级别换样本量，会同时遇到四堵墙：

| 墙 | 出处 |
|---|---|
| 数据可得性（分钟线深度、复权） | 第 4 章 |
| T+1（日内不可执行） | 第 36 章 |
| 成本占比（级别越低越高） | 第 37 章 |
| 约定敏感性（每降一级叠加一次） | 第 24 章 |

〔推论〕**这四堵墙不是可以绕过的技术细节，它们共同定义了这套工具的天花板。**

## 39.3 三个天花板

把前面的结论归纳成三条，它们是**结构性的**，不是当前实现的缺陷。

### 天花板一：滞后

每一层的判定都要等结构走完（第 16 章 16.4 节那条链）：

```text
分型 ← 第三根 K 线
笔   ← 终点分型 + 间隔条件
线段 ← 特征序列分型；第二种情况（39.6%）还要等反向确认
中枢 ← 前三段走完
破坏 ← 离开段 + 回抽段走完
背驰 ← c 段走完
```

〔推论〕**这套工具给出的是"已完成结构的分类"，不是"当下正在发生的判断"**
（第 30 章 30.2 节把它论证成了〔推论〕）。

**它不是一个可以改进的工程问题**——
滞后来自定义本身：判定一个结构需要这个结构存在，而存在需要走完。

### 天花板二：约定依赖

〔推论〕**分解结果是「价格序列 + 22 项约定」的函数**（第 11 章 Q2）。

实测的量级：

| 改动 | 后果 |
|---|---|
| 三项几何层约定 | 笔端点重合率低至 **17.3%** |
| 判不重叠的区间（第 18 项） | 趋势占比 16.4% ↔ **95.7%** |
| 力度度量（第 20 项） | 第一类买卖点 8 ↔ 31 |

〔推论〕**没有声明约定的缠论结论，无法被任何人复核**——
包括未来的你自己。

这同样不是可以消除的：约定来自原文留下的解释空间，
而"选哪一套"没有更高的裁判。本书的立场是
**标准统一优先于标准正确**（第 10 章 10.7 节）。

### 天花板三：样本稀缺

〔推论〕**大级别 = 小样本，这是递归结构的必然后果。**

第 17 章实测：级别链只有 3~4 层，各层中枢数约 `49 → 11 → 2`。

所以：

| 想要 | 代价 |
|---|---|
| 大级别（噪声小、成本占比低） | 样本个位数，**无法验证也无法积累经验** |
| 小级别（样本多） | 成本高、约定敏感、T+1 不可执行 |

〔推论〕**这个取舍没有最优解，只有适配你自己条件的选择**（第 29 章 29.4 节）。

## 39.4 合理的用法

基于以上，本书认为下面几种用法是**与这套工具的能力匹配**的：

| 用法 | 为什么匹配 |
|---|---|
| **作为记录与复盘的语言** | 定义无歧义，可对账；滞后不影响事后归档 |
| **作为实现的规范** | 20 余条自检断言可以自动检查 |
| **作为讨论的框架** | 让分歧可以被定位到具体约定 |
| **作为约束自己的纪律** | 选定级别后状态由结构确定（第 30 章） |

而下面几种用法**超出了它的能力**：

| 用法 | 为什么超出 |
|---|---|
| ❌ 实时预警 | 滞后是结构性的 |
| ❌ 预测方向或幅度 | 定义层不含收益信息；经验层未被检验 |
| ❌ 跨人比较"谁看得准" | 约定不同则结论不可比 |
| ❌ 作为收益的依据 | 见 39.2 节 |

## 39.5 合规与法律边界

最后交代本书从第 1 章就在守的那条线。

⚠️ 中国的证券投资咨询是**特许经营**。
监管对"非法荐股"的认定是三要件：
**无资质 + 提供证券投资分析/预测/建议 + 直接或间接获取利益**；
并且明确**"免责声明不构成抗辩"**——认定看行为实质。

〔推论〕**所以"加一句免责声明"并不能让一段荐股内容变得合规。**

本书全程的做法：

| 做法 | 对应 |
|---|---|
| 不出现任何标的的代码与名称 | `check_book.py` 强制拦截 6 位代码 |
| 不预测行情 | 全书无方向性判断 |
| 不收费、不引流、不设社群 | —— |
| 承诺性措辞只允许作为**被评注的原文**出现在引用块 | `check_book.py` 强制 |
| 每章带风险提示 | `check_book.py` 强制 |
| 实操两档都不要求真实下单 | 全书 39 章无例外 |

⚠️ 写作过程中，这套脚本**拦下了本书自己 5 处违规**（第 28 章转述原文时用到的一句极强措辞）——
这说明靠脚本比靠自觉可靠。

〔推论〕**如果你要基于本书的内容做任何公开分享，
请先确认自己是否触及那三个要件**，而不是依赖免责声明。

## 39.6 最后

这本书从第 1 章的一个问题开始：

> 两个人看同一张图，一个说上涨中继，一个说顶部结构，谁也说服不了谁。

走完 39 章之后，本书能给的回答是：

**它没有解决"谁对"的问题——它解决的是"怎么对账"的问题。**

〔推论〕**当两个人声明了相同的级别与相同的 22 项约定时，
他们对同一段走势会得到相同的分解。** 这是本书六部分实测反复验证的。

至于那个分解**能不能赚钱**——

> **在本书的数据条件下，答不了。**
> 不是无效，是**答不了**。要答它，需要更长的低级别历史、
> 更独立的样本、以及一次真正预登记的检验（项目 P5）。

〔推论〕**"答不了"是一个诚实的终点，而不是一个失败的终点。**

本书全书的纪律——给每条主张打标签、报比例必报基准与样本量、
测不了就明说——指向的正是这个终点。
一个从不足以支撑结论的数据里硬挤出结论的做法，
在这个领域里代价是实在的。

> **祝你在选定的级别上，按自己声明过的约定，
> 把每一次判断都记录成可以回看的样子。**

## 常见说法辨析

| 说法 | 证据强度 | 辨析 |
|---|---|---|
| "学完缠论就能稳定盈利" | ❌ 明确错误 | 定义层不含收益信息，经验层在本书条件下未被检验。而且"稳定盈利"这类表述本身就是合规红线 |
| "本书否定了缠论" | ❌ 明确错误 | 本书通篇处在"**无法检验**"状态（第 38 章 38.5 节），且对定义层与推论层的评价相当正面 |
| "既然有天花板，学它没用" | ❌ 明确错误 | 39.4 节列了四种匹配的用法。"不能做 A"不蕴含"什么都不能做" |
| "滞后可以靠优化算法解决" | ❌ 明确错误 | 滞后来自定义本身——判定结构需要结构走完（39.3 节）。这是结构性的，不是工程问题 |
| "加个免责声明就合规了" | ❌ 明确错误 | 监管口径明确"免责声明不构成抗辩"，认定看行为实质的三要件（39.5 节） |
| "约定问题可以通过统一标准解决" | ⚠️ 有争议 | 在**一个团队/一个实现内部**可以，而且应该（标准统一优先于标准正确）。但跨社区没有更高的裁判——所以"声明"比"统一"更现实 |

## 本章实操

两档都**不需要开户、不需要下单**。

### 🅐 手工版：写一份自己的边界声明

**需要**：全书 🅐 档的全部记录。

写一页纸，包含四部分：

**一、我的约定集。** 22 项，全部填满。

**二、我的级别选择与理由。** 为什么选这一级？
对照第 29 章 29.4 节的三条结构性考虑与第 34 章的资金期限约束。

**三、我能用这套工具做什么。** 从 39.4 节那张表里挑，
并写出你**具体**打算怎么用。

**四、我不用它做什么。** 同样从 39.4 节挑，
并写出为什么——用本书的实测数字支持。

⚠️ 第四部分最重要。**明确写下"我不用它做什么"，
比写下"我要用它做什么"更能防止越界。**

### 🅑 代码版：产出一份完整的可复现包

**需要**：全书 🅑 档的全部实现。

把它们打包成一个**别人能跑起来**的东西：

| 组件 | 内容 |
|---|---|
| **配置** | 22 项约定，显式、无硬编码 |
| **数据快照** | 带日期戳与校验和（项目 P1） |
| **实现** | 几何层 → 中枢 → 背驰 → 买卖点 |
| **自检套件** | 20 余条断言 + 增量/全量一致性 |
| **实测报告** | 复现本书各部分的统计，并标注偏离与原因 |
| **敏感性报告** | 至少第 10、18、20 项 |
| **边界声明** | 明写这套实现**不能**用来做什么 |

**验收标准只有一条**：

> **把这个包交给另一个人，他能得到和你逐行相同的结果吗？**

如果不能，缺的那一项就是你的实现里**没有被声明的约定**——
而那正是本书从第 6 章讲到第 39 章的同一件事。

## 🔎 最后五条

1. **声明级别，声明约定。** 没有这两样，任何缠论结论都无法被复核。
2. **报比例必报基准与样本量。** 这一条能筛掉一半的说法。
3. **区分结构与收益。** 前者可以从定义推出，后者必须检验。
4. **"答不了"是一个正当的结论。** 比硬挤出一个结论好得多。
5. **记录下来，包括你判错的和拿不准的。** 那些才是进步的材料。
