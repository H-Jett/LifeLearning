# 第 35 章 · 常见说法辨析总表

> 把全书各章「常见说法辨析」里的条目汇总成一张**可查的表**。
> 这一章不引入新内容，它是一个**索引**——
> 听到某个说法时翻到这里，找到它的证据强度与出处。

## 怎么用这张表

| 标记 | 含义 |
|---|---|
| ✅ | 有共识（在本书样本/推导上成立） |
| ⚠️ | 有争议，或本书未检验 / 缺乏证据 |
| ❌ | 明确错误 |

⚠️ 注意"**⚠️ 缺乏证据**"与"**❌ 明确错误**"的区别：
前者是"本书答不了"，后者是"可以指出它错在哪"。
把前者读成后者，是对本书立场的误读。

## 一张"听到就该警觉"的清单

把全书出现频率最高的几类错误提炼成五条。**听到任何一条，先追问。**

| # | 听到这类话 | 追问什么 |
|---|---|---|
| 1 | 任何不带**级别**的判断 | "在哪个级别上？怎么近似的？" |
| 2 | 任何**比例 / 胜率**数字 | "样本量多少？**基准是多少**？成本扣了吗？" |
| 3 | 用**幅度或时间**代替结构判据 | "跌了多少、延伸几段，和判据有什么关系？" |
| 4 | 从**结构**直接跳到**收益** | "这是〔推论〕还是〔经验断言〕？检验过吗？" |
| 5 | 用"**多义性**"化解分歧 | "相同约定 + 相同级别重跑，结果会一样吗？" |

〔推论〕**这五条覆盖了本书辨析表中绝大多数 ❌ 条目。**

## 本章实操

两档都**不需要开户、不需要下单**。

### 🅐 手工版：给一段真实材料做辨析

**需要**：任意一段缠论教程、视频文字稿或社群讨论（500 字以上）。

1. 逐句扫，把其中的**实质性主张**圈出来（通常 10~20 条）。
2. 对每一条，先查本表——**表里有吗**？
3. 表里有的，直接记下强度与出处。
4. 表里没有的，用第 1 章 1.7 节的流程打标签
   （〔定义〕〔推论〕〔经验断言〕〔不可证伪〕）。
5. 统计：这段材料里 ❌ 的比例是多少？
6. 最后用"五条警觉清单"再扫一遍，看有没有漏掉的。

⚠️ 注意第 5 步的结果**不代表材料的价值**——
一段材料可以有很多不严谨的表述，同时仍然把某个概念讲清楚了。
辨析的目的是**知道哪些能用、哪些不能当依据**，不是打分。

### 🅑 代码版：建一个可查的辨析库

**需要**：任意能存结构化数据的工具。

**第一步：把本表结构化**

```text
claim_id | 说法 | 强度 | 一句话 | 出处章节 | 错误类型
```

"错误类型"这一列自己归纳，建议的分类：

| 类型 | 例子 |
|---|---|
| 未声明级别 | "不用管级别，看日线就行" |
| 用幅度/时间代替结构 | "跌得太多了该结束了" |
| 结构 → 收益的跳跃 | "完备性证明了这套方法有效" |
| 记号误用 | "`ZG` 就是最高点" |
| 比例无基准 | "第三类买点胜率 66%" |
| 省略条件 | "小级别背驰可以引发大级别转折" |

**第二步：统计错误类型分布**

哪一类最多？这个分布本身就是一个有用的结论——
它告诉你**最该防的是哪种错误**。

**第三步：持续补充**

每遇到新说法就加一行。**这个库的价值随时间增长**，
而且它比死记硬背有用得多。

**第四步（选做）：做一个自查脚本**

对你自己写的判读记录，扫描是否出现下列模式：

```text
- 出现"级别"字样了吗？
- 出现比例数字时，附近有没有"基准""对照""样本量"？
- 出现"所以""说明"时，前后是结构还是收益？
```

这不是要自动判对错，而是**提示你回头检查**。

## 🔎 看盘时的用处

1. **五条警觉清单背下来。** 它覆盖了绝大多数常见错误。
2. **⚠️ 不等于 ❌。** "本书答不了"和"这是错的"是两回事。
3. **表里有一条 ✅。** 说明本书不是为批评而批评。
4. **辨析不是打分。** 目的是知道哪些能当依据用。
5. **自己建库并持续补充。** 比记住这一章有用。
