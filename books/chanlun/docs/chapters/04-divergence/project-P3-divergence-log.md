# 🛠 项目 P3 · 建立自己的背驰样本库

> 第四部分的收尾项目。这个项目的目标不是"找到背驰"，
> 而是**建立一个足够诚实的样本库**——包括那些**没通过判定**的候选。
>
> 本书第 20 章测出：11 年 7 个样本只有 8 个趋势背驰实例。
> 所以这个项目最重要的产出，很可能是**你亲手确认了样本量有多小**。

## 为什么要建样本库

第四部分反复遇到同一个问题：**样本量不够**。

| 对象 | 本书样本量 |
|---|---|
| 趋势背驰 | 8 |
| 趋势背驰的演化分类 | 9 |
| 盘整背驰 | 41 |

在这样的量级上，任何"胜率""准确度"都没有意义。
而个人判读积累起来的样本量只会更小。

〔推论〕**所以对个人而言，背驰样本库的价值不在统计，在于对账**：

- 看清自己平时把多少"疑似"当成了"确认"；
- 找出自己的判据最容易在哪一步松掉；
- 为第六部分的正式检验准备一批**规则先定**的样本。

## 交付物

| # | 交付物 | 作用 |
|---|---|---|
| 1 | 约定清单（22 项，见下） | 让判定可复现 |
| 2 | 判定记录（**含未通过的**） | 对账的原材料 |
| 3 | 漏斗统计 | 看清筛选发生在哪一层 |
| 4 | 演化跟踪记录 | 第 23 章三种演化的实例 |
| 5 | 样本量声明 | **放在报告第一行** |

第 2 项里的"含未通过的"是硬要求。**只记通过的，等于只记录了自己判对的那些。**

## 约定清单（22 项）

在开始之前**先填完**。前 16 项来自第 11 章，后 6 项是第三、四部分新增的。

| # | 约定 | 我的选择 | 出处 |
|---|---|---|---|
| 1–16 | 几何层全部约定 | | 第 11 章 11.5 节 |
| 17 | 中枢延伸段数上限 | | 第 13 章 |
| 18 | **判"不重叠"用 `[ZD,ZG]` 还是 `[DD,GG]`** | | 第 14 章 |
| 19 | 扩张后大中枢区间怎么算 | | 第 15 章 |
| 20 | 力度用什么度量（含 MACD 参数） | | 第 19 章 |
| 21 | 盘整背驰的"前一同向段"取哪一段 | | 第 21 章 |
| 22 | 区间套降到哪一级停止 | | 第 24 章 |

⚠️ **第 18 项影响最大**：它能让趋势占比在 16.4% 与 95.7% 之间跳，
直接决定你有多少背驰候选。

## 🅐 手工版

**需要**：[背驰记录表](../../forms/divergence-log.md)、行情软件。

### 第一步：定规则

填完上面的约定清单。**填完之后不许改**——
中途改规则会让整个样本库失去意义（这是第六部分"预登记"的预演）。

### 第二步：规则先定地选样本

⚠️ **不要**在图上翻找"看起来像背驰"的地方。那是事后挑选。

正确做法：**先定一个机械的扫描规则**，比如：

```text
选定 N 个标的（匿名编号）× 某个固定的历史区间
从左到右扫描，每遇到一对相邻中枢就记一行
```

这样得到的样本是**规则先定**的，才有对账价值。

### 第三步：逐行判定

对每一行，按第 20 章 20.3 节的四步走：

1. 是趋势吗？（注明用的哪个区间口径）
2. 两中枢同级别吗？
3. `c` 是次级别吗？
4. 比较力度。

**任何一步没通过，记下挡在第几步**——这一列是整个项目的核心数据。

### 第四步：漏斗统计

| 层 | 数量 | 相对上一层 | 本书对照 |
|---|---|---|---|
| 候选（相邻中枢对） | | —— | 329 |
| 通过前提一（是趋势） | | | 54（16.4%） |
| 通过全部三个前提 | | | 27 |
| 判为背驰 | | | 8（约 30%） |

### 第五步：演化跟踪

对判出的每一次背驰，按第 23 章跟踪它属于三种演化中的哪一种，
填进记录表的「演化跟踪」部分。

⚠️ **初判与最终结果不一致是正常的**（第 23 章 Q5：
原著自己说判别"不是绝对的"）。**把不一致记下来**，那是最有价值的部分。

### 第六步：诚实的结论

在报告第一行写样本量，然后写一句：

> "样本量 ⟨n⟩。⟨足够 / 不足以⟩ 支持关于有效性的推断。"

**如果 n < 30，第二个选项是唯一诚实的答案。**

## 🅑 代码版

**需要**：第 19~24 章实现的全套背驰判定。
**先填[检验预登记表](../../forms/prereg-template.md)。**

### 第一步：把 22 项约定全部参数化

到这一步，你的实现应该有一个完整的配置对象。
**任何硬编码的约定都要挑出来变成参数**——
这是做后续所有敏感性测试的前提。

### 第二步：跑全套自检断言

汇总前面各部分的断言（第 11 章 14 条 + 第三部分 9 条 + 第四部分）：

| 新增断言 | 依据 |
|---|---|
| 面积恒为非负 | 第 19 章 |
| 漏斗各层计数单调递减 | 第 20 章 |
| 每个背驰点被归入三种演化之一 | 第 23 章 |
| 情形 ② 之后的盘整，中枢级别 > 原中枢级别 | 第 23 章 |
| 区间套每层区间包含在上层内 | 第 24 章 |

**全部通过再往下。**

### 第三步：复现第四部分的全部实测

| 指标 | 本书实测 |
|---|---|
| 趋势对 / 可判定 / 趋势背驰 | 54 / 27 / 8 |
| 面积比中位数 | 2.05 |
| 面积比 < 1 的占比 | 30% |
| 盘整背驰候选 / 判出 | 332 / 41（12%） |
| 演化分布 | n = 9，不下结论 |

⚠️ 偏离本书的数字**不代表你错了**——你的约定不同，结果自然不同。
但**趋势对远多于 54** 几乎一定意味着第 18 项约定用错了。

### 第四步：三项敏感性测试

| 测什么 | 变量 | 报告 |
|---|---|---|
| 力度度量 | MACD 面积 / 幅度 / 斜率 | 判出数 + **位置重合率** |
| MACD 参数 | 至少三组 | 判出数 + 位置重合率 |
| 第 21 项 | 首个同向段 / 前一同向段 | 判出数 + 位置重合率，**按延伸段数分组** |

⚠️ 三项都**只报告，不选优**。在没有定义"效果"之前选参数就是数据窥探
（第六部分会讲透）。

### 第五步：为第六部分准备

这一步是 P3 与 P5 的接口。把你的样本库存成一个**冻结的数据集**：

```text
sample_id | 标的(匿名) | 时间 | 级别 | 挡在第几步 | 判定 | 演化 | 约定集哈希
```

**"约定集哈希"这一列很重要**——它让你日后能确认某一批样本
是用哪套约定生成的。改了约定，样本库要重新生成并换一个哈希。

### 第六步：登记

全部结果登记进[出处与资料](../../sources.md)第五节。

## 验收标准

- [ ] 22 项约定**全部**填写？
- [ ] 样本是**规则先定**选出来的，不是在图上挑的？
- [ ] 记录里**包含未通过判定的候选**？
- [ ] "挡在第几步"这一列有内容？
- [ ] 漏斗四层的数量都报了？
- [ ] 报告第一行写了**样本量**？
- [ ] 样本量 < 30 时，明确写了"不足以支持推断"？
- [ ] 敏感性测试报了**位置重合率**而不只是数量？

## 常见的坑

| 坑 | 症状 | 出处 |
|---|---|---|
| 在图上挑"像背驰"的地方 | 样本量看起来不小，但全是事后选的 | 本项目第二步 |
| 只记通过的判定 | 漏斗没法算，也看不出自己在哪一步松 | 本项目交付物 2 |
| 判不重叠用 `[ZD,ZG]` | 趋势对暴增，背驰候选虚高 | 第 14、15 章 |
| 把盘整背驰记成趋势背驰 | 趋势背驰数量远超 8 | 第 21 章 |
| 报比例不报样本量 | 结论无法被评估 | 第 20、23 章 |
| 中途改约定 | 样本库前后不一致，且无法察觉 | 本项目第一步 |
