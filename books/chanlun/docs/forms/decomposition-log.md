# 走势分解记录表

用来记录"我把这段走势分解成了什么"，以及**哪里我拿不准**。

配套章节：第 1 章（三分类）、第 17 章（走势类型与级别）、第 31 章（多义性）。

## 表头怎么填

- **样本标识**：一律**匿名化**。写"样本 A""样本 B"，或写成
  `板块-序号`（如 `制造-03`）。**不要填股票代码或名称**。
- **级别**：写你选定的分解级别（如 "L = 日线近似"）。级别一旦选定，
  整张表都在这一个级别上讨论——跨级别混填是这张表最常见的填错方式。
- **段类型**：上涨 / 下跌 / 盘整。⚠️ 只有**完成的**走势才填类型，
  还在进行中的写"未完成"。
- **判据**：写你是**凭什么**判成这个类型的。写"看起来像"不算判据，
  写"数到 2 个不重叠的同级别中枢"才算。
- **歧义**：这一列最重要。如果换一种分解方式也说得通，把另一种写下来。

## 分解自检

填完以后逐条对一遍，任何一条答"否"就回去改：

- [ ] 整张表**只在一个级别上**讨论？
- [ ] 每个"上涨 / 下跌"都真的数出了**两个及以上**同级别中枢，且它们**互不重叠**？
- [ ] 每个"盘整"都真的**只有一个**中枢？
- [ ] 相邻两段是否出现了"上涨 + 上涨"或"下跌 + 下跌"？
      如果有，说明分解错了——同向同级别的两段应该合并成一段，或者中间漏了一个中枢。
- [ ] 还在进行中的那一段，有没有被我不自觉地当成已完成？
- [ ] 「歧义」列是不是空的？**如果全空，多半不是没有歧义，而是没找。**
