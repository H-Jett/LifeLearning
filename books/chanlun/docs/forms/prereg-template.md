# 检验预登记表

**在跑数据之前**填完这张表，填完再动手。配套第六部分与项目 P5。

## 为什么要预登记

技术分析最常见的错误不是算错，是**先看数据、再定规则**。
在同一批数据上反复试不同的参数与规则，总能试出一条"有效"的——
这条规则的表现里，有多少是真规律、有多少是运气，事后无法分辨。

预登记的作用很朴素：**把"我打算怎么判"写死在看到结果之前**。
填完这张表你就失去了事后微调的余地，这正是它的价值。

## 一、假设

| 项 | 填写 |
|---|---|
| 要检验的命题（一句话） | |
| 它属于哪类命题 | 〔推论〕/〔经验断言〕（〔定义〕与〔不可证伪〕无法检验，别填） |
| 什么结果会**推翻**它 | |
| 我预期的结果 | （先写下来，跑完好对照自己的偏见） |

> ⚠️ 如果"什么结果会推翻它"这一栏填不出来，说明这条命题不可证伪，
> **不要检验，去第 1 章把它重新标一遍类**。

## 二、数据口径

## 三、规则

| 项 | 填写 |

| 判据的精确定义（可以直接翻译成代码） | |

| 一共试了多少组规则与参数 | （多重检验要用到这个数） |

| 项 | 填写 |
|---|---|
| 全部结果（不是最好的那个） | |
| 多重检验校正后的结论 | |

| 这次检验的局限 | |

> **报告纪律**：把**试过的全部规则的结果**写出来，不只写表现最好的那一条。
> 只报最好结果的检验，等于没做检验。
