# 中枢标注表

逐个中枢登记它的区间、构成段与状态。配套第 12–16 章与项目 P2。

记号含义见[记号速查](../notation.md)。这里只提醒一次最容易错的地方：
**`[ZD, ZG]` 由前三段确定，`GG / DD` 统计全部围绕波动**——两组不要混填。

**状态**填以下之一：

| 状态 | 含义 | 判据 |
|---|---|---|
| 形成 | 前三段已重叠，中枢刚成立 | 三段有共同重叠区间 |
| 延伸 | 继续围绕它波动，没有产生新的同级别中枢 | 离开与返回都是次级别以下 |
| 扩张 | 与相邻同级别中枢的波动区间重叠，升级成更大中枢 | 围绕两中枢的波动区间发生重叠 |
| 新生 | 产生了新的同级别中枢，且与本中枢不重叠 | 新中枢区间与本中枢无任何重叠 |
| 破坏 | 次级别走势离开后，回抽不再回到区间内 | 回抽的极值未进入 `[ZD, ZG]` |
| 未定 | 还在进行中 | —— |

## 自检

- [ ] 每个中枢的构成段都是**次级别的完成走势类型**，不是随手圈的一段？
- [ ] `ZD ≤ ZG`？如果算出 `ZD > ZG`，说明这三段根本没有共同重叠区间，**不构成中枢**。
- [ ] `DD ≤ ZD` 且 `ZG ≤ GG`？（区间必然被围绕波动包住，否则填错了）
- [ ] 判"趋势"之前，检查了相邻同级别中枢**完全不重叠**（含瞬间波动）？
- [ ] 「歧义」列非空？
