# 背驰记录表

用来记录一次背驰判定的**全过程**，重点是记录**在哪一步被挡住**。

配套第 19–24 章与项目 P3。

## 为什么要记"被挡住的"

按第 20 章实测，候选结构里只有约 16% 能通过全部三个前提。
也就是说，**大部分记录都会是"没通过"**——而那才是最有价值的部分：

- 它让你看清自己平时把多少"疑似背驰"当成了真背驰；
- 它告诉你自己的判据在哪一步最容易松。

**只记成功的判定，等于只记录了自己判对的那些。**

## 判定记录

一次判定填一行。⚠️ 样本标识一律匿名化（"样本 A""制造-03"），

**填写说明**：

- **级别口径**：写"以 X 周期近似"或"笔中枢 L1"等（第 3 章）；
- **① 是趋势？** 注明判"不重叠"用的是 `[DD, GG]` 还是 `[ZD, ZG]`
  （约定清单第 18 项，影响极大）；
- **④ 面积比**：注明力度度量方式与参数（约定清单第 20 项）；
- **结论**：趋势背驰 / 盘整背驰 / 都不是；
- **挡在第几步**：没通过时**必填**。

## 演化跟踪

判为背驰之后，跟踪它的演化（第 23 章的三种）。

| # | 对应上表第几行 | 回抽是否触及 `B` 的 `[DD,GG]` | 回抽是否进入 `B` 的 `[ZD,ZG]` | 判定的演化类型 | 备注 |
|---|---|---|---|---|---|
| | | | | | |

**三种演化**（第 23 章）：

| 类型 | 判据 |
|---|---|
| ① 最后一个中枢的级别扩展（最弱） | 回抽仅触及 `B` 的外围，未进入区间 |
| ② 该级别更大级别的盘整 | 回抽重新进入 `B` 的区间 |
| ③ 该级别以上级别的反趋势 | 回抽一路回到 `A` |
