# 记录表

可复用的表格集中放在这里，各章**链接**过来，不复制粘贴。
表格的作用是把"我看出来了"变成"我记下来了，下次能对账"——
判读能力的进步几乎全部来自回看自己当时的记录。

| 表 | 用途 | 配套章节 |
|---|---|---|
| [走势分解记录表](decomposition-log.md) | 记一段走势的分解结果与产生歧义的地方 | 第 1、17、31 章 |
| [中枢标注表](pivot-worksheet.md) | 逐个中枢登记区间、构成段、生住坏灭状态 | 第 12–16 章、项目 P2 |
| [检验预登记表](prereg-template.md) | **动手跑数据之前**先把规则与口径写死 | 第六部分、项目 P5 |

## 怎么用

1. **先填再看答案**。所有表都设计成"当下填写"，不是事后补记。
2. **把不确定写下来**。表里都留了「歧义 / 不确定」列——那一列才是最有价值的，
   它记录的是你的判据还不够硬的地方。
3. **不要填入买卖计划**。这些表是**观察记录**，不是交易计划。
   本书的实操两档都不要求真实下单。
