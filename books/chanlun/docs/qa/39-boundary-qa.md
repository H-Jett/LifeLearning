# 第 39 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · 三样产出

**答**：

**一、一组无歧义的概念。**
中枢、走势类型、级别、背驰、三类买卖点——
每一个都有形式化定义，不含"我觉得""看起来像"。

**二、一组可以自动检查的结构性质。**
全书累计 20 余条自检断言，**全部从定义推出、全部 O(n)**：

| 层 | 例子 |
|---|---|
| 包含处理 | 输出无包含、幂等、长度不增 |
| 分型 | 顶底严格交替 |
| 笔 / 线段 | 方向严格交替、端点一顶一底 |
| 中枢 | `DD ≤ ZD ≤ ZG ≤ GG`、去向穷尽 |
| 走势类型 | 完成必含中枢、至少三段次级别 |
| 买卖点 | 完备性、一二类与一三类不重合 |
| 全局 | 增量结果 == 全量结果 |

〔推论〕**这些断言的价值不依赖理论是否"有效"**——
它们让你能验证**自己的实现写对了没有**。

**三、一套讨论的纪律。**
声明级别、声明约定、区分定义与经验断言——
让分歧可以被**定位到具体哪一项**，而不是变成立场之争。

**共同点**：三样都属于**定义层与推论层**，
所以它们的价值**不依赖经验断言层被检验**。

<a id="q2"></a>
## Q2 · 三个天花板

**答**：

| # | 天花板 | 为什么是结构性的 |
|---|---|---|
| 一 | **滞后** | 判定一个结构需要这个结构**存在**，而存在需要**走完**。这来自定义本身 |
| 二 | **约定依赖** | 约定来自原文留下的解释空间，而"选哪一套"**没有更高的裁判** |
| 三 | **样本稀缺** | 大级别 = 小样本，是**递归结构的必然后果**（每层衰减到约 1/4） |

**为什么不是工程问题**：

**天花板一（滞后）**：

不是"算法不够快"。即便算力无限，
你也必须等第三根 K 线才能确认分型、
等回抽走完才能确认中枢破坏——
**信息在那个时点上根本不存在**。

〔推论〕**优化算法能减少计算时间，但减少不了"等结构走完"的时间。**

**天花板二（约定依赖）**：

不是"标准还没统一"。原文在多处没有写死
（第 6 章四项、第 8 章失败处理、第 10 章第 4/7 步），
而本书对第 62 课之后无原文。
在这种情况下，**任何"正确标准"的主张都缺乏依据**——
所以本书的立场是"标准统一优先于标准正确"。

**天花板三（样本稀缺）**：

不是"数据还不够多"。级别链的每一层对象数衰减到约 1/4
（实测 49 → 11 → 2），所以要让高层样本量翻两番，
需要**指数级**增长的历史数据（第 17 章 Q2：多一层约需 44 年日线）。

〔推论〕**三个天花板分别来自定义、来自文本、来自结构——
没有一个可以靠更好的工程实现突破。**

<a id="q3"></a>
## Q3 · 为什么免责声明不能让荐股合规

**答**：因为监管认定看的是**行为实质的三要件**，而不是页面上写了什么。

**三要件**：

```text
① 无资质（未经批准从事证券投资咨询业务）
② 提供证券投资分析、预测或建议
③ 直接或间接获取经济利益
```

**免责声明属于什么**：它是一段**声明**，
而三要件描述的是**行为**。声明改变不了行为的性质。

打个比方：在一份实质上是投资建议的材料末尾写"本文不构成投资建议"，
就像在一份实质上是合同的文件上写"本文件不是合同"——
**文件的性质由它的内容决定，不由它对自己的描述决定。**

**监管口径对此是明确的**："免责声明不构成抗辩"。

**本书的做法**（39.5 节）：

不是靠声明，而是**从行为上避开要件 ②**：

| 做法 | 避开了什么 |
|---|---|
| 不出现任何标的的代码与名称（脚本强制拦截） | 无法构成对具体标的的分析 |
| 不预测行情 | 无"预测" |
| 不给操作建议，实操两档都不要求真实下单 | 无"建议" |
| 承诺性措辞只允许作为被评注的原文出现在引用块（脚本强制） | 无收益暗示 |
| 不收费、不引流、不设社群 | 同时避开要件 ③ |

〔推论〕**合规靠的是"内容里没有那些东西"，不是"声明里说没有"。**

⚠️ 值得一提的是：本书的合规脚本在写作过程中
**拦下了本书自己 5 处违规**（第 28 章转述原文时用到的一句极强措辞）。
这说明**靠脚本比靠自觉可靠**——人写着写着就会松。

<a id="q4"></a>
## Q4 ·【标签】"答不了"是什么结论状态

**答**：它是一个**正当的、完整的结论状态**，与"检验后无效"性质不同。

| | 无法检验 | 检验后无效 |
|---|---|---|
| 证据状态 | **没有证据**（正反都没有） | 有**否定性**证据 |
| 能据此否定吗 | **不能** | 能 |
| 下一步该做什么 | 说明需要什么条件才能答；去创造那些条件 | 停止使用该主张 |
| 本书的状态 | **通篇如此** | 无 |

**为什么"答不了"是完整的结论**：

因为它**回答了一个真实的问题**——"以现有证据能得出什么？"
答案是"不能得出关于有效性的结论"，这本身是一个信息。

而且它带着**可操作的后续**：38.5 节与 39.2 节都说明了
要答它需要什么（更长的低级别历史、更独立的样本、一次真正预登记的检验）。

〔推论〕**一个说明了"为什么答不了"和"怎样才能答"的结论，
比一个从不足数据里硬挤出来的结论有用得多。**

**两种误读的代价**：

| 误读 | 代价 |
|---|---|
| 把"答不了"读成"无效" | 以为问题已解决，不再去做那个检验 |
| 把"答不了"读成"有效" | 在没有证据的情况下使用它 |

本书在第 21、28、33、38 章反复强调这个区分，
就是因为**两个方向的误读都会发生**。

## Q5 · "怎么对账"为什么也有价值

**答**：

**两个问题的区别**：

| | "谁对" | "怎么对账" |
|---|---|---|
| 问的是 | 哪个判断符合未来的事实 | 两个人能不能得到**相同的分解** |
| 需要什么 | 预测能力 | **共同的定义与约定** |
| 本书的结论 | 答不了（第 38、39 章） | **基本做到了**（六部分实测） |

**为什么前者也有价值**——三条：

**一、它把争论变成了可定位的分歧。**

在没有共同定义时，"这是上涨还是顶部"是一个立场之争，
双方各说各话、无法收敛。

有了共同定义与约定清单之后，同样的分歧变成：
"我们的第 18 项约定不同"——**一个可以查、可以统一的技术问题**。

〔推论〕**能被定位的分歧，就有解决的路径；
不能被定位的分歧，只能变成立场。**

**二、它让记录变得有意义。**

第 30 章说过：判读能力的进步几乎全部来自回看自己当时的记录。
但**只有当记录是按固定口径写下的**，回看才有意义——
否则你不知道当时的"我觉得"是怎么来的。

**三、它是检验的前提。**

项目 P5 要检验一个策略，前提是这个策略是**一个确定的函数**
（P4 的要求）。而"确定的函数"正是"能对账"的另一种说法。

〔推论〕**没有对账能力，连"这个方法有没有用"这个问题都问不出来**——
因为你说的"这个方法"本身就不确定。

**所以**：

> 对账能力不是"退而求其次"的安慰奖，
> 它是**任何关于有效性的讨论能够开始**的前提条件。

<a id="q6"></a>
## Q6 ·【查证】别人能复现你的结论吗

**答**：开放题。**几乎所有人的答案都会是"不能"，而缺的那一项很可能是同一样。**

**怎么检验**：

把你的记录（或代码 + 报告）交给另一个人，让他**不问你任何问题**，
只按材料重做一遍。然后比对结果。

**最常缺的几项**（按出现频率）：

| 缺什么 | 症状 | 出处 |
|---|---|---|
| **约定清单不完整** | 对方要问"你这里怎么处理的" | 第 11 章 11.5 节 |
| **没写级别口径** | 对方不知道在哪一层上做 | 第 3 章 |
| **数据快照没冻结** | 对方拿到的数据和你的不同 | 项目 P1 |
| **"成笔失败怎么办"没说** | 影响最大的那一项，最少被声明 | 第 11 章 11.2 节 |
| **中途改过规则** | 前后记录不一致，而且你自己没察觉 | 第 29 章 Q4 |

〔推论〕**如果对方需要问你任何问题才能复现，
那么缺的就是你没有声明的那项约定。**

**这道题的用意**：

它是把全书从第 6 章到第 39 章讲的同一件事，
变成一次**你自己能做的检验**：

```text
第 6 章： 几何层的输出是「价格序列 + 约定集」的函数
第 11 章：22 项约定清单
第 31 章：判别问句——相同约定重跑会一样吗
第 39 章：把你的材料交给别人，他能复现吗
```

四处说的都是同一件事，只是越来越具体。

**加分项**：

- 把对方问你的每一个问题**记录下来**——
  那张问题列表就是你的约定清单的缺口清单；
- 补完之后**再试一次**，看这次需要问几个问题；
- 如果两次都能复现，恭喜——你的分解**是可对账的**，
  而这正是第 1 章 1.1 节提出的那个目标。
