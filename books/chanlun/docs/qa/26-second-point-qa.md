# 第 26 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · 一类与二类的依据不同

**答**：

| | 第一类 | 第二类 |
|---|---|---|
| 依据 | **力度比较**（趋势背驰） | **结构计数**（分解定理二） |
| 保证来自 | `c` 段力度弱于 `a` 段 | 走势类型至少三段次级别，所以后面**还必须有第三段** |
| 需要的前提 | 背驰三前提（第 20 章） | 第一类已成立 + 能分辨次级别 |
| 实测数量（本书） | 8（MACD 口径） | 与第一类同量级 |

**关键区别**：

- 第一类问的是"**还推得动吗**"——这是一个关于力度的**经验性**判断，
  需要度量、需要参数（第 19 章）；
- 第二类问的是"**够三段了吗**"——这是一个**计数**，
  由分解定理二这条〔推论〕直接保证。

〔推论〕**所以第二类的"安全性"在定义体系内部比第一类更硬**——
它只依赖一条从定义推出的定理，不依赖任何力度度量。

⚠️ 但这个"更硬"只在**定义体系内部**成立。
实践中它依赖"第一类已经判对"和"能正确分辨次级别"，
而这两者都带着大量约定。

<a id="q2"></a>
## Q2 · 会不会无限递归，以及代价

**答**：**不会**，因为级别有最低层；但实现上**继承下一层的全部约定不确定性**。

**为什么不会无限递归**：

归结链是 `L 级第二类 → L−1 级第一类`。
如果 `L−1` 级的那个点又是第二类，则继续归结到 `L−2` 级……

但这个链条必然终止，因为**级别有最低层**
（第 3 章 3.1 节的〔推论〕：递归良定义当且仅当存在最低级别）。
递归到最低级别时，第一类由该级别的背驰直接给出，不再往下归。

本书实测（第 17 章）：从日线笔中枢起算，级别链只有 **3~4 层**——
所以这个归结链最多也就三四步。

**实现上的代价**：

要验证"本级别第二类 = 次级别第一类"，必须**在次级别上重做一遍**：

```text
次级别的几何层（16 项约定）
  → 次级别的中枢（第 17/18/19 项约定）
    → 次级别的背驰（第 20 项约定）
      → 次级别的第一类买卖点
```

〔推论〕**每降一级，约定的影响叠加一次**——
这与第 24 章区间套的限制二是同一个问题。

**具体后果**：

- 匹配率**不会是 100%**；
- 层数越多，偏差越大；
- 两个人用不同约定去做同一个归结，**越往下分歧越大**。

**所以**：买卖点定律在理论上很优雅（三类归一），
但**优雅不等于实现上更稳**。本书 🅑 档要求报告**匹配率**而不是
"是否成立"，原因就在这里。

<a id="q3"></a>
## Q3 · "某级别"三个字为什么重要

**答**：因为原著特意排除了"就是次级别"这个更强的读法，而误读会导致判错。

**原著的说明**（第 17 课，转述）：这个级别**不一定是次级别**，
因为次级别里也可以是第二类买卖点；而且还存在**不同级别同时出现买卖点**
的共振情形。

**读成"次级别"会产生什么问题**：

**一、在次级别找不到就误判为"转折不成立"。**
如果实际的第一类买卖点出现在次次级别（因为次级别那一层是第二类），
只看次级别的人会找不到，进而否定一个真实的转折。

**二、忽略共振。**
不同级别同时出现买卖点是原著明确提到的情形。
固定只看一层，会把共振当成普通信号，低估了它的结构含义。

**三、把"存在性陈述"当成了"构造性陈述"。**
"任何下跌转折都由**某级别**的第一类买点构成"是一个**存在性**断言——
它保证存在这样一个级别，但**不告诉你是哪一层**。
读成"次级别"等于凭空给了它一个构造方法。

**正确的用法**：

> 看到转折 ⟹ 知道**存在某一层**上有第一类买卖点 ⟹
> **需要逐层去找**（这正是区间套做的事，第 24 章）。

〔推论〕**趋势转折定律其实是区间套方法的理论依据之一**——
正因为"某级别"不确定是哪一层，才需要逐级收缩去定位。

<a id="q4"></a>
## Q4 ·【标签】"中枢下方的第二类买点力度值得怀疑"

**答**：〔经验断言〕，本书未检验。但它的**结构逻辑**可以理解。

**为什么是〔经验断言〕**：

"力度值得怀疑""可能性极大"都是关于后续市场行为的倾向性判断，
从定义推不出来。而且要检验它，还得先定义"力度"和"可能性"怎么测。

**结构逻辑**（这部分是可以讲清楚的）：

第二类买点的位置，反映了**第一段上涨走了多远**：

```text
第二类买点在中枢下方  ⟹  第一段上涨连中枢都没回到  ⟹  走得很弱
第二类买点在中枢上方  ⟹  第一段上涨已经站上中枢    ⟹  走得较强
```

而"能否在原中枢之上形成一个**不重叠**的新中枢"决定了是趋势（新生）
还是扩张（第 14、15 章）。位置越低，越难拉开到不重叠，
所以越可能是扩张。

**与实测的方向一致**：

第 15 章测出**扩张占 79.3%、趋势仅 16.4%**——
也就是说"走不了那么高"是常态。
这和"位置低 ⟹ 更可能扩张"的方向吻合。

⚠️ 但方向吻合**不等于验证了原著的比例判断**
（"可能性极大""机会对半"这些具体的量）。本章 🅑 档第四步就是去测它。

<a id="q5"></a>
## Q5 · 为什么一类与三类不可能重合

**答**：因为它们**必然分处中枢的两侧**。

**位置关系**（第 21 课，转述）：

| 类型 | 与最近中枢的位置 | 为什么 |
|---|---|---|
| **第一类买点** | 中枢**下方** | 它是下跌走势类型的完成点，出现在趋势最后一个中枢被跌破之后 |
| **第三类买点** | 中枢**上方** | 它的定义就是"向上离开中枢后回试**不跌破** `ZG`"（第 27 章） |

一个在下、一个在上，**不可能是同一个位置**。

**原著给的更完整的分类**（第 21 课，转述）：

- **一类与二类**：前后出现（二类必在一类之后），所以不重合；
- **一类与三类**：分处中枢上下，所以不重合；
- **二类与三类**：**可能重合**——这是唯一可能重合的一对。

**重合的条件**（26.5 节）：第一类之后，一个次级别走势**凌厉地直接上破**
前面下跌的最后一个中枢，然后在其上的次级别回抽**不触及该中枢**。
此时这个点既是"第一类之后的第一次次级别回调低点"（第二类），
又是"离开中枢后回试不回中枢"（第三类）。

**实用价值**：

这三条是很好的**结构自检**：

> 如果你的实现输出了"第一类与第三类在同一位置"，
> **一定是判定有误**——去查中枢的位置关系。

<a id="q6"></a>
## Q6 ·【查证】位置分类与后续演化

**答**：实操题。这是一次对〔经验断言〕的**正式检验**，要按纪律来。

**必须做到的四条**：

1. **规则先定**：在跑之前把"下方/之中/上方"的判据写死
   （用 `[ZD, ZG]` 还是 `[DD, GG]` 判位置？这本身就是一个约定）；
2. **报告全部结果**：三个位置 × 两种演化，六个格子全报，
   不只报支持原著的那几个；
3. **写明样本量**：每个格子的 n 是多少；
4. **写明约定集**：22 项。

**要报的表**：

| 第二类买点位置 | n | 其后扩张 | 其后新生（趋势） |
|---|---|---|---|
| 中枢下方 | | | |
| 中枢之中 | | | |
| 中枢上方 | | | |

**与原著对照**：

| 位置 | 原著的倾向性判断 |
|---|---|
| 下方 | 扩张可能性**极大** |
| 之中 | 扩张与新生**对半** |
| 上方 | 新生机会**很大** |

**预期的困难**（这才是本题真正要教的）：

**一、样本量可能不够。** 第一类买卖点本身只有 8~31 个（第 25 章），
第二类与之同量级，再按三个位置分组，**每组可能只有个位数**。

**二、基准问题。** 即便"上方"组的新生比例更高，
也要和**整体基准**比——第 15 章实测整体扩张占 79.3%。
如果"上方"组是 70% 扩张，那它其实仍然以扩张为主，
只是比基准略低。**没有基准的比较没有意义**（第 27 章会详细讲这一点）。

**三、不能事后调整分组。** 如果你发现"下方/之中"合并起来更显著，
**不能合并**——那是数据窥探（第六部分）。

**一个合格的结论**：

"在 ⟨样本、约定⟩ 下，三组的 n 分别为 ⟨…⟩，扩张比例分别为 ⟨…⟩，
整体基准为 79.3%。样本量 ⟨不足 / 足够⟩ 支持对原著倾向性判断的评价。"
