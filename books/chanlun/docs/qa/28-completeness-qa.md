# 第 28 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · 拆成两个主张

**答**：

| # | 主张 | 标签 |
|---|---|---|
| **A** | **分类完备性**：结构性的买卖位置只有三类，没有第四类 | 〔推论〕 |
| **B** | **赢利性**：这三类买卖点都能赢利 | 〔经验断言〕 |

**为什么必须拆开**：

**一、验证方式完全不同。**

- A 由定义决定：买卖点必然与最近中枢发生位置关系，而中枢只有三种去向。
  **不需要任何数据**；
- B 需要数据：要定义收益、扣成本、做预登记、处理样本相关性。

**二、成立与否互不影响。**

A 成立而 B 不成立是完全可能的：分类可以是完备的，
但这些位置未必能在扣除成本后盈利。

**三、混为一谈会产生一个具体的逻辑跳跃**：

> "完备性被严格证明了" ⟹ "所以这些买卖点是有效的"

这个跳跃把一个**关于分类的定理**当成了**关于收益的证据**。
这是缠圈最常见的一个推理错误。

**四、它们失败时该做的事也不同**（第 1 章 Q4 的纪律）：

- A 测出违例 → **改实现**；
- B 测出不成立 → 那就是事实，理论的这一半被推翻了。

<a id="q2"></a>
## Q2 · 完备性论证的关键一步

**答**：关键一步是——**所有买卖点都必然对应着与最近那个中枢的位置关系**。

**为什么这一步是关键**：

它把一个**看似开放的问题**（"买卖点可能有多少种？"）
转化成了一个**封闭的枚举**（"相对于一个中枢，买卖点能在哪里？"）。

**论证的完整链条**：

1. 走势中任何一点都面临两种可能：**延续或转折**；
2. 买点要么是"上升中的延续"，要么是"由下往上的转折"；
3. 延续只能发生在上升过程中，而上升中的延续**前面必然有一个中枢**；
4. 转折的前一段只能是下跌或盘整，而两者之前**也必然有中枢**
   （原理二：完成的走势类型必含中枢）；
5. ⟹ **无论哪种情况，买卖点都对应着某个中枢**；
6. 而中枢只有三种去向：**延伸、扩张、新生**（第 16 章的穷尽性）；
7. 逐一分析位置：
   - 中枢**上方**的买点：延伸时不可能有（延伸要求中枢上的走势都转折向下），
     所以只能来自扩张或新生 → **第三类**；
   - 中枢**下方**的买点：只能出现在下跌确立之后 → **第一类**；
   - 第二类与第一类紧密相连。

**所以第 5 步是枢纽**：它让第 6 步的"三种去向"能够被用来穷举买卖点。

〔推论〕**完备性的力量来自中枢去向的穷尽性**（第 16 章 16.3 节那张流程图）。
两者是同一个结构的两次使用。

<a id="q3"></a>
## Q3 ·【判读】"完备性被证明所以安全"

**答**：跳跃在于**把 A 的成立当成了 B 的证据**。

**拆开他的推理**：

```text
前提：完备性（A）已被严格证明
结论：按三类买卖点操作是安全的（涉及 B）
```

中间缺了一整步：**A 与 B 是独立的主张**（Q1）。

**具体缺什么**：

| 缺口 | 说明 |
|---|---|
| "赢利"未定义 | 赢多少？持有多久？扣成本了吗？ |
| 成本未计 | 中枢宽度中位数只有 3.4%（第 12 章），成本占比不可忽略 |
| 样本量 | 第一类买卖点 11 年 7 样本只有 8~31 个（第 25 章） |
| 未预登记 | 第 27 章那个 66% 是探索的结果，不是检验的结果 |
| 执行约束 | T+1、涨跌停、停牌（第七部分） |

**另一处更微妙的跳跃**："安全"这个词。

原著那句极强的措辞（见第 28 章 28.5 节的引用），准确含义是**在定义体系内部无歧义**
（28.5 节），而他读成了**市场上无风险**。

这是两个不同的"安全"：

| | 定义体系内 | 真实市场上 |
|---|---|---|
| 保证什么 | 第三类买点之后必是扩张或新生 | 不保证价格怎么走 |
| 类比 | 三角形内角和 180 度 | 拿尺子量真实三角形 |

**正确的表述**：

"分类完备性在定义体系内成立（〔推论〕）。
至于这三类位置在扣除成本后是否具有正期望，
属于〔经验断言〕，需要按 ⟨预登记 + 样本外 + 多重检验⟩ 的流程检验。"

<a id="q4"></a>
## Q4 · "被理论保证"的准确含义

**答**：**在定义体系内部自洽**，不是"在真实市场上会盈利"。

**类比**（28.5 节）：

> 欧几里得几何**保证**"三角形内角和为 180 度"。
> 但它**不保证**你拿尺子量一个真实的三角形能得到 180 度——
> 因为真实空间未必是欧氏的，尺子也有误差。

**对应到缠论**：

| 层面 | 保证什么 | 不保证什么 |
|---|---|---|
| **定义体系内** | 第三类买点之后必是扩张或新生（〔推论〕） | —— |
| **真实市场上** | —— | 扩张之后价格怎么走；涨幅是否覆盖成本；能否成交 |

**为什么这个区分特别重要**：

因为原著用的措辞极强（第 28 章 28.5 节引用了原文）。
这些措辞如果被读成关于市场的断言，会产生非常危险的预期。

**一个佐证**：原著自己在具体情形上是留有余地的。
第 26 章 26.5 节提到，讨论二三类重合时，
作者明确写过"理论上没有任何必然的理由"确定重合之后
一定不会只构成更大级别的中枢扩张。

〔推论〕**作者本人在"体系内的必然"与"市场上的必然"之间是有区分的**，
只是流传中强措辞被保留、限定被丢掉了——
这正是本书要逐条标注证据强度的原因。

<a id="q5"></a>
## Q5 · 完备性的边界

**答**：它只在**缠论自己的框架内**完备——不排除框架之外的其他交易依据。

**展开**：

完备性论证的每一步都用到了缠论的概念：
中枢、走势类型、级别、延伸/扩张/新生。
所以它证明的是：

> **在"用中枢结构描述走势"这个框架内，结构性的买卖位置只有三类。**

**它不排除什么**：

| 框架外的依据 | 为什么不受完备性约束 |
|---|---|
| 基本面 | 完全不在价格序列的描述范围内 |
| 其他技术流派 | 用的是别的结构描述（波浪、形态、量价） |
| 统计套利、事件驱动等 | 依据的是完全不同的原理 |
| 甚至缠论框架内的**非结构性**机会 | 比如利用制度性摩擦（第七部分） |

〔推论〕**完备性是一个"相对于某个描述框架"的性质，不是绝对性质。**

**这个边界的实际意义**：

**一、别用完备性去否定别的方法。**
"缠论已经完备了，所以别的都是多余的"——这是对完备性的越界使用。

**二、别用它证明缠论覆盖了一切机会。**
它说的是"在这个框架内没有第四类"，不是"没有别的赚钱方式"。

**三、它仍然是一个好用的自检。**
在**你自己的缠论实现内部**，输出的买卖点应当能归入三类——
归不了类就是判定有误。这个用法不越界。

<a id="q6"></a>
## Q6 ·【查证】完备性断言

**答**：实操题。**有违例时按下面的顺序查。**

**断言**：每个输出的买卖点都能被归入三类之一。

**违例时的排查顺序**：

**一、查它与最近中枢的位置关系（最常见）。**

完备性论证的枢纽是"买卖点必然对应某个中枢"（Q2 第 5 步）。
如果归不了类，最可能是：

- 该点附近**没有识别出中枢**（中枢识别漏了）；
- 或者"最近的中枢"选错了（比如选了时间上更远的那个）。

**二、查中枢的去向分类是否完整。**

第 16 章 16.3 节要求每个中枢的结局必属于
{延伸中, 破坏→扩张, 破坏→新生}。
如果某个中枢的去向是"未分类"，那么它上方/下方的买卖点自然也归不了类。

**三、查级别是否混用。**

买卖点在 L 级别，对应的中枢也必须在 L 级别。
用 L−1 的中枢去判 L 的买卖点，位置关系会错乱。

**四、查是不是二三类重合被误处理了。**

重合是合法的（第 21 课），但如果实现把重合的点
既不归入二类也不归入三类，就会产生"未分类"。
**正确做法是标记为"二类 & 三类"，而不是丢弃。**

**⚠️ 唯一不该做的**：加一个 `else: return "其他类"` 把违例吸收掉。
完备性是〔推论〕，违例必然是实现问题（第 1 章 Q4 的纪律）。
加 `else` 会把 bug 永久埋进去，而且从此检测不到。

**加分项**：

- 同时加上三条互斥性断言（一类&二类、一类&三类不重合；
  二类&三类重合时满足 26.5 节条件）；
- 把违例的样本**导出来单独看**，而不只是计数——
  违例往往集中在某一类结构上，那本身就是诊断信息；
- 把这四条断言加入回归测试，每次改约定后重跑。
