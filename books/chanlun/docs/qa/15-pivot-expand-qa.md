# 第 15 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · 为什么扩张是唯一通道

**答**：因为延伸和新生**按定义**都不产生新的更高级别对象。

**延伸为什么不升级**：
延伸的充要条件是"离开与返回中枢的走势类型都是次级别以下的"（第 18 课定理二）。
既然全程没有出现同级别的走势类型离开，那么就**没有产生任何新的同级别中枢**；
没有第二个同级别中枢，就无从谈"两个中枢合成更大的中枢"。
整段走势始终只有一个中枢——按走势类型的定义，它就是一个**盘整**，级别不变。

**新生（趋势）为什么不升级**：
新生产生了第二个同级别中枢，但前提是它与原中枢**完全不重叠**（含围绕波动）。
既然连触须都不碰，两个中枢就没有任何"合成"的接触面，
它们只是**同一级别上先后排列**的两个对象。
整段走势是一个同级别的趋势，级别同样不变。

**扩张为什么升级**：
扩张的定义就是"围绕两个同级别中枢的波动区间发生重叠"。
有了这个接触面，两个中枢加上它们之间的连接段，
在**更高一层**上恰好构成"三个连续次级别对象的重叠"——
这正是中枢的定义。于是一个 L+1 级别的中枢诞生了。

**所以**：三条路里只有扩张创造了"更高一层的重叠"，
这是原著第 20 课定理二用"**当且仅当**"的原因。

<a id="q2"></a>
## Q2 ·【标签】走势级别延续定理二

**答**：〔推论〕。

**判别**：

1. 它在规定词义吗？不是——"中枢""级别"都已在别处定义。
2. 能从定义推出来吗？**能**。见本章 Q1：
   - 必要性：不重叠 ⟹ 无接触面 ⟹ 高一层上构不成三段重叠 ⟹ 不产生更大中枢；
   - 充分性：重叠 ⟹ 高一层上三个连续对象有共同重叠区间 ⟹ 按中枢定义产生更大中枢。
3. 什么观测会推翻它？没有——它的真假只取决于定义。

**它是"当且仅当"这一点很重要**：

充要条件意味着你可以**双向使用**它：

- 看到波动区间重叠 → 断定级别会提升；
- 看到级别提升了 → 断定此前必然发生过波动区间重叠。

后一个方向在排错时特别有用：如果你的实现输出了一个 L+1 中枢，
但回查发现两个 L 中枢的 `[DD, GG]` 并不重叠，
那**一定是实现错了**，而不是"特殊情况"。

<a id="q3"></a>
## Q3 · 为什么级别链不会无限升高

**答**：因为**每升一级，参与比较的对象数量都会衰减**，级别链的高度是对数式的。

**机制**：

在 L 级别上有 `n` 个中枢。其中约八成的相邻对走向扩张，
每次扩张会把**两个（或更多）L 级中枢连同连接段**合成**一个** L+1 级中枢。

所以 L+1 级别上的中枢数量，大致是 L 级别的一个**分数**——
粗略地说每升一级数量减少到原来的三分之一左右
（因为一个高级中枢至少要吃掉三个次级别对象）。

于是：

```text
L0:  n 个
L1:  约 n/3
L2:  约 n/9
⋯
Lk:  约 n/3^k
```

当 `n/3^k < 3` 时就构不成新的中枢，递归终止。
所以层数大约是 `log₃(n)` 量级——**对数增长，不是线性增长**。

**用本书的数字感受一下**：336 个日线笔中枢，
按每层除以 3 估算：336 → 112 → 37 → 12 → 4 → 1，
大约 **5 层**就到顶了。

**所以两件事不矛盾**：

| 说法 | 说的是什么 |
|---|---|
| "八成走向扩张" | **同一层内部**，相邻中枢的关系分布 |
| "级别链只有有限层" | **层与层之间**，对象数量的衰减 |

前者描述横向，后者描述纵向。

**（加分）**：这也从机制上解释了原著第 27 课那句"站在最大的级别看，
所有股票都只有一个中枢"——不断向上合成，最终必然收敛到一个。

<a id="q4"></a>
## Q4 ·【判读】"趋势占 94%"

**答**：**第一判断——他用错了判重叠的区间**，即用 `[ZD, ZG]` 代替了 `[DD, GG]`。

**依据**：

本书实测，宽松口径下"不重叠"的比例是 `79.3% + 16.4% = 95.7%`。
94% 与这个特征值非常接近，而与严格口径的 16.4% 相差近六倍。

**验证方法**（从快到慢）：

**一、看代码里判重叠的那一行**（最快）。
找到判断两个中枢是否重叠的地方，看它比较的是 `ZD/ZG` 还是 `DD/GG`。
一行就能确认。

**二、抽样对照**。随便取一对被判为"趋势"的相邻中枢，
把四个数 `ZD / ZG / DD / GG` 都打出来，手工判一遍。
如果 `[DD, GG]` 明明重叠却被判成趋势，问题确认。

**三、跑双口径对比**。按本章 🅑 档第三步，两种口径各跑一次，
看趋势占比是不是在 16% 和 96% 之间跳。

**四、排除其他可能**（如果上面三步都没问题）：

- **`GG/DD` 算错了**：比如延伸时没更新，或遍历范围不对
  （第 12 章 Q2 列过排查项）；
- **中枢划分本身有问题**：中枢太少太短，导致 `[DD, GG]` 异常窄；
- **级别太高**：在很高的级别上中枢数很少，样本量小，比例不稳定。

**为什么这个自查值得做**：用错区间**不会报错**，
输出的结构完全自洽，只是把约八成的盘整读成了趋势（15.5 节）。
"趋势占比"是一个成本极低、灵敏度很高的体检指标。

<a id="q5"></a>
## Q5 · 大中枢区间该怎么算

**答**：按定义，在**高一层**上重新套用标准公式；
简化做法要声明，因为三者不等价。

### 按定义怎么算

中枢的定义是"三个连续**次级别走势类型**的重叠"。
在扩张的场景里，L+1 级别的"次级别对象"是 L 级别的走势类型——
也就是 `X（中枢1）`、`连接段`、`Y（中枢2）` 这些东西。

所以：

```text
1. 把这些 L 级对象各自的高低点取出来
2. ZG(L+1) = min(三个对象的高点)
3. ZD(L+1) = max(三个对象的低点)
```

注意每个"对象"的高低点是它覆盖范围内的**极值**（即含围绕波动），
而不是它的 `[ZD, ZG]`。

### 为什么不等于交集或并集

- **交集** `[max(X.ZD, Y.ZD), min(X.ZG, Y.ZG)]`：
  只用了两个中枢的**核心区间**，完全忽略了连接段，
  也忽略了围绕波动——而扩张恰恰是由围绕波动的重叠触发的。
  这个算法在逻辑上和触发条件**不一致**。
- **并集 / 包络** `[min(X.DD, Y.DD), max(X.GG, Y.GG)]`：
  把两个中枢的全部波动都包进去，得到的区间**远宽于**按定义算出的中枢。
  中枢应当是"重叠"的结果，而包络是"合并"的结果，方向相反。

按定义算出的区间通常**介于两者之间**，但不必然等于任何一个。

### 为什么简化要声明

因为 `[ZD, ZG]` 是**所有上层判据的参照**：

```text
大中枢的 [ZD, ZG]
  → 判断它是否被破坏（第 16 章）
  → 判断第三类买卖点（第 27 章）
  → 再往上一层的扩张判定
```

区间取宽了，中枢更难被破坏、第三类买卖点更少；
取窄了，反过来。**这是一个系统性的偏移，不是随机误差**。

所以它属于必须声明的约定（第 19 项）。

<a id="q6"></a>
## Q6 ·【查证】三种区间算法的影响

**答**：实操题。**三个量都要报。**

**合格答案必须包含**：

1. 三种算法（按定义重算 / 取交 / 取包络）下的**级别链层数**；
2. 各级别的**中枢总数**；
3. **最高级别中枢的区间**（把三个区间并排写出来）；
4. 样本范围、复权方式、几何层约定、第 17/18 项约定的取值。

**预期会看到的现象**：

| 算法 | 大中枢区间 | 中枢更难/更易被破坏 | 级别链 |
|---|---|---|---|
| 取包络 | 最宽 | 最难被破坏 | 通常**最深**（中枢存活久，有更多机会扩张） |
| 按定义重算 | 居中 | 居中 | 居中 |
| 取交 | 最窄 | 最易被破坏 | 通常**最浅** |

**加分项**：

- 报告三种算法下**第三类买卖点数量**的差异（第 27 章会用到）——
  这能把"区间宽窄"的影响翻译成一个下游的可观察量；
- 注意到差异随级别升高而**放大**（每层的偏移会累积），
  所以在最高级别上三者的区间可能差得很远；
- 在约定清单补上第 19 项。

**典型不合格答案**：

- 只报层数不报区间 → 看不出偏移的方向和幅度；
- 断言某种算法"正确" → 只有"按定义重算"与定义一致，
  但另两种作为**声明过的简化**是可接受的（第 11 章 11.6 节的立场）。
