# 第 19 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · `a+A+b+B+c` 五个部分

**答**：

| 记号 | 是什么 |
|---|---|
| `a` | 进入第一个中枢的那一段 |
| `A` | 第一个中枢 |
| `b` | 连接两个中枢的那一段 |
| `B` | 第二个中枢（与 `A` **同级别**） |
| `c` | 离开第二个中枢的那一段 |

**背驰比较的是 `c` 段与 `a` 段**——注意不是 `c` 与 `b`。

**为什么是 `a` 与 `c`**：它们是这个趋势里**方向相同**的两段
（`b` 是连接段，方向与趋势一致但夹在两个中枢之间，角色不同）。
背驰要问的是"这个趋势的推进能力衰减了吗"，
所以要比较**同一趋势里两次同向推进**的力度。

**（加分）** 按第 14 章的定理一，`b` 必然是**次级别以下**的；
而第 19.1 节第 3 条要求 `c` 是次级别的。
`a`、`c` 与 `b` 在结构中的角色不同，这也是不拿 `b` 去比的原因。

<a id="q2"></a>
## Q2 ·【标签】"力度是比较量"

**答**：〔推论〕。

**判别**：能从力度的定义方式直接推出。
无论用均线面积、MACD 面积还是幅度，得到的都是一个**依赖价格绝对水平、
波动率与参数**的数值——它没有归一化，也没有基准单位。
一个没有基准的数值只能和**同样口径下的另一个数值**比较，
不能单独解读。

**它的实用价值**：这条〔推论〕给了一把尺子，
可以立刻判断一句关于力度的话**合法不合法**：

> 只要句子里的"力度"没有明确的比较对象，且比较对象不在同一个
> `a+A+b+B+c` 结构内，这句话就越界了。

<a id="q3"></a>
## Q3 · 为什么跨标的比较力度没意义

**答**：至少三条理由。

**一、量纲不同。** MACD 的数值单位是价格单位。
一只 10 元的标的和一只 300 元的标的，
同样幅度的波动算出的柱体面积**相差一个数量级以上**。

**二、波动率不同。** 即便做了价格归一化，
不同标的的典型波动幅度差异很大。
"面积大"可能只是因为它本来就波动大，与推进能力无关。

**三、结构不可比。** 更根本的一条：
背驰的定义是**在同一个 `a+A+b+B+c` 结构内部**，
比较两段同向推进。两只标的的结构是两个独立的结构——
**它们之间不存在"同一个趋势"这个共同前提**，
所以连比较的语境都不存在。

**（加分）四、参数敏感。** 如果用 MACD，
12/26/9 这组参数对不同波动特征的标的适配程度不同，
会引入系统性偏差。

> **一句话**：力度不是标的的属性，是**结构内部两段之间的关系**。
> 问"哪只标的力度强"，等于问"这个房间的左边比那个房间的右边更左吗"。

<a id="q4"></a>
## Q4 · 不确定性放在哪一层

**答**：

| 度量 | 不确定性在哪 | 具体是什么 |
|---|---|---|
| **MACD 面积** | **参数层** | 12/26/9 是人定的；换参数，柱体面积与背驰判定都会变 |
| **中枢结构** | **级别判定层** | 需要先判准 `c` 段与 `B` 的级别关系，而级别带着第三部分那一串约定（延伸上限、判重叠的区间、扩张后区间算法，第 17 章 17.5 节） |

**为什么说"不是哪个更准的问题"**：

两种做法都**无法消除**不确定性，只是把它挪了个位置。

- 用 MACD：你要声明参数，并承认结论依赖参数；
- 用中枢结构：你要声明第 13~15 章那三项约定 + 第 11 章那 16 项，
  并承认结论依赖它们。

后者与定义一致，所以在**理论上**更正当；
但它依赖的约定更多，**实践中未必更稳**。

**本书的处理**：把度量方式列为约定清单第 20 项，要求声明。
这与全书的立场一致——**不追求消除选择，追求让选择可见**（第 11 章 11.6 节）。

<a id="q5"></a>
## Q5 ·【判读】"这次背驰比上次严重，所以跌得更深"

**答**：至少**三处**越界。

**一、跨结构比较力度。**
"这次背驰"和"上次那次"分属两个不同的 `a+A+b+B+c` 结构。
按 19.3 节，力度比较只在**同一结构内部**有意义。
两次背驰各自是各自结构内的相对判断，**彼此之间没有可比性**。

**二、把"背驰"当成了程度量。**
背驰在定义上是一个**布尔判定**：`Area(c) < Area(a)` 成立或不成立。
它没有"严重程度"这个维度。
说"更严重"是在给一个二值判定强加一个连续刻度。

**三、从背驰推幅度。**
背驰的定义只说明**当前结构的推进能力在衰减**。
按第 23 章（背驰—转折定理），它之后有三种演化，
其中最弱的一种只触及最后一个中枢的外围——**几乎没有幅度可言**。
所以从"背驰"推不出"跌多深"。

**（加分）四、没说级别。**
不同级别的背驰，后续演化的级别也不同（第 23 章）。
不说级别，"跌得更深"没有参照。

**正确的表述**：
"在 ⟨某级别⟩ 上，当前 `a+A+b+B+c` 结构中 `c` 段力度弱于 `a` 段，构成背驰。
按背驰—转折定理，其后有三种可能的演化，需要观察回抽是否重新触及 `B`
才能分辨（第 23 章）。"

<a id="q6"></a>
## Q6 ·【查证】三种度量的差异

**答**：实操题。**报数量差异，也报重合率。**

**合格答案必须包含**：

1. 三种度量（MACD 面积 / 价格幅度 / 斜率）下被判为背驰的结构数；
2. **三者判定结果的两两重合率**（不只是数量）；
3. 样本量（本书是 27，你的很可能也在几十的量级）；
4. MACD 参数、样本范围、几何层与中枢层的约定。

**预期会看到的现象**：

- **数量会差不少**。幅度法忽略时间，斜率法对短段极敏感，
  三者的筛选倾向不同；
- **重合率可能不高**。这才是关键——数量接近不代表判的是同一批结构；
- **样本量太小，差异不稳定**。换一批样本，排序可能就变了。

**最重要的一条报告纪律**：

⚠️ **不要去找"哪种度量效果最好"**。
在没有定义"效果"（预测什么？评价指标是什么？）之前，
这个问题没有意义；而在这么小的样本上做选择，**必然是数据窥探**
（第六部分会专门讲）。

正确的结论形式是：
"在 ⟨样本⟩ 上，三种度量分别判出 ⟨N₁/N₂/N₃⟩ 个背驰，
两两重合率 ⟨…⟩；样本量 ⟨n⟩ 不足以判断优劣。"

> 市场有风险，任何据此产生的后果由读者自负。
