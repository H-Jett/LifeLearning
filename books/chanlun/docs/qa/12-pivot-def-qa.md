# 第 12 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · 为什么是三段不是两段

**答**：两条理由。

**一、两段形不成"中心"。**
中枢要表达的是"价格在某个区间里**来回**"。两段只说明有交集，
描述不了来回——来回至少需要"去、回、再去"三段。
两段重叠的情形太普遍，把它叫中枢，这个概念就失去了区分力。

**二、与分解定理二一致。**
任何走势类型至少由三段次级别走势类型构成（第 1 章 1.6 节）。
中枢是走势类型的内核，用三段起步与整个体系的下界一致。
如果中枢只要两段，就会出现"中枢比它所属的走势类型还要求低"的别扭情形。

**补充（加分）**：三段还带来一个实用后果——
由于笔与线段方向必然交替（第 8、9 章），三段必然是"同、反、同"的结构，
于是中枢区间可以简化为由**首尾两段**（同向的那两段）决定（12.3 节）。
两段就没有这个结构。

<a id="q2"></a>
## Q2 ·【标签】四个不等式

**答**：〔推论〕。算出 `GG < ZG` 说明**实现错了**，不是数据特殊。

**推导**：

- `ZG = min(g1, g2)`，而 `GG = max(gn)` 遍历全部段。
  前两段也在"全部段"里，所以 `GG ≥ max(g1, g2) ≥ min(g1, g2) = ZG`。
- 同理 `DD = min(dn) ≤ min(d1, d2) ≤ max(d1, d2) = ZD`。
- 而 `ZD ≤ ZG` 是中枢成立的条件本身。

三条串起来即 `DD ≤ ZD ≤ ZG ≤ GG`。∎

**`GG < ZG` 时该查什么**（按可能性排序）：

1. **`GG` 的遍历范围错了**——只算了部分段，或者漏掉了延伸进来的段；
2. **`ZG` 用了全部段而不是前两段**（见本章 Q6）——这会让 `ZG` 变小或变大，
   打乱不等式；
3. **`gn` 取的是错误的段**——`Zn` 应当是**与中枢形成方向一致**的那些段，
   取成了全部段或反向段；
4. **延伸时更新了 `ZG`**——`[ZD, ZG]` 由前三段确定后**不应再改变**（12.1 节〔推论〕），
   如果延伸时把它一起更新了，各种不等式都会乱。

第 4 条最隐蔽，也最常见。

<a id="q3"></a>
## Q3 · 两组记号各管什么

**答**：

> **`[ZD, ZG]` 管"中枢有没有被破坏"；`GG/DD` 管"两个中枢会不会合成更大的中枢"。**

**用 `[ZD, ZG]` 去判扩张会犯什么错**：

会**系统性地把本该扩张的情形判成趋势**。

机制：扩张的条件是**围绕两个中枢的波动区间**发生重叠，
而波动区间是 `[DD, GG]`，它**包含**并且通常**远宽于** `[ZD, ZG]`。

所以存在大量这样的情形：

```text
两个中枢的 [ZD, ZG] 不重叠     → 用 ZD/ZG 判：不重叠 ⟹ 判成趋势 ❌
但 [DD, GG] 重叠               → 正确判定：扩张 ✅
```

**这个误判有多常见**：按第 14、15 章的实测，
相邻中枢里"区间不叠但围绕波动叠"的占 **79.3%**，
而"完全不叠"的只有 16.4%。

也就是说：**用错记号会把约八成的扩张误判成趋势**。

后果是级联的：趋势判错 → 走势类型错 → 背驰的前提（必须是趋势）失效 →
买卖点全错。这就是为什么本章要把这两组记号单独拎出来讲。

<a id="q4"></a>
## Q4 ·【判读】"一直在横盘，所以是一个大中枢"

**答**：跳过了三个必要步骤。

1. **没有说级别。** 中枢必须在某个级别上讨论（第 3 章）。
   "横盘"在日线上看和在 30 分钟上看是不同的对象。
   不说级别，"一个大中枢"没有指称。

2. **没有数段。** 中枢由**三段次级别走势类型的重叠**确定。
   他是从"形态看着横"直接跳到结论，没有：
   - 划出次级别的笔或线段；
   - 取连续三段算 `ZG`、`ZD`；
   - 验证 `ZD ≤ ZG`。

   横盘形态完全可能三段不重叠（比如逐级下台阶的横向整理），那就不构成中枢。

3. **没有区分"一个中枢"和"多个中枢"。**
   一段长时间的横向区域，可能是**一个中枢在延伸**（第 13 章），
   也可能是**多个中枢先后新生**（第 14 章），还可能是**中枢扩张**（第 15 章）。
   三者的技术含义完全不同——第一种意味着级别没升，第三种意味着级别升了。
   仅凭"一直在横盘"无法分辨。

**正确的表述**：
"在以 ⟨X⟩ 近似的级别上，这段走势由 ⟨N⟩ 笔构成，
其中第 ⟨i⟩ 到第 ⟨j⟩ 笔构成一个中枢，区间 `[ZD, ZG] = ⟨…⟩`，
之后 ⟨延伸 / 新生 / 扩张⟩。"

<a id="q5"></a>
## Q5 · 中枢内"高抛低吸"要考虑什么

**答**：本题只要求列出因素，不要求结论。至少应想到下面四条。

**一、幅度与成本的比例。**
实测中枢区间宽度中位数只有 **3.4%**。而一次完整的买卖要承担
佣金（双边）、印花税（卖出）、以及买卖价差与冲击成本。
这几项加起来占 3.4% 的多大比例，是第一个要算的数——第 37 章会算。

**二、判定的滞后。**
`[ZD, ZG]` 由**前三段**确定，也就是说**中枢被确认时，前三段已经走完了**。
而中枢跨度中位数 28 根合并 K 线、约一个半月。
所以"知道这里是中枢"的时刻，已经错过了一部分区间。

**三、T+1 与方向限制。**
中枢内的完整来回包含"跌到下沿买、涨到上沿卖"和反向两段，
而只能做多的账户只能做其中一半，且当日买入次日才能卖（第 2 章 2.4 节）。

**四、中枢随时可能被破坏。**
按定义，中枢**随时可以结束**（第 13 章）。所谓"在区间内高抛低吸"，
隐含假设了区间会继续存在——而这个假设没有任何保证。
被破坏时，本以为的"低吸"位置会变成趋势的中途。

**（加分）五、样本内的宽度分散很大。**
中位数 3.4%，但 90 分位是 7.3%。用中位数去做统一的操作计划，
会在窄中枢上系统性亏损。

⚠️ 再说一次：本题只要求**指出要考虑的因素**。
本书不给任何操作建议，也不评价这种做法可行与否。

<a id="q6"></a>
## Q6 ·【查证】`ZG` 用前两段还是全部段

**答**：本题重点是定位到那一行代码并判断后果。

**合格答案必须包含**：出处、那一行（或几行）代码、判断结果。

**怎么找**：搜 `ZG`、`zg`、`min(` 附近的中枢构造函数。
关键是看 `min` 遍历的是**三段（或前两段）**还是**中枢覆盖的全部段**。

**如果是"全部段"，会导致什么**（这是本题的重点）：

1. **`ZG` 会随延伸不断变小、`ZD` 不断变大**，于是中枢区间**越延伸越窄**。
   而按定义，`[ZD, ZG]` 由前三段确定后**不应再改变**（12.1 节）。
2. **中枢可能"自己把自己否定掉"**：延伸到某一段时，
   新算出的 `ZD` 超过了 `ZG`，代码会认为中枢不成立——
   但它明明已经成立了。实现里通常表现为中枢突然消失或抛异常。
3. **破坏判定失真**：判断"离开后回抽有没有回到中枢内"用的是 `[ZD, ZG]`。
   区间被越缩越窄，会让**回抽更容易被判成没回到中枢**，
   于是中枢被过早判为破坏，第三类买卖点被过度识别（第 27 章）。
4. **四个不等式会被违反**：`GG ≥ ZG` 仍成立，但 `ZG` 的语义已经变了——
   它不再是"上沿"，而变成了某种"全段最窄重叠"。

**加分项**：

- 注意到有些实现用"全部段"其实是**有意为之**（想要一个更保守的核心区间），
  但**没有声明**——按第 11 章的立场，问题在于没声明；
- 构造一段有长延伸的数据，对比两种算法的 `ZG`，把差异量化。
