# 第 35 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · ⚠️ 与 ❌ 的区别

**答**：

| 标记 | 含义 | 本书的处理 |
|---|---|---|
| **⚠️ 缺乏证据** | **本书答不了**——样本量不够、数据拿不到、或需要先定义某些东西 | 说明为什么答不了，以及要答它需要什么 |
| **❌ 明确错误** | **可以指出它错在哪**——与定义矛盾、与实测矛盾、或推理有跳跃 | 指出具体错在哪一步 |

**例子**：

**⚠️ 缺乏证据**：

> "用盘整背驰找大底很可靠"（第 21 章）

本书未检验，而且说明了原因：大级别中枢只有个位数，
**在可得数据上测不了**。这不是说它不对，是说**答不了**。

**❌ 明确错误**：

> "第一类买点就是最低点"（第 25 章）

可以指出错在哪：第一类买点的定义是**走势类型的完成点**，
与价格极值是两个不同的对象。而且第 13 章已推出真正的极值一闪而过。

**为什么这个区别重要**：

把 ⚠️ 读成 ❌，就把"本书保持中立"读成了"本书在否定"。
这会导致两种误读：

1. 认为本书在贬低缠论（第 35 章 Q5 会处理这个）；
2. 反过来，把本书的"未检验"当成"已否定"，
   从而不再去做那个检验——而本书恰恰希望读者去做。

<a id="q2"></a>
## Q2 · 唯一的 ✅

**答**：**"前三根 K 线决定全天波动区间"**（第 32 章）。

**为什么它能被标 ✅**：

因为它同时满足了三个条件，而其他经验断言至少缺一个：

| 条件 | 这一条 | 其他多数经验断言 |
|---|---|---|
| **样本量够** | n = 2246 个交易日 | 8 个 / 9 个 / 41 个 |
| **有基准可比** | 随机基准约 61%，实测 97% | 多数没有对照 |
| **可直接判定** | 极值在不在前三根，一看就知道 | 多数需要先定义"有效""赢利" |

**为什么其他断言做不到**：

**样本量**：这条测的是"每一天"，所以一年就有约两百个样本；
而趋势背驰要经过 中枢 → 趋势(16.4%) → 背驰(30%) 的漏斗，
11 年只剩 8 个（第 20 章）。

**基准**：这条的基准可以**解析算出来**（8 根 K 线里极值的位置分布）；
而"背驰有没有用"的基准需要构造对照组，本身就是一个难题
（第 27 章 Q5 专门讨论）。

**可判定性**：这条的观察量是**位置**，客观、无歧义；
而多数断言涉及"力度""有效""赢利"，都需要先操作化。

〔推论〕**一条经验断言能否被检验，
取决于它的"漏斗深度"、"基准可得性"和"观察量的客观性"。**

这解释了本书为什么对不同断言的态度差别很大——
不是立场问题，是这三个条件的差别。

<a id="q3"></a>
## Q3 · 三样追问用 66% 说明

**答**：第 2 条要求追问：**样本量、基准、成本**。

用第 27 章那个 66% 逐一说明：

**一、样本量为什么必要。**

66% 的 n 是 160。这个量级**看起来不小**，但：

- 7 个标的、同一时期 → 样本**不独立**（同期同涨同跌），
  有效样本量远小于 160；
- 所以标准误差按 160 算会被**严重低估**。

如果 n 只有 20，66% 与 49% 的差距完全可能是随机的。
**不知道 n，就无法判断差距是否有意义。**

**二、基准为什么必要。**

66% 单独看很漂亮。但对照组是 **49%**——
差值只有 17 个百分点。

更关键的是：**49% 不是"随机"**（第 27 章 Q4）。
它是这个市场上这类结构的**自然基准**，
已经包含了市场的所有固有特性。

〔推论〕**没有基准的比例数字，无法区分"方法的贡献"与"市场本来就这样"。**

对比第 32 章那条 ✅：97% vs 61%，差 36 个百分点——
基准摆出来之后，那条断言的分量才显现。

**三、成本为什么必要。**

66% 是"下一笔是否超越前一同向笔极值"的比例，
**不含幅度、不含失败时的损失、不含交易成本**。

而第 12 章实测中枢宽度中位数只有 **3.4%**（日线）、
**0.87%**（30 分钟，第 32 章测）。
在这个量级上，一次往返的交易成本占比相当可观（第 37 章会算）。

〔推论〕**一个 66% 命中但每次赢一点、输很多、还要扣成本的规则，
完全可能是亏钱的。**

**三者合起来**：

```text
样本量  → 差距是不是随机的？
基准    → 差距是方法带来的，还是市场本来就这样？
成本    → 差距扣完成本还剩多少？
```

缺任何一个，那个数字都不能支持结论。

<a id="q4"></a>
## Q4 · 用幅度/时间代替结构判据

**答**：本表中至少有五条属于这一类（答出三条即可）。

| 说法 | 用什么代替了结构 | 出处 |
|---|---|---|
| "连续一字板说明级别很大" | 用**时间长度**代替中枢计数 | 第 2、32 章 |
| "这个中枢延伸 7 段了，很快要结束" | 用**段数**代替结构判据（延伸的终止是结构性的） | 第 13 章 |
| "跌得太多了，按走势终完美该结束了" | 用**幅度**代替走势类型的完成判定 | 第 18 章 |
| "价格一直在涨就是上涨趋势" | 用**涨跌**代替"两个不重叠同级别中枢" | 第 14 章 |
| "跌了不少，先减点仓" | 用**幅度**代替卖点判据 | 第 30 章 |

**共同的错误结构**：

```text
观察到一个可见但无关的量（时间/幅度/次数）
  → 用它推出一个结构性结论
    → 而结构性结论的判据里根本不包含这个量
```

**为什么这类错误特别顽固**：

因为幅度和时间是**最容易观察**的量——
不需要划笔、不需要数中枢，看一眼就有。

而结构判据需要走完整个链条（几何层 → 中枢 → 级别），
成本高得多。所以人会**自动**退回到容易观察的量上。

〔推论〕**这类错误不是知识问题，是"便利性"问题**——
所以光知道它错还不够，必须养成**追问判据**的习惯
（第 35 章那条警觉清单的第 3 条）。

## Q5 ·【判读】"这本书把缠论批得一无是处"

**答**：不成立。用本表的**结构**和**内容**两方面回应。

### 一、看强度标记的分布

本表里 ❌ 的条目确实最多。但**❌ 的对象是"流传的说法"，不是"理论本身"**。

这个区分是关键：

| 被标 ❌ 的是什么 | 例子 |
|---|---|
| 对定义的**误读** | "`ZG` 就是最高点" |
| 省略了**条件**的转述 | "小级别背驰可以引发大级别转折" |
| **逻辑跳跃** | "完备性证明了这套方法有效" |

〔推论〕**批评一个说法误读了理论，恰恰预设了这个理论本身是有内容的。**

### 二、看本书对理论本身的处理

本书对**定义与推论**层的评价其实相当正面：

| 本书的判断 | 出处 |
|---|---|
| 分类完备性论证**成立** | 第 28 章 |
| 顶底交替、方向交替等一系列〔推论〕**成立**，且是免费的自检 | 第 7、8、9 章 |
| 中枢三定理**成立** | 第 16 章 |
| 分解定理二是四条里**最硬**的一条 | 第 18 章 |
| 资金管理那几条在逻辑上**相当硬** | 第 34 章 |
| 第 46 课"前三根决定全天"**被数据明显支持** | 第 32 章 |

本书用了整整 14 条自检断言（第 11 章）+ 9 条（第三部分）+ 若干条，
**全部来自缠论自己的定义**——一个没有内容的理论提供不了这些。

### 三、看本书对"不知道"的处理

本书多次明确写"**未检验 ≠ 无效**"：

- 第 21 章："本书的立场是在可得数据上无法判断";
- 第 28 章："'未检验'和'错'是两回事";
- 第 33 章：完全不测，并说明理由链。

〔推论〕**一个为了否定而写的书，不会花篇幅说明自己为什么答不了。**

### 正确的概括

> 本书的立场是：**定义层相当讲究，推论层可以放心用，
> 经验断言层多数在可得数据上还答不了，
> 而流传的说法里有大量误读——后者才是 ❌ 的主要对象。**

## Q6 ·【查证】找十条表外的说法

**答**：开放题。**重点是判断有没有本表遗漏的"类型"。**

**要报的**：

1. 十条说法（注明来源类型：教程 / 视频 / 社群 / 工具文档）；
2. 每条的标签（〔定义〕〔推论〕〔经验断言〕〔不可证伪〕）与强度；
3. 每条归入 🅑 档列的**错误类型**（未声明级别 / 幅度代替结构 /
   结构→收益跳跃 / 记号误用 / 比例无基准 / 省略条件）；
4. **有没有归不进这六类的**？

**第 4 问是本题的核心。**

**可能遗漏的类型**（供参考，如果你找到了就是对本书的补充）：

| 可能的类型 | 例子形态 |
|---|---|
| **诉诸权威** | "缠师说过……"（而不说是哪一课、原文怎么写的） |
| **不可证伪的心法表述** | "要与走势合一""放下贪婪恐惧" |
| **循环论证** | "没赚到是因为没学懂，学懂了就能赚" |
| **幸存者叙事** | "某某用缠论赚了多少"（样本量为 1 且有选择性） |
| **工具与理论混淆** | "某软件画的才是标准缠论" |

⚠️ 特别注意**第三类（循环论证）**：
它在任何方法论社群里都存在，而且**不可证伪**——
因为任何反例都能被归因于"没学懂"。

按本书的标签体系，它属于〔不可证伪〕，
处理方式是**标出来、不当依据用**（第 1 章 1.6 节）。

**加分项**：

- 统计十条里各类型的占比，看和本表的分布是否一致；
- 如果发现了本表没有的类型，**把它加进你自己的辨析库**（🅑 档第三步）；
- 注意有没有说法是**本书判错了**的——
  如果你能给出反例或更好的论证，那对本书是有价值的修正。

> ⚖️ 本书只讲方法与检验，不推荐任何标的、不预测行情、不构成投资建议。
> 市场有风险，任何据此产生的后果由读者自负。
