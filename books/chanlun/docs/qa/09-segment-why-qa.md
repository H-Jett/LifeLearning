# 第 9 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · 为什么笔不是走势类型

**答**：对不上的环节是——**走势类型按"含几个中枢"分类，而笔里数不出中枢**。

**逐步对照**：

| 定义 | 要求什么 |
|---|---|
| 走势类型 | 盘整 = 含 1 个中枢；趋势 = 含 ≥ 2 个中枢 |
| 中枢 | 被至少三个连续**次级别走势类型**重叠的区间 |
| 笔 | 两个相邻分型（一顶一底）之间的方向段，**中间的波动按定义忽略** |

问题出在第一行和第三行之间：

- 要把某个对象归类为"盘整"或"趋势"，**必须能数出它里面有几个中枢**；
- 而笔的定义里，"顶和底之间的其他波动都忽略不算"（第 8 章 8.2 节）——
  它**主动丢弃了内部结构**；
- 没有内部结构，就没有"三个连续次次级别走势类型的重叠"可言，
  自然数不出中枢；
- 数不出中枢，就无法按中枢个数分类，**也就不满足"走势类型"的定义**。

**换个说法**：笔是一个**几何对象**（由两个端点确定），
走势类型是一个**递归对象**（由它包含的下层结构确定）。
两者的构造方式根本不同。

**所以缠论怎么办的**：让笔去**扮演**最低级别的走势类型。
这是一个显式的约定，不是一个恒等——正是 9.2 节说的那处"接缝"。

<a id="q2"></a>
## Q2 ·【标签】"次级别走势类型必须含有次次级别的中枢"

**答**：〔推论〕。

**判别**：

1. 它在规定词义吗？不是——它在陈述一个从已有定义导出的必然性质。
2. 能从定义推出来吗？**能，一步**：
   - 走势类型的定义是"按包含的中枢个数分类"（盘整 1 个、趋势 ≥ 2 个）；
   - 一个不含任何中枢的对象，无法被归入这两类中的任何一类；
   - 所以凡是被称为"走势类型"的东西，必然含有至少一个中枢。
   - 而它含有的那些中枢，按中枢定义，是由**再低一级**的走势类型重叠构成的。
3. 什么观测会推翻它？没有——它的真假只取决于定义。

**为什么这条〔推论〕值得单独拎出来**：

它是 9.2 节整个论证的支点。有了它，"笔是不是走势类型"就从一个感觉问题
变成了一个**可以对照定义检查**的问题：只要问"笔里面数得出中枢吗"，
答案是否定的，结论立刻成立。

**顺带一提**：这条〔推论〕还解释了**为什么必须有最低级别**（第 1 章 1.5 节）。
如果每个走势类型都必须含有更低级别的中枢，而中枢又由更低级别的走势类型构成，
这个链条要是没有底，就永远构造不出第一个对象。
原著第 35 课用"每一笔成交"给了这个底。

<a id="q3"></a>
## Q3 · 逐笔成交为什么没人用，改用笔/线段失去了什么

**答**：数据拿不到；失去的是**级别链的绝对起点**，因而"级别"变成相对的。

### 为什么没人用

**第 4 章的实测结论**：

| 频率 | 本书测试环境下的可得性 |
|---|---|
| 日线 | 可得，2015 年至今完整 |
| 5 分钟 | 可得，但**最早只到 2020-01-02** |
| **逐笔成交** | **不提供** |

免费数据源根本不给逐笔。商业数据源有，但：

- 数据量极大（逐笔比日线大好几个数量级），存储与计算成本都高；
- 历史深度通常有限且昂贵；
- 即便拿到，从逐笔一路递归上来，层数会非常多，计算不现实。

所以"每一笔成交是最低级别"在理论上自洽，在实践中**不可执行**。

### 改用笔/线段失去了什么

**失去的是级别链的绝对起点，因此级别从"绝对层数"退化成"相对层数"。**

具体展开：

1. **起点不同，层数就不同**。
   从逐笔起步的链和从笔中枢起步的链，同一段行情上数出来的"第 3 层"
   不是同一个东西。
2. **"某某级别"失去跨实现的可比性**。
   甲用笔中枢起步、乙用线段中枢起步，两人说的"次级别"差了一层。
   这和第 3 章 3.2 节"周期不是级别"是同一类问题的另一个侧面——
   一个来自**用时间近似层数**，一个来自**用几何对象近似最低走势类型**。
3. **接缝处多了一个约定**（9.2 节）。
   笔/线段要"扮演"走势类型，而它们本身不是按中枢个数定义的。

### 但没有失去什么

诚实起见，也要说清楚代价的边界：

- **级别之间的相对关系仍然成立**。本级别由次级别构成、
  趋势需要两个同级别中枢——这些都不依赖起点在哪。
- **同一套实现内部完全自洽**。只要全程用同一个起点，
  所有判据照常工作。
- 所以这不是"缠论错了"，而是**"你的级别"和"原著定义的级别"不是一回事**，
  需要在交流时说明。

<a id="q4"></a>
## Q4 ·【判读】每三笔切一段

**答**：违反了"**线段方向必然交替**"这条〔推论〕；
而且还漏掉了原文的第二个下界条件——**前三笔必须有重叠**（第 65 课）。

**推理链**：

1. **他的理由**："原文说线段至少三笔"——他把**下界**当成了**完成条件**，
   而且只记住了两个下界条件中的一个（漏了"前三笔有重叠"，第 65 课）。
2. **下界 ≠ 完成**：原著第 18 课讲中枢时说得很明确，三段重叠之后
   **随时可以完成，也可以不断延伸下去**。线段同理：攒够三笔只说明它
   **有资格**叫线段，不说明它**已经走完**。
3. **机械切段会发生什么**：一个实际由 7 笔构成的线段，会被切成
   "3 笔 + 3 笔 + 1 笔"。前两段的方向**是相同的**（因为它们本来属于同一段），
   于是输出里出现了**同方向的两段相连**。
4. **为什么这违反〔推论〕**：线段的两个端点必然是一顶一底
   （同第 8 章 8.6 节的论证），而顶底严格交替（第 7 章 7.3 节），
   所以线段方向必然交替。同向相连是不可能的。

**为什么这条〔推论〕可以当自检用**（本题的第二问）：

因为它满足一个好断言的三个条件：

| 条件 | 说明 |
|---|---|
| **从定义推出** | 不依赖任何数据或参数，所以失败一定是实现错 |
| **检查成本极低** | 遍历一遍线段列表比较相邻方向即可，O(n) |
| **覆盖面广** | 线段划分的多数错误（切早了、切晚了、漏了、多了）最终都会表现为方向不交替 |

所以它应该和第 6、7、8 章那几条断言一起，写进几何层的测试套件。
这是本书反复用的模式：**每往上搭一层，就收获一条免费的自检断言**。

| 层 | 自检断言 |
|---|---|
| 包含处理 | 输出无包含关系；幂等；长度不增 |
| 分型 | 顶底严格交替；顶底数量差 ≤ 1 |
| 笔 | 方向交替；端点一顶一底；笔数 ≤ 分型数 − 1 |
| 线段 | **方向交替**；每段 ≥ 3 笔 |

<a id="q5"></a>
## Q5 · 线段怎么"吸收"笔层面的差异

**答**：因为一个线段由多笔构成，而**改动其中一笔往往不改变线段的端点**。

**机制**：

1. 线段至少三笔，实践中常常更多。
2. 线段的端点只取决于**首尾**——中间那些笔的具体划法，
   只要不影响破坏判定，就不会改变这个线段的起止位置。
3. 所以当两种成笔标准（老笔 / 新笔）在某处给出不同的笔划分时，
   若差异发生在**线段中部**，两种划分会得到**端点相同的同一个线段**。

**打个比方**：一条路由若干路段拼成，中间某一段是走小路还是大路，
不改变这条路的起点和终点。

**什么时候吸收不掉**（边界条件，这部分同样重要）：

| 情形 | 会不会被吸收 |
|---|---|
| 差异发生在线段中部 | **会**——端点不变 |
| 差异发生在线段**端点处** | **不会**——端点直接改变 |
| 差异影响到**破坏判定**（第 10 章） | **不会**——可能整段被切开或合并 |
| 差异导致笔数从 3 降到 2 | **不会**——不足三笔，线段不成立 |

所以准确的说法是：

> **线段吸收掉的是"中部的"差异，吸收不掉"端点处的"和"影响破坏判定的"差异。**

**这解释了什么**：公开资料里常说"老笔新笔的差异对分段影响不大"——
机制就在这里。本书第 8 章测出笔数只差约 9%，而这 9% 里又有相当一部分
会落在线段中部被吸收掉，所以**线段数的差异应当小于 9%**。

⚠️ "应当小于"是一个推理，不是实测。本书把这个量留到第 11 章一起测。

<a id="q6"></a>
## Q6 ·【查证】笔中枢还是线段中枢

**答**：本题没有唯一答案，重点是**判断出来，并说明你的判断依据**。

**合格答案必须包含**：

1. **出处**（仓库 / 教程，可查的标识）；
2. **结论**：笔中枢 / 线段中枢 / 两者都提供 / 判断不出；
3. **依据**——你是从哪里看出来的。

**怎么判断**（从易到难）：

| 线索 | 怎么看 |
|---|---|
| 函数或变量名 | `bi_zhongshu` / `xd_zhongshu` / `stroke_pivot` / `segment_pivot` 这类命名 |
| 中枢构造的**输入** | 找到算中枢的函数，看它接收的是笔列表还是线段列表——**这是最可靠的依据** |
| 有没有实现特征序列 | 完全没有特征序列相关代码，基本可以断定是笔中枢（线段划分离不开它，第 10 章） |
| 中枢的数量级 | 笔中枢会比线段中枢多得多。和本书的基线对照能有个粗判 |
| 文档措辞 | 直接写明的最省事，但**这类实现是少数** |

**大概率会观察到的现象**（这正是本题的目的）：

- 多数实现**没有明说**，要靠读代码里中枢函数的入参来推断；
- 有些实现两种都提供，但**默认值**藏在参数里，使用者不改就不知道自己在用哪个；
- 少数实现在文档里说"实现了缠论中枢"，而代码里其实只有笔中枢——
  这不算错，但使用者会以为自己拿到的级别和别人的可比。

**加分项**：

- 注意到该实现有没有在**输出里标注**中枢的类型
  （只给一个"30 分钟中枢"而不说是笔还是线段中枢，对方无法复核）；
- 把同一段数据分别用笔中枢和线段中枢跑一遍，**统计中枢数量之比**——
  把定性判断变成数字；
- 注意到它是否**混用**：比如低级别用笔中枢、高级别用线段中枢，
  却没有说明两者如何衔接。

**典型不合格答案**：

- 只写"它用的是缠论标准算法" → 没有定位到具体依据；
- 断言笔中枢"不正规" → 两条路线都有人用，本书不判优劣（9.5 节）。
  要评价的是**有没有声明**，不是选了哪个。
