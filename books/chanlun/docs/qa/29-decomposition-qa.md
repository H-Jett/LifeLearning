# 第 29 章 · 思考题参考答案

> 本册**只记「问题 + 正确答案」**，不记读者作答。想清楚再看。

<a id="q1"></a>
## Q1 · 结合律与多义性

**答**：

**结合律**（第 36 课）：走势类型的连接满足 `A+B+C = (A+B)+C = A+(B+C)`，
而且 `A`、`B`、`C` 的**级别可以不同**。

**为什么带来多义性**：

结合律意味着同一段走势可以被**重新括号**。
把括号打在不同位置，就得到不同的"组成单元"，
于是同一段走势可以写成不同级别的分解：

```text
A = A₁₋₁ + A₁₋₂ + ⋯      （按最低级别）
  = A₅₋₁ + A₅₋₂ + ⋯      （按中间级别）
  = A日₋₁ + A日₋₂ + ⋯     （按更高级别）
```

**这些分解都是合法的**——它们描述的是同一段走势，只是**粒度不同**。

〔推论〕**多义性来自"可以选择在哪一层上看"，而不是来自"定义含糊"。**

**一个已经用过的例子**：第 20 章 Q5——当 `A` 的级别大于 `B` 时，
把 `a+A+b+B+c` 重新括号为 `a+A+(b+B+c)`，
于是它从"趋势"变成了"围绕 `A` 的盘整"。两种写法都合法，
但**哪一种适用由级别关系决定**，不是随便选的。

<a id="q2"></a>
## Q2 · 允许什么、不允许什么

**答**：

| | 允许 | 不允许 |
|---|---|---|
| 内容 | 选择**用哪一套分解规则**（哪个级别） | 同一套规则下出现**多种结果** |
| 依据 | 结合律（第 36 课） | 第 38 课：好的分解必须保证唯一性 |

原著的原话大意是：多义性就像解题时设定不同的参数——
参数设定有随意性，但好的设定让问题变简单；
而且**一个好的分解，其规则下必须保证分解的唯一性**。

**"看起来像多义性、其实是约定分歧"的例子**：

甲乙都在"以日线周期近似的那个级别"上分解同一段走势，
结果甲划出 5 笔、乙划出 7 笔。

甲说："这是缠论的多义性。"

**错**。两人：

- 在**同一个级别**上；
- 分歧发生在**几何层**（笔的划分），不是走势类型的组合层；
- 而几何层的输出是「价格序列 + 约定集」的确定性函数（第 11 章 Q2）。

所以这是**约定分歧**：两人的 22 项约定里至少有一项不同。
按第 11 章实测，仅"成笔失败处理"一项就能让笔端点重合率低到 26.2%。

〔推论〕**能通过统一约定消除的分歧，都不是多义性。**

**判别方法**（很实用）：

> 问一句："如果我们用完全相同的 22 项约定重跑，结果会一样吗？"
> 会 → 之前的分歧是约定分歧；
> 不会 → 才可能是多义性（或者有 bug）。

<a id="q3"></a>
## Q3 · 三条结构性考虑与取舍

**答**：

| # | 考虑 | 来源 |
|---|---|---|
| 一 | **级别越高，样本越少** | 第 17 章：级别链 3~4 层，顶层中枢个位数 |
| 二 | **级别越低，约定敏感性越高** | 第 24 章 24.3 节：每降一级叠加一次约定影响 |
| 三 | **级别越低，成本占比越高** | 第 12 章：日线中枢宽度中位数 3.4%，更低级别更窄 |

**它们怎么构成取舍**：

```text
级别低  →  ✅ 样本多，可以积累经验、可以做统计检验
        →  ❌ 成本占比高、约定敏感、T+1 限制执行

级别高  →  ✅ 成本占比低、约定影响被线段/中枢吸收
        →  ❌ 样本极少（一生可能只遇到几次），无法积累经验
```

〔推论〕**这是一个真正的取舍，没有"最优级别"这种东西**——
它取决于你的资金量、时间、成本水平，而这些是外部条件。

**第一条尤其值得强调**：

"大级别更可靠"是一个很流行的直觉，但第 17 章的实测给了它一记反驳——
顶层中枢只有个位数意味着：

- 你**无法通过经验改进**在那个级别上的判断（样本太少）；
- 你**无法验证**它的有效性（统计不可能）。

所以"大级别更可靠"这个信念，在大级别上恰恰是**最难被检验**的。

<a id="q4"></a>
## Q4 ·【判读】"看到日线也涨就改成日线持有"

**答**：这是**事后改规则**，问题有三层。

**一、换档时机没有事先规定。**

按 29.5 节，换档在结构上是可行的（同级别分解的等式列保证了
小级别与大级别描述的是同一段走势）。但**换档条件必须事先写死**。

他的换档触发条件是"看到日线也涨"——
这是一个**在看到结果之后**才启用的规则。

**二、两套判据的信号位置不同。**

30 分钟级别的卖点和日线级别的卖点在不同位置。
他在 30 分钟上"本该卖出"的地方改成了继续持有——
这不是"换了个视角"，而是**取消了一个已经触发的信号**。

〔推论〕**换档如果发生在信号触发之后，等于用另一套规则来否决当前规则的结论。**
这在任何规则体系里都是不允许的。

**三、这是一个有方向的偏差。**

值得注意的是：人们通常**只在赚钱的时候换档到更高级别**
（"还能涨，拿住"），而在亏钱的时候不会换
（很少有人说"我亏了，改成月线级别持有"）。

〔推论〕**这种不对称会系统性地放大持有时间，
使得"赢时小赚、输时大亏"——**
这恰恰是第 34 章要讲的资金管理问题。

**正确的做法**：

在**开始之前**把换档规则写死，比如：
"当 L+1 级别出现第三类买点时，升级为 L+1 操作级别"——
然后**无论盈亏都照此执行**。

<a id="q5"></a>
## Q5 ·【标签】"小级别操作可自动换档"

**答**：〔推论〕。

**判别**：能从同级别分解的结构直接推出。

推导：按结合律，`A = A₅₋₁ + A₅₋₂ + ⋯ = A日₋₁ + A日₋₂ + ⋯`——
两个等式描述的是**同一段走势**。
所以若干连续的小级别走势类型累加起来，**恰好构成**一个大级别走势类型。

既然两种分解描述同一对象，视角就可以在任意时刻切换——
不需要任何额外假设。

**⚠️ 但本书补了一条限定**（29.5 节）：

换档在**结构上**可行，不等于在**操作上**无代价。
换档意味着换一套判据，而两套判据的信号位置不同。

所以准确的表述是：

> 〔推论〕结构上，小级别分解与大级别分解可以互相转换。
> 〔约定〕换档的**时机**是一个必须事先规定的选择，不是结构性质。

**为什么要做这个区分**：

原著讲换档时着重讲了它的可行性（"自动模式换档"），
读者容易把"可以换"读成"可以随时换"。
而 Q4 说明了：随时换（尤其是看到结果再换）会引入系统性偏差。

<a id="q6"></a>
## Q6 ·【查证】两个级别的分解对比

**答**：实操题。**重点看买卖点的位置重合率。**

**要报的量**：

1. 两个级别下走势类型的**段数**；
2. 三类买卖点的**数量**（分别报三类）；
3. **位置重合率**——L 级别的买卖点，有多少能在 L+1 级别找到对应；
4. 样本量、22 项约定。

**预期会看到的现象**：

| | L（低级别） | L+1（高级别） |
|---|---|---|
| 段数 | 多 | 少（约为 L 的 1/4，第 17 章实测的层间衰减比） |
| 买卖点数量 | 多 | 少 |
| 重合率 | —— | **低**——高级别的点大多能在低级别找到对应，反之不然 |

**注意这个不对称**：

这与第 5 章测均线参数时看到的结构**完全一样**——
慢参数的事件近似是快参数事件的子集（第 5 章 5.3 节）。

所以要**双向都算**：

```text
L+1 的点 → 能在 L 中找到对应的比例   （预期：高）
L 的点   → 能在 L+1 中找到对应的比例  （预期：低）
```

只算一个方向会漏掉这个结构。

**加分项**：

- 报告 L 级别那些**找不到 L+1 对应**的买卖点，
  它们是否集中在某一类（预期：第三类最多，因为它最高频）；
- 验证第 26 章的买卖点定律：L+1 的第二类买点，
  是否对应 L 的第一类买点？报告**匹配率**（不会是 100%，见第 26 章 Q2）；
- 用第 29 章 🅑 档第二步的唯一性断言检查两个级别的分解是否各自唯一。
