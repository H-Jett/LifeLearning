## 这本书讲什么

把缠论的定义链条讲透——
**包含处理 → 分型 → 笔 → 线段 → 中枢 → 走势类型 → 级别 → 背驰 → 三类买卖点**——
讲到读者能自己在图上标出来、能自己写成代码。

同时对每一条主张打标签，这是全书最重要的体例：

| 标签 | 含义 | 怎么对待 |
|---|---|---|
| 〔定义〕 | 理论自己的规定 | 照着用，不争对错 |
| 〔推论〕 | 从定义严格导出 | 看推导；能写成代码的就验证 |
| 〔经验断言〕 | 要事实才能判真假 | 说清怎么检验，能跑就跑 |
| 〔不可证伪〕 | 事后永远为真 | 标出来，**不当依据用** |

判别方法只有一句话：**问"什么样的观测会推翻它？"**

## 与其他缠论材料的区别

1. **不按原著课号顺序**。原著是 2006–2008 年的时间序博客合集，
   前十几课讲的是一套被作者自己取代的均线框架。本书按定义依赖关系重排。
2. **不搬运原文**。原著仍在著作权保护期内。本书只转述定义、标注课次、
   给出自己的论证与检验，引用原文只引短句且必须作为被评注的对象。
3. **该说"不知道"就说**。本书掌握的原文只到第 48 课，
   分型 / 笔 / 线段的严格定义在其后，相关章节会明确标注"据公开转述，未见原文"。
4. **能跑的都跑**。行情数据免费可得，所以凡是能写成代码的判据就写成代码，
   并且跑之前先填预登记表。

## 本地构建

```bash
pip install mkdocs-material pyyaml

python scripts/check_book.py     # 校验
mkdocs build --strict            # 严格构建

# 或在仓库根上构建本书（必须带 --only，不带会清空整个 site/）
python ../../scripts/build_site.py --only chanlun
```
