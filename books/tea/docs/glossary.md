## 一、成分与化学

<a id="tea-polyphenols"></a>
### 茶多酚（Tea polyphenols）
茶叶中多酚类物质的总称，占干物质约 18%~36%，主体是[儿茶素](#catechin)类（占茶多酚 70%~80%）。
感官上贡献**苦**与**涩**，是茶汤滋味的最大可变量，也是红茶氧化产物的原料。
测定方法见 GB/T 8313。

<a id="catechin"></a>
### 儿茶素（Catechins）
属黄烷醇类，茶多酚的主体。分两组：
- **酯型儿茶素**（复杂儿茶素）：EGCG、ECG —— 苦涩强、收敛性强；
- **非酯型儿茶素**（简单儿茶素）：EGC、EC、C —— 苦涩较弱、偏爽口。

**EGCG**（Epigallocatechin gallate，表没食子儿茶素没食子酸酯）是含量最高的单体儿茶素。
"总多酚相同但口感不同"的主要原因之一，就是两组的比例不同。

<a id="theanine"></a>
### 茶氨酸（L-theanine）
茶树的**特征性氨基酸**，占茶叶游离氨基酸总量一半以上（不同资料给 40%~70%）。
呈**鲜**（umami）带甜的味感，且能在感官上**掩盖苦涩**。遮阴栽培可提高其含量。
游离氨基酸总量测定见 GB/T 8314。

<a id="caffeine-tea"></a>
### 咖啡碱（Caffeine，茶叶中亦称茶素）
生物碱，占干物质 2%~4%，呈**苦**味，溶解度随温度显著升高。
能与[茶黄素](#theaflavin)、[茶红素](#thearubigin)络合，低温析出形成[冷后浑](#cream-down)。
测定方法见 GB/T 8312。

<a id="phenol-amino-ratio"></a>
### 酚氨比（Ratio of polyphenols to amino acids）
`茶多酚含量 ÷ 氨基酸含量`。判断茶树品种**适制性**与滋味走向的常用单一指标：
比值低 → 鲜爽（适制绿茶）；比值高 → 浓强苦涩（适制红茶）。
常见经验划分：<8 适制绿茶、8~15 兼制、>15 适制红茶（**各教材略有差异**）。

<a id="water-extract"></a>
### 水浸出物（Water extract）
规定条件下能被水浸出的物质总量，典型为干物质的 30%~48%。对应茶汤的浓度上限与"耐泡度"。
**只反映总量、不反映结构**，因此可作为"内质单薄"的下限门槛，不能单独作为高品质依据。
测定方法见 GB/T 8305。

<a id="theaflavin"></a>
### 茶黄素（Theaflavins, TF）
儿茶素氧化聚合的产物，红茶中典型 0.3%~1.5%。呈**橙黄色**、汤色**明亮**，
带鲜爽与刺激性，是红茶"浓、强、鲜"的主要来源。

<a id="thearubigin"></a>
### 茶红素（Thearubigins, TR）
氧化产物中含量最高的一类，红茶中典型 5%~11%。呈**红色**，滋味甜醇，是红茶汤色的主体。

<a id="theabrownin"></a>
### 茶褐素（Theabrownins, TB）
深度氧化/聚合产物，红茶中典型 4%~9%，黑茶中更高。呈**暗褐色**，滋味**滞钝**。
含量过高对应审评词"红暗""欠亮""味钝"。

<a id="cream-down"></a>
### 冷后浑（Cream down）
红茶茶汤冷却后变浑浊甚至出现乳凝的现象。机制是咖啡碱与茶黄素/茶红素形成络合物，
低温下溶解度降低而析出。**不是变质**，传统上视为内含物丰富、品质好的正面表征。

<a id="astringency"></a>
### 涩（Astringency）
**不是味觉，而是触觉/化学感**：多酚与唾液蛋白结合沉淀，口腔黏膜润滑性下降，
产生收敛、发干的机械感。特征是**有延迟**、**会累积**、覆盖整个口腔。
必须与[苦](#bitterness)分开记录。

<a id="bitterness"></a>
### 苦（Bitterness）
**味觉**，由咖啡碱、酯型儿茶素等刺激苦味受体产生。即时发生、舌根明显、会疲劳适应。

<a id="hui-gan"></a>
### 回甘 / 生津（Hui-gan / salivation）
咽下后口腔返回甜感（回甘）与唾液持续分泌（生津）。现象稳定存在且与品质相关，
但**生理机制尚有争议**（对比效应 / 缓慢释放 / 反射性分泌等假说）。本书照记现象，不把任何机理当定论。

## 二、原料与栽培

<a id="suitability"></a>
### 适制性（Processing suitability）
一份鲜叶（由品种、季节、生态、嫩度决定的成分格局）**更适合被加工成哪一类茶**。
它是"原料格局"与"工艺改造方向"的匹配问题，**不是品质高低问题**。

<a id="shaded-cultivation"></a>
### 覆下栽培 / 遮阴栽培（Shaded cultivation，日语「覆下栽培」）
采摘前若干天遮去大部分光照。效果是减少多酚合成、利于茶氨酸累积 → 酚氨比大幅下降 → 极致鲜爽。
日本玉露、抹茶的关键农艺手段。代价是产量下降、成本上升、香气类型改变。

<a id="cultivar"></a>
### 品种 / 茶树品种（Cultivar）
栽培品种。大叶种（如云南大叶种）多酚高、浓强，适制红茶与普洱；
小叶种（江浙一带）酚氨比低、鲜爽细腻，适制绿茶。
⚠️ 这个二分法**只是统计趋势**：变种间儿茶素平均差异约 6%，而种质个体间差异超过 4 倍，
且各分类单元可自由杂交形成**连续渐变群（cline）**——不能从变种名推断个体。

<a id="terroir-shanchang"></a>
### 山场（Shanchang，产地小环境）
茶行业对"具体那一小块地"的说法，最典型是武夷岩茶的**正岩 / 半岩 / 洲茶**之分。
它不是独立的玄学变量，而是**多个已知变量在一小块地上的特定组合**：
岩壁挡光（漫射光多）、谷地（湿度高、温差特殊）、砾质土（保水又透气，正岩含砂砾 24%~29%、
孔隙度约 50%）、钾锰含量高而酸度适中。
⚠️ "正岩/半岩"的市场边界近年已漂移，不同年代文献指的不是同一块地。

<a id="fish-leaf"></a>
### 鱼叶（Fish leaf）
新梢基部第一片发育不完全的小叶，形似鱼鳞。**通常不采**——产地讲"留鱼摘"。
原料中鱼叶多会使成品可溶出物质偏少、品质降低，还影响下一季产量。

<a id="dui-jia-ye"></a>
### 对夹叶（Banjhi leaf）
顶芽停止生长后形成的两片对生叶，**无正常芽**。是"这根新梢已停长"的信号。
适中采时可兼采幼嫩对夹叶，但它与正常新梢的成分格局不同，做实验取样时应排除。

<a id="tender-stem"></a>
### 嫩梗（Tender stem）
芽叶之间的嫩茎。**[茶氨酸](#theanine)含量比芽叶高 1~3 倍**，
所以乌龙、白茶带梗是正常且必要的，日本"茎茶"以此为独立品类。
挑梗干净属于外形净度（规格），不是滋味指标。

<a id="kai-mian-cai"></a>
### 开面采（Plucking at "open face"）
乌龙茶等特种茶的采摘标准：新梢长到 3~5 叶将成熟、顶叶六七成开面时采下 2~4 叶。
三档按顶部第一叶与第二叶的面积比：

- **小开面** ≈ 第二叶的 1/2（夏暑茶、持嫩性强的茶园）
- **中开面** ≈ 2/3（**春、秋茶常用**）
- **大开面** ≈ 与第二叶相当

**三叶中开面梢最适制乌龙茶**。采太嫩 → 色泽红褐灰暗、香低味涩；采太老 → 粗大淡薄。
另有**细嫩采**（名优茶：单芽/一芽一二叶初展）、**适中采**（大宗茶：一芽二叶为主，最普遍）、
**成熟采**（边销茶：一芽四五叶）。

<a id="wu-fen-kai"></a>
### 五分开（采摘的均一性要求）
品种分开、早午晚青分开、粗叶嫩叶分开、干湿茶青分开、不同地片分开。
**这是硬要求**：后续所有工艺参数都按原料均一性设定，原料不匀则同一套参数对其中一部分必然是错的，
最终暴露为**叶底花杂**。

## 三、工艺（第二部分展开）

<a id="fermentation-tea"></a>
### "发酵"（Fermentation，茶叶语境）
茶行业沿用的历史名词。**除黑茶外，六大茶类里的"发酵"指的都不是微生物发酵**，
而是以多酚氧化酶催化的**酶促氧化**。真正的微生物参与只出现在黑茶/熟普的渥堆等后发酵工艺。
（第 4、11 章展开。）本书统一区分下面三种机制：

<a id="ppo"></a>
### 多酚氧化酶（PPO, Polyphenol Oxidase）
催化多酚氧化的铜结合酶，是茶叶转化的核心酶。茶叶中另有过氧化物酶（POD）等也参与氧化。

**关键：底物与酶在活细胞里是分开存放的**——多酚在液泡、酶在质体等细胞器，被膜隔开。
所以叶片完好时氧化不会大规模发生，必须靠**揉捻/摇青破坏细胞结构**让两者相遇。

**温度决定它的命运（指叶温）**：

| 叶温 | 状态 |
|------|------|
| 20~45 ℃ | 最适活动区，每升 10 ℃ 活性**翻倍** |
| 70 ℃ | 开始钝化、变性 |
| 80~85 ℃ | 凝固破坏，基本灭活 |

这套节点直接推出杀青要求（最短时间冲过活跃区）、以及晒青（<80 ℃ 保留部分活性 → 普洱可陈化）
与烘炒青（>90 ℃ 彻底破坏）的分野。

<a id="enzymatic-oxidation"></a>
### 酶促氧化（Enzymatic oxidation）
由茶叶**自身**的 [PPO](#ppo) 等酶催化的氧化反应。绿、白、黄、青（乌龙）、红茶的转化主体。
路径：儿茶素 → 邻醌 → 联苯酚醌 → [茶黄素](#theaflavin) → [茶红素](#thearubigin) →
[茶褐素](#theabrownin)。**这条链单向推进**，所以"过度发酵"的结果是暗而淡，不是更浓。

<a id="wet-heat"></a>
### 湿热作用（Wet-heat / non-enzymatic action）
**非酶**的化学变化，靠温度 + 水分推动（多酚非酶氧化、多糖水解等）。
出现在闷黄、干燥、渥堆等环节。与酶促氧化的区别是**不依赖酶活性**，
所以在酶已灭活的茶坯中仍会持续——这是"杀青后要马上摊凉"和红茶"宁轻勿重"的原因。

<a id="microbial-action"></a>
### 微生物作用（Microbial action）
外来微生物及其**胞外酶**主导的转化，**只出现在黑茶/熟普**等后发酵茶。
这是六大茶类里**唯一名副其实的"发酵"**。见 [渥堆](#pile-fermentation)。

<a id="fixation"></a>
### 杀青（Fixation / "kill-green"）
用高温使多酚氧化酶失活，**终止酶促氧化**，把成分"冻结"在接近鲜叶的状态。绿茶的关键工序。

<a id="withering"></a>
### 萎凋（Withering）
鲜叶失水并伴随内含物缓慢转化的过程。白茶工艺的核心，也是乌龙、红茶的前置工序。

<a id="men-huang"></a>
### 闷黄（Men-huang / yellowing）
黄茶的关键工序：在温和的[湿热](#wet-heat)条件下使茶多酚轻度氧化、多糖部分水解。
**"黄变"只是表象，"转味"才是实质**（去青气与生涩，转为甜醇）。

不是一道工序而是**一类手法**（堆闷/包黄/渥闷/堆黄/摊黄），常在不同工序**多次进行**。
按位置分三类：杀青后闷黄、揉捻后闷黄、毛火后闷黄。

⚠️ **是否含酶促作用学界表述不一**：一说属湿热作用，一说是利用**残余酶**的轻度酶促氧化。
本书采"**以湿热为主、可能伴残余酶**"——因为杀青后酶活性大幅下降但未必归零
（见 [PPO](#ppo) 的温度节点），残留多少取决于杀青程度，两种说法可容纳于同一框架。

<a id="cell-rupture"></a>
### 细胞破损率（Cell rupture rate）
揉捻/揉切造成的细胞结构破坏程度，决定多酚与 [PPO](#ppo) 接触的充分程度。
**不是越高越好**：红碎茶破损率最高、[茶黄素](#theaflavin)最高、浓强度最好，
但**香气与甜度明显不如工夫红茶**——因为破损过强会使其它酶活性降低、
水解反应减弱，而水解产生的可溶性糖与氨基酸正是甜与部分香气的来源。
即"浓强"与"香甜"是需要权衡的两个目标。

<a id="pile-fermentation"></a>
### 渥堆（Pile fermentation）
黑茶/熟普的后发酵工艺：晒青毛茶洒水、覆盖堆积，堆高约 **1~2 m**，
**中心温度可达 40~60 ℃**，靠[微生物](#microbial-action)及其胞外酶把多酚深度转化为
[茶褐素](#theabrownin)与水不溶性多酚。

**黑曲霉是优势菌种**（约占微生物总量 80%），产约 20 种水解酶（葡萄糖淀粉酶、纤维素酶、果胶酶等），
把多糖、纤维、果胶、蛋白分解成单糖、氨基酸、水化果胶等可溶物——这是熟普"甘、滑、醇厚"的物质基础。
⚠️ **不同黑茶的优势菌不同**（茯砖等以灰绿曲霉为主、米砖黑曲霉、康砖青霉、六堡多种），
"黑茶"是工艺类别，不是一种微生物过程。

## 四、审评（第三部分展开）

<a id="five-factors"></a>
### 五因子（Five factors）
标准感官审评的五个评价维度：**外形、汤色、香气、滋味、叶底**。方法见 GB/T 23776。

<a id="dry-wet-evaluation"></a>
### 干评 / 湿评（Dry / wet evaluation）
干评看未冲泡的干茶（外形、色泽、匀整度、净度）；湿评评冲泡后的汤色、香气、滋味、叶底。

<a id="reference-sample"></a>
### 对样评茶（Evaluation against a reference sample）
以标准样（实物参考样）为基准做相对判断，而非凭绝对记忆打分。是评茶保持一致性的核心手段。
