# 项目 P1 · 参考答案

> 对应《项目 P1：从工艺特征反推茶类与工艺缺陷》的四张工艺侦探卡。

<a id="card-a"></a>

## 卡 A

最可能是**绿茶，且可能杀青不足或原料/加工中保留了较重青气**。翠绿、黄绿汤、嫩绿叶底和鲜爽是
绿茶线索；“青草气、涩而不化、生青味”是需要回查杀青和原料的线索。不能仅凭涩感断言杀青不足，
因为高酚原料、投茶量或浸泡过度也能造成涩；需补充加工信息，或在标准化冲泡下与已知绿茶对照。

<a id="card-b"></a>

最可能是**乌龙茶**。叶缘红、中央绿是做青造成局部氧化的强线索，花香与轻焙火香指向做青后杀青、
再焙火的路径。具体是闽南、闽北、广东或台湾风格，不能靠这些信息确定。

<a id="card-c"></a>

它可能是**氧化/转化过度的红茶，或储存后出现劣变的茶样**；红浓、暗褐叶底、不苦却木和平、
香低闷共同支持“茶褐素方向过多”的候选。碎末也可能来自红碎茶工艺而非缺陷。要区分红茶过度、
黑茶风格和仓储问题，必须补产品标签、是否有霉味/受潮史、叶底活性及对照样。

<a id="card-d"></a>

这是**以绿茶为茶坯的茉莉花茶**。最终产品是花茶/再加工茶，花香指向窨制；绿茶鲜爽提示茶坯。
包装名称提供了强佐证，但不能从花香强度推出窨制次数，也不能凭是否看见花瓣判断品质或是否添加香精。

<a id="method"></a>

## 项目方法的参考答案

“缺陷”和“风格”的分界不在某个单一词上，而在**多项线索是否共同指向失控**：例如焙火香可以是
乌龙茶风格，若同时出现焦苦、炭化叶底与香低，才更支持火候过度；陈香可以是陈化风格，若同时有
霉味、受潮、汤浊与叶底糊烂，才应优先怀疑仓储问题。追加观察应尽量独立，例如从香气再看叶底和
包装/储存信息，而不是把同一感受换个词重复一次。
