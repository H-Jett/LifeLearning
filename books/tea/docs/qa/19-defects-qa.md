# 第 19 章 · 思考题参考答案

<a id="q1"></a>
## 1. 烟气何时是风格，何时更像缺陷？

先看产品是否有熏焙工艺，再看烟气是否纯正、协调，还是刺鼻、焦苦并掩盖主体香气。后者若还伴随
焦斑或香低，受热/污染异常的候选更强。

<a id="q2"></a>
## 2. 为什么仓味不能叫陈香？

陈香描述可能被接受的陈化气息；仓味通常指潮湿、不洁或陈旧异气。二者在纯度、协调性及仓储
含义上不同，不能用“陈香”给仓储异常背书。

<a id="q3"></a>
## 3. 审评面对霉味能做什么、不能做什么？

能记录霉味、汤浊、受潮、叶底糊烂等异常，并建议停止把它当正常风格、检查产品；不能鉴定具体
霉菌或毒素含量，也不能替代食品安全检测。
