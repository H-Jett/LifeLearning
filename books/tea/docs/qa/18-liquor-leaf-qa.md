# 第 18 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么“红浓”不自动等于“红浓明亮”？

红浓主要写色类和色度；明亮写光泽与明暗度；还须另看清浊。一杯茶可红浓但暗、或红浓但浑，
所以三个维度必须分别记录。

<a id="q2"></a>
## 2. 三条异常证据如何改变判断？

闷气、平钝和暗褐不匀分别来自香气、滋味和叶底，若同时出现，会加强“转化/储存异常”的候选；
但仍要排除冲泡过度、样品受潮史和产品类型，不能只凭此锁定一个工艺错误。

<a id="q3"></a>
## 3. 叶底匀整支持什么？

它支持原料规格或受热/转化较一致的判断；不能单独证明高等级、单一产地、树龄或价格合理。
