# 第 20 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么分数不是永久属性？

分数是特定样品、冲泡条件、对照样、评审者和权重下的压缩结果。任一坐标变化，分数含义都会变化；
它不是附着在茶叶上的固定物理量。

<a id="q2"></a>
## 2. 为什么先评语后给分？

评语保留五因子的差异来源，数字只是最后汇总。先写评语可防止品牌或直觉先锚定一个数字，
也使之后能解释“为什么多/少几分”。

<a id="q3"></a>
## 3. 两个 90 分为什么不可直接比较？

若茶类、目标风格、审评协议、对照样或评分者不同，“90”并不在同一标尺上。它们可能各自在
自己的标准中表现出色，但不能由此推出横向等价。
