# 第 22 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么“矿泉水”不足以预测结果？

这是产品类别而非单一理化变量。不同水样的钙、镁、碳酸氢盐、总溶解固体、pH 等都可能不同，
而茶样本身也不同；名称不能代替测量和对照。

<a id="q2"></a>
## 2. 为什么要固定其他参数？

水温和投茶量也会改变溶出与感官。若它们同时改变，就无法把观察到的差异归因于水，实验没有解释力。

<a id="q3"></a>
## 3. 为什么一次对比不能外推所有茶？

一次结果只说明该茶样、该水样、该冲泡条件下的表现；不同茶类的成分、形态和冲泡方式不同，
需要在新的条件下重新验证。
