# 第 14 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么干评不能代替湿评？

干评看的是原料规格、整形、色泽、整碎与净度等外形信息；它看不到冲泡后才出现的汤色、
香气、滋味和叶底。外形符合规格不代表内质协调，反过来某些外形特征也可能只是产品路线。

<a id="q2"></a>
## 2. 为什么不能一概说“碎茶多所以差”？

条形绿茶碎末增多，可能反映运输破损、筛分不足或包装损耗；但红碎茶本就通过揉切加工形成
颗粒或碎片，以获得不同的萃取和滋味目标。判断先要问产品原本的设计是什么，再判断是否符合
它的规格，不能把一种形态标准套在所有茶上。

<a id="q3"></a>
## 3. 如何改写“汤色红浓好看”？

例如：“主色橙红；色度较深；明亮度较好；茶汤清澈、未见明显悬浮物。”若实际观察到的是
暗或浑，应如实写“红浓欠亮”或“红褐欠清”，不能用“好看”掩盖差异。

<a id="q4"></a>
## 4. 为什么叶底放在末尾看？

叶底在完成香气、汤色和滋味观察后，能为前面的工艺推断提供一份相对独立的证据。例如前面
怀疑转化不均，若叶底也红绿花杂，推断增强；若叶底均匀完整，则应重新考虑冲泡参数、储存或
个人感知。它不是“最后才重要”，而是避免先看叶底让预期污染前面记录的顺序设计。
