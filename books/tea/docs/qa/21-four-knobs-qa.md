# 第 21 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么茶水比与时间不是同一个动作？

茶水比主要改变杯中浓度；时间改变浸出持续多久及后段物质的相对比例。二者都可能减弱苦涩，
但对香气、厚度和成分结构的影响不同，不能视作完全等价。

<a id="q2"></a>
## 2. 为什么紧压茶不能直接套散茶时间？

紧压茶需要吸水、解块，水接触内部叶片的路径不同；同样时间下实际浸出程度可能与散茶差异很大。

<a id="q3"></a>
## 3. 太淡不苦时如何调整？

可先选择一个方向，如略提高茶水比或延长时间；选择取决于你想保留的香气与口感。一次只改一项，
才能知道变化是由浓度还是浸出时间造成，而非混合结果。
