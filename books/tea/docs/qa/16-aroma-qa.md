# 第 16 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么“花香高”不完整？

它只说明类型和部分浓度；还须记录香气是否纯正、是否持久、是否有青气或闷气等异杂气，
并与滋味、汤色和叶底一起判断协调性。

<a id="q2"></a>
## 2. 三种温度状态补充什么？

热香捕捉挥发快、冲击强的部分；温香更便于辨别类型与纯度；冷香补看留香和细节。它们是不同
挥发条件下的观察，不能用其中一次代替全部。

<a id="q3"></a>
## 3. 为什么焦气不能立刻等于焙火过度？

焦气可能来自焙火，也可能来自其他受热环节或外来污染。需要看是否伴随焦苦、焦斑、香低，
并核对产品本身是否有熏焙风格，才能加强“受热过度”的推断。

<a id="q4"></a>
## 4. 如何改写“茉莉花茶很香”？

例如：“热香为明显茉莉花香，强度较高；温香仍清晰、较纯，无明显闷气；冷却后留香中等。
茶汤仍有绿茶鲜爽底子。”这描述样品表现，不从中推出窨制次数或是否高价。
