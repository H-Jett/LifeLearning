# 第 13 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么标准审评常不等于“最好喝的一泡”？

标准审评要固定条件并放大样品差异，让香气纯度、滋味协调、叶底状态等信息更容易暴露；
日常冲泡则服务个人偏好。前者是比较和检验工具，后者是饮用方案，目标不同，因此不应互相替代。

<a id="q2"></a>
## 2. 为什么不能用单一因子完成工艺判断？

单一现象通常有多个原因。比如汤色深可能来自充分氧化，也可能来自过度转化、仓储劣变、
投茶过量或浸泡过久。还要同时看香气是否低闷、滋味是否平钝、叶底是否暗褐不匀，才能让
“转化过度”成为较强候选，而非只凭颜色下结论。

<a id="q3"></a>
## 3. 四种程序各减少什么误差？

密码编号减少品牌、价格、产地等身份线索引起的期待偏差；随机呈样减少顺序和对比效应；
对样减少每个人心中“好茶”标准不同造成的漂移；先记后议减少群体讨论中锚定、从众和措辞
传染。它们降低误差，但不能消除样本、方法与训练的全部局限。

<a id="q4"></a>
## 4. 如何改写“这茶很顺、很高级”？

例如：“汤色橙黄明亮、无明显悬浮物；香气为清甜花香，纯度较好；入口苦感低，涩感弱且
不滞留；中段有一定厚度，回甘出现较快；叶底颜色较匀整。”这些仍是个人感官记录，但已能
让别人按同样维度复核。不能从这些观察直接推出“高级”、产地或价格合理性。
