# 第 3 章 · 思考题参考答案

> 只记录问题与参考答案。对应正文《第 3 章 3.9 思考题》。

## 1. 名优绿茶采单芽，乌龙茶为什么要等"中开面"？

**参考答案**：因为两者**要的东西根本不同**。

**从目标风味看**：

- **绿茶**要的是**鲜爽**。绿茶工艺（杀青）不改造多酚，成茶滋味几乎直接反映鲜叶的酚氨比。
  所以必须用酚氨比最低的部位——芽和第一、二叶。
- **乌龙茶**要的是**香气的复杂度 + 醇厚的滋味 + 层次**。它的风味主要由**做青**（第 9 章）
  这一步创造出来，鲜叶不是成品的直接投影，而是**工艺的底物**。

**从成分梯度看**：

- 芽尖部位氨基酸、咖啡碱比例高、酚氨比低 → 直接对应鲜爽；
- 而成熟叶片提供的是**转化底物与香气前体**。本章给了一个直接的暗示：
  '紫娟'新梢中 **第三叶的 EGCG3″Me 含量最高（1.24%）**，高于鲜叶整体（1.05%），
  而 EGCG3″Me 恰恰是第 2 章提到的**乌龙茶适制性标记物**。
  也就是说——**乌龙需要的某些成分，恰恰不在最嫩的部位。**

**还有一层物理原因**：做青要靠摇青使叶缘细胞**有控制地损伤**，太嫩的叶片过于柔软、
含水量高，经不起摇，无法形成"绿叶红边"那种局部氧化。**成熟叶片有足够的机械强度**。

**实证结论**：据鲜叶内含成分分析，**三叶中开面梢最适宜制乌龙茶**；
采太嫩成茶色泽红褐灰暗、香低味涩，采太老则外形粗大、滋味淡薄。

## 2. "茶氨酸嫩梗比芽叶高 1~3 倍"能解释哪三件事？

**参考答案**：至少三件：

1. **乌龙茶、白茶带梗是正常且必要的**，不是偷工减料。梗带来的是鲜甜与厚度，
   挑光了梗反而损失茶氨酸。
2. **日本"茎茶"（茎ほうじ茶 / かりがね）能作为独立品类存在**，且口感偏甜鲜——
   它的原料就是加工中分离出来的茶梗。
3. **挑梗挑得太干净可能是审美而非品质**。干茶"净度"是外形指标（第 3.6 节：等级是规格），
   把它当成滋味指标就错了。

**可以补第四件**：某些茶的"回甘、厚度好但芽头不多"，别急着当缺陷——
先看它的梗和成熟叶比例。

## 3.（推测题）乌龙采太嫩为什么会"又暗又涩"？

**参考答案**：这是道推理题，答案要点在于**做青需要什么样的叶片**。

**为什么涩**：

- 嫩叶的**酯型儿茶素（EGCG、ECG）比例更高**（本章 3.3 节：EGCG、ECG 随伸育程度递减，
  也就是越嫩越高），而酯型儿茶素正是苦涩最强的那一组（第 1 章 1.3 节）；
- 乌龙是**半发酵**，多酚只被部分氧化。如果原料本身酯型儿茶素高、而氧化又不彻底，
  留下的就是**没转化掉的强涩物质**；
- 嫩叶含水量高、组织柔软，做青时**失水与走水不顺畅**，多酚转化不充分 → 涩感留存。

**为什么暗（色泽红褐灰暗）**：

- 嫩叶柔软、细胞脆弱，摇青时容易**大面积无控制地破损**（而不是只损伤叶缘）→
  酶促氧化在整片叶子上失控发生 → 氧化过度、生成偏多的深色聚合产物（茶褐素方向）→
  色泽转向红褐、发暗；
- 同时叶绿素在这个过程中被破坏，绿色褪去而褐色显现 → **灰暗**。

**归纳成一句话**：乌龙茶要的是**局部、可控**的氧化（绿叶红边），
而嫩叶给出的是**整体、失控**的氧化。这与"发酵不足留涩"叠加，就得到"又暗又涩"。

> 本题结论会在第 9 章（乌龙茶：做青与焙火）验证。这里允许你先推，
> 推理路径比结论重要。

## 4. "明前茶氨基酸高"的机理链，以及它在哪不适用？

**参考答案**：

**机理链（可靠）**：

```
越冬期养分充分积累 + 早春气温低、生长慢
   → 氮代谢占优、碳代谢受抑
   → 氨基酸偏高、茶多酚偏低
   → 酚氨比低 → 鲜爽、苦涩轻
```

清明后气温升高、生长加快 → 氨基酸降低、茶多酚上升 → **涩味增加**。

**不适用的范围（四条）**：

1. **茶类**：明前/雨前的说法**一般只用于绿茶或类似绿茶的茶类**。
   **铁观音一般谷雨才开采**，**六安瓜片在谷雨前后采**——这两类本来就没有"明前"之说。
   所以"明前铁观音"是概念错位。
2. **产区**：这是**江南茶区**（浙、湘、赣、皖南、苏南、鄂南等）按节气对春茶阶段的称呼。
   云南、福建等地的气候节律不同，套用节气意义有限。
3. **风味目标**：对需要**浓强度**的茶类（红茶、岩茶），酚氨比低反而不是优势——
   第 2 章讲过夏茶更适制红茶。
4. **"越早越好"本身不成立**：明代许次纾《茶疏》就说"清明太早，立夏太迟，**谷雨前后，其时适中**"；
   雨前茶内含物也较丰富，**往往滋味更浓、更耐泡**。

**额外要分清的一层**：明前茶受追捧还有非成分因素——早春虫害少、产量稀少。
这些是真实价值（安全性、稀缺性），但**不等于滋味更好**。

## 5. "五分开"为什么是硬要求？不做会在哪暴露？

**参考答案**：

**五分开**指：品种分开、早午晚青分开、粗叶嫩叶分开、干湿茶青分开、不同地片分开。

**为什么是硬要求**：因为后续所有工艺（萎凋、做青、杀青、发酵、干燥）的参数——
温度、时长、失水率、摇青轻重——都是**按原料的均一性设定的**。

> 一筐茶青里混着不同品种、不同嫩度、干湿不一，
> **同一套工艺参数对其中一部分必然是错的**。

具体地说：

- 嫩叶与老叶**失水速率不同** → 同一萎凋时间，一部分萎凋过度、一部分不足；
- 干湿不一 → 杀青时一部分焦、一部分不透；
- 不同品种的酶活性与成分格局不同 → 同一发酵时长，一部分过度、一部分欠发酵。

**会在哪暴露**：主要在**叶底**，其次是**香气与滋味**：

| 审评项 | 表现 |
|--------|------|
| **叶底** | **花杂**（颜色深浅不一、老嫩不匀）——这是最直接、最难掩盖的证据 |
| 香气 | 不纯、杂气（部分欠发酵的青气 + 部分过度的闷气同时存在） |
| 滋味 | 青涩与闷味并存，层次乱 |
| 外形 | 匀整度差 |

**所以有一条实用的诊断经验**：审评看到"**叶底花杂**"，root cause 常常在**采摘环节**
（原料不匀），而不是制茶师傅的手艺。第 19 章会系统讲这类"从哪一步坏的"判断。

## 6. "特级比一级好喝"可能错在哪？

**参考答案**：至少四处。

1. **混淆了规格与品质**。等级主要描述**嫩度、匀整度、净度、外形**，即"规格"；
   "好喝"是滋味与香气。两者相关但不等价。
2. **不同品名之间的等级不可比**。"特级寿眉"和"特级白毫银针"里的"特级"，
   指的是各自品名下的规格，含义完全不同——不能横向比较。
3. **嫩不一定适口**。对乌龙、黑茶，成熟原料是**必需**的；
   纯芽头的绿茶外形好但内含物不及一芽一二叶丰富，**龙井特级用的就是一芽一、二叶**。
4. **等级由具体产品标准定义**，不同标准（国标/地标/企标）的等级划分不同。
   看到"特级"必须先问：**按哪个标准、哪个品名的特级？**

**再加一条实践层面的**：等级不覆盖**新鲜度与储存状况**。
一款存坏了的特级，绝对不如一款状态好的一级。

## 7.（进阶）怎么设计一个可靠的分叶位成分梯度实验？

**参考答案**：核心难点是**把"叶位"这一个变量从一大堆混杂因素里拆出来**。

**取样设计**：

1. **单一品种、单一茶园、单一批次**——把品种和环境固定住（第 2 章的两层）；
2. **同一天、同一时段采摘**（避开"早午晚青"差异）；
3. **只取发育状态一致的新梢**：例如统一取"一芽五叶且顶芽未停长"的梢，
   排除对夹叶梢（顶芽已停长的梢，其成分格局不同）；
4. **按叶位逐一分离**：芽、第一叶、第二叶、第三叶、第四叶、第五叶、**嫩梗分段**——
   梗必须单列，因为茶氨酸在梗中高 1~3 倍；
5. **足量重复**：每个叶位设生物学重复（不同植株、不同小区），报告均值 ± 标准差，
   而不是单株单次。

**必须控制/记录的变量**：

| 变量 | 为什么 |
|------|--------|
| 品种、树龄、栽培管理 | 第 2 章：种质内变异可达 4 倍 |
| 采摘日期与季节 | 春/夏/秋成分差异可达数倍 |
| 当日天气、是否雨水叶 | 含水量影响以干基计算的结果 |
| 采后到固样的时间 | **最容易被忽略**：鲜叶离体后酶促氧化立刻开始，必须**立即杀酶固样**（如液氮/蒸汽固定），否则测的是"已经变化过的叶子" |
| 干燥与磨碎方式 | 应按 GB/T 8303 制备试样，以**干物质**为基准 |
| 测定方法 | 茶多酚/儿茶素按 GB/T 8313、氨基酸按 GB/T 8314、咖啡碱按 GB/T 8312——否则数据无法与文献比较 |

**要避免的混杂因素**：

- **叶位与叶龄混淆**：同一梢上第三叶比第一叶"老"，但不同梢之间发育进度不同——
  必须靠"统一梢发育阶段"来对齐；
- **梗混进叶片样**：会系统性抬高氨基酸值；
- **只测总量不测组分**：总多酚相同而酯型/非酯型比例不同，结论会误导（第 1 章 1.3 节）。
  应至少测儿茶素单体（EGCG/ECG/EGC/EC/C）。

**加一步会让结论更有用**：把每个叶位的样**分别做成茶并做感官审评**，
建立"成分梯度 → 感官"的对应。否则你只有化学数据，仍然回答不了"该采到第几叶"。

> **这道题的意义**：它解释了为什么本章找不到可靠的分叶位定量表——
> **要做对，成本很高**。也因此，网上那些没有出处的漂亮表格，应当默认不可信。
