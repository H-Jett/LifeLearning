# 第 15 章 · 思考题参考答案

<a id="q1"></a>
## 1. 如何改写“很香很顺”？

例如：“热香为清甜花香，强度中等偏高；温香仍较清晰，未见明显异气；入口苦感较低；
涩感弱且不滞留；中段较醇和，咽下后有轻微回甘。”这比总评更可复核，但仍应说明冲泡条件。

<a id="q2"></a>
## 2. 为什么“像桂花”不等于成分鉴定？

它是评审者把气味归入个人记忆参照的结果，同一气味可由不同挥发物组合形成，且不同人记忆库
不同。除非进行了针对性的化学分析，不能从一个感官词直接断言某种物质存在或某一道工艺发生。

<a id="q3"></a>
## 3. 四个程度词分别问什么？

浓/淡问总体滋味强度；强/弱问刺激和冲击；厚/薄问口腔饱满或单薄；醇通常是对柔和、协调、
少粗涩的整体判断。它们可同时高低不同，例如一杯茶可以浓而薄、强而不醇，故不能互换。

<a id="q4"></a>
## 4. 哪些是记录，哪些需要额外证据？

“回甘强”可作为感官记录，但应进一步写出现时机、持续性和比较对象；“霸气”不是明确的
规范因子，应拆成苦、涩、浓强、刺激等观察；“老班章”是产地/产品身份，需要标签和溯源；
“很值”是价格判断，需要成本、市场和个人预算等额外证据，不是感官结论。
