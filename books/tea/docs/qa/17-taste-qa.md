# 第 17 章 · 思考题参考答案

<a id="q1"></a>
## 1. 为什么苦涩必须分开？

苦主要是味觉，常即时出现；涩是收敛、发干等触觉，常有延迟和累积。两者可能由不同成分比例、
工艺与冲泡条件造成；分开记录才能让后续诊断知道究竟是哪条线出了问题。

<a id="q2"></a>
## 2. “浓而薄”和“淡而厚”是什么？

浓而薄指滋味强度明显，但口腔饱满度不足、结构单一；淡而厚指整体强度不高，却有一定稠实、
柔和或饱满感。它们说明浓淡和厚薄是两条独立维度。

<a id="q3"></a>
## 3. 为什么“顺”仍需拆开？

“顺”是整体印象，可能来自低涩、醇和、厚度适中或余味干净。拆开记录后，别人才能知道它是
如何顺，也能在下一泡或另一款茶中判断这个印象是否稳定。

<a id="q4"></a>
## 4. 为什么先查冲泡变量？

水温、时间、投茶量、细碎度和解块程度会显著改变茶汤中苦涩物质的溶出。它们是可控且高频的
替代解释；先排除它们，再结合香气、叶底和对照样讨论工艺，结论才不至于过度。
