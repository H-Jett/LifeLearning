# 系统学茶：从一片叶子到一杯茶汤

> 一本"走走停停"的茶学入门书，深度对标**评茶员知识体系**：工艺原理 + 茶叶化学 + 感官审评。
> 力求**正确**：所有数值标注出处，流传的说法逐条标注证据强度，
> 拿不准的地方明确写"有争议"而不含糊过去。

## 这本书的核心观点

> **茶的一切技术问题，本质都是一件事——让哪些成分、以多少比例、进入茶汤。**

- **工艺**在定向改造成分（六大茶类的分野就是改造程度的分野）；
- **冲泡**在选择性溶出成分（四个旋钮各自调的是不同分子）；
- **审评**在从感受反向读出成分格局。

所以这本书不从"记名字"开始，而是**先建立机理，再挂名字**。

## 怎么读这本书

- **术语**首次出现处有脚注，全称与解释汇总在[术语表](glossary.md)。
- 每章有**「常见说法辨析」**栏目：把茶圈流传的说法逐条标注
  ✅ 有共识 / ⚠️ 有争议 / ❌ 明确错误。
- 每章末有**思考题**（指向[答案册](qa/01-leaf-chemistry-qa.md)），以及**本章实操**，分两档：
  - **🅐 无器具版**——不用买茶具茶样，现在就能做；
  - **🅑 有条件版**——需要盖碗/秤/温度计/茶样，标注"备齐后再做"。
- **不做医疗建议**：茶与健康只陈述研究现状与证据等级（第 37 章）。

## 关于正确性的三条纪律

这本书没有 GPU 可以跑数据来自证，所以正确性靠纪律维持：

1. **数值必须有出处**：国标编号 / 教科书 / 明确标注"行业经验值"，并说明波动范围。
   **不编造精确数字**——宁可写"典型在 x~y 区间，因品种季节差异很大"。
2. **区分「机理」与「说法」**：证据不足的一律标注证据强度，不含糊其辞。
3. **数字只当示例，讲的是规律**：要带走的是"为什么"，不是背表格。
