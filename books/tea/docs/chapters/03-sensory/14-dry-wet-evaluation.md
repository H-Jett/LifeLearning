# 第 14 章 干评与湿评：先看“原料和做工”，再看“茶汤和叶底”

> **本章问题**：为什么不能只喝一口就给茶下结论？干茶、茶汤和叶底分别在替你排除什么误判？

GB/T 23776 将审评拆为外形、汤色、香气、滋味和叶底。实操时常把它组织为**干评**和**湿评**：
先在干茶状态看外形，再在冲泡后看、闻、尝并检查叶底。[^standard]

## 14.1 干评：还没加水，已经能看到很多事

干评主要评外形。对初制茶，外形通常综合形状、嫩度、色泽、整碎和净度；精制茶则更强调
形状、色泽、整碎和净度。[^standard] 这不是“看着漂亮就高分”，而是查看产品是否与其目标规格一致。

| 观察项 | 问什么 | 可能提供的线索 | 不能单独证明什么 |
|--------|--------|----------------|------------------|
| 形状 | 条、针、扁、卷、颗粒是否符合该产品的设计？ | 整形工艺、规格一致性 | 产地、树龄或滋味必然好 |
| 嫩度 | 芽叶比例、粗细、毫与叶质怎样？ | 原料等级与采摘规格 | “越嫩越好”的跨茶类结论 |
| 色泽 | 润、枯、匀、花杂？ | 干燥、焙火、氧化及储存状态的候选线索 | 单凭颜色锁定茶类或年份 |
| 整碎 | 完整度、碎末比例如何？ | 加工、运输、筛分和包装损耗 | 碎茶一定低级（红碎茶是特定产品路线） |
| 净度 | 梗、片、非茶夹杂物是否异常？ | 精制与卫生控制 | 嫩梗一定是杂质（有些茶带梗是风格需要） |

紧压茶还要看形状规格、松紧度、表面光洁度与色泽；分里、面茶时还需留意起层脱面、
包心外露等。[^standard] 这正说明审评是**按产品类型选择观察点**，不是一张表生搬到底。

## 14.2 湿评：按照固定顺序，让样品留下多种证词

```mermaid
flowchart LR
    A[同条件冲泡] --> B[嗅热香]
    B --> C[看汤色]
    C --> D[尝滋味]
    D --> E[嗅温香/冷香]
    E --> F[看叶底]
    F --> G[记录事实，再综合]
```

具体冲泡参数应按 GB/T 23776 对应茶类和产品的规定执行；不要从某一类茶的审评参数，
推成所有茶的家庭冲泡参数。对初学者而言，最重要的是**两样比较时保持同一条件**：
器具、水、投茶量、水温、浸泡时间和出汤动作都尽量一致。

### 汤色：先分色类，再看亮度与清浊

汤色不是只写“黄/红/绿”。至少拆成三层：

| 层次 | 记录问题 | 示例写法 |
|------|----------|----------|
| 色类 | 主色是什么？ | 黄绿、橙黄、橙红、红褐 |
| 明暗 | 明亮、尚亮、暗？ | 橙黄明亮；红浓欠亮 |
| 清浊 | 清澈、尚清、浑浊？ | 清澈；有悬浮物、欠清 |

“浓”描述的是颜色深度，不能替代“亮”；“红”描述色类，也不能替代“清”。把它们混成
“红浓好看”，别人就无法判断问题究竟在色度、明度还是浑浊度。

### 香气：同一杯茶，热闻、温闻和冷闻是在问不同问题

热香帮助捕捉易挥发、强度高的部分；温度下降后再闻，更容易辨认细节与纯度；冷却后的
留香可补充持久性信息。它们不是三次重复，而是同一香气在不同挥发条件下的截面。

不过，闻到某个词不等于已经找到分子或工艺原因。第 16 章会把“类型、浓度、纯度、持久性”
分开；此处先练习把每一次闻香的温度状态写下来。

### 滋味：把入口、中段、尾段分开

一口茶的感受会变化。建议至少写：

| 时段 | 可记录项目 |
|------|------------|
| 入口 | 浓淡、苦感、鲜感、刺激性 |
| 中段 | 厚薄、醇和度、涩感及其累积 |
| 咽下后 | 回甘、生津、余味、是否滞留或有异味 |

不要把“没有苦”自动记为“醇”。一杯茶可能淡而无苦，也可能厚而苦涩协调；这是不同维度。

### 叶底：最后看，是为了让它替前面的推断交叉作证

叶底看嫩度、色泽、明暗和匀整度。它尤其适合检验两个猜测：原料是否均匀、受热/转化是否一致。
例如，若汤色和香气提示工艺不均，再看到叶底红绿花杂或焦斑，推断才变强；若叶底均匀完整，
就应回头考虑是否是冲泡或储存条件造成的感受差异。

## 14.3 一个可复用的记录顺序

| 步骤 | 只记录什么 | 暂时不写什么 |
|------|------------|--------------|
| 干评 | 形、色、整碎、净度 | “值不值钱” |
| 热香 | 强度、第一印象、异常气 | 山场/品牌猜测 |
| 汤色 | 色类、明暗、清浊 | “一定是老茶” |
| 滋味 | 浓淡、厚薄、苦涩鲜钝、余味 | 健康功效 |
| 温/冷香 | 类型、纯度、持久性 | 某个化合物的断言 |
| 叶底 | 嫩度、色泽、明暗、匀整 | 以一片叶底替全部样品下结论 |
| 综合 | 与目标样/另一样的相对差异 | 把偏好伪装成事实 |

## 14.4 常见说法辨析

| 说法 | 判定 | 说明 |
|------|------|------|
| “干茶好看，泡出来一定好” | **❌ 错误** | 外形只能提供规格与加工线索；香气、滋味和叶底仍须独立审评。 |
| “碎末多一定品质差” | **⚠️ 需看产品类型** | 对条形茶可能提示损耗或筛分问题；红碎茶等产品则以颗粒/碎片为设计形态。 |
| “茶汤越深越浓越好” | **❌ 错误** | 色类、色度、明暗和清浊必须分开；深而暗、浑不等于好。 |
| “叶底只是泡完的废料” | **❌ 错误** | 叶底是核查原料均匀性、受热与转化一致性的重要证据。 |
