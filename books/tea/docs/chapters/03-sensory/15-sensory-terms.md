# 第 15 章 审评术语：不是背词库，而是把观察写成别人能复核的句子

> **本章问题**：为什么“香、顺、高级”不是合格审评记录？怎样既不装腔，也不丢掉感受？

GB/T 14487 是茶叶感官审评术语的规范来源。它的价值不在于给感受贴上唯一正确的名字，
而在于让记录至少包含**对象、特征、程度和异常与否**。[^terms]

## 15.1 一句合格记录的最小语法

```text
〔因子〕 + 〔特征 / 类型〕 + 〔程度〕 + 〔纯度、均匀性或持续性〕
```

| 不够用的总评 | 改写为可复核记录 |
|--------------|------------------|
| “很香” | 香气为清甜花香，较高，较持久，纯度较好 |
| “汤色漂亮” | 汤色橙黄明亮、清澈 |
| “很顺” | 入口苦感低，涩感弱；中段较醇和；咽下后无明显滞涩 |
| “叶底不错” | 叶底嫩度尚好，黄绿较匀整，无明显焦斑 |

这仍不是仪器数据，却已经允许另一个人按同一因子检查你究竟在说什么。

## 15.2 先用规范维度，再加个人联想

个人记忆非常有价值：它能帮助你识别“像栀子、熟果、烤坚果”之类的气味。但个人联想
应放在可交流维度之后。

| 因子 | 先记录的规范维度 | 再补充的个人联想 |
|------|------------------|------------------|
| 香气 | 类型、浓度、纯度、持久性 | 像某种花、果、谷物或木质气息 |
| 滋味 | 浓淡、厚薄、醇涩、纯异、鲜钝 | 像蜂蜜、坚果、药草的联想 |
| 汤色 | 色类、明暗、清浊 | 像琥珀、杏黄等视觉比喻 |
| 外形/叶底 | 形、色、嫩度、匀整、净度 | 触感、画面感描述 |

“像什么”是一个假设性比喻，不是成分鉴定。若你写“桂花香”，更稳妥的含义是“我把它
归到桂花这类记忆参照”，不是“茶中已被证明含有桂花的全部挥发物”。

## 15.3 程度词不是装饰词，是比较尺

审评中的“高、低、浓、淡、强、弱、厚、薄、鲜、钝”不能互换。最实用的做法是每次只在
**同一组对照样**里使用它们：

| 词 | 问的问题 | 不等于什么 |
|----|----------|------------|
| 浓/淡 | 可感知滋味物质的总体强度如何？ | 厚/薄，也不等于苦/涩 |
| 强/弱 | 刺激或冲击感如何？ | 品质高/低 |
| 厚/薄 | 口腔中的饱满、稠实或单薄感如何？ | 汤色深/浅 |
| 鲜/钝 | 鲜爽活性或迟钝平滞感如何？ | 是否加了“鲜味剂” |
| 醇/涩 | 是否柔和协调，还是收敛发干？ | 有苦/无苦 |

没有对照样时仍可记录，但应少用绝对级词，多写原始观察，例如“涩感在咽下约十余秒后增强”。

## 15.4 评语的四条纪律

1. **一因子一行**：不要用“香甜顺滑”跨越香气与滋味；
2. **先正面后异常**：先写主体特征，再注明青、焦、烟、酸、霉、闷等异气异味；
3. **把不确定写出来**：分不清花香还是果香，就写“花果香倾向，待对照确认”；
4. **避免从词跳到故事**：术语只能描述样品表现，不能自动推出山场、树龄、价格或功效。

## 15.5 常见说法辨析

| 说法 | 判定 | 说明 |
|------|------|------|
| “术语越多，审评越专业” | **❌ 错误** | 术语必须与实际观察对应；堆砌词汇会降低可复核性。 |
| “个人闻到什么就是什么” | **⚠️ 不充分** | 个人联想可记录，但需要与类型、纯度、强度及对照样分开。 |
| “苦就是不醇，涩就是不顺” | **❌ 错误** | 苦是味觉、涩是收敛触感；醇和是整体协调判断，三者不可互代。 |
| “标准术语限制表达” | **❌ 错误** | 标准维度是共同坐标；你仍可在其后加个人比喻。 |
