# 🛠 项目 P2 · 自建审评表 + 30 天盲品训练计划

> **交付物**：一张自己实际会用的五因子表、一组稳定的对样记录，以及一份知道边界的个人词库。

## P2.1 先做你的最小表，而不是复制一套华丽词库

| 因子 | 原始观察 | 程度/方向 | 与对样相比 | 不确定处 |
|------|----------|-----------|------------|----------|
| 外形 | | | | |
| 汤色 | | | | |
| 香气（热/温/冷） | | | | |
| 滋味（入口/中段/尾段） | | | | |
| 叶底 | | | | |

只保留你能稳定辨认的词。词库不是越大越好；一个能反复正确使用的“青气”，胜过十个靠猜的花名。

## P2.2 30 天节奏：重复优先于样品数量

| 周期 | 任务 | 成功标准 |
|------|------|----------|
| 第 1 周 | 同一款茶重复记录 3 次 | 参数与五因子记录完整 |
| 第 2 周 | 两款茶固定条件对样 3 次 | 能写出稳定差异，而非只猜身份 |
| 第 3 周 | 加入密码编号 | 揭晓前不写产地、价格、等级猜测 |
| 第 4 周 | 回看全部记录、删掉不稳定词 | 建立个人“能用/待确认”词库 |

### 🅐 无器具版

用过往茶评、图片和包装完成第 1 周的表格练习：练的是分因子记录与“不知道”，不假装闻到了香气。

### 🅑 有条件版

每周至少一次双样盲评。保持水、器具、投茶量、时间不变；同伴随机编号；每次先记录后揭晓。

## P2.3 结业复盘

1. 我最稳定的三个词是什么？
2. 我最常混淆的两条线索是什么？
3. 哪个判断过去受包装或价格影响最大？
4. 下一轮只准备训练哪个因子？

本项目不产生“评茶证书”，也不能用 30 天记录替代专业训练；它的价值是建立一个可复查的个人基准。
