# 🛠 项目 P5 · 一次真实选购决策复盘

目标：把“想买”拆成可解释、可复盘的决定。建议从小规格样品开始，而不是用一次大额购买验证理论。

## 🅐 无器具版

选一个准备购买的商品页，填下表并写出“不买”的条件。

| 项目 | 记录 |
|------|------|
| 用途、总预算与价格口径 | |
| 可核验的产品/批次/储存信息 | |
| 无法核验的叙事 | |
| 替代品与比较口径 | |
| 我愿意承担的不确定性 | |
| 不买/改买小样的触发条件 | |

## 🅑 有条件版

购买小规格样品后，保留包装，做一次盲评并在一周后复盘：

1. 实际感受与购买前证据是否一致？
2. 哪个字段对判断最有帮助？
3. 下次会增加、删除或改变哪个核验步骤？

**交付物**：一条可复用的购买规则，例如“批次与贮存条件不明时，只买可承受损失的小样，或不买”。
