# 第七部分小结（速查）：回到证据与当期来源

健康、历史和职业信息最容易被一句漂亮话过度简化。先确认来源与对象，再决定如何使用。

| 领域 | 最重要的边界 |
|------|--------------|
| 健康 | 茶饮、提取物、观察关联与治疗结论不能混用 |
| 历史 | 文献记录有时代与作者边界，不能外推为全部日常 |
| 考试 | 报名条件和评价机构以当期官方公示为准 |
| 标准/术语 | 先看适用范围与版本，再引用编号或英文 |
