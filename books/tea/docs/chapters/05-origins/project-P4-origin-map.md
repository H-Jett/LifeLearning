# 🛠 项目 P4 · 谱系盲品地图

目标不是猜中“山头”或国家，而是训练：让观察支持**候选路线**，并清楚标出不确定性。

## 🅐 无器具版

从三张茶包装中遮住产区名，只保留原料、形态、工艺和标准信息。为每张卡写两个候选产品路线，
并在打开产区名后记录：哪些线索真的有用，哪些只是名称联想？
