# 🛠 项目 P3 · 控制变量冲泡矩阵

选择一款茶，建立属于你的参数曲线，而非复制网红配方。

## 🅐 无器具版

先写实验卡：只选一个变量（时间、水温或茶水比），其他条件固定；预先写下你预测会变的是苦、涩、鲜、厚还是香气。

## 🅑 有条件版：3×3 矩阵

选一个变量设三档，连续做三次；第二轮才换下一个变量。每格只记五因子中的差异方向。

| 变量档位 | 浓淡 | 苦 | 涩 | 鲜/厚 | 香气 | 下次决定 |
|----------|------|----|----|-------|------|----------|
| 低 | | | | | | |
| 中 | | | | | | |
| 高 | | | | | | |

**交付物**：一条“在我的茶、我的水、我的器具下，若想更鲜/更厚/更少涩，我先调哪个旋钮”的条件句。
它不是通用配方；换茶、换水或换器具就应重新标定。
